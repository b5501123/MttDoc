# 新手常見錯誤

## 本章學習目標

1. 識別短牌新手最常見的 5 大錯誤
2. 理解每個錯誤的具體危害

## 前言

從 NLH（德州撲克）轉來的玩家，常常在短牌中踩入相同的陷阱。這些錯誤大多源於把 NLH 的直覺硬套在短牌上。本章將詳細分析 5 個最致命的錯誤，每個錯誤都配有具體的手牌情景和正確做法。

---

## 錯誤 1：用德州的牌型順序（忘了 Set > Straight，Flush > Full House）

### 錯誤描述

這是短牌最常見也最致命的錯誤：新手在關鍵時刻用了德州撲克的牌型順序，導致直接的籌碼損失。

### 具體危害場景

**場景 A：誤以為順子擊敗三條**

```
桌面情況：
你的手牌：J♠ T♠
公共牌：8♥ 9♦ A♣ K♣ 7♥

河牌攤牌，你有：7-8-9-T-J（順子）
對手攤出：A♥ A♦（三條 A，因為公共牌有 A♣）
→ A♥ A♦ A♣ K♣ 9♦ = 三條 A

你以為順子比三條大（德州的直覺），叫 "我贏了！"
實際上：短牌中三條（Set）> 順子
你輸了！
```

**場景 B：誤以為葫蘆擊敗同花**

```
桌面情況：
你的手牌：A♠ K♠
公共牌：Q♠ J♠ 9♥ 9♦ 8♠

河牌結束：
你的最佳 5 張：A♠ K♠ Q♠ J♠ 8♠ = 同花（A 高，5 張 ♠）

對手的手牌：9♠ 9♣（口袋 9，公共牌有兩張 9）
對手最佳 5 張：9♠ 9♣ 9♥ 9♦ A♠ = 四條 9！（不是葫蘆）

好吧，換個例子：
對手手牌：A♥ 9♠
公共牌：Q♠ J♠ 9♥ 9♦ 8♠
對手最佳 5 張：9♠ 9♥ 9♦ A♠ A♥ = 葫蘆（9 over A）

短牌結果：你的同花（A 高）> 對手的葫蘆
德州直覺：葫蘆 > 同花，以為自己輸了...

新手錯誤：以為自己輸了，不敢下注，導致贏了但沒有建立底池！
或者更糟：主動 Fold 同花面對對手的葫蘆全押！
```

### 正確做法

**記憶方法**：「短牌顛倒中間兩組」

```
德州：... > Full House > Flush > ... > Straight > Three of a Kind > ...
短牌：... > Flush > Full House > ... > Three of a Kind > Straight > ...
        ↑↑↑ 這兩對對調了 ↑↑↑
```

**每次坐下短牌桌前**：在紙上或心裡默念：
「Flush > Full House，Three of a Kind > Straight」

**實戰技巧**：在翻牌後，每次評估手牌時，重新確認牌型順序，不要依賴德州直覺。

## 錯誤 2：用德州的 Outs 計算（每 Out 不是 2%，是 3%）

### 錯誤描述

使用德州的「Rule of 2 and 4」（每張 Out × 2% 計算轉牌，× 4% 計算兩街），而沒有換算到短牌的正確比例。

### 具體危害場景

**場景：錯誤計算底池賠率**

```
桌面情況（翻牌後）：
你有：J♠ T♠，翻牌：9♠ 8♠ K♦
→ 你有：J♠ T♠ 9♠ 8♠ = 4 張 ♠（同花聽牌）
→ 同花 Outs = 5 張（每色 9 張 - 4 已用）

對手 C-bet：底池 1000，下注 500

德州計算（錯誤！）：
→ 你的同花聽牌 = 9 Outs（德州計算）
→ 9 Outs × 2% = 18%（轉牌）
→ 底池賠率 = 500/1500 = 33%
→ 18% < 33%，考慮跟注時需要強隱含賠率

短牌正確計算：
→ 你的同花聽牌 = 5 Outs（短牌計算）
→ 5 Outs × 3% = 15%（轉牌）
→ 底池賠率 = 500/1500 = 33%
→ 15% < 33%，需要更強的隱含賠率才合理跟注

另外的錯誤方向：
→ 新手以為有 9 Outs × 3% = 27%（混用兩個系統！）
→ 27% < 33%，誤以為勝率更高（實際只有 15%）
→ 在應該慎重考慮的情況下，過於激進地跟注
```

**損失計算**：

```
如果每次都高估同花 Outs（誤用 9 而不是 5）：
→ 每次翻牌後的同花聽牌跟注 EV 都被高估
→ 長期來看，這是穩定的負 EV 操作
→ 假設每次這樣的錯誤花費 200bb（大底池）
→ 每 100 局犯 10 次這個錯誤 = 損失 2000bb 的 EV
→ 按 100bb 買入計算，等於多輸 20 個買入
```

### 正確做法

**記憶方法**：

```
短牌每色只有 9 張（不是 13 張）：
→ 每色 9 張 - 4（你持有的 4 張同花）= 5 個 Outs
→ 5 Outs × 3% ≈ 15%（翻牌後轉牌）

德州每色有 13 張：
→ 每色 13 張 - 4（你持有的 4 張同花）= 9 個 Outs
→ 9 Outs × 2% ≈ 18%（翻牌後轉牌）
```

**速查記憶**：

| 聽牌類型 | 德州 Outs | 短牌 Outs |
|---------|---------|---------|
| 同花聽牌 | 9 | 5 |
| 雙端順子 | 8 | 8（不變！） |
| 內聽順子 | 4 | 4（不變！） |

注意：順子 Outs 不變（因為每個點數仍然有 4 張），但每張 Out 的比例變大（因為總牌數更少）。

## 錯誤 3：低估 Flush 的強度（短牌 Flush 很難被超越）

### 錯誤描述

把短牌的 Flush 當作德州的 Flush 來對待，使用保守的下注 Size，或者在 Flush 完成後不敢大注（因為在德州習慣了 Flush 有時候輸給葫蘆）。

### 具體危害場景

**場景 A：Flush 完成後下注太小**

```
桌面情況：
你有：A♣ K♣，翻牌：Q♣ 9♣ 7♦，轉牌：J♣

你的完成手牌：A♣ K♣ Q♣ J♣ 9♣ = A 高同花（Flush）
→ 短牌中，這是第 4 強牌型，只輸給同花順和四條

對手：翻牌後一直跟注，可能有 K-Q-J（三條或葫蘆？）

你的錯誤做法：
→ 轉牌下小注（1/4 pot），因為害怕對手有葫蘆
→ 實際上，即使對手有葫蘆，你的 Flush 也贏！
→ 小注 = 損失了大量潛在價值

正確做法：
→ 轉牌下大注（3/4 pot 或 pot）
→ Flush > Full House，你幾乎無法輸（除非有同花順）
→ 建立大底池，讓對手的強牌（葫蘆等）去跟注
```

**場景 B：Flush 完成後被嚇到**

```
河牌情況：
公共牌：Q♠ J♠ 9♠ T♥ 8♦
你有：A♠ 7♠（A 高同花）
→ 你有 A♠ Q♠ J♠ 9♠ 7♠ = 同花（A 高）

對手在河牌大注或全押

你的錯誤思維：
→「他全押，他一定有更好的牌...」
→ 「同花在德州可以輸給四條、同花順、葫蘆...」
→ 猶豫跟注或甚至棄牌

正確思維：
→ 短牌的 Flush 是第 4 強牌型
→ 對手能擊敗你的情況：同花順（Q-T-9-8-? 同花？）或四條
→ 公共牌 Q♠ J♠ 9♠，你的 A♠ 讓你有最高同花
→ 對手必須有比你更高同花的牌（不可能，你有 A♠）或同花順才能贏
→ 同花順的機率很低（公共牌 Q-J-9-T-8，需要 ♠ 的 8-9-T-J-Q 或 9-T-J-Q-K）
→ 果斷跟注！
```

### 正確做法

**建立「短牌同花是強牌」的心理模型**：

```
短牌同花的強度分級：
A 高同花：幾乎無法輸（除非同花順/四條）→ 大注，全押友好
K 高同花：可能輸給 A 高同花 → 積極但注意多人底池
Q/J 高同花：有被更高同花擊敗的風險 → 中等積極，多人底池謹慎

記住：即使是 J 高同花，它仍然比葫蘆更強！
→ 不要因為葫蘆而放棄同花
```

## 錯誤 4：高估小對子（66, 77 比德州弱很多）

### 錯誤描述

用德州的「小對子 Set Mining」策略，在短牌中過度依賴小對子試圖翻出三條，或者在翻出三條後過度投入。

### 具體危害場景

**場景 A：翻出 Set 但面對同花翻牌**

```
你的手牌：7♥ 7♦（口袋 7）
翻牌：7♠ 8♠ K♠

你翻出了三條 7（7♥ 7♦ 7♠）！在德州這幾乎是必贏的情況。

但是：翻牌有三張 ♠！
→ 任何持有兩張 ♠ 的玩家已成同花
→ 任何持有一張 ♠ 的玩家有同花聽牌
→ 在 9-max 桌，你面對 4-6 個對手入局，至少 1-2 個有 ♠

短牌結果：
→ 你的三條 7 可能已經輸給了對手的同花
→ 即使你現在領先（對手只有同花聽牌），完成的同花會擊敗你

德州玩家的直覺錯誤：
→ 「我有 Set，這是很強的牌，我要 Stack Off（全押）！」
→ 在短牌中，三條 7 面對三色翻牌可能已經落後
```

**場景 B：小對子翻前全押的 EV 問題**

```
你有：77，面對 UTG 全押（25bb）
UTG 的 Push Range：AA, KK, QQ, JJ, TT, 99, 88, AKs, AKo, AQs

德州計算：77 vs UTG Range 的勝率（取決於範圍，大約 35-45%）
→ 在德州，這通常是合理的 Call（考慮底池賠率）

短牌計算：
→ 77 vs 較強手牌：德州一般的 77 vs AA 是 80:20，短牌類似
→ 但短牌中 UTG 的 Range 可能更寬（因為短牌積極性更高）
→ 77 vs 同花連牌（JTs 等）：短牌中 JTs 的翻前優勢更大

短牌的問題：
→ 77 翻出 Set 後，仍然可能輸給 Flush
→ 小對子的 Set Mining 價值降低
→ 在短疊（25bb）全押時，77 的 EV 比德州更低

建議：
→ 短疊情況下，77 的全押 Call 需要更謹慎
→ 除非底池賠率非常好（>40%+），否則考慮棄牌
```

### 正確做法

**重新評估小對子的實際 EV**：

```
短牌小對子策略：

66-77（最小對子）：
→ 主要用於深疊後位（CO/BTN）
→ 不在早位用於全押
→ 翻出 Set 後，謹慎評估翻牌濕潤程度
→ 在濕潤翻牌上（有兩張以上同色），不要無腦 Stack Off

88-99（中小對子）：
→ 可以更廣泛使用，但仍然謹慎
→ 88 翻出 Set 後，同樣要評估 Flush 的威脅

所有小對子的翻牌後策略：
→ 乾燥翻牌（三色無連牌）：積極，Set 幾乎必贏
→ 兩色翻牌：積極，但大注保護
→ 三色翻牌（公共牌已同色）：極度謹慎，可能已落後
```

## 錯誤 5：C-bet 太多（短牌對手幾乎都有 Draw）

### 錯誤描述

把德州的 C-bet 頻率（60-70%）直接套用到短牌，在幾乎所有翻牌都進行 C-bet，導致在對手有 Draw 的情況下，C-bet 的利潤極低甚至是負 EV。

### 具體危害場景

**場景 A：在極濕潤翻牌上 C-bet 失去所有籌碼**

```
你的手牌：A♦ K♦（3-bet 后，你是 aggressor）
翻牌：9♠ 8♠ T♣

你的牌：A 高，未配對（你沒有成牌！）

分析翻牌：
→ 9-8-T 連牌：雙端順子聽牌（7-Q 完成）非常多
→ 9♠ 8♠ 兩張 ♠：同花聽牌也很多

你的手牌對這個翻牌幾乎沒有對應：
→ 你有 A♦ K♦，只有高牌
→ 你有 D♦ K♦，有一個「未來的」same-suit 潛力，但翻牌前沒有 ♦

德州玩家的錯誤：
→ 「我是 3-bet 的人，我應該 C-bet！」
→ C-bet 2/3 pot = 浪費籌碼
→ 對手幾乎都有某種 Draw，C-bet 後他們不會輕易棄牌

結果：
→ C-bet 後對手跟注（他有同花聽牌 + 順子聽牌）
→ 轉牌你仍然是高牌
→ 你繼續 Barrel（因為已投入）= 更多籌碼損失
→ 最終輸掉底池
```

**場景 B：過度 C-bet 模式的累積損失**

```
假設你每次翻牌都 C-bet 70%（德州習慣），底池平均 20bb：

短牌翻牌後的 C-bet 平均成功率：
→ 德州的 C-bet 折疊率：約 50-55%
→ 短牌的 C-bet 折疊率：約 35-40%（對手有 Draw，不輕易放棄）

每次 C-bet 的 EV（以 1/2 pot = 10bb 為例）：

德州：
→ 折疊率 50%：+0.5 × 20 + 0.5 × (-10) = +10 - 5 = +5bb（當沒有手牌時 bluff C-bet）

短牌：
→ 折疊率 35%：+0.35 × 20 + 0.65 × (-10) = +7 - 6.5 = +0.5bb（幾乎沒有利潤！）

如果頻繁 C-bet（沒有足夠的手牌時）：
→ 你的 Bluff C-bet 在短牌中幾乎沒有 EV
→ 長期下來，過度 C-bet = 穩定地損失籌碼
```

### 正確做法

**降低 C-bet 頻率，提高 C-bet 質量**：

```
短牌 C-bet 決策框架：

問題 1：翻牌有多濕潤？
→ 乾燥（三色，無連牌）：可以 C-bet（相對）
→ 中等：謹慎 C-bet
→ 濕潤：大幅減少 C-bet

問題 2：你的手牌對翻牌有多好？
→ 有強牌（Set/Flush）：必須 C-bet
→ 有 Draw（自己也有 Combo Draw）：Semi-Bluff C-bet 可以
→ 沒有配對，沒有 Draw：通常 Check

問題 3：對手的跟注傾向？
→ 對手有 Draw 的手牌（已顯示積極性）：少 C-bet
→ 對手可能沒有太多 Draw（如果翻牌對他們不好）：更多 C-bet

正確頻率參考：
→ 單挑，乾燥翻牌：50% C-bet
→ 單挑，濕潤翻牌：25-35% C-bet
→ 多人底池，任何翻牌：< 25% C-bet（除非你有強牌）
```

## 六、其他常見小錯誤

### 6.1 追求「便宜 Flush Draw」但沒有賠率

```
錯誤：每次有同花聽牌就跟注，不管賠率
→ 短牌同花聽牌只有 5 Outs（不是 9），勝率 16%（轉牌）
→ 很多情況下，跟注是 -EV 的

正確：計算底池賠率 + 隱含賠率後再決定
```

### 6.2 忽略短牌中 Set 的保護需求

```
錯誤：翻出 Set 後過牌（陷阱打法）
→ 短牌中 Draw 完成率更高，免費給 Draw 代價大

正確：翻牌後立即大注保護 Set
```

### 6.3 忘記 A-6-7-8-9 是最低順子

```
錯誤：以為 A-6-7-8-9 是高順子（因為 Ace 通常很高）
→ 在短牌中，A 用作低牌時，A-6-7-8-9 是最低順子

正確：清楚記住，A-6-7-8-9 是最低順子，輸給 6-7-8-9-T 以上的任何順子
```

## 七、自我評估清單

在每次短牌 MTT 結束後，用以下問題評估你是否犯了常見錯誤：

```
□ 我有沒有在 Set vs Straight 的情況下正確判斷誰贏？
□ 我有沒有在 Flush vs Full House 的情況下正確判斷誰贏？
□ 我在計算 Outs 時，同花聽牌用的是 5（不是 9）嗎？
□ 我在 C-bet 時，有沒有考慮翻牌的濕潤程度？
□ 我在用小對子時，有沒有過度 Set Mining？
□ 我在 Set 翻牌後，有沒有立即積極下注保護？
□ 我在 Flush 完成後，有沒有積極建立底池（而不是怕葫蘆）？
```

如果以上任何一項你回答「不確定」，回去複習對應的章節。

| 錯誤 | 核心問題 | 正確做法 |
|------|---------|---------|
| 1. 牌型順序混用 | 用德州順序判斷短牌 | 背熟：Flush > Full House，Set > Straight |
