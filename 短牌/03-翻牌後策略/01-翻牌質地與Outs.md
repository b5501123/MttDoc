## 一、為什麼短牌翻牌幾乎都是濕潤的？

### 1.1 濕潤 vs 乾燥翻牌的定義

**乾燥翻牌（Dry Board）**：
- 很少或沒有 Draw 可能
- 例如：K♠ 7♥ 2♦（彩虹翻，無同花，無順子可能）
- 在德州中比較常見

**濕潤翻牌（Wet Board）**：
- 有多種 Draw 可能
- 例如：8♠ 9♠ T♣（同花可能 + 順子可能）
- 在短牌中幾乎所有翻牌都是這樣

### 1.2 短牌為何難以產生乾燥翻牌

**牌組縮短的直接影響**：

短牌只有 A K Q J T 9 8 7 6 這 9 個點數。連續兩個點數之間的間距比德州更密集。

```
德州的「彩虹乾燥」翻牌例子：
K♠ 7♥ 2♦
→ 點數差異大（K, 7, 2），幾乎無順子可能
→ 無同花（三色）
→ 真正的乾燥翻牌

短牌嘗試乾燥翻牌：
K♠ 7♥ 6♦
→ 7 和 6 相鄰！有順子可能（6-7-8-9-T 等）
→ 短牌中沒有像德州那樣「跨越很大點數差」的翻牌

A♠ K♥ 6♦
→ A 和 K 是連牌！K 和 6 也有距離，但...
→ 任何持有 Q-J-T 的玩家都有順子聽牌
→ 不算真正乾燥
```

**結論**：短牌的 9 個點數（A K Q J T 9 8 7 6）幾乎全部相連，翻牌中的三張牌幾乎必然有某種順子可能性。

### 1.3 同花的普遍性

短牌每種花色 9 張牌（vs 德州 13 張）。

```
翻牌出現兩張同花的機率：

短牌：
從 36 張中抽 3 張，至少兩張同花的機率：
3張中有2張同花：C(9,2)×C(27,1) / C(36,3) = 36×27/7140 ≈ 13.6%
3張全同花：C(9,3) / C(36,3) = 84/7140 ≈ 1.2%
至少兩張同花：≈ 14.8%

德州：
至少兩張同花的翻牌機率：≈ 11.8%

差別不大，但考慮到牌型評估上同花的重要性更高，翻牌中出現兩張同花讓短牌玩家更積極追花。
```

### 1.4 連牌翻牌的普遍性

```
短牌翻牌中出現至少兩張連牌（相差 1 點）的機率：

相差 1 的連牌對（6-7, 7-8, 8-9, 9-T, T-J, J-Q, Q-K, K-A, A-6）：
9 個點數中，相鄰點數對：K-A, A-6, 6-7, 7-8, 8-9, 9-T, T-J, J-Q, Q-K = 9 對
每對有 4×4 = 16 種花色組合

翻牌出現至少兩張連牌（間距≤2）的機率非常高，因為只有 9 個點數。
```

實踐觀察：短牌職業玩家通常認為**超過 80% 的翻牌在某人手中都會產生有意義的 Draw**（同花或順子）。

## 二、不同類型翻牌的分析

### 2.1 三色翻牌（彩虹，三種不同花色）

**例：K♦ 9♥ 7♣**

```
翻牌分析：
- 三色：沒有同花可能（當前無同花聽牌，除非手牌兩張同花）
- 順子分析：K-9-7 的連接性
  → 9-8（手牌中 8 可以配 7-8-9）
  → 7-8-9（只差 8）
  → 6-7-8-9（需要 6 和 8）

實際上：K♦ 9♥ 7♣ 是相對乾燥的翻牌，
但短牌玩家仍然會有 6-8 同花連牌等聽牌
```

**策略含義**：三色翻牌是短牌中最「乾燥」的翻牌，C-bet 頻率可以稍高（但仍低於德州同類翻牌）。

### 2.2 兩色翻牌（有同花聽牌可能）

**例：K♠ 9♠ 7♣**

```
翻牌分析：
- 兩張 ♠：任何持有一張 ♠ 的玩家有同花聽牌
- 短牌每種花色 9 張，剩餘 ♠ = 9 - 2 = 7 張在牌墩中
- 同花聽牌的完成機率更高
- 加上順子聽牌可能

注意：K♠ 9♠ 7♣ 翻牌中，
- 任何 ♠♠ 的手牌已成同花（K♠ 和手牌中另一 ♠）
- 任何 X♠ 的手牌有 Flush Draw
- 這個翻牌比德州的「兩色翻牌」要更濕潤
```

### 2.3 單色翻牌（三張同花）

**例：K♠ 9♠ 7♠**

```
翻牌分析：
- 三張同花：已有同花可能，任何手牌中有 ♠ 的玩家已成花（部分）
- 如果你手持兩張 ♠ = 你已有同花（至少是 5 張中有 2 手 + 3 翻）
- 沒有 ♠ 的玩家幾乎只能寄希望於成對或特殊情況

這種翻牌對短牌影響：
- 持有 ♠ 的玩家大量入底池
- 非 ♠ 玩家只能偶爾詐唬
- 翻牌後策略非常複雜
```

## 三、Outs 計算的特殊規則

### 3.1 回顧短牌 Outs 的基本法則

**每張 Out ≈ 3%（翻牌後轉牌）**

但更重要的是：**在短牌中要正確識別什麼是「真正的 Out」。**

### 3.2 有效 Outs vs 名義 Outs

**問題**：短牌中，你的 Out 可能改善你的牌，但同時也改善對手的牌。這些稱為「折扣 Outs（Discounted Outs）」。

```
例：你有 8♠ 9♠，翻牌 6♠ 7♠ K♣

你的情況：同花聽牌（4 張 ♠）+ 已有順子（6-7-8-9，差 T 或 5？）
等等，短牌沒有 5，所以：
6-7-8-9-T = 需要 T，雙端（A-6-7-8-9 需要 A）
→ OESD：T 和 A 各 4 張 = 8 Outs
→ Flush Draw：♠ 剩餘 = 9 - 4 = 5 Outs（但要扣除 T♠ 和 A♠ 已算入順子 Outs）
→ 有效 Outs：順子 6 張（非♠的 T 和 A）+ 同花 5 張 = 約 11 Outs

對手（如果有同花連牌）也可能有類似的 Draw，
某些 Out 對你有利但也可能對對手有利。
```

### 3.3 計算複雜 Combo Draw 的 Outs

**步驟法**：

```
第一步：列出所有能改善你牌的牌
第二步：去除重複計算
第三步：考慮對手的牌（如果知道的話）
第四步：評估每張 Out 的完成後強度

例：你有 J♦ T♦，翻牌 8♦ 9♦ 6♣

第一步：
同花 Outs（♦）：剩餘 ♦ = 9 - 4（J♦ T♦ 8♦ 9♦）= 5 張
→ A♦, K♦, Q♦, 7♦, 6♦（等等 6♦ 在翻牌）→ A♦ K♦ Q♦ 7♦ = 4 張
順子 Outs：
  → 需要 Q 或 7 完成 8-9-T-J-Q 或 6-7-8-9-T？
  → 等等，6-7-8-9-T：需要 7，但 7♦ 已算入同花 Outs
  → 8-9-T-J-Q：需要 Q，Q♦ 已算入同花 Outs，Q♥ Q♣ Q♠ = 3 張非♦順子 Outs
  → 6-7-8-9-T（用翻牌中的 6）：需要 7♥ 7♣ 7♠ = 3 張非♦順子 Outs

第二步（去重）：
同花 Outs（非重複）：A♦ K♦ 7♦ = 等等，7♦ 完成順子同花，非常好
→ A♦（改善到 A 高同花）：1 Out
→ K♦（K 高同花）：1 Out
→ Q♦（Q 高同花 + 順子同花）：1 Out
→ 7♦（7 同花 + 順子同花順！）：1 Out
→ 6♦ 已在翻牌

純順子 Outs（不是同花）：
→ Q♥ Q♣ Q♠：3 Out
→ 7♥ 7♣ 7♠：3 Out

第三步：共 4 + 6 = 10 個有效 Outs（Q 或 7 完成順子，♦ 改善同花）

第四步：完成後的強度
→ 完成同花：強（特別是 Q♦ 和 7♦ 是同花順！）
→ 完成順子：強牌（短牌中 Straight > Three of a Kind，但仍輸給 Flush 和 Full House）
```

## 四、不同 Draw 類型的 Outs 快速表

### 4.1 同花相關 Outs

| 聽牌類型 | Outs 數量 | 說明 |
|---------|---------|------|
| Flush Draw（4 張同花） | 5 | 每種花色 9 張，已用 4 張 |
| Backdoor Flush Draw（3 張同花） | 需要兩張 | 5×5/30 ≈ 2.5%（近似） |

### 4.2 順子相關 Outs

| 聽牌類型 | Outs 數量 | 說明 |
|---------|---------|------|
| OESD（雙端） | 8 | 兩端各 4 張 |
| Gutshot（內聽） | 4 | 一端 4 張 |
| Double Gutshot（雙內聽） | 8 | 兩個缺口各 4 張 |

### 4.3 成對相關 Outs

| 聽牌類型 | Outs 數量 | 說明 |
|---------|---------|------|
| Over-pair 配對（兩張高牌） | 6 | 兩個點數各 3 張剩餘 |
| Kicker 配對 | 3 | 一個點數 3 張剩餘 |
| Set → Full House（有 Pair 的公共牌） | 取決於情況 | 複雜計算 |

## 五、翻牌後 Outs 實戰判斷流程

### 5.1 四步驟評估法

```
第一步：確認你現在的手牌強度
→ 是否已成牌？成了什麼牌型？
→ 在短牌牌型順序中，你的牌排名多少？

第二步：確認你有多少 Outs
→ 同花 Outs？順子 Outs？配對 Outs？
→ 有沒有重複計算？

第三步：評估這些 Outs 的質量
→ 完成後，你的牌夠強嗎？
→ 對手是否也有可能在你完成 Outs 時超越你？

第四步：比對底池賠率
→ 底池賠率 vs 你的勝率
→ 如果需要的賠率好於底池賠率，跟注有利（純直接勝率）
→ 加上隱含賠率後，更多手牌值得跟注
```

### 5.2 實例演練

**情況 1：你有 T♠ J♠，翻牌 7♠ 8♠ 6♣**

```
第一步：你現在的牌？
→ T♠ J♠ + 7♠ 8♠ 6♣
→ 你有：T♠ J♠ 7♠ 8♠ = 4 張 ♠（同花聽牌）
→ 你也有：6-7-8-T？不是連續的（缺 9）
→ 或者 7-8-9-T（需要 9）
→ 目前沒有成手牌（只有同花聽牌 + 需要 9 的順子聽牌）

第二步：Outs？
→ 同花 Outs：♠ 剩餘 = 9-4 = 5 張（A♠ K♠ Q♠ 9♠ 6♠，其中 6♠？在翻牌）
→ 實際同花 Outs：A♠ K♠ Q♠ 9♠ = 4 張
→ 純順子 Outs（9 完成 7-8-9-T，但不是同花的 9）：9♥ 9♦ 9♣ = 3 張
→ 總 Outs ≈ 7 張

第三步：質量？
→ 完成同花（4 Outs）：強牌，除非對手有更高同花或同花順
→ 完成順子 9（3 Outs）：短牌中順子是第 7 強牌型，可能輸給同花和 Set
→ 順子的質量略低（在短牌中容易被超越）

第四步：底池賠率比對
→ 7 Outs × 3% ≈ 21% 勝率（翻牌後轉牌）
→ 如果底池下注，需要 33% 以上勝率 → 不夠
→ 如果半鍋下注，需要 25% 以上 → 勉強
→ 加上隱含賠率（深疊時完成同花後還可以贏更多）→ 通常值得跟注
```

**情況 2：你有 9♥ 9♦，翻牌 9♠ A♠ 8♠**

```
第一步：你現在的牌？
→ 9♥ 9♦ + 9♠ A♠ 8♠ = 三條 9（暗三條/Set）
→ Set 9，短牌第 6 強牌型

但等等！翻牌有 A♠ 和 8♠，任何持有兩張 ♠ 的手牌已成同花（5 張 ♠ 中的 2+3）

等等：翻牌只有 3 張，其中 A♠ 8♠ 9♠ = 三張都是 ♠！
→ 任何持有任意一張 ♠ 的手牌都已有 4 張 ♠（成同花聽牌）
→ 任何持有兩張 ♠ 的手牌已有 5 張 ♠ = 已成同花！

分析：
→ 你的 Set 9 是強牌，但面對可能已成同花的對手，你可能已經輸了！
→ 在這種翻牌上，你的 Set 非常危險

第二步：你的 Outs？（如果你落後）
→ 假設對手有同花（5 張 ♠），你需要：
→ 讓底池湊出葫蘆（Full House）：需要翻牌中出現另一張 9 或 A 或 8
→ 9 點數：全部 4 張已知（你 2 張 + 翻牌 1 張），剩餘 1 張 = 1 Out
→ A 點數：翻牌有 A♠，手牌沒有 A，剩餘 A = 3 張 = 3 Outs（升為葫蘆）
→ 8 點數：剩餘 3 張 = 3 Outs

若完成葫蘆（Full House），在短牌中仍輸給同花！
→ 你實際上無法通過 Full House 翻身（Flush > Full House）

第三步：質量評估
→ 如果對手有 Flush（同花），你的 Set 9 輸了，而且無法通過葫蘆反超
→ 只有翻出 9（四條）才能贏，1 Out ≈ 3%
→ 你在很糟糕的位置！

策略建議：
→ 這種翻牌下，Set 不應該大額入鍋
→ 可以小注（控制底池），但面對大注應考慮棄牌
→ 這是短牌的關鍵教訓：Set 在濕潤翻牌上需要特別謹慎
```

## 六、翻牌後的多人底池考量

### 6.1 多人底池讓 Draw 更有價值

```
3 人底池：
→ 更大的底池意味著更好的賠率
→ 每張 Out 完成後預期贏得更多
→ Draw 的隱含賠率更高

但：
→ 多人底池中，完成 Draw 後被超越的機率也更高
→ 在短牌中，即使完成同花，也要小心對手有更高同花
→ 「Nut Draw」（最高等級的 Draw）在多人底池中更有價值
```

### 6.2 Nut Draw 的重要性

```
Nut Flush Draw = A 高同花聽牌（最強同花）
→ 完成後只可能輸給更高同花順
→ 在多人底池中是最安全的 Draw

Non-Nut Flush Draw = 例如 K♠ 高或 J♠ 高的同花聽牌
→ 完成後可能輸給 A 高同花
→ 多人底池中要更謹慎
```

## 本章重點摘要

1. **短牌翻牌幾乎都濕潤**：9 個點數緊密相連，同花普遍
2. **Outs 計算用 ×3%**（不是德州的 ×2%）
3. **同花 Outs = 5 張**（每色 9 張 - 4 張已用）
4. **Combo Draw 更強**：10+ Outs 在短牌中勝率達 30-40%
5. **Set 在濕潤翻牌中很危險**：Flush 可以擊敗 Set，無法用 Full House 反超
6. **Nut Draw 更有價值**：多人底池中，最高等級的 Draw 遠比次級 Draw 重要
