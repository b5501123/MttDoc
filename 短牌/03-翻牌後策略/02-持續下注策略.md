## 一、短牌 C-bet 的基本框架

### 1.1 C-bet 頻率為何應該降低？

德州撲克中，翻牌前加注方在翻牌後以 C-bet 繼續施壓是標準策略。但短牌中，C-bet 頻率應該降低，原因如下：

**原因 1：對手幾乎都有某種 Draw**

短牌翻牌後，多數情況下對手手中都持有某種聽牌（同花聽牌、順子聽牌或 Combo Draw）。對有 Draw 的對手 C-bet，他們的跟注頻率更高。

**原因 2：翻牌後權益差距更小**

短牌中，已成牌（Made Hand）vs Draw 的對比不如德州懸殊。一個強力 Combo Draw（12+ Outs）的勝率可達 40%，對比德州的 25-30%。這讓 C-bet 更難作為保護手段。

**原因 3：多人底池更常見**

短牌因為入局成本相對低（BTN Ante 格式），多人底池更頻繁。多人底池中 C-bet 的折疊率更低。

### 1.2 德州 vs 短牌的 C-bet 頻率對比

| 場景 | 德州 C-bet 頻率 | 短牌 C-bet 頻率 |
|------|--------------|--------------|
| 乾燥翻牌（三色，無連牌） | 70-80% | 50-60% |
| 中等濕潤翻牌（兩張連牌/同色） | 50-60% | 35-45% |
| 濕潤翻牌（連牌+同色） | 40-50% | 25-35% |
| 極濕潤翻牌（雙色+多連牌） | 30-40% | 15-25% |
| 三色翻牌 | 60-70% | 40-50% |

## 二、根據翻牌質地調整 C-bet

### 2.1 乾燥翻牌的 C-bet（短牌相對少見）

短牌的「乾燥翻牌」基本定義：
- 三種不同花色（彩虹）
- 三張牌之間點數差距較大（在短牌中這幾乎不可能）

```
最接近乾燥的短牌翻牌例子：
A♦ K♥ 6♣（A、K、6，三色）
→ 即使是這個翻牌，6-7-8-9 的順子聽牌存在
→ 短牌中沒有真正乾燥的翻牌

策略：
→ 對乾燥三色翻牌（AK6 彩虹等），可以以稍高頻率 C-bet（50-60%）
→ 但仍然比德州的同類型翻牌保守
```

**乾燥翻牌的 C-bet 手牌構成**：
- 翻牌配對（Top Pair 以上）：常規 C-bet
- 沒有成牌但有超高牌的「乾燥 Bluff」：少量（對手 Draw 少，折疊率較高）
- 過牌（Check）的手牌：中等強牌（等到後街）

### 2.2 中等濕潤翻牌

```
例：J♥ T♠ 7♦（兩色，有順子可能）

這個翻牌的 Draw 分析：
→ J-T 連牌：任何持有 K-Q 的手牌有 OESD（K-Q-J-T 需要 A 或 9）
→ T-7：需要 8-9 的組合
→ J-T-7：8-9 完成 7-8-9-T-J
→ 幾乎所有手牌都有某種順子聽牌
→ 有一對 ♥♠：沒有同花（三色翻牌中只有 J♥ T♠）

實際：這個翻牌有很多順子聽牌，但同花聽牌少

C-bet 策略：
→ 頻率：35-45%
→ 強牌（Set J/T/7）：C-bet（需要保護）
→ Top Pair + 好踢腳牌（AJ）：C-bet
→ 弱牌或中等牌：通常過牌（對手有太多跟注理由）
```

### 2.3 濕潤翻牌（最常見）

```
例：9♠ 8♠ 7♦（兩張同花 + 連牌）

Draw 分析：
→ 9-8-7：任何有 J-T 的手牌有 OESD（6-7-8-9-T 或 7-8-9-T-J）
→ 9♠ 8♠：任何有一張 ♠ 的手牌有同花聽牌
→ 兩種 Draw 同時存在！這個翻牌極其濕潤

C-bet 策略：
→ 頻率：25-35%（非常保守）
→ 強牌（Set 9/8/7）：必須 C-bet（需要立即保護！）
→ 強 Draw（自己也有 Combo Draw）：可以 C-bet 作半詐唬
→ 弱手牌：幾乎必須過牌
→ 理由：對手跟注頻率太高，弱手牌 C-bet 的利潤很低
```

### 2.4 三張同花翻牌

```
例：T♠ 8♠ 6♠（三張同花）

特殊情況：
→ 如果你有 A♠ 或 K♠：你持有最高同花，可以積極
→ 如果你沒有 ♠：你幾乎沒有什麼 Outs
→ 任何持有兩張 ♠ 的對手已成同花

C-bet 策略：
→ 有頂端同花：C-bet（建立底池，對手會以次級同花跟注）
→ 有 Set 或 Full House：C-bet，但需要評估是否已落後於同花
→ 沒有 ♠ 的手牌：通常棄牌（除非可以詐唬）
→ 詐唬頻率：極低（對手持有 ♠ 的機率很高）
```

## 三、保護強牌的重要性

### 3.1 為什麼短牌中強牌需要更多保護？

短牌中，即使是很強的牌也容易被超越：

```
強牌保護的例子：

你有 T♥ T♦（口袋 T），翻牌 T♠ 8♠ 7♣

你的 Set T = 三條 T（短牌第 6 強牌）
問題：8♠ 7♣ + T♠ 有兩張 ♠，任何持有兩張 ♠ 的手牌已成同花
而且 7-8-9-T-J 的順子聽牌存在

如果你過牌，對手免費 Draw：
→ 同花聽牌有 ≈ 16% 機率完成（轉牌）
→ 順子聽牌 OESD 有 ≈ 26% 機率完成
→ Combo Draw 可達 40%+ 機率完成

你必須立即下大注，讓 Draw 付出代價：
→ C-bet 2/3 鍋到 pot size
→ 保護你的 Set T
```

### 3.2 Set 在短牌中的保護策略

```
Set（三條）的翻牌後行動指南：

乾燥翻牌（彩虹無連牌）：
→ 可以考慮慢打（Check）偶爾，讓對手繼續跟注
→ 但即使乾燥翻牌也有 Draw，通常建議 C-bet

半濕潤翻牌：
→ 標準 C-bet，Size 稍大（2/3 pot）
→ 保護強牌，不讓 Draw 免費推進

極濕潤翻牌（如三張連牌或兩張同花）：
→ 必須立即大注（pot size 或接近 pot）
→ 寧願現在贏一個小底池，也不要讓 Draw 免費完成
→ 這種翻牌上翻牌後 All-in 也是合理的
```

### 3.3 同花在短牌中的保護

```
你有 A♠ K♠，翻牌 Q♠ J♠ 9♥
→ 你已成 A 高同花！（A♠ K♠ Q♠ J♠ + 需要 1 張 ♠）
→ 等等，你有 4 張 ♠，還差 1 張

重新：
A♠ K♠ + Q♠ J♠ = 4 張 ♠，還需 1 張
→ Flush Draw（需要任何 ♠ 以外的牌）

不對，你有 4 張 ♠ 了（A♠ K♠ Q♠ J♠）
→ 還需要第 5 張 ♠ 來完成同花
→ Flush Draw：Outs = 5 張剩餘 ♠

同時：A♠ K♠ Q♠ J♠ 9♥（去掉 9♥）還有：
Q♠-J♠-10-9-8 = 需要 T 和 8 的雙端順子？
或者 A-K-Q-J-T = 皇家同花順（需要 T♠）！

策略：
→ 持有 Flush Draw + 皇家同花順 Draw = 超強手牌
→ 積極 C-bet，建立底池
→ 完成後贏得巨大底池
```

## 四、C-bet Size 選擇

### 4.1 短牌 C-bet Size 應更大

| 翻牌類型 | 德州 C-bet Size | 短牌 C-bet Size | 原因 |
|---------|--------------|--------------|------|
| 乾燥翻牌 | 1/3 - 1/2 pot | 1/2 - 2/3 pot | 有更多 Draw，需要更大保護 |
| 中等翻牌 | 1/2 pot | 2/3 pot | 同上 |
| 濕潤翻牌 | 2/3 - pot | pot 或更大 | 對手 Draw 太強，需要最大 Size |

### 4.2 為什麼用更大 Size？

1. **給 Draw 更糟糕的賠率**：如果你用小 Size，Draw 的跟注成本低，EV 更高
2. **更快地建立底池**（對強牌有利）：強牌需要更大的底池
3. **減少多人底池**：更大的 C-bet 讓邊緣手牌棄牌，減少多人底池

```
計算：翻牌後底池 600，你有 Set T（強牌）

小注（1/3 pot = 200）：
→ 同花 Draw 的底池賠率 = 200/800 = 25%
→ 同花 Draw（5 Outs ≈ 16%）跟注是正確的（25% 但可能有隱含賠率）
→ 但 Draw 需要承擔 25% 的成本，不是特別划算

中注（2/3 pot = 400）：
→ 同花 Draw 的底池賠率 = 400/1000 = 40%
→ 5 Outs ≈ 16%，跟注需要 40% 勝率 → 勝率不夠！
→ Draw 跟注是錯誤的（除非有大量隱含賠率）

大注（pot = 600）：
→ 同花 Draw 的底池賠率 = 600/1200 = 50%
→ Draw 幾乎不可能合理跟注
→ 你保護了你的強牌！
```

### 4.3 Size 選擇的決策流程

```
決策流程：

是否有強牌（Set、Flush 等）？
→ 是：使用大 Size（2/3 pot 至 pot），保護強牌
→ 否：考慮 C-bet 是否值得

翻牌有多濕潤？
→ 極濕潤：必須大 Size 或棄牌（不要小 Size C-bet）
→ 中等濕潤：2/3 pot
→ 較乾燥：1/2 pot

多人底池？
→ 多人：用大 Size 或選擇過牌（小 Size 在多人底池效果差）
→ 單挑：靈活調整
```

## 五、過牌（Check）的策略

### 5.1 什麼時候應該過牌（不 C-bet）？

```
1. 翻牌質地對對手更有利時
→ 例如：你有 AA，翻牌 8-9-T 全連
→ 對手的跟注範圍中有大量這種牌的 Draw
→ 即使你的 AA 可能仍然領先，C-bet 收益不大
→ 考慮過牌，控制底池

2. 多人底池且手牌強度不足
→ 在多人底池中，中等強牌（如 Top Pair 弱踢腳牌）不應大額 C-bet
→ 後面的玩家有大量多樣化的 Draw

3. 希望誘騙（Trapping）
→ 偶爾用超強牌過牌（如 Set、Flush），引誘對手下注
→ 但不要太常用，避免被識破

4. 沒有好的手牌（整體 Range 考量）
→ 有些位置的 C-bet Range 需要平衡（Value + Bluff）
→ 如果不該 Bluff，就不該 C-bet
```

### 5.2 過牌-跟注（Check-Call）的手牌

```
適合在翻牌過牌-跟注的手牌：
→ 中等強牌（如 Second Pair 強踢腳牌）
→ 有良好 Draw 的手牌（自己有 Combo Draw，可以過牌-跟注，等到有更多把握時下注）
→ 陷阱手牌（偶爾用強牌過牌）

不適合過牌-跟注的手牌：
→ 需要保護的脆弱強牌（如 Set 在濕潤翻牌）
→ 純 Bluff 的手牌（沒有 Draw 的手牌不適合 Check-Call，應 Check-Fold）
```

## 六、轉牌和河牌的持續下注調整

### 6.1 轉牌 C-bet（Double Barrel）

```
轉牌 C-bet 的條件：
1. 翻牌 C-bet 後，轉牌對你有利
   → 例如：你有 Top Pair，轉牌出現了一張空白牌
   → 繼續下注維持優勢

2. 對手 Draw 沒有完成（轉牌是安全牌）
   → 繼續施壓，不讓 Draw 免費看到河牌

3. 你的手牌在轉牌有所改善
   → 例如：翻牌 Flush Draw，轉牌完成同花 → 積極下注

不應轉牌 C-bet 的情況：
1. 轉牌是對手的完成牌（例如同花完成）
   → 已成的 Draw 可以獨力 Lead，你不需要繼續下注
2. 翻牌 C-bet 沒有任何改善，且面對跟注
   → 對手仍然持有強牌的可能性高
```

### 6.2 河牌 C-bet（Triple Barrel）

短牌中三次下注（Triple Barrel）應更謹慎：

```
三筒下注（三次持續下注）：
→ 對手在短牌中更少純詐唬（因為他們有 Draw 的機率高）
→ 但也更不會「裝弱」（因為 Draw 完成後會主動下注）

因此：
→ 如果對手跟注了翻牌和轉牌，他們到河牌通常有強牌
→ 河牌上的 Bluff（三筒）成功率相對較低
→ 除非有強牌讀牌理由，否則不要輕易三筒 Bluff
```

## 七、多人底池的 C-bet 策略

### 7.1 多人底池的特殊考量

```
3 人以上的底池：
→ 對手越多，某人擊中翻牌的機率越高
→ C-bet 成功（所有人棄牌）的機率更低
→ 因此：C-bet 頻率更低，但 C-bet 成功時收益更大

建議：
→ 多人底池中，只 C-bet 強牌（Value C-bet）
→ 避免 Bluff C-bet（多人底池中 Bluff 效率很低）
→ 如果有強牌（Set、Flush），立即大注建立底池
```

### 7.2 面對多人底池的 C-bet Size

```
多人底池 C-bet Size：
→ 必須比單挑底池更大
→ 原因：每個對手個別跟注的機率降低，但合計跟注率更高

例：底池 1000（4 人進翻牌）
→ 你 C-bet 400（1/2.5 pot）：每個對手跟注 400/1400 = 28.6%
   → 但有 3 個對手，至少一人跟注的機率很高
→ 你 C-bet 800（4/5 pot）：每個對手跟注 800/1800 = 44.4%
   → 折疊率更高，但 Size 太大也有風險
→ 通常用 pot size 或接近 pot 的 Size
```

## 本章重點摘要

1. **C-bet 頻率要降低**：對手幾乎都有某種 Draw，折疊率不如德州
2. **C-bet Size 要更大**：2/3 pot 到 pot，給 Draw 差的賠率
3. **強牌必須保護**：Set 在濕潤翻牌上要立即大注
4. **多人底池更謹慎**：C-bet 主要用 Value 手牌，避免 Bluff
5. **過牌有其策略意義**：控制底池、誘騙、以及不確定手牌的管理
6. **三筒 Bluff 要謹慎**：短牌對手跟注頻率高，河牌 Bluff 成功率低
