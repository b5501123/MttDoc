## 一、短牌 Draw 的基本哲學

### 1.1 短牌中 Draw 是強牌，不是弱牌

在德州撲克中，初學者習慣把 Draw 視為「弱牌」，需要「被施捨才能跟注」的狀態。短牌改變了這個觀念：

**短牌的 Draw 哲學**：
1. 強力 Draw（10+ Outs）的勝率達 30-40%，接近已成牌的對手
2. Combo Draw 的勝率有時超過已成牌（如 Top Pair）
3. Draw 完成後的牌型通常是非常強的牌（Flush 是第 4 強牌型）

**心態調整**：把短牌的 Draw 視為「暫時落後的強牌」，而非「弱手牌」。

### 1.2 Draw 在短牌中的相對勝率

| Draw 類型 | Outs | 翻牌後勝率（對比已成牌） | 結論 |
|---------|------|---------------------|------|
| 同花聽牌 | 5 | ≈ 30%（兩次機會） | 接近 Top Pair |
| 雙端順子 | 8 | ≈ 47% | 幾乎 50/50 |
| 同花+順子 | 10-13 | ≈ 55-65% | 領先大多數已成牌 |
| 超強 Combo Draw | 15 | ≈ 73% | 明顯領先 |

## 二、Flush Draw（同花聽牌）的打法

### 2.1 Nut Flush Draw（A 高同花聽牌）

**最強的同花聽牌**，因為完成後只可能輸給同花順和四條。

```
手牌：A♠ K♠
翻牌：9♠ 7♣ 6♦（2 張 ♠ 在手，1 張在翻牌）

等等：需要 3 張 ♠ 才成聽牌
A♠ K♠ + 9♠ = 3 張 ♠，距同花還差 2 張

重新計算：
你有 A♠ K♠，翻牌 9♠ 7♠ 6♣
→ A♠ K♠ 9♠ 7♠ = 4 張 ♠ = 同花聽牌！

情況分析：
→ Nut Flush Draw（A 高，完成後是最強同花）
→ 翻牌後轉牌 Flush 完成率：5 Outs ≈ 16%
→ 翻牌後河牌（兩次機會）：≈ 30%

打法選項：
1. 主動下注（Semi-Bluff）：
   → 如果沒有成手牌（A♠ K♠ + 9♠ 7♠ 6♣，A 和 K 未配對）
   → 可以下注 2/3 pot，積極建立底池
   → 如果完成同花，贏大底池；如果被大注回壓，評估是否值得繼續

2. 跟注（Draw Mode）：
   → 如果對手 C-bet 且賠率合適
   → 5 Outs ≈ 16%（轉牌），需要底池賠率低於 16%
   → 計入隱含賠率後，通常值得跟注

3. 加注（Raise as Semi-Bluff）：
   → 深疊時偶爾可以加注
   → 給對手 Bluff 的機會，或讓他們以次級 Flush Draw 付出更多
```

### 2.2 Non-Nut Flush Draw（非 A 高同花聽牌）

```
手牌：K♠ J♠
翻牌：Q♠ 9♠ 7♦

你有：K♠ J♠ Q♠ 9♠ = 4 張 ♠ = 同花聽牌（K 高）
→ K 高同花，完成後只輸給 A 高同花
→ 在多人底池中，有人持有 A♠ 的機率不低

打法調整：
→ 比 Nut Flush Draw 更保守
→ 跟注合理的 C-bet（底池賠率合適）
→ 避免大額加注（如果被全押，你可能面對 A 高同花）
→ 單挑底池更積極，多人底池更謹慎
```

### 2.3 Flush Draw + 配對的打法

```
手牌：A♠ 9♠
翻牌：9♣ 7♠ 6♠

你有：A♠ 7♠ 6♠ = 3 張 ♠（不是同花聽牌？）
等等：A♠ + 9♠ 手牌 + 7♠ 6♠ 翻牌 = 4 張 ♠ = 同花聽牌！
加上 A♠ 9♠ + 9♣ = 一對 9（Top Pair）

你有：同花聽牌（A 高）+ Top Pair（9）

分析：
→ 這是很強的組合手牌
→ 即使同花沒有完成，Top Pair 仍有一定強度
→ 即使對手有 Set 9，你的同花完成後仍然會贏（Flush > Set）

打法：積極下注或加注，建立底池，有兩條勝利路徑
```

## 三、Straight Draw（順子聽牌）的打法

### 3.1 OESD（雙端順子聽牌）

```
手牌：J♦ T♦（非同花連牌）
翻牌：8♣ 9♥ K♠

你有：T-J + 8-9 翻牌 = 8-9-T-J，雙端（需要 7 或 Q）
→ OESD：8 個 Outs
→ 轉牌完成率：8 Outs × 3% ≈ 24%
→ 翻牌後兩次機會：≈ 47%

注意：短牌中，順子（Straight）是第 7 強牌型
→ 如果對手翻後下注，他可能有 Set 或更強牌型
→ 完成的順子可能仍然輸

打法考量：
1. 跟注合理的 C-bet：賠率足夠時跟注（底池賠率需低於 47%，幾乎都合適）
2. 但要注意：完成後，你的順子在短牌中只是「中等強牌」
3. 深疊時 Semi-Bluff 加注：如果對手 C-bet 很小，可以加注讓對手難受
4. 如果完成順子，要評估是否有人有 Set 或 Flush
```

### 3.2 Gutshot（內聽順子）

```
手牌：J♥ 8♥（非同花）
翻牌：6♠ 9♦ T♣

你有：J-T-9-8（缺 7）= Gutshot（內聽順子，需要 7）
→ 4 個 Outs × 3% ≈ 12%（轉牌），≈ 25%（兩次機會）

打法：
→ 通常只跟注小注（底池賠率需低於 12-25%）
→ Gutshot 在短牌中比德州強（25% vs 17%），但仍不夠積極打
→ 除非還有其他 Outs（配對等），否則 Gutshot 通常跟注小注、棄牌大注
→ 加注的理由幾乎不存在（除非有強力的讀牌或位置優勢）
```

### 3.3 順子聽牌 + 配對的組合

```
手牌：T♠ T♣
翻牌：8♥ 9♦ J♠

你有：口袋 T + 8-9-T-J（需要 7 或 Q）
→ Top Pair（一對 T）+ OESD
→ 注意：T-T 是 Top Pair（J 在公共牌）還是 Second Pair？
→ J-T-9-8，你有 TT，公共牌最高是 J
→ 所以 TT 是 Second Pair

分析：
→ Second Pair + OESD（8 Outs for 順子）
→ 即使沒完成順子，Second Pair 也有一定強度
→ 更重要的是：在短牌中，如果翻出三條 T（Set），你有 Set+順子可能

打法：
→ 積極參與底池
→ 跟注大多數 C-bet
→ 偶爾加注（有強力組合手牌）
```

## 四、Combo Draw（組合聽牌）的打法

### 4.1 為什麼 Combo Draw 是短牌最強的手牌類型之一？

組合聽牌（同時有多種聽牌）在短牌中的威力來自：
1. 更高的勝率（10-15 Outs = 30-47% 轉牌，60-73% 兩次機會）
2. 完成後是非常強的牌型（Flush 是第 4 強）
3. 即使未完成，手牌本身也可能有一些「保底」強度（配對等）

### 4.2 同花 + 雙端順子的打法

```
手牌：J♠ T♠
翻牌：9♠ 8♠ 6♣

你有：J♠ T♠ 9♠ 8♠ = 4 張 ♠（Flush Draw）
順子：9-8-T-J（缺 7 或 Q 是雙端？）
→ 6-7-8-9-T：需要 7（Gutshot）
→ 7-8-9-T-J：需要 7（同一個 Gutshot）
→ 8-9-T-J-Q：需要 Q（OESD 的另一端）
→ 你有 OESD：需要 7 或 Q

計算：
→ 同花 Outs：剩餘 ♠ = 9-4 = 5 張，但 7♠ 和 Q♠ 已算入順子
→ 純同花 Outs（非順子）：A♠ K♠ = 2 張？不對，還有其他 ♠
→ 所有 ♠：A♠ K♠ Q♠（也完成順子！）7♠（也完成順子！）= 4 張有效同花 Outs
→ 純順子 Outs（非♠）：7♥ 7♦ 7♣ = 3張；Q♥ Q♦ Q♣ = 3張 = 6 張純順子 Outs

總 Outs = 4 + 6 = 10 張
→ 10 Outs × 3% ≈ 30%（轉牌）
→ 兩次機會 ≈ 55%

打法：
→ 這是非常強的手牌！勝率 55% 超過大多數已成牌
→ 積極半詐唬下注（Full Pot 或接近）
→ 面對加注：跟注（有位置），或全押（很深時）
→ 這種手牌在翻牌後幾乎不應該棄牌
```

### 4.3 同花 + Gutshot 的打法

```
手牌：A♠ 8♠
翻牌：6♠ 7♠ T♣

你有：A♠ 8♠ 6♠ 7♠ = 4 張 ♠（Flush Draw）
順子：6-7-8-？-T（缺 9 = Gutshot）
→ Gutshot Outs：9♥ 9♦ 9♣ = 3 張（不是♠）
→ 同花 Outs：剩餘 ♠ = 9-4 = 5，其中 9♠ 也完成順子 → A♠ K♠ Q♠ J♠ 9♠ = 5 Outs

計算：
→ 純同花 Outs：A♠ K♠ Q♠ J♠（不完成順子的）= 4 Outs
→ 同花順子 Outs：9♠ = 1 Out（同花順！）
→ 純順子 Outs：9♥ 9♦ 9♣ = 3 Outs

總 Outs = 4 + 1 + 3 = 8 Outs
→ 8 Outs × 3% ≈ 24%（轉牌）
→ 兩次機會 ≈ 45%

打法：
→ 仍然是強力聽牌
→ 積極參與（跟注或適度加注）
→ 完成同花（最高概率）後極強，很難被超越（A 高同花）
→ 如果完成 9♠ 的同花順更強（難以被擊敗）
```

## 五、何時追 Draw，何時棄牌

### 5.1 基本決策框架

```
追 Draw 的條件（需要同時滿足）：
1. 底池賠率 OR 隱含賠率 > 所需勝率
2. 完成後的牌足夠強（不會被超越）
3. ICM 壓力允許（MTT 特殊考量）
4. 資金允許（不要為了 Draw 把全部籌碼放進去）

棄牌 Draw 的條件：
1. 底池賠率不合適，且隱含賠率也不足
2. 完成後的牌容易被超越（Non-Nut Draw 在多人底池中）
3. ICM 壓力高（泡沫期短疊）
4. 對手顯示出非常強的牌力（可能已成更強手牌）
```

### 5.2 同花聽牌的追牌決策

```
情境 1：底池 1000，對手下注 400
→ 底池賠率：400/1400 = 28.6%
→ 同花聽牌勝率（轉牌）：≈ 16%
→ 直接賠率不夠（需要 28.6% 但只有 16%）
→ 加入隱含賠率：如果完成同花後可以額外贏 X 元，是否值得？

計算隱含賠率需求：
→ 你需要整體 EV > 0
→ 付出 400，有 16% 機率完成，完成後贏得 X
→ 0.16 × X - 0.84 × 400 > 0
→ X > 0.84 × 400 / 0.16 = 2,100 元

→ 如果完成同花後能贏到對手超過 2,100 元的額外籌碼，跟注有利
→ 深疊時通常可以達到這個要求
→ 短疊時可能無法，考慮棄牌
```

### 5.3 MTT 中 Draw 的特殊考量

**短疊情況下的 Draw**：
```
情境：你有 25bb，面對半鍋下注
→ 底池 15bb，對手下注 8bb
→ 底池賠率：8/(15+8) ≈ 35%
→ 同花聽牌勝率 ≈ 30%（兩次機會）

直接賠率：35% 需要，30% 勝率 → 略微不足
但：MTT 中籌碼是不同的 ICM 價值
→ 如果跟注並輸，你失去 8bb，可能短疊到危險位置
→ 如果棄牌，保留 25-8 = 17bb 的安全籌碼

ICM 考量使你更傾向棄牌，即使純 EV 上略虧
```

**深疊情況下的 Draw**：
```
情境：你有 200bb，面對 1/3 鍋下注
→ 底池賠率很低，幾乎所有 Draw 都值得跟注
→ 隱含賠率極佳（對手還有 200bb）
→ 積極追 Draw
```

### 5.4 面對 All-in 時的 Draw 決策

```
情境：翻牌後對手全押，你有 Flush Draw（5 Outs）

計算：
→ 翻牌後（還有轉牌和河牌）：5 Outs × 6% ≈ 30%
→ 如果你跟注全押，需要底池賠率 < 30% 才有利

例：底池 500，對手全押 1000（共底池 1500）
→ 底池賠率：1000/1500 ≈ 67%
→ 你的勝率 30% < 67% → 棄牌

例：底池 2000，對手全押 500（短疊全押，共底池 2500）
→ 底池賠率：500/2500 = 20%
→ 你的勝率 30% > 20% → 跟注！
```

## 六、牌局情景演練

### 情景 1：強力 Combo Draw 的全押決策

```
情境：
你：9♠ T♠（BTN，100bb 深疊）
對手：UTG 開牌，你跟注
翻牌：8♠ 7♠ J♦

公共牌：8♠ 7♠ J♦
你的手牌：9♠ T♠

分析：
→ 你有：9♠ T♠ 8♠ 7♠ = 4 張 ♠（Flush Draw）
→ 你有：7-8-9-T-J（成順子！）= 已成順子 7 到 J
→ 你已經有順子！（7♠ 8♠ 9♠ T♠ J♦ → 7-8-9-T-J 順子）

等等，讓我重新確認：
7♠ 8♠ = 翻牌中的 ♠，9♠ T♠ = 你的手牌中的 ♠，J♦ = 非♠
→ 你有 4 張 ♠（9♠ T♠ 8♠ 7♠）= 同花聽牌
→ 你有 7-8-9-T-J = 已成順子！

你的牌：順子（7-J）+ 同花聽牌（♠）= 非常強！

對手 UTG C-bet 2/3 pot，你的選擇：
→ 跟注：等轉牌（但讓對手控制底池）
→ 加注：積極建立底池（如果對手有 Set，你仍有 Flush Draw 的備胎）
→ 全押：如果深疊，等轉牌；如果中疊（30-50bb），考慮全押

如果對手有 Set J（三條 J），你的勝率：
→ 你有：順子（完成）+ 同花聽牌（完成後 Flush > Set）
→ 你的順子暫時落後 Set J（Set > Straight in Short Deck）
→ 你需要完成同花才能贏：5 Outs ≈ 16%（轉牌），30%（兩次機會）

結論：跟注合理，但不必全押（等到同花完成後再大注）
```

### 情景 2：Non-Nut Flush Draw 在多人底池

```
情境：
你：K♠ T♠（CO，50bb 深度）
UTG 開牌，HJ 跟注，你跟注（多人底池）
翻牌：Q♠ 9♠ 6♥

你有：K♠ T♠ Q♠ 9♠ = 4 張 ♠ = K 高同花聽牌

UTG C-bet 2/3 pot，HJ 跟注，你的選擇？

分析：
→ K 高同花聽牌（Non-Nut）
→ 多人底池（UTG + HJ 都有牌）
→ 有人可能持有 A♠（Nut Flush Draw 或已成同花）

問題：如果你完成 K 高同花，但有人有 A 高同花 = 你輸！

計算：
→ 你的同花 Outs = 5，但有人可能持有 A♠（一張 Out 被「污染」）
→ 有效 Outs ≈ 4-4.5
→ 跟注 2/3 pot：需要 40% 賠率，你只有 4 Outs × 3% ≈ 12%

直接賠率：不夠！
隱含賠率：如果完成 K 高同花而沒有人有 A 高同花，可以贏很多
但：多人底池中，持有 A♠ 的機率不低

決策：這種情況下通常棄牌比較保守
→ 兩個對手都跟注，你的 Non-Nut 同花聽牌在多人底池中很危險
→ 除非籌碼很深，可以考慮跟注但不加注
```

## 七、Draw 打法的心態調整

### 7.1 接受 Draw 的不確定性

短牌 Draw 有 30-70% 的勝率，這意味著你會經常「輸牌」即使決策正確。接受這種方差是短牌的必要心態：

1. 正確決策長期有利，短期結果不重要
2. 不要因為 Draw 沒有完成就後悔追牌的決策
3. 同樣，不要因為 Draw 完成了就認為每次都應該追

### 7.2 避免「Draw 依賴症」

```
常見的 Draw 錯誤：
1. 在勝率不足時追 Draw（沒有計算底池賠率）
2. 完成 Draw 後過度加注（誤判對手的牌力）
3. 以為 Flush 完成後一定安全（忽略更高同花的可能）
4. 無視 ICM 壓力（泡沫期盲目追 Draw）

正確心態：
→ Draw 是工具，不是目標
→ 每次追 Draw 都需要計算和理由
→ 完成 Draw 後仍然需要評估對手的牌力
```

## 本章重點摘要

1. **Draw 是強牌**：短牌的 Draw 勝率比德州高很多（×3% 每 Out）
2. **Combo Draw 最強**：10+ Outs 的 Combo Draw 勝率超過大多數已成牌
3. **Nut Draw 優先**：A 高同花聽牌比非 A 高更安全，多人底池更重要
4. **追 Draw 要算賠率**：直接賠率 + 隱含賠率都要考慮
5. **ICM 影響 Draw 決策**：MTT 短疊時要比深疊時更保守地追 Draw
6. **完成 Draw 後仍需判斷**：Flush 完成後仍可能輸給更高 Flush 或同花順
