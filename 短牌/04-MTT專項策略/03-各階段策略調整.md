## 一、深疊期（100bb+）

### 1.1 深疊的核心特徵

深疊期通常出現在：
- MTT 早期（起始深度 100-200bb）
- 大疊玩家在比賽中期
- 深疊格式的特殊 MTT

**深疊期的核心優勢**：
1. 隱含賠率最高（有更多籌碼可以贏）
2. 策略靈活性最大（可以跟注 Draw，可以 Set Mine 等）
3. 各種打法都有可行空間

### 1.2 深疊期的進攻性原則

短牌深疊期比 NLH 更應積極：

```
深疊積極打的理由：

1. Draw 的隱含賠率更高
→ 你有 JTs（Combo Draw 潛力）
→ 深疊 200bb 時跟注 3-bet（付出 15bb）
→ 如果完成 Flush，可以贏對手 150-200bb 的籌碼
→ 極佳的隱含賠率！

2. 短牌的 Combo Draw 在深疊時更強
→ 10+ Outs 的 Combo Draw 勝率 55%+
→ 深疊時值得 Semi-Bluff（對手不容易放棄）

3. 積極建立底池對強牌更有利
→ Set/Flush 需要大底池才能發揮最大价值
→ 深疊時可以多街下注，每街都建立底池
```

### 1.3 深疊期的具體策略

**翻牌前**：
```
→ 擴大入局範圍（特別是同花連牌）
→ 積極 3-bet（有位置時，Combo Draw 潛力的手牌）
→ 跟注範圍更寬（隱含賠率好）

允許的「寬入局」：
→ 所有同花連牌：JTs, TJs, 9Ts, 89s, 78s, 67s
→ 中等對子：99-66（Set Mining 有 ROI）
→ 同花牌（A6s, K7s 等）：Flush 完成後強，深疊有隱含賠率
```

**翻牌後**：
```
→ 積極 Semi-Bluff（強力 Draw + 下注 = 半詐唬）
→ 多人底池也可以參與（隱含賠率更好）
→ 慢打（Slow Play）的機會更多（深疊時陷阱打法更有效）

建議的翻牌後 Deep Stack 打法：
→ 強牌（Set/Flush 等）：通常積極下注，但偶爾 Check-Raise 更有效
→ Combo Draw：常規 Semi-Bluff，建立大底池
→ 弱牌或純 Draw：用 Pot Odds 決定是否跟注
```

### 1.4 深疊多人底池的特殊打法

```
深疊 3+ 人底池：

你的優勢：
→ 更大的底池 = 更好的隱含賠率
→ 更多機會讓強牌從多個對手贏籌碼

你的劣勢：
→ 更多玩家有 Draw，某人擊中的機率更高
→ 非 Nut 的牌型更危險（有更多人可能超越你）

策略調整：
→ 多人底池中更強調 Nut Draw（A 高同花聽牌）
→ 非 Nut 手牌更保守
→ Set 在多人底池中要立即積極下注（保護！）
```

## 二、中疊期（30-100bb）

### 2.1 中疊期的挑戰

中疊期（30-100bb）是最複雜的階段，原因是：
1. 隱含賠率開始下降
2. 但仍有足夠的空間進行多街下注
3. ICM 開始產生影響（如果接近 Bubble）
4. 需要在積極和謹慎之間取得平衡

### 2.2 中疊期翻牌前策略

```
收緊入局範圍：
→ 開始減少純 Draw 類型的入局
→ 同花連牌仍然可以入局，但位置要求更嚴格
→ 不再使用最低端的同花連牌（67s、56s 在 50bb 以下去掉）

中疊的開牌策略：
→ 繼續使用標準 Size（3-3.5x）
→ 但 3-bet 更謹慎（收緊範圍到強牌為主）
→ 面對 3-bet，棄牌頻率提高（更少跟注 3-bet）

30-50bb 的考量：
→ 跟注 3-bet 後，底池中的籌碼比例更高
→ 翻牌後如果有任何動作，很快就接近全押
→ 這讓翻牌前的決策更重要（知道後面的路線）
```

### 2.3 中疊期翻牌後策略

```
調整 1：C-bet 更謹慎
→ 減少 Bluff C-bet
→ 只在有良好 Equity 時下注（Value 或強 Semi-Bluff）

調整 2：Draw 的跟注更保守
→ 50bb 時，跟注 C-bet 消耗的籌碼比例更高
→ 只有底池賠率明確合適時才追 Draw
→ 避免用非 Nut Draw 大額投入

調整 3：避免「陷入中間地帶」
→ 中疊時，往往沒有好的中間選擇
→ 要麼很強（全押），要麼過牌/棄牌
→ 避免小注搜索信息（浪費籌碼）

中疊（50bb）翻牌後的典型路線：
強牌（Set/Flush）：開翻牌下注，準備 Stack Off（全押）
中等強牌（Top Pair 強踢腳牌）：謹慎下注，不要 Stack Off
Draw：根據賠率決定，通常更謹慎
弱牌：棄牌或過牌等待情況
```

### 2.4 「Stack Off 區」的概念

在中疊期，每一個下注都可能導向全押：

```
例：50bb 深疊

翻牌後底池 30bb（翻前建立）
你 C-bet 20bb（2/3 pot）
對手 加注到 60bb
→ 底池現在是 30 + 20 + 60 = 110bb
→ 你只剩 30bb
→ 你面臨：跟注 30bb 進入 140bb 底池，或棄牌

這就是「Stack Off 區」：你的翻牌 C-bet 實際上創造了一個全押情境。

策略含義：
→ 翻牌下注前，想好如果被加注怎麼辦
→ 持有強牌（Set/Flush）：很好，預計要全押
→ 持有中等強牌：考慮 Check 而不是 C-bet（避免陷入全押兩難）
```

## 三、短疊期（15-30bb）

### 3.1 短疊期的 Push/Fold 框架

短疊期的策略大幅簡化為 Push（全押）或 Fold（棄牌）：

```
為什麼是 Push/Fold？
→ 如果你開牌（不全押），底池已佔你籌碼的很大比例
→ 翻牌後幾乎必然要全押（因為底池 = 大部分籌碼）
→ 因此，在開牌時就全押（預先全押）是更直接的策略

短牌的 Push/Fold 特殊考量：
→ 比 NLH 更緊（大疊跟注更寬）
→ 不要用小對子（大疊跟注你的小對子有更多 Draw 機會）
→ 同花連牌的翻前全押 EV 下降（沒有翻牌後的 Draw 優勢）
```

### 3.2 短牌 Push Range（不同位置）

**20bb 的 Push 範圍**：

| 位置 | 推疊手牌 |
|------|---------|
| UTG | AA, KK, QQ, JJ, TT, AKs, AKo |
| UTG+1/UTG+2 | + AQs, 99 |
| LJ/HJ | + AQo, AJs, 88 |
| CO | + 77, ATs, AJo, KQs |
| BTN | + 66, KQo, A9s |
| SB | + 更寬的 A 高（A8s 以上），KJs |

**15bb 的 Push 範圍（更緊，因為大疊跟注更積極）**：

| 位置 | 推疊手牌 |
|------|---------|
| UTG | AA, KK, QQ, JJ, TT, AKs/o |
| LJ/HJ | + AQs, 99, AQo |
| CO | + AJs, 88, AJo, KQs |
| BTN | + 77, ATs, KQo |

**注意**：短牌的 Push Range 比 NLH 的 Nash Push Range 更緊，主要原因是大疊的跟注 Range 更寬。

### 3.3 短疊期面對開牌的決策

```
你有 20bb，面對 UTG 開牌（3.5x = 7bb）：

你的選擇：
1. 棄牌
2. 全押（Push Over The Open）
3. 跟注（通常不推薦，除非手牌非常特殊）

全押的條件：
→ 你的手牌在翻前有足夠的勝率（vs UTG 的範圍）
→ 即使輸了，ICM EV 也是可以接受的

棄牌的情況：
→ 你的手牌不夠強（勝率不足）
→ UTG 的範圍很強（3-bet Bluff 成功率低）

跟注的罕見情況：
→ 你有超強牌（AA/KK）但想誘騙更多人入局（深疊時才有意義）
→ 短疊時跟注通常創造不好的底池結構
```

## 四、超短疊（<15bb）

### 4.1 超短疊的緊急模式

超短疊（<15bb）進入「緊急模式」：

```
緊急模式的特徵：
→ 每手牌都可能是你的最後機會
→ Ante 的侵蝕很快（每輪消耗 2-3bb）
→ 必須主動出擊，不能坐等好牌

例：你有 8bb，盲注 Ante 格式
→ 每輪你在 BTN 時要付 1bb 的 Ante
→ 在 SB 時要付 SB（另外再 1bb）
→ 每輪實際消耗約 2bb（有時更多）
→ 8bb 只能維持 4 輪，必須在這段時間找到全押機會
```

### 4.2 超短疊的 Push 範圍

**10bb 以下的 Push 範圍**：

```
BTN（寬 range，因為位置最好）：
AA, KK, QQ, JJ, TT, 99, 88, 77, 66
AKs, AKo, AQs, AQo, AJs, AJo, ATs, A9s, A9o
KQs, KQo, KJs, QJs, JTs

SB（稍窄，因為 BB 後位）：
AA, KK, QQ, JJ, TT, 99, 88
AKs, AKo, AQs, AQo, AJs
KQs

BB（面對 SB 完成盲注）：
BB 已部分投入底池，可以更寬地「完成」（跟注 SB 的全押）
跟注範圍：A 高、任何對子、高牌連牌等

非常短疊（5bb 以下）：
→ 幾乎任何 Ace 高的手牌都應該 Push
→ 因為你的折疊率讓 Ante 很快侵蝕你的籌碼
```

### 4.3 超短疊面對加注

```
你有 10bb，在 BB，UTG 開牌到 3bb

選擇 1：棄牌（節省 10bb - 1bb = 9bb？不對，你已付 BB 1bb，剩 9bb）
選擇 2：全押（13bb 進底池）
選擇 3：只跟注（3bb）—— 最糟糕的選擇（避免！）

分析：
→ 跟注後底池 = UTG 3bb + BB 跟注 3bb = 6bb
→ 你還有 7bb 在翻牌後
→ 翻牌後幾乎任何情況都要全押 → 等於現在就全押了

結論：短疊時，面對加注，選擇棄牌或全押，避免跟注。
```

## 五、9-max 位置調整的特殊考量

### 5.1 深疊期各位置的調整

```
深疊期（100bb+）位置策略：

UTG：最保守，只用強牌，但可以用同花連牌（隱含賠率好）
BTN：最廣，幾乎所有有潛力的手牌，積極偷底池

特別注意：BTN Ante 讓 BTN 有額外的「投資感」
→ BTN 需要更積極（已付 Ante，需要回收）
→ SB 和 BB 的反應更重要（他們的防守頻率影響 BTN 的偷底池策略）
```

### 5.2 不同深度的全桌策略協調

```
當桌上有不同深度的玩家：

大疊（你）vs 短疊：
→ 積極向短疊施壓（短疊不想全押）
→ 但要注意 ICM：短疊全押後，你輸了仍然不是淘汰

大疊（你）vs 大疊：
→ 避免不必要的大底池對決（雙方都在風險中）
→ 除非你有超強牌或必要的全押情況

中疊（你）vs 所有人：
→ 選擇性地和短疊互動（獲得 ICM EV）
→ 避免和大疊的大底池對決
→ 積極偷底池維持籌碼
```

## 六、各階段的關鍵指標

### 6.1 不同深度的目標 M 值

M 值 = 你的籌碼 / (BB + SB + Ante × 入局人數)

```
M 值和策略對應：

M > 20（深疊）：Full Ring 策略，廣泛入局
M 10-20（中等）：標準 MTT 策略，稍微收緊
M 5-10（短疊）：Push/Fold 開始主導
M < 5（超短疊）：只等最強牌，準備全押
M = 1（臨界）：必須本手牌全押，否則下一輪 BB 就沒了
```

### 6.2 短牌 M 值調整

因為 BTN Ante 的特殊性，短牌 MTT 的「有效 M 值」計算方式略有不同：

```
短牌（BTN Ante 格式）的有效 M 計算：

傳統 M = 籌碼 / (SB + BB + Ante)

例：籌碼 15,000，盲注 500/500，BTN Ante 500
M = 15,000 / (500+500+500) = 10

但你每輪只有 1/9 的機會在 BTN（付 Ante）
→ 平均每輪付出：(500+500)/9 + 500/9 ≈ 222 (SB/BB) + 56 (Ante) ≈ 278
→ 有效 M ≈ 15,000 / 278 ≈ 54 輪（這是你「存活」的輪數估算）

但實際在比較中，M 值主要用於比較策略調整點，不需要精確計算
```

## 七、各階段的常見錯誤

### 7.1 深疊期常見錯誤

```
錯誤 1：太保守不入局
→ 深疊時應該廣泛入局（隱含賠率好）
→ 特別是同花連牌，深疊時非常有價值

錯誤 2：不保護強牌
→ Set/Flush 翻牌後不下注 = 讓 Draw 免費
→ 短牌的 Draw 完成率高，不保護代價大

錯誤 3：Slow Play 過度
→ 偶爾 Slow Play 可以，但不應是常態
→ 深疊時 Slow Play 的風險：對手的 Draw 可能擊敗你
```

### 7.2 短疊期常見錯誤

```
錯誤 1：用小對子 Push
→ 短牌中，66/77 的 Push 被跟注後勝率不高
→ 大疊有更多 Draw 機會，小對子優勢更小

錯誤 2：等待「好時機」導致籌碼被侵蝕
→ 等到 5bb 以下才 Push = 籌碼太小，贏了也沒有意義
→ 在 15-20bb 時積極 Push，而不是等到 < 10bb

錯誤 3：用同花連牌 Push（短疊）
→ JTs 的翻前 Push EV 在短疊時比深疊差很多
→ 沒有隱含賠率，同花連牌的優勢在翻後，而不是翻前全押
```

## 本章重點摘要

1. **深疊（100bb+）**：積極入局，隱含賠率好，保護強牌，多使用 Semi-Bluff
2. **中疊（30-100bb）**：收緊範圍，避免「陷入中間地帶」，謹慎 C-bet
3. **短疊（15-30bb）**：Push/Fold 主導，Push Range 比 NLH 更緊
4. **超短疊（<15bb）**：緊急模式，幾乎全押或棄牌，不能跟注
5. **位置調整**：每個深度都要根據位置調整策略，BTN 永遠是最廣的範圍
6. **避免籌碼侵蝕**：不要等到超短疊才行動，在 20bb 左右積極 Push
