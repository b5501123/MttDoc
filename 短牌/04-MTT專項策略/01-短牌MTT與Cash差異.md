## 一、5 大核心差異

### 差異 1：籌碼具有 ICM 價值，不是面值

**Cash Game（現金局）**：
- 籌碼 = 現金，直接可以兌換
- 贏 100 籌碼 = 贏 100 元（假設 1:1）
- 決策純粹基於 Chip EV（籌碼期望值）
- 可以隨時離場，無需考慮排名

**MTT（多桌錦標賽）**：
- 籌碼≠現金（不能直接兌換）
- 籌碼的「真實價值」取決於你的排名和獎金結構
- 需要考慮 ICM（獨立籌碼模型）
- 只有進入獎圈才有收益

```
ICM 影響示例：
總籌碼：1,000,000
第 1 名獎金：$10,000
第 2 名獎金：$6,000
第 3 名獎金：$3,000

如果你有 200,000 籌碼（總籌碼的 20%）：
Chip EV 計算：你有 20% 的籌碼，但
ICM EV = P(1st)×10,000 + P(2nd)×6,000 + P(3rd)×3,000 + ...
→ 你的 ICM EV ≠ 20% × $10,000 = $2,000（Chip EV）
→ ICM EV 通常低於 Chip EV（因為你不能把所有籌碼換成第 1 名）
```

### 差異 2：全押（All-in）的後果不同

**Cash Game**：
- All-in 輸了：可以 Rebuy（再補買入）
- 每次 All-in 是獨立的事件
- 長期 EV 主導決策

**MTT**：
- All-in 輸了：淘汰（或嚴重縮短疊）
- 每次 All-in 的後果是永久性的
- ICM 讓 All-in 的「風險成本」更高

**短牌 MTT 的特殊挑戰**：
- 短牌比 NLH 更多全押情況（Draw 多、籌碼流動快）
- 每次全押的頻率更高 → ICM 壓力更大、更頻繁
- 需要更精確的全押決策

### 差異 3：籌碼深度持續變化

**Cash Game**：
- 籌碼深度相對穩定（可以 Rebuy 到滿疊）
- 策略相對固定

**MTT**：
- 深疊（100bb+）→ 中疊（30-100bb）→ 短疊（15-30bb）→ 超短疊（<15bb）
- 每個階段的策略完全不同
- 盲注不斷上漲，有效深度不斷下降

**短牌 MTT 的深度變化更快**：
- 全押更頻繁，籌碼轉移速度更快
- 比賽中籌碼格局的波動比 NLH MTT 更大
- 你需要能夠快速切換不同深度的策略

### 差異 4：底池賠率結構不同

**Cash Game**：
- 固定深疊（通常 100bb），底池賠率穩定
- 可以計算精確的長期 EV

**MTT**：
- 深度不斷變化，底池賠率隨之改變
- 某些 Draw 在深疊時值得追，短疊時不值得
- 需要動態調整 Draw 的跟注決策

```
例：同花聽牌（5 Outs ≈ 30% 兩次機會）

深疊（200bb）：
→ 底池 20bb，對手下注 10bb
→ 底池賠率：10/30 = 33%
→ 30% 勝率 < 33%，直接賠率不足
→ 但隱含賠率（還有 180bb 可以贏）≈ 非常充足
→ 跟注是 +EV 的

短疊（15bb）：
→ 底池 5bb，對手下注 3bb
→ 底池賠率：3/8 = 37.5%
→ 30% 勝率 < 37.5%，不夠
→ 隱含賠率？你只剩 10bb，對手可能也沒有多少
→ 跟注可能是 -EV 的（特別是考慮 ICM）
```

### 差異 5：比賽節奏和心理壓力

**Cash Game**：
- 可以隨時離開，不受時間壓力
- 只有純策略的考量

**MTT**：
- 有獎金結構的激勵（每進一名都有價值）
- 泡沫、FT（決賽桌）等特殊心理壓力
- 比賽疲勞、時間壓力影響決策質量

**短牌 MTT 的心理特殊性**：
- 更多刺激的全押場景，心理波動更大
- 需要在高方差的環境下保持冷靜
- 連續的 Draw 失敗或成功會影響下一手牌的判斷

## 二、短牌 MTT 比 NLH MTT 更需要積極打

### 2.1 為什麼必須積極打？

**理由 1：Draw 的機率更高，需要積極保護強牌**

短牌翻牌後幾乎每個對手都有 Draw。如果你持有強牌（Set、Flush 等）但不積極下注，對手有太多機會免費完成 Draw 並擊敗你。

```
例：你有 Set K（三條 K），翻牌 K♠ 9♠ 8♣
→ 公共牌有兩張 ♠，任何持有 ♠ 的對手有同花聽牌
→ 如果你過牌，讓對手免費看轉牌（16% 機率完成同花）
→ 你的強牌在免費給對手機會，這是錯誤的

積極下注：
→ 下注 2/3 pot，強迫 Draw 付出代價（底池賠率變差）
→ 保護你的 Set
```

**理由 2：籌碼流動速度快，積極打才能累積籌碼**

短牌的全押比例高，如果你總是保守打，你的籌碼會被慢慢侵蝕（Ante、盲注）。需要積極建立底池，累積籌碼維持競爭力。

**理由 3：對手也積極打，被動只會被利用**

短牌環境中，積極的玩家（AGG players）會頻繁下注 Draw 作為半詐唬。如果你太被動，這些 Semi-Bluff 會一次次地把你逼退出底池。

### 2.2 但要聰明地積極，不是瘋狂地積極

積極不等於無腦全押或無節制地追 Draw：

```
聰明的積極：
→ 持有強牌或 Combo Draw 時積極下注
→ 在合適的賠率下追 Draw
→ 利用位置優勢，在有利翻牌上積極

不應做的「盲目積極」：
→ 用弱牌持續 Bluff（短牌中對手不輕易棄牌）
→ 在 ICM 壓力高時冒不必要的風險
→ 用純 Bluff 全押（沒有 Backup Equity）
```

## 三、短牌 MTT 的特殊格式注意事項

### 3.1 BTN Ante 的 MTT 影響

BTN Ante 格式在 MTT 中的特殊考量：

```
深疊早期（100bb+）：
→ BTN 付出 Ante，形成相對大的初始底池
→ 偷 Blind（Steal from late position）的價值更高
→ BTN 有積極偷底池的動機（已付 Ante，需要回收）

盲注快速上升期：
→ Ante 占盲注等級的比例固定
→ 隨著盲注增加，每手牌的初始底池相對於籌碼更大
→ 這進一步加速了籌碼的流動
```

### 3.2 短牌 MTT 中的 All-in Preflop 頻率

短牌 MTT 比 NLH MTT 有更多翻前全押：

**原因**：
1. 翻前的「對子 vs 對子」勝率差距更小（AA vs KK = 75:25，不是 80:20）
2. 對子 vs 同花連牌的差距也更小（AA vs JTs ≈ 65:35）
3. 這讓翻前全押的「必要性」降低，但同時讓中等強牌的翻前全押更有競爭力

**實際影響**：
- 口袋對（JJ+）更頻繁地在翻前全押（對抗同花連牌的優勢仍然足夠）
- AKs 的翻前全押頻率更高（Flush 潛力 + 直接勝率）
- 同花連牌（JTs, TJs）的翻前全押 EV 提高

## 四、Cash vs MTT 的具體策略差異

### 4.1 相同牌情況下的決策差異

```
情境：你有 QQ，面對 UTG 3-bet

Cash Game（100bb）：
→ 通常 4-bet 或跟注，根據 UTG 的 3-bet 範圍決定
→ 純 EV 計算，沒有 ICM 考量

MTT 泡沫期（你是中疊，有 20 個玩家還在桌上）：
→ QQ 4-bet 被 UTG 跟注/5-bet 的情況
→ 如果輸了，你可能被淘汰或嚴重短疊
→ ICM 告訴你不要冒全疊的風險
→ 可能選擇跟注而不是 4-bet，控制底池大小
→ 甚至在某些情況下棄牌（如果 UTG 的 3-bet 非常罕見，代表 AA/KK）
```

### 4.2 Draw 決策的 Cash vs MTT 差異

```
情境：翻牌後，底池 1000，對手下注 800（接近 Pot），你有 Flush Draw（5 Outs）

Cash Game：
→ 底池賠率：800/(1000+800) = 44%
→ 5 Outs 兩次機會 ≈ 30%
→ 直接賠率不夠，但隱含賠率（對手還有更多籌碼）
→ 如果深疊，跟注可能合理

MTT 泡沫期（短疊 20bb）：
→ 你的 20bb 中，這個 8bb 的跟注消耗了你 40% 的籌碼
→ ICM 讓你的籌碼比面值更值錢（保住籌碼 = 更高 ICM EV）
→ 棄牌可能是正確決策，即使 Chip EV 上跟注更好
```

## 五、短牌 MTT 的心理和節奏

### 5.1 接受高方差環境

短牌 MTT 的方差比 NLH MTT 更高：
- 更多全押場景
- Draw vs Made Hand 的對局結果不確定性更高
- 一次 Bad Beat（被逆轉）的成本可能是全部籌碼

**心理建議**：
1. 接受 Bad Beat 是短牌的正常部分
2. 不要追逐「輸牌後的翻身」
3. 每手牌獨立決策，不受之前結果影響

### 5.2 比賽節奏的管理

短牌 MTT 的節奏比 NLH MTT 更快：
- 平均底池更大（更多全押）
- 每手牌持續時間更長（更多翻牌後動作）
- 整體比賽時間類似，但每手牌更緊張

**建議**：
- 每個關鍵決策前，花幾秒鐘回想「短牌規則」（特別是牌型順序）
- 不要在疲勞時做高風險決策
- 設定明確的策略前，不要讓情緒主導

## 六、Cash 到 MTT 心態轉換的實用練習

### 6.1 識別你的「Cash Game 殘留直覺」

從 Cash Game 轉到 MTT 最大的挑戰是直覺的切換。以下是一些常見的 Cash 殘留直覺，以及如何在短牌 MTT 中修正：

**殘留直覺 1：「輸了再 Rebuy」**
- Cash Game：輸掉一個底池後，補充籌碼繼續
- 短牌 MTT：每個籌碼都是「不可再生」的，要更謹慎地使用
- 修正：每次做決策前，問自己「如果輸了，我還能繼續嗎？」

**殘留直覺 2：「只要 EV 是正的就做」**
- Cash Game：所有正 EV 決策長期都是好的
- 短牌 MTT：ICM 可能讓某些正 Chip EV 的決策成為負 ICM EV
- 修正：在 Bubble 或 FT 時，做 ICM 考量，不只是 Chip EV

**殘留直覺 3：「深疊時可以大膽追 Draw」**
- Cash Game：是的，深疊隱含賠率好，追 Draw 有利
- 短牌 MTT：深疊時也需要考慮 ICM，特別是關鍵階段
- 修正：MTT 早期（距離獎圈遠）= 像 Cash Game 追 Draw；接近 Bubble = 更保守

### 6.2 短牌 MTT 的「節點」識別

在短牌 MTT 中，有幾個關鍵「節點」需要從 Cash Game 模式切換到 MTT 模式：

```
節點 1：當剩餘人數 = 獎圈人數 × 1.5 時
→ 開始考慮 ICM，但不要過度保守

節點 2：當剩餘人數 = 獎圈人數 + 2（接近 Bubble）
→ 全面切換到 ICM 模式，大疊積極，中疊謹慎，短疊決策

節點 3：進入 Bubble（剩餘 = 獎圈人數 + 1）
→ ICM 最高壓，每個決策都要考慮獎金影響

節點 4：進入獎圈後
→ 稍微鬆開，但 FT 仍有 ICM 影響

節點 5：FT（決賽桌）
→ 重新計算 ICM，每個位置升級都有金錢意義
```

## 七、短牌 MTT 中的常見策略誤區

### 7.1 「短牌比 NLH 更暴力，所以要更激進」

**誤區**：認為短牌文化就是「無腦全押」，每手牌都要玩大。

**現實**：短牌確實有更多全押場景，但這是自然發生的（因為 Draw 多、強牌對決更頻繁），而不是刻意造成的。

**正確做法**：在有理由（强牌或强力 Draw）時積極，在沒有理由時比 NLH 更謹慎地退出底池。

### 7.2 「短牌就是同花聽牌，一直追就對了」

**誤區**：看到 Flush Draw 就無條件追。

**現實**：
- 短牌同花聽牌只有 5 Outs（不是 9）
- 沒有適當底池賠率時追 Flush Draw 是 -EV
- MTT 的 ICM 讓追 Draw 的代價更高

**正確做法**：計算底池賠率 + 隱含賠率，只在合算時追。

### 7.3 「ICM 只在 Bubble 才重要」

**誤區**：在 Bubble 前完全不考慮 ICM。

**現實**：ICM 在 MTT 的每個階段都有一定影響，只是在 Bubble 期最強。

**正確做法**：在 MTT 任何階段，即使是早期，也要有「這個決策對我的比賽生命有什麼影響」的意識。

## 本章重點摘要

1. **ICM vs Chip EV**：MTT 中籌碼不是面值，ICM 讓某些全押決策改變
2. **全押影響更大**：MTT 中輸了無法 Rebuy，每次全押的後果是永久的
3. **積極保護強牌**：短牌翻牌後幾乎都有 Draw，強牌必須主動下注
4. **Draw 決策隨深度變化**：深疊時 Draw 有隱含賠率，短疊時更保守
5. **比 NLH MTT 更多全押**：短牌的翻前全押頻率更高，策略需調整
6. **高方差環境**：接受結果的不確定性，保持穩定的決策邏輯
7. **Cash 思維要切換**：進入 Bubble/FT 時，從 Chip EV 模式切換到 ICM 模式
