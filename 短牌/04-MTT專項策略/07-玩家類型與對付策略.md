# 短牌 MTT 玩家類型與對付策略

## 本章學習目標

1. 識別短牌 MTT 中四種核心玩家類型
2. 理解短牌規則如何放大各類型玩家的弱點
3. 掌握針對每種類型的具體利用策略

## 短牌的特殊背景

短牌（36 張牌）相比 NLH 有幾個關鍵差異，**直接影響玩家類型的表現和利用方式**：

```
短牌核心差異對玩家類型的影響：

1. Draw 更強（每張 out ≈ 3%，比 NLH 的 2% 高 50%）
   → Calling Station 更危險（他們的 draw 真的容易成牌）
   → Nit 拿強牌也常被追出（「我有 top set 怎麼會輸」）

2. Equity 更接近（翻牌後差距比 NLH 小）
   → LAG 的積極打法 EV 較 NLH 稍低（他們被 call 的 equity 差距小）
   → 強牌應更積極最大化（不要慢打，因為 equity 優勢容易被追）

3. 翻牌幾乎全是濕潤板
   → Nit 的翻牌後 check-fold 習慣更容易被利用
   → TAG 在乾燥板施壓的機會更少

4. 牌型大小改變（Flush > Full House）
   → 不懂規則的 Recreational 玩家常犯大錯（Full House 慢打被 Flush 打爆）
```

## 四象限速查表

```
                 被動（Passive）           主動（Aggressive）
緊（Tight）   │ Nit / 緊弱               │ TAG / 緊強
              │ VPIP <15%, PFR <8%       │ VPIP 15-25%, PFR 13-22%
              │ 弱點：翻牌後過度 fold     │ 弱點：偏少（打標準 GTO 應對）
              │ 利用：大量偷盲、c-bet      │ 利用：位置施壓，不亂 bluff
──────────────┼──────────────────────────┼──────────────────────────────
寬（Loose）   │ Calling Station / 寬弱   │ LAG / 寬強
              │ VPIP 40%+, PFR <12%     │ VPIP 35%+, PFR 22%+
              │ 弱點：draw 錯誤跟注       │ 弱點：range 廣被 value 打爆
              │ 利用：薄 value，不要 bluff │ 利用：value 3-bet，打大底池
```

## 類型一：TAG（Tight Aggressive，緊強）

### 特徵

```
HUD 參考：VPIP 15-25%, PFR 13-22%, 3-bet% 7-12%

行為特徵：
  - 只入局優質牌，入局後積極下注
  - 懂短牌規則，了解 Flush > Full House
  - 位置意識好：IP 主導，OOP 保守
  - 翻牌後有計劃（不是亂 bet，也不是亂 check）
  - 對 draw 有正確的 equity 認知（知道每張 out ≈ 3%）
```

### 識別方式

- HUD 數據平衡，VPIP 和 PFR 差距小（≤ 5%）
- 下注尺寸合理（底池的正確比例）
- 面對強 action 時有明確反應（不是每次都 fold 也不是每次都 call）

### 對付策略

```
主要策略：打標準 GTO，避免過度利用（他們會調整）

翻牌前：
  ✓ 在位置上對他們 open 和 3-bet 時，要有明確計劃
  ✓ 不要用弱牌對他們 4-bet bluff（他們的 3-bet range 較強）
  ✗ 不要試圖在他們後位 limp 入（位置是他們的優勢）

翻牌後（短牌特有）：
  ✓ 濕潤板上他們會 c-bet，可以用 strong draw raise（短牌 draw equity 夠大）
  ✓ 他們 IP 施壓時，OOP 用 Nut draw 或強牌 check-raise
  ✗ 不要在他們下注後用弱牌 call（他們的 value range 很真實）

注意：短牌的 TAG 比 NLH 的 TAG 更難被 bluff（因為翻牌後幾乎都有一些 equity）
```

## 類型二：LAG（Loose Aggressive，寬強）

### 特徵

```
HUD 參考：VPIP 35%+, PFR 22%+, 3-bet% 12%+

行為特徵：
  - 廣泛的 open range，頻繁 steal 和 3-bet
  - 翻牌後積極 c-bet 和 barrel
  - 知道短牌 draw 強，會用 semi-bluff 積極施壓
  - 在多種牌面上主動施壓（乾燥板和濕潤板都 bet）
```

### 識別方式

- HUD 顯示 VPIP 和 PFR 都偏高，且 3-bet% 高
- 頻繁從後位和盲注位 open
- 翻牌後很少 check-fold，經常三桶

### 對付策略

```
主要策略：等強牌，讓他們付錢；不要和他們打 bluff 戰

翻牌前：
  ✓ Value 3-bet 頻率增加（KK, QQ, AJ suited 等都可以 3-bet for value）
  ✓ 收緊 3-bet bluff（他們 4-bet 或 call 頻率高）
  ✓ 對他們的 steal，用 strong hands squeeze（多人底池他們會謹慎）

翻牌後（短牌特有）：
  ✓ 在濕潤板不要輕易 check-raise bluff（他們的 range 廣，draw equity 強）
  ✓ 用 Nut 手牌打大底池（他們 range 廣讓你的 value 更有利）
  ✓ 當他們三桶 bluff 時，用 Nut 或 Near-Nut call down
  ✗ 不要因為他們積極就隨便 call（確認你有 Nut 優勢才 commit）

短牌特殊注意：
  LAG 在短牌中的 semi-bluff 比 NLH 更有效（draw equity 高）
  → 面對他們的翻牌後 bet，需要更強的手牌才能 call down
```

## 類型三：Nit（Tight Passive，緊弱）

### 特徵

```
HUD 參考：VPIP <15%, PFR <8%, Fold to Steal >75%

行為特徵：
  - 只打 Premium hands（AA, KK, QQ, AK 等）
  - 翻牌後幾乎不 bluff，只 value bet
  - 面對任何 aggression 傾向 fold
  - 對短牌特性理解不足（可能仍用 NLH 思維評估牌型）
  - 在 Bubble 和 FT 過度保守（ICM 恐懼放大）
```

### 識別方式

- HUD 顯示 VPIP 極低（<15%）
- 在位置（BTN, CO）也不 steal
- 翻牌後一有 c-bet 就大量 fold
- 很少主動 raise 或 re-raise

### 對付策略

```
主要策略：大量偷盲，翻牌後積極施壓

翻牌前：
  ✓ BTN 和 CO 對他們幾乎任何牌都可以 open（他們的 defend 範圍極窄）
  ✓ 對他們的 open，3-bet bluff 頻率大幅增加（Fold to 3-bet >70%）
  ✓ Bubble 時向他們施壓（ICM 恐懼讓他們更容易 fold）
  ✓ 在 SB 對他們的 BB，steal 頻率最大化

翻牌後（短牌特有）：
  ✓ 幾乎所有板面都可以 c-bet（他們不會 check-raise 你）
  ✓ 連續多桶打壓（他們看到 aggression 就 fold）
  ✓ 短牌的濕潤板讓他們更不安全（他們不確定你有什麼 draw）
  ✗ 當他們 raise 或 re-raise 時，要非常尊重（他們只有強牌才這樣做）

注意：Nit 拿到強牌時的「慢打」很常見 → 看到他們突然 limp/call，小心
```

## 類型四：Calling Station（Loose Passive，寬弱）

### 特徵

```
HUD 參考：VPIP 40%+, PFR <12%, WTSD% 55%+, Fold to C-bet <35%

行為特徵：
  - 過度 call，很少主動加注
  - 追各種 draw（包括 non-nut draw）
  - 對 bluff 免疫：他們不相信你
  - 在短牌中更危險：draw 成牌機率高，他們的 call 有時真的 +EV
  - 不了解 Flush > Full House，常因牌型誤解犯大錯
```

### 識別方式

- HUD 顯示 VPIP 遠高於 PFR（差距 30%+）
- 頻繁 limp，很少 raise
- 打到 showdown 比例很高（WTSD% 55%+）
- 對任何下注都 call，很少 fold

### 對付策略

```
主要策略：薄 value，完全停止 bluff

翻牌前：
  ✓ Isolate（隔離）他們：對他們的 limp，用中等以上手牌 raise 隔離
  ✓ 不要用弱牌 limp 進入和他們打（他們的 call 機率高，equity 差難利用）
  ✓ 3-bet for value 比 bluff 有效得多

翻牌後（短牌特有）：
  ✓ 薄 value bet：Two Pair、低 Set 都可以積極 bet（他們會 call）
  ✓ Nut 手牌直接打大底池（他們不介意 call 大注）
  ✓ 完全停止 bluff（0% bluff，他們 call 一切）
  ✓ 注意短牌的 draw 強度：他們追的 draw 有 3% per out，不要 value bet 太薄被 draw 打爆

短牌特殊危險：
  短牌 Calling Station 比 NLH 更難對付：
    - 他們的 draw call 在短牌中有更高 equity（3% per out）
    - 濕潤板上他們的 random call 更容易成牌
  → 對付策略調整：只用 Nut 或 Near-Nut 打大底池，避免 Two Pair 以下大注
```

## 短牌特殊類型：NLH 轉型玩家

短牌 MTT 中有大量從 NLH 轉型的玩家，形成短牌特有的錯誤模式。

### 特徵

```
行為特徵：
  - 翻牌前範圍和 NLH 類似，但翻牌後犯 NLH 思維錯誤
  - 仍用 NLH 的牌型強弱順序（以為 Full House > Flush）
  - 不習慣短牌的濕潤板（每張 out ≈ 3% 的認知不足）
  - 過度重視 Top Pair（NLH 習慣），低估 Flush 危險性
  - Set 被 Flush 打爆後會「不可置信」地繼續犯同樣錯誤
```

### 識別方式

- 面對 Flush 可能時仍然大注（以為 Set 或 Full House 夠強）
- 用 NLH 的 out 計算（把 draw 的 equity 低估 50%）
- 在濕潤板 c-bet 大注但翻牌後容易被 draw 打爆

### 對付策略

```
翻牌前：
  ✓ 標準打法即可，他們的 range 和 NLH reg 類似

翻牌後（利用 NLH 思維錯誤）：
  ✓ 在 Flush 可能的板面 semi-bluff（他們不夠尊重你的 Flush）
  ✓ 當板面完成 Flush 時，積極 value bet（他們的 Full House 不夠強）
  ✓ 在濕潤板用 strong draw aggressive（他們低估你的 equity）
  ✓ 當他們大注代表強牌但牌型不是 Nut 時，用 Nut 打爆他們

注意：不要對他們 bluff 沒有 Flush 可能的板面（他們在這種板面反而判斷較準）
```

## 桌面讀牌：快速識別玩家類型

### 第一輪（前 15-20 手，無 HUD 時）

```
觀察要點：

1. 入局頻率
   常入局（40%+）→ Calling Station 或 LAG 傾向
   很少入局（<15%）→ Nit 或 TAG 傾向

2. 入局方式
   頻繁 limp → Calling Station 或 Recreational
   幾乎都 raise → TAG 或 LAG

3. 翻牌後行為
   經常 fold 面對 c-bet → Nit 或 TAG（保守）
   幾乎不 fold → Calling Station
   頻繁 raise / re-raise → LAG

4. 短牌特有觀察
   用 Full House 大注被 Flush 打爆後仍繼續 → NLH 轉型玩家
   不了解 Outs 賠率（明顯 -EV call）→ Recreational / Calling Station
```

### 快速決策指引

| 觀察到的行為 | 可能類型 | 立即對策 |
|------------|---------|---------|
| 每手都 limp 進來 | Calling Station | 用強牌 isolate，薄 value |
| BTN 也不 steal | Nit | 大量 steal，3-bet bluff |
| 3-bet 很多不同手牌 | LAG | 收緊 bluff，value 3-bet |
| 下注尺寸很精確、不 limp | TAG / Reg | 打標準 GTO |
| Full House 被 Flush 打後仍大注 set | NLH 轉型 | Flush 板面積極 value |

## 本章重點回顧

1. **四象限框架**：TAG（緊強）、LAG（寬強）、Nit（緊弱）、Calling Station（寬弱）是核心分類。
2. **短牌放大弱點**：Draw 更強讓 Calling Station 更難對付，同時讓 Nit 的翻牌後 fold 更容易被利用。
3. **TAG**：打標準 GTO，位置上施壓，不要亂 bluff。
4. **LAG**：等強牌打大底池，收緊 bluff，value 3-bet 增加。
5. **Nit**：大量偷盲，翻牌後連續 barrel，Bubble 施壓。
6. **Calling Station**：薄 value，0% bluff，只用 Nut/Near-Nut 打大底池。
7. **NLH 轉型玩家**：利用他們的牌型誤解，在 Flush 板面積極 value bet。
