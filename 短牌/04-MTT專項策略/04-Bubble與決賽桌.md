## 一、短牌 Bubble 的特殊動態

### 1.1 什麼是 Bubble？

Bubble = 比賽剩餘玩家數比獎圈人數多 1 的特殊階段。

例如：比賽前 20 名進獎圈，現在剩 21 人 → 「泡沫期（Bubble）」

「Bubble Boy」= 第 21 個被淘汰的玩家，什麼都拿不到。

### 1.2 短牌 Bubble 為什麼不同於 NLH Bubble？

**NLH Bubble 的典型現象**：
- 幾乎所有人都變得保守
- 全桌的 VPIP（入池率）大幅下降
- 大疊橫行，小注偷底池頻繁

**短牌 Bubble 的不同之處**：
1. 翻牌後的 Draw 讓玩家難以完全保守（Draw 需要追）
2. 全押的頻率仍然相對高（短牌的自然特性）
3. ICM 壓力雖然高，但不像 NLH 那樣讓所有人完全停滯
4. 大疊的進攻性更強（因為對手更難放棄 Draw 類型的手牌）

```
短牌 Bubble 的動態平衡：
→ 中疊/短疊：更保守，避免 Bubble Boy 的命運
→ 大疊：積極進攻，利用 ICM 壓力施壓中疊/短疊
→ 但即使大疊，也不能忽視強牌的威脅（短牌全押後任何人都有機會）
```

## 二、大疊的 Bubble 策略

### 2.1 大疊的優勢和責任

作為大疊，你的 ICM 壓力最小：
- 即使輸掉一個底池，你通常不會被淘汰
- 你輸一個底池 = 損失籌碼，但仍在比賽中
- 你贏一個底池 = 更大的籌碼優勢，下一名次機率更高

**大疊應該做的**：
1. 頻繁偷底池（對中疊和短疊施壓）
2. 面對短疊的全押，用更寬的範圍跟注
3. 避免和其他大疊的大底池對決

### 2.2 大疊的 Bubble 進攻性

```
大疊在 Bubble 的偷底池策略：

目標對象：中疊（ICM 壓力最大的玩家）
方式：從後位頻繁開牌，C-bet，施壓

具體動作：
→ 從 CO/BTN 幾乎所有手牌都開牌（寬 range）
→ 翻牌後積極 C-bet（即使沒有成牌）
→ 面對跟注，謹慎行事（中疊跟注通常有真實手牌）

短牌的額外考量：
→ C-bet 要用大 Size（短牌習慣），因為對手有 Draw
→ 純 Bluff 在短牌中效率較低（對手有 Draw，不願棄牌）
→ 所以大疊的進攻性應是「有支撐的進攻」（Semi-Bluff，有一些 Equity）
```

### 2.3 大疊面對短疊全押的跟注範圍

```
短牌 Bubble 大疊跟注範圍（vs 短疊 15-25bb 全押）：

比 NLH 更寬地跟注，原因：
→ 短牌中對子 vs 對子，大對子優勢仍然顯著
→ 但也更多 Draw 讓相差不大的手牌有機會

建議跟注範圍（大疊 vs 短疊全押）：
→ 對子：66+ 或更寬（視情況）
→ A 高：ATo+（A 高的配對潛力 + 短牌的 Flush Drive）
→ 同花連牌：JTs+（有 Combo Draw 潛力，值得跟注短疊）
→ 比 NLH 更積極的跟注這些手牌

但不要太瘋狂：
→ 短疊的手牌通常有一定強度（否則他們不會 Push）
→ 不要用純垃圾手牌跟注（即使是大疊）
```

## 三、中疊的 Bubble 策略

### 3.1 中疊的 ICM 困境

中疊（通常是平均籌碼量附近的玩家）面臨最大的 ICM 壓力：

```
中疊的困境：
→ 太保守：被大疊侵蝕，可能進獎圈但很短疊
→ 太積極：可能意外淘汰（成為 Bubble Boy）

最佳策略：
→ 針對短疊施壓（短疊在 Bubble 期更怕全押）
→ 避免和大疊的大底池對決（輸了可能嚴重短疊）
→ 選擇性地偷底池（位置好且對手是短疊/另一個中疊時）
```

### 3.2 中疊面對大疊進攻的防守

```
大疊頻繁開牌/C-bet，你（中疲）的應對：

情況 1：大疊開牌，你的手牌
→ 只有真正強牌才跟注或 3-bet
→ 中等牌通常棄牌（ICM 讓你保守）

情況 2：你在 BB，大疊在 BTN 偷底池
→ 比普通情況更保守地 3-bet（被全押後的損失大）
→ 只有超強手牌才 3-bet（AA/KK/AKs）
→ 中等手牌可以跟注但不要 3-bet
→ 弱手牌棄牌（即使 BB 已投入）

情況 3：你先行動（位置不好），大疊在後位
→ 盡量避免在 BB 以外的位置入局弱牌
→ 不要給大疊加注後你「夾在中間」的機會
```

### 3.3 中疊對陣短疊的互動

```
中疊 vs 短疊（Bubble 期）：

你（中疊）可以積極對短疊施壓：
→ 短疊在 Bubble 期會盡量避免全押
→ 你可以用頻繁的開牌/下注讓短疊承受壓力
→ 如果短疊全押，你可以用相對較寬的範圍跟注
  （贏了 = 消滅短疊，ICM EV 提升；輸了 = 你仍在比賽）

注意：
→ 不要讓短疊的全押讓你的 ICM EV 嚴重受損
→ 例如：你是中疊（剛好在平均線上），短疊全押，你跟注並輸了
→ 你可能變成比平均更短的疊，ICM 壓力增加
→ 這種情況下，用更保守的跟注範圍
```

## 四、短疊的 Bubble 生存策略

### 4.1 短疊的兩種選擇

短疊在 Bubble 期有兩個明確的方向：

**選擇 A：等待進獎圈（保守）**
- 最小化行動，讓其他短疊先被淘汰
- 只有超強牌才 Push
- 目標：進入獎圈，即使只拿最低獎金

**選擇 B：積極尋找翻身機會（積極）**
- 在合適的機會全押
- 試圖在 Bubble 時積累籌碼
- 目標：進入決賽桌強疊

**哪個更好？**

```
取決於：
1. 你距離「被淘汰的最後排名」有多近
2. 獎金結構（前幾名獎金是否遠高於進獎圈最低獎金）
3. 其他短疊的情況（是否有比你更短的疊）

建議：
→ 如果有比你更短的疊，考慮保守等待
→ 如果你是最短疊，必須積極（等待 = 被 Ante 侵蝕到死）
→ 如果獎金差距大（FT 獎金遠高於 Bubble 獎金），更積極
```

### 4.2 短疊的 Push Range（Bubble 期）

```
Bubble 期短疊 Push Range（15bb）：

比正常 MTT Push Range 更緊：
因為大疊在 Bubble 期會更積極地跟注（消滅短疊對大疊有 ICM 好處）

只 Push：
AA, KK, QQ, JJ（高對子）
AKs, AKo（超強高牌）
TT, 99（視位置，後位才用）
AQs, AQo（後位）

不 Push（即使平時會 Push）：
小對子（77 以下）——短牌大疊更願意跟注這些
同花連牌——沒有翻後優勢的翻前全押
中等不同花牌
```

## 五、Final Table（決賽桌）策略

### 5.1 FT 的動態與 NLH MTT 的差異

短牌 FT 比 NLH FT 更動盪：
1. 全押頻率更高
2. 籌碼格局變化更快
3. 需要更頻繁地調整策略

### 5.2 FT 早期（9-6 人）

```
FT 早期的關鍵：
→ 每個位置的升級都有真實獎金意義
→ 從第 9 名到第 8 名就可能有幾千美元的差距

策略：
→ 仍然謹慎（ICM 影響仍高）
→ 大疊繼續施壓，但不要過度冒險
→ 中疊等待機會，不要急於跟注大疊
→ 短疊積極尋找全押機會（等待只會被侵蝕）

短牌 FT 早期的特殊動態：
→ 全押比 NLH FT 更頻繁
→ 每手牌的方差更高
→ FT 早期就可能出現多次全押對決
```

### 5.3 FT 中期（5-3 人）

```
FT 中期（5 人到 3 人）：
→ 獎金差距變大，ICM 影響仍然顯著
→ 但比 FT 早期更積極（因為人更少，每人份額更大）

策略調整：
→ 開始更積極地建立底池
→ ICM 讓你不能太被動（籌碼被 Ante 侵蝕的代價更高）
→ 大疊的「收割」能力更強

短牌 3 人桌：
→ 幾乎所有手牌都值得考慮入局
→ 3-bet 更頻繁（人少，強牌出現機率更高）
→ 翻牌後積極性更強
```

### 5.4 FT HU（最後 2 人）

短牌單挑（HU）是一種非常特殊的對局形式：

```
HU 的基本調整：

1. 手牌評估大幅放寬
→ 任何 Ace 高都是強牌
→ 對子幾乎都值得入局
→ 同花連牌的價值更高（Flush 潛力）

2. 位置更重要
→ HU 時，BTN 是 SB，翻牌前最後行動
→ 翻牌後 BTN 先行動（OOP）
→ 但翻牌前的位置優勢補償了翻牌後的劣勢

3. 入局範圍幾乎包含所有手牌
→ BTN（SB）：90%+ 的手牌至少加注
→ BB：廣泛地跟注，或 3-bet 強牌

4. 3-bet 的大幅放寬
→ HU 時 3-bet 非常常見
→ 幾乎每 3-5 手就有一次 3-bet
→ 4-bet/5-bet 的頻率也更高

短牌 HU 的翻牌後策略：
→ C-bet 頻率恢復到較高水平（因為每個人都有 Draw，但你也有！）
→ 積極進攻，但注意 ICM（每個決策的獎金差距可能很大）
```

### 5.5 HU 的籌碼策略

```
HU 時的籌碼動態：

深疊 HU（100bb+）：
→ 廣泛的 Draw 追逐
→ 積極 Semi-Bluff
→ 多街的建底池

中疊 HU（30-100bb）：
→ 翻前加注 = 幾乎 100%
→ 翻牌後 C-bet 頻率高
→ 謹慎的 Stack Off 決策

短疊 HU（<30bb）：
→ Push/Fold 主導
→ 每手牌幾乎都是全押或棄牌
→ ICM 仍然重要（第 1 名和第 2 名的獎金差距）

HU 短疊 Push Range（20bb）：
幾乎所有手牌都可以 Push，包括：
所有對子，所有 Ace 高，所有連牌（同花更好），King 高等
```

## 六、Bubble 和 FT 的心理因素

### 6.1 Bubble 的心理壓力

```
常見的 Bubble 心理誤區：

1. 「進獎圈就是勝利」心態
→ 問題：進了獎圈卻是短疊，最終只拿到最低獎金
→ 正確：考慮 ICM EV，進獎圈的同時也要考慮後續潛力

2. 「避免一切風險」
→ 問題：太保守導致籌碼被侵蝕，進獎圈時已是超短疊
→ 正確：在 ICM 允許的範圍內保持適當積極性

3. 「我怎麼這麼倒霉」（Bad Beat 後效應）
→ 問題：在 Bubble 期遭遇 Bad Beat 後情緒化決策
→ 正確：每手牌獨立決策，過去的結果不影響當前決策
```

### 6.2 FT 的心理壓力

```
FT 的壓力管理：

1. 每個決策都有大額金錢意義
→ 解決方案：專注於正確的決策過程，而非結果

2. 在大家都認識的對手面前表現的壓力
→ 解決方案：把 FT 當作普通的 MTT 繼續打，不要改變策略

3. 「想要贏冠軍」而冒不必要的風險
→ 解決方案：記住 ICM，不同位置的獎金已經有意義了
→ 例如：從第 3 名到第 2 名可能比從第 2 名到第 1 名更容易
```

## 七、決賽桌手牌情景分析

### 情景 1：FT 9 人，Bubble 後第一手牌

```
背景：剛進 FT，9 人，你有 45bb（中上等）

你在 BTN，大疊（80bb）在 CO 開牌 3x
你的手牌：K♠ J♠（同花 KJ）

分析：
→ 剛進 FT，每個升級都有價值
→ KJs 是強牌，但面對 CO 開牌（UTG 附近的位置信號強）
→ BTN 可以 3-bet 或跟注

考量：
→ 3-bet 後如果被 4-bet，你面臨棄牌（損失 3-bet 金額）或跟注全押（很大的 ICM 風險）
→ KJs 在 FT 早期不夠好到全押面對 CO 的 4-bet

建議：跟注（IP，保留翻牌後的靈活性）
→ 翻牌後根據情況決定（有 Draw 就積極，沒有就控制底池）
```

### 情景 2：FT 4 人，你是短疊

```
背景：FT 剩 4 人，你有 15bb（最短疊），其他人都有 30bb+

你在 UTG（BTN 在大疊左邊），手牌：9♦ 7♦（同花 97）

分析：
→ 97s 在 UTG 是不夠強的 Push 牌
→ 4 人桌，UTG 是最糟的位置，後面有 3 個人
→ 短牌中 97s 的翻前 Push EV 不高（大疊跟注後你的勝率不好）

建議：棄牌，等待更好的機會
→ 在 CO 或 BTN 時，97s 可以 Push
→ 在 UTG，等到更強的手牌（A 高、對子等）

如果是 A♦ 7♦：
→ 14-15bb 的 A 高同花，FT 4 人桌的 UTG
→ 短牌中 A7s 有一定的 Flush 潛力，但 UTG 仍然謹慎
→ 此情況，Push 是可以接受的（A7s 的翻前勝率 vs 隨機手牌 > 50%）
```

### 情景 3：HU，你有大疊

```
背景：HU，你有 2:1 的籌碼優勢（200bb vs 100bb）

手牌：T♥ 8♥（同花 T8）

分析：
→ HU 時，T8s 是很強的手牌（有 Flush 潛力 + 連接性）
→ 你的大疊讓你可以更積極
→ BTN（SB）開牌，BB 可能 3-bet

打法：BTN 標準開牌（3x），如果 BB 3-bet，考慮跟注（有 Flush 潛力）
→ HU 的 T8s 值得跟注 3-bet（有位置，有 Draw 潛力）
→ 翻牌後積極參與（有任何 T♥ Draw 就 Semi-Bluff）
```

## 本章重點摘要

1. **Bubble 大疊**：積極施壓，偷底池，用更寬的範圍跟注短疊全押
2. **Bubble 中疊**：謹慎，避免和大疊的大底池，積極對短疊施壓
3. **Bubble 短疊**：根據情況選擇保守（等進獎圈）或積極（尋找翻身）
4. **FT 早期**：ICM 仍高，謹慎行事，大疊繼續施壓
5. **FT 中後期**：更積極，獎金差距讓積極建底池更合理
6. **HU**：幾乎任何手牌都入局，3-bet 頻繁，ICM 仍然重要
