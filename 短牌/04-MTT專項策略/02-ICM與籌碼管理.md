## 一、ICM 基本概念

### 1.1 什麼是 ICM？

ICM（Independent Chip Model，獨立籌碼模型）是一種計算 MTT 玩家「當前籌碼所對應的期望獎金」的模型。

**核心假設**：每個玩家獲得各名次的機率，與其持有的籌碼占比成正比。

```
ICM 基本公式：

P(player i 獲得第 1 名) = chips_i / total_chips

P(player i 獲得第 2 名) = Σ over all j≠i [P(j gets 1st) × chips_i / (total_chips - chips_j)]

以此類推...

ICM EV = P(1st) × prize_1st + P(2nd) × prize_2nd + P(3rd) × prize_3rd + ...
```

### 1.2 ICM 計算示例

**情境**：4 人剩餘，獎金結構 $10,000 / $6,000 / $3,000 / $1,000（第 4 名進錢）

| 玩家 | 籌碼 | 籌碼比例 |
|------|------|---------|
| 玩家 A | 400,000 | 40% |
| 玩家 B | 300,000 | 30% |
| 玩家 C | 200,000 | 20% |
| 玩家 D | 100,000 | 10% |

```
玩家 A 的 ICM EV 計算：
P(A 得 1st) = 0.40 × $10,000 = $4,000

P(A 得 2nd)：（假設 B 先得 1st 的情況下）
= P(B 1st) × A/(total-B的籌碼) + P(C 1st) × A/(total-C的籌碼) + P(D 1st) × A/(total-D的籌碼)
= 0.30 × (400K/700K) × $6,000 + 0.20 × (400K/800K) × $6,000 + 0.10 × (400K/900K) × $6,000
≈ (0.30 × 0.571 + 0.20 × 0.500 + 0.10 × 0.444) × $6,000
≈ (0.171 + 0.100 + 0.044) × $6,000
≈ 0.315 × $6,000 = $1,890

（完整計算需要考慮所有排列組合，這裡是近似）

玩家 A 的估計 ICM EV ≈ $4,000 + $1,890 + ... ≈ $6,000-$7,000
（精確計算需要更複雜的遞迴公式）
```

**重要結論**：玩家 A 雖然有 40% 的籌碼，但 ICM EV ≈ $6,500，而不是 Chip EV = 40% × $20,000 = $8,000。

**ICM 壓縮效應**：籌碼多的玩家，每增加 1 個籌碼的邊際 ICM 價值遞減。

### 1.3 ICM 壓力的方向

```
ICM 壓力如何改變決策：

短疊玩家（籌碼少）：
→ 每個籌碼對 ICM EV 的貢獻更大
→ 輸掉全部籌碼 = 淘汰，ICM EV 歸零
→ 應更謹慎，避免不必要的全押

大疊玩家（籌碼多）：
→ 籌碼的邊際 ICM 價值較低
→ 輸掉一部分籌碼不會淘汰
→ 可以利用 ICM 壓力欺壓短疊

例：大疊 vs 短疊（短疊是 Bubble 外的最短疊）：
→ 大疊可以頻繁全押，短疊必須用超強牌才反擊
→ 這就是 Bubble 期的「大疊欺壓」策略
```

## 二、Chip EV vs ICM EV 的切換時機

### 2.1 Chip EV 主導的情況

以下情況下，純 Chip EV 決策更接近正確：

1. **MTT 早期**：距離獎圈很遠，排名不影響 ICM
2. **HU（單挑）**：只有 2 人，ICM 影響最小（只有 1 名和 2 名的差別）
3. **遠離 Bubble**：不在泡沫期附近

```
MTT 早期的策略：
→ 像 Cash Game 一樣打（Chip EV 導向）
→ 積極建立籌碼
→ 不要為了保存籌碼而放棄好的 EV 機會

例：早期階段，你有 AKs，面對 UTG 全押（對方可能是 AA/KK）
→ Chip EV：AKs 對 AA ≈ 18% 勝率，數學上可能不合算
→ ICM EV：和 Chip EV 幾乎一樣（ICM 影響極小）
→ 決策：基於 Chip EV，通常棄牌（如果確信是 AA/KK）
```

### 2.2 ICM EV 主導的情況

以下情況下，ICM 會顯著改變決策：

1. **泡沫期**：差幾個人進獎圈
2. **FT 早期**：每個位置的升級有真實金錢差異
3. **多人決賽桌**：從 9 人到 3 人，每消滅一人都有獎金
4. **有超短疊在桌上**：讓一個超短疊自然淘汰的 ICM 價值

```
泡沫期 ICM EV 示例：
情境：100 人報名，前 15 名進獎圈，現在剩 16 人
你：中疊 30bb
對手：大疊 80bb
你的手牌：QQ

對手全押：
→ 對手的 range 可能是 AA, KK, AK, 偶爾 JJ
→ Chip EV 上跟注 QQ 可能有利（對 AK 有優勢，對 AA/KK 劣勢）
→ ICM EV 上：如果輸，你被淘汰，ICM EV = $0（沒有拿到任何獎金）
             如果贏，你有 63bb（大疊），排名大幅提升
→ ICM EV 讓你更謹慎：等到更確定的手牌，因為淘汰的成本極高
```

### 2.3 短牌 MTT 的 ICM 切換更頻繁

由於短牌全押更頻繁，ICM 決策點更多：

```
短牌 MTT 中的 ICM 決策時刻：

1. 翻牌前全押（比 NLH 更多）：
   → 短牌玩家更願意翻前全押（更多人有 Combo Draw 潛力）
   → ICM 影響這些決策

2. 翻牌後全押（非常頻繁）：
   → 短牌翻牌後 All-in 比率極高
   → 即使在 MTT 早期，也需要考慮 ICM 的潛在影響

3. Draw vs Made Hand 的對局：
   → 短牌中更常見這種高方差對局
   → ICM 讓這些決策更重要
```

## 三、Bubble 時的短牌特殊考量

### 3.1 短牌 Bubble 比 NLH Bubble 更激烈

在 NLH MTT 的 Bubble，玩家普遍更謹慎，全押頻率降低。短牌 Bubble 有些不同：

**原因**：
1. 短牌的翻牌後 Draw 更多，玩家難以避免全押情況
2. 積極打（Semi-Bluff）是短牌的正確策略，即使在 Bubble 期
3. 一些強力 Draw 的全押是合理的，即使在 Bubble

```
短牌 Bubble 的平衡點：

過於保守的錯誤：
→ 在 Bubble 期完全不做 Semi-Bluff
→ 結果：籌碼被 Ante 和盲注侵蝕，到獎圈時是短疊
→ 進了獎圈但只拿到最低獎金

適當積極：
→ 在 Bubble 期，持有強力 Draw 時仍然半詐唬
→ 但對純弱牌（無 Backup Equity）更保守
→ 平衡 ICM 壓力和籌碼需求
```

### 3.2 大疊/中疊/短疊的 Bubble 策略

**大疊（前 20% 籌碼量）**：
```
→ 積極利用 ICM 壓力
→ 頻繁偷底池（對中疊和短疊施壓）
→ 面對短疊的全押，可以更寬地跟注（他們輸了是淘汰，你輸了仍然有很多）
→ 但不要用全疊和其他大疊決鬥（雙方都不需要這樣）

短牌特殊：
→ 大疊的 Semi-Bluff 更有效（因為你有籌碼優勢和 Draw 支撐）
→ 積極下注強力 Draw，給中疊施壓
```

**中疊（中間 50% 籌碼量）**：
```
→ ICM 最敏感的位置
→ 需要避免和大疊的大底池對決（特別是 All-in 情況）
→ 集中在和短疊的互動（消滅短疊對你的 ICM EV 有利）
→ 收緊全押範圍，但仍要積極偷底池

短牌特殊：
→ 避免用 Non-Nut Draw 面對大疊的大注
→ 持有 Nut Draw 時仍可以積極（完成後難以被超越）
```

**短疊（最後 30% 籌碼量或低於平均）**：
```
→ 面臨生存壓力
→ Push/Fold 邏輯主導
→ 選擇：等到進獎圈（保命），或全力搏一個翻身的機會

短牌特殊：
→ 短疊的全押 range 要比 NLH 更謹慎（短牌大疊會更寬地跟注）
→ 原因：短牌的 Draw 讓大疊的跟注 EV 更高（他們有更多追上的機會）
→ 所以短疊 Push Range 要更緊（只用真正強的手牌）
```

## 四、短疊在短牌 MTT 的生存策略

### 4.1 短疊的 Push/Fold 原則

短疊（15-30bb）在短牌 MTT 中的策略比 NLH 更保守：

```
短牌 Push Range（大約 20bb 深疊）：

非常積極推疊（幾乎所有位置）：
AA, KK, QQ, JJ, TT, AKs, AKo

中位以後積極推疊：
AQs, AQo, 99, AJs

後位（CO/BTN）才推疊：
88, 77, ATs, AJo, KQs

不應推疊（即使是短疊）：
小對子（66-）——短牌中大疊跟注更寬
中等不同花手牌——與德州比較，在短牌中更弱
純同花連牌（JTs 等）——翻前全押沒有同花優勢

原因：
短牌大疊的跟注 range 比 NLH 更寬，因為：
→ 短牌中任何對子或連牌都有更多 Draw 潛力
→ 完成 Draw 的機率更高
→ 大疊願意跟注的理由更充分
```

### 4.2 超短疊（< 15bb）的策略

超短疊幾乎只有 Push/Fold 選項：

```
<15bb 的決策框架：
1. 翻前全押（Push）：需要較強手牌
2. 棄牌：所有其他情況
3. 不要 Limp（跟注盲注），這在短疊時是弱的打法

什麼情況必須 Push（即使很短疊）：
→ < 10bb：BB 都要 Push 大多數手牌（因為輪到 BB 時自動跟注很多）
→ 積極推疊以防 Ante 侵蝕

注意：短牌短疊的計算：
有效深度 = 你的籌碼 / (當前 BB 大小 + Ante)
如果 Ante = BB（BTN Ante），每手牌你付出的是：
→ 如果你在 BTN：2 個 BB（BTN Ante + 正常行動）
→ 如果你在其他位置：通常 0（除非你在 SB/BB）
→ 所以你的「有效消耗率」不是每手 1BB，而是每輪約 2-3 個 BB
→ 10bb 可以維持約 3-5 輪，不是 10 輪
```

## 五、ICM 數值計算的實際應用

### 5.1 邊際 ICM 計算（簡化版）

```
實際賽場上的 ICM 近似方法：

「$EV 法」：計算每個決策的期望獎金收益

情境：8 人剩餘，獎金結構（$5k/$3k/$2k/$1k/$500×4），
你有 200,000 chips（總籌碼 1,000,000，你的份額 20%）

現在你面臨一個全押決策：
→ 贏：你的籌碼變為 380,000（38%）
→ 輸：你被淘汰，ICM EV = $0（在第 8 名，如果獎圈是前 8 名，剛好在線上）

假設你進獎圈的基本值：
→ 第 8 名：$500
→ 贏了全押後大幅提升排名

如果是 Bubble（差 1 個名次進獎圈）：
→ 你進獎圈就值 $500，即使馬上被淘汰
→ ICM 計算：現在 Push 的成本是輸了 = $0，贏了 = 顯著提升
→ 如果勝率 > 33%（基本 ICM 折扣計算），全押有利
```

### 5.2 短牌特有的 ICM 計算調整

短牌的 ICM 計算在一個方面有別於 NLH：**每手牌的方差更高**

```
方差對 ICM 的影響：

在高方差環境（短牌）中：
→ 不確定性更大
→ ICM 「風險溢價」更高
→ 你需要更高的 Chip EV 優勢才能彌補 ICM 的風險

近似規則：
→ 短牌 MTT 中，All-in 決策需要的 Chip EV 優勢比 NLH 高 5-10%
→ 例如：NLH 中 55% 勝率的全押在 ICM 調整後可能 OK
→ 短牌中，同樣情況可能需要 60% 的勝率
```

## 六、籌碼管理的黃金法則

### 6.1 不要把大部分籌碼放進不確定性高的局

```
短牌 MTT 的籌碼管理規則：

規則 1：避免非必要的高方差 All-in
→ 你不需要每個 All-in 機會都接受
→ 選擇最高 EV 的機會，不是所有機會

規則 2：持有 Nut Draw 才全押
→ Non-Nut Draw 完成後可能仍然輸
→ 把全疊放進 Non-Nut Draw = 巨大方差

規則 3：維持最低可用籌碼深度
→ 不要讓自己短疊到只能 Push/Fold
→ 短疊失去了很多策略選擇
→ 在合適的時機補充籌碼（積極建立底池）
```

### 6.2 不同階段的籌碼目標

| 比賽階段 | 籌碼目標 | 說明 |
|---------|---------|------|
| 早期（> 100bb） | 維持或增加，不必冒大風險 | 深疊優勢大，等候好機會 |
| 中期（30-100bb） | 積極偷底池，維持有效深度 | 避免被 Ante 侵蝕 |
| 短疊（15-30bb） | 找最佳 Push 機會 | Push/Fold 邏輯 |
| 泡沫期 | 根據大疊/中疊/短疊的不同策略 | ICM 最關鍵 |
| FT | 每個位置的升級都有意義 | 平衡積極和 ICM 考量 |

## 本章重點摘要

1. **ICM 計算**：籌碼的 ICM 價值 ≠ 面值，邊際價值隨籌碼增加而遞減
2. **Bubble 期最重要**：ICM EV 在 Bubble 附近影響最大，決策要謹慎
3. **短疊 Push Range 更緊**：短牌大疊跟注更寬，所以短疊要更保守
4. **高方差補償**：短牌需要更高的 Chip EV 優勢才能抵銷 ICM 風險
5. **大疊的特權**：大疊可以利用 ICM 壓力欺壓中疊和短疊
6. **Nut Draw 才全押**：Non-Nut Draw 的 All-in 在 ICM 環境下風險過高
