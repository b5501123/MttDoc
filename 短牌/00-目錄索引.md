## 快速導覽

短牌（Short Deck Poker，又稱 6+ Hold'em）是從標準德州撲克演變而來的變體，移除了所有 2、3、4、5 的牌，僅使用 36 張牌進行遊戲。這個改變看似微小，實際上徹底顛覆了牌型強弱順序、勝率計算、以及所有翻牌前後的策略邏輯。

本教材專為 **MTT（多桌錦標賽）** 場景設計，聚焦於 9-max 標準桌，幫助您從零開始系統性地掌握短牌 MTT 的完整策略體系。

## 短牌術語速查表

以下收錄短牌 MTT 最常用的 30 個術語，供快速查閱：

| 術語 | 英文原文 | 定義與說明 |
|------|----------|------------|
| 短牌 | Short Deck / 6+ Hold'em | 移除 2-5 的 36 張牌版德州撲克 |
| 牌組 | Deck | 短牌使用 36 張牌（移除 2、3、4、5） |
| BTN Ante | Button Ante | 由莊家位（BTN）支付全桌底注的結構 |
| Full Ante | Full Ante | 全桌每人都付底注的格式 |
| 同花 | Flush | 短牌中比葫蘆（Full House）更強的牌型 |
| 葫蘆 | Full House | 短牌中比同花弱的牌型（順序改變） |
| 三條 | Three of a Kind / Set | 短牌中比順子更強的牌型 |
| 順子 | Straight | 短牌中比三條弱（A-6-7-8-9 是最低順子） |
| 低 A 順子 | Wheel（短牌版） | A-6-7-8-9（短牌的最低順子，非德州的 A-2-3-4-5） |
| Out | Out | 可以改善手牌的牌；短牌每張 out ≈ 3% |
| 同花聽牌 | Flush Draw | 4 張同花，聽第 5 張；短牌中更強 |
| 順子聽牌 | Straight Draw | 4 張連牌聽順子 |
| 雙端順子 | Open-Ended Straight Draw (OESD) | 兩端都可完成的順子聽牌，8 個 outs |
| 內聽順子 | Gutshot / Inside Straight Draw | 只有一端可完成，4 個 outs |
| Wrap | Wrap Draw | 超過 8 個 outs 的順子聽牌組合 |
| 三條（暗） | Set | 手持對子，翻牌又出現第三張同點數的牌 |
| 三條（明） | Trips | 公共牌有對子，手持第三張同點數的牌 |
| 持續下注 | Continuation Bet (C-bet) | 翻牌前加注方在翻牌後繼續下注 |
| ICM | Independent Chip Model | 籌碼獨立模型，用於評估 MTT 籌碼的真實價值 |
| Chip EV | Chip EV | 以籌碼計算的期望值，不考慮 ICM |
| ICM EV | ICM EV | 以獎金計算的期望值，考慮泡沫壓力 |
| Bubble | Bubble | 差一步進獎圈的關鍵階段 |
| FT | Final Table | 決賽桌（最後剩下的 9 人桌） |
| HU | Heads-Up | 單挑（最後兩人） |
| Push/Fold | Push/Fold | 短疊時只能選擇全押或棄牌 |
| Squeeze | Squeeze | 在有開牌者和跟注者之後的 3-bet |
| 3-bet | 3-bet | 對開牌者再加注（第三次下注行為） |
| 4-bet | 4-bet | 對 3-bet 再加注（第四次下注行為） |
| Pot Odds | Pot Odds | 底池賠率，決定是否跟注聽牌 |
| Equity | Equity | 勝率，手牌當前的期望贏得底池比例 |

## 短牌 vs 德州撲克（NLH）核心差異速覽

| 項目 | 德州撲克（NLH） | 短牌（Short Deck） |
|------|-----------------|-------------------|
| 牌組張數 | 52 張 | 36 張（移除 2-5） |
| Flush vs Full House | Full House > Flush | **Flush > Full House** |
| Three of a Kind vs Straight | Straight > Three of a Kind | **Three of a Kind > Straight** |
| 最低順子 | A-2-3-4-5 | **A-6-7-8-9** |
| 每張 Out 翻牌後機率 | ≈ 4%（轉牌+河牌） | ≈ 3%（翻牌後計至轉牌） |
| 翻牌後濕潤程度 | 中等 | **幾乎都是濕潤翻牌** |
| 底注結構 | BB + SB | BTN Ante（常見格式） |
| AA vs KK 前勝率 | AA ≈ 80% | AA ≈ 75%（差距縮小） |
| Flush Draw 勝率 | ≈ 35%（翻牌後） | ≈ 45%（翻牌後） |

## 和 NLH MTT 教材的對照學習建議

如果您同時在學習 NLH MTT，建議以下對照學習方式：

### 相同原理，可直接遷移
- ICM 基本概念（泡沫、FT 策略框架）
- 位置優勢的重要性
- 籌碼深度對策略的影響邏輯
- GTO vs 剝削性策略的基本思路

### 需要重新學習，切勿混用
- **牌型強弱順序**：短牌的 Flush > Full House 與 NLH 完全相反
- **Outs 計算**：短牌每張 out ≈ 3%，NLH 每張 out ≈ 2%（翻牌後計至轉牌）
- **起始牌評估**：小對子在短牌價值下降，同花連牌價值提升
- **C-bet 頻率**：短牌因翻牌後 draw 更多，C-bet 頻率應降低
- **全押頻率**：短牌 MTT 全押發生頻率遠高於 NLH MTT

### 建議學習順序（雙修玩家）
1. 先完全掌握 NLH MTT 的 ICM 概念
2. 再學習短牌的基礎規則（第一章全部）
3. 建立「短牌思維」——不要試圖把 NLH 邏輯硬套
4. 實際遊戲時完全切換模式，不要在短牌桌用 NLH 本能反應

## 短牌 MTT 快速複習卡

以下是最重要的知識點一覽，建議列印或截圖，坐上短牌桌前快速確認：

### 牌型順序（由強到弱）
```
1. 皇家同花順  Royal Flush
2. 同花順      Straight Flush
3. 四條        Four of a Kind
4. 同花        Flush         ← 比葫蘆強！
5. 葫蘆        Full House
6. 三條        Three of a Kind ← 比順子強！
7. 順子        Straight
8. 兩對        Two Pair
9. 一對        One Pair
10. 高牌       High Card
```

### Outs 計算

| 聽牌 | Outs | 轉牌勝率 | 兩街勝率 |
|------|------|---------|---------|
| 同花聽牌 | 5 | 16% | 30% |
| 雙端順子 | 8 | 26% | 47% |
| Combo Draw | 10-12 | 32-39% | 55-65% |
| 內聽順子 | 4 | 13% | 25% |

### 最低順子
A-6-7-8-9（不是 A-2-3-4-5）

### 開牌 Size
通常 2.5-3.5x（比德州更大）

### C-bet 頻率
- 乾燥翻牌：50%
- 中等翻牌：35%
- 濕潤翻牌：25%

### MTT 各深度策略重點
| 深度 | 策略 |
|------|------|
| 100bb+ | 廣泛入局，追 Draw，隱含賠率高 |
| 30-100bb | 收緊，避免中間地帶 |
| 15-30bb | Push/Fold，範圍比 NLH 緊 |
| <15bb | 緊急模式，等強牌全押 |

### Bubble 策略
- 大疊：積極施壓中疊/短疊
- 中疊：謹慎，針對短疊
- 短疊：選擇保守等或積極搏翻身

## 版本說明

本教材基於 **Triton Poker 規則**（最廣泛採用的線上標準）：
- Three of a Kind > Straight（Set 優於 Straight）
- Flush > Full House

部分現場賽事可能使用不同規則（如 Straight > Three of a Kind），
參賽前務必確認主辦方的規則版本。
