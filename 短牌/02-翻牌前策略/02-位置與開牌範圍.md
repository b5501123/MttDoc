## 一、位置在短牌 MTT 中的重要性

短牌中位置的重要性比德州撲克更高，原因如下：

1. **翻牌後更多動作**：幾乎每手牌翻牌後都有 Draw，擁有後位讓你更容易控制底池
2. **更高的對局頻率**：更多 Draw 意味著更多翻牌後行動，後位信息優勢更大
3. **BTN Ante 影響**：BTN 支付底注，形成特殊的籌碼結構

---

## 二、BTN Ante 結構的深層影響

### 2.1 誰付什麼

```
9-max BTN Ante 結構（100/100 盲注）：
座位 1（BTN）：支付 Ante = 100
座位 2（SB）：支付 SB = 100
座位 3（BB）：支付 BB = 100
座位 4-9（UTG 至 CO）：不需付任何費用
```

初始底池：300（Ante + SB + BB）

### 2.2 對 VPIP 成本的影響

```
各位置的入局成本：
UTG：入局成本 = 開牌加注（例如 250 或 3x）
→ 底池 300，跟注/加注到 250？不對，應該更精確：

如果 BTN 開牌到 300（3x BB）：
UTG 跟注：300（入局成本 300）
如果 UTG 開牌到 300：
後位跟注：300
BTN 跟注：300（但 BTN 已付了 100 Ante，實際追加 200）
SB 跟注：300（已付 SB 100，追加 200）
BB 跟注：300（已付 BB 100，追加 200）
```

**BTN 的 Ante 讓 BTN 有「投資感」**，但位置優勢讓 BTN 仍然是最有利的位置。

### 2.3 開牌 Size 建議

短牌通常使用比德州**更大的開牌 Size**：

| 情境 | 德州通常 Size | 短牌通常 Size | 原因 |
|------|------------|------------|------|
| BTN 開牌 | 2.2-2.5x | 2.5-3x | 更大底池，更多動作 |
| CO 開牌 | 2.2-2.5x | 3x | 同上 |
| UTG 開牌 | 2.5-3x | 3-3.5x | 更大 size 減少多人底池 |
| SB vs BB | 2.5x | 3-4x | SB 位置劣勢，需要更大 size |

**為什麼短牌用更大 Size？**
1. 翻牌後 Draw 更多，更大的 pot odds 才能有效篩選對手
2. 底池本身就更大（BTN Ante），相對 Size 更合理
3. 更多 Draw 的環境中，給對手免費 Draw 的代價更高

## 三、9-max 各位置詳細開牌範圍

以下範圍適用於深疊（100bb+）情況，MTT 中疊/短疊需要調整。

### 3.1 UTG（Under the Gun）

**UTG 是 9 人桌中最早行動的位置，應使用最緊的範圍。**

```
UTG 建議開牌範圍（≈ 12-15%）：

超強對子：AA KK QQ JJ TT（5 種，20 個組合）
高牌同花：AKs AQs AJs ATs（4 種，16 個組合）
中等對子：99 88（視讀牌風格，可保守）
強同花連牌：KQs JTs（可選）

典型 UTG 範圍：
AA KK QQ JJ TT 99 88
AKs AKo AQs AJs ATs
KQs JTs

約 15-18% VPIP
```

**UTG 的思考邏輯**：
- 後面有 8 個玩家，被 3-bet 的機率很高
- 持有的牌必須在被 3-bet 後也能舒適決策
- 短牌環境讓 bluff 3-bet 更少，UTG 開牌時被 3-bet 通常代表強牌

### 3.2 UTG+1

```
UTG+1 範圍（≈ 15-18%）：比 UTG 稍寬

新增手牌：
- 77 66（小對子，但謹慎）
- KJs KTs（K 高同花）
- QJs（Q 高同花連牌）
- 9Ts 89s（中等同花連牌）
- AQo（A 高不同花）
```

### 3.3 UTG+2 / Lojack

```
UTG+2/LJ 範圍（≈ 18-22%）：

新增手牌（在 UTG+1 基礎上）：
- 77（口袋 7，位置稍好可用）
- KQo（K Q 不同花，後位開始可用）
- 78s 67s（低端同花連牌）
- QTs（Q T 同花）
- AJo（後位才用）
```

### 3.4 HJ（Hijack，莊家右邊第三位）

```
HJ 範圍（≈ 22-26%）：

新增手牌：
- 66（邊緣小對子）
- JTo QJo（不同花中等連牌，開始有用）
- K9s Q9s（高牌+9 同花）
- T9s 68s（低端同花連牌）
- KJo（K J 不同花）
```

### 3.5 CO（Cutoff，莊家右邊第二位）

```
CO 範圍（≈ 28-35%）：

CO 是次佳位置，範圍顯著擴大：

新增手牌：
- ATo A9s（A 高同花）
- K8s K7s（K 高低點同花）
- Q8s Q7s（Q 高低點同花）
- J8s J7s（J 高低點同花）
- T7s T8s（T 高低點同花）
- 更多不同花連牌：KTo, QTo, J9o
```

**CO 的特殊考量**：
- BTN 還在後面，CO 開牌後 BTN 可能偷底池（steal）
- 需要平衡：夠寬以獲取價值，夠緊以避免 BTN 利用

### 3.6 BTN（Button，莊家位）

```
BTN 是最佳位置，範圍最寬（≈ 45-55%）

BTN 已付 Ante，有「成本感」，但位置優勢是全桌最大的

典型 BTN 開牌範圍：
所有 A 級、B 級、C 級牌，加上：
- 所有同花牌（A-高、K-高、Q-高 + 任何點數）
- 所有同花連牌（包括 56s、67s 等短牌可用的）
- 不同花的中等牌（KTo, QTo, JTo 等）
- 部分 one-gap 同花牌（A8s, K9s, Q9s 等）

BTN 需要偷 SB/BB 的盲注，所以範圍要夠寬
```

### 3.7 SB（小盲）

SB 是最棘手的位置，因為：
1. 翻牌前只剩 BB 一個對手
2. 翻牌後 SB 永遠是第一個行動（位置劣勢）

```
SB vs BB 的特殊動態：

SB 對 BB 的開牌範圍（直接加注，不跟注）：
≈ 50-60%（比 BTN 更寬，因為只有一個對手）

SB 開牌 Size：通常比其他位置更大（3-4x），
因為位置劣勢需要用 Size 補償

SB 要避免的錯誤：
1. 用小 Size 開牌（讓 BB 輕鬆跟注）
2. 在 BB 3-bet 後跟注太鬆（位置不好）
3. 跟注而不是加注（給 BB 免費位置優勢）
```

### 3.8 BB（大盲）

BB 是唯一能以折扣跟注的位置：

```
BB vs 各位置開牌者的跟注範圍：

vs BTN 開牌（最鬆對手）：≈ 55-65% 跟注
vs CO 開牌：≈ 45-55% 跟注
vs UTG 開牌（最緊對手）：≈ 30-40% 跟注

BB 跟注邏輯：
已付 BB，折扣跟注所需勝率更低
但翻牌後無位置，需要更強手牌或更好的 Draw 潛力
```

## 四、位置對決（Position vs Position）策略

### 4.1 BTN vs Blinds

```
BTN 開牌，SB/BB 3-bet：
- BTN 跟注範圍：ATs+, KQs, JTs, TJs, 88+, 以及一些同花連牌
- BTN 4-bet 範圍：AA, KK, QQ, AKs（Value），偶爾 Bluff（AJs 等）

BTN 跟注 3-bet 的思考：
- 有位置優勢，可以跟注比較寬
- 但對手 3-bet range 通常較強
- 同花連牌的隱含賠率在 BTN 位置更高
```

### 4.2 CO vs BTN

```
CO 開牌，BTN 3-bet（最常見的位置戰）：
CO 面對 BTN 3-bet 的選擇：
1. 跟注：持有中等強牌但不夠 4-bet 的手牌（如 JTs, TT, 99）
2. 4-bet：持有超強牌（AA, KK, AKs）
3. 棄牌：大多數 CO 開牌範圍的手牌
```

### 4.3 3-bet 線性 vs 極化範圍

在短牌 MTT 中，**3-bet 範圍通常比德州更線性**（更少 Bluff）：

原因：
1. 翻牌後 Draw 很多，對手不會輕易放棄
2. 純 Bluff 3-bet 風險更高
3. ICM 壓力讓玩家更謹慎

```
線性 3-bet（以強牌為主）：
AA, KK, QQ, JJ, AKs, AQs, KQs

適當加入的半bluff 3-bet：
AJs（有 Flush 潛力）
JTs（有 Combo Draw 潛力）
TJs（同上）
```

```

不同花：AKo AQo AJo ATo KQo KJo KTo QJo QTo JTo
特殊：同花 A6s, K6s, Q6s, J6s 等（最低端同花）
```

## 六、開牌後的延續策略

### 6.1 面對跟注（Flat Call）

當你開牌後有人跟注（而不是 3-bet）：

```
典型情況：你 UTG 開牌，BTN 跟注，BB 也跟注（3 人底池）

注意：多人底池在短牌中比德州更常見（更多玩家有足夠的入局理由）

策略調整：
1. 強牌（AA-TT）：翻牌後仍然主動下注
2. 同花連牌（JTs 等）：在多人底池中更有隱含賠率，更值得入局
3. 不同花手牌：在多人底池中價值降低，需要更謹慎
```

### 6.2 面對 3-bet

```
你開牌後面對 3-bet 的決策框架：

強牌（AA, KK, AKs）：4-bet 或跟注
中等強牌（QQ, JJ, AQs）：跟注（有位置時），或棄牌（無位置）
偷底池牌（寬範圍開牌時的 bluff 手牌）：棄牌
同花連牌（JTs）：有位置時跟注，無位置時棄牌（ICM 考量）
```

## 七、MTT 特殊調整

### 7.1 大盲深度調整

深疊（200bb+）：範圍更寬，同花連牌更有價值
中疊（50-100bb）：標準範圍
短疊（20-50bb）：收緊，聚焦 Premium
極短疊（<20bb）：Push/Fold 邏輯

### 7.2 Ante 的影響

在有 Ante 的 MTT 中，底池更大，這讓：
1. 偷底池（Steal）的動作更有利
2. 開牌的相對大小更小（底池更大，2.5x 開牌只是底池的一部分）
3. 後期位置開牌應更積極

---

## 本章重點摘要

1. **BTN 是最佳位置**，已付 Ante 但仍可以用最廣泛的範圍開牌
2. **UTG 最緊**：只用超強牌，因為後面有 8 個玩家
3. **SB 要用大 Size**：補償位置劣勢（3-4x 開牌）
4. **短牌 Size 比德州大**：通常 2.5-3.5x，因為翻牌後 Draw 更多
5. **同花連牌在後位更有價值**：隱含賠率高，翻牌後主動性強
