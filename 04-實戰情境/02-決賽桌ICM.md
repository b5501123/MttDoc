# 決賽桌（Final Table）ICM 策略

## Final Table 的特殊性

Final Table 和一般 MTT 的最大差異：

1. **每個名次差距極大**：1st 和 2nd 可能差 2 倍獎金
2. **ICM 永遠在場**：每一手都要考慮獎金影響
3. **玩家結構固定**：你清楚地知道每個人的 stack
4. **心理壓力最大**：每個人都想拿更好的名次

---

## ICM 計算基礎（FT 版本）

### 簡化版 ICM 公式

每個玩家的 ICM equity ≈ 各名次獎金 × 拿到該名次的機率

**機率估算（簡化）：**
- 贏得 1st 的機率 ≈ 你的籌碼 ÷ 全桌籌碼
- 2nd 的機率 ≈ 你贏 2nd 的模擬機率（較複雜）

**關鍵感覺：**
籌碼越多，邊際 ICM 價值越低。
從 0 到 min cash 的跳升 > 從 min cash 到 2nd 的跳升。

---

## FT 各人數的策略調整

### 10人 FT（剛開始）

**類似 Bubble 的感覺**

策略：
- 比正常更保守（每出局一人都有獎金跳升）
- 尤其注意 bubble 邊緣的玩家
- 短疊出局 = 你的 ICM equity 自動提升

打法重點：
- 讓短疊自己出局，不要主動找麻煩
- 針對中疊的弱點（他們 ICM 壓力大）
- 大疊之間的大底池謹慎

---

### 6人剩餘

**玩家多數已適應，打法趨於正常化**

策略：
- ICM 壓力比 10人時低一些
- 可以更積極打
- 仍然注意每個位置的獎金差距

---

### 4人剩餘（Bubble of Bubble）

**再出局一人（3人）可能有大額獎金跳升**

例：
```
4th: $5,000
3rd: $8,000（+$3,000）
2nd: $15,000（+$7,000）
1st: $30,000（+$15,000）
```

4th 到 3rd 的跳升相對小 → ICM 壓力比 Bubble 時低
但 3rd 到 2nd 的跳升很大 → 進 2 名 = 重要目標

---

### 3人剩餘

**ICM 最複雜的點**

3人的 ICM 計算：
```
如果你有 50% 的籌碼：
- 贏 1st 機率 ≈ 50%
- 但 2nd/3rd 機率的計算需要考慮另外兩人的對決結果
```

打法：
- 和短疊的對決更值得（ICM 獎勵更大）
- 避免和另一個大疊的無謂對決
- 保持積極但謹慎

---

### 2人剩餘（Heads-Up）

**ICM 幾乎消失，接近 Cash Game**

2人時：
- 籌碼代表勝率，不再有多名次跳升
- 打法回歸正常 NL 頭對頭策略
- 位置重要性恢復最高

---

## FT 的關鍵概念：ICM 自殺

**ICM 自殺** = 在 ICM 角度不值得的情況下冒全部籌碼的險。

**典型例子：**

```
FT 5人剩餘，獎金：
5th: $3,000
4th: $5,000
3rd: $8,000
2nd: $15,000
1st: $30,000

你：中等 stack，25bb
大疊（55bb）push all-in，你在 BB 有 TT

Chip EV 角度：跟注（你有 53% 勝率）是正 EV
ICM 角度：輸了你出局拿 $3,000，贏了你有 50bb

計算：
ICM EV（call）= 53% × (贏後 ICM equity) + 47% × $3,000
ICM EV（fold）= 保留現有 ICM equity（約 $8,500）

即使 TT 有 53% 勝率，fold 的 ICM EV 可能更高
```

**結論：高 ICM 壓力場景，即使有牌力優勢，有時候 fold 更好。**

---

## FT 的積極場景

不是所有 FT 場景都要保守。以下情況應該積極：

### 情況 1：你是 Chip Leader

你的籌碼比其他所有人加起來還多（或接近）：
- ICM 壓力最低
- 可以積極偷盲
- 每贏一手 = 提升冠軍機率

### 情況 2：短疊對決

兩個短疊在你旁邊互打：
- 你不在底池，直接 equity 提升
- 如果你能加入且有很強的牌 → 參與

### 情況 3：進錢位置已安全

你已經鎖定某個目標名次（例如確定能進 top 3）：
- ICM 壓力降低
- 可以更積極打以衝更高名次

---

## FT 實戰思路框架

**每手牌前問自己：**

```
1. 現在幾人剩？ → 確認 ICM 壓力等級
2. 我的 stack 相對排名？ → 大疊/中疊/短疊角色
3. 這手牌的風險有多大？ → all-in EV vs fold EV
4. 誰是 ICM 壓力最大的玩家？ → 欺負他
5. 有沒有獎金跳升在眼前？ → 縮緊等跳升
```

---

## 常見 FT 錯誤

### 錯誤 1：FT 打得像常規桌
「我有 60% 勝率，當然跟注」
→ FT 的 ICM 讓很多「+EV」的跟注實際上是 -EV

### 錯誤 2：短疊過度保守
「我要等到 FT 結束再 push」
→ 短疊等待 = 籌碼被盲注吃掉，越來越沒籌碼

### 錯誤 3：忽略 Stack 排名
打每一手牌的方式不考慮籌碼相對大小
→ 你是第二大疊還是第三小疊，打法完全不同

### 錯誤 4：Heads-Up 打得保守
「這是 FT，要謹慎」
→ Heads-Up 沒有 ICM，要積極打！
