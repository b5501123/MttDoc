# Bubble 打法：MTT 最賺錢的時刻

## 什麼是 Bubble

**Bubble** = 再出局 N 人就進錢的狀態。

最典型的：100人報名，最後18人進錢 → 19人剩餘時就是 bubble。

**為什麼 Bubble 是最賺錢的時刻？**
- 大部分玩家在 bubble 會過度保守
- 中疊寧可 fold 牌也不想 bubble out
- 大疊可以「免費」偷取大量底池

---

## Bubble 的四種角色

### 角色 1：Chip Leader / 大疊（>平均 2 倍）

**最強的位置。你主宰 bubble。**

策略：
- **積極偷盲**，尤其針對中疊
- Open range 比平時放寬 10-15%
- 可以對中疊輕易 3-bet bluff
- 只要注意短疊的 push（他們 ICM 壓力低，range 正常）

心態：
> Bubble 的中疊玩家會 fold 很多。
> 你每次 open 對他們來說都是威脅。
> 利用這個心理優勢。

**大疊 Bubble 行動清單：**
- [ ] 頻繁從 BTN/CO/SB 偷盲
- [ ] 對中疊的 open 做 3-bet（他們很難 call）
- [ ] 不要和其他大疊做不必要的大底池
- [ ] 不要輕易和短疊全壓（短疊不怕出局，range 正常）

---

### 角色 2：中疊（接近平均，但不到平均 1.5 倍）

**ICM 壓力最大的位置。最難打。**

策略：
- **縮緊所有 range**（push, open, call）
- 避免和大疊的大底池對決
- 等短疊出局，你自然進錢
- 積極針對其他中疊和短疊

心態：
> 現在出局 = $0
> 等一等就能進錢 = 有獎金
> 這個差距讓「保守」有很高的 EV

**中疊 Bubble 行動清單：**
- [ ] 縮緊 push range 15-20%
- [ ] 避免 call 大疊的 push/3-bet（ICM 代價太高）
- [ ] 仍然對其他中疊/短疊正常偷盲
- [ ] 如果大疊偷盲，fold 比反偷更安全

---

### 角色 3：短疊（<10bb）

**你沒什麼可輸的，打 Nash。**

策略：
- Push/fold 正常打，輕微縮緊即可
- 等待好機會 push
- 不要「等到 bubble 破掉」，你等不起

心態：
> 我已經很短了，再等盲注吃更多
> 現在 push 有 fold equity
> 等到 5bb 再 push，fold equity 幾乎沒了

**短疊 Bubble 行動清單：**
- [ ] 找到好機會 push
- [ ] 不要超過 Nash 的縮緊程度
- [ ] 如果有大疊在 BTN，你在 BB，準備好 call range

---

### 角色 4：短短疊（<5bb，岌岌可危）

**最極端的短疊，almost pot-committed。**

策略：
- 幾乎全部手牌都 push
- 優先選擇有機會被 fold 的位置
- 別等了，每個 orbit 都是損失

---

## Bubble 的特殊場景

### 場景 1：你是中疊，BB，大疊 BTN push

**最難的 Bubble 決策之一。**

```
情境：
- 你：中疊 30bb，在 BB
- 大疊 BTN：80bb，push all-in
- 還有一個短疊 12bb 在 SB（已 fold）
- Bubble（20人剩18人進錢）

分析：
- 大疊知道你 ICM 壓力大，push range 可能很寬（70%+）
- 你 call 輸 = 可能 bubble out（$0）
- 你 fold = 損失 BB，但仍有 30bb，可能 survive

Pot Odds（純數學）：
call 29bb，底池 61bb → 需要 48% 勝率

ICM 調整後：
即使有 52-55% 勝率，fold 可能更好！
因為 ICM 讓輸的代價遠大於贏的收益。

建議：只用 TT+, AQs+ 的 call range（約 5%）
```

### 場景 2：你是大疊，短疊在 BB

**你可以積極施壓。**

短疊在 BB 面對你的 push：
- 他 pot odds 很好（大部分要 call）
- 但他也可能 fold 邊緣牌

**你的策略：**
Push 比平時更寬，因為：
1. 短疊 ICM 壓力讓他 fold 比 Nash 更多
2. 即使被 call，短疊只有 10bb，你損失有限

---

### 場景 3：你是中疊 BB，另一個中疊 push

**最典型的 Bubble 困境。**

```
情境：
- 你：25bb，在 BB
- 另一個中疊 HJ：22bb，push

分析：
- 他從 HJ push，range 約 40%
- 你 call 需要約 44% 勝率（pot odds）
- 輸了你就出局或超短疊
- 贏了你有 47bb，安全進錢

ICM 計算通常顯示：
你需要的實際勝率比 pot odds 更高（約 55-60%）

建議 call range：JJ+, AKs, AKo（約 7%）
```

## Bubble 心理學

### 對手常見的 Bubble 錯誤

1. **中疊 fold 太多**：他們 fold AA preflop 都有可能（罕見但存在）
2. **過度等待**：明明 15bb 不 push，等到 7bb 才 push（fold equity 已消失）
3. **怕大疊**：即使有很好的手牌，面對大疊也 fold
4. **忘記攻擊其他中疊**：不敢攻擊，但其他中疊其實也怕你

### 如何利用這些錯誤

**如果你是大疊：**
- 向所有中疊頻繁偷盲，他們 fold 頻率遠高於正常
- 不需要好牌，位置和 stack 優勢已經足夠

**如果你是中疊：**
- 找到另一個保守的中疊，對他偷盲
- 不要被大疊嚇死，但也不要輕易 call

## Bubble 決策速查表

| 你的 Stack | 面對大疊 push | 面對中疊 push | 面對短疊 push | 你自己 push |
|-----------|-------------|-------------|-------------|------------|
| 大疊 | 依牌力（放寬）| 放寬 call | 輕忽（短疊 range 正常）| 放寬 |
| 中疊 | 縮緊（TT+, AK）| 縮緊（JJ+, AKs）| 相對放寬 | 縮緊 15-20% |
| 短疊 | 正常 Nash | 正常 Nash | 正常 Nash | 正常 Nash |

## Bubble 結束後

**進錢的第一反應：很多人鬆一口氣，打得更鬆。**

**你的機會：**
- Bubble 破掉後，所有人都在慶祝
- 大家的 ICM 壓力暫時降低
- **繼續積極偷盲**，趁其他人還在開心時積累籌碼
