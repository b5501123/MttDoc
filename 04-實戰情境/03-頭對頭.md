# 頭對頭（Heads-Up）策略

## Heads-Up 的本質

Heads-Up = ICM 消失，回到純 Chip EV 競賽。

只有兩個名次，籌碼代表勝率：
- 你有 70% 籌碼 → 大約 70% 機率贏 1st
- 沒有中間名次的 ICM 考量

**打法回歸：積極、位置、讀牌。**

---

## HU 的基本調整

### Range 大幅放寬

HU 中，每人只需要擊敗一個對手。

```
HU BTN（SB）open range：~70-80%
HU BB defend range：~70-75%

相比 6-max 的 BTN（45-55%）和 BB（35-45%），大幅放寬
```

### 手牌強度重新評估

**HU 中的強牌：**
- A high：非常強（比 6-max 強很多）
- K high：算中等強牌
- 小對子（22-55）：相當強
- 任何 pair：強牌

**原因：** HU 中對手的隨機手牌平均強度比 6-max 弱很多。
A7o 在 6-max UTG 是 fold，HU 是強牌。

---

## HU 翻牌前策略

### BTN（SB）的策略

HU 中 BTN = 翻牌前最後行動 + 翻牌後 IP

```
Limp or Raise?

現代 HU 打法：混合 limp 和 raise
- Limp：用部分強牌和部分弱牌 limp，製造平衡
- Min-raise（2bb）：最常見，建底池且控制 SPR
- Large raise（2.5-3bb）：針對特定對手調整
```

**Min-raise 的優點：**
小 open size → 底池小 → 更多後手靈活性
BB 的 pot odds 更好（讓他 call 更寬）→ 你的強牌賺更多

**Limp 的戰略價值：**
- 讓對手無法讀出你的 range
- 可以 limp-raise 陷阱強牌
- 免費看翻牌，降低費用

### BB 的策略

HU 中 BB 翻牌前最後行動：
- 有機會 check（如果對手 limp）或 raise（3-bet）
- 可以 check 進入翻牌

**面對 BTN min-raise：**
BB call pot odds 非常好：
```
面對 2bb raise，BB 需投入 1bb，底池 3bb
所需勝率：1/3 = 33%
```
幾乎所有有邊際價值的牌都值得 call。

---

## HU 翻牌後策略

### 位置的超高價值

HU 翻牌後 IP = 幾乎所有 bluff 都有效

```
你在 IP：
- 對手 check → 你可以 bet 或 check back
- 對手 bet → 你可以 call, raise, 或 fold
- 你有完整的資訊後行動
```

```
你在 OOP：
- 你先行動，對手有後手優勢
- Check-raise 是你的主要武器
- Range advantage 有時可以補償 position 劣勢
```

### C-bet（持續下注）頻率

HU 的 c-bet 頻率比 6-max 更高：
- BTN IP c-bet：約 55-65%（比 6-max 高）
- SB OOP c-bet：約 45-55%（選擇性）

原因：HU 中對手 miss flop 的機率更高（只有一個人 defend）

## HU 心理戰

### 節奏控制

HU 是心理對決。控制節奏很重要：

```
打快 vs 打慢：
- 打快：讓對手沒時間思考，增加他犯錯的機率
- 打慢：強調某些決策的重要性，製造壓力
```

### 調整對手

**對手 fold 太多（Nit）：**
- 頻繁小尺寸 bet 拿底池
- 增加 bluff 頻率
- Open range 最寬

**對手 call 太多（Station）：**
- 增加 value bet，減少 bluff
- 用強牌建大底池
- 不做三條街 bluff

**對手 3-bet 太頻繁（Aggressive）：**
- Limp-call 或 limp-raise 更多強牌
- 擴大 4-bet 範圍
- 不讓他輕易偷走底池

## HU Push/Fold（短疊 HU）

當任何一方進入短疊狀態，切換 push/fold 模式。

### HU Nash Push Range（BTN/SB）

```
20bb：約 55-60%（包含大部分手牌）
15bb：約 65-70%
10bb：約 78-82%
7bb：約 87%+
5bb：幾乎全部
```

### HU Nash Call Range（BB）

```
面對 10bb push：
約 45-50%

所有對子 + 大部分 Ax + 大部分 Kx + 大部分連牌
```

**HU 的 Call Range 比 6-max 寬很多**，因為：
- 對手 push range 很寬
- Pot odds 需要的勝率較低
- 沒有 ICM 壓力

---

## HU 速查重點

```
翻牌前：
- Open 70-80%，幾乎全部有邊際價值的牌
- 小 open size（2bb）
- Limp-raise 陷阱強牌（偶爾）

翻牌後 IP：
- C-bet 頻率高
- 積極 value bet 和 bluff
- 位置是最大優勢

翻牌後 OOP：
- Check-raise 是武器
- 不要 donk bet 太多
- 選擇性打，not every hand

短疊：
- Push/fold，range 比 6-max 寬很多
- 不要等到 3bb 才 push
```

## 心態：享受 HU

HU 是撲克最純粹的對決。
沒有 ICM，沒有多人動態，只有你和對手。

**最後建議：**
- 放鬆打，不要因為「快贏了」而緊張
- 每次失誤是學習機會
- HU 是可以練習和改善最快的領域
