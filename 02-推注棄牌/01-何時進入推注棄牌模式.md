# 何時進入 Push/Fold 模式

## 核心定義

**Push/Fold** = 只允許兩個動作：
- **Push**（All-in）
- **Fold**（棄牌）

不再有 open-raise、call、3bet 等複雜動作。

---

## 為什麼短疊要用 Push/Fold

### 原因 1：Fold Equity 是你最大的武器

當你 push all-in，對手必須面對「call = 冒險整個 stack」的壓力。
對手如果不確定，會選擇 fold → 你拿到盲注 = 積累籌碼。

當你只 open 2bb，對手面對的風險很小，call range 更寬 → 你失去 fold equity。

**短疊 open 2bb 的問題：**
```
你：10bb，open 2bb
對手 3bet：4-5bb
你：被迫 all-in 或 fold（等於浪費了 2bb）
```
Open 小尺寸 + 被 3bet 後 push = 損失了 2bb + 損失了主動權
直接 push 10bb = 對手需要考慮 call 10bb，fold equity 更大

### 原因 2：數學支持

Open 2bb 然後被 3bet fold = 損失 2bb
Open-shove 10bb 被 fold = 贏 1.5bb（盲注）
Open-shove 10bb 被 call 且輸 = 輸 10bb

但 open-shove 的 **fold equity** 讓你在被 fold 時獲利，平均結果更好。

---

## Push/Fold 的臨界點

**理論臨界點：15bb**

但實際上更靈活：

| Stack | 建議 |
|-------|------|
| 20bb+ | 可以 open 小（2-2.5bb），但要有 3bet 計劃 |
| 15-20bb | 視位置：BTN/CO 可 open，UTG/HJ 考慮 shove |
| 10-15bb | 大多數位置直接 shove |
| <10bb | 純 push/fold，無例外 |

**判斷標準：**
> 如果你 open 後被 3bet，你會不知道該怎麼辦 → 直接 shove 更好

---

## Open-Shove vs Open-Small 的選擇

### 什麼時候 Open-Shove 更好（≤15bb）

1. **UTG 短疊**：open 後面有很多人，被 squeeze 的機率高
2. **有鬆散玩家**：他們會用寬 range call → 你的 open 會被輕易 call → shove 反而讓他們更難決策
3. **Bubble 或 FT**：對手 ICM 壓力大，fold equity 更高

### 什麼時候 Open-Small 更好（15-20bb）

1. **BTN/CO 位置**：偷盲成功率高，open 小贏更多（被 fold 時損失少）
2. **對手是 Nit**：他們不會輕易 3bet，open 小的期望值更高
3. **進 money 後 ICM 壓力降低**：可以多一些靈活性

---

## Push/Fold 模式的 3 種場景

### 場景 1：你第一個行動（unopened pot）
標準 push/fold：根據位置和手牌決定是否 push。

### 場景 2：有人已經 open，輪到你
這時候叫做 **Reshove**（反推）：
- 評估 open 者的 range
- 用 ICM/Nash 計算你的 reshove range
- 通常比 unopened push 更窄（因為對手已經表示有牌力）

### 場景 3：在 BB，有人 push，你要決定 call/fold
這叫 **BB Defense**：
- 計算 pot odds
- 對比對手的 push range
- 需要的勝率 = 你的 call 金額 ÷ call 後底池

---

## Pot Odds 快速計算（BB Call 用）

公式：
```
所需勝率 = Call 金額 ÷ (Call 後底池)
```

範例：
```
你在 BB（1bb），對手從 BTN push 8bb
SB 已 fold，你需要 call 7bb（已有 1bb）
底池 = 8 + 0.5（SB）+ 1（BB）= 9.5bb，call 後 = 16.5bb

所需勝率 = 7 ÷ 16.5 = 42%
```

如果你的手牌對抗對手的 push range 有超過 42% 勝率 → call 是正確的。

---

## 實戰判斷流程

```
1. 確認我幾 bb？
   ↓
2. 小於 15bb → 進入 push/fold 模式
   ↓
3. 確認 pot 狀態（unopened / 有人 open）
   ↓
4. 查對應位置的 push range 圖表
   ↓
5. 我的手牌在 range 內 → push
   我的手牌在 range 外 → fold
```
