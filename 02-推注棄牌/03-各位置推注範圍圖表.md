# 各位置 Push Range 圖表

## 閱讀說明

### 手牌表記方式
- `AKs` = AK 同花（suited）
- `AKo` = AK 非同花（offsuit）
- `AK+` = AK 以上（包含 AA, KK, AK）
- `TT+` = TT 以上的對子（TT, JJ, QQ, KK, AA）

### 圖表使用方式
- **綠色 = Push**：這手牌應該 all-in
- **空白 = Fold**：這手牌應該棄牌
- 表中左上角 = 最強同花（`AA`），沿對角線往右下 = 非同花版本

## BB Call Range（面對 push）

BB call range 取決於：
1. Push 者的位置（決定對手 push range 的寬度）
2. 你需要的 pot odds

### 面對 BTN Push（BTN push range 最寬）

**10bb BTN push，你在 BB：**
```
需要勝率 ≈ 38%（標準計算）

Call range 約 40%：
- 所有對子（22+）
- A2s+, A7o+
- K9s+, KJo+
- Q9s+, QJo+
- JTs
- 等等...
```

### 面對 UTG Push（UTG push range 最緊）

**10bb UTG push，你在 BB：**
```
UTG push range 只有 ~37%，更多強牌 → 你需要更強的牌才能 call

Call range 約 20%：
- TT+（對子）
- AJs+, AQo+
- KQs
```

**關鍵原則：** 對手 push range 越寬 → 你可以 call 更寬

## 快速記憶法

### BB 到 BTN 的寬度記憶（10bb）

```
UTG  → 37% push → BB call 用 20%
HJ   → 45% push → BB call 用 25%
CO   → 55% push → BB call 用 30%
BTN  → 67% push → BB call 用 40%
SB   → 70% push → BB call 用 43%
```

### Push Range 的 "感覺"

```
20bb BTN：強牌 + 中等牌
15bb BTN：大部分有價值的手牌
10bb BTN：幾乎 2/3 的手牌
7bb BTN： 接近 4/5 的手牌
5bb BTN： 幾乎全部
```

## ICM 調整（Bubble / Final Table）

**縮緊 Push Range（Bubble）：**
- 中疊：push range 縮緊 ~15-20%（例如 10bb BTN 從 67% → 50%）
- 大疊：push range 放寬 ~10%（大疊不怕輸）
- 短疊：push range 幾乎不變（反正快出局）

**Bubble 縮緊的原則：**
- 去掉最弱的 bluff push（76o, 85o 等）
- 保留 value push（AX, 對子）
- 保留 semi-bluff（A2s-A4s）
