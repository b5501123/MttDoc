# 深疊翻牌後場景分析（9-max）

所有場景均以 9-max 標準 MTT 深疊（60bb+）為基準，線上環境，**預設 Big Blind Ante（BBA）格式**。

## BBA 前提說明

現代線上 MTT 使用 BBA（Big Blind Ante）：
- BB 除付大盲外，額外付 1bb 作為 ante
- 翻牌前底池（heads-up 或多人）均比傳統無 ante 大
- **BBA 翻牌前底池計算：SB + BB + BB ante**
- SPR 計算和下注尺度必須基於 BBA 底池

**BBA 底池計算範例（100bb 深疊，盲注 100/200）：**
```
翻牌前底池（BBA，SB/BB 對決）：
  SB 100 + BB 200 + BB ante 200 = 500 chips

翻牌前底池（BTN open，BB call，無 SB）：
  BB 200 + BTN raise + BB call = 視開注尺寸而定
```

## 場景 1：BTN vs BB，乾燥高牌翻牌的 C-bet 決策（BBA）

**設定：**
- 9-max，BBA 格式，100bb 深疊
- BTN open 2.5bb，BB call（SB fold），其他人 fold
- **BBA 翻牌前底池：** BB 2.5bb + BTN 2.5bb + SB 0.5bb = 5.5bb
  - 注意：BBA 的 ante 已包含在 BB 的 2.5bb call 中（BB 投入 1bb 大盲 + 1bb ante，再補 1.5bb = 2.5bb）
  - 實際翻牌底池：BTN 2.5 + BB 2.5 + SB 0.5 = **5.5bb**
- 翻牌：A♠ 7♦ 2♣（乾燥 rainbow）
- BB check

**SPR 計算（BBA）：**
```
翻牌底池 = 5.5bb
有效籌碼 = 100 - 2.5 = 97.5bb
SPR = 97.5 ÷ 5.5 = 17.7
```

**手牌：** BTN 持有 K♦ Q♦（KQo）

**分析：**

翻牌 A-7-2 rainbow，BTN 對 BB 有 range advantage：
- BTN range 包含大量 Ax（AK, AQ, AJ, AT, A9s...）
- BB range 也有 Ax，但 BB defend 較多小牌對（22, 33）和 A5s-A2s

BTN 的 KQ 是無成牌手牌（未配對），但在乾燥 A-high 翻牌上：
- BB 的成牌 range 有限（A-7-2，BB 有些 77/22，也有 Ax）
- BTN 的 range advantage 很高（所有 BTN 的 Ax 都在這裡有價值）

**決策：C-bet（小尺寸）**

理由：
1. Range advantage：BTN 的 range 在 A-high 翻牌更強
2. Dry board：對手難以 slow play 強牌（22 有底pair，77 有中 pair，但 range 很少）
3. KQ 有後手（轉牌 K 或 Q 可能成牌）
4. 小尺寸 c-bet（25-33% 底池）效率最高：對 BB 的大量弱牌（mid pair, low pair）施壓

**行動（BBA 底池）：** Bet 1.8bb（底池 5.5bb 的 33%）

```
下注金額 = 5.5 × 33% ≈ 1.8bb
（傳統無 ante 底池約 5bb，小 bet 約 1.5bb；BBA 底池讓下注略大）
```

**後手計劃：**
- BB fold → 直接贏得底池 5.5bb ✓
- BB call → 轉牌是 blank，仍可再 bet（barrel）；K 或 Q 落，有成牌
- BB raise → Fold（KQ 在這個翻牌無法繼續面對 raise）

## 場景 2：UTG vs CO，Wet Board 上的 Range 分析（BBA）

**設定：**
- 9-max，BBA 格式，80bb 深疊
- UTG open 2.5bb，CO call，其他人 fold
- **BBA 翻牌前底池（heads-up，無 SB/BB）：**
  UTG 2.5bb + CO 2.5bb + BB 1bb（折疊但 ante 留底）+ SB 0.5bb（折疊）= 6.5bb
  更精確計算（BBA 格式）：SB 0.5 + BB 1 + BB ante 1 + UTG raise 2.5 + CO call 2.5 = **7.5bb**
- 翻牌：9♠ 8♦ 7♠（高度連接，有 spade flush draw）
- UTG 先行動

**SPR 計算（BBA）：**
```
翻牌底池 = 7.5bb
有效籌碼 = 80 - 2.5 = 77.5bb
SPR = 77.5 ÷ 7.5 = 10.3
```

**手牌：** UTG 持有 A♠ K♠（AK suited spades）

**分析：**

翻牌 9-8-7，是 CO 有 range advantage 的翻牌（CO range 有更多中等連牌，UTG 的 range 相對缺少 67、78、89 等）。

但你持有 A♠K♠：
- Nut flush draw（需要一張 spade 成 nut flush）
- 兩張 overcards（A 和 K 可以成 top pair）
- 後門 Broadway straight 可能性

這是強 semi-bluff 手牌。

**決策選項分析：**

選項 A：Check
- 讓 CO 下注，你 check-raise semi-bluff
- 優點：更大底池，CO 可能 bluff 讓你有機會 raise
- 缺點：CO 可能 check back（免費看牌），你損失了 fold equity

選項 B：C-bet
- 主動代表強牌（UTG range 在 9-8-7 上有 TT-QQ 等 overpair）
- 有 fold equity，同時 AKs 有很強的後手

**決策：C-bet（中等尺寸）**

Bet 3.75bb（底池 7.5bb 的 50%）。

```
BBA 底池 7.5bb × 50% = 3.75bb
（傳統無 ante 底池約 6bb，50% = 3bb；BBA 底池讓下注略大，對 CO 的 draw 施壓更有效）
```

理由：
- UTG c-bet on 9-8-7 代表 over pair（TT+）或 set（99, 88）
- AKs 的 equity 很強（約 44% vs CO 的 range），半詐牌合理
- BBA 底池更大，c-bet 金額更大，CO 的 draw 繼續需要付出更多
- 如果 CO raise，你有 nut flush draw + overcards，可以考慮 call 或 re-raise

## 場景 3：BB vs BTN，Check-Raise Semi-Bluff（BBA）

**設定：**
- 9-max，BBA 格式，90bb 深疊
- BTN open 2.5bb，BB call
- **BBA 翻牌前底池：** SB 0.5 + BB 1 + BB ante 1 + BTN 2.5 + BB call = 7.5bb（含 SB fold 留底的 0.5）
  精確：BTN 2.5 + BB 2.5（含 ante 已計）+ SB 0.5（fold 留底）= **5.5bb**（heads-up，SB fold）
  注意：BB 在 BBA 格式下，call BTN 2.5bb 時已經支付了大盲 1bb + ante 1bb，實際補差 0.5bb
  **翻牌底池 = 5.5bb**
- 翻牌：J♦ T♣ 5♦（有 diamond flush draw）
- BB check，BTN bet 1.8bb（底池 5.5bb 的 33%）

**SPR 計算（BBA）：**
```
翻牌底池 = 5.5bb
有效籌碼 = 90 - 2.5 = 87.5bb
SPR = 87.5 ÷ 5.5 = 15.9
```

**手牌：** BB 持有 8♦ 9♦（flush draw + OESD）

**分析：**

你有 8♦9♦ on J-T-5 with diamond draw：
- 直接 flush draw（需要 diamond 完成）
- Open-ended straight draw（7 或 Q 完成 straight）
- 估計 equity vs BTN range：約 52-58%（有大量 outs）

這是教科書的 semi-bluff check-raise 機會。

**為什麼 Check-Raise：**
1. 你的 hand 有足夠 equity（即使被 call，有很高機會成牌）
2. 你在 BB（OOP），CR 是主動武器
3. 翻牌 J-T-5 配合你有廣泛的 semi-bluff range（你的 BB defend 有大量 suited 手牌）
4. 讓 BTN 的弱 c-bet（用 air 和弱牌 c-bet）付出代價

**決策：Check-Raise（BBA 底池計算）**

BTN bet 1.8bb（底池 5.5bb 的 33%），CR 到約 12-13bb。

```
CR 計算：
  底池（含 BTN bet）= 5.5 + 1.8 = 7.3bb
  CR to 3x BTN bet = 1.8 × 3 = 5.4bb，再加底池部分
  標準 CR = 約 12bb（底池 7.3bb 的 160%）
  BBA 底池比傳統（約 5bb）大，CR 金額也相應更大
```

**後手計劃：**
- BTN fold → 直接贏 ✓（best case，贏 7.3bb 底池）
- BTN call → 轉牌打出 draw，繼續 bet；沒打出，可能放棄
- BTN 4-bet → 已有足夠 equity，call 或 fold 視情況（面對 4-bet 你仍有 50%+ equity，可以 call）

## 場景 4：CO vs BB，三條街價值線路（BBA）

**設定：**
- 9-max，BBA 格式，70bb 深疊
- CO open 2.5bb，BB call（SB fold）
- **BBA 翻牌前底池：** SB 0.5（fold）+ BB 2.5（含 ante）+ CO 2.5 = **5.5bb**
- 翻牌：K♥ T♦ 4♣
- BB check

**SPR 計算（BBA）：**
```
翻牌底池 = 5.5bb
有效籌碼 = 70 - 2.5 = 67.5bb
SPR = 67.5 ÷ 5.5 = 12.3
```

**手牌：** CO 持有 K♠ T♠（KTs，兩對）

**分析：**

翻牌 K-T-4 rainbow，你成了 top two pair（KT）。

這是很強的手牌，但：
- BB range 有 44（三條），少量 KK/TT（也三條），但你佔有大量 value combo
- 翻牌乾燥，draw 少，不需要太大尺寸
- 你需要建立底池（想被 call）

**三條街策略（BBA 底池）：**

翻牌（底池 5.5bb）：
```
Bet = 5.5 × 45% ≈ 2.5bb
選 45%：不讓 BB 太貴 fold，想讓他繼續
（傳統底池約 5bb，45% = 2.25bb；BBA 底池稍大，下注稍多）
```

轉牌（假設 7♣，完全 blank，底池 = 5.5 + 2.5 + 2.5 = 10.5bb）：
```
BB check，CO bet = 10.5 × 55% ≈ 5.75bb
繼續 value，代表我仍然有 K 的優勢
```

河牌（假設 2♠，完全 blank，底池 = 10.5 + 5.75 + 5.75 = 22bb）：
```
BB check，CO bet = 22 × 52% ≈ 11.5bb
三條街全 value，KT 在 K-T-4-7-2 上是非常強的手牌
```

**BBA 底池效應：**
```
BBA 翻牌底池（5.5bb）比傳統（5bb）大，三條街價值累積：
  翻牌 bet：2.5bb（BBA）vs 2.25bb（傳統）
  河牌底池累積到約 22bb（BBA）vs 約 20bb（傳統）
  三條街總收益多了約 2bb——BBA 的底池效應在深疊價值手牌中持續複利
```

**結論：** 三條街 value，每條街 bet 50% 附近，讓 BB 以 KJ、KQ、Tx 等手牌繳費。

**BB 應該怎麼做：**
BB 持有 KQ 應該 call 翻牌和轉牌，考慮 fold 河牌（三條街 aggression 代表很強的 range，KQ 的 kicker 很差）。

## 場景 5：多人底池，Overcards 的 Check/Fold（BBA）

**設定：**
- 9-max，BBA 格式，80bb 深疊
- UTG open 2.5bb，HJ call，CO call，BB call（4人底池）
- **BBA 翻牌前底池（4人進入，SB fold）：**
  SB 0.5（fold）+ BB 2.5（含 ante）+ UTG 2.5 + HJ 2.5 + CO 2.5 = **10.5bb**
- 翻牌：9♥ 6♠ 3♦
- BB check，UTG ??

**SPR 計算（BBA，多人）：**
```
翻牌底池 = 10.5bb
有效籌碼 ≈ 80 - 2.5 = 77.5bb
SPR = 77.5 ÷ 10.5 = 7.4
```

**手牌：** UTG 持有 A♣ Q♦（AQo）

**分析：**

多人底池（BBA 格式底池 10.5bb），翻牌 9-6-3，你沒有成牌（AQ 是兩張 overcard）。

在多人底池的這種翻牌：
- 有三個對手，c-bet 成功率很低（需要三個人都 fold）
- 9-6-3 對 UTG 的 range 沒有明顯優勢（很多連牌在後位 caller 的 range 內）
- AQ 的 equity 很弱（只有 A 或 Q 落才成牌，約 24% 機會）
- BBA 底池（10.5bb）比傳統底池大，c-bet 金額更大，失敗成本更高

**決策：Check**

在這個多人底池的低翻牌，check 是最優選擇：
- 免費看一張轉牌（A 或 Q 落 → 有強牌可繼續）
- 不浪費籌碼 c-bet 三個人（BBA 底池大，c-bet 需要投入更多，失敗更貴）
- 如果對手有人 bet，根據 bet size 決定 fold or call（基本上 fold，除非 bet 很小）

**如果轉牌是 A：**
- BB c-bet，你可以 call 或 raise（根據底池大小和對手特性）
- 這裡 AQ 成了頂對，仍然是好牌
- BBA 翻牌底池積累了 10.5bb，轉牌底池較大，A 落的 value 更高

**關鍵原則（BBA 環境）：** 多人底池不要習慣性 c-bet，特別是翻牌不利於你的位置和 range 時。BBA 使底池更大，每次 c-bet 的代價更高，這讓在多人底池中「不要胡亂 c-bet」的原則更加重要。

## 共同主題與學習要點（BBA 版本）

以上五個場景展現了幾個翻牌後的核心概念，全部在 BBA 環境下計算：

1. **BBA 底池是計算基礎：** 翻牌前底池比傳統大約 1-2bb，所有下注尺寸都應以 BBA 底池為基準
2. **SPR 要重新計算：** BBA 底池更大，SPR 略低，翻牌後承諾程度更高
3. **Range Advantage 決定 c-bet 頻率：** 乾燥高牌翻牌對 EP openers 有利 → 高頻 c-bet（下注金額因 BBA 稍大）
4. **Semi-bluff 的 equity 要求：** 只有足夠 equity 的半詐牌才值得 CR
5. **多人底池簡化：** 四人 BBA 底池（10.5bb+）不要機械 c-bet
6. **三條街一致性：** 強牌在 K-T-4 三條街都應該 bet，BBA 底池讓價值累積更多
7. **SPR 感知（BBA 調整）：** 每個決定前先確認 BBA 底池和 SPR，BBA 讓 SPR 略低，更容易 commit

**BBA 翻牌底池速查（100bb 深疊常見場景）：**

| 場景 | 翻牌底池（BBA）| 翻牌底池（傳統）| SPR（BBA）|
|------|------------|------------|---------|
| BTN open，BB call | 5.5bb | 5bb | 17.7 |
| EP open，MP call | 7.5bb | 6.5bb | 10.3 |
| 3人進入（含 SB）| 9bb | 7.5bb | 8.6 |
| 4人進入（BB call）| 10.5bb | 9bb | 7.4 |
