# 短疊推注場景分析（9-max）

所有場景均以 9-max 標準線上 MTT 為基準，**預設 Big Blind Ante（BBA）格式**。

## BBA 標準前提

現代線上 MTT 全面採用 Big Blind Ante（BBA）：
- BB 除了付大盲 1bb，還需額外支付 1bb 作為 ante
- 每圈翻牌前底池：SB（0.5bb）+ BB（1bb）+ BB ante（1bb）= **2.5bb**
- 例：盲注 100/200，翻牌前底池 = 50 + 200 + 200 = **450**（非傳統 450 而是含 BBA）
- BBA 讓每次偷盲的收益更大，push/fold 的 EV 也相應提升
- **所有 push/fold 計算均使用 BBA Nash 均衡數值**

---

## 範例 1：UTG 10bb，K9o — 邊緣手牌判斷

**場景：**
9-max MTT，中期，BBA 格式。你在 UTG，有效籌碼 10bb。所有人 fold 前你。手牌：K9o。

**底池背景（BBA）：**
```
翻牌前底池（未入局）= SB 0.5bb + BB 1bb + BB ante 1bb = 2.5bb
成功 push 後贏得 = 2.5bb（淨收益 = 2.5 - 0 = +2.5bb，因為你是未行動的）
```

**分析：**

UTG 10bb 的 BBA Nash push range ≈ 28%。

K9o 在整體手牌分佈中屬於大約前 30-32% 的強度。它在 UTG 10bb push range 的**邊緣**，略寬於 BBA Nash 標準。

更具體地說：
- UTG 10bb push 通常包含：A2o+, KTo+, QJo+, K8s+, Q9s+, J9s+, T8s+, 55+
- K9o 落在 KTo 的邊緣以下，在 BBA Nash 標準中通常是 fold

**BBA 的影響：**
BBA 使底池更大（2.5bb 而非傳統 1.5bb），偷盲的 EV 略微提升。但 UTG 有 7 個後位玩家，即使 BBA 提升了偷盲 EV，K9o 仍處於邊緣範圍。

**結論：fold**

補充說明：
- 線上低/中 stakes 可以稍微放寬（+3-5%），K9o 是極邊緣的 push
- 如果已知後面的 SB/BB 跟注頻率偏低，可以 push
- ICM 壓力下（接近 bubble），fold 傾向更強
- BBA 底池雖大，但 UTG 的位置劣勢無法被 BBA 補償

---

## 範例 2：BTN 10bb，T8s — 後位推注

**場景：**
9-max MTT，BBA 格式。你在 BTN，有效籌碼 10bb，手牌 T8s。前位所有人 fold。

**底池背景（BBA）：**
```
翻牌前底池（未入局）= SB 0.5bb + BB 1bb + BB ante 1bb = 2.5bb
成功 push 後淨贏 = +2.5bb
```

**分析：**

BTN 10bb BBA Nash push range ≈ 65%。T8s 約在前 48% 的手牌強度，遠寬於 65%。

等等——65% range 包含了前 65% 的手牌，T8s 在前 48%，**在 push range 內**。

驗證：BTN 10bb push range 包含：
- 22+, A2o+, K2s+, K7o+, Q4s+, Q9o+, J6s+, JTo, T6s+, T9o, 96s+, 98o, 86s+, 76s, 65s

T8s 確認在 range 內（T6s+ 包含 T8s）。

**BBA 的影響：**
BBA 使底池達到 2.5bb，比傳統（無 ante）的 1.5bb 大了 67%。BTN push 成功的 EV 因此顯著提升，進一步支持 push 決定。

**結論：push**

額外考量：
- T8s 有翻牌後的潛力（如果被 call）：flush draw 和 straight draw 機會
- 有 fold equity（SB/BB 需要很強的牌才 call 65% range 的 BTN push）
- BBA 讓 SB/BB 的 call range 計算也略微改變（底池更大，對他們來說 call 所需勝率略降）
- 這是清楚的 push，不需要猶豫

## 範例 3：HJ 12bb，AJo — 積極推注

**場景：**
9-max MTT，BBA 格式。你在 HJ，12bb。前位（UTG, UTG+1, UTG+2, LJ）全部 fold。手牌：AJo。

**底池背景（BBA）：**
```
翻牌前底池（未入局）= SB 0.5bb + BB 1bb + BB ante 1bb = 2.5bb
push 成功淨贏 = +2.5bb（比無 ante 環境多贏 1bb）
```

**分析：**

HJ 12bb BBA push range（Nash，BBA 環境）≈ 34-38%。AJo 屬於前 22% 的強牌，遠在 range 內。

HJ push 的考量：
- 還有 CO、BTN、SB、BB 在後面（四個人）
- 12bb push，對手的 call 需要約 40% 勝率（BBA 底池 odds 計算如下）
- AJo 是 HJ 的標準 push

**BBA call 所需勝率計算（BB 視角）：**
```
底池 = 12bb（push）+ 0.5bb（SB）+ 1bb（BB）+ 1bb（BB ante 已計入）
     = 12 + 0.5 + 1 = 13.5bb（BB ante 已是 BB 的投資的一部分）
BB call 需補 = 12 - 1 = 11bb（已有 1bb BB 在鍋中）
所需勝率 = 11 ÷ (13.5 + 11) = 11 ÷ 24.5 = 44.9%
```

**結論：push**

注意：如果此時是 bubble（強 ICM），push range 可能縮緊到 28-30%，AJo 仍在 range 內。BBA 底池讓 push EV 更高，強化了這個決定。

## 範例 4：BB Call 場景 — BTN Push 9bb，你有 JTs（BBA）

**場景：**
9-max，BBA 格式。BTN push all-in 9bb（有效籌碼 9bb）。SB fold。你在 BB，手牌 JTs，有 15bb。

**Pot Odds 計算（BBA）：**

```
底池組成：
  BTN push = 9bb
  SB fold（0.5bb 留底池）
  BB 已投入 = 1bb（大盲）+ 1bb（BB ante）= 2bb

底池合計 = 9bb + 0.5bb + 2bb = 11.5bb
你需要 call = 9 - 1 = 8bb（BB ante 不計入需補金額，大盲已算）

注意：BB ante 已包含在 BB 的前期投入，計算 call 金額時以大盲 1bb 為基礎
實際需補 call = 9bb - 1bb（BB）= 8bb

Call 後總底池 = 11.5 + 8 = 19.5bb
所需勝率 = 8 ÷ 19.5 = 41.0%
```

**BBA 底池影響對比：**
```
傳統（無 ante）：底池 = 9 + 0.5 + 1 = 10.5bb，call 後 = 18.5bb，所需勝率 = 8/18.5 = 43.2%
BBA 格式：底池 = 11.5bb，call 後 = 19.5bb，所需勝率 = 8/19.5 = 41.0%
BBA 讓 call 所需勝率降低了約 2.2%，對邊緣手牌有利
```

**BTN 9bb BBA push range ≈ 66%**（9bb 比 10bb 更短，range 更寬）

**JTs 對 BTN 66% push range 的勝率：**

JTs 的 equity 對很廣的 range 通常在 47-52%（JTs 對廣泛 range 表現良好，有連接性和 flush 潛力）。

查表：JTs 對 66% range ≈ 50-52% 勝率。

**決策：**
```
BBA 下所需勝率：41.0%
JTs 提供勝率：約 50-52%
明顯超過所需勝率 → Call
（即使是傳統 ante 的 43.2%，也應 call；BBA 讓這個 call 更加確定）
```

**結論：call**

補充：JTs 是對廣泛 push range 的標準 call。BBA 底池讓 call 的賠率更好，進一步確認了 call 的正確性。它有很好的 equity realization（適合多街 draw，有 flush 和 straight potential）。

## 範例 5：Bubble 中疊 BB，大疊 BTN Push — 你有 99（BBA）

**場景：**
大型線上 MTT，BBA 格式，200人 bubble（進 180 名），你在 BB，40bb（中等籌碼）。BTN 是全桌最大疊（120bb），push all-in。SB fold。你有 99。

**初步 Pot Odds（BBA）：**
```
底池組成：
  BTN push = 40bb（限制在你的有效籌碼）
  SB fold（0.5bb）
  BB 已投入 = 1bb（大盲）+ 1bb（BB ante）= 2bb

底池合計 = 40 + 0.5 + 2 = 42.5bb
你 call 需補 = 40 - 1 = 39bb

Call 後底池 = 42.5 + 39 = 81.5bb
所需勝率 = 39 ÷ 81.5 = 47.9%
```

**傳統 vs BBA 對比：**
```
傳統（無 ante）所需勝率 ≈ 48.5%
BBA 所需勝率 ≈ 47.9%
BBA 略微降低所需勝率，但差距對這個情境不顯著
```

**純 Chip EV 分析：**
大疊的 BTN push range（大疊 BTN push 中疊 BB，在 bubble 期間）可能是 50-60%。

99 對 55% range ≈ 53-55% 勝率 → Chip EV 是 call（53% > 47.9%）

**ICM 分析：**
- 你有 40bb，是中等籌碼，處於 bubble，ICM 壓力最大
- 輸了：從 40bb 到 0bb，直接 bubble 出局，$0
- 贏了：80bb+（BBA 底池更大，約 82bb），進入前段籌碼，大幅改善 ICM equity

計算（簡化）：
- 現在 ICM equity：假設 $320
- 贏了（53%）：ICM equity ≈ $520（大幅提升，BBA 底池讓籌碼堆更大）
- 輸了（47%）：$0（直接 bubble）

```
Call EV = 53% × $520 + 47% × $0 = $275.6
Fold EV ≈ $320
```

ICM 說 **fold**（fold EV > call EV）。

**結論：fold**

這是中疊在 bubble 最典型的「ICM 自殺」場景。即使 Chip EV 是正的（且 BBA 底池讓 Chip EV 稍微更正），ICM 仍然讓 fold 更優。

大疊知道這一點，所以他 push 很寬。你需要非常強的牌（如 AK+, JJ+）才能 call。BBA 不改變這個結論的方向，只是讓所有數字的分子分母同時略微擴大。

## 範例 6：SB 8bb，Q9s — 只剩 BB（BBA）

**場景：**
9-max，BBA 格式。所有前位 fold，你在 SB，8bb，手牌 Q9s。

**底池背景（BBA）：**
```
翻牌前底池（入局前）= BB 1bb + BB ante 1bb = 2bb（SB 0.5bb 加入後）
實際底池 = 0.5bb（SB）+ 1bb（BB）+ 1bb（BB ante）= 2.5bb
Push 成功淨贏 = 2.5 - 0.5（SB 已投）= +2bb（淨增加）
```

**分析：**

SB 8bb BBA push range（只需過 BB）≈ 72-75%。

Q9s 屬於前 38% 的手牌強度，遠寬於 72-75%，**在 push range 內**。

驗證：SB 8bb push range 包含幾乎所有有 Broadway 牌、所有 suited、所有對子，以及大多數有連接性的雜牌（75o, 64s 等）。Q9s 完全在範圍內。

**BBA 的影響：**
BBA 底池（2.5bb）讓 SB push 成功的淨收益比傳統格式更高。BB call 的所需勝率計算如下：
```
BB call 所需勝率（BBA）：
底池 = 8 + 0.5 + 1 = 9.5bb，call 需補 = 8 - 1 = 7bb
所需勝率 = 7 ÷ (9.5 + 7) = 7 ÷ 16.5 = 42.4%

傳統（無 ante）：
底池 = 8 + 0.5 + 1 = 9.5bb（同），但 BB 的投入少了 1bb（無 ante）
實際計算 BBA：底池 = 8 + 0.5 + 2bb(BB投入含ante) = 10.5bb，call補 7bb，
所需勝率 = 7 ÷ 17.5 = 40%

BBA 讓 BB call 所需勝率略降，意味著 BB 更容易 call —— 但 Q9s 勝率充足
```

**理由：**
- 只需讓 BB fold，fold equity 最高
- BB 的 call range 面對 SB 的 push ≈ 40%（只有前 40% 的手牌才 call，BBA 下略寬）
- Q9s 有 blocker 效果（Q blocker 阻止 QQ+）
- 即使被 call，Q9s 對很多 call range 有超過 40% 的勝率

**結論：push**

補充：SB 的推注在有些情況下可以加入 ICM 考量（bubble），但 8bb 的短疊讓 ICM 調整幅度很小。BBA 底池讓 push EV 更高，SB push 8bb 仍然是強迫選擇，push 是最優的。

## 快速判斷框架（BBA 版本）

所有短疊 push/fold 決策可以用這個框架快速判斷：

```
1. 我在哪個位置？→ 確定 BBA Nash push range %
2. 我的籌碼深度？→ 調整 range（越短越寬）
3. 我的手牌強度？→ 在 BBA Nash range 內嗎？
4. 有 ICM 壓力嗎？→ 縮緊 5-15%
5. 線上環境 call range 偏窄？→ 稍微放寬（+3-5%）
```

**BBA 底池計算速查（常用盲注）：**

| 盲注結構 | SB | BB | BB ante | 底池（BBA）| 傳統底池對比 |
|---------|----|----|---------|-----------|------------|
| 100/200 | 100 | 200 | 200 | **500** | 300（差 200）|
| 200/400 | 200 | 400 | 400 | **1,000** | 600（差 400）|
| 500/1000 | 500 | 1000 | 1000 | **2,500** | 1,500（差 1,000）|
| 1000/2000 | 1000 | 2000 | 2000 | **5,000** | 3,000（差 2,000）|

對於大多數手牌，前三步就能得出答案。ICM 和線上調整只影響邊界手牌。BBA 的底池更大讓偷盲 EV 更高，在 BTN/CO/SB 位置時要記得這個加成。
