# 短疊推注場景分析（9-max）

所有場景均以 9-max 標準 MTT 為基準，線上環境。

---

## 範例 1：UTG 10bb，K9o — 邊緣手牌判斷

**場景：**
9-max MTT，中期，有 antes。你在 UTG，有效籌碼 10bb。所有人 fold 前你。手牌：K9o。

**分析：**

UTG 10bb 的 Nash push range ≈ 28%。

K9o 在整體手牌分佈中屬於大約前 30-32% 的強度。它在 UTG 10bb push range 的**邊緣**，略寬於 Nash 標準。

更具體地說：
- UTG 10bb push 通常包含：A2o+, KTo+, QJo+, K8s+, Q9s+, J9s+, T8s+, 55+
- K9o 落在 KTo 的邊緣以下，在 Nash 標準中通常是 fold

**結論：fold**

補充說明：
- 線上低/中 stakes 可以稍微放寬（+3-5%），K9o 是極邊緣的 push
- 如果已知後面的 SB/BB 跟注頻率偏低，可以 push
- ICM 壓力下（接近 bubble），fold 傾向更強

---

## 範例 2：BTN 10bb，T8s — 後位推注

**場景：**
9-max MTT，你在 BTN，有效籌碼 10bb，手牌 T8s。前位所有人 fold。

**分析：**

BTN 10bb Nash push range ≈ 65%。T8s 約在前 48% 的手牌強度，遠寬於 65%。

等等——65% range 包含了前 65% 的手牌，T8s 在前 48%，**在 push range 內**。

驗證：BTN 10bb push range 包含：
- 22+, A2o+, K2s+, K7o+, Q4s+, Q9o+, J6s+, JTo, T6s+, T9o, 96s+, 98o, 86s+, 76s, 65s

T8s 確認在 range 內（T6s+ 包含 T8s）。

**結論：push**

額外考量：
- T8s 有翻牌後的潛力（如果被 call）：flush draw 和 straight draw 機會
- 有 fold equity（SB/BB 需要很強的牌才 call 65% range 的 BTN push）
- 這是清楚的 push，不需要猶豫

---

## 範例 3：HJ 12bb，AJo — 積極推注

**場景：**
9-max MTT，你在 HJ，12bb。前位（UTG, UTG+1, UTG+2, LJ）全部 fold。手牌：AJo。

**分析：**

HJ 12bb push range（Nash，有 antes）≈ 34-38%。AJo 屬於前 22% 的強牌，遠在 range 內。

HJ push 的考量：
- 還有 CO、BTN、SB、BB 在後面（四個人）
- 12bb push，對手的 call 需要約 40% 勝率（pot odds 計算）
- AJo 是 HJ 的標準 push

**結論：push**

注意：如果此時是 bubble（強 ICM），push range 可能縮緊到 28-30%，AJo 仍在 range 內。

## 範例 4：BB Call 場景 — BTN Push 9bb，你有 JTs

**場景：**
9-max，BTN push all-in 9bb（有效籌碼 9bb）。SB fold。你在 BB，手牌 JTs，有 15bb。

**Pot Odds 計算：**

```
底池 = 9bb（BTN push）+ 0.5bb（SB）+ 1bb（你的 BB）= 10.5bb
你需要 call = 9 - 1 = 8bb（已有 1bb 在底池）
需要勝率 = 8 / (10.5 + 8) = 8 / 18.5 = 43.2%
```

**BTN 9bb push range ≈ 66%**（9bb 比 10bb 更短，range 更寬）

**JTs 對 BTN 66% push range 的勝率：**

JTs 的 equity 對很廣的 range 通常在 47-52%（JTs 對廣泛 range 表現良好，有連接性和 flush 潛力）。

查表：JTs 對 66% range ≈ 50-52% 勝率。

**決策：**
```
需要 43.2%，JTs 提供約 50-52%
明顯超過需要勝率 → Call
```

**結論：call**

補充：JTs 是對廣泛 push range 的標準 call。它有很好的 equity realization（適合多街 draw，有 flush 和 straight potential）。

## 範例 5：Bubble 中疊 BB，大疊 BTN Push — 你有 99

**場景：**
大型線上 MTT，200人 bubble（進 180 名），你在 BB，40bb（中等籌碼）。BTN 是全桌最大疊（120bb），push all-in。SB fold。你有 99。

**初步 Pot Odds：**
```
底池 = 40bb（BTN push 限制在你的 40bb）+ 0.5bb（SB）+ 1bb（BB）= 41.5bb
你 call = 39bb
需要勝率 = 39 / (41.5 + 39) = 39 / 80.5 = 48.5%
```

**純 Chip EV 分析：**
大疊的 BTN push range（大疊 BTN push 中疊 BB，在 bubble 期間）可能是 50-60%。

99 對 55% range ≈ 53-55% 勝率 → Chip EV 是 call（53% > 49%）

**ICM 分析：**
- 你有 40bb，是中等籌碼，處於 bubble，ICM 壓力最大
- 輸了：從 40bb 到 0bb，直接 bubble 出局，$0
- 贏了：80bb+，進入前段籌碼，大幅改善 ICM equity

計算（簡化）：
- 現在 ICM equity：假設 $320
- 贏了（53%）：ICM equity ≈ $520（大幅提升）
- 輸了（47%）：$0（直接 bubble）

```
Call EV = 53% × $520 + 47% × $0 = $275
Fold EV ≈ $320
```

ICM 說 **fold**（fold EV > call EV）。

**結論：fold**

這是中疊在 bubble 最典型的「ICM 自殺」場景。即使 Chip EV 是正的，ICM 讓 fold 更優。

大疊知道這一點，所以他 push 很寬。你需要非常強的牌（如 AK+, JJ+）才能 call。

## 範例 6：SB 8bb，Q9s — 只剩 BB

**場景：**
9-max，所有前位 fold，你在 SB，8bb，手牌 Q9s。

**分析：**

SB 8bb push range（只需過 BB）≈ 72-75%。

Q9s 屬於前 38% 的手牌強度，遠寬於 72-75%，**在 push range 內**。

驗證：SB 8bb push range 包含幾乎所有有 Broadway 牌、所有 suited、所有對子，以及大多數有連接性的雜牌（75o, 64s 等）。Q9s 完全在範圍內。

**理由：**
- 只需讓 BB fold，fold equity 最高
- BB 的 call range 面對 SB 的 push ≈ 40%（只有前 40% 的手牌才 call）
- Q9s 有 blocker 效果（Q blocker 阻止 QQ+）
- 即使被 call，Q9s 對很多 call range 有超過 40% 的勝率

**結論：push**

補充：SB 的推注在有些情況下可以加入 ICM 考量（bubble），但 8bb 的短疊讓 ICM 調整幅度很小。SB push 8bb 仍然是強迫選擇，push 是最優的。

---

## 快速判斷框架

所有短疊 push/fold 決策可以用這個框架快速判斷：

```
1. 我在哪個位置？→ 確定 push range %
2. 我的籌碼深度？→ 調整 range（越短越寬）
3. 我的手牌強度？→ 在 range 內嗎？
4. 有 ICM 壓力嗎？→ 縮緊 5-15%
5. 線上環境 call range 偏窄？→ 稍微放寬（+3-5%）
```

對於大多數手牌，前三步就能得出答案。ICM 和線上調整只影響邊界手牌。
