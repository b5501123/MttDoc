# 多桌管理與心態：線上 MTT 的效率核心

## 多桌的本質

線上撲克最大的優勢之一是可以同時進行多個比賽，大幅提升每小時的 EV。

**理論上：**
- 1 桌：100% EV
- 2 桌：180-190% EV（因為注意力分散，每桌 EV 略降）
- 4 桌：300-350% EV
- 8 桌：450-550% EV（EV 因注意力大幅分散而降低）

實際上，每增加一桌，**每桌的決策品質**都會下降。最優桌數因人而異。

---

## BBA 在多桌環境中的重要性

**在多桌環境下，BBA 底池計算更容易出錯——這是最常見的多桌失誤之一。**

### 為什麼多桌時 BBA 計算更容易出錯

多桌時，玩家往往快速行動，跳過底池計算步驟。但在 BBA 環境下：

```
每一桌的底池都比你直覺想的更大：
  直覺底池（無 ante 思維）：SB + BB = 1.5bb
  實際 BBA 底池：SB + BB + BB ante = 2.5bb
  誤差：67%（低估底池）
```

低估底池會導致：
- C-bet 尺寸太小（相對底池比例偏低）
- Push/fold 判斷用了錯誤的賠率
- SPR 計算偏高（因為翻牌底池被低估）

### 多桌 BBA 底池計算的自動化

為了在多桌環境下正確應用 BBA，你需要**自動化**以下計算：

**即時底池辨識（BBA 標準）：**
```
一看到盲注結構，立即心算 BBA 底池：
  100/200 → 底池 500（= 100 + 200 + 200）
  200/400 → 底池 1,000
  500/1000 → 底池 2,500
  1000/2000 → 底池 5,000
  2000/4000 → 底池 10,000
```

這個心算必須在多桌壓力下也能立即完成，不能在每桌都停下來計算。

### BBA 下注尺寸的自動化

多桌時，下注尺寸計算要基於 BBA 底池：

```
25% BBA 底池 c-bet：
  100/200 → 底池 500 → 25% = 125（傳統底池 75，差 50）
  1000/2000 → 底池 5,000 → 25% = 1,250（傳統 750，差 500）

50% BBA 底池 c-bet：
  100/200 → 500 × 50% = 250（傳統 150，差 100）
  1000/2000 → 5,000 × 50% = 2,500（傳統 1,500，差 1,000）
```

在多桌環境下，固定 BBA 底池的百分比下注，不要用傳統底池的直覺金額。

## 多桌的風險與挑戰

### 決策品質下降

多桌的最大代價：
- 在複雜情境下沒有足夠時間深入分析
- ICM 計算在多桌壓力下容易出錯
- **BBA 底池計算在多桌壓力下更容易被遺忘**
- 在同一時刻多桌都需要行動時，必須優先排序

### 漏掉資訊

多桌時：
- 無法充分觀察每桌的對手打法
- HUD 數據累積更慢（每桌的手數更少）
- 錯過桌面的動態（誰是大疊、誰是短疊、誰在積極 push）
- **無法追蹤每桌的盲注結構和 BBA 底池大小（不同桌可能在不同盲注階段）**

### 情緒管理更難

多桌壞牌運可能同時出現（多桌同時 bad beat），情緒負擔更大。在多桌 BBA 環境下，底池更大的壞牌運損失感更強烈。

## 多桌策略框架

### 桌子優先級系統

任何時刻，都要有明確的「主桌」和「次桌」區分：

**主桌（最高優先級）：**
- 籌碼最多的桌（最有 EV 的比賽）
- 接近 bubble 或 final table 的桌（ICM 最關鍵）
- 正在進行大底池的桌
- **BBA 底池最大的桌（高盲注階段，BBA 讓底池更大，每手決策的 EV 差異更大）**

**次桌（次要優先級）：**
- 籌碼較少的桌
- 早期或遠離關鍵時刻的桌
- 可以用更簡化的決策處理
- **低盲注階段（BBA 底池相對小，錯誤成本較低）**

### 多桌時的 BBA 底池快速確認

每次行動前，養成習慣確認：
1. 當前盲注是多少？
2. BBA 底池是多少（盲注 × 2.5）？
3. 我的下注是底池的幾個百分比？

這個三步驟在多桌時只需 1-2 秒，但能防止因遺忘 BBA 而出現的底池計算錯誤。

### 桌數的自我管理（BBA 版本）

**初學者（<6 個月線上經驗）：** 最多 2 桌
- 重點：掌握每個決策的思考過程，**確保 BBA 底池計算正確**
- 多桌過早會固化錯誤習慣（包括忽略 BBA 的錯誤）

**中級玩家：** 最多 4 桌
- 應該有足夠的自動化決策能力（push/fold、標準 open/fold）
- **BBA 底池計算應已自動化**
- 複雜情境（bubble ICM、翻牌後大底池 BBA 計算）仍需充分時間

**進階玩家：** 最多 6-8 桌（視螢幕大小和情境）
- 在 bubble/FT 時主動減桌
- 不同比賽類型混搭（Hyper Turbo + Regular，讓桌間時間錯開）
- **BBA 底池計算完全自動化，無需停下來思考**

### 自動減桌規則（BBA 重要性）

設定自己的規則，在以下情況主動減桌（暫停報名或放棄某桌）：

1. 任何一桌進入 bubble：其他桌減至最少
2. 任何一桌進入 FT：關閉所有其他桌
3. 體力/注意力明顯下降：主動減桌
4. **任何一桌的大底池（BBA 高盲注）需要你仔細計算：暫停其他桌的行動**

BBA 底池更大，每個關鍵決策的 EV 差異更大。在高盲注 BBA 桌的 bubble 時，每個決策的錯誤成本遠高於早期。減桌是保護 EV 的重要工具。

## Bankroll 管理

### MTT Bankroll 的基本原則

MTT 的波動比 Cash Game 大很多。即使你在長期有 10% ROI，也可能連續幾個月沒有大結果。

**建議 bankroll：**
- 休閒玩家（<5 桌/週）：50-100 buy-ins
- 半職業/職業：100-200 buy-ins

**範例：**
你打 $22 MTT，bankroll 應該至少 $2,200-$4,400。

### 線上 MTT 的 Downswing 現實

MTT 是高度波動的項目：
- 即使 15% ROI 的玩家，在 500 場比賽內可能出現 -30% 的 downswing
- 需要幾千場的樣本才能確認技術水平（不是幾十場）

**心態要求：**
- 不要以單場或短期結果評估自己
- 不要因為一個月沒大結果就懷疑自己的水平

### 賽事選擇和 Bankroll

不要只打一個 stake level：
- 主要在 comfortable stake（確保長期有足夠 buy-ins）
- 偶爾 take shots（衛星贏到更高 stake，或在大型系列賽投入更高）
- 避免 downswing 時上 stake（情緒衝動的最大陷阱）

## Tilt 管理

Tilt 是線上 MTT 最大的 EV 殺手之一。

### Tilt 的類型

**結果型 Tilt：** 因為壞牌運（bad beat）而情緒化
- 例：KK 輸給 AA，下一手 shove 了 J8o

**決策型 Tilt：** 因為自己的失誤而情緒化
- 例：錯誤 fold 了贏牌，之後開始冒險補回
- **BBA 特殊情況：** 因為低估 BBA 底池而做出錯誤決策，之後情緒化冒更大的風險

**比較型 Tilt：** 因為看到別人贏了而心態失衡
- 例：多桌時看到另一桌有人贏了大底池，忘記自己桌的策略

### Tilt 的早期警告信號

你可能正在 tilt 的跡象：
- 下注尺寸突然變化（比以前更大或更小）
- 對 range 的考慮減少，更多「感覺」決策
- 在 time bank 用盡時才行動（說明無法集中）
- 開始希望某特定結果（而非計算 EV）
- **忘記 BBA 底池計算，用直覺金額下注（說明注意力已不集中）**

### 防 Tilt 的實際方法

1. **設定停損點：** 在一天內 X 次 buy-in 損失後，停止打牌
2. **Short session：** 不強迫自己打完所有比賽（可以報名後放棄，或在早期退出）
3. **Bad beat 處理流程：** 壞牌後，主動休息 5-10 分鐘，喝水，然後繼續
4. **結果分離：** 只評估決策品質，而非結果（結果有運氣成分）
5. **手牌回顧代替自責：** 比賽結束後回顧，而不是比賽中自責
6. **BBA 計算核對：** 如果比賽中感覺決策不順，停下來核對是否正確使用了 BBA 底池

## 比賽時的心態框架（BBA 整合版）

### 每手牌的思考流程（BBA 版本）

不論多少桌，每手牌的思考應該遵循：
1. 我的位置？
2. 當前盲注結構？**BBA 底池是多少？**
3. 我的籌碼深度（bb）？
4. 對手的大概 range？
5. 有 ICM 壓力嗎？
6. 最優行動（基於 BBA 底池計算）？

自動化步驟 1-3（特別是 BBA 底池），讓步驟 4-6 有更多思考時間。

### BBA 心態：底池永遠比你想的大

在多桌快速環境下，最容易犯的錯誤是用「直覺」估算底池。記住：

```
BBA 底池 = 傳統底池 × 1.67（大約）
每次下注前：BBA 底池比你想的大，下注金額要相應調整
```

這個心態習慣在多桌時特別重要，因為你沒有時間每次都重新計算。

### 長期心態

MTT 是長期遊戲：
- 一場比賽的結果毫無意義（樣本太小）
- 100-500 場才能看出技術趨勢
- 目標是每手牌做出最優決策（包括正確的 BBA 底池計算），結果交給概率

保持這種心態，讓你在 downswing 時不崩潰，在 upswing 時不驕傲。
