# 工具與資源：線上 MTT 玩家的技術武器庫

## 核心計算工具

### HRC（Hold'em Resources Calculator）

**用途：** Push/fold 計算 + ICM 分析，最全面的 MTT 工具

**主要功能：**
- Nash push/fold ranges（9-max 完整支援）
- ICM push/fold（加入獎金結構）
- 手牌範圍輸入和分析
- 多人 call 模擬
- PKO 模式（賞金計算）

**使用場景：**
- 賽後分析短疊 push/fold 決策
- 練習 push range 記憶
- ICM bubble 情境計算

**費用：** 一次性購買（約 $50-80），值得投資。

**使用步驟：**
1. 選擇桌子類型（9-max）
2. 輸入各位置的籌碼量
3. 設定盲注結構（含 antes）
4. 選擇計算模式：Nash 或 ICM
5. 查看各位置的 push/call range

---

### ICMIZER 3

**用途：** ICM 分析和 push/fold，用戶友好

**主要功能：**
- ICM 情境分析（輸入手牌、stack、獎金結構）
- 提供 push/call 建議
- 支援 PKO 模式
- 「Spot Analysis」：分析特定手牌的 EV

**使用場景：**
- 快速查詢 bubble 手牌的正確決策
- MTT 賽後回顧（導入手牌歷史）

**費用：** 月訂閱制（約 $15-25/月），有免費基礎版本。

---

### GTO Wizard

**用途：** 完整的 GTO 求解器，覆蓋翻牌前和翻牌後

**主要功能：**
- MTT GTO 解（9-max，含 ICM）
- 翻牌後完整 GTO strategies（各 stack depth）
- Drill mode（練習模式）
- Range Viewer（視覺化 range）

**使用場景：**
- 學習翻牌後 GTO 打法
- 分析特定翻牌的 c-bet 策略
- 練習 range 識別

**費用：** 月訂閱制（$50-100/月），是目前最貴但最全面的工具。

---

### Simple Nash / Poker Stove（免費工具）

**Simple Nash：**
- 免費，快速查詢 Nash push range
- 介面簡單，直接輸入 stack 和位置

**Equilab（PokerStrategy）：**
- 免費的 equity 計算工具
- 快速計算手牌對 range 的勝率
- 適合驗算 call 的 pot odds 計算

## 手牌回顧工具

### 平台內建工具

**GGPoker：**
- Hand History（手牌歷史）可以匯出
- My Hand（我的手牌）在 app 內可以回顧
- 有些情境可以 replay

**PokerStars：**
- Hand History 匯出功能完整
- 可以通過 email 請求手牌歷史

### PokerTracker 4 / Holdem Manager 3

**用途：** 手牌追蹤、統計分析、HUD

**主要功能：**
- 記錄所有手牌歷史
- 生成詳細統計（VPIP, PFR, 3-bet 頻率等）
- HUD 功能（即時顯示對手統計，部分平台支援）
- 贏率分析（按位置、按手牌類型）

**費用：** 約 $100（一次性）或月訂閱

**注意：** GGPoker 不支援即時 HUD，但 PT4/HM3 可以分析已匯出的歷史，以及在支援的平台（PokerStars）使用 HUD。

## 平台選擇指南

### 選擇平台的考量因素

| 因素 | 考量 |
|-----|------|
| 玩家池軟硬 | 魚多 = 更高 EV（GGPoker 通常最軟）|
| 賽事品質 | 大型賽事 = 更大獎金（PokerStars WCOOP/SCOOP）|
| 允許 HUD | 使用 HUD 的情況下優先支援平台 |
| 提款方便性 | 本地支援的支付方式 |
| 促銷和 Rakeback | 長期來說影響 EV |

### 新手建議

1. 從一個平台開始（推薦 GGPoker）
2. 先打低 stake（$5-$11 MTT）積累手數
3. 熟悉後加入 PokerStars（最大型賽事）
4. 使用 ICMIZER 免費版分析早期手牌

### 投資優先順序

有限預算下，工具投資的優先順序：

1. **HRC（或 ICMIZER）** — Push/fold 計算（最高優先）
2. **PokerTracker 4 / HM3** — 手牌追蹤（如果打 PokerStars）
3. **GTO Wizard** — 翻牌後 GTO 學習（進階）
4. **課程（RIO 或 Upswing）** — 系統化學習

## 使用工具的正確心態

工具的目的是**輔助學習**，不是代替思考：

- 不要在桌上即時查工具（依賴工具不建立直覺）
- 用工具賽後回顧，培養自動化決策
- 最終目標：不需要工具，靠直覺和計算在桌上做出正確決策
- 工具是建立框架的工具，不是拐杖
