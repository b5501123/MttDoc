# 工具與資源：線上 MTT 玩家的技術武器庫

## BBA 設定說明（使用所有工具前必讀）

**現代線上 MTT 全面採用 Big Blind Ante（BBA），所有計算工具在使用前必須正確設定 BBA。**

```
BBA 設定要求：
- 在 antes 欄位選擇「Big Blind Ante」或「BB Ante」
- 不要使用「傳統 ante（每人付 1bb）」設定
- 不要使用「無 ante」設定
- 錯誤的 ante 設定會讓計算結果偏差 10-20%
```

---

## 核心計算工具

### HRC（Hold'em Resources Calculator）

**用途：** Push/fold 計算 + ICM 分析，最全面的 MTT 工具

**主要功能：**
- Nash push/fold ranges（9-max 完整支援）
- ICM push/fold（加入獎金結構）
- 手牌範圍輸入和分析
- 多人 call 模擬
- PKO 模式（賞金計算）

**BBA 設定步驟（重要）：**
1. 選擇桌子類型（9-max）
2. 輸入各位置的籌碼量
3. 設定盲注結構：在 **Antes** 欄位選擇 **「Big Blind Ante」**
4. 輸入 ante 金額 = 大盲金額（例：盲注 1000/2000，ante = 2000）
5. 選擇計算模式：Nash 或 ICM
6. 查看各位置的 push/call range

**BBA 底池驗證：**
設定完成後，確認 HRC 顯示的底池：
```
盲注 1000/2000，BBA 2000：
  底池應顯示 = 4,000（SB 1000 + BB 2000 + BB ante 2000 = 5,000，減去未開彩）
  確認底池是 5,000 而非 3,000（若是 3,000，代表未啟用 BBA）
```

**費用：** 一次性購買（約 $50-80），值得投資。

**使用場景：**
- 賽後分析短疊 push/fold 決策
- 練習 BBA push range 記憶
- ICM bubble 情境計算（BBA 設定下）

---

### ICMIZER 3

**用途：** ICM 分析和 push/fold，用戶友好

**主要功能：**
- ICM 情境分析（輸入手牌、stack、獎金結構）
- 提供 push/call 建議
- 支援 PKO 模式（BBA + Bounty 組合）
- 「Spot Analysis」：分析特定手牌的 EV

**BBA 模式說明（ICMIZER）：**

ICMIZER 3 的 BBA 設定位置：
1. 進入 **Tournament Structure** 設定
2. 找到 **Ante Type** 選項
3. 選擇 **「Big Blind Ante」**（不要選「No Ante」或「Standard Ante」）
4. Ante 金額會自動設為與大盲相等

**BBA 設定後的差異：**
```
以 10bb push 為例（BTN，9-max）：
  BBA 設定：push range 約 65%（底池更大，push EV 更高）
  無 ante 設定：push range 約 60-62%（底池較小）
  差異：3-5%（對邊緣手牌決策影響顯著）
```

**PKO BBA 模式：**
1. 啟用 PKO 模式
2. 選擇 BBA ante（同上步驟）
3. 輸入各玩家的賞金金額
4. ICMIZER 會自動計算 BBA Chip EV + Bounty EV + ICM

**費用：** 月訂閱制（約 $15-25/月），有免費基礎版本。

**使用場景：**
- 快速查詢 bubble 手牌的正確決策（BBA 模式）
- MTT 賽後回顧（導入手牌歷史，BBA 格式自動識別）

---

### GTO Wizard

**用途：** 完整的 GTO 求解器，覆蓋翻牌前和翻牌後

**主要功能：**
- MTT GTO 解（9-max，含 ICM）
- 翻牌後完整 GTO strategies（各 stack depth）
- Drill mode（練習模式）
- Range Viewer（視覺化 range）

**BBA 在 GTO Wizard 中的表現：**
```
GTO Wizard 的 MTT 解已內建 BBA 格式：
  翻牌前底池預設 = 2.5bb（SB 0.5 + BB 1 + BB ante 1）
  所有翻牌後下注尺寸均基於 BBA 底池
  SPR 計算使用 BBA 翻牌底池
```

使用 GTO Wizard 時，注意確認你選擇的是 BBA 結構的解，而非舊版的傳統 ante 解。

**使用場景：**
- 學習翻牌後 GTO 打法（BBA 底池下的 SPR 和下注尺寸）
- 分析特定翻牌的 c-bet 策略（BBA 底池讓 c-bet 金額更大）
- 練習 range 識別

**費用：** 月訂閱制（$50-100/月），是目前最貴但最全面的工具。

---

### Simple Nash / Poker Stove（免費工具）

**Simple Nash：**
- 免費，快速查詢 Nash push range
- 介面簡單，直接輸入 stack 和位置
- **BBA 注意：** 確認設定中選擇了 BBA 選項；若工具不支援 BBA，結果約偏差 3-5%

**Equilab（PokerStrategy）：**
- 免費的 equity 計算工具
- 快速計算手牌對 range 的勝率
- 適合驗算 BBA call 的 pot odds 計算
- **使用方式：** 手動輸入 BBA 底池大小（不要用預設的無 ante 底池）

**BBA 免費工具限制：**
許多免費工具未更新 BBA 選項，使用時需手動調整：
```
手動調整方式：
  底池 = SB + BB + BB ante（手動計算，輸入到工具中）
  例：盲注 1000/2000 → 底池手動輸入 5,000（非工具計算的 3,000）
```

## 手牌回顧工具

### 平台內建工具

**GGPoker：**
- Hand History（手牌歷史）可以匯出
- My Hand（我的手牌）在 app 內可以回顧
- 有些情境可以 replay
- **BBA 格式：** GGPoker 的手牌歷史已記錄 BBA ante，匯入 ICMIZER/HRC 時 BBA 自動識別

**PokerStars：**
- Hand History 匯出功能完整
- 可以通過 email 請求手牌歷史
- **BBA 格式：** PokerStars 手牌歷史標注 BBA，回顧工具會自動處理

### PokerTracker 4 / Holdem Manager 3

**用途：** 手牌追蹤、統計分析、HUD

**主要功能：**
- 記錄所有手牌歷史
- 生成詳細統計（VPIP, PFR, 3-bet 頻率等）
- HUD 功能（即時顯示對手統計，部分平台支援）
- 贏率分析（按位置、按手牌類型）

**BBA 相關設定：**
- PT4/HM3 可以識別 BBA 格式的手牌歷史
- 在篩選和統計時，BBA 底池的數據已自動包含
- 分析翻牌底池大小時，BBA 數據會顯示正確的底池（含 ante）

**費用：** 約 $100（一次性）或月訂閱

**注意：** GGPoker 不支援即時 HUD，但 PT4/HM3 可以分析已匯出的歷史，以及在支援的平台（PokerStars）使用 HUD。

## 學習資源

### 課程平台

**RunItOnce（RIO）：**
- Phil Galfond 創立，高品質視頻課程
- MTT 課程豐富（多位頂級玩家教學）
- 月訂閱制（約 $25-50/月，依等級）
- **BBA 建議：** 觀看課程時注意確認教學影片是否為 BBA 環境（2019 年後的影片通常是）

**Upswing Poker：**
- Doug Polk 和多位職業玩家的課程
- MTT 有專門課程（Nick Petrangelo, Parker Talbot 等）
- 月訂閱或單獨購買
- **BBA 建議：** 近年課程已更新為 BBA 標準

**Jonathan Little Training：**
- 専攻 MTT 的教學平台
- 詳細的手牌分析視頻
- 適合中級玩家
- **BBA 建議：** Jonathan Little 的近年影片均以 BBA 為前提

### YouTube 免費資源

**值得關注的 MTT 頻道：**
- Jonathan Little（大量手牌分析，免費，BBA 環境）
- Brad Owen（休閒風，好的思維框架）
- Rampage Poker（MTT 實況）
- MTT 相關職業玩家的 Twitch 直播

**BBA 重要提示：** 2018 年以前的舊影片可能使用傳統 ante 格式，不要直接套用舊影片中的底池計算，但策略原則仍然適用。

### 書籍

**推薦 MTT 書籍：**
- Jonathan Little《Mastering Mixed Game Tournaments》
- Collin Moshman《Sit 'n Go Strategy》（基礎 push/fold）
- Dan Harrington《Harrington on Hold 'em》（較舊但經典）

**BBA 注意：** 這些書籍出版時 BBA 尚未普及，書中的底池計算用傳統 ante 或無 ante。閱讀時需要把底池計算換算為 BBA（底池 × 1.67 大約等於 BBA 底池）。

## 平台選擇指南

### 選擇平台的考量因素（BBA 版本）

| 因素 | 考量 |
|-----|------|
| 玩家池軟硬 | 魚多 = 更高 EV（GGPoker 通常最軟）|
| 賽事品質 | 大型賽事 = 更大獎金（PokerStars WCOOP/SCOOP）|
| 允許 HUD | 使用 HUD 的情況下優先支援平台 |
| 提款方便性 | 本地支援的支付方式 |
| 促銷和 Rakeback | 長期來說影響 EV |
| **BBA 工具相容性** | **確認你的分析工具支援平台的 BBA 格式** |

### 新手建議（BBA 版本）

1. 從一個平台開始（推薦 GGPoker）
2. 先打低 stake（$5-$11 MTT）積累手數
3. **立即學習 BBA 底池計算（100/200 → 底池 500）**
4. 熟悉後加入 PokerStars（最大型賽事）
5. 使用 ICMIZER 免費版分析早期手牌（確保 BBA 設定正確）

### 投資優先順序（BBA 工具優先）

有限預算下，工具投資的優先順序：

1. **HRC（或 ICMIZER）——BBA 設定** — Push/fold 計算（最高優先）
   - 必須正確設定 BBA，否則所有計算都是錯的
2. **PokerTracker 4 / HM3** — 手牌追蹤（如果打 PokerStars）
3. **GTO Wizard（BBA MTT 解）** — 翻牌後 GTO 學習（進階）
4. **課程（RIO 或 Upswing）** — 系統化學習（選 BBA 環境的近年課程）

## 使用工具的正確心態（BBA 版本）

工具的目的是**輔助學習**，不是代替思考：

- 不要在桌上即時查工具（依賴工具不建立直覺）
- 用工具賽後回顧，培養自動化決策
- 最終目標：不需要工具，靠直覺和計算在桌上做出正確決策
- 工具是建立框架的工具，不是拐杖

**BBA 特別說明：**
- 在你的工具中永久設定 BBA 為默認選項
- 每次開始新的分析前，檢查 BBA 設定是否正確
- 不要在「快速查看」時切換到無 ante 設定——這是最常見的工具使用錯誤

## BBA 工具設定速查

| 工具 | BBA 設定路徑 | 驗證方法 |
|-----|-----------|--------|
| HRC | Antes → Big Blind Ante → 金額 = 大盲 | 確認底池 = SB+BB+BB ante |
| ICMIZER 3 | Tournament Structure → Ante Type → Big Blind Ante | 確認分析結果中底池正確 |
| GTO Wizard | 選擇 MTT BBA 解（預設已設定）| 確認翻牌底池 = 2.5bb |
| Simple Nash | Settings → Ante → BB Ante | 確認 push range 比無 ante 稍寬 |

所有工具使用前，**先確認 BBA 設定，再開始計算**。
