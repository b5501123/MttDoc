# 線上環境特性：線上 MTT 的獨特生態

## 線上 vs 現場：根本差異

### 資訊獲取方式

**現場：**
- 依靠觀察對手的動作、表情、聲音（tells）
- 可以看籌碼量、計算速度、下注方式
- 每手只有一桌，注意力可以集中

**線上：**
- 無法觀察對手的肢體語言
- 替代工具：**HUD（Heads-Up Display）**，追蹤對手的統計數據
- 可以同時觀察多桌，但注意力分散

### 速度差異

線上 MTT 每小時手數遠高於現場：
- 現場：約 20-30 手/小時
- 線上（單桌）：約 60-80 手/小時
- 線上（多桌）：每桌 60-80 手 × 桌數 = 大量手數

這意味著你在線上可以在同樣時間內積累更多樣本，但也需要更快的決策速度。

## Big Blind Ante（BBA）：線上 MTT 的標準格式

**這是線上 MTT 最重要的結構特性：現代線上 MTT 全面採用 Big Blind Ante（BBA）。**

### 什麼是 BBA

- BB（大盲）除支付大盲外，還需額外支付等於大盲的 ante
- 格式：盲注 100/200 → BB 付 200（大盲）+ 200（ante）= 400 total
- SB 只付 100（小盲），無需額外 ante
- UTG 及以後所有玩家翻牌前無需付 ante

### BBA 底池計算（線上 MTT 標準）

```
BBA 翻牌前底池 = SB + BB + BB ante
              = 0.5bb + 1bb + 1bb = 2.5bb（以 bb 計）

具體例子（盲注 100/200）：
  翻牌前底池 = 100 + 200 + 200 = 500 chips

傳統格式（無 ante）：
  翻牌前底池 = 100 + 200 = 300 chips

BBA 底池比傳統大 67%
```

### BBA 在不同平台的實施方式

| 平台 | BBA 實施 | 備註 |
|-----|---------|------|
| **GGPoker** | 全面 BBA | 所有常規 MTT 和 PKO 系列均為 BBA |
| **PokerStars** | 全面 BBA | 2019 年後所有 MTT 轉換為 BBA |
| **888poker** | 主要 BBA | 大多數賽事採用 BBA |
| **partypoker** | 主要 BBA | 主流賽事採用 BBA |
| **現場（WSOP 等）** | 部分 BBA | 大型系列賽事逐漸採用 BBA |

**關鍵：你打的所有線上 MTT 幾乎都是 BBA，這必須是你默認的計算前提。**

### BBA 對策略的三大影響

**1. 每圈成本更高（對 BB 影響最大）**
```
傳統格式每圈成本（9-max）：1.5bb
BBA 格式每圈成本（9-max）：2.5bb（BB 付 2bb + SB 0.5bb，平均每人）
增加：67%
```
→ BB 每次比傳統多付 1bb（ante），每圈守盲成本更高
→ 應更積極 defend BB，避免讓偷盲玩家每次都免費獲益

**2. Steal EV 更高（對後位影響最大）**
```
BTN 偷盲成功：傳統贏 1.5bb，BBA 贏 2.5bb
EV 提升：67%
```
→ BTN、CO、SB 應更積極 steal（open range 可以稍微放寬）
→ 特別是在 bubble 附近，大疊偷盲的 EV 更顯著

**3. Push/Fold 計算需要 BBA Nash**
```
所有 push/fold 分析工具（HRC、ICMIZER）必須設定為 BBA 格式
BBA 環境下 push range 比傳統格式稍寬（因為 push EV 更高）
```

## 線上玩家類型

理解線上 MTT 常見的玩家類型，有助於做出更好的桌面選擇和策略調整。

### 四象限速查表

```
                 被動（Passive）        主動（Aggressive）
緊（Tight）   │ Nit / 緊弱            │ TAG / 緊強
              │ VPIP <15%, PFR <8%    │ VPIP 15-25%, PFR 13-22%
              │ 對付：偷盲、3-bet bluff │ 對付：打標準 GTO，不要輕易 bluff
──────────────┼────────────────────────┼─────────────────────────────────
寬（Loose）   │ Calling Station / 寬弱 │ LAG / 寬強
              │ VPIP 40%+, PFR <12%   │ VPIP 35%+, PFR 22%+
              │ 對付：薄 value，不要 bluff │ 對付：value 3-bet，打大底池
```

---

### 類型一：TAG（Tight Aggressive，緊強）

**特徵：**
- VPIP 15-25%，PFR 13-22%，VPIP/PFR 比例緊密（差距 ≤ 5%）
- 入局牌型優質，翻牌後有計劃地下注
- 理解位置，IP 積極，OOP 保守
- 是最常見的「正規玩家（Reg）」核心形態

**識別方式：**
- HUD 數據平衡，下注尺寸合理（BBA 底池的正確百分比）
- 面對 3-bet 有明確策略（不是永遠 fold 也不是永遠 call）
- 翻牌後不亂 bluff，也不亂跟注

**對付策略：**
- 打標準 GTO，不要嘗試過度複雜的利用性策略
- 可以在位置上對他們施壓（他們 OOP 較保守）
- 不要用弱牌對他們 call river（他們的 value range 很真實）

---

### 類型二：LAG（Loose Aggressive，寬強）

**特徵：**
- VPIP 35%+，PFR 22%+
- 廣泛的 open range，高 3-bet 頻率
- 積極的翻牌後打法，頻繁 c-bet 和 barrel
- 利用 BBA 底池主動 steal（BBA 底池讓 LAG 的積極打法 EV 更高）

**識別方式：**
- HUD 顯示 VPIP >> PFR 以外的數值明顯偏高
- 頻繁從後位 open 和 3-bet
- 翻牌後很少 check-fold

**對付策略：**
- 對他們收緊 3-bet bluff（他們 4-bet 頻率高）
- 增加 value 3-bet 頻率（KK, QQ, AQ+ 都可以 3-bet for value）
- 準備在強牌時打大底池（他們的 range 廣，你的 value 更有利）
- BBA 底池讓 value 對 LAG 更有利：底池更大，你的強牌報酬更高

---

### 類型三：Nit（Tight Passive，緊弱）

**特徵：**
- VPIP <15%，PFR <8%
- 只打超強牌，面對任何 aggression 傾向 fold
- Fold to 3-bet 很高（>70%）
- 翻牌後 check/fold 頻繁，幾乎不 bluff

**識別方式：**
- HUD 顯示 VPIP 極低
- 在不合適的情況下頻繁棄牌（連 BTN 都不 steal）
- 翻牌後一有抵抗就 fold

**對付策略：**
- 大量增加 steal 頻率（BTN、CO 幾乎所有牌都可以 open）
- 3-bet bluff 頻率增加（他們 fold 很多）
- 翻牌後積極 c-bet（即使 miss，他們也容易 fold）
- BBA 底池讓你的 steal EV 更高：每次 steal 成功贏得更多

---

### 類型四：Calling Station（Loose Passive，寬弱）

**特徵：**
- VPIP 40%+，PFR <12%
- 過度 call，很少主動加注
- 對 bluff 免疫（他們不 fold）
- 追非優質 draw，在不利的賠率下繼續
- 不了解 BBA 底池大小，常用固定金額下注

**識別方式：**
- HUD 顯示 VPIP 遠高於 PFR（差距 30%+）
- 頻繁 limp 進入底池
- 奇怪的下注尺寸（固定金額而非底池比例）
- 常常打到 showdown（WTSD% 很高）

**對付策略：**
- 薄 value bet：比正常更頻繁、更大地下注 value 手牌
- 完全停止 bluff（他們不 fold，bluff 是 EV 負的）
- BBA 底池更大 → 你的 value bet 金額更高，利用效率更好
- 不要試圖「讓他們明白」，直接用 value 拿錢

---

### 類型五：Nitty Reg（保守型職業）

**特徵：**
- 技術不錯但過度保守（介於 TAG 和 Nit 之間）
- VPIP 18-22%，但 Fold to 3-bet 偏高（>65%）
- 翻牌後 check/fold 頻繁（Fold to C-bet >65%）
- 在 BBA 環境下 steal range 偏窄（沒有充分利用 steal EV）

**對付策略：** 增加 steal 和 3-bet bluff 頻率。他們的弱點是過度 fold，BBA 底池讓你的 steal EV 更高。

---

### 類型六：Recreational（娛樂型，兼具寬弱特性）

**特徵：**
- 不使用 HUD 或不熟悉 GTO
- 可能不了解 BBA 底池，下注尺寸不精確
- 過度 call（Calling Station 傾向）或過度 fold（Nit 傾向）
- 在特定情況下做出非常規決定

**識別方式：**
- 奇怪的下注尺寸（固定金額，或完全不考慮 BBA 底池比例）
- 奇怪的行動節奏（極快或永遠用完 time bank）
- 在不合適的情況下 limp 或 call

**對付策略：** 判斷他們偏向 Calling Station 還是 Nit，再套用上方對應策略。BBA 底池更大，對兩種娛樂型玩家的利用效率都更高。

## HUD 的使用

HUD（Heads-Up Display）是線上 MTT 最重要的工具之一，在允許的平台上使用。

### 主要統計數據

| 統計 | 定義 | 參考範圍（reg vs fish）|
|-----|------|----------------------|
| VPIP | 自願投入底池的頻率 | Reg: 18-28%, Fish: 35%+ |
| PFR | 翻牌前 raise 的頻率 | Reg: 15-25%, Fish: 5-15% |
| 3-bet % | 3-bet 的頻率 | Reg: 7-12%, Fish: 1-5% |
| Fold to 3-bet | 面對 3-bet 的 fold 率 | Reg: 55-65%, Fish: 70%+ |
| Fold to Cbet | 面對 c-bet 的 fold 率 | Reg: 50-60%, Fish: 65%+ |
| AF（Aggression Factor）| 主動攻擊因子 | >2 積極，<1 被動 |
| BTN steal % | BTN 位置的 steal 頻率 | Reg: 50-65%（BBA 環境應更高）, Fish: 20-35% |

**BBA 環境的 HUD 注意事項：**
- BTN steal % 在 BBA 環境應該比傳統稍高（因為 steal EV 更高）
- 低 BTN steal %（<50%）在 BBA 環境可能代表對手沒有充分利用 BBA 底池的 steal 機會

### HUD 的限制

- **MTT 中 sample size 小：** 一場 MTT 與某人的手數可能只有 30-50 手，統計不夠可靠
- **玩家調整：** 好的玩家在注意到你的打法後會調整
- **不適用所有平台：** GGPoker 不允許即時 HUD（有歷史數據查詢）；PokerStars 允許

**建議：** HUD 作為參考，結合現場觀察，不要完全依賴。

## Timing Tell（時間讀牌）

線上撲克的「tells」主要是 timing（行動速度）：

### 即時行動（快）

- 即時 check：通常是弱牌（決定已做，直接 check）
- 即時 bet：可能是強牌（或習慣性自動 bet）
- 即時 call：通常是中等手牌或 draw（願意繼續但不想 raise）

### 慢速行動（使用 time bank）

- 慢速 call：邊緣手牌，在 fold 和 call 之間猶豫
- 慢速 raise：強牌（故意慢打）或 semi-bluff（計算中）
- 慢速 fold：強牌放棄（如 set 面對 action，痛苦 fold）

### 注意事項

- Timing tells 的準確性遠低於現場 tells
- 很多玩家有固定的 timing 習慣（與手牌強弱無關）
- 使用 time bank 的頻率因人而異
- 不要完全依賴 timing，結合 range 分析

## 線上平台選擇（BBA 標準）

**所有主要平台均採用 BBA，以下分析均以 BBA 為前提。**

### GGPoker

**優點：**
- 最大的玩家群體（魚最多）
- 豐富的賽事（每日大型 MTT，WSOP 系列）
- PKO Bounty Builder 是主打格式（BBA + Bounty 雙重優勢）
- 完善的衛星系統
- 介面現代，功能豐富（Deal 功能、insure、etc.）
- **BBA 全面支援，所有工具計算均以 GGPoker BBA 為基準**

**缺點：**
- 不允許即時 HUD（有歷史 HUD，但準確性較低）
- 軟體有時需要更多資源

**BBA 補充：** GGPoker 是推動 BBA 普及的主要平台之一，其 PKO 系列與 BBA 的結合是目前線上 MTT 最有價值的賽事格式。

### PokerStars

**優點：**
- 歷史最悠久，最大的賽事（WCOOP, SCOOP, EPT）
- 允許 HUD（部分限制）
- 軟體穩定，功能完整
- 玩家池廣泛
- **BBA 已全面實施（2019 年後）**

**缺點：**
- 相對更多的 reg（競爭更激烈）
- 一些功能需要付費

**BBA 補充：** PokerStars 大型賽事（WCOOP SCOOP）均為 BBA，打這些賽事時必須使用 BBA 計算工具。

### 888poker

**優點：**
- 相對較軟的玩家群體
- 特定賽事的價值好

**缺點：**
- 玩家池相對小

### 策略建議（BBA 環境）

對於大多數玩家，**GGPoker 是首選**（最大的魚池、最豐富的賽事、BBA + PKO 最佳組合），**PokerStars 是重要補充**（最大賽事，WSOP 系列）。同時在兩個平台運作是職業玩家的標準配置。

**記住：兩個平台都是 BBA，你的所有 push/fold 計算必須基於 BBA Nash 數值。**
