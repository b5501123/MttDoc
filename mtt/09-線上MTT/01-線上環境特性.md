# 線上環境特性：線上 MTT 的獨特生態

## 線上 vs 現場：根本差異

### 資訊獲取方式

**現場：**
- 依靠觀察對手的動作、表情、聲音（tells）
- 可以看籌碼量、計算速度、下注方式
- 每手只有一桌，注意力可以集中

**線上：**
- 無法觀察對手的肢體語言
- 替代工具：**HUD（Heads-Up Display）**，追蹤對手的統計數據
- 可以同時觀察多桌，但注意力分散

### 速度差異

線上 MTT 每小時手數遠高於現場：
- 現場：約 20-30 手/小時
- 線上（單桌）：約 60-80 手/小時
- 線上（多桌）：每桌 60-80 手 × 桌數 = 大量手數

這意味著你在線上可以在同樣時間內積累更多樣本，但也需要更快的決策速度。

## 線上玩家類型

理解線上 MTT 常見的玩家類型，有助於做出更好的桌面選擇和策略調整。

### 類型一：Reg（Regular，職業型或半職業型）

**特徵：**
- 使用 HUD，熟悉 GTO 概念
- 多桌運作，高效率
- 打法接近標準，難以輕易利用

**識別方式：**
- 在多個賽事同時出現
- HUD 統計平衡（VPIP/PFR 比例合理）
- 下注尺寸精確

**策略：** 對 reg 打標準 GTO，不要嘗試複雜的利用性策略（他們會調整）。

### 類型二：Recreational（娛樂型，魚）

**特徵：**
- 不使用 HUD 或不熟悉 GTO
- 過度 call（calling station）或過度 fold（nit）
- 在特定情況下做出非常規決定

**識別方式：**
- 奇怪的下注尺寸（如 bet exactly $XX 而非底池比例）
- 奇怪的行動節奏（很快 or 永遠等到 time bank）
- 在不合適的情況下 limp 或 call

**策略：** 薄價值 bet 更多，減少 bluff，利用他們的 calling station 傾向。

### 類型三：Nitty Reg（保守型職業）

**特徵：**
- 技術不錯但過度保守
- Fold to 3-bet 很高（>65%）
- 翻牌後 check/fold 頻繁

**策略：** 增加 steal 和 3-bet bluff 頻率。他們的弱點是過度 fold。

### 類型四：Loose Aggressive（LAG）

**特徵：**
- 廣泛的 open range（VPIP 35%+）
- 高 3-bet 頻率
- 積極的翻牌後打法

**策略：** 對他們收緊 3-bet bluff，增加 value 3-bet，準備在強牌時打大底池。

## HUD 的使用

HUD（Heads-Up Display）是線上 MTT 最重要的工具之一，在允許的平台上使用。

### 主要統計數據

| 統計 | 定義 | 參考範圍（reg vs fish）|
|-----|------|----------------------|
| VPIP | 自願投入底池的頻率 | Reg: 18-28%, Fish: 35%+ |
| PFR | 翻牌前 raise 的頻率 | Reg: 15-25%, Fish: 5-15% |
| 3-bet % | 3-bet 的頻率 | Reg: 7-12%, Fish: 1-5% |
| Fold to 3-bet | 面對 3-bet 的 fold 率 | Reg: 55-65%, Fish: 70%+ |
| Fold to Cbet | 面對 c-bet 的 fold 率 | Reg: 50-60%, Fish: 65%+ |
| AF（Aggression Factor）| 主動攻擊因子 | >2 積極，<1 被動 |
| BTN steal % | BTN 位置的 steal 頻率 | Reg: 50-65%, Fish: 20-35% |

### HUD 的限制

- **MTT 中 sample size 小：** 一場 MTT 與某人的手數可能只有 30-50 手，統計不夠可靠
- **玩家調整：** 好的玩家在注意到你的打法後會調整
- **不適用所有平台：** GGPoker 不允許即時 HUD（有歷史數據查詢）；PokerStars 允許

**建議：** HUD 作為參考，結合現場觀察，不要完全依賴。

## Timing Tell（時間讀牌）

線上撲克的「tells」主要是 timing（行動速度）：

### 即時行動（快）

- 即時 check：通常是弱牌（決定已做，直接 check）
- 即時 bet：可能是強牌（或習慣性自動 bet）
- 即時 call：通常是中等手牌或 draw（願意繼續但不想 raise）

### 慢速行動（使用 time bank）

- 慢速 call：邊緣手牌，在 fold 和 call 之間猶豫
- 慢速 raise：強牌（故意慢打）或 semi-bluff（計算中）
- 慢速 fold：強牌放棄（如 set 面對 action，痛苦 fold）

### 注意事項

- Timing tells 的準確性遠低於現場 tells
- 很多玩家有固定的 timing 習慣（與手牌強弱無關）
- 使用 time bank 的頻率因人而異
- 不要完全依賴 timing，結合 range 分析

## 線上平台選擇

### GGPoker

**優點：**
- 最大的玩家群體（魚最多）
- 豐富的賽事（每日大型 MTT，WSOP 系列）
- PKO Bounty Builder 是主打格式
- 完善的衛星系統
- 介面現代，功能豐富（Deal 功能、insure、etc.）

**缺點：**
- 不允許即時 HUD（有歷史 HUD，但準確性較低）
- 軟體有時需要更多資源

### PokerStars

**優點：**
- 歷史最悠久，最大的賽事（WCOOP, SCOOP, EPT）
- 允許 HUD（部分限制）
- 軟體穩定，功能完整
- 玩家池廣泛

**缺點：**
- 相對更多的 reg（競爭更激烈）
- 一些功能需要付費

### 888poker

**優點：**
- 相對較軟的玩家群體
- 特定賽事的價值好

**缺點：**
- 玩家池相對小

### 策略建議

對於大多數玩家，**GGPoker 是首選**（最大的魚池、最豐富的賽事），**PokerStars 是重要補充**（最大賽事，WSOP 系列）。同時在兩個平台運作是職業玩家的標準配置。
