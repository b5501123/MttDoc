## 為什麼進步緩慢

### 「打牌時數的謬誤」

許多玩家相信：打了越多時間，自然會越進步。這個觀念是錯的。

**一個典型的停滯玩家的一週：**
- 週一：打 4 小時 MTT，輸了 3 個買入
- 週二：打 5 小時 MTT，贏了 1 個買入
- 週三：打 3 小時 MTT，早出局，輸 1 個買入
- 週四：休息
- 週五：打 6 小時 MTT，進了一個最終桌，贏 8 個買入
- 週六：打 5 小時 MTT，輸了 2 個買入
- 週日：打 4 小時 MTT，輸了 2 個買入
- 總計：打牌 27 小時，**複盤 0 分鐘**

這個玩家打了 27 小時，可能犯了 50 個可識別的錯誤，但一個都沒有學習到。下週他還是會犯同樣的 50 個錯誤。

### 學習沒有發生的三個原因

**原因 1：沒有標記（記錄的缺失）**

打牌中遇到困難決策時，大多數玩家的反應是：
- 糾結一下，做出決策
- 繼續打下一手牌
- 對局結束，把那手牌忘記

沒有標記，就沒有後續的複盤材料。一週後你已經完全不記得那手牌的細節。

**原因 2：問錯問題（複盤角度錯誤）**

即使有些玩家會複盤，他們常常問的是：
- 「我輸了對嗎？」
- 「對手是不是在詐唬？」
- 「河牌那張牌太倒霉了」

這些問題都在為「結果」找解釋，而非分析「決策」是否正確。

正確的問題是：
- 「在我做決策的那一刻，基於我的資訊，這個決策的 EV 是正的嗎？」
- 「我的範圍分析是否正確？」
- 「如果我重複這個情境 1000 次，這個決策會讓我盈利嗎？」

**原因 3：沒有提取可重複的原則**

就算你找到了一個錯誤，如果只是說「那手牌我打錯了」，下次遇到類似情境你仍然不知道該怎麼打。

有效的複盤必須提取「可重複應用的原則」——在 X 條件下，應該做 Y。

## 4步驟複盤框架

### 步驟 1：標記手牌

**什麼手牌值得標記？**

不是每一手牌都需要複盤。標記的原則是：「我不確定自己做了正確的決策」或「這個情況很不尋常」。

值得標記的情境：
- **邊緣決策：** 你在棄牌和跟注之間猶豫了超過 10 秒
- **大底池手牌：** 任何底池超過 30BB 的手牌
- **被動反擊（check-raise）情境：** 你或對手做了 check-raise
- **詐唬決策：** 你選擇了詐唬，特別是大底池詐唬
- **範圍優勢不清楚的情況：** 你不確定你的範圍相對於對手的優勢/劣勢
- **直覺告訴你「不對」但你還是做了：** 這些手牌最值得審查

**如何在打牌時標記？**

- **PokerStars：** 使用手牌歷史中的「加星號」功能
- **GGPoker：** 在遊戲中使用「備忘錄」標記
- **888Poker：** 在客戶端的歷史手牌中標記
- **離線筆記：** 打牌時在便利貼寫下手牌編號，例如「H#12345678 - 翻牌後 check-raise 決策」
- **簡短文字記錄：** 「BB 對抗 BTN 的 3-bet 底池，我的 KQ 在 K-high 牌面 check-raise 了」

**黃金標準：** 在打牌中，每小時至少標記 2～3 手值得複盤的牌。

---

### 步驟 2：重建決策點

複盤時，系統地重建每個決策點，而不是只看結果。

**四個街道（Streets）的分析框架：**

**翻牌前（Pre-flop）分析：**

問自己：
1. 我的位置是什麼？（UTG/MP/CO/BTN/SB/BB）
2. 前面的行動是什麼？（limpers/open/3-bet）
3. 我的疊碼（BB 數）是多少？
4. 我的手牌範圍應該是什麼？
5. 我的實際行動（fold/call/raise/all-in）是否符合這個範圍？

**具體例子：**
```
情境：40BB 疊碼，CO 位置，UTG open 2.5BB，我持有 AJs
問題：應該 fold/call/3-bet？
分析：
- 40BB 疊碼下，AJs 對 UTG open 的建議行動是 3-bet or fold
- 因為 40BB 的 SPR 在跟注後太低（跟注後剩 37.5BB 對底池 5.5BB = SPR ≈ 7）
- 但 3-bet 到 8-10BB 後，SPR 降到 2-3，我有 40BB 可以 all-in
- AJs 對 UTG open range 的 equity 約 55-60%
- 決策：3-bet 全押或 fold，不應該單純跟注
```

**翻牌（Flop）分析：**

問自己：
1. 牌面如何？（乾燥/濕潤/對子）
2. 底池大小和有效疊碼比（SPR）
3. 誰的範圍在這個牌面上更占優（range advantage）？
4. 我應該 check/bet？如果 bet，大小應是多少？
5. 面對對手的行動，我應該 fold/call/raise？

**轉牌（Turn）分析：**

轉牌的分析需要包含「牌面變化」：
1. 轉牌改變了誰的範圍優勢？
2. 如果是某種「警戒牌」（如完成了聽牌的牌），需要重新評估
3. 底池大小增加後，有效 SPR 如何變化？
4. 我的行動（check/bet）是否考慮了轉牌帶來的資訊？

**河牌（River）分析：**

河牌是最終決策，需要最完整的範圍分析：
1. 我的範圍在河牌的分布（強牌/薄價值牌/bluff）
2. 對手的可能範圍
3. 如果下注，對手的跟注頻率（calling frequency）
4. 如果 check，對手的下注頻率
5. 最優河牌策略是什麼？

---

### 步驟 3：問正確的問題

這是最重要的一步，也是最容易犯錯的地方。

**錯誤的問題（結果導向）：**
- 「我跟注了，結果輸了，我應該棄牌嗎？」
- 「對手是不是在詐唬我？」
- 「那張河牌太倒霉了，對嗎？」

這些問題的問題在於：你已經知道結果，然後用結果倒推決策，這叫「結果偏見」（outcome bias）。

**正確的問題（決策導向）：**

對每個決策點，問：

```
「在我做決策的那一刻（不是現在，而是當時），
基於我擁有的資訊，這個決策的期望值（EV）是正的嗎？」
```

具體的決策品質問題：

**翻牌前：**
- 「我的入場範圍是否符合 GTO 建議？」
- 「如果我 3-bet，我的 3-bet 範圍是否平衡（有足夠的 bluff 和 value）？」
- 「這個疊碼下，我的 push/fold 決策是否符合 ICM 計算？」

**翻牌後：**
- 「我的 C-bet 頻率是否過高/過低？」
- 「我的下注大小是否與我的策略目的一致？（保護？建底池？詐唬？）」
- 「面對 check-raise，我的決策是否考慮了對手的 check-raise 範圍？」

**詐唬決策：**
- 「我的詐唬是否有合理的 fold equity？（對手 fold 的機率 × 底池是否 > 下注成本）」
- 「我的詐唬牌手是否在這個牌面上有合理的詐唬範圍？（blockers、未打中的強手等）」

---

### 步驟 4：提取可重複應用的原則

每次複盤的最終產出應該是：**一個可以在未來類似情境中應用的具體規則**。

**不好的複盤結論：**
- 「那手牌我打錯了」
- 「下次要更謹慎」
- 「運氣太差了」

**好的複盤結論（具體原則）：**

例 1：
- 情境：翻牌後持有 top pair weak kicker，面對對手的大尺寸下注
- 錯誤決策：全部跟注到河牌
- 原則提取：「在底池限注情況下，top pair weak kicker 面對 75%+ 底池下注，應該考慮 fold 或 raise-fold，而非被動跟注。原因是對手的大尺寸下注往往代表強牌或強聽牌，而 TPWK 在不利牌面很少是最佳手牌。」

例 2：
- 情境：10-handed，SB 位置，CO open，我持有 Kxs（K5s）
- 錯誤決策：3-bet
- 原則提取：「SB 對 CO 的 3-bet 範圍中，K5s 通常不在標準 3-bet 範圍內（應 fold 或 call）。K5s 的 3-bet 效果不好，因為即使 flop 打中頂對，kicker 問題嚴重；同花子也不夠強。下次應 fold K5s 對 CO open（SB 位置）。」

**建立個人「原則手冊」：**

建議建立一個文件，記錄每次複盤提取的原則，格式如下：

```
[日期] [情境] → [錯誤做法] → [正確做法] → [底層原則]

例：
2026-03-15 | 25BB 疊碼，UTG push，我在 BB 持有 KJo | 跟注 | 應該棄牌 |
原則：KJo 在 25BB 疊碼下，對抗 UTG push range 的 equity 不足，需要約 40% 才值得跟，但 KJo 對 UTG push range 只有約 38% equity，略低於盈虧平衡。
```

每週整理這個手冊，每月回顧，確保這些原則真正被內化。

## 每周學習計劃模板

### 打牌時間 vs 學習時間的比例

**初學者（第一年）：** 建議 1:1（每打 1 小時，花 1 小時學習）
**中級玩家：** 建議 2:1（每打 2 小時，花 1 小時學習）
**高級玩家：** 建議 3:1（每打 3 小時，花 1 小時學習）

許多玩家過度打牌、學習不足，在沒有提高的情況下不斷重複相同的錯誤。

### 模板：每周 20 小時的分配（中級玩家）

| 時段 | 活動 | 時間 | 說明 |
|------|------|------|------|
| 週一晚 | 上週複盤 | 1.5 hr | 查看標記手牌，分析最關鍵的 3 手 |
| 週二晚 | MTT 打牌 | 3 hr | 邊打邊標記，不求結果求決策 |
| 週三晚 | Solver 學習 | 1.5 hr | 針對上週複盤發現的弱點練習 |
| 週四晚 | MTT 打牌 | 3 hr | 同週二 |
| 週五晚 | 影片/書籍學習 | 1.5 hr | 系統性學習新概念 |
| 週六白天 | MTT 打牌 | 4 hr | 正常 session |
| 週六晚 | 即時複盤 | 1 hr | 當天打牌的標記手牌複盤 |
| 週日白天 | MTT 打牌 | 3 hr | 正常 session |
| 週日晚 | 週總結 | 1 hr | 總結本週學習，設定下週重點 |
| **合計** | | **20 hr** | 打牌 13 hr，學習 7 hr |

### 每月目標設定框架

**技術目標（可量化）：**
- 本月要解決的具體漏洞（例：「翻牌後的 check-raise 頻率過低」）
- 本月要讀完的書籍章節
- 本月要用 solver 分析的情境數量（例：15 個不同場景）

**非技術目標：**
- 本月的停牌紀律執行情況
- 本月的複盤頻率（至少每次打牌後都做簡短複盤）

## 有效使用 Solver

### GTO Wizard 的最佳使用方式

GTO Wizard 提供了 MTT 場景的 GTO 解，但很多玩家使用方式錯誤。

**錯誤的使用方式：**
- 只記憶「翻牌後應該下注 33%」的結論，不理解為什麼
- 把 solver 當作「答案查詢機」，沒有主動思考
- 直接背誦 range，不理解底層原理

**正確的使用方式：**

**第一步：先自己分析，後查 solver**

在把手牌輸入 solver 之前，先自己回答：
1. 在這個翻牌面上，我應該如何行動？（C-bet/check？下注多大？）
2. 面對對手的 check-raise，我應該如何回應？
3. 我這樣判斷的理由是什麼？

然後才把情境輸入 solver，比較 solver 的建議和你的判斷。

**第二步：理解「為什麼」，而非只看「什麼」**

Solver 告訴你：「在 A♠7♣2♦ 翻牌面，CO vs BB，建議 C-bet 75% 頻率，下注 33% 底池」

你需要理解的是：
- 為什麼是 75% 頻率，不是 100% 或 50%？
- 為什麼是 33% 而不是 66%？
- 哪些具體手牌屬於 C-bet？哪些選擇 check？

**第三步：節選具體手牌做深入分析**

不要只看整體策略，而是選取你在實戰中遇到困難的具體手牌範圍分析。

例：
```
我在 CO 持有 KJo，翻牌是 A♠7♣2♦
問題：我應該 C-bet 嗎？如果 check，對手 bet 後我應該 fold/call/raise？

Solver 分析：
- KJo 在這個牌面通常選擇 C-bet（因為有兩張高牌保護）
- 但如果 check，面對小尺寸下注可以跟注，面對大尺寸下注應該 fold
- 原因：A-high 牌面對 BB 不利（BB 的範圍包含很多 Ax），KJo 沒有配對，
  只有後門同花和 BDSD，保護需求不高
```

### PioSolver 的深度使用

PioSolver 適合更深入的翻牌後分析（特別是 IP vs OOP 的多街策略）：

**適合用 PioSolver 分析的場景：**
- 3-bet 底池的翻牌後策略
- 深疊情況下的多街詐唬
- 河牌的 bluff 配比計算

**基本工作流程：**
1. 設定翻牌前範圍（雙方的入場範圍）
2. 輸入翻牌、轉牌、河牌
3. 跑解（run solve）
4. 分析特定手牌的策略分布
5. 理解整體範圍的策略模式

**工具：**

- GTO Wizard（進階版）：更複雜的場景
- Monker Solver（PLO 為主，但也用於 NLH 複雜場景）
- 找 study group：和同等或更高水準的玩家每週討論手牌

**目標：** 接近 GTO 打法的同時，識別並剝削對手的漏洞

### Coach 的選擇

什麼時候需要找 Coach？

- 你已經打了 6 個月以上，仍然有明顯的策略盲點
- 你的 ROI 停滯不前超過 3 個月
- 你有特定的情境（如 ICM spots，深疊 3-bet 底池）一直感到不確定

選擇 Coach 的標準：
1. 他們在你打的級別有可驗證的成績（HendonMob 或 SharkScope 數據）
2. 他們能解釋「為什麼」而不只是告訴你「什麼」
3. 他們有教學方法（不只是打給你看）
4. 試課後你感到有收穫，而非困惑

## 進步停滯的解決

### 診斷「進步停滯」

如果你感覺自己進步停滯，先診斷原因：

**問題一：你的複盤頻率不足嗎？**
- 每週複盤時間少於 2 小時
- 複盤只是「看看輸贏」，沒有系統分析
- 解決：立即建立每週複盤習慣（參考本章 4 步驟框架）

**問題二：你停留在「舒適圈」？**
- 每次打同樣的比賽類型，對同樣的對手
- 沒有主動接觸新的策略挑戰
- 解決：有意識地挑戰你的弱點場景（例如：如果你不擅長 3-bet 底池，強迫自己更常打這種情境）

**問題三：你的學習是「被動的」嗎？**
- 只看影片，不分析
- 把 solver 的輸出直接記憶，不理解
- 解決：每次學習後，用自己的話解釋剛剛學到的原則

**問題四：你有「知識詛咒」嗎？**
- 你知道很多「理論」，但在實戰中無法應用
- 複盤時你能說出正確答案，但打牌時卻做錯
- 解決：把知識轉換成「IF-THEN 規則」，例如：
  - IF 疊碼 < 25BB，AND 在 CO/BTN，THEN push range 包含 A8o+, Kxs, 78s+
  - IF 牌面是 三低牌, AND 我是 preflop agressor, THEN C-bet 頻率 > 60%

**問題五：你的「自我評估」準確嗎？**
- 很多玩家認為自己已經是「中高級」，但實際上仍有初級錯誤
- 解決：讓更好的玩家 review 你的打法，或使用 solver 驗證你認為「肯定正確」的決策
- 謙遜地接受反饋是進步最快的方式

### 常見停滯原因清單

**技術層面：**
- [ ] 翻牌前 range 不平衡（太緊或太寬）
- [ ] C-bet 頻率和大小不符合牌面
- [ ] 不知道如何構建 check-raise range
- [ ] 河牌詐唬頻率過高或過低
- [ ] ICM 計算不準確（特別是泡沫圈和 FT 策略）

**學習習慣層面：**
- [ ] 沒有系統的複盤習慣
- [ ] 沒有追蹤自己的進步指標
- [ ] 學習資源選擇不當（太高/太低水準）
- [ ] 沒有找到 study partner 或 coach

**心理層面：**
- [ ] 結果導向，影響複盤客觀性
- [ ] 傲慢，認為自己知道的已經足夠
- [ ] 恐懼改變，不願意調整熟悉的策略

### 恢復進步的具體行動計劃

**第一週：診斷**
1. 找出你最近 100 手標記的手牌
2. 請 solver 或更好的玩家分析其中 20 手
3. 找出重複出現的錯誤類型

**第二週：聚焦學習**
1. 針對最嚴重的錯誤類型，找 2～3 個針對性資源
2. 每天 30 分鐘的刻意練習（專注於這個弱點）
3. 打牌時特別注意這個特定場景

**第三週：整合**
1. 繼續打牌，但帶著「今天我要在 X 場景做出更好的決策」的具體目標
2. 每次打牌後，立即複盤 X 場景的決策
3. 記錄進步情況

**第四週：評估和調整**
1. 評估這個月的進步：這個場景的決策比一個月前更好嗎？
2. 如果是，找下一個最大的弱點
3. 如果不是，重新診斷——可能需要更基礎的學習

## 學習者心態的長期培養

### 「永遠是學生」的信念

最好的撲克玩家都保持持續學習的心態，哪怕他們已經是世界頂尖。

Phil Ivey 在成為傳奇之後，仍然和同時代的頂尖玩家進行大量的手牌討論。Bryn Kenney 在多個 GTO 求解工具出現後，花費大量時間重新學習。

**培養學習者心態的方法：**

1. **把失敗視為資料：** 每次輸錢都是一次「學習事件」，而非打擊
2. **主動尋求反饋：** 不要等別人告訴你你的錯誤，主動去找
3. **量化你的學習：** 每個月結束時，你比上個月多懂什麼？
4. **接受「我不知道」：** 遇到不確定的情況，承認不確定比假裝確定更有利

### 實踐清單

每次打牌結束後（5 分鐘）：
- [ ] 標記今天最值得複盤的 3 手牌
- [ ] 用一句話描述今天的決策品質

每週複盤（90 分鐘）：
- [ ] 分析標記的手牌
- [ ] 更新「原則手冊」
- [ ] 設定下週學習重點

每月評估（1 小時）：
- [ ] 計算本月 ROI 和場次
- [ ] 回顧本月的學習目標完成情況
- [ ] 設定下月目標
