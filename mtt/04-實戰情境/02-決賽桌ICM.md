# 決賽桌 ICM：Final Table 的名次博弈

## FT 的 ICM 環境

進入決賽桌（Final Table，FT），每個淘汰都有顯著的獎金差距。這讓 ICM 壓力達到 MTT 的最高點（直到剩 2 人後消失）。

典型的 FT 獎金結構（10人 FT，總 prize pool $10,000）：

| 名次 | 獎金 | ICM 差距 |
|------|------|---------|
| 1st | $3,000 | 1st vs 2nd: $1,000 |
| 2nd | $2,000 | 2nd vs 3rd: $600 |
| 3rd | $1,400 | 3rd vs 4th: $400 |
| 4th | $1,000 | 4th vs 5th: $200 |
| 5th | $800 | |
| 6th | $600 | |
| 7th | $500 | |
| 8th | $400 | |
| 9th | $300 | |

每多活一名，都有具體的獎金收益。

---

## FT 各人數的 ICM 壓力

### 9-10 人（FT 剛開始）

ICM 壓力相對溫和：
- 名次差距存在，但還沒到「命懸一線」的程度
- 正確策略：繼續積累籌碼，但開始注意相對籌碼量
- 短疊仍需積極 push，不能「只求混名次」

### 6-7 人（中期 FT）

ICM 壓力顯著增加：
- 每個出局的名次差距更大
- 中疊的 ICM 壓力最高（類似 bubble 的中疊情境）
- 大疊可以施壓，應積極利用

### 4-5 人（後期 FT）

**ICM 壓力達到峰值：**
- 每個名次差距最大（通常 3-4 名的獎金差距超過 10-20%）
- 非常保守的中疊是正確的（即使 Chip EV 說 call，ICM 可能說 fold）
- 大疊的施壓能力最強

### 3 人（最後三人）

ICM 仍然非常重要，但有一個特殊點：
- 3rd 和 2nd 的差距可能高達 50% 的獎金
- 短疊的「ICM 自殺」最危險（跟注輸了直接第3名）

### 2 人（Heads-Up）

ICM 消失：
- 剩 2 人時，不再有中間名次，第 1 名拿最多、第 2 名拿固定獎金
- 決策回歸純 Chip EV
- Push/call range 大幅放寬

## ICM 自殺的例子

**場景：4 人 FT，獎金結構：1st $10,000 / 2nd $6,000 / 3rd $4,000 / 4th $2,000**

籌碼分佈：
- 你（Player A）：120,000
- Player B：80,000
- Player C：60,000
- Player D：40,000

**Player B push all-in 80,000，到你。**

你有 AJo，勝率約 55%（假設 B 的 push range 是 QQ- KK- AA 等強牌，可能低於 55%）。

**Chip EV：** 呼喚是正 EV（55% 勝率）

**ICM 計算：**
- 你現在 ICM equity ≈ $5,800（最大疊）
- 贏了（55%）：200,000 籌碼，ICM equity ≈ $7,200
- 輸了（45%）：40,000 籌碼（還剩），ICM equity ≈ $3,400

```
Call EV = 55% × $7,200 + 45% × $3,400 = $3,960 + $1,530 = $5,490
Fold EV ≈ $5,800（維持現有 ICM equity）
```

**Call 的 ICM EV 比 Fold 低 $310。**

即使 55% 勝率，fold 更好！這就是「ICM 自殺」：用一個 Chip EV 正的 call 來損害自己的獎金期望值。

## FT 的籌碼動態

FT 的桌面動態和常規牌局不同：

**觀察每個人的 ICM 壓力：**
- 誰是短疊？他們更需要 double up，push range 更廣
- 誰是中疊？他們 ICM 壓力最大，對你的 push 更容易 fold
- 誰是大疊（除你之外）？他們可能也在施壓，需要注意

**利用差異化的 ICM 壓力：**
- 大疊優先打 3-bet 在中疊的 SB/BB 上
- 避免在不必要時和另一個大疊衝突
- 偶爾讓兩個中疊互打（不參與讓他們消耗）

**FT 中的 Chip EV vs ICM 博弈：**

| 人數 | Chip EV 的相對重要性 | ICM 的相對重要性 |
|------|---------------------|----------------|
| 10 | 60% | 40% |
| 7 | 50% | 50% |
| 5 | 35% | 65% |
| 3 | 30% | 70% |
| 2 | 100% | 0% |

## 線上 FT 特殊考量

### 疲勞管理

大型線上 MTT 的 FT 可能在深夜（台灣時間 GMT+8，歐美大賽可能在凌晨 1-3 點開始 FT）。疲勞會顯著降低決策品質，尤其是 ICM 計算。

**建議：**
- 提前準備：比賽前充分休息
- FT 前的準備：喝水、站起來活動，保持清醒
- 減少多桌：FT 時應關閉其他桌，100% 專注
- 設定時間限制提醒：不要讓比賽拖到嚴重疲勞的狀態

### Deal 協議（Chop/ICM Deal）

很多線上平台提供協議功能：

**GGPoker：**
有 built-in deal 功能，可以在 FT 期間提出 ICM deal 或平分剩餘獎金。

**PokerStars：**
Tournament Director 可以幫助協調 deal，玩家可以申請 deal。

**何時考慮 Deal：**
1. 你是大疊，場面有利於你時談 deal 有優勢
2. 高度疲勞或身體不適，繼續打下去決策品質會下降
3. 籌碼差距不大，ICM deal 對各方都接近公平

**ICM Deal 計算：**
ICM deal 是按當前籌碼量計算每人的 ICM equity，以此分配獎金。這是最常見也最公平的 deal 方式。

**Deal 談判技巧：**
- 不要主動提出 deal（讓別人先提，你可以接受更好的條件）
- 如果你是大疊，稍微高於 ICM equity 是合理的（因為你有位置優勢）
- 不要因為疲勞急於接受不公平的 deal

### 線上 FT 的心態管理

FT 的壓力可能讓玩家做出不理性的決策：
- **Don't tap the aquarium（不要打擊魚玩家）：** FT 上可能有大魚，不要讓情緒影響你對他們的策略
- **每手獨立：** 上一手的輸贏不影響這一手的正確策略
- **記住 ICM：** FT 上折疊強牌是 OK 的，只要 ICM 說 fold
