# MTT 玩家類型與對付策略

> 章節：4-4 | 難度：⭐⭐⭐ | 建議先修：第三章、4-1 Bubble 打法

---

## 本章學習目標

1. 掌握 MTT 中六種核心玩家類型的識別方式
2. 理解 ICM 壓力如何改變各類型玩家的行為
3. 對每種類型建立具體的翻牌前和翻牌後剝削策略

---

## 四象限框架

所有玩家基本上可以用兩個維度描述：**入局頻率（緊/寬）** 和 **下注積極程度（強/弱）**。

```
                  被動（Passive）              主動（Aggressive）
  緊（Tight）  │ Nit / 緊弱                  │ TAG / 緊強
               │ VPIP <15%, PFR <8%          │ VPIP 15-25%, PFR 13-22%
               │ 弱點：翻牌前和後都過度 fold  │ 弱點：偏少，打 GTO 應對
               │ 利用：偷盲、連續 barrel      │ 利用：位置施壓，不亂 bluff
  ─────────────┼─────────────────────────────┼──────────────────────────────
  寬（Loose）  │ Calling Station / 寬弱       │ LAG / 寬強
               │ VPIP 40%+, PFR <12%        │ VPIP 30%+, PFR 22%+
               │ 弱點：不 fold，亂 call draw  │ 弱點：range 廣，被 value 打爆
               │ 利用：薄 value，停止 bluff   │ 利用：value 3-bet，打大底池
```

**MTT 特殊類型：**
- **Nitty Reg**（緊強偏保守）：技術有，但 ICM 恐懼讓他過度 fold
- **Maniac**（極端 LAG）：Bubble 時會做出 chip EV 正但 ICM EV 負的決策

## 類型一：TAG（Tight Aggressive，緊強）

### 特徵

```
HUD 參考：VPIP 15-25%, PFR 13-22%, 3-bet% 7-12%, Fold to 3-bet 55-65%

行為特徵：
  - 入局牌型優質，入局後積極下注（raise/3-bet，不 limp）
  - 位置意識強：IP 積極施壓，OOP 保守
  - 翻牌後有計劃：有 c-bet 計劃，也有 check 計劃（含陷阱和放棄）
  - 了解 ICM，Bubble 時適度收緊（但不過度）
  - 會依據板面調整 c-bet 頻率（乾燥板高，濕潤板低）
```

### 識別方式

- VPIP 和 PFR 差距小（≤ 5%），很少 limp
- 面對 3-bet 的反應多樣（有時 4-bet，有時 call，有時 fold）
- 翻牌後下注尺寸合理（底池的 33-75%，不是固定金額）

### 對付策略

**翻牌前：**
```
✓ 在位置上可以輕微放寬 3-bet range（他們的 fold to 3-bet 合理，55-65%）
✓ 3-bet bluff 用手牌：A2s-A5s、suited connectors（有 blockers 和 equity）
✓ 對他們的 steal，BB defend 用標準 GTO range
✗ 不要用完全無 equity 的牌 3-bet bluff（他們不怕，會 call 或 4-bet）
```

**翻牌後：**
```
✓ 在位置上對他們施壓（他們 OOP 比較保守）
✓ 面對他們的 c-bet，可以 float IP（有計劃在 turn 施壓）
✗ 不要在他們 bet 後用弱牌 river call（他們的 value range 真實）
✗ 不要輕易 bluff-raise 他們的 value bet（他們懂得 call down）
```

**MTT/ICM 特殊考量：**
```
Bubble 時：TAG 的策略在 Bubble 會稍微收緊，但不過度
  → 你對他們的 steal 可以維持，但大底池要謹慎
FT 時：TAG 的 ICM 意識強，他們的 fold 在 FT 是真的有 value 的 fold
  → 不要誤判他們的 fold 為弱點
```

## 類型二：LAG（Loose Aggressive，寬強）

### 特徵

```
HUD 參考：VPIP 30%+, PFR 22%+, 3-bet% 12%+, Fold to 3-bet <50%

行為特徵：
  - 廣泛的 open range，頻繁 steal（BTN steal% 70%+）
  - 積極 3-bet，包含很多半詐唬和純詐唬
  - 翻牌後頻繁 c-bet 和多桶 barrel
  - 在 Bubble 仍然積極（知道大疊的 Fold Equity 價值）
  - 用位置和積極性彌補手牌的弱點
```

### 識別方式

- VPIP 和 PFR 都明顯偏高
- 頻繁從 BTN、CO 甚至 HJ open 和 3-bet
- 翻牌後很少 check-fold，幾乎都 bet 或 raise

### 對付策略

**翻牌前：**
```
✓ Value 3-bet 範圍放寬：KK, QQ, JJ, AK, AQ（甚至 TT, AJ suited）
  理由：他們 call 3-bet 的頻率高，value range 報酬更高
✓ 4-bet bluff 頻率正常（不需要特別增加，他們 5-bet 的頻率也高）
✓ 對他們的 3-bet，call 比 fold 更好（他們 range 廣，IP 可以 exploit 翻牌後）
✗ 不要用弱牌 3-bet bluff（他們不怕，Fold to 3-bet < 50%）
```

**翻牌後：**
```
✓ 在他們 c-bet 後用 strong draw raise（他們 c-bet range 廣，含大量弱牌）
✓ 用 Nut 或 Near-Nut 打大底池（他們 range 廣讓你的 value 更有利）
✓ 面對他們的 turn/river barrel，有 medium-strong hand 可以 call down
✗ 不要試圖 bluff-raise 他們（他們 fold 少，bluff 是 -EV）
```

**MTT/ICM 特殊考量：**
```
Bubble 時：LAG 是最難應對的玩家，因為他們知道用 Fold Equity
  → 最佳應對：等強牌，讓他們付錢；不要 bluff 他們
FT 時：LAG 的積極性在 FT 可能帶來 ICM 錯誤（push too wide）
  → 識別這個，用強牌 call 他們的 all-in 施壓
```

## 類型三：Nit（Tight Passive，緊弱）

### 特徵

```
HUD 參考：VPIP <15%, PFR <8%, Fold to Steal >75%, Fold to 3-bet >70%

行為特徵：
  - 只打超強牌（AA, KK, QQ, AK，偶爾 JJ, AQ）
  - 翻牌前遇到 aggression 就 fold
  - 翻牌後只 c-bet value，不 bluff
  - Bubble 時極度保守（ICM 恐懼放大他們的 Nit 傾向）
  - 在位置不利時幾乎不入局
```

### 識別方式

- VPIP 極低（<15%），甚至 BTN 都不 steal
- 遇到 3-bet 幾乎每次都 fold
- 翻牌後一有 c-bet 就 fold，很少 check-raise

### 對付策略

**翻牌前：**
```
✓ BTN、CO 幾乎所有牌都可以 open（他們的 defend range 極窄）
✓ 3-bet bluff 大量增加：他們 fold to 3-bet >70%，bluff EV 非常高
✓ Squeeze（多人底池）對他們特別有效（他們不喜歡打 3-way）
✓ Bubble 時向他們施壓（ICM 恐懼讓他們 fold 更多）
```

**翻牌後：**
```
✓ 幾乎所有牌面都可以 c-bet（他們翻牌後也 fold 很多）
✓ 連續多桶 barrel（他們遇到持續 aggression 就放棄）
✓ Turn 施壓（他們的 check 通常代表弱牌，可以 bluff）
✗ 當他們 raise 或 3-bet 時：極度尊重（他們只有 Nuts 才這樣做）
✗ 不要用邊緣牌對他們 call river（他們的 river bet = 強牌）
```

**MTT/ICM 特殊考量：**
```
Bubble 時：Nit 是最容易在 Bubble 被打爛的類型
  → 你是大疊？每手都可以用 ante 施壓他們的盲注
  → 他們是中疊？他們不會在 Bubble 做任何 flip
FT 時：Nit 在 FT 後期（剩 3-4 人）會更積極，因為 ICM EV 已經很高
  → 識別這個轉變，不要繼續用 Bubble 時的方式 bluff 他們
注意：等到他們「打出強牌信號」時，要能放棄你的 bluff（他們不會亂打）
```

## 類型四：Calling Station（Loose Passive，寬弱）

### 特徵

```
HUD 參考：VPIP 40%+, PFR <12%, Fold to C-bet <35%, WTSD% 55%+

行為特徵：
  - 過度 call，很少主動加注
  - 對 bluff 免疫（不相信你有強牌）
  - 追各種 draw，包括非 nut draw 和 gutshot
  - 不了解 pot odds 或 implied odds 的概念
  - 在 Bubble 時常做出 chip EV 決策（不懂 ICM）
  - 下注尺寸常用固定金額（不考慮底池比例）
```

### 識別方式

- VPIP 遠高於 PFR（差距 30%+），大量 limp 進入底池
- 打到 showdown 頻率非常高（WTSD% 55%+）
- 面對 c-bet 很少 fold，常看下一張牌

### 對付策略

**翻牌前：**
```
✓ Isolate（隔離）他們：對他們的 limp，用中等以上手牌 raise 到 4-5bb
  目的：頭對頭對他們打，避免被其他玩家夾住
✓ 放棄 3-bet bluff（他們 call 一切，bluff 無效）
✓ Value 3-bet 增加：TT+, AQ+ 都可以 3-bet for pure value
```

**翻牌後：**
```
✓ 薄 value bet：Two Pair、低 Set、Top Pair 好踢腳都可以積極下注
✓ 多桶 value barrel：如果你有強牌，每條街都下注
✓ 完全停止 bluff（0% bluff 頻率），他們 call 一切
✓ 底池大小要適當放大（他們 call，所以 value 金額越高越好）
✗ 不要和他們打 draw vs draw 大底池（draw 結果無法控制）
✗ 不要試圖「讓他們明白」自己的 call 是錯的（他們不會改變）
```

**MTT/ICM 特殊考量：**
```
Bubble 時：Calling Station 常在 Bubble 做 ICM 錯誤（call 太寬）
  → 對你有利：用強牌在 Bubble 打大底池，他們會 call 錯誤
  → 注意：他們的 call 可能讓你 bust（即使你 +EV），要確保 roll 夠
FT 時：他們在 FT 也不改變行為，繼續 call
  → FT 中 value bet 他們更重要，因為籌碼更值錢
```

## 類型五：Nitty Reg（保守型職業）

### 特徵

```
HUD 參考：VPIP 18-22%, PFR 14-18%, Fold to 3-bet 65-75%, Fold to C-bet 60-70%

介於 TAG 和 Nit 之間。技術有，但有系統性的「過度保守」問題。

行為特徵：
  - 翻牌前選牌合理，但 Fold to 3-bet 偏高（不想打大底池）
  - 翻牌後大量 check-fold（對 c-bet 過度尊重）
  - 沒有充分利用自己的位置優勢（BTN steal 偏少）
  - Bubble 時更保守（ICM 放大本已存在的過度 fold 傾向）
  - 3-bet range 過緊（只有超強牌才 3-bet）
```

### 對付策略

**翻牌前：**
```
✓ 3-bet bluff 頻率增加（他們 Fold to 3-bet 65-75%，bluff EV 很高）
  特別好的位置：CO vs BTN open，BTN vs CO open
✓ BTN steal 積極化（他們在 BB 的 defend range 窄）
✓ Squeeze 有效（他們不想打多人 3-bet 底池）
```

**翻牌後：**
```
✓ 頻繁 c-bet（他們 Fold to C-bet 60-70%，高於 GTO 的 50-55%）
✓ Turn barrel（他們 check-call 翻牌後，turn 再 bet 他們容易 fold）
✓ 不需要太複雜的線路，簡單的「bet-bet-bet」就能拿到底池
✗ 注意：他們如果 raise 或 re-raise，要給予尊重（他們有真實強牌）
```

**MTT/ICM 特殊考量：**
```
Bubble 時：Nitty Reg 在 Bubble 是最容易被欺負的玩家
  → 最佳利用期：Bubble 的前半段（ICM 壓力最大時）
  → 他們會 fold 很多有價值的手牌（KQ, JJ 等）
FT 時：他們在 FT 剩少數人時才會稍微放開
  → 在 FT 早期（6-9人）繼續用 Bubble 策略對他們
```

## 類型六：Maniac（極端 LAG，瘋狂激進）

### 特徵

```
HUD 參考：VPIP 50%+, PFR 40%+, 3-bet% 20%+

極端版的 LAG。相比真正的 LAG（知道自己在做什麼），Maniac 常做出 chip EV 正但 ICM EV 極負的決策。

行為特徵：
  - 幾乎每手都入局，頻繁 3-bet 和 4-bet
  - 不在乎 ICM（Bubble 時還是狂 bluff）
  - 下注尺寸常常過大（over-bet 很多）
  - 在翻牌後幾乎每次都下注，不管牌面對他是否有利
  - 籌碼波動劇烈（要不快速累積，要不快速 bust）
```

### 對付策略

**翻牌前：**
```
✓ 等強牌讓他們付錢（KK+, AK 的 value 極高）
✓ 4-bet for value 範圍放寬：QQ+ 都可以 4-bet for value（他們 5-bet 很寬）
✓ 在他們後面的位置可以設陷阱（limp-reraise 強牌）
✗ 不要和他們打 bluff 戰（他們不在乎，Fold Equity 幾乎為零）
```

**翻牌後：**
```
✓ 用強牌 check-raise（讓他們 bet，你再加注）
✓ 不要慢打：Nut 手牌直接積極下注，讓他們付錢
✓ 用 medium hand 的 call down（他們 bluff 頻率很高）
✗ 不要試圖 bluff 他們（他們 call 一切）
```

**MTT/ICM 特殊考量：**
```
Bubble 時：Maniac 在 Bubble 做出嚴重 ICM 錯誤，這對你有利
  → 讓他們在 Bubble 做錯誤的 all-in，你用強牌 call
  → 不要被他們的積極性嚇到，計算清楚再行動
  → 注意：他們可能意外地贏到籌碼，成為 Bubble 的大疊威脅
FT 時：他們在 FT 是最難處理的對手，但也是 EV 最高的機會
  → 等強牌，讓 ICM EV 和 Chip EV 都站在你這邊
```

## 綜合：不同階段對手行為變化

### 各類型在 MTT 不同階段的行為

| 玩家類型 | 深疊期（100bb+） | 中疊期（30-60bb） | 短疊期（<20bb） | Bubble | FT |
|---------|----------------|-----------------|--------------|--------|-----|
| TAG | 標準 GTO | 稍微收緊 | Push/Fold 精確 | 適度調整 | ICM 意識強 |
| LAG | 積極施壓 | 仍然積極 | 積極 push | 仍然積極 | 可能有 ICM 錯誤 |
| Nit | 極度保守 | 更保守 | 只 push AA/KK | 幾乎不動 | 剩少數人才放開 |
| Calling Station | 大量 call draw | 仍然 call | 會 call flip | ICM 錯誤 call | FT 也 call |
| Nitty Reg | 合理保守 | 偏保守 | Push 偏緊 | **最容易被欺負** | 早期保守 |
| Maniac | 極端積極 | 極端積極 | 亂 push | ICM 錯誤最多 | 難以預測 |

## 桌面讀牌：快速識別（無 HUD 時）

### 前 10 手觀察要點

```
1. 入局頻率
   每手都入局 → Calling Station 或 Maniac
   很少入局（<3 手/輪）→ Nit 或 TAG

2. 入局方式
   頻繁 limp → Calling Station 或 Recreational
   幾乎都 raise → TAG、LAG 或 Maniac

3. 面對 c-bet 的反應
   幾乎都 fold → Nit 或 Nitty Reg（可以增加 bluff）
   幾乎都 call → Calling Station（停止 bluff，增加 value）
   頻繁 raise → LAG 或 Maniac

4. 3-bet 行為
   沒有 3-bet 過 → Nit 或 Calling Station
   偶爾 3-bet（看起來有強牌）→ Nitty Reg 或 TAG
   頻繁 3-bet → LAG 或 Maniac

5. Bubble 行為
   Bubble 時沉默、不動 → Nit 或 Nitty Reg（最大利用期）
   Bubble 時仍然積極 → LAG 或 Maniac（等強牌）
```

### 快速決策表

| 觀察到的行為 | 可能類型 | 立即對策 |
|------------|---------|---------|
| 每手 limp，很少 raise | Calling Station | Isolate，薄 value，0% bluff |
| BTN 也不 open | Nit | 大量偷盲，3-bet bluff |
| 3-bet 很多手牌 | LAG / Maniac | 等強牌，value 3-bet |
| 下注精確，入局不多不少 | TAG / Reg | 打 GTO，位置施壓 |
| Fold to 3-bet 後又 limp | Nitty Reg | 3-bet bluff，翻牌後 barrel |
| Over-bet，不在乎底池大小 | Maniac | 等 Nuts，check-raise |

## 本章重點回顧

1. **四象限**：TAG（緊強）、LAG（寬強）、Nit（緊弱）、Calling Station（寬弱）是基礎框架。
2. **MTT 特有**：Nitty Reg 和 Maniac 是 MTT 中常見的特殊類型，ICM 壓力放大他們的弱點。
3. **ICM 與玩家類型**：Nit 在 Bubble 最容易被利用；Calling Station 在任何階段都是 value 的來源；LAG 在 FT 可能做 ICM 錯誤。
4. **核心對付原則**：Nit/Nitty Reg → 偷盲和 bluff；Calling Station/Maniac → 等強牌 value；TAG → GTO；LAG → value 3-bet 和打大底池。
5. **無 HUD 識別**：前 10 手的入局方式、面對 c-bet 的反應、Bubble 行為是最快的識別方式。
