# 河牌策略：MTT 終局決策

## 前言：河牌的特殊性

河牌（River）是德州撲克中最特殊的一條街。當最後一張公牌亮出後，所有不確定性已經消除——牌面不再改變，手牌強度已經固定。每一個河牌決策都是最終決策，沒有退路，沒有「等下一張牌看看」的機會。

這種終局性讓河牌成為撲克中 EV 差異最大的地方。一個正確的河牌 bet sizing 決策，可能比整個翻牌前策略更影響你的長期勝率。

### 河牌決策的三大核心原則

**原則一：沒有保護需求**
翻牌和轉牌需要考慮保護（protection），因為對手可能在後面的街抽到更好的牌。但河牌上，所有的牌都已經亮出，你不需要「保護」你的強牌——只需要最大化從這手牌能得到的 EV。

**原則二：Range 極化（Polarization）最重要**
在河牌上，GTO 策略趨向高度極化。你的下注 range 應該由兩類牌組成：
1. 非常強的牌（value bet）
2. 已無法贏得 showdown 的牌（bluff）

中等強度的牌（中對、二對等）通常採用 check/showdown 策略，因為這類牌既不夠強做大注 value，又太有價值來做 bluff 犧牲。

**原則三：Sizing 與 Range 的一致性**
河牌的 bet size 必須與你宣稱的 range 一致。如果你用大注（overbet），對手會預期你的 range 非常強或非常弱（極化）；如果你用小注，range 應該更寬廣（uncapped 但不極化）。

## 第一節：河牌 Value Bet

### 1.1 什麼是 Value Bet？

Value bet 是指你下注的目的是讓被對手較差的手牌 call，從而盈利。在河牌上，value bet 的核心問題是：**對手的 call range 中，有多少比你弱？**

如果你認為對手 call 的手牌中有超過 50% 比你弱，下注就有 value。

### 1.2 Thin Value Bet（薄 value）

「Thin value bet」指的是對手 call range 中，只有接近 50-55% 的手牌比你弱的情況下仍然下注。這是更進階的技巧，需要精確的對手 range 讀取。

**適合 thin value bet 的情況：**

1. **對手是 calling station（愛跟牌的玩家）**
   - 這類玩家 call range 非常寬，任何配對、任何花色牌都可能 call
   - 即使你只有中等強度的牌，對他們下注也有薄 value

2. **牌面有很多 bluff 可能（draw-heavy boards）**
   - 如果牌面有很多 flush draw 和 straight draw 可能，對手更可能 call 你的 thin value bet，因為他們認為你可能在 bluff

3. **你有強於平均水平的中強牌**
   - 例如：牌面 A-7-2-9-3（rainbow，無同花），你有 KK，對手 range 有很多 Ax 手牌
   - KK 不是 nuts，但在這個牌面對手很多 Ax 比你弱

**具體例子：**

```
場景：6-max MTT，盲注 500/1000，有效籌碼 25,000
位置：你在 BTN（button），對手在 BB
翻牌前：BB 跟注，進入翻牌
翻牌：A♠ 7♦ 2♣（pot 2,200）
轉牌：9♥（你 C-bet 1,400，對手 call，pot 5,000）
河牌：3♠（pot 5,000）

你的手牌：K♠ K♥
```

這裡你有 KK，在 A-high 牌面。對手的 call range 在翻牌和轉牌後可能包含：
- 中等 Ax（A5, A6, A4 等） - 這些手牌比你弱
- 弱 pair（77, 22 等中的一些） - 比你弱
- 有些可能有 QQ, JJ, TT - 比你弱
- 但也有 AA, AK, A9, A7 - 比你強

在這個情況下，small value bet（比如 1/3 pot，1,667）是可以考慮的 thin value，因為對手的 call range 中有相當多的弱 Ax 和中對。

### 1.3 Value Bet Sizing：河牌用大還是小？

河牌 value bet sizing 是一個複雜的決策，取決於**對手 call range 的寬度**。

**核心邏輯：**
- 如果對手的 call range 很寬（愛跟牌），用**大注**：對手用更多弱牌 call，你的強牌賺更多
- 如果對手的 call range 很窄（只用強牌 call），用**小注**：確保你的 value bet 被 call，不要嚇跑對手

**不同 sizing 的使用場景：**

| Sizing | 使用時機 |
|--------|---------|
| 1/3 pot | 薄 value，希望對手用弱牌 call；或希望 block bet 防止被 raise |
| 1/2 pot | 標準 value，對手有中等強度牌的 call range |
| 2/3 pot | 強 value，牌面利於你，對手可能有強但比你弱的牌 |
| Full pot | 強 value，極化 range，對手有強牌可能 call |
| 1.5x pot（overbet） | 超強 value，對手有強牌但比你弱，讓他們付出最高代價 |

**實際例子——選擇正確 sizing：**

```
場景：你在 CO，對手在 BB
翻牌前：你 raise，BB call
牌面：K♥ Q♣ J♦ - 7♠ - 2♥（五張公牌）

你的手牌：A♠ T♠（Broadway 順子）
```

在這個牌面，你有 broadway 順子（A-K-Q-J-T），這是非常強的手牌。

對手的 range 在這個牌面可能有：
- KK（set，比你強）
- QQ（set，比你強）
- KQ（兩對，比你弱）
- KJ（兩對，比你弱）
- QJ（兩對，比你弱）
- 可能有一些 AK、AT（都比你弱）
- 有些玩家可能有 AJ（second nut straight，比你弱）

注意對手有 KK 和 QQ 這些非常強的牌（但比你弱），所以你應該使用大注或 overbet：**75-100% pot 的 value bet**。

為什麼不用小注？因為用小注，你放棄了對手用 KK/QQ set 跟注所帶來的龐大 EV。

### 1.4 Overbet for Value：何時用 125-150% Pot

Overbet for value 是最高級的 value bet 技術，適用於特定條件。

**適合 overbet value 的條件：**

1. **你有 nuts 或接近 nuts**
   - 你的牌強到不需要保護，且你想讓對手「付最多」

2. **對手可能有弱強牌（second-best hands）**
   - 對手有 KK，但你有 AA
   - 對手有順子，但你有 flush
   - 對手有 set，但你有 full house

3. **牌面有很多 bluff 的可能性（支持你的 overbet range 故事）**
   - 如果牌面 draw-heavy，你的 overbet 更可信，因為看起來像 bluff

4. **底池不大但對手籌碼深**
   - Overbet 在深疊時更有意義，因為可以拿到更多籌碼

**具體例子：**

```
場景：MTT 深疊，500bb 有效籌碼
你在 BTN，對手在 BB
翻牌前：你 raise 2.5bb，BB call

翻牌：A♦ K♦ 9♦（pot 5.5bb）
- 你 C-bet 4bb（BB call）

轉牌：2♣（pot 13.5bb）
- check / check

河牌：T♦（pot 13.5bb）
你的手牌：Q♦ J♦（皇家同花順，最強的手牌！）
```

對手可能有的牌：
- 任何 A♦ x（nut flush 比你弱）
- K♦ x（flush）
- 可能有 AK（強兩對）

在這個情況下，overbet（150% pot 或更多）完全合理，因為：
- 你有皇家同花順，無法被打敗
- 對手可能有 A♦ K♦ 這樣的超強牌，他們一定會 call overbet
- 用小注反而「少賺」

### 1.5 常見 Value Bet 錯誤

**錯誤一：河牌 value bet 太小，被 raise 後很難受**

很多玩家在河牌用 small bet（1/4 pot 或 1/3 pot），認為這樣「安全」。但問題是：
- 如果你用小注 value bet，你的 range 看起來像 thin value 或 bluff catch
- 對手看到你用小注，更容易用強牌 raise
- 結果：你的中強牌 value bet 被對手的超強牌 raise，你必須 fold，損失 value 且支付了 raise

**正確做法：** 如果你用小注，必須願意在被 raise 後 call，或者直接用更大的注讓對手難以 raise bluff。

**錯誤二：河牌 value bet 太大，嚇跑對手**

相反地，新手常在有強牌時用超大注（比如 2x pot），結果對手的所有弱牌都 fold，只有超強牌才 call——而這些超強牌往往比你更強。

**正確做法：** 根據對手的 call range 調整 sizing，而非根據你自己手牌的強度。

**錯誤三：在不利牌面 over-value bet**

例如：你有 JJ，牌面是 A-K-Q（rainbow），河牌是 T。

這個牌面你的 JJ 雖然有「一對」，但對手可能有 Broadway 順子（AK, AQ, KQ, QJ 等都完成了順子）。在這個牌面用 JJ 做 value bet 是嚴重錯誤。

## 第二節：河牌 Bluff

### 2.1 河牌 Bluff 的數學基礎

河牌 bluff 是純粹的數學遊戲。你下注的目的是讓對手用比你更強的手牌 fold，從而贏得底池。

**損益平衡 Fold 頻率計算：**

如果你在底池 P 中下注 B，你需要對手以以下頻率 fold 才能損益平衡：

```
損益平衡 Fold% = B / (P + B)
```

例子：
- 底池 10,000，你下注 5,000（1/2 pot）
- 損益平衡 Fold% = 5,000 / (10,000 + 5,000) = 33.3%
- 如果對手 fold 超過 33.3%，你的 bluff 盈利

- 底池 10,000，你下注 10,000（full pot）
- 損益平衡 Fold% = 10,000 / (10,000 + 10,000) = 50%
- 需要對手至少 50% 的頻率 fold

- 底池 10,000，你下注 15,000（1.5x pot/overbet）
- 損益平衡 Fold% = 15,000 / (10,000 + 15,000) = 60%
- 需要對手至少 60% 的頻率 fold

### 2.2 選擇正確的 Bluff 手牌：Blockers 的重要性

在河牌上選擇 bluff 手牌，最重要的原則是：**選擇有最好 blockers 的手牌做 bluff**。

**Blocker 的定義：** 你手中持有的牌，減少了對手持有特定強牌的可能性。

**最好的 bluff blockers：**

1. **Nut hand blockers（擋住最強牌的牌）**
   - 例如：如果牌面可能有順子，持有順子的關鍵牌讓你適合 bluff
   - 牌面 9-T-J，你持有 Q 或 8，擋住了 QJ 和 89 順子

2. **Flush draw blockers**
   - 持有 flush 的 A 或 K（尤其是 nut flush）
   - 例如：牌面三張 spades，你持有 A♠ 但沒有成花，你的 A♠ 擋住了對手的 nut flush

3. **Bluff 手牌選擇標準（優先順序）：**
   - 優先：有 blocker 且在 showdown 沒有價值的手牌
   - 次優：pure air（完全沒有 showdown value）但有 blockers
   - 最差：有 showdown value 的手牌（這些牌寧可 check/showdown，不要當 bluff 犧牲）

**具體例子——選擇 Bluff 手牌：**

```
牌面：K♠ J♠ 8♥ - 2♦ - Q♠（完成了 flush 可能）
底池：12,000

你有兩個選擇：
A) 手牌：A♠ T♦（有 nut flush blocker + 有順子 blocker）
B) 手牌：6♥ 5♥（pure air，但沒有任何 blocker）
```

答案：A 是更好的 bluff 手牌，因為：
- A♠ 擋住了對手的 nut flush（A♠ Q♠ 或 A♠ 其他）
- T♦ 擋住了順子（AKQ, KJT 等）
- 在 showdown 完全沒有價值（所以值得用來 bluff 犧牲）

### 2.3 河牌 Overbet Bluff

河牌 overbet bluff 是最勇猛、EV 最高（但也最危險）的技術。

**何時使用 Overbet Bluff：**

1. **對手的 range 整體很弱**
   - 三街多次 barrel 後，對手的 call range 已經很小
   - 對手只剩下「bluff catchers」（弱強牌），很少有超強牌

2. **牌面轉移（board runs out poorly for caller）**
   - 你的三街打法表明你有一個特定強牌
   - 河牌上出現了「破壞」大多數 bluff catcher 的牌

3. **你有很好的 blockers**
   - Overbet bluff 必須配合強 blockers，因為你需要更高的 fold 頻率

**具體例子：**

```
場景：MTT 後期，盲注 3,000/6,000
CO vs BB（你在 CO，對手在 BB）
有效籌碼：150,000

翻牌前：CO raise 13,000，BB call（pot 27,000）
翻牌：A♥ 9♥ 7♦
- BB check，CO bet 18,000，BB call（pot 63,000）
轉牌：K♠
- BB check，CO bet 42,000，BB call（pot 147,000）
河牌：2♣
- BB check

你的手牌：Q♥ J♥（翻牌有 flush draw + 順子 draw，但都沒有完成）
```

分析：
- 你在三條街上 barrel，表明你可能有 AK, AQ, KK, AA, 99, 77 等強牌
- 對手 call 了三街，他可能有 Ax, KQ, 99, 77 等
- 河牌 2♣ 完全是空白牌，對手的弱 Ax 和 KQ 都是 bluff catchers

在這裡，overbet bluff（比如 120,000 進 147,000 底池，約 80% pot，接近對手的 all-in）是合理的：
- Q♥ 擋住了 AQ（對手可能有的強牌）
- J♥ 擋住了一些組合
- 你的三街打法與 AK、AA 等強牌一致，故事可信

### 2.4 三條街 Bluff Line 的可信故事

成功的河牌 bluff 必須在「故事層面」上一致。如果你的三條街打法不能代表一個可信的強牌 range，對手更容易 call。

**可信故事的要素：**

1. **翻牌前行動一致**：你的 position 和翻牌前行動要與你宣稱的手牌類型一致
2. **翻牌後每條街的行動要解釋得通**：為什麼你在每條街繼續下注？
3. **牌面變化要支持你的 range**：如果河牌的牌「幫助」了你宣稱的 range，bluff 更可信

**可信故事例子：**

```
場景：你在 EP（早位）raise，只有 BB call
牌面：K♣ Q♦ J♠ → 8♣ → T♥

你的 bluff：A♣ 2♣（沒有完成同花，也沒有順子）

你在三條街上的打法：
- 翻牌 K-Q-J：你 C-bet（宣稱有 KK, QQ, JJ, AK, KQ 等）
- 轉牌 8：繼續 barrel（宣稱強牌繼續打）
- 河牌 T：大注 bluff
```

問題：這個 bluff 故事可信嗎？

分析：K-Q-J-8-T 的牌面有很多順子完成（AKQ 完成了 Broadway，9-T 完成了一些順子）。你宣稱的 range（AK, KQ）在這個牌面可以有很多 two pair 和 trips，但對手的 range 也一樣強。**這個 bluff 故事一般般**——不是最好的三街 bluff 選擇，因為對手也有很多強牌。

**更好的三街 bluff 故事：**

選擇在對手 range 非常弱的牌面做三街 bluff，或者讓河牌的 card 「撐起」你的故事。

### 2.5 Bluff Sizing：為什麼河牌 Bluff 通常要大

河牌 bluff 有一個反直覺的特性：**bluff 通常應該用大注，甚至 overbet**。

**原因分析：**

1. **大注讓對手做 fold 決策更困難**
   - 面對 small bet，對手的 pot odds 很好，容易 call（需要的 fold equity 低）
   - 面對 large bet，對手需要更多 equity 才能 call 合算

2. **大注更接近「極化 range」，對手更難 exploit**
   - 如果你只用 small bet bluff，對手知道你的 bluff range 很寬，容易 call
   - 大注表示極化 range（強牌 or 純 bluff），讓對手在強牌面前 fold 的頻率更高

3. **增加 bluff 的 fold equity**
   - 數學上，更大的注讓你需要的 fold 頻率上升，但如果對手有很多弱牌，仍然盈利

**例外情況——小注 bluff 合理的時機：**
- 對手是 call station（任何大小都跟），小注 bluff 節省損失
- 底池很小，你只需要少量 bluff 就可以拿走底池

## 第三節：河牌 Check-Call vs Check-Fold

### 3.1 河牌 Bluff Catching

Bluff catching 在河牌上達到最純粹的形式。此時手牌強度已固定，你的決策純粹是：**對手的 bet range 中，有多少比例是 bluff？**

**Bluff Catching 的核心計算：**

```
你的 Pot Odds = Call Size / (Pot + Call Size)
```

如果你 call 的頻率需要 > 損益平衡，就應該 call。

例子：底池 10,000，對手下注 6,000
- 你的 Pot Odds = 6,000 / (10,000 + 6,000) = 37.5%
- 如果你相信對手的 bet range 中至少有 37.5% 是 bluff，call 有利

**哪些手牌適合當 Bluff Catcher：**

1. **有 showdown value 但不是強牌的手牌**：中對、弱兩對
2. **在對手的 value range 面前明顯 behind，但在 bluff range 面前 ahead**
3. **你在多條街上已經 call，river 的牌沒有完成任何特別 draw**

**具體例子——Bluff Catching 決策：**

```
牌面：J♥ 9♣ 4♦ - 2♠ - 7♦
你的手牌：A♣ J♣（頂對頂 kicker）

對手三街 bet（越來越大），河牌 overbet（140% pot）

問題：A♣ J♣ 是好的 bluff catcher 嗎？
```

分析：
- 對手的 value range 在這個牌面：99, 44, J9, J4, 97 等（大多數比你強）
- 對手的 bluff range：KQ（open-ended straight draw 未完成）、Q8（gutshot 未完成）
- 你的 A♣ J♣ 打敗對手所有 bluff，但輸給大多數 value

**決策取決於：** 對手是否會在這個牌面三街 bluff，且用 overbet 做結束。如果對手是 tight/passive，他幾乎沒有 bluff，應該 fold。如果對手是 aggressive，這是合理的 call。

### 3.2 何時 Check-Raise River

河牌 check-raise 是非常強的 play，通常用於兩種情況：

**情況一：你有非常強的牌（想要更多 value）**

```
牌面：A♠ 8♣ 5♦ - J♥ - 2♠
你的手牌：A♥ A♦（暗三條，最強牌之一）

對手在河牌下注（你應該 check-raise 而非 check-call）
```

為什麼 check-raise 而非 call？
- Check-raise 讓對手可能用 bluff 或強牌付出更多
- 直接 call 只拿到一個 bet 的 value
- Check-raise 可能拿到兩倍的 value（對手的 bet + raise 的 call）

**情況二：純 bluff check-raise（高風險、高回報）**

河牌純 bluff check-raise 是高級玩法，需要：
- 你的 range 在這個 spot 看起來可以有強牌（check-raise range 可信）
- 對手是可以被 fold 的玩家（非 calling station）
- 你有好的 blockers

**不適合 Check-Raise 的情況：**
- 你有 thin value 的手牌（如中對）——check-raise 後如果對手 re-raise，你很難受
- 你的 range 在這個 spot 不可信有強牌

### 3.3 Pot Control on the River：何時 Check Back

當你在位置上（IP），有時候最好的河牌打法是 **check back**（直接 showdown），而非 bet。

**Check Back 的適用情況：**

1. **你有 showdown value，但不夠 value bet 的牌**
   - 例：你有中對，對手的 range 中有很多弱牌，但下注後對手只用強牌 call
   - Check back 拿 showdown value，讓弱牌付免費的 showdown

2. **你擔心被 check-raise**
   - 如果對手可能 check-raise bluff，check back 避免被 check-raise 趕出底池

3. **你需要保護你的 checking range（GTO 考量）**
   - 在 GTO 框架中，即使有強牌，偶爾也需要 check back，以防止對手在你 check 後永遠 bluff

**具體例子：**

```
牌面：K♠ Q♦ J♣ - 8♥ - 3♣
你（BTN）的手牌：A♠ K♥（頂對頂 kicker）

對手（BB）在翻牌和轉牌都 check，你 bet 了兩次，河牌對手又 check
```

在這裡，check back 是合理的選擇：
- 你有中等強度的手牌（一對 K，但牌面 K-Q-J 對手可能有順子）
- Value bet 後，對手只用比你強的牌（順子、two pair）call
- Check back 讓你免費 showdown，避免 bluff-raise 的可能

## 第四節：ICM 對河牌決策的影響

### 4.1 ICM 基礎回顧

ICM（Independent Chip Model）在 MTT 中改變了所有決策的 EV 計算。在 bubble 或 final table 附近，籌碼的邊際價值遞減——贏得更多籌碼的 EV 增加幅度小於損失籌碼的 EV 損失幅度。

### 4.2 Bubble 時的河牌 Bluff Call

**核心原則：Bubble 時，river call 的 ICM 成本非常高**

當你在 bubble 附近，river call 通常意味著 all-in 或接近 all-in。如果你 call 錯了，你被淘汰；如果你 call 對了，你贏得籌碼但 ICM 增益有限。

**數學分析：**

假設你在 bubble（差一個人進錢圈），籌碼 30bb，對手 all-in。
- 如果你 fold：繼續比賽，等待 bubble 破裂，獲得最低獎金的概率很高
- 如果你 call 並贏：60bb 籌碼，ICM value 上升，但未來期望下降相對較少
- 如果你 call 並輸：被淘汰，ICM value 歸零，損失所有已獲得的 ICM equity

在這種情況下，你的 breakeven equity 不是傳統的 50%，而可能需要 60-70% 的實際勝率才能 call。

**具體例子：**

```
MTT Bubble 場景：
- 還剩 21 人，前 20 名進錢圈（最低獎金 $500）
- 你在 BTN，籌碼 28bb
- 大盲（BB）籌碼 30bb，all-in push（有效注 28bb）

你的手牌：A♣ 9♦（一個邊緣 call 手牌）

Chip EV 計算：你有約 55% 勝率 vs 對手的 push range
ICM 計算：你的 ICM 勝率需要明顯高於 50%
```

在這個例子中，即使你的 chip EV 是正的（55% 勝率），ICM 調整後可能讓這個 call 變成 EV 接近零甚至微負。**Bubble 時應該更謹慎地做河牌 call/all-in 決策。**

### 4.3 短疊 vs 深疊的河牌策略差異

**短疊（< 20bb）的河牌策略：**

- 翻牌後的策略已經大幅簡化（通常只有 push/fold）
- 河牌的 bluff 意義不大，因為所有行動都是 all-in
- 重要的是翻牌前的 range 選擇，而非河牌技巧
- ICM 壓力更大，應該避免 marginal all-in

**深疊（> 50bb）的河牌策略：**

- 有完整的翻牌後策略（check, bet small, bet big, raise 等）
- Sizing 選擇更重要，因為不是 all-in
- 可以進行複雜的河牌 check-raise bluff 等高級技術
- ICM 壓力相對較小，更接近現金局策略

**中疊（20-50bb）的河牌策略：**

- 翻牌後策略開始簡化，但還不是純 push/fold
- 需要特別注意 river overbet 的 ICM 影響
- Overbet all-in 的 ICM 成本高，應該更謹慎

## 第五節：具體河牌手牌場景分析

### 場景一：河牌 Value Bet 決策

```
MTT 中期，盲注 300/600，有效籌碼 45,000
位置：你（HJ），對手（CO）
翻牌前：HJ raise 1,400，CO call，其他人 fold

翻牌：J♥ 9♣ 4♦（pot 3,500）
- 你 C-bet 2,000，CO call（pot 7,500）

轉牌：6♠（pot 7,500）
- 你 bet 4,500，CO call（pot 16,500）

河牌：2♣（pot 16,500）

你的手牌：J♠ T♠（頂對 + 順子聽牌，但未完成）
```

**分析：**

對手在翻牌和轉牌都 call，river 是 2♣。

你的手牌 JT 有：
- 頂對（J-high pair）
- 未完成的 open-ended straight draw（8-T 或 Q-K-T 等）

對手可能的 range：
- J-x（頂對，比你的 JT 可能更強或更弱）
- 99（set，比你強）
- 44（set，比你強）
- QT, T8（open-ended straight draw，未完成，比你弱）
- 可能有 some KJ, QJ（比你弱的頂對）

**決策：Small value bet（1/3 pot，約 5,500）**

理由：
- 你的頂對有 value，對手可能有 QJ, KJ, T9（比你弱的手牌）call
- 但你不夠強到用大注（對手有 99, 44 set 在 range 中）
- Small bet 讓對手用弱牌 call，同時限制損失（如果對手 raise）

**結果討論：**
- 如果對手 call：你展示 JT，通常贏得 showdown vs 比你弱的 J-x
- 如果對手 raise：fold，你損失 5,500 而非更多

### 場景二：河牌 Bluff 決策

```
MTT 後期，盲注 800/1,600，有效籌碼 70,000
位置：你（BTN），對手（BB）

翻牌前：你 raise 3,500，BB call（pot 7,800）

翻牌：K♠ T♣ 7♠（pot 7,800）
- BB check，你 C-bet 4,500（BB call，pot 16,800）

轉牌：J♠（pot 16,800）
- BB check，你 bet 9,000（BB call，pot 34,800）

河牌：4♦（pot 34,800）

你的手牌：A♠ Q♦（沒有成花，順子 draw 也沒完成）
```

**分析：**

你 A♠ Q♦ 在 K-T-7-J-4 的牌面完全未中。A♠ 你有 nut flush draw 但沒完成（4♦ 是方塊，不是黑桃），Q♦ 沒有特別意義。

Showdown value：基本沒有（A-high，對手有任何一對都贏你）

**Bluff 的考量：**

1. 你有 A♠ blocker，擋住了對手的 nut flush（如果對手有 X♠ A♠ 形式的手牌）
2. 你有 Q 作為部分 blocker（對手的 KQ 少了一個組合）
3. 你三條街的打法表明你有強牌（C-bet on K-high board, continue on J）

**決策：River Bluff，size 約 70-80% pot（約 25,000-28,000）**

理由：
- A♠ 是好的 blocker
- 三街打法可信（宣稱 AK, KQ, KJ 等）
- 對手在 J 轉牌後仍然 call，他可能有 KT, K7, T7 等（draw 完成後的 bluff catchers）
- 大注讓對手做出困難的 fold 決策

**潛在風險：**
- 如果對手有 J♠ X♠（完成了 flush），他不會 fold，你 bluff 失敗
- 對手有 KK, TT, 77（set）的情況也不會 fold

### 場景三：ICM 壓力下的 Bluff Catch 決策

```
MTT Bubble（40進錢，還剩42人）
你的籌碼：35bb
對手籌碼：42bb（最大疊，你是第二大）
位置：你（BB），對手（BTN）

翻牌前：BTN raise 2.2bb，你 call with A♥ J♦

翻牌：Q♠ 9♣ 3♦（pot 5bb）
- 你 check，BTN bet 2.5bb，你 call（pot 10bb）

轉牌：7♥（pot 10bb）
- 你 check，BTN check

河牌：2♠（pot 10bb）
- 你 check，BTN bet 8bb（80% pot）
```

**分析：**

你在 bubble 上，AJ 在 Q-9-3-7-2 的牌面只有 A-high。

對手的 range：
- BTN 在翻牌 C-bet，轉牌 check，河牌 bet
- 轉牌 check behind 通常表示中等強度牌（不想繼續加大底池）或 bluff 放棄
- 河牌 bet 後：可能是 thin value（QT, Q8 等）或 bluff（未完成的 draw）

**ICM 考量：**

如果你 call 並輸（35bb - 8bb 下去，剩 27bb 且底池輸掉）：
- 你的籌碼從 35bb 降到約 27bb
- 兩個短疊玩家可能在 bubble 存活時超過你

如果你 call 並贏（你會有約 50bb）：
- 你的 ICM 地位明顯改善
- Bubble 壓力消失

**決策：Fold（ICM 壓力大，A-high 作為 bluff catcher 代價太高）**

理由：
- 在 bubble 上，even 50% win rate 的 call 也可能 ICM 為負
- A-high 作為 bluff catcher 需要對手有非常高的 bluff 頻率
- 保存籌碼讓你進入 money 的 EV 更高

### 場景四：Overbet Value 決策

```
MTT Final Table（8 人剩）
盲注 5,000/10,000
你（chip leader，350,000）vs 對手（180,000）
位置：你（CO），對手（BB）

翻牌前：CO raise 22,000，BB call（pot 47,000）

翻牌：9♥ 8♥ 7♦（pot 47,000）
- BB check，CO bet 28,000，BB call（pot 103,000）

轉牌：6♠（pot 103,000）
- BB check，CO bet 65,000，BB call（pot 233,000）

河牌：J♠（pot 233,000）

你的手牌：T♠ 9♠（你有 broadway 順子：T-J-9-8-7，實際上是 straight 7-J with T high）
```

**分析：**

等等，讓我重新確認手牌。你有 T♠ 9♠，公牌是 9♥ 8♥ 7♦ - 6♠ - J♠。

- 你的 9♠ 配對（trip 9s？不，你有 T♠ 9♠，公牌有 9♥，所以你有 trip 9s 嗎？不對。你有一對 9s。）
- 讓我重新分析：T♠ 9♠ 在 9-8-7-6-J 的牌面
- 你有順子：7-8-9-T-J（7 到 J 的順子），這是非常強的手牌！
- 同時你有 T♠ 9♠，可能有同花順（如果公牌有黑桃同花）

實際上牌面是 9♥ 8♥ 7♦ 6♠ J♠，你有 T♠ 9♠：
- 你有順子 7-8-9-T-J（jack-high straight）
- 但更強的順子是 T-J-Q-K-A（如果對手有 QK）或 9-T-J-Q-K（如果對手有 QK）

**注意：T♠ 9♠ 給你 J-high straight（J-T-9-8-7），非常強！**

對手可能有：
- QT（Q-high straight，更強！），要特別注意
- T♠ 7♠ 或其他組合（同花順可能性）
- 一些較弱的兩對或 set

**決策：Large value bet or all-in（約 180,000 overbet）**

如果對手有 QT（更強的順子），你已經輸了，但要假設你沒有被 dominated 的情況：

對手在翻牌 C-bet 後 call，轉牌再 call，river 可能有：
- 強牌（set, two pair）但比你的順子弱
- 可能有更強的順子（QT）

在沒有 QT 顧慮的情況（或若你認為對手的 range 中 QT 比例低），all-in overbet 是合理的，因為對手可能有 set 或 two pair 不願意 fold。

### 場景五：河牌 Check-Raise Bluff 決策

```
MTT 中期，盲注 400/800，有效籌碼 55,000
位置：你（BB），對手（BTN）

翻牌前：BTN raise 1,800，你 call（pot 4,000）

翻牌：A♦ 5♣ 2♥（pot 4,000）
- 你 check，BTN C-bet 2,200，你 call（pot 8,400）

轉牌：K♠（pot 8,400）
- 你 check，BTN bet 5,000，你 call（pot 18,400）

河牌：3♦（pot 18,400）

你的手牌：6♠ 4♣（你完成了順子！2-3-4-5-6，但這是低端順子）
```

**分析：**

你有 6-high straight（A-2-3-4-5-6，但你的是 2-3-4-5-6，6-high）。

等等，牌面是 A-5-2-K-3，你有 6-4：
- 6-4 在 A-5-2-K-3 的牌面
- 2-3-4-5-6 是完整的順子（你有 4 和 6，公牌有 2, 3, 5）
- 但 A-2-3-4-5 也是順子（wheel，如果對手有 A-4 或 A-6）

你有 6-high straight，這是相當強的手牌，但可能被 wheel（A-2-3-4-5）打敗。

**更重要的是：對手可能有 A-4（completed the wheel）**

在 A-5-2-K-3 牌面：
- 你的 6-4 = 6-high straight（2-3-4-5-6）
- 對手的 A-4 = wheel（A-2-3-4-5），比你更強？
  - 實際上 A-high straight（A-2-3-4-5）= 5-high straight，以 5 為頂
  - 你的 6-4 = 6-high straight，比 wheel 強！

所以你的 6-4 是 nut straight（最強的順子）！

**決策：Check-Raise for value（不是 bluff）**

- 你有 nuts，check-raise 可以最大化 value
- 對手三條街 bet，他可能有強牌（AA, KK, set）
- Check-raise 讓他付更多錢

這是 check-raise for value，而非 bluff。

**結果：**
理想情況下，對手有 set 或 A-4（以為自己有 nuts 的 wheel），會 call 或 re-raise，讓你拿到最大 value。

## 第六節：河牌策略總結

### 關鍵原則清單

1. **Value Bet 原則**
   - 只有當你認為被 call 的 range 中超過 50% 比你弱時才 value bet
   - Sizing 根據對手的 call range 決定，不是根據你的手牌強度
   - Overbet value 用在對手有強但比你弱的手牌時

2. **Bluff 原則**
   - 計算損益平衡 fold 頻率，確認 bluff 有 EV
   - 選擇有最好 blockers 的手牌做 bluff
   - 河牌 bluff 通常用大注，讓對手做困難的 fold 決策
   - 確保三街打法有可信故事

3. **Check-Call / Check-Fold 原則**
   - 用 pot odds 計算 bluff catch 的合理性
   - 不要在明顯 behind 的情況下 hero call
   - 有 showdown value 但不夠 bet 的牌，考慮 check-call 或 check-fold

4. **ICM 原則**
   - Bubble 時降低 call 的頻率，提高 fold 的頻率
   - 短疊的河牌決策更接近 push/fold，不需要複雜的 sizing 策略
   - Final table 的 ICM 差異可能極大，每一個 call 決策都要仔細計算

### 常見錯誤總結

| 錯誤 | 正確做法 |
|------|---------|
| 只看手牌強度決定 sizing | 根據對手 call range 決定 sizing |
| 在 bubble 做 marginal bluff call | 提高 fold 頻率，保護 ICM equity |
| 在多人底池 river bluff | 避免多人底池 bluff（fold equity 太低） |
| 用有 showdown value 的牌做 bluff | 只用無 showdown value 的牌做 bluff |
| 忽略 blockers | 選擇有最好 blockers 的牌做 bluff |
| 三街故事不一致就 bluff | 確保三街打法有可信故事才 bluff |
