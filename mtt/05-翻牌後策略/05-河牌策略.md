# 河牌策略：線上 MTT 最昂貴的一街

本教材預設場景：線上 No-Limit Hold'em MTT、Big Blind Ante、8-max 或 9-max、多桌節奏。除非特別說明，所有籌碼深度都用有效 bb 計算，底池預設包含 SB、BB、BB ante。

## 本章定位
河牌沒有未來 equity，所有錯誤都直接變成籌碼與獎金 EV。線上 BBA 讓前面底池更快長大，因此河牌決策常牽動整個賽事生命。

## 線上 BBA 原則
河牌要把範圍分成價值下注、bluff、check back、bluff catch、fold。每個下注都要問：更差會 call 嗎，更好會 fold 嗎，這個尺寸代表什麼。

## 操作框架
1. 價值下注先找目標：要從哪類更差牌拿錢。
2. bluff 要選 blocker 好且攤牌價值低的牌。
3. 面對下注先算 pot odds，再看對手頻率。
4. ICM 壓力下，薄 value 與大 bluff 都要更精準。
5. 不要因已投入很多就自動 call。

## 尺寸與節奏
- 薄 value 常用 25% 到 50% pot，逼 bluff catcher 付錢。
- polarized value/bluff 用大尺寸，通常 75% pot 以上。
- overbet 需要 nut advantage 與 blocker 支撐。
- 短碼河牌小注可能已讓對手 pot committed。

## 線上常見偏差與調整
- 對手 call station：少 bluff，多 thin value。
- 對手 overfold river：用 missed draw 與 blocker bluff。
- 對手不會 value bet thin：面對大注可更常 fold。
- 對手怕出局：pay jump 前增加小而痛的 value/bluff 混合。

## 本章練習
- 每個河牌下注前寫出三個會被你打敗且會 call 的牌。
- 複盤所有 river bluff，檢查 blocker 是否合理。
- 把 river call 的輸贏分開，不用結果判斷，而用頻率判斷。

## 快速檢查
- 我知道下注目標。
- 我不因 sunk cost call。
- 我用 blocker 選 bluff。
