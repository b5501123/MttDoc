# 抓詐打法（Bluff Catching）

## 什麼是 Bluff Catching

**Bluff Catching** = 用中等牌力手牌 call 對手的 bet，目的是抓住他的 bluff。

不是 value call（你不確定你贏），也不是 hero call（純靠感覺）。
是**系統性的分析**：對手這條 betting line 的 bluff 頻率夠高，call 是正 EV。

---

## 基本邏輯：Bluff Catching 的數學

### 最低需要的 Bluff 頻率

你要 call 一個 bet，需要對手的 bluff 頻率超過損益平衡點。

```
損益平衡 bluff 頻率 = Call 金額 ÷ (Call 後底池)

例：底池 100，對手 bet 75
你 call 75，call 後底池 250

損益平衡 = 75 ÷ 250 = 30%

→ 只要對手有超過 30% 的機率是在 bluff，call 就是正 EV
```

**簡化記憶：**
| Bet size（占底池%）| 你需要的對手 bluff 頻率 |
|-------------------|----------------------|
| 33%               | 20%                  |
| 50%               | 25%                  |
| 75%               | 30%                  |
| 100%              | 33%                  |
| 150%（overbet）   | 38%                  |

對手 bet 越大，需要的 bluff 頻率越高。但大 bet 本身往往代表更多 bluff（對手用大 bet 試圖讓你 fold）。

## 哪些手牌適合當 Bluff Catcher

**好的 Bluff Catcher 特性：**

1. **打不贏 value，打得贏 bluff**
   - 中等強度（例：中等 pair, top pair 弱踢腳）
   - 對手的 value range 領先你，但 bluff range 輸你

2. **有 Showdown Value（攤牌價值）**
   - 不需要改善，現在的牌就有勝率
   - 打到 showdown 有機會贏

3. **Blocker（阻礙效果）**
   - 你的牌阻礙了對手的 nuts
   - 例：你有 A♠，阻礙對手的 nut flush 或 AA

**典型 Bluff Catcher 例子：**

```
翻牌：A♣ K♦ 7♠

你有：K♥ Q♦（Second pair, decent kicker）

對手的 range：
- Value：AK, AA, KK, 77（領先你）
- Bluff：QJ, JT, flush draw miss, 空氣牌（輸你）

你的 K♥ Q♦ 是很好的 bluff catcher：
打不贏 AK/AA，但打贏所有 bluff
```

## 識別對手在 Bluff 的信號

### 信號 1：Line 不一致

對手的 betting line 和他聲稱的手牌不符。

```
例：
翻牌：A♠ 8♦ 3♣
對手 check
轉牌：Q♥
對手 check
河牌：2♠
對手 bet 大

分析：
對手在翻牌和轉牌都 check，現在 river 才大注？

如果他有 A（top pair）：
翻牌應該 bet，或轉牌 bet，不會等到 river 才下注
→ River 突然大注 = 可能是 bluff（missed draw 在試圖偷底池）
```

### 信號 2：Missed Draw 的 River Bet

翻牌和轉牌都有 draw 的牌面，river 沒有完成。

```
例：
翻牌：T♠ 9♠ 3♦（有 flush draw 和 straight draw）
對手 bet
轉牌：5♣
對手 bet（繼續）
河牌：2♦（空白，draw 沒完成）
對手 overbet

分析：
如果對手有 made hand（TT, 99, T9）：
他的手牌不需要 overbet，標準 value bet 就好

如果對手有 flush draw / straight draw（KsQs, JsQs...）：
Draw miss → 現在只能 bluff
→ 大尺寸 bet 很可能是 bluff
```

### 信號 3：Board Texture 變化

轉牌或河牌出現對你有利的牌，但對手繼續下注。

```
例：
翻牌：K♥ Q♦ 7♣
你有：Q♠ J♠（middle pair）
對手 c-bet，你 call

轉牌：A♠
對手繼續 bet

分析：
A 出來對你不利（對手 range 有 AK, AQ）
但如果對手有 AK, AQ：他為什麼要 bet 大？
→ 他可能是在 bluff（沒有 A）

如果對手有 KK, QQ：A 出來他可能 slow down
→ 繼續 bet 可能是 bluff 或弱 value（KQ, K7）
```

### 信號 4：對手 Bluff 頻率高（歷史數據）

**HUD 數據：**
- River C-bet：>70% → 可能在 bluff 太多
- Fold to River Raise：>60% → 他的 bet 很多是 bluff

**無 HUD 時的觀察：**
- 這個對手之前 bluff 被抓過
- 他在很多底池主動下注（LAG 風格）
- 他在不利的牌面還是繼續下注

## Bluff Catching 的三條街策略

### 翻牌抓詐

**何時在翻牌就開始 bluff catch？**
通常不在翻牌就「抓詐」，翻牌更多是確認你的 hand strength。
除非：翻牌明顯對手是在用超寬 C-bet bluff。

### 轉牌抓詐（最重要的一條街）

轉牌是確認對手 range 的關鍵街。

**轉牌 Bluff Catch 的指標：**
```
1. 對手翻牌 C-bet，你 call
2. 轉牌出現空白（不改變任何 hand strength）
3. 對手繼續 bet（Double barrel）

問題：他的雙桶有多少是 bluff？

分析：
雙桶 = 有更強的 commitment，代表：
- 有強牌（繼續 build pot）
- 有半詐注（draw 繼續）
- 純詐注（兩條街都是 bluff）

轉牌 bluff 頻率通常比翻牌低
→ 轉牌 call 需要比翻牌 call 更強的手牌
```

### 河牌抓詐

河牌是最純粹的 bluff catch 時刻。

**河牌 Bluff Catch 原則：**
```
1. 計算對手的 bluff 頻率（是否超過損益平衡）
2. 你的手牌能 beat 他的 bluff 嗎？
3. 你被他的 value 領先的比例有多高？
```

**河牌 Bluff Catch 的典型手牌：**
- 中等 pair（沒有改善）
- Top pair with weak kicker
- 有 blocker 的手牌（你有 A，對手的 nut flush 概率低）

## 被動抓詐 vs 主動抓詐

### 被動抓詐（Passive Bluff Catch）

Check-call 讓對手繼續 bluff：

```
你有強牌但選擇 check（不是 bet）
對手 bet（他以為你弱）
你 call

目的：讓對手用更多 bluff 打進來
優點：最大化對手 bluff EV
缺點：失去一些 value（弱牌不 call 就沒賺）
```

**適合被動抓詐的情況：**
- 對手激進，會對你的 check 進行大量 bluff
- 你的手牌中等，raise 效果不好（fold out bluff）
- 翻牌後你有強牌但不是 nuts，check 製造陷阱

---

### 主動抓詐（Check-Raise Bluff Catch）

Check，等對手 bet，然後 raise：

```
你 check
對手 bet（可能 bluff）
你 raise

目的：施壓讓對手 fold bluff，同時保護自己不被再 bet
```

**適合 Check-Raise 抓詐的情況：**
- 你有 strong draw 或 semi-bluff（check-raise 有 equity 支撐）
- 你相信對手 bet 頻率高，但 raise 後會 fold bluff
- 你的手牌不能 call 三條街，但 check-raise 可以結束戰鬥

## 抓詐的常見錯誤

### 錯誤 1：Hero Call（英雄 call）

「我感覺他在 bluff」→ 沒有邏輯支撐就 call。

**正確做法：**
分析他的 betting line → 估計 bluff 頻率 → 計算損益平衡 → 決定

### 錯誤 2：用弱牌抓詐

你 call 了，結果對手的 bluff 比你的弱牌還贏你（他有底對，你有 K-high）。

**正確做法：**
Bluff catcher 必須能 beat 對手的 bluff range。
如果你的牌連 bluff 都打不贏，fold 更好。

### 錯誤 3：在 OOP 多條街抓詐

你在 OOP，call 了翻牌，call 了轉牌，現在 river 也要 call？
OOP 多條街 call 非常被動，對手可以控制底池大小。

**正確做法：**
OOP 時更多 check-raise（主動抓詐），少用被動三條街 call。

### 錯誤 4：忽略 ICM（Bubble/FT）

Bubble 時，即使邏輯上是 +EV 的 bluff catch，ICM 讓你失去的代價更大。

**Bubble 時的 Bluff Catch 原則：**
- 只在底池小的情況下抓詐（損失可控）
- 大底池的 bluff catch 要謹慎（輸了可能 bubble out）
- 對大疊的 bluff catch 更保守（他不怕輸）

## 抓詐打法的線上特別技巧

### 線上玩家的 Bluff 模式

**常見線上 bluff 模式：**

1. **Auto-pilot C-bet bluff**：很多玩家 100% C-bet，不管翻牌對他們 range 好不好
   → 識別後用 float + check-raise 抓詐

2. **Scared money bluff（短疊轉大疊）**：剛積累了很多籌碼，開始過度 bluff
   → 針對他增加 call range

3. **River overbet bluff**：用超大尺寸試圖讓你 fold 強牌
   → 計算他的 value/bluff 比例，overbet 常常包含更多 bluff

4. **Multiway pot 詐注**：多人底池中，對手在所有人都 check 後下注
   → Multiway bluff 成功率低，這個 bet 通常有更多 value

### 如何在線上識別 Bluffer

**無 HUD 時：**
- 觀察他過去幾手的下注模式
- 注意他是否在不利牌面繼續下注
- 注意他的 bet sizing 是否有規律

**有 HUD 時：**
- River C-bet% > 70%：三條街 bluff 多
- Fold to River Raise > 60%：他的 river bet 很多是 bluff
- W$SD（走到 showdown 贏率）< 45%：經常輸 showdown = bluff 頻繁

## 抓詐決策流程

```
1. 對手下了大注，你有中等手牌。

2. 問：他的 betting line 合理嗎？
   ├─ 不合理（line 說 AK，但 pre-flop 行動不像 AK）
   │   → 繼續分析 bluff 可能性
   └─ 合理（每條街都和強牌一致）
       → 更傾向 fold

3. 這條 line 有多少是 bluff？
   估計對手 bluff 頻率。

4. 計算損益平衡：
   Call 金額 ÷ (Call 後底池) = 最低需要的 bluff 頻率

5. 對手 bluff 頻率 > 損益平衡？
   ├─ 是 → Call（bluff catch）
   └─ 否 → Fold

6. ICM 調整：
   Bubble/FT → 需要更高的 bluff 頻率才 call
```
