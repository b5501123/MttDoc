# 炸虎（Bomb Pot）策略——BBA 環境全解析

## 重要前提：本文以 BBA 為預設環境

本文所有分析均以 **Big Blind Ante（BBA）** 為預設前提，在說明涉及炸虎特殊底池結構時會明確區分 BBA 是否同時生效。

---

## 第一章：什麼是 Bomb Pot（炸虎）？

### 基本定義

**Bomb Pot（炸虎）** 是一種特殊的撲克玩法變體，其核心規則如下：

- **所有在座玩家**在翻牌前各自 post 一個指定金額（通常為 **3-5bb**）
- **沒有翻牌前的下注輪**——沒有 open raise、3-bet，甚至沒有 option 機會
- 完成所有 post 之後，**直接發翻牌牌**，從翻牌開始第一輪下注
- 翻牌時底池已經非常大（9 人桌 × 3bb = **27bb 起步**）

### 名稱由來

「炸虎」這個中文名稱來自於底池「像炸彈一樣突然膨脹」的特性——還沒看手牌就已經有大底池在等著爭奪。英文「Bomb Pot」直譯即為「炸彈底池」，形象描述了翻牌前底池的爆炸性增長。

### 賽制中的炸虎

炸虎最初在**現金局（Cash Games）**中流行，後來逐漸進入部分特殊賽制：

| 賽制 | 炸虎應用方式 |
|------|------------|
| 現金局 | 最常見，可約定每隔 X 手進行一次 bomb pot |
| 特殊 MTT | 部分線上平台的 Special Format 賽事（如「Bomb Pot Tournaments」）|
| Home Games | 業餘牌局中常見的娛樂性玩法 |
| Streaming 活動 | 直播牌局中作為觀賞性特殊規則 |

### 炸虎與一般手牌的關鍵差異

| 特性 | 一般手牌 | 炸虎（Bomb Pot）|
|------|---------|---------------|
| 翻牌前行動 | 有完整下注輪 | 無，直接到翻牌 |
| 翻牌底池（9人桌，3bb each）| 通常 3-7bb | 27bb |
| 翻牌後 SPR（100bb 深）| 12-17 | 約 3.7 |
| 位置資訊 | 翻牌前行動提供 range 資訊 | 無翻牌前資訊 |
| 聽牌 implied odds | 取決於對手是否繼續下注 | 底池已大，不需等對手下注 |

## 第二章：BBA + Bomb Pot 的結合

### MTT 中 BBA 與 Bomb Pot 的共存規則

當一個 MTT 既有 BBA 規則又進行炸虎輪時，需要明確以下規則問題：

**不同賽制的處理方式：**

| 賽制設計 | BBA 在 Bomb Pot 中的處理 |
|---------|----------------------|
| 標準 MTT（無官方炸虎）| BBA 正常生效，無炸虎 |
| Bomb Pot 特殊輪（有 BBA）| 通常 BB 仍 post BBA，但炸虎額外 post 是主要底池來源 |
| Bomb Pot 專屬賽事 | 可能不設 BBA，每手都是炸虎結構 |
| Home Game 炸虎 | 規則自訂，BBA 可包含或排除 |

**最常見的情況：**在有 BBA 的 MTT 中偶發炸虎輪時，**BBA 仍由 BB 位 post**，加上所有人 post 炸虎額，翻牌底池為：

> 炸虎底池 = （所有人 × 炸虎額）+ BBA

### 炸虎底池計算（含 BBA）

**標準算法（100/200 盲注，BBA 200，9 人桌，炸虎 600 = 3bb each）：**

```
炸虎底池計算：
- 9 名玩家 × 600 chips（3bb）= 5,400 chips（27bb）
- BBA（BB post）         = 200 chips（1bb）
- 翻牌總底池             = 5,600 chips（28bb）

SPR 計算（100bb = 20,000 chips 開始）：
- 每名玩家 post 炸虎後剩餘：20,000 - 600 - 200（BB 位）≈ 19,200
  （非 BB 位：20,000 - 600 = 19,400）
- 有效籌碼（最短疊）≈ 19,200 chips（96bb）
- SPR = 19,200 / 5,600 = 3.43

結論：BBA 炸虎翻牌 SPR ≈ 3.4-3.6
```

**各種炸虎金額的底池比較（9 人桌，BBA，100bb 深）：**

| 炸虎金額（每人）| 炸虎底池 | +BBA 底池 | 翻牌 SPR |
|-------------|---------|---------|---------|
| 2bb（共 18bb）| 18bb | 19bb | 4.8 |
| 3bb（共 27bb）| 27bb | 28bb | 3.4 |
| 4bb（共 36bb）| 36bb | 37bb | 2.6 |
| 5bb（共 45bb）| 45bb | 46bb | 2.1 |

**重要結論：在 BBA 環境中，炸虎的翻牌 SPR 通常在 2.1-4.8 之間，屬於「高度承諾」區間。**

## 第三章：Bomb Pot 策略核心原則

### 核心原則一：翻牌 SPR 極低

以最常見的 3bb 炸虎、9 人桌、BBA 為例：

- **翻牌底池：28bb**
- **有效籌碼：約 96-97bb**
- **SPR：約 3.4-3.5**

SPR 3.4 代表什麼？根據 SPR 理論：

| SPR 區間 | 策略含義 |
|---------|---------|
| > 8 | 深疊，多條街策略，慢玩有意義 |
| 4-8 | 中等承諾，翻牌決策定方向 |
| **2-4（炸虎常見區）** | **高度承諾，Top Pair 幾乎應 commit** |
| < 2 | 已全面承諾，翻牌即全下 |

**在炸虎中，SPR < 4 代表：幾乎所有 Top Pair 好 Kicker 或更強手牌都應該進入 commit 模式。**

### 核心原則二：Commit 門檻大幅降低

在正常 SPR 15 的環境中，你需要 **Two Pair+** 才考慮 commit；在炸虎的 SPR 3.4 中：

**炸虎 Commit 標準（SPR ≈ 3.4）：**

| 手牌強度 | 正常 SPR（15）策略 | 炸虎 SPR（3.4）策略 |
|---------|-----------------|------------------|
| Two Pair+ | Commit | Commit（更早） |
| Top Pair + Good Kicker（TPGK）| 中等，視情況 | 幾乎 Commit |
| Top Pair + Weak Kicker（TPWK）| 保守 | 評估 Commit |
| Middle Pair | 控制底池 | 可能 Fold |
| 強 Flush Draw（9 outs+）| Semi-bluff | 積極 Semi-bluff，Commit |
| 弱 Flush Draw（< 9 outs）| 謹慎 | 視賠率決定 |

### 核心原則三：聽牌的 Implied Odds 不同

在正常底池中，聽牌的價值主要依賴「對手未來會繼續投入的籌碼（implied odds）」。

在炸虎中，**底池已經大到不需要等對手繼續投入**：

**範例（3bb 炸虎，BBA，底池 28bb，你有 Flush Draw）：**

一般翻牌情境（底池 6.5bb）：
- 追 Flush Draw 需要 pot odds 或良好 implied odds
- 你需要對手在轉牌/河牌繼續投入才能獲利

炸虎情境（底池 28bb）：
- **現有底池已經足夠大**，即使對手在轉牌後停止投入，你的 equity 也已值得繼續
- Semi-bluff 更有效——底池大，bluff 成功贏得的金額更可觀
- 不需要「等待」implied odds，**pot odds 本身就已足夠**

### 核心原則四：位置更重要（因為沒有翻牌前資訊）

在正常手牌中，翻牌前的行動（誰 open、誰 call、誰 3-bet）提供了豐富的 range 資訊。

在炸虎中，**所有玩家 range 都是「全範圍」**（因為沒有翻牌前行動）：

**這對位置的影響：**

| 效果 | 說明 |
|------|------|
| 位置資訊更純粹 | 你只能依賴翻牌行動來讀取對手 range |
| OOP 更加困難 | 沒有翻牌前資訊，OOP 更難讀取 IP 的手牌 |
| IP 的優勢被放大 | IP 有最後行動權，且能根據所有資訊決策 |
| 第一個行動者壓力最大 | 面對大底池卻最少資訊 |

## 第四章：Bomb Pot 翻牌決策框架

### 決策流程總覽

```
炸虎翻牌決策流程（BBA 環境，SPR ≈ 3.4）：

第一步：確認炸虎底池大小
└─ 基礎底池 + BBA（如適用）
   例：9 人 × 3bb + 1bb BBA = 28bb

第二步：計算 SPR
└─ 有效籌碼 / 翻牌底池
   例：96bb / 28bb = SPR 3.4

第三步：評估手牌強度（vs 全範圍對手）
├─ Strong（Two Pair+）→ Fast Play，大注
├─ Medium（TPGK）→ 根據 SPR 決定 commit
├─ Draw（9 outs+）→ Semi-bluff，積極打
├─ Marginal（Weak TP / Middle Pair）→ 謹慎，視情況
└─ Air（未成牌，無 draw）→ 通常放棄

第四步：考慮位置
├─ IP（BTN/CO）→ 可更廣泛 call，後手優勢
├─ OOP（SB/BB）→ 更謹慎，偏向 fast play 強牌或 fold
└─ 第一個行動者 → 需要清晰計劃再下注

第五步：ICM 考量（MTT 特有）
├─ Bubble 附近 → 更謹慎，炸虎讓 ICM 壓力加倍
├─ 短疊（< 20bb after post）→ 幾乎自動全下模式
└─ 深疊 → 標準炸虎策略
```

### 強牌（Two Pair 或更強）：Fast Play

在炸虎的低 SPR 環境中，強牌必須快速建立底池，否則底池太淺後無法收取足夠 value。

**操作原則：**
- 翻牌直接大注（75-100% pot 或全下）
- 不慢玩（SPR 低，慢玩讓對手便宜看轉牌/河牌）
- 目標：在 2-3 條街內完成全下

**BBA 炸虎 Fast Play 計算（底池 28bb，SPR 3.4，有效籌碼 96bb）：**

| 下注策略 | 翻牌下注 | 轉牌下注 | 河牌下注 | 總投入 |
|---------|---------|---------|---------|-------|
| 75-75-all | 21bb | 49bb | All（約 26bb）| 96bb |
| All-in 翻牌 | 96bb（SPR < 1 時直接全下）| — | — | 96bb |
| 50-100-all | 14bb | 56bb | All（26bb）| 96bb |

**結論：強牌在炸虎中通常 2 條街內完成全下。**

### 中等牌力（TPGK）：根據 SPR 決定 Commit

Top Pair Good Kicker（如 AK on A-7-3）在炸虎中幾乎等同「強牌」，因為 SPR 已低至 commit 門檻以下。

**TPGK 的炸虎策略（SPR ≈ 3.4）：**

1. **在 IP**：下注 50-75% pot，計劃翻牌-轉牌全下
2. **在 OOP**：下注 50% pot 或 check-raise，避免讓 IP 控制底池
3. **面對 raise**：通常 commit（SPR 低，不值得 fold TPGK）
4. **面對 re-raise（3-bet pot）**：評估是否已全面 commit（SPR < 2 時幾乎全下）

**注意**：TPWK（Top Pair Weak Kicker）在多人炸虎底池中應更謹慎——多個對手時，TPWK 的勝率顯著下降。

### 聽牌：根據 Pot Odds 決定，積極 Semi-Bluff

**Flush Draw（9 outs，約 35-37% hit on 2 streets）：**

在炸虎底池 28bb 中，flush draw 的 equity 計算：

```
炸虎 Flush Draw 決策（底池 28bb，SPR 3.4）：

Pot Odds 計算（面對 75% pot 下注 = 21bb）：
- 底池：28 + 21 = 49bb
- 你需要 call：21bb
- Pot odds：21 / (49 + 21) = 30%
- Flush Draw equity（1 street）：≈ 19%（9 outs × 2.2%）
- Flush Draw equity（2 streets）：≈ 35%

→ 在 2 條街計算下，35% > 30% pot odds → Call 數學上成立
→ 但在炸虎的低 SPR 環境，Semi-bluff raise 通常更優（贏得底池或建立 FE）
```

**Draw 的炸虎策略推薦：**
- **強 Draw（Flush Draw + 其他 outs）**：積極 semi-bluff raise 或大注
- **標準 Flush Draw（9 outs）**：可 call 或 semi-bluff，視位置
- **弱 Draw（< 6 outs）**：視 pot odds，謹慎

### 弱牌 / 未中（Air）：通常直接放棄

在炸虎的大底池中，持有完全無 equity 的手牌（例如 7-2o 翻牌 A-K-J rainbow），繼續的成本極高：

- 需要 bluff 入大量籌碼才能讓對手 fold
- 多人底池中 bluff 成功率大幅降低
- SPR 低，一旦被 call 幾乎全下

**例外**：如果你在 IP，翻牌有多個對手都 check，且你有一定的 back-door 可能性，可以考慮一次小額 steal。但這不是標準策略。

## 第五章：Bomb Pot 的常見錯誤

### 錯誤一：用正常 SPR 思維打炸虎

**問題**：玩家習慣在 SPR 15 的環境下打牌，對 TPGK 傾向「保守跟注，不全下」。

**在炸虎中的後果**：SPR 只有 3.4，TPGK 面對全下的正確策略往往是 call，但玩家卻 fold，損失大量 EV。

**修正**：在炸虎開始前，提醒自己重新計算 SPR，並根據炸虎的 SPR 決定 commit 門檻。

### 錯誤二：對聽牌過度謹慎

**問題**：玩家在正常底池（6.5bb）中習慣「追 draw 需要好的 implied odds」，在炸虎中依然保守地 call 小注追 draw。

**在炸虎中的後果**：底池已經 28bb，flush draw 的 equity 已足以支撐更積極的打法（semi-bluff），但玩家只是 call，錯失 fold equity。

**修正**：在炸虎底池中，semi-bluff raise 的 fold equity + equity 組合讓它比 call 更有利。

### 錯誤三：不調整 Bluff 頻率

**問題**：玩家認為「炸虎底池大，bluff 有風險」，因此不敢 bluff，只在有強牌時下注。

**在炸虎中的後果**：range 過於可讀，對手可以輕鬆 fold 弱牌，讓你的 value bet 無人跟注。

**修正**：炸虎底池大，bluff 成功時贏得的金額更可觀；同時，balanced range 要求在大底池下依然有適當的 bluff 比例。在 IP 時尤其要維持 bluff 頻率。

### 錯誤四：多人炸虎底池中過度 C-bet

**問題**：玩家在 9 人炸虎翻牌後習慣性地對所有人 c-bet（以為自己是「第一個下注的人」）。

**在炸虎中的後果**：多人底池中，所有人 range 都是全範圍，被 call 或 raise 的機率極高；c-bet bluff 在多人炸虎底池中幾乎無效。

**修正**：炸虎的第一個行動者不是「pre-flop aggressor」（炸虎沒有 aggressor），應以「你的手牌強度」而非「你是否是 aggressor」來決定是否下注。

### 錯誤五：忽略位置優勢

**問題**：因為炸虎「所有人都有大底池要爭奪」，玩家忽略了 OOP 在炸虎中的特殊劣勢。

**在炸虎中的後果**：OOP 以中等牌力大注下注，被 IP raise 後陷入困境。

**修正**：OOP 在炸虎中對中等牌力應更謹慎，考慮 check-raise 而非 donk bet，避免在 IP 大注面前處於被動。

## 第六章：MTT Bomb Pot ICM 考量

### ICM 對炸虎的特殊影響

在 MTT 中，ICM（Independent Chip Model）讓每一枚籌碼的「真實價值」並非線性——你損失的籌碼比你贏得的籌碼「更有價值」。

**炸虎如何放大 ICM 壓力：**

1. **強制性底池**：所有人都必須 post 炸虎額，這是強制的 ICM 風險
2. **底池更大**：28bb 底池意味著即使翻牌 fold，已損失 3bb；若 commit，損失可達全疊
3. **多人同時 commit**：炸虎中可能有 3-4 人同時進入 commit 模式，ICM 計算更複雜

### Bubble 附近的炸虎策略

在 MTT bubble（距離獲獎名次 1-3 名）時，炸虎的危險性被顯著放大：

**Bubble 炸虎核心原則：**

| 情況 | 建議策略 |
|------|---------|
| 你是深疊（20%+ chips）| 可以正常打，ICM 壓力相對較小 |
| 你是中疊（平均疊）| 謹慎 commit，只有 Top Pair+ 才 commit |
| 你是短疊（< 15bb after post）| 幾乎自動全壓模式（SPR < 1）|
| 你面對短疊的 all-in | ICM 要求寬泛 call（他的 range 是全範圍）|
| 你面對深疊的大注 | 比正常 SPR 更謹慎——深疊在 bubble 有 ICM 優勢 |

**Bubble 炸虎的 ICM 損失計算範例（簡化）：**

假設 10 人桌，獎金池如下：
- 1st: 40%, 2nd: 25%, 3rd: 15%，4th-10th: 0%
- 在 10 人 bubble（11 人剩下），你是平均疊（10% chips）
- 炸虎 3bb post 後，你的 ICM EV 已 slightly 下降
- 如果全壓並輸，你的 ICM EV 歸零（bust out）

**建議：Bubble 時炸虎，fold 邊緣手牌（Middle Pair、弱 Draw），只對明確強牌（Two Pair+）commit。**

### 短疊在炸虎中的自動全壓情境

當玩家在炸虎中 post 後剩餘 stack 極短時，幾乎進入自動全下模式：

**短疊炸虎計算（30bb 開局，3bb 炸虎，BBA）：**

```
開局 stack：30bb
Post 炸虎（BB 位，需同時 post BBA）：3bb + 1bb = 4bb
Post 後剩餘：26bb
翻牌底池：28bb
SPR = 26 / 28 = 0.93
```

**SPR < 1：玩家在翻牌第一次行動時幾乎必然全下。**

即使是 Middle Pair，在 SPR 0.93 的情況下，call 全下的 pot odds 幾乎永遠成立：

```
面對翻牌下注（例如對手下 14bb 進 28bb 底池）：
- 底池：28 + 14 = 42bb
- 需 call：14bb
- Pot odds：14 / (42 + 14) = 25%
- 你的 Middle Pair equity（vs 全範圍）：約 45-55%
→ Call 是絕對正確的
```

## 第七章：位置策略（Bomb Pot）

### BTN / CO（有位置優勢）

**BTN 在炸虎中的優勢：**

1. **最後行動**：看所有人翻牌行動後再決策
2. **range 資訊最多**：多人 check 暗示弱牌，有人大注暗示強牌
3. **控制底池大小**：可以選擇 check back 看免費轉牌或下注建大底池

**BTN 炸虎策略調整：**

| 手牌強度 | BTN 策略 |
|---------|---------|
| 強牌（Two Pair+）| 大注（75-100% pot），或 raise 他人的下注 |
| TPGK | 下注 50-75%，或 raise 小注 |
| 聽牌（9 outs+）| Semi-bluff 或 call（視人數） |
| 中等牌力 | Check back，免費看轉牌 |
| 弱牌 / Air | Check back 或 fold（若有人下注）|

**BTN 的特殊優勢**：在所有人 check 後，BTN 可以用任意強度的手牌下注偷底池（28bb 的底池值得偷）。但需要注意 check-raise 的可能——有人 check 不代表他沒有強牌。

### SB / BB（無位置）

**OOP 在炸虎中的挑戰：**

1. **行動最早**（SB 通常第一個行動）
2. **資訊最少**：還沒看到任何人的行動
3. **被 IP raise 後困境最深**：OOP 面對 raise，不知道 IP 的 range 強度

**SB / BB 炸虎策略：**

| 手牌強度 | OOP 策略 |
|---------|---------|
| 強牌（Two Pair+）| 直接大注（fast play），不讓 IP 免費看 |
| TPGK | 中等注（50% pot），準備應對 raise |
| 聽牌 | Check 或小額 semi-bluff |
| 中等牌力 | Check，評估 IP 行動 |
| 弱牌 | Check-fold |

**特別建議**：OOP 在炸虎中對強牌的 fast play 比正常底池更重要，因為底池大（28bb），讓 IP 免費看轉牌代價極高。

### 第一個行動者的責任

在炸虎中，第一個行動者（通常是 UTG 或 SB，視桌位規則）面臨最大的決策壓力：

**沒有任何翻牌前資訊可參考，且底池已是 28bb。**

**第一個行動者的決策原則：**

1. **先評估手牌強度**，再考慮下注
2. **強牌必須下注**：不能 check，讓 8 個對手免費看轉牌
3. **中等牌力考慮 check**：讓 IP 先定義 range，再決定 check-call 或 check-raise
4. **弱牌不要 donk bluff**：多人底池，bluff 幾乎無效
5. **有清晰計劃**：如果你下注 14bb（50% pot），且被 raise 到 42bb，你的回應是什麼？事先想好。

## 第八章：BBA 底池計算進階（含 Bomb Pot）

### 多種 Bomb Pot 情境的 BBA 計算

**情境 1：標準炸虎（3bb × 9 人 + BBA，100bb 深）**

```
翻牌底池：27bb + 1bb(BBA) = 28bb
有效籌碼（BB 位，付了炸虎和 BBA）：100 - 3 - 1 = 96bb
SPR = 96 / 28 = 3.43

三條街全下計劃（SPR 3.43）：
- 翻牌下注 75% pot = 21bb → 底池 70bb
- 轉牌下注 75% pot = 52.5bb → 底池 175bb（但 stack 只剩約 75bb）
→ 轉牌時幾乎全下（75bb into 70bb pot ≈ overbet）
→ 實際上 2 條街就完成全下
```

**情境 2：炸虎 4bb × 9 人 + BBA，50bb 深（中疊短疊情境）**

```
翻牌底池：36bb + 1bb(BBA) = 37bb
有效籌碼（BB 位）：50 - 4 - 1 = 45bb
SPR = 45 / 37 = 1.22

SPR < 2：翻牌一次下注即全下模式
- 翻牌下注 pot = 37bb → 底池 74bb + call 37bb = 111bb
→ 已接近全下
```

**情境 3：炸虎 2bb × 9 人 + BBA，100bb 深（保守炸虎）**

```
翻牌底池：18bb + 1bb(BBA) = 19bb
有效籌碼：100 - 2 - 1 = 97bb
SPR = 97 / 19 = 5.1

SPR 5.1：中等承諾，接近正常 3-bet 底池的 SPR
→ TPGK commit；Two Pair+ fast play
→ 可以打 2-3 條街，但還是比正常翻牌更快進入全下
```

### 炸虎中的 Pot Odds 快速計算（BBA 環境）

在 28bb 炸虎底池中，常見的下注金額和對應 pot odds：

| 下注金額 | 底池 + 下注 | 你的 Call 金額 | Pot Odds（需要的 equity）|
|---------|------------|--------------|------------------------|
| 14bb（50% pot）| 42bb | 14bb | 14/56 = 25% |
| 21bb（75% pot）| 49bb | 21bb | 21/70 = 30% |
| 28bb（100% pot）| 56bb | 28bb | 28/84 = 33% |
| 42bb（150% pot）| 70bb | 42bb | 42/112 = 37.5% |

### 手牌範例一：炸虎強牌 Fast Play

**賽制背景：**
- 線上 MTT，100/200 盲注，BBA 200
- 9 人桌，炸虎 3bb（600）每人
- 英雄籌碼：20,000（100bb）
- 位置：BTN

**翻牌前：** 所有 9 人各 post 600，BB 額外 post BBA 200
- 翻牌底池：**5,600（28bb）**

**英雄手牌：** Jh-9h

**翻牌：** Jc-Js-4d（英雄三條 J）

**翻牌行動：**
- UTG：Check
- UTG+1：Check
- MP1：Check
- MP2：Check
- HJ：Check
- CO：Check
- 英雄（BTN）：**下注 21,00（75% pot，21bb）**

**分析：**
- 三條 J 是極強牌，炸虎 SPR 3.43，必須 fast play
- 6 個人 check 給英雄，增加了部分對手「有中等牌、等英雄先行動」的可能
- 大注下注保護底池，不讓所有人免費看轉牌（可能有人有 flush draw 或 4）

**SB：Raise 到 6,000（30bb）**
- SB 可能持有 JX（兩對或 J 另一張）、44（葫蘆）、或 bluff

**英雄決策：**
- 底池：21,00 + 2,100（BB/其他 fold）+ 6,000 = 11,200
- SPR（after raise）：(20,000 - 2,100 - 6,000 fold) → 剩餘約 11,900
- 英雄 Re-raise All-In：Jam 剩餘 17,900

**分析：**
- 三條 J 在炸虎中近乎 nuts，面對 SB 的 raise，直接 re-raise all-in
- SPR 已低，沒有慢玩的理由
- SB 如果有 J（三條），對方 kicker 較小；如果有 44，英雄需要兩對以外的牌

**結果：** SB fold（可能有 TPGK 或中等對子），英雄贏得約 14,000 的底池。

**學習要點：**
- 炸虎強牌必須 fast play，即使在 BTN（有位置）也不應 slow play
- SB 的 raise 代表強度，但英雄的三條在 full range 環境中仍是極強手牌
- 炸虎底池 28bb + raise 後的底池已很大，all-in 是正確選擇

### 手牌範例二：炸虎 TPGK Commit 決策

**賽制背景：**
- 現場 MTT（Festival 賽事），200/400 盲注，BBA 400
- 9 人桌，炸虎 4bb（1,600）每人
- 英雄籌碼：40,000（100bb）
- 位置：SB（OOP）

**翻牌前：** 所有 9 人各 post 1,600，BB 額外 post BBA 400
- 翻牌底池：**14,800（37bb，含 BBA）**

**英雄手牌：** As-Kc

**翻牌：** Ad-7h-3c（英雄 TPBK，Top Pair Best Kicker）

**翻牌行動：**
- 英雄（SB，第一個行動）：**下注 7,400（50% pot）**

**分析：**
- AK on A-7-3 rainbow = TPBK，在炸虎 SPR 3.73 中幾乎是 commit 牌
- OOP 的英雄必須 fast play，不能 check（讓 8 個對手免費看轉牌）
- 50% pot 是合理起點，建立底池同時測試對手

**行動：**
- UTG：Fold
- UTG+1：Fold
- MP1：Call 7,400
- MP2-CO：全 Fold
- BTN：Raise 到 22,000

**此時狀況：**
- 底池：14,800 + 7,400 + 7,400 + 22,000 = 51,600
- 英雄需 call 額外 14,600（已付 7,400，BTN raise 22,000，差 14,600）
- 英雄剩餘 stack：40,000 - 1,600 - 7,400 = 31,000

**英雄決策分析：**

```
Pot odds 計算：
底池（含 call）：51,600 + 14,600 = 66,200
英雄需 call：14,600
Pot odds = 14,600 / 66,200 = 22%

英雄 equity（AK on A-7-3 vs BTN raise range）：
- BTN raise range（炸虎）：AA（set），77（set），33（set），A7，A3，77s
  → 這些 beat 英雄
- BTN 也可能有：AQ/AJ（TPGK but weaker），KK/QQ（overpair 但沒有 A）
  → 英雄 ahead
- Bluff：BTN raise bluff with FD or 更弱手牌

Equity 估算：英雄 AK vs 合理 BTN range ≈ 45-55%
45% > 22% pot odds → Call 是正確的
```

**英雄決策：Call 14,600**
- MP1 也 call（三路底池進入轉牌）

**轉牌：** 2s（底板 Ad-7h-3c-2s，彩虹翻牌，無明顯成牌板面）

**英雄行動（OOP）：All-in 31,000**（剩餘 stack 全下，進入 overbet 轉牌）

**分析：**
- 底池 66,200，英雄下 31,000（約 47% pot）—— 實為全下
- 剩餘 SPR ≈ 0（英雄已全下）
- 翻牌-轉牌 2 條街完成全下，與炸虎 SPR 3.7 的預期一致

**結果：** MP1 fold，BTN call with Ah-Qh（TPGK 同等，但 kicker 輸）
英雄贏得底池。

**學習要點：**
- 炸虎 TPBK 在 SPR 3.73 中是 commit 牌
- OOP 必須 fast play，不能讓多人免費看牌
- 面對 BTN raise，pot odds + equity 分析支持繼續（call）
- 轉牌 all-in 完成炸虎的 2 條街全下計劃

### 手牌範例三：炸虎 Flush Draw Semi-Bluff

**賽制背景：**
- 線上 MTT，100/200 BBA 200
- 6 人桌炸虎（6 × 600 = 3,600 + BBA 200 = 3,800 = 19bb）
- 英雄籌碼：20,000（100bb）
- 位置：CO（相對有位置）

**翻牌底池：3,800（19bb）**（6 人桌炸虎，SPR 更高）

**英雄手牌：** Kh-Qh

**翻牌：** Ah-9h-4c（英雄有 Nut Flush Draw，K 高）

**翻牌行動：**
- SB：Check
- BB：Check
- UTG：Check
- HJ：**下注 1,900（50% pot，9.5bb）**
- CO（英雄）：**Raise 到 6,500（約 3.4×）**

**分析：**
- Nut Flush Draw + K 高 = 英雄有約 40% equity（9 outs，另有 K 高 outs）
- 炸虎底池 19bb，SPR 5.3（6 人桌較高，但仍是高度承諾區間）
- 面對 HJ 的 50% pot 下注，英雄 raise 有兩個來源的 EV：
  1. Fold equity（HJ 可能持有中等牌，fold 給英雄底池）
  2. Equity（flush draw，即使被 call 也有約 36% 機率翻牌成 flush）

**HJ 決策（假設他有 A9，兩對）：**

```
HJ Pot odds 面對 raise：
底池：3,800 + 1,900 + 6,500 = 12,200
HJ 需 call：6,500 - 1,900 = 4,600
Pot odds = 4,600 / (12,200 + 4,600) = 27.4%

HJ 的 A9 equity vs 英雄（Nut FD range）：約 55-60%
60% > 27.4% → HJ call 是正確的
```

**HJ Call，其他人 Fold**

**轉牌：** Th（英雄成 Nut Flush！）

**轉牌行動：**
- HJ：Check（合理，面對英雄的 raise range，翻牌可能有強牌）
- 英雄：**下注 9,000（約 74% pot）**

**分析：**
- 英雄已成 Nut Flush，fast play 建大底池
- HJ 持有 A9（兩對），不知英雄已成 flush
- 下注 74% pot 是 value bet，假裝繼續 semi-bluff

**HJ：Call 9,000**

**河牌：** 2d

**底池：** 約 30,200

**轉牌行動：**
- HJ：Check
- 英雄：**All-in 4,500**（剩餘籌碼全下）

**結果：** HJ call，英雄 Nut Flush 贏得約 40,000 底池。

**學習要點：**
- 炸虎的大底池讓 semi-bluff raise 更有利（底池值得偷，equity 也支撐）
- Nut Draw 在炸虎中應積極打，而非保守 call
- 翻牌 raise → 轉牌 value bet → 河牌 all-in 是合理的 3 條街計劃

### 手牌範例四：Bubble 炸虎的 ICM 決策

**賽制背景：**
- 線上 MTT，Bubble（12 人剩下，11 名獲獎）
- 100/200 BBA 200，9 人桌炸虎 3bb（600）
- 英雄籌碼：18,000（90bb，略低於平均）
- 位置：UTG（第一個行動者）
- 最短疊玩家：5,000（25bb），坐在 BTN

**翻牌底池：5,600（28bb）**（含 BBA）
**英雄 post 炸虎後剩餘：** 18,000 - 600 = 17,400（87bb）

**英雄手牌：** Tc-8d

**翻牌：** Th-6h-2c（英雄 Top Pair，Weak Kicker，無 draw）

**翻牌行動（英雄，第一個行動）：**

**此時 ICM 分析：**

```
英雄情況：
- 底板：Th-6h-2c
- 手牌：T8o，TPWK（Top Pair Weak Kicker）
- 翻牌 SPR：17,400 / 28 = 6.2（因為 bubble，保守計算）
- 位置：OOP，沒有任何人的行動資訊

ICM 考量：
- Bubble 時，下注等於邀請對手 raise → 可能面對全下決定
- 全下面對全範圍，T8o 的 equity ≈ 40-50%（不確定）
- 如果全下輸掉，從 90bb 跌到 0，直接 bust（獎金 0）
- 如果 fold，剩餘 87bb，依然有 ICM 價值（可以等到 bubble break）

結論：在 Bubble 的炸虎中，TPWK 不是 commit 牌
→ 傾向 Check，而非主動建大底池
```

**英雄決策：Check**

**後續行動：**
- UTG+1：Check
- MP1：**下注 5,600（100% pot）**
- MP2-BTN：全 Fold
- 英雄面對全下決定

**再次 ICM 分析：**

```
面對 MP1 的 100% pot 下注（5,600 into 28bb）：
底池：28 + 5,600 = 33,600
英雄 call：5,600
Pot odds = 5,600 / 39,200 = 14.3%

Chip EV（不考慮 ICM）：
T8 equity vs MP1（下 100% pot range）≈ 40-45%
40% > 14.3% → Chip EV 上是 call

ICM 修正：
- 英雄在 bubble，call 並輸 → 損失約 5,600 chips（17,400 → 11,800）
  ICM EV 下降顯著
- 英雄 fold → 剩 17,400，ICM EV 維持

ICM 修正後的正確決定：通常是 Fold
→ TPWK 在 Bubble 炸虎中，面對 pot-size 下注，ICM 修正建議 Fold
→ 如果是 TPGK（T9+）則可考慮 Call
```

**英雄決策：Fold**

**結果：** 英雄放棄 3bb 炸虎 post，但保住 87bb 的 ICM 價值，等待 bubble break。

**學習要點：**
- Bubble 時炸虎的 ICM 壓力比普通底池更大（所有人都 post 了大量籌碼）
- TPWK 在 Bubble 炸虎中通常不值得 commit
- 第一個行動者 check 是合理選擇（保留資訊優勢）
- ICM 修正讓 chip EV 正的決定也可能變成 fold

## 總結：Bomb Pot 核心要點

1. **炸虎的翻牌 SPR 通常在 2-5 之間**，遠低於正常手牌（12-17），整體承諾門檻大幅降低。

2. **BBA 讓炸虎底池再增加 1bb**，SPR 進一步壓縮（標準 3bb 炸虎：28bb 底池，SPR 3.4）。

3. **Top Pair Good Kicker 在炸虎中幾乎等同強牌**，應計劃在 2 條街內全下。

4. **聽牌在炸虎中更有攻擊性**：底池已大，semi-bluff 的 fold equity + equity EV 遠高於 call。

5. **多人炸虎底池中，降低 bluff 頻率**，但在單挑或 heads-up 翻牌後可維持 bluff 比例。

6. **位置在炸虎中更重要**（因無翻牌前資訊），IP 可更廣泛 call 聽牌，OOP 對中等牌力應更謹慎。

7. **Bubble 炸虎的 ICM 壓力被放大**：所有人都強制 post，建議只對 Two Pair+ 在 bubble 時 commit（中疊情況）。

8. **短疊在炸虎中幾乎自動全下**：SPR < 1.5 時，幾乎任何有 equity 的手牌都值得全下。
