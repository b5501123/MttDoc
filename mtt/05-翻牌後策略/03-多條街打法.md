# 多條街打法：轉牌與河牌的決策邏輯

## 多條街的核心思維

翻牌只是起點，轉牌（turn）和河牌（river）決定了大多數大底池的最終結果。

多條街打法的三個核心問題：
1. **我的手牌在這條街的 equity 如何？**（仍有 draw，還是已成牌，還是完全沒有）
2. **SPR 告訴我還有多少空間？**（剩餘籌碼 / 底池，決定是否 commit）
3. **這條牌對誰更有利？**（range advantage 是否改變）

---

## SPR 與 Commitment 的關係

SPR（Stack-to-Pot Ratio）= 有效籌碼 ÷ 底池

| SPR | 狀態 | 策略含義 |
|-----|------|---------|
| >6 | 深，有後手空間 | 可以打多條街，慢玩有意義 |
| 3-6 | 中等承諾 | 打到底的選擇已定型 |
| 1-3 | 高度承諾 | 翻牌有強牌直接全壓最優 |
| <1 | 已 commit | 繼續跟注到底 |

**MTT 的特殊性：** MTT 中由於籌碼深度持續下降，SPR 通常比 Cash Game 更低。在 40-60bb 的深度，翻牌後 3-bet 底池的 SPR 可能已經是 1-2，直接進入 commit 模式。

## 翻牌後的 Range 演變

### 翻牌（Flop）

- 建立 range 的初步分類：強牌 / 中等手牌 / draw / 空氣
- 決定打法路線：bet/check，value/bluff

### 轉牌（Turn）

轉牌是「強化線路」的時機：
- Draw 完成 → 成牌，可以繼續下注
- Draw 未完成 → 考慮是否繼續 bluff（還有一張牌機會）
- Value hand → 繼續 bet（增加底池）
- 中等手牌 → 通常 check/control pot

**轉牌牌面的影響：**

| 轉牌類型 | 對 pre-flop aggressor | 建議 |
|---------|---------------------|-----|
| Blank（完全無關的牌）| 維持 flop range advantage | 繼續 bet（高頻） |
| 完成 draw 的牌（4th flush card）| 可能讓對手完成 draw | 謹慎，size up 或 check |
| 配對翻牌的牌（board pairs）| 改變 range advantage | 分析受益者 |
| A 或 K（high card）| 通常對 EP openers 有利 | EP 玩家 bet 頻率高 |

### 河牌（River）

河牌是「最終決定」：
- 沒有更多 draw，純粹 value vs bluff 決策
- 選牌 size：通常 50-75% 底池（value 或 bluff）
- 常見的 polarized sizing（小牌面 100%，或極小的 25%）

**河牌 bluff 的條件：**
1. 你的 range 在河牌有 bluff combo（曾經 bet，但沒有成牌的手牌）
2. 對手的 range 有 bluff catcher（中等強牌，願意 call 但不想 raise）
3. Size 要夠大（讓對手的 call 需要 40-45%+ 勝率）

## 打法路線的一致性

每一條街的動作都應該是「故事」的一部分，前後要一致。

**例子（一致的價值線路）：**
- UTG open → BB call
- Flop K-J-5：UTG c-bet（有 KK/KJ/JJ/AK）
- Turn 7：UTG bet again（同樣的手牌繼續）
- River A：UTG bet（AK 成了大兩對，繼續 value）

**例子（一致的 bluff 線路）：**
- CO open → BB call
- Flop 9-8-6：CO check（看起來是 A-high 或 pair）
- Turn 7（完成了多種 draw）：CO bet（代表 5678 等 straight）
- River 2（完全 blank）：CO can still bluff（代表之前的 draw 是 T-7 或 J-T）

不一致的打法（如翻牌 bet，轉牌 check，河牌 bet）讓你的 range 不清楚，對手更容易做出最優決策。

---

## MTT 的多條街簡化原則

在 MTT 中，以下情況下應該簡化打法（傾向更直接的 bet/fold）：

1. **SPR < 3：** 直接以強牌 bet/shove，不玩複雜線路
2. **ICM 壓力高（bubble/FT）：** 複雜的多條街 bluff 風險更高，減少精細操作
3. **位置劣勢 + 弱牌：** OOP 持有空氣，不要試圖多條街 bluff

## 線上多桌時的多條街決策

多桌情境是線上 MTT 的主要挑戰之一。

**問題：** 同時面對多個桌的翻牌後決策，很難對每個底池做複雜分析。

**建議：**

### 主桌原則
確認哪桌是你最重要的桌（通常是籌碼最多、最接近關鍵時刻的桌），給予完整專注。

### 次桌簡化策略
對於次要的桌：
- 使用更簡化的 c-bet / check 規則（例如：有成牌就 bet，無成牌就 check）
- 避免複雜的 check-raise bluff 和三條街 bluff 線路
- 接受在次要桌損失一些 EV，換取主桌的完整專注

### 減桌原則
當任何一桌進入關鍵時刻（bubble、FT、大底池），立刻減少其他桌的數量。

**實際建議：**
- 初學者：最多 2 桌
- 有經驗：最多 4 桌（但 bubble/FT 時減至 1-2 桌）
- 每桌 BB 定時器不要讓自己常常只剩 5 秒決定

## 常見多條街錯誤

**錯誤 1：轉牌自動繼續 bet（不分析轉牌的影響）**
翻牌 c-bet 後，轉牌來了一張 flush 完成牌，對手有可能完成了 flush。不分析就繼續 bet 是錯誤。

**錯誤 2：中等手牌多條街 call（pot 過度 committed）**
翻牌 call，轉牌 call，河牌被大 bet，手持 TP 中等 kicker 不知道該怎麼辦。解決方案：在翻牌或轉牌更早決定（raise 或 fold），而不是被動 call 到河牌。

**錯誤 3：河牌 over-bluff（太多 bluff combo）**
河牌選擇所有沒成牌的手牌 bluff，但 bluff combo 遠多於 value combo，對手的正確策略是大幅增加 call 頻率並直接 exploit 你。

**錯誤 4：忘記 SPR 導致不必要的打法複雜化**
SPR 已經是 2（幾乎 commit），仍然嘗試複雜的 check/raise/re-raise 線路。應直接打到底。
