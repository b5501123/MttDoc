# 多人底池策略：MTT 多方對戰翻牌後決策

## 前言：為什麼多人底池是最難的情境

多人底池（Multiway Pot）是德州撲克中最被低估的難點之一。大多數玩家的策略訓練集中在單挑（heads-up）場景，但在 MTT 中，3-way、4-way 甚至 5-way 的底池非常普遍，尤其是在早期深疊階段。

錯誤地將單挑策略應用在多人底池是最常見的漏洞之一，代價非常昂貴。

---

## 第一節：多人底池的核心差異

### 1.1 需要更強的牌才能 Bet/Call

這是最根本的原則。在單挑底池，你的手牌只需要在對一個對手 range 的比較中有優勢。在多人底池，你的手牌需要在對抗多個對手的組合 range 中有優勢。

**數學說明：**

假設每個對手各有 30% 的機率打敗你的手牌（獨立計算）：
- 1 個對手：30% 機率有人打敗你
- 2 個對手：1 - (0.7 × 0.7) = 1 - 0.49 = **51% 機率有人打敗你**
- 3 個對手：1 - (0.7 × 0.7 × 0.7) = 1 - 0.343 = **65.7% 機率有人打敗你**

即使你的手牌只有 30% 被每個個別對手打敗，在 3-way 底池，超過 65% 的情況你會輸。

**實際影響：**

在單挑底池有價值的牌，在多人底池可能沒有價值：

| 手牌 | 單挑底池 | 3-way 底池 | 4-way 底池 |
|------|---------|-----------|-----------|
| 頂對中 kicker（TPMK） | 強，可大注 | 謹慎，中注 | 很弱，check |
| 中對（pocket pair 中） | 可下注 | 弱，通常 check | 基本無價值 |
| 底部兩對 | 中等 | 弱 | 非常弱 |
| 頂部兩對 | 強 | 中等 | 謹慎 |
| Set（三條） | 非常強 | 強 | 強（但仍需謹慎） |
| Flush | 非常強 | 強，但注意 nut | 只有 nut flush 有信心 |

### 1.2 Bluff 成功率急劇下降

在多人底池進行 bluff 需要**所有對手都 fold**。這使得 bluff 的成功率按指數降低。

**折疊成功率計算（假設每個對手各有 60% fold 頻率）：**

- 1 個對手：60% 成功率
- 2 個對手：60% × 60% = **36% 成功率**
- 3 個對手：60% × 60% × 60% = **21.6% 成功率**
- 4 個對手：60%^4 = **12.96% 成功率**

換句話說，在 4-way 底池，即使每個對手面對你的 bet 有 60% fold 頻率，你的 bluff 也只有 13% 的成功率。這幾乎不可能有盈利的 bluff。

### 1.3 更多 Nut Hands 在 Showdown

在多人底池，到達 showdown 的玩家通常都有強牌，因為：
- 在面對多方的底池中，中等牌的玩家通常早早棄牌或被擠出
- 願意在多人底池多條街下注/call 的玩家，通常有非常強的手牌

**這意味著：** 如果你只有中等強牌，在多人底池 showdown 通常輸。

## 第二節：3-Way 底池打法

### 2.1 翻牌 C-Bet 頻率的調整

在單挑底池，翻牌前 raiser 在翻牌上 C-bet 的頻率可以高達 50-70%（取決於牌面和位置）。

在 3-way 底池，C-bet 頻率應該**大幅降低**，通常只在以下情況才 bet：

**可以 C-bet 的情況（3-way）：**

1. **你有 top pair 或更強的牌**
   - 頂對好 kicker（TPTK）在乾燥牌面仍可 C-bet
   - Set、兩對等超強牌明顯可以 bet

2. **你有 Nut draw（堅果聽牌）**
   - Nut flush draw + 兩張高牌 = 足夠強可以 C-bet
   - Open-ended straight draw with overcards

3. **牌面非常有利於你的 range**
   - 你從 UTG raise，牌面 A-K-3（rainbow）= 非常有利於 UTG 的 range
   - 在這種情況下，即使是 3-way，C-bet 頻率可以維持

**不應該 C-bet 的情況（3-way）：**

1. **你只有 backdoor draw**
   - 沒有即時 equity，且有兩個對手可能 call

2. **你有中等強牌但牌面不利**
   - 例：你有 66，翻牌 K-Q-J（非常不利，任何人有任何 broadway 牌都超過你）

3. **你沒有任何牌，只是 air**
   - 多人底池純 air bluff 幾乎沒有 EV

**3-Way C-bet 頻率參考：**

| 情況 | 單挑頻率 | 3-Way 頻率 |
|------|---------|-----------|
| BTN vs BB（干燥牌面） | 60-70% | 35-45% |
| BTN vs BB（潮濕牌面） | 45-55% | 25-35% |
| EP vs 2 個 callers | 55-65% | 25-35% |
| 所有乾燥、有利牌面 | 任何 | 降低 20-25% |

### 2.2 OOP（無位置）在 3-Way 底池的打法

當你 OOP（out of position，沒有位置），在 3-way 底池需要更加謹慎。

**OOP 的核心策略：Check 更多，等對手暴露信息**

原因：
- 你不知道後面的玩家有什麼
- 下注後，後面的玩家可能 raise，讓你陷入困境
- Check 讓你免費看到對手的行動，收集信息

**OOP 在 3-way 的具體打法：**

情況一：你在 BB，SB 和 BTN 都 call（3-way，你 OOP）

```
牌面：Q♠ 8♣ 4♦（你在 BB，SB 和 BTN 都進入翻牌）

你的手牌：Q♥ J♣（頂對中 kicker，TPMK）
```

**推薦打法：Check**

理由：
- 雖然你有頂對，但還有兩個對手
- 如果你 bet，可能面對 raise（有人有 QQ, 88, 44 或 Q8 等）
- Check 讓你看到後面玩家的反應
  - 如果 SB check，BTN bet：你可以考慮 call 看轉牌
  - 如果 SB bet，BTN raise：你的 QJ 在這裡很難受，容易 fold
- 保護你的 checking range，也讓你在強牌時不總是 bet

情況二：你有非常強的牌（set 或以上）

```
牌面：J♥ 9♣ 4♠

你的手牌：J♣ J♦（set of Jacks）
```

**推薦打法：bet（因為牌面潮濕，需要保護）**

理由：
- J-9-4 是 connected 牌面，有很多 draw（T8, Q8, KQ 等）
- 你有 set，但對手可能在抽牌
- 下注保護你的強牌，同時建立底池
- 即使在 3-way，set 在潮濕牌面需要主動 bet

### 2.3 IP（有位置）在 3-Way 底池的打法

有位置給你信息優勢，但在多人底池，這個優勢縮小了，因為你面對更多對手。

**IP 在 3-way 的核心原則：**

1. **等前面玩家行動，不要急著 bet**
   - 如果前面玩家都 check，你可以選擇 bet 或 check back
   - 根據你的手牌強度和牌面來決定

2. **仍然需要謹慎的 C-bet sizing**
   - 在多人底池，C-bet 通常用較小的 size（1/3 - 1/2 pot）
   - 大注在多人底池風險更高（如果被 raise，損失更大）

3. **有位置的 check-back 很有價值**
   - 你可以用中等強牌 check-back，然後在後面的街根據牌面決策

**IP 具體例子：**

```
場景：MTT 早期，100bb 深疊
BTN（你）vs SB vs BB（3-way）

翻牌前：你在 BTN raise 2.5bb，SB call，BB call

翻牌：A♥ K♦ T♣（pot 8bb）

SB check，BB check

你的手牌：Q♠ J♠（open-ended straight draw，Broadway draw）
```

**分析：**

你有 QJ on A-K-T：
- 你有 open-ended straight draw（9 完成 9-K straight，Q 的組合... 等等）
- 實際上：A-K-T，你有 QJ，需要 J 或 Q 在後面？不對，J 已在手牌
- 更正分析：QJ on A-K-T，你有 QJ，如果 J 在牌面... 不，J 在你手中
- A-K-T 牌面，你有 QJ：J 與 Q 都在手中。你需要任何 9（完成 K-Q-J-T-9）或 J... 不，J 在手
- 正確：你的 QJ 在 A-K-T 牌面有 gutshot straight draw（需要 J 出現在牌面... 但 J 在你手裡）

讓我重新分析：
- 你有 Q♠ J♠
- 牌面 A♥ K♦ T♣
- Broadway draw：A-K-Q-J-T（你需要公牌出 Q 和 J，但你的手牌已有 Q 和 J！）
- 所以你需要的是 A-K-Q-J-T 其中公牌已有 A, K, T，你手有 Q, J
- 你已經有了 Broadway 的所有五張！A-K-Q-J-T = Broadway Straight（最大順子）

恭喜！你已經有 Broadway Straight！

**決策：Bet for value（約 1/2 pot，4bb）**

你有 nuts（Broadway）在 3-way 底池。這是罕見的情況，你應該 bet 建立底池。

但為什麼用 1/2 pot 而非更大？
- 3-way 底池，大注可能嚇跑所有人
- 1/2 pot 讓對手（可能有 AK, AT, KT, A-x 等）願意 call
- 建立底池，後面的街繼續 bet

### 2.4 被多人 Call 後的轉牌/河牌策略

在 3-way 底池翻牌 bet 後，如果被多人 call，後面的打法更加謹慎。

**多人 call 後的轉牌策略：**

1. **繼續 barrel 的條件更嚴格**
   - 你需要比單挑更強的牌才繼續下注
   - 或者牌面對你有利（出現了你 range 的好牌）

2. **Check 評估的頻率上升**
   - 如果你的優勢不明確，check 讓你省錢且看到信息

3. **注意 draw completion**
   - 如果轉牌完成了 flush 或 straight，你的非 nut 強牌可能突然變弱

## 第三節：4+ 人底池打法

### 3.1 基本原則：打 Nut，否則棄牌

在 4 人以上的底池，策略大幅簡化：**只有 nut 或接近 nut 的手牌才值得投入大量籌碼**。

什麼是「Nut」或「接近 Nut」？

- **Nut**：在當前牌面上最強的可能手牌（flush nuts, straight nuts, full house 等）
- **接近 Nut**：在非常低概率被打敗的情況（top full house, top set with 有利牌面）

**為什麼這個原則如此重要？**

在 4-way 底池，對手中有強牌的概率大幅上升。統計上：
- 每個對手各有 10% 機率有非常強的牌
- 4-way：1 - (0.9^4) = 34% 的概率至少有一個對手有強牌

### 3.2 有 Nut Potential 的手牌在多人底池的優勢

「Nut Potential」指的是手牌能夠完成非常強的組合的能力。

**最有 Nut Potential 的手牌類型：**

1. **高階套牌（Suited aces/kings）**
   - A♠ K♠：如果成花，通常是 nut flush
   - 即使未成花，AK 有頂對頂 kicker 的 value

2. **Pocket Pairs（暗對）**
   - 高暗對（TT+）在多人底池有 set mining 價值
   - Set 在多人底池是非常強的手牌

3. **Suited Connectors（同花連張）**
   - 67♥8♥ 類型的手牌能完成 nut straight 或 nut flush
   - 在深疊多人底池，implied odds 很好

4. **Low pairs for set mining**
   - 22-66 這類小對，在多人深疊底池有很好的 set mining implied odds

### 3.3 多人底池中的 Set Mining

Set Mining 是指用小對/中對在翻牌前跟注，希望在翻牌上 flop 三條（set），然後贏得大底池。

**Set Mining 的 EV 計算：**

- 你用口袋對打 flop set 的概率：約 11.8%（約 8 比 1 不利）
- 為了讓 set mining 盈利，你需要在 flop set 時贏得足夠的籌碼

**Set Mining 公式（粗略估算）：**

```
需要的 implied odds = 跟注金額 × 8
```

例子：翻牌前需要跟注 10bb，你需要在 flop set 時能贏至少 80bb（通常是指對手的有效籌碼深度）。

**多人底池讓 Set Mining 更有價值的原因：**

1. **更大的隱含賠率（Implied Odds）**
   - 多個對手意味著更多的「付錢者」
   - 如果你 flop set，可能從多個對手拿到籌碼

2. **更少被發現的概率**
   - 多人底池通常有更多人在翻牌和轉牌，分散了注意力
   - 你的 set 更容易被誤判為 bluff 或弱牌

3. **Set 在多人底池更有信心**
   - 在單挑底池，你的 set 可能面對對手的超強牌（full house 等）
   - 在多人底池，set 贏得底池的概率仍然很高

**Set Mining 具體例子：**

```
場景：MTT 早期，100bb 深疊，6 人桌
UTG raise 2.5bb，MP call，CO call，你在 BTN call with 7♠7♣，BB fold
4-way pot（about 11bb）

翻牌：7♥ 4♦ 2♣

你 flopped a set of sevens！
```

在這個 4-way 底池，你有 set：
- 對手可能有 AK, AQ, 99, TT（overcards）
- 對手可能有 44, 22（lower set，你 beats 他們）
- 對手可能有 55, 66, 66（underpairs，你 beat）

這是 set 在多人底池的理想情況，牌面很乾燥（no flush draw），你的 set 很有可能是最強牌。

**推薦打法：Check，讓對手在 dry board 繼續 bluff，或 lead bet to build pot**

### 3.4 Flush Draw 在多人底池

在多人底池，flush draw 的策略與單挑截然不同：**你需要 nut flush draw，否則成花也可能輸**。

**Non-nut Flush Draw 的危險：**

```
牌面：K♥ 8♥ 4♣（4-way 底池）

你的手牌：7♥ 6♥（有 flush draw，但不是 nut）
```

即使你完成了 flush，你可能輸給有 A♥ 或 Q♥ 的對手！在 4-way 底池，某個對手有更高花色牌的概率非常高。

**在多人底池，Flush Draw 的建議：**

1. **只有 A-high 或 K-high flush draw 才值得積極打**
   - A♥ x 的 flush draw = nut flush draw，可以在多人底池繼續
   - 更低的 flush draw 應謹慎，可能只是「付錢完成花但輸給 nut flush」

2. **有額外 equity 的 flush draw 更好**
   - Flush draw + overcards（如 A♥ K♥ on K-5-2 two hearts）= 很強
   - Flush draw + straight draw = 可以更積極

## 第四節：多人底池常見錯誤

### 4.1 用 Bluff 嘗試拿多人底池

這是最昂貴的錯誤之一。許多玩家在多人底池看到翻牌很差（對自己的手牌），仍然嘗試用 bluff 拿走底池。

**為什麼多人底池 bluff 幾乎沒有 EV：**

數學回顧：假設每個對手有 55% fold 頻率（已經很高了）：
- 2 個對手：55% × 55% = 30% 成功
- 3 個對手：55%^3 = 16.6% 成功
- 4 個對手：55%^4 = 9.1% 成功

如果你需要全部 fold 才能成功，在 4-way 底池，即使每個人有超過一半的機率 fold，你的 bluff 成功率只有 9%！

**幾乎任何 bet sizing 在 9% 成功率下都是虧損的 bluff。**

### 4.2 用非 Nut 強牌在大底池下注

另一個常見錯誤是用「強牌」（但非 nut）在多人大底池積極下注，結果被 raise 後陷入困境。

**具體例子：**

```
4-way 底池，你有 A♠ K♥
翻牌：K♣ Q♦ J♥

你有頂對頂 kicker（TPTK），但牌面非常 connected（K-Q-J 可能完成很多順子）
```

你的 AK 雖然強，但在 K-Q-J 牌面：
- 任何人有 T9（Broadway 順子已完成！）就打敗你
- 任何人有 KK, QQ, JJ（set）就打敗你
- KQ, KJ, QJ（兩對）也打敗你

在 4-way 底池，至少一個對手有這些強牌的概率非常高。**用 TPTK 在 4-way 大底池 bet large 是巨大錯誤。**

**正確打法：Check（pot control），等對手行動再決策**

### 4.3 低估後面玩家的牌力

在多人底池中，「平跟注」（flat call）通常代表強牌，因為：
- 在有多人在底池的情況，用 flat call 而非 raise 的玩家，通常有很強但想要慢玩（slowplay）的手牌
- 或者他們有很好的隱含賠率手牌（set mining, 套牌）

**例子：**

```
UTG raise，MP call，CO call，BTN call，SB fold，BB call

翻牌：A♦ K♠ Q♣（5-way 底池）

UTG bet 60% pot
```

在這個情況，MP/CO/BTN 的 flat call 可能代表：
- AK（兩對）
- AQ（兩對）
- Broadway 順子（JT，已完成！）
- Set（AA, KK, QQ）

如果你是 MP 只有 AJ（兩對或一對 A），在這個 5-way 底池面對 UTG 的 bet，很多跟注後的玩家可能有比你更強的手牌。**低估這些玩家的牌力會讓你在 turn 和 river 支付過多。**

## 第五節：MTT 多人底池的 ICM 考量

### 5.1 多人 All-In 的 ICM 複雜性

當多人 all-in 時，ICM 計算變得非常複雜。簡單的「我有 55% 勝率」不再足夠，必須考慮：

- 你對每個對手的單獨勝率
- 每個對手的籌碼量對 ICM 的影響
- 你的 payout 結構位置

**例子：三人全下（3-way all-in）**

```
Final Table ICM 情境：
- 剩餘 4 人
- 你：50bb
- 對手 A：50bb
- 對手 B：30bb
- 短疊：30bb（旁觀者）

三人底池 all-in：你 vs A vs B
```

在這種情況，即使你在三人 all-in 中是籌碼 favorite，ICM 可能使這個全下 EV 為負，因為：
- 如果你和 A 都輸給 B，你的 ICM 地位大幅下滑
- 有時候「生存」比「贏得籌碼」更有 ICM 價值

### 5.2 Bubble 時避免多人底池

在 bubble 附近，多人底池是高度危險的情境。

**Bubble 多人底池的危險：**

1. **增加了被淘汰的方式**
   - 在單挑底池，你只需要打敗一個對手
   - 在多人底池，多個對手增加了你輸的可能

2. **保護 ICM 贏進 money 的機會**
   - 每個「survive」的玩家讓你更接近 money
   - 在 bubble 進行多人底池大注，即使有 chip EV 優勢，ICM 調整後可能不划算

3. **Bubble 策略：縮緊多人底池的跟注範圍**

   當面對多人底池時：
   - 提高跟注標準（需要更強的牌才 call）
   - 避免 speculative 手牌（套牌、小對 set mining）在 bubble 的多人底池
   - 除非你有很強的保護（chip lead），否則不要在多人底池冒巨大風險

### 5.3 深疊 vs 短疊的多人底池差異

**深疊（100bb+）多人底池：**

- Set mining、套牌的 implied odds 非常好
- 可以進行更多的「投機」性手牌
- 多人底池的複雜性更高，需要更精細的閱讀

**短疊（< 30bb）多人底池：**

- 推注或棄牌（push or fold）策略大幅簡化決策
- 多人底池通常只有一次 push 機會，沒有翻牌後的精細策略
- ICM 壓力在短疊時更大，更容易錯誤地在多人底池全下

## 第六節：具體場景分析

### 場景一：3-Way 底池，你有 Set，如何建立底池

```
MTT 早期，100bb 深疊
UTG raise 2.5bb，BTN（你）call，BB call（3-way，pot 8bb）

你的手牌：8♣ 8♥

翻牌：8♦ 5♣ 2♠（你 flopped set of eights！）
```

**分析：**

你有 set in a 3-way pot，牌面 8-5-2（乾燥，無 flush draw，無 straight draw）。

UTG 是翻牌前 raiser，BB 是 flat caller。

**UTG 的行動：**
- 如果 UTG C-bet：你應該如何應對？
- 如果 UTG check：你應該怎麼打？

**情況 A：UTG check，BB check（dry flop，UTG 可能 C-bet 放棄）**

如果你 IP bet（say 40% pot）：
- 對手可能 fold（乾燥牌面，C-bet 後通常大家 fold）
- 但你的 set 想要建立底池

**推薦：bet 40% pot（小注，讓對手有理由 call 或 float）**

理由：
- 乾燥牌面，你不需要大注保護
- 小注讓對手（可能有 55, 22 或 overcards）覺得值得繼續
- 建立底池，後面的街繼續加注

**情況 B：UTG C-bet**

UTG C-bet 60% pot（4.8bb），BB fold，輪到你：

**推薦：Call（flat call，不要 raise）**

理由：
- UTG C-bet 可能是 continuation bet（可能沒有牌）
- 如果你 raise，UTG 沒有 value 的牌會 fold，你只拿到小底池
- Flat call 看轉牌，如果 UTG 繼續 bet，你可以在轉牌或河牌 raise
- 「慢玩」讓 UTG 繼續在後面的街 bluff

### 場景二：4-Way 底池，你有 Flush Draw，如何打

```
MTT 中期，60bb 有效籌碼（考慮短疊）
EP raise，MP call，BTN call，你在 BB call（4-way，pot 8bb）

你的手牌：A♥ 7♥

翻牌：K♥ T♣ 3♥（4-way，pot 8bb）

EP bet 5bb，MP fold，BTN call，輪到你
```

**分析：**

你有 A♥ 7♥：
- 你有 nut flush draw（A♥ 是最高的心花牌）
- 牌面 K♥ T♣ 3♥ 有兩張心花
- 如果完成 flush，你有 nut flush

對手 EP bet，BTN call：這是 3-way（對你來說）的翻牌決策。

**你的 equity：**
- Nut flush draw：約 9 個 outs × 2 = 18% on turn，或 9 × 4 = 36% by river（粗略估算）
- 有時候 A♥ 可能打到 pair（但 K-T 牌面，A 打到 pair 價值有限）

**決策：Call（或 raise）**

Call 理由：
- 你有 nut flush draw，implied odds 很好（3-way pot，如果完成花，可能從多個對手拿籌碼）
- Raise 也可能合理（fold equity + equity），但 4-way 之後仍有 BTN 在

**Call 後的計劃：**
- 轉牌如果出心花：大注甚至 overbet（你有 nut flush）
- 轉牌如果沒有心花：check-fold（outs 減少，已無太多價值）

### 場景三：多人底池，你決定不 Bluff

```
MTT 後期，盲注 500/1000
CO raise 2,200，BTN call，SB call，BB call（4-way，pot 9,200）

你的手牌（你在 SB）：K♦ Q♣

翻牌：A♠ J♥ 8♦（pot 9,200）

BB check，CO check，BTN check，輪到你
```

**分析：**

你有 KQ on A-J-8：
- 你有 gutshot straight draw（T 完成 Broadway A-K-Q-J-T，不對，你有 K-Q，需要 T 和 J... 已有 J，需要 T）
- 實際上：A-J-8，你有 K-Q。你需要 T（讓你有 A-K-Q-J-T）
- 這是 gutshot straight draw + backdoor flush potential

4-way 底池，A-high 牌面，大家都 check。

**應該 bluff 嗎？**

分析：
- 你有 K♦ Q♣：blocker 效果一般（K 擋住了對手的 AK 一個組合，Q 擋住了 AQ 一個組合）
- 你有 gutshot（需要 T），约 4 個 outs
- 4-way 底池，bluff 成功率非常低

**決策：Check（不 bluff）**

理由：
- 4-way 底池 bluff 需要所有 4 人（包括你后面的 3 人）fold
- 即使每人 60% fold 率，成功率只有 21.6%
- 你的 gutshot 有 4 個 outs（約 8% 完成機率）
- Check，看轉牌是否能完成 draw 再決定

**轉牌決策：**
- 如果出 T（完成 Broadway）：你有 nuts，開始建立底池
- 如果出其他牌：繼續 check，等待免費或低成本的機會看河牌

### 場景四：多人底池 ICM 壓力下的棄牌決策

```
MTT Bubble（前 20 進錢，剩 22 人）
你的籌碼：28bb
其他人：25bb, 30bb, 45bb（最大疊，你是第二大）

UTG（45bb chip leader）raise 2.5bb
MP call
CO call
你在 BTN，手牌：T♠ T♣（口袋 TT）
```

**分析：**

這是一個非常難的決策。口袋 TT 在正常情況下是很強的手牌，在 bubble 的 ICM 情境下，需要重新評估。

**選項：**

1. **3-bet（re-raise）**
   - 如果 chip leader 4-bet，你必須考慮 5-bet all-in 或 fold
   - ICM 風險極高

2. **Call（進入多人底池）**
   - 多人底池，TT 的勝率下降
   - 如果翻牌出 A, K, Q，你可能要 fold
   - 但可以 set mine！

3. **Fold（最保守）**
   - 在 bubble，TT call 有 ICM 風險
   - 如果你 fold，你確保進入 money（假設你的 28bb 足夠生存到 bubble 破裂）

**Bubble ICM 調整：**

在正常 cash game，TT vs 3 opponents call/raise 是不用考慮的，當然跟注或 3-bet。

在 MTT bubble 上，**你需要計算 ICM 折扣**：
- 你現在 28bb，在 bubble 存活的 ICM value 很高
- 如果你在多人底池輸了一半籌碼（14bb），你的 ICM 地位大幅下降
- 如果有短疊（25bb）在底池，all-in 情況下你可能被淘汰

**建議：Call（不要 3-bet），翻牌再看**

理由：
- TT 足夠強可以翻牌
- 翻牌後如果沒有過牌且有人下注，可以 fold（保護 ICM）
- 如果 flop set，可以在多人底池拿大底池
- 避免 3-bet（拒絕面對 chip leader 的 4-bet 壓力）

## 第七節：多人底池策略總結

### 核心原則清單

1. **牌力要求提升**
   - 多人底池需要更強的牌才能積極下注
   - 中等強牌（TPMK, 中對）通常應該 check-call 或 check-fold

2. **杜絕多人底池 bluff**
   - 除非你有非常好的理由和 blockers，否則不要在多人底池 bluff
   - 數學上，多人底池 bluff 幾乎都是 EV 負的

3. **Set mining 價值更高**
   - 在深疊多人底池，小對/中對的 set mining 是很好的 play
   - Set 在多人底池的 implied odds 非常好

4. **只用 Nut Flush Draw 積極打**
   - 在多人底池，非 nut flush draw 完成後可能輸給更高的 flush
   - 只有 A-high flush draw 才值得在多人底池積極下注

5. **ICM 在多人底池的影響**
   - Bubble 時，多人底池的 ICM 風險更高
   - 避免在 bubble 的多人底池進行邊緣 call

### 多人底池策略速查表

| 情況 | 推薦策略 |
|------|---------|
| 有 set，dry board，3-way | Bet（小注或 check-raise） |
| 有 TPTK，connected board，4-way | Check（pot control） |
| 有 nut flush draw，3-way | Bet/call（建立底池） |
| 有 non-nut flush draw，4-way | Check-fold 若無其他 equity |
| 完全沒牌，4-way | Check-fold，絕不 bluff |
| 有 Broadway 順子，任意多人 | 積極 bet（但注意 sizing） |
| Bubble，多人底池邊緣手牌 | 提高棄牌頻率 |
