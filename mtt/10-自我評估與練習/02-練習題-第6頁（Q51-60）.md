# 練習題 第6頁：計算題（Q51-60）

這一頁需要動筆計算，建議先在紙上算好再看答案。

難度：⭐ 基礎 / ⭐⭐ 中級 / ⭐⭐⭐ 進階

**本頁前提：所有底池計算均預設 Big Blind Ante（BBA）格式。**
BBA 標準：BB 付大盲 + 額外 1bb ante，底池 = SB + BB + BB ante（例：100/200 → 底池 500）

---

**51. ⭐⭐**
底池 120bb，對手 all-in bet 80bb。你的 call 損益平衡勝率是多少？

<details>
<summary>答案</summary>

所需勝率 = Call 金額 ÷ Call 後底池
= 80 ÷ (120 + 80 + 80) = 80 ÷ 280 = **28.6%**

BBA 說明：此計算本身是翻牌後的情境，不直接受 BBA 設定影響（底池已形成）。但要注意，在 BBA 環境下，翻牌底池本身比傳統大，因此到了這個 all-in 情境時，120bb 的底池比傳統格式更常見（BBA 翻牌底池更大，多條街後累積更快）。

</details>

---

**52. ⭐⭐**
盲注 1000/2000，**BBA 2000**。你在 BB，已投入 2,000（大盲）+ 2,000（BB ante）= 4,000。CO open 2.5bb（5,000 chips），其他人 fold，SB fold。你要 call，需要付多少？Call 後底池多少？損益平衡勝率？

<details>
<summary>答案</summary>

**BBA 底池計算：**
```
- 需補：5,000 - 2,000（大盲）= 3,000 chips（1.5bb）
  （BB ante 2,000 已計入你的前期投入，不計入需補金額）

- 翻牌底池（BBA）：
  CO 5,000 + BB call 5,000 + SB fold 500（留底池）= 10,500 chips
  （含 BB ante 的貢獻：大盲 2,000 + ante 2,000 + 補 1,000 = 5,000）

更精確計算：
  CO 5,000 + BB 5,000（含 ante）+ SB 500（fold 留底）= 10,500 chips

- 損益平衡：
  Call 金額 = 3,000
  Call 後底池 = 10,500 + 3,000 = 10,500（已算入）
  所需勝率 = 3,000 ÷ 10,500 = **28.6%**

傳統（無 ante）比較：
  底池 = 5,000 + 5,000 + 500 = 10,500（相同，因 BB ante 計入 BB 投入）
  所需勝率 ≈ 相同（BBA 下 BB 的前期投入包含 ante，結果類似）
```

面對 CO open，你需要約 28-29% 勝率才值得 call。在 BBA 環境下，BB 的投入已包含 ante（2bb total），讓 BB 的 call EV 比傳統略高。

</details>

**53. ⭐⭐**
對手 bet 50% pot（BBA 底池 200bb，bet 100bb）。為了讓你的 bluff call 在河牌有利，對手的 bluff 頻率需要超過多少？

（此題底池已是翻牌後既成底池，BBA 對計算公式無影響，但底池形成時已使用 BBA）

<details>
<summary>答案</summary>

損益平衡 = 100 ÷ (200 + 100 + 100) = 100 ÷ 400 = **25%**

對手的 betting range 中需要超過 25% 是 bluff，你的 call 才是正 EV。

BBA 背景說明：
```
在 BBA 環境下，底池到達 200bb 的速度更快（翻牌底池本身更大）。
這意味著到了河牌，對手的 bet 金額（100bb）的絕對值更大，
但損益平衡 bluff 頻率計算方式不變（仍是 25%）。

BBA 讓底池在各條街都更大，讓強牌的 value betting 和 bluff catching
的金額都更高，但判斷對手 bluff 頻率的邏輯不變。
```

</details>

**54. ⭐⭐**
你有 flush draw（9 outs），還有一條街。盲注 500/1000，**BBA 1000**。翻牌底池（BBA）= 5,500 chips。對手 bet 75% pot（= 4,125 chips）。你有足夠勝率 call 嗎？

```
BBA 底池 = 5,500 chips
對手 bet 75% = 5,500 × 75% = 4,125 chips

所需勝率：
Call 金額 = 4,125
Call 後底池 = 5,500 + 4,125 + 4,125 = 13,750 chips
所需勝率 = 4,125 ÷ 13,750 = 30%
```

<details>
<summary>答案</summary>

- 所需勝率（BBA 75% pot bet）= 4,125 ÷ 13,750 = **30%**
- 9 outs 的勝率（一條街）：約 **9 × 2 = 18%**（近似法）或更精確約 19%

**18% < 30%，純 pot odds 不夠，fold 是正確的。**

BBA 說明：
```
BBA 翻牌底池（5,500）比傳統（5,000）大 10%。
75% 的 bet 金額更大（4,125 vs 3,750），
但所需勝率不變（仍是 30%）。

在 BBA 環境下，flush draw 面對 75% bet 仍然是 fold（pot odds 不足）。
除非有 implied odds（完成 flush 後可以在 BBA 大底池贏更多）才可以考慮 call。
BBA 底池讓 implied odds 略微更好（底池更大，完成後可贏更多），
但不足以讓純 odds call 變成正確的。
```

</details>

**55. ⭐⭐**
你有 open-ended straight draw（8 outs），翻牌後還有轉牌和河牌。轉牌勝率（一條街）大約多少？河牌勝率？翻牌到攤牌的總勝率？

（此題為純勝率計算，不受 BBA 影響）

<details>
<summary>答案</summary>

- **轉牌勝率**（1條街）：8 × 2 = 約 **16%**
- **河牌勝率**（1條街）：8 × 2 = 約 **16%**
- **翻牌到攤牌**（2條街）：8 × 4 = 約 **32%**（近似法）

精確計算：翻牌到攤牌的勝率約為 31-32%。

BBA 應用：
```
在 BBA 環境下，OESD（8 outs）的 call/fold 決策要基於 BBA 底池：

假設翻牌底池（BBA）= 5,500 chips，對手 bet 50%（2,750 chips）：
  所需勝率（一條街）= 2,750 ÷ (5,500 + 2,750 + 2,750) = 2,750 ÷ 11,000 = 25%
  轉牌勝率 16% < 25% → 純 pot odds 不足

但考慮 implied odds（兩條街）：翻牌到攤牌 32% 足夠補償，
call 考慮兩條街的 implied odds 可能是正確的（特別在深疊 BBA 環境）。
```

</details>

**56. ⭐⭐**
你在 BTN，push 12bb，CO call range 是 TT+, AKs, AKo。盲注 1000/2000，**BBA 2000**。你有 A♣ K♦（AKo），AK 對這個 call range 的大約勝率是多少？

**BBA push 底池計算：**
```
BTN push 12bb = 24,000
底池（BBA，含 SB/BB fold）= 24,000 + 500 + 2,000 + 2,000 = 28,500 chips
（或含所有 fold 的 ante）
```

<details>
<summary>答案</summary>

AKo vs 緊 call range（TT+, AKs, AKo）：

- AK vs AA：約 7% 勝率（dominate）
- AK vs KK：約 30% 勝率（dominated）
- AK vs QQ/JJ/TT：約 45% 勝率
- AK vs AKs：約 50%
- AK vs AKo：約 50%

**整體約 40-45% 勝率**（因為 AA/KK 大量 dominate）

注意：AK 對緊 call range 不是強牌！

BBA 說明：
```
BBA push 底池（28,500 chips）比傳統（26,500）大。
你的 BTN push EV（成功時）更高：
  成功 push → 贏 28,500 - 24,000 = 4,500 chips（淨）
  傳統 → 贏 26,500 - 24,000 = 2,500 chips

BBA 讓 push 成功的 EV 更高，但如果被 call，
AK 對 TT+/AK 的勝率分析不受 BBA 影響（仍是 40-45%）。
這個 push 在 BBA Nash 環境下仍然是正確的（fold equity + BTN 的 push range advantage）。
```

</details>

**57. ⭐⭐⭐**
SPR 計算（BBA 版本）：盲注 200/400，**BBA 400**。你在 BTN open 2.5bb（1,000 chips），SB fold，BB call。翻牌底池多少（BBA）？你有 100bb，翻牌 SPR 是多少？

<details>
<summary>答案</summary>

**BBA 翻牌底池計算：**
```
BTN raise = 1,000 chips
BB call = 1,000 chips（含 BB 的大盲 400 + ante 400 + 補 200）
SB fold = 200 chips（留底池）
翻牌底池（BBA）= 1,000 + 1,000 + 200 = 2,200 chips（5.5bb）

傳統（無 ante）翻牌底池 = 1,000 + 1,000 + 200 = 2,200 chips
（相同，因為 BB ante 計入 BB 的總投入 1,000 中）

更精確的 BBA 計算：
  SB fold 留底 = 200（SB 的 0.5bb）
  BB 投入 = 400（大盲）+ 400（ante）+ 200（補到 BTN 1,000）= 1,000
  BTN raise = 1,000
  翻牌底池 = 200 + 1,000 + 1,000 = 2,200 chips = 5.5bb
```

有效籌碼 = min(BTN 99,000 remaining, BB 99,000 remaining) = **99,000 chips**（99bb）

SPR（BBA）= 99,000 ÷ 2,200 = **45**

（傳統 SPR ≈ 99,000 ÷ 2,000 = 49.5，BBA 讓 SPR 略低）

BBA 補充：SPR 非常高（45），有大量後手空間，可以玩多條街複雜打法。在 BBA 環境下，SPR 比傳統略低（45 vs 49.5），代表你的 commitment 程度略高，但兩者都是深疊，差別不大。

</details>

**58. ⭐⭐⭐**
ICM 簡化計算：3人剩餘，獎金 1st $600 / 2nd $400 / 3rd $0。三人籌碼各 33%。你的大致 ICM equity 是多少？

（此題為純 ICM 計算，與 BBA 無關，但在 BBA 環境下積累籌碼更快，三人局的籌碼分佈可能更快達到）

<details>
<summary>答案</summary>

簡化估算：
- 贏 1st 機率 ≈ 33%，獲得 $600
- 贏 2nd 機率 ≈ 33%（非精確），獲得 $400
- 拿 3rd 機率 ≈ 33%，獲得 $0

ICM equity ≈ 33% × $600 + 33% × $400 + 33% × $0
= $198 + $132 + $0 = **$330**

（精確 ICM 計算會略有不同，但大約在 $330 附近）

BBA 說明：BBA 底池在三人局影響更大（每圈成本 2.5bb，三人輪流做 BB 的速度更快）。三人局的盲注壓力在 BBA 下更強，短疊更快被消耗，ICM 決策的時機更緊迫。

</details>

**59. ⭐⭐⭐**
BBA 底池計算練習：盲注 1000/2000，**BBA 2000**，9人桌。你在 BTN，open 4000（2bb）。SB/BB fold。你淨贏了多少？

<details>
<summary>答案</summary>

**BBA 底池（你 open 前，SB/BB 已在底池）：**
```
SB = 1,000
BB = 2,000（大盲）
BB ante = 2,000
底池合計 = 1,000 + 2,000 + 2,000 = **5,000 chips（2.5bb）**

（傳統無 ante：底池 = 1,000 + 2,000 = 3,000 chips）

你 open BTN = 4,000 chips，SB/BB fold：
  你贏 = 5,000 chips（SB + BB + BB ante）
  你花費 = 4,000 chips（open 成本）
  淨收益 = 5,000 - 4,000 = **+1,000 chips**

傳統（無 ante）淨收益：
  贏 3,000 - 花 4,000 = -1,000（等等，不對）
  正確：贏 SB + BB = 1,000 + 2,000 = 3,000，花 4,000，淨 = -1,000？

不對——成功偷盲是「收回投注 + 贏對方的投入」：
  你投入 4,000，對方（SB + BB = 1,000 + 2,000 + 2,000 = 5,000）fold
  你收回 = 4,000（你的）+ 5,000（對方）= 9,000
  淨收益 = 9,000 - 4,000 = **+5,000 chips（你淨贏 SB+BB+ante = 5,000）**

BBA 淨收益：+5,000 chips
傳統淨收益：+3,000 chips（僅 SB + BB）
BBA 多贏：+2,000 chips（BB ante 部分）
```

**BBA 讓每次成功偷盲多贏了 2,000 chips（BB ante 部分）！**

這就是為什麼在 BBA 環境下 BTN/CO/SB 應該更積極 open，steal EV 比傳統格式高出 67%。

</details>

**60. ⭐⭐⭐**
你的 MTT bankroll 管理（BBA 版本）：你打 $25 MTT（BBA 格式，線上），建議最低資金是多少？如果你打了 50 場，虧損了 $300，你應該怎麼做？

<details>
<summary>答案</summary>

- 建議最低資金：$25 × 100 = **$2,500**（保守）或 $25 × 50 = **$1,250**（激進）

50 場虧損 $300：
- 這是正常方差範圍（MTT 需要數百場才能看出 EV）
- BBA 環境下：確認你是否正確使用 BBA Nash 計算（push/fold 用 BBA 數值）
- 確認你的剩餘資金是否仍在 50-100 買入
- 如果資金剩餘 < 50 買入 → **降級**（打 $10 MTT）
- 分析手牌確認是壞牌還是打錯了
- **BBA 特別檢查：** 確認所有 push/fold 計算使用 BBA Nash（HRC/ICMIZER BBA 設定），確認底池計算包含 BB ante

BBA 說明：在 BBA 格式下，每圈成本更高（2.5bb vs 1.5bb），stack 燃燒速度更快，MTT 的方差可能比傳統格式略大。這讓 bankroll 管理更重要，保守的 100 buy-ins 標準在 BBA 環境下更有道理。

</details>
