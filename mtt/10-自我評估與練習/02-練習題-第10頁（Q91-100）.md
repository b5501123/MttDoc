# 練習題 第10頁：最終綜合挑戰（Q91-100）+ 計分

難度：⭐⭐⭐ 進階

**本頁前提：所有底池計算均預設 Big Blind Ante（BBA）格式。**
BBA 標準：BB 付大盲 + 額外 1bb ante，底池 = SB + BB + BB ante（例：100/200 → 底池 500）

---

**91. ⭐⭐⭐**
請列出 BBA Bubble 時各角色（大疊/中疊/短疊）的最重要的「一件事」，並加入 BBA 底池計算支持：

<details>
<summary>答案</summary>

**大疊：積極偷盲，施壓中疊（BBA 讓每次成功偷盲的 EV 更高）**
```
BBA steal EV（盲注 1000/2000，BBA 2000）：
  成功贏 = SB 500 + BB 2,000 + BB ante 2,000 = 4,500 chips
  傳統 = SB 500 + BB 2,000 = 2,500 chips
  BBA 提升 80%
中疊因 ICM 壓力 fold 更多，大疊 BBA bubble steal 是 EV 最高的時機。
```

**中疊：縮緊 push range 15-20%，避免和大疊大底池（BBA 底池讓大底池更危險）**
```
BBA 底池讓每次 all-in 輸掉的損失更大（籌碼更多流動）。
中疊在 BBA bubble 應使用 ICMIZER BBA 設定計算 push range，
而非傳統 Nash（BBA push range 比傳統略寬，但 ICM 縮緊更強）。
中疊面對大疊 raise 的 BBA call EV = 非常負（ICM 壓力 > BBA chip odds）。
```

**短疊：按 BBA Nash push/fold，不要等到 2-3bb 才 push（BBA fold equity 更快消失）**
```
BBA 短疊 push EV：
  成功 push 贏 BBA 底池（4,500 chips）> 傳統（2,500 chips）
  但 2-3bb 時，call 金額相對底池小，fold equity 幾乎消失
  短疊應在 8-10bb 時積極 push，使用 BBA Nash push range
```

</details>

**92. ⭐⭐⭐**
請解釋為什麼 SB 幾乎不應該 limp call 或 limp fold，而應該 raise or fold（BBA 環境下更加重要）。

<details>
<summary>答案</summary>

SB limp 的三個問題（BBA 版本）：

1. **免費讓 BB 看牌（BBA 讓 BB 更有動力 raise）：**
   BB 已付了大盲 + ante（2bb），非常不願意讓 SB 廉價進入底池。
   SB limp 後，BB 可能 raise（利用 BBA 底池優勢），SB 要面對 limp-fold（浪費 0.5bb）或 limp-call（OOP 進入更大底池）。

2. **翻牌後 OOP（BBA 底池更大，OOP 更被動）：**
   BBA 翻牌底池更大（2.5bb vs 1.5bb 傳統），OOP 的劣勢在 BBA 大底池中更顯著。
   SB limp 後 OOP 面對 BBA 大底池的 c-bet，check-fold 損失更多。

3. **Limp-fold 浪費半個盲注（BBA 讓每個盲注成本更貴）：**
   BB 每圈已付 2bb（BBA），SB 如果 limp-fold 只是浪費 0.5bb，但整體來說代表糟糕的策略。

**Raise 的優點（BBA 加成）：**
- 可能贏得底池（BB fold）→ BBA 底池 2.5bb，比傳統 1.5bb 更多
- SB raise 成功偷盲贏 2.5bb，EV 比傳統高 67%
- 翻牌後雖然 OOP，但 SPR 更合理

**結論：BBA 讓 SB 偷盲 EV 更高，更應該 raise or fold，而非 limp。**

</details>

**93. ⭐⭐⭐**
解釋為什麼「9-max UTG push range 比 6-max UTG 更緊」，並給出 BBA Nash 數字佐證。

<details>
<summary>答案</summary>

原因：後面需要過的人越多，push 的成功率越低。

- **6-max UTG**：後面有 5 個人（HJ, CO, BTN, SB, BB）
- **9-max UTG**：後面有 7 個人（UTG+1, UTG+2, LJ, HJ, CO, BTN, SB, BB）

更多人 = 更多人可以 call（且對手可能有強牌） = push range 更緊。

**BBA Nash 數字（ICMIZER/HRC BBA 設定）：**
```
6-max UTG 10bb BBA Nash push：≈ 37%
9-max UTG 10bb BBA Nash push：≈ 28%
差距 9%，顯著影響哪些手牌可以 push

BTN 差異小（兩者都只需過 SB/BB）：
  6-max BTN ≈ 67%
  9-max BTN ≈ 65%
  差距僅 2%
```

**BBA 的影響（對比傳統 Nash）：**
```
BBA 讓所有位置的 push range 比傳統稍寬（約 +2-3%），因為底池更大。
但位置差異（6-max vs 9-max UTG）的 9% 差距仍然顯著。

6-max UTG BBA push（37%）>> 9-max UTG BBA push（28%）
這個差距在邊緣手牌（QJo, KTo, 55 等）的決策上非常重要。
```

</details>

**94. ⭐⭐⭐**
描述一個完整的 Bluff Catching 手牌分析流程（BBA 格式）：盲注 500/1000，**BBA 1000**。你在 BB，call 了 BTN open 2.5bb（2,500 chips）。翻牌 Q♦ J♠ 5♣（BBA 翻牌底池計算），你有 K♥ T♣（open-ended straight draw）。BTN c-bet 50%，你 call。轉牌 2♠（空白），BTN bet 50%，你 call。河牌 3♥（空白，draw miss），BTN overbet 120% pot。你的分析（全程用 BBA 底池計算）？

<details>
<summary>答案</summary>

**BBA 底池全程追蹤：**

```
翻牌底池（BBA）：
  BTN 2,500 + BB 2,500 + SB fold 500 = 5,500 chips（5.5bb）

翻牌 c-bet 50%：5,500 × 50% = 2,750 chips
Call → 轉牌底池 = 5,500 + 2,750 + 2,750 = 11,000 chips

轉牌 bet 50%：11,000 × 50% = 5,500 chips
Call → 河牌底池 = 11,000 + 5,500 + 5,500 = 22,000 chips

河牌 overbet 120%：22,000 × 120% = 26,400 chips
```

**逐步分析（BBA）：**

翻牌（BBA 底池 5,500）：KTo 有 OESD（8 outs），call 合理。

轉牌（BBA 底池 11,000）：空白，繼續 call。BTN 雙桶代表：有強牌（QQ, JJ, KJ, QJ）或有 draw 繼續或 bluff。

**河牌 overbet 120%（BBA 底池 22,000 → overbet 26,400）：**
- BTN 的 strong hands（QQ, JJ, QJ）通常用標準 value bet，不需要 overbet
- River overbet 最常見的是：nut 強牌或 bluff
- 翻牌是 QJ5，沒有太多 flush draw
- BTN 的 overbet 有相當機率是：missed draw bluff 或空氣牌

**BBA 損益平衡計算：**
```
overbet 120%（26,400 chips）
所需 bluff 頻率 = 26,400 ÷ (22,000 + 26,400 + 26,400)
               = 26,400 ÷ 74,800 ≈ **35.3%**

傳統底池（無 BBA）河牌底池 ≈ 20,000，overbet ≈ 24,000：
所需 bluff 頻率 = 24,000 ÷ (20,000 + 24,000 + 24,000) = 24,000 ÷ 68,000 ≈ 35.3%
（比例相同，因為 overbet 比例不變）

你的 KT 在這個 line 能 beat 所有 bluff（KT 比 QJ, 9x 等 bluff 強）。
```

**行動：Call（Bluff catch）**

你的 KT 打不贏 QQ/JJ，但打得贏大量 bluff，且損益平衡合理（35%）。BTN 在 BBA 大底池做 overbet 的 bluff 頻率通常 > 35%。

</details>

**95. ⭐⭐⭐**
一個玩家從不 3-bet bluff，只 3-bet value（QQ+, AK）。如何利用這個弱點？在 BBA 環境下，這個弱點的可利用性如何變化？

<details>
<summary>答案</summary>

**利用方式：**

1. **面對他的 3-bet：fold 更多，包括 JJ 也可以 fold**
   - 他 3-bet = QQ+, AK，你的 JJ 對這個 range 是弱牌

2. **你的 open 不需要擔心他的 3-bet**
   - 他幾乎不會 bluff 3-bet，你可以更放心地 open

3. **你可以用更多 4-bet bluff 針對他**
   - 他 3-bet 後如果被 4-bet，他知道你可能有 KK+
   - 他的 QQ 可能 fold 你的 4-bet bluff

4. **面對他的 3-bet，你可以選擇性 5-bet shove**
   - 他 3-bet = QQ+, AK，你有 KK/AA 時 5-bet 是強牌

**BBA 環境下的可利用性增強：**
```
在 BBA 格式下，這個弱點更值得利用：

1. BBA 底池讓 3-bet 後底池更大：
   你 open 2.5bb，他 3-bet 8bb（BBA 環境）：
   底池（BBA）= 8bb + 2.5bb + SB 0.5 + BB 2bb（含 ante）= 13bb
   他 3-bet 後底池比傳統（11bb）大 18%

2. 你的 4-bet bluff 在 BBA 底池 EV 更高：
   成功 4-bet bluff（他 3-bet 後 fold）：
   BBA 底池 13bb → 你的 4-bet bluff 成功贏得 13bb
   傳統底池 11bb → 成功贏得 11bb
   BBA 讓 4-bet bluff 的 EV 提升 18%

3. 識別這個玩家後：
   對他的 3-bet，KQ/AJ/TT 等 fold（比 Nash 更多 fold）
   你 open 的 range 可以更寬（他不會 3-bet bluff）
   在 BBA 大底池環境下，他的 value-only 3-bet 更容易被識別和利用
```

</details>

## 計分參考（BBA 版本）

| 正確題數 | 評估 |
|---------|------|
| 75-100 | 很好，BBA 理論基礎紮實，計算精確 |
| 55-74 | 中等，有幾個 BBA 計算需要加強的區塊 |
| 35-54 | BBA 基礎還在建立，多練習 BBA 底池計算 |
| <35 | 建議從第 01 章重新閱讀，特別是 BBA 相關章節 |

重點不是分數，而是**哪些題目答錯了**，以及**是否因為 BBA 計算錯誤而答錯**。

**BBA 自我評估核心問題：**
1. 你能立即心算任何盲注的 BBA 底池嗎？（1000/2000 → 5,000）
2. 你用 HRC/ICMIZER 時，是否永遠選擇 BBA 設定？
3. 你計算 SPR 時，是否使用 BBA 翻牌底池而非傳統底池？
4. 你在 PKO 中，是否正確計算 BBA Chip EV + Bounty EV 的組合？
5. 多桌時，你能快速確認每桌的 BBA 底池大小嗎？

如果以上五個問題有任何一個答「否」，那個地方就是你需要回去複習的章節。
