# 練習題 第5頁：快速判斷（Q41-50）

每題只需給出行動和一句理由。

難度：⭐ 基礎 / ⭐⭐ 中級 / ⭐⭐⭐ 進階

**本頁前提：所有底池計算均預設 Big Blind Ante（BBA）格式。**
BBA 標準：BB 付大盲 + 額外 1bb ante，底池 = SB + BB + BB ante（例：100/200 → 底池 500）

---

**41. ⭐ BTN，7bb，盲注 1000/2000，BBA 2000，K♠ 5♣，所有人 fold → ?**

BBA 底池（push 成功）= 500 + 2,000 + 2,000 = 4,500 chips

<details><summary>答案</summary>

**Push**。BTN 7bb BBA Nash push range ≈ 76%，K5o 在 range 內。BBA 底池 4,500 chips（比傳統 3,000 多 50%），push EV 更高。

</details>

---

**42. ⭐ UTG，20bb，盲注 500/1000，BBA 1000，T♦ 9♦，9-max → ?**

BBA 底池（push 成功）= 250 + 1,000 + 1,000 = 2,250 chips

<details><summary>答案</summary>

**Fold**。UTG 20bb BBA Nash push range ≈ 13%，T9s 不在 range 內，UTG 後有 7 個玩家，BBA 底池雖大但無法補償位置劣勢。

</details>

---

**43. ⭐ SB，12bb，盲注 1000/2000，BBA 2000，對 BB，A♣ 2♦ → ?**

BBA 底池（push 成功）= 500 + 2,000 + 2,000 = 4,500 chips（SB push 成功贏）
- SB push 24,000，BB fold：SB 淨贏 BBA 底池中 BB 的貢獻 = 2,000 + 2,000 = 4,000 chips（扣掉 SB 自己的 500）

<details><summary>答案</summary>

**Push**。SB push range 很寬（BBA ≈ 62%），A2o 有 Ace 牌力，只需過 BB 一人。BBA 底池讓 SB 的偷盲 EV 更高，push 明確正確。

</details>

---

**44. ⭐⭐ BB，盲注 1000/2000，BBA 2000，面對 BTN push 10bb，你有 66，計算 BBA pot odds 決定 call/fold → ?**

**BBA 底池計算：**
```
BTN push = 20,000（10bb）
SB fold = 500
BB 已投入 = 2,000（大盲）+ 2,000（ante）= 4,000

底池 = 20,000 + 500 + 4,000 = 24,500
（或更精確：20,000 + 500 + 2,000 = 22,500，BB ante 包含在 BB 投入）
call 需補 = 20,000 - 2,000 = 18,000

所需勝率（BBA）= 18,000 ÷ (22,500 + 18,000) = 18,000 ÷ 40,500 = **44.4%**
```

<details><summary>答案</summary>

**Call**。BBA 所需勝率 ≈ 44.4%（傳統 45.5%，BBA 降低約 1%），66 對 BTN 65% BBA push range 勝率約 45-46%，略超 BBA 所需勝率，Call 是正 EV。

</details>

---

**45. ⭐⭐ Bubble，中疊 22bb，盲注 1000/2000，BBA 2000，BTN open 2.5bb（5,000 chips），你 BB 有 Q♠ Q♦ → ?**

**BBA 底池（call）：** BTN 5,000 + BB call 5,000 + SB fold 500 = 10,500 chips（5.25bb，加上 BB ante 已計入）

<details><summary>答案</summary>

**3-bet（或 call）**。QQ 是強牌，bubble 中疊應該用 QQ 打，但尺寸要合理（不要 shove 全部）。3-bet 到約 7-8bb（14,000-16,000 chips），翻牌後見機行事。

BBA 說明：3-bet 後底池（BBA）= BTN 5,000 + BB 3-bet ≈ 14,000-16,000，BBA 底池讓你的 3-bet 代表更大的爭奪，施壓效果更好。

</details>

---

**46. ⭐⭐ 翻牌 J♦ T♠ 9♥，你 OOP 有 A♠ K♠（two overcards + backdoor）→ bet 還是 check？**

**BBA 場景：** 假設翻牌底池（BBA）= 5,500 chips（BTN open，BB call，SB fold）

<details><summary>答案</summary>

**Check**。超濕潤翻牌，OOP，AK 只有 overcards，bet 被 raise 後很難受。Check 保留選擇（check-call 或 check-fold）。

BBA 說明：BBA 底池（5,500）讓翻牌的賭注更大，在超濕潤翻牌 OOP 主動 bet 的風險更高（被 check-raise 損失更多）。Check 是 BBA 環境下 AK miss 的正確保守打法。

</details>

---

**47. ⭐⭐ 轉牌出現 flush，你之前 C-bet 翻牌被 call，現在 OOP 有 T♥ T♣（no flush）→ ?**

**BBA 場景：** 假設翻牌底池（BBA）= 5,500，c-bet 1,815（33%），call 後轉牌底池 = 5,500 + 1,815 + 1,815 = 9,130 chips

<details><summary>答案</summary>

**Check/evaluate**。轉牌 flush 讓對手的 call range 可能包含 flush。Check，如果對手 bet 大，考慮 fold；如果 bet 小，考慮 call。

BBA 說明：BBA 翻牌底池更大，c-bet 金額更高（1,815 vs 傳統約 1,650），轉牌底池（9,130）也更大。面對大底池的 flush board，check/evaluate 更謹慎，保留籌碼用於後續更有價值的決策。

</details>

---

**48. ⭐⭐ 河牌空白，你有 K♥ Q♥（second pair），對手三條街都 bet 小（33% 每條街）→ call 還是 fold？**

**BBA 底池追蹤：**
```
假設翻牌底池（BBA）= 5,500
翻牌 bet 33% = 1,815，call → 轉牌底池 = 9,130
轉牌 bet 33% = 3,013，call → 河牌底池 = 15,156
河牌 bet 33% = 5,001
```

<details><summary>答案</summary>

**傾向 Call（Bluff catch）**。三條街小 bet 可能是 thin value 或大量 bluff。損益平衡低（33% bet 需要 20% bluff 頻率），call 通常有利。

BBA 說明：BBA 翻牌底池更大，三條街小 bet 的累積金額也更大（河牌 call 5,001 chips vs 傳統約 4,350）。但損益平衡 bluff 頻率不變（仍是 25% 左右），call 在 BBA 環境下仍然是正確的。KQ second pair 在這條 line 是有效的 bluff catcher。

</details>

**49. ⭐⭐⭐ PKO Bubble，盲注 500/1000，BBA 1000。你有 40bb，對手 short stack 10bb，他的賞金是你進場費的 3 倍。他 push，你有 A♦ 7♦ → call 還是 fold？**

**BBA 底池計算：**
```
對手 push 10bb = 10,000
底池（BBA）= 10,000 + 250（SB，假設 SB fold）+ 1,000（BB）+ 1,000（BB ante）= 12,250
call 需補 = 10,000 - 1,000 = 9,000
所需勝率（BBA）= 9,000 ÷ (12,250 + 9,000) = 9,000 ÷ 21,250 = **42.4%**
```

<details><summary>答案</summary>

**Call**。BBA 追殺 EV 計算：
```
BBA 所需勝率 = 42.4%（比傳統 44% 更低）
A7s 對短疊寬 push range 勝率 ≈ 57-60%，遠超 42.4%
追殺 EV = 賞金（3× 進場費）× 50% × 57% = 高正 EV

BBA + 賞金雙重加成：call 明顯正確。
短疊 push range 很寬，A7s 有足夠勝率，加上 BBA 讓 chip EV 更好，
再加賞金 EV → 三重正值，毫無疑問 call。
```

</details>

---

**50. ⭐⭐⭐ HU，盲注 1000/2000，BBA 2000，你 BTN/SB，30bb，手牌 5♣ 3♦ → push 還是 fold？**

**BBA 底池（push 成功）：**
```
SB push = 60,000
HU BBA 底池（push 成功，BB fold）：
  SB push 60,000，BB fold，SB 贏 BB 的 2,000（大盲）+ 2,000（ante）= 4,000 chips 淨收益
```

<details><summary>答案</summary>

**Push（或 open small）**。HU 30bb BBA push range 很寬（≈55%），5-3o 是邊緣牌，但 HU 只需過 BB 一人，push 可以。也可以 min-raise 2bb 試探。

BBA 說明：BBA 讓 HU push 的底池 EV 更高（BB 多付了 ante），每次成功偷盲贏得 4,000 chips（BB 大盲 + ante）而非傳統的 2,000（只有大盲）。這讓邊緣牌如 53o 在 HU BBA 環境下 push EV 更正向。

</details>
