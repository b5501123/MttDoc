# 練習題 第9頁：綜合分析（Q81-90）

這一頁需要完整分析，沒有選擇題。

難度：⭐⭐⭐ 進階

**本頁前提：所有底池計算均預設 Big Blind Ante（BBA）格式。**
BBA 標準：BB 付大盲 + 額外 1bb ante，底池 = SB + BB + BB ante（例：100/200 → 底池 500）

---

**81. ⭐⭐⭐**
你在線上 MTT（BBA 格式），觀察到對手有以下統計：VPIP 45%, PFR 8%, Fold to C-bet 75%。
請描述這個對手的類型，以及你應該採取什麼策略（包含 BBA 底池的應用）。

<details>
<summary>答案</summary>

**類型：鬆弱（Loose Passive / Calling Station）**

- VPIP 45% = 參與很多底池（鬆）
- PFR 8% = 很少主動加注（被動）
- Fold to C-bet 75% = 翻牌面對 c-bet 會 fold

**對策（BBA 版本）：**
1. **C-bet 幾乎所有翻牌**（他 fold 75%，非常有利可圖）
2. **多 value bet，少 bluff**（他會 call 中等牌，但 c-bet 有效因為他先 fold）
3. 翻牌後如果他 call C-bet，通常有牌力 → 減少 bluff
4. 不要用複雜的 3-bet bluff line（他會 call）
5. **等強牌建大底池**，他會 call 到底

**BBA 底池應用：**
```
盲注 1000/2000，BBA 2000。對手做 BB：
  BBA 翻牌底池（你 open，他 BB call）= 約 5,500 chips

  C-bet 33%（BBA）= 1,815 chips
  他 fold 75% → EV = 75% × 5,500 = 4,125 chips（直接贏底池）
  他 call 25% → 需要繼續打（有牌力才繼續）

  BBA 讓你的 c-bet 金額更大（1,815 vs 傳統 1,650），
  成功 fold 贏得更多，對 Calling Station 的 c-bet EV 更高。

三條街 value bet（BBA 累積）：
  翻牌 c-bet 1,815 + 他 call → 轉牌底池 = 9,130
  轉牌 50% bet = 4,565 + 他 call → 河牌底池 = 18,260
  河牌 50% bet = 9,130
  總共三條街贏得：1,815 + 4,565 + 9,130 = 15,510 chips（BBA）
  vs 傳統（底池稍小）三條街 ≈ 13,500 chips
  BBA 讓每場三條街 value 多贏約 2,000 chips
```

</details>

**82. ⭐⭐⭐**
線上 MTT（BBA 格式），盲注 500/1000，**BBA 1000**。翻牌：K♠ Q♣ 2♦。你在 BB，call 了 BTN open 2.5bb（2,500 chips）。你有 K♥ T♦（top pair, medium kicker）。

**BBA 翻牌底池計算：**
```
BTN 2,500 + BB call 2,500 + SB fold 500 = 5,500 chips（5.5bb）
```

BTN c-bet 50% pot（2,750 chips）。請分析：call 還是 raise？如果 call，轉牌 A♥ 對手繼續 bet 50%，你的行動是？

<details>
<summary>答案</summary>

**翻牌決策（BBA）：Call**

KTo 是 top pair medium kicker，不是強牌（可能被 KQ, KK dominate）。Call 翻牌，保持底池可控，觀察轉牌。Raise 讓你面對 3-bet 後很難受。

BBA 翻牌計算：
```
翻牌底池（BBA）= 5,500 chips
BTN c-bet 50% = 2,750 chips
Call 後轉牌底池 = 5,500 + 2,750 + 2,750 = 11,000 chips
```

**轉牌 A♥（BBA）：Check-fold 或 Check-call（保守）**

BBA 轉牌底池 = 11,000 chips

A 出來：
- BTN 的 range 包含 AK, AQ（現在都領先你）
- 你的 KT 變成中等牌，已落後
- 如果 BTN 繼續 bet 50%（5,500 chips）→ 他可能有 A 或繼續 bluff
- 用 **bluff catch 思維（BBA）**：

```
BTN 50% bet on 11,000 pot = 5,500 chips
損益平衡 bluff 頻率 = 5,500 ÷ (11,000 + 5,500 + 5,500) = 5,500 ÷ 22,000 = **25%**

BBA 底池（11,000）比傳統（10,000）大，
call 金額（5,500 vs 5,000）也更大，但損益平衡 bluff 頻率相同（25%）。
如果 BTN 在這條 line 上 bluff > 25% → call 正確。
```

乾燥翻牌（KQ2），轉牌 A，BTN 繼續 bet：他的 value 多（AK, AQ），但也有 bluff（draw miss, air）。接近損益平衡，**Check-call 一次，河牌再評估**。

</details>

**83. ⭐⭐⭐**
你正在打快速賽（Turbo），BBA 格式，盲注 1000/2000，**BBA 2000**。進場 30 分鐘，你現在 25bb（50,000 chips）。旁邊有一個玩家 12bb（24,000），在 bubble（3人進錢，現在 4人）。你在 BTN，12bb 短疊在 SB，大疊（50bb，100,000 chips）在 BB。行動到你（BTN），所有人 fold 到你，你有 A♦ 5♦（A5s）。

**BBA 底池計算（push 成功或被 call）：**
```
BTN push 25bb = 50,000 chips
底池（BBA，SB call 或 fold）：
  如果 SB fold + BB fold：贏 SB 500 + BB 2,000 + BB ante 2,000 = 4,500 chips
  如果 SB call（12bb）：底池 = 50,000 + 24,000 + 500 = 74,500（BB fold）
  如果 BB（大疊）call：底池 = 50,000 + 2,500 + 2,000 = 54,500（SB fold 500）
```

你應該？
A. Push（針對短疊，bubble 壓力讓 BB 難 call）
B. Fold（bubble 保守）
C. Open 2bb

<details>
<summary>答案</summary>

**A - Push**

分析（BBA 版本）：
- 你 push → SB 短疊（12bb）可能 call（他 push range 正常，但是他 ICM 壓力不高）
- 你 push → BB 大疊（50bb）在 bubble 可能 fold（他不需要冒險）
- A5s 是強牌，suited Ace 有牌力
- Turbo 快速賽，積累籌碼很重要，不能等
- Bubble 讓 BB 大疊更傾向 fold

BBA 底池影響：
```
Push 成功（SB + BB 都 fold）：
  BBA 淨贏 = SB 500 + BB 2,000 + BB ante 2,000 = 4,500 chips（2.25bb）
  傳統淨贏 = SB 500 + BB 2,000 = 2,500 chips（1.25bb）
  BBA 多贏 2,000 chips（80% 提升）

BBA 讓每次成功 push 回報更高，
在 Turbo bubble 中積累籌碼的激勵更強。

A5s 的 BBA Nash push range 在 BTN 25bb ≈ 包含（按 ICMIZER BBA 設定）。
```

**結論：Push 是正確的積極打法。**

</details>

**84. ⭐⭐⭐**
描述「Bluff 的可信故事（Credible Story）」是什麼意思，並舉例說明一個好的 bluff line 和一個不好的 bluff line（BBA 環境下，用 BBA 底池大小說明）。

<details>
<summary>答案</summary>

**可信故事：** 你的每條街的行動都和你「假裝擁有的手牌」一致，對手無法從你的 line 看出矛盾。

**好的 bluff line（BBA 環境）：**
盲注 1000/2000，BBA 2000。UTG open 5,000，BTN fold，BB fold，SB fold，你在 BB call（有 BBA 底池 5,500）。

- 你 UTG open（代表強牌）
- 翻牌 A♠ K♦ 7♣（BBA 底池 5,500），你 C-bet 33%（1,815 chips）（UTG open 有大量 AK, AA, KK）
- 轉牌 Q♦，翻牌底池 = 9,130，你繼續 bet 50%（4,565 chips）（AK, AQ 都有牌力）
- 對手折服，fold

這條 line 中，你的每條街都和「有 AK 或 top pair」一致，是可信的。BBA 底池讓每次 bet 金額更大，可信故事的「成本」更高，但 fold equity 也更高。

**不好的 bluff line（BBA 環境）：**
- 你 BTN open
- BBA 翻牌底池 5,500，翻牌 A♠ K♦ 7♣，你 check（表示沒有 A 或 K）
- 轉牌 2♥（空白），底池 5,500，你 suddenly bet 75%（4,125 chips）

矛盾：你翻牌 check 暗示沒牌，轉牌空白卻突然下大注（BBA 底池讓這個 4,125 bet 更顯眼），對手很難相信你有強牌，bluff 成功率低。在 BBA 大底池下，這種不一致的 line 更容易被識破。

</details>

**85. ⭐⭐ 什麼是「Fold Equity」？短疊為何比深疊更需要注意 fold equity 的消失？在 BBA 格式下，fold equity 如何影響 push EV？**

<details>
<summary>答案</summary>

Fold Equity = 對手因為你的 bet/push 而 fold 的機率帶來的 EV 收益。

短疊 push 時，對手面對「call = 冒全部籌碼」的壓力，所以 fold equity 高。
但當你只剩 3bb，對手 call 只需要少量額外投入，fold equity 幾乎消失。
這就是為什麼 3bb 的 push range 比 10bb 更寬（必須靠牌力，不能靠 fold equity）。

**BBA 格式下的 fold equity 計算：**
```
BBA 底池（盲注 1000/2000，BBA 2000）：

10bb push 成功（fold）贏 = SB 500 + BB 2,000 + BB ante 2,000 = 4,500 chips
10bb push fold EV = fold% × 4,500 chips

傳統（無 ante）10bb push 成功贏 = SB 500 + BB 2,000 = 2,500 chips
fold EV = fold% × 2,500 chips

BBA 讓 fold equity 的「價值」提升 80%（4,500 vs 2,500）。
這意味著在 BBA 環境下：
  1. 即使 fold% 略低（對手更容易 call），push EV 仍可能相近
  2. fold equity 對短疊 push 的 EV 貢獻更大
  3. push range 可以比傳統格式稍微放寬（因為成功 push 贏得更多）
```

</details>

**86. ⭐⭐ 什麼是「Range Advantage」？舉一個 BBA 環境下你有 range advantage 的翻牌例子（9-max，附 BBA 底池計算）。**

<details>
<summary>答案</summary>

Range Advantage = 在這個翻牌上，哪一方的手牌整體更強。

**BBA 例子：** 盲注 1000/2000，BBA 2000。你 UTG open（range 12-15%，只有強牌），BB call（range 更廣）。

BBA 翻牌底池：
```
SB fold 500 + BB 5,000（含 ante + call）+ UTG 5,000 = 10,500 chips（5.25bb）
或更精確：UTG 5,000 + BB 5,000 + SB 500 = 10,500 chips
```

翻牌 A♠ K♦ 9♣：
- 你的 UTG range 包含大量 AA, KK, AK, AQ...
- BB 的 range 雖然包含 Ax, Kx，但強牌比你少

**你有 range advantage → 可以用更高頻率 C-bet（BBA 底池計算）：**
```
BBA 翻牌底池 = 10,500 chips
33% c-bet = 3,465 chips
50% c-bet = 5,250 chips

BBA 底池讓你的 c-bet 金額更大（10,500 底池 vs 傳統 9,000），
range advantage + BBA 大底池 = 更積極 c-bet 的雙重理由。
```

</details>

**87. ⭐⭐ 線上 MTT（BBA 格式）中，什麼是「Timing Tell」，如何利用它？BBA 環境下是否有特殊的 timing tell 需要注意？**

<details>
<summary>答案</summary>

Timing tell = 對手行動速度透露的資訊。

- **快速 check**：通常是弱牌（預設行為）→ 你可以在下條街積極 bet
- **快速 call**：可能是強牌慢打，或是有 draw（不需要思考）
- **慢速 raise（用 time bank）**：通常有一定牌力，不是純 bluff
- **河牌快速 overbet**：可能是 bluff（想讓你快速 fold，沒想太多）

注意：高手會故意混淆 timing，不能完全依賴。

**BBA 特殊 Timing Tell：**
```
在 BBA 環境下，底池更大，行動的金額更大，某些玩家的猶豫時間更長：

1. 慢速 fold（BB 面對 preflop raise）：
   BB 在 BBA 下投入了 2bb，慢速 fold 可能代表他在計算
   BBA 底池下 BB 的 call 賠率更好，慢速 fold 代表他有牌但認為 call 不值（弱牌）

2. 即時 3-bet（BB 面對 BTN open）：
   BB 在 BBA 下已有 2bb 投入，即時 3-bet 可能代表強牌
   （已計算好 BBA 底池，決定快速）

3. 慢速 BBA 底池 call：
   在 BBA 大底池下慢速 call 可能是在計算 BBA odds，
   不一定代表弱牌（可能只是在驗算 BBA 計算）
```

</details>

**88. ⭐⭐⭐ 什麼是「ICM 自殺」？請舉一個 BBA 格式下的具體例子（含 BBA 底池計算）。**

<details>
<summary>答案</summary>

ICM 自殺 = 在 ICM 角度明顯不值得的情況下冒全部籌碼。

**BBA 例子：** 盲注 3000/6000，**BBA 6000**。FT 5人剩，你中疊 25bb（150,000 chips），有 TT。大疊 push all-in（他的 push range 很寬，你有 55% 勝率）。

**BBA 底池計算：**
```
大疊 push（假設 50bb = 300,000 chips）
底池（BBA）= 300,000 + 1,500（SB）+ 6,000（BB）+ 6,000（BB ante）= 313,500
call 需補 = 150,000 - 6,000 = 144,000

BBA chip EV 所需勝率 = 144,000 ÷ (313,500 + 144,000) = 144,000 ÷ 457,500 = **31.5%**

TT 勝率 55% >> 31.5% → BBA chip EV 非常正
```

Chip EV：call 是正 EV（BBA 底池讓 chip odds 更優）

ICM 計算（BBA 環境）：
- 輸了：從 150,000 到 0，出局拿最低獎金
- 贏了：310,000+，大幅改善 ICM equity
- 但 FT 5人，ICM 非常敏感：

```
現在 ICM equity（假設）：$2,000
贏了（55%）：ICM equity ≈ $3,200（明顯提升）
輸了（45%）：$500（最低獎金）

Call EV = 55% × $3,200 + 45% × $500 = $1,760 + $225 = $1,985
Fold EV = $2,000

$1,985 < $2,000 → fold 略微更好（ICM 自殺）
```

這就是 ICM 自殺：「BBA chip EV 非常正，但 ICM 讓 fold 更好」。BBA 底池雖然讓 chip odds 更好，但不能改變 FT ICM 的核心邏輯。

</details>

**89. ⭐⭐ 線上 MTT 的 bankroll 標準（BBA 格式）：打 $50 MTT（BBA 線上）建議最低資金多少？如果你連輸 30 場，剩餘 $800，應該繼續打 $50 還是降級？附：如何確認你的 BBA 計算是否正確？**

<details>
<summary>答案</summary>

- 建議最低資金：$50 × 100 = **$5,000**（保守）

連輸 30 場，剩 $800：
- $800 ÷ $50 = 16 買入，遠低於建議的 50-100 買入
- **必須降級**：改打 $5-10 的 MTT（BBA 格式相同，只是金額更小）
- 不要因為 downswing 就加倍，這是 tilt 的開始
- 分析手牌確認是方差還是打錯了

**BBA 計算正確性驗證：**
```
快速自查：
1. 你的 push/fold 決策是否使用 BBA Nash（HRC/ICMIZER BBA 設定）？
   驗證：BTN 10bb BBA Nash ≈ 65%（非傳統的 62%）

2. 你的底池計算是否包含 BB ante？
   驗證：盲注 1000/2000 → 你計算的底池是 5,000（BBA）還是 3,000（傳統）？

3. 你的 SPR 計算是否基於 BBA 翻牌底池？
   驗證：BTN open，BB call，100bb → SPR ≈ 17.7（BBA）還是 19.5（傳統）？

如果這三個問題任何一個答錯 → 你的計算一直在使用傳統框架，
這可能是 downswing 的策略原因（非純粹方差）。
```

</details>

**90. ⭐⭐ 解釋「Pot Odds」和「Implied Odds」的差異，並說明哪種情況 Implied Odds 更重要。在 BBA 環境下，Implied Odds 如何受影響？**

<details>
<summary>答案</summary>

**Pot Odds（底池賠率）：**
當前底池對你 call 金額的比率。計算你現在 call 是否有利可圖。

**Implied Odds（隱含賠率）：**
如果你的手牌改善了，預期從對手那裡額外贏得的籌碼。

**Implied Odds 最重要的情況：**
- 深疊時（100bb+），set 或 flush 完成後可以贏大底池
- 小對子 flat call（set mining）：Pot odds 可能不夠，但 implied odds 讓它值得
- Suited connector：flush/straight 完成後可以大贏

**BBA 環境下的 Implied Odds：**

BBA 讓翻牌底池更大，因此 implied odds 在 BBA 環境下更有價值：

```
小對子 set mining（55，面對 CO 3bb open，BTN 100bb，BBA 格式）：
  CO open 3bb（6,000 chips，盲注 1000/2000 BBA 2000）
  BBA 翻牌底池（BTN call）= CO 6,000 + BTN 6,000 + SB 500 + BB 400+400（含 ante）
  = 約 13,300 chips（6.65bb）

  Set 率 ≈ 11%
  BBA 底池更大，set 後的 value bet 更多：
    BBA 翻牌底池 13,300 vs 傳統 12,500
    三條街 value（BBA）可能多贏約 10-15%

  Implied odds = set 率 × 預期贏得（BBA 大底池）
  BBA 讓 implied odds 比傳統格式更好（底池更大，set 後可贏更多）

結論：在 BBA 環境下，set mining 和 suited connector 的 implied odds 更高，
call 的最低籌碼深度要求略低（因為完成後底池更大）。
```

</details>
