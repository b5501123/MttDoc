# 練習題 第7頁：判斷正誤（Q61-70）

判斷以下打法是否正確，並說明原因。

難度：⭐ 基礎 / ⭐⭐ 中級 / ⭐⭐⭐ 進階

**本頁前提：所有底池計算均預設 Big Blind Ante（BBA）格式。**
BBA 標準：BB 付大盲 + 額外 1bb ante，底池 = SB + BB + BB ante（例：100/200 → 底池 500）

---

**61. ⭐⭐ 「Bubble 時我把 QQ fold 了，因為大疊 push，我是中疊，ICM 壓力大。」**

<details>
<summary>答案</summary>

**視情況，可能正確但也可能過於保守**

QQ 是強牌。Bubble 中疊 fold QQ 需要特殊條件：
- 大疊 range 很緊（不太可能 bluff）
- 其他短疊即將出局
- ICM 計算顯示 fold 更好

純粹「因為是大疊就 fold QQ」通常過於保守。QQ+ 通常是 call range 的一部分。

BBA 補充：
```
在 BBA 格式的 bubble 中，call QQ 的 pot odds 計算：
  假設大疊 push 20bb，盲注 1000/2000，BBA 2000：
  底池（BBA）= 40,000 + 500 + 2,000 + 2,000 = 44,500
  call 需補 = 40,000 - 2,000 = 38,000
  所需勝率（BBA）= 38,000 ÷ 82,500 = 46.1%
  （傳統所需勝率 = 47.2%，BBA 略低）

  QQ 對大疊寬 push range（假設 40%）≈ 68% 勝率 >> 46.1%
  BBA chip EV 非常正，QQ 在 bubble 通常應該 call
```

唯一讓 fold QQ 合理的情況：ICM 計算明確顯示 fold > call（使用 HRC/ICMIZER **BBA 設定**計算）。

</details>

**62. ⭐⭐ 「我從 SB limp，翻牌後用 donk bet（主動對 BB 下注）。」**

<details>
<summary>答案</summary>

**通常不正確**

SB limp 本身就是問題（應該 raise or fold）。即使 limp 了，翻牌後 donk bet 也是弱點暴露（表示你有牌，但打法不平衡）。應該 check，讓 BB 用 c-bet 告訴你他的 range。

BBA 補充：
```
在 BBA 格式下，SB limp 的代價更大：
  BB 已付了大盲 + ante（2bb），非常不願意讓 SB 免費或廉價進入底池
  SB limp 後，BB 更有動力 raise（他已投入更多，底池更大讓 raise EV 更高）
  BB raise 後 SB limp-fold = 浪費 0.5bb（SB 的小盲）

BBA 讓 SB limp 的問題更嚴重：
  底池（SB limp，BB check）= SB 0.5bb + BB 1bb + BB ante 1bb = 2.5bb
  翻牌後 donk bet 在 2.5bb 底池是弱點暴露，BB 更容易利用
```

SB 在 BBA 環境下更應該 raise or fold，而非 limp。

</details>

**63. ⭐⭐ 「我在 BTN，對手 UTG open，我用 JJ flat call（IP），翻牌來 A。我 check-fold。」**

<details>
<summary>答案</summary>

**正確**

UTG range 有很多 Ax，A 翻牌對他有利。JJ 在 A♠ K♦ 7♣ 翻牌已經變成 third pair，check-fold 是正確的（除非有特殊讀牌依據）。這就是 IP flat call JJ 的計劃：miss 的時候 check-fold，不需要強打。

BBA 補充：
```
在 BBA 格式下，IP flat call 後翻牌底池（BBA）：
  UTG 2.5bb + BTN call 2.5bb + SB 0.5 + BB 2bb（含 ante）= 7.5bb

  JJ check-fold 的 「損失」= 7.5bb 底池放棄
  但繼續打的「風險」= 可能在 A-high 翻牌對 UTG 的強 Ax range 繼續輸籌碼

  BBA 翻牌底池更大（7.5 vs 傳統 6.5），check-fold 放棄的底池更大，
  但這仍然是正確的打法——JJ 在 A-high 對 UTG 緊 range 不值得繼續。
```

</details>

**64. ⭐⭐⭐ 「Final Table 2人剩，我有 KK，對手 push all-in，我 fold 了因為他可能有 AA。」**

<details>
<summary>答案</summary>

**錯誤**

Heads-Up 時 ICM 幾乎消失，就是純 Chip EV 對決。KK vs AA 機率只有 1/221，對手的 push range 很寬（HU range 70%+）。Fold KK HU 是嚴重的錯誤，損失巨大的 EV。

BBA 補充：
```
HU BBA pot odds 計算（假設對手 push 30bb，盲注 5000/10000，BBA 10000）：
  底池（BBA）= push 300,000 + SB 5,000 + BB 10,000 + ante 10,000 = 325,000
  call 需補 = 300,000 - 10,000 = 290,000
  所需勝率（BBA）= 290,000 ÷ (325,000 + 290,000) = 290,000 ÷ 615,000 = 47.2%

  KK vs HU 70% push range ≈ 70-75% 勝率 >> 47.2%

  BBA 讓 HU call 的所需勝率略低（比傳統的 48% 少），
  KK 在 HU BBA 環境下 call 的 EV 非常高。
  折 KK HU 是極度錯誤的決策，BBA 更加確認了 call 的正確性。
```

</details>

**65. ⭐⭐⭐ 「我打了翻牌 C-bet 和轉牌 semi-bluff（有 flush draw），河牌 miss，我 check/give up。」**

<details>
<summary>答案</summary>

**通常正確**

三條街 bluff 在 MTT 高風險，尤其 OOP 或中等 ICM 壓力時。flush draw miss 後的 check/give up 保留籌碼是合理選擇。

例外：如果你 IP、有 blocker、對手 check range 很弱，river bluff 可以考慮。

BBA 底池影響：
```
假設翻牌底池（BBA）= 5,500，c-bet 33% = 1,815，call
轉牌底池 = 9,130，semi-bluff 50% = 4,565，call
河牌底池 = 18,260 chips

河牌 check/give up 放棄 18,260 chips 底池
如果繼續 bluff（假設 75%）= 13,695 chips，成功率需達到？

損益平衡 = 13,695 ÷ (18,260 + 13,695 + 13,695) = 13,695 ÷ 45,650 = 30%

BBA 底池更大，三條街 bluff 的風險也更大（河牌 bet 金額更高）。
在沒有充分理由（blockers、對手超弱 range）的情況下，
check/give up 在 BBA 大底池環境下更加正確。
```

</details>

**66. ⭐⭐ 「多桌時（打 6 桌），我在每桌都做很多 float 和 bluff。」**

<details>
<summary>答案</summary>

**不理想**

多桌時注意力分散，不應該在每桌做複雜的 float 和 multi-street bluff。多桌的正確策略是**簡化決策**：傾向 3-bet or fold，少 flat call；value bet 多，複雜 bluff line 少。

BBA 補充：
```
在 BBA 多桌環境下，複雜打法的問題更嚴重：
  1. BBA 底池更大，複雜 bluff line 的損失更大（失敗時損失更多）
  2. 每桌的底池大小可能不同（不同盲注階段），
     多桌時很難記住每桌的 BBA 底池大小，複雜打法更容易出錯
  3. 簡化決策在 BBA 環境下：傾向標準 BBA push/fold，少 float
```

多桌時特別要避免在忘記 BBA 底池大小的情況下做複雜的 bluff line。

</details>

**67. ⭐⭐ 「Bubble 時我是大疊，我 fold 了所有 BTN steal，因為不想冒險。」**

<details>
<summary>答案</summary>

**錯誤**

大疊 Bubble 是偷盲的黃金時機！中疊不敢 call，ICM 讓他們 fold 比 Nash 更多。大疊 fold BTN steal = 放棄免費 EV，這是常見的大疊錯誤。

BBA 補充：
```
在 BBA Bubble，大疊 BTN open 的 EV 更高：
  BBA 底池（盲注 1000/2000，BBA 2000）= 5,000 chips
  大疊 open 2.5bb（5,000 chips），中疊 BB 因 ICM 壓力 fold：
    淨贏 = SB 500 + BB 2,000 + BB ante 2,000 = 4,500 chips

  傳統（無 ante）大疊 BTN steal 淨贏：
    SB 500 + BB 2,000 = 2,500 chips

  BBA 讓大疊每次成功偷盲多贏 2,000 chips（BB ante）
  Bubble + BBA 是大疊偷盲 EV 最高的組合，絕對不應該 fold 所有 BTN steal。
```

</details>

**68. ⭐⭐⭐ 「我用 A2s 做 4-bet bluff，因為有 Ace blocker。」**

<details>
<summary>答案</summary>

**正確（合理打法）**

A2s 做 4-bet bluff 是標準的 polar 4-bet range 選擇：
- Ace blocker 降低對手 AA/AK 的機率
- Suited 讓被 call 後有翻牌潛力
- 小 kicker 讓這手牌不適合 flat call（容易被 dominated）

BBA 補充：
```
在 BBA 格式下，4-bet bluff 的 EV 更高（底池更大）：
  對手 3-bet 後底池（BBA）> 傳統底池
  成功 4-bet bluff 贏得更多（因為底池更大）

  A2s 4-bet bluff 在 BBA 環境下更有 EV：
    BBA 底池讓 blocker 的折疊 EV 更高
    被 call 後，A2s suited 在 BBA 翻牌大底池也有 nut flush 潛力
    是 BBA 環境下標準的 polar 4-bet 選擇
```

</details>

**69. ⭐⭐ 「我從不 check-raise，因為要等好牌再 bet。」**

<details>
<summary>答案</summary>

**錯誤**

從不 check-raise 讓你的 check = 弱牌，對手可以自由 bet 所有牌。你需要在 check range 中加入 check-raise（包含 value 和 semi-bluff），否則對手可以利用你。

BBA 補充：
```
在 BBA 格式下，從不 check-raise 的代價更大：
  BBA 翻牌底池更大（5.5bb vs 5bb），對手的 c-bet 金額更高（33% = 1.8bb vs 1.65bb）
  如果你從不 CR，對手可以用更大的金額安全 c-bet 你

  BBA 環境下 check-raise 的 value 更高：
    底池更大，CR 的尺寸也更大，施壓效果更強
    semi-bluff CR（有 equity 支撐）在 BBA 大底池更有效率

  從不 CR 在 BBA 環境下損失的 EV 更多（讓對手免費打更大的底池）。
```

</details>

**70. ⭐⭐⭐ 「我在線上打 MTT，每次 downswing 就加大報名費想「贏回來」。」**

<details>
<summary>答案</summary>

**嚴重錯誤（Tilt 行為）**

這是典型的 Tilt 症狀。MTT 的方差極大，downswing 是正常現象。加大報名費是情緒決策，可能導致 bankroll 崩潰。正確做法：停牌休息、分析手牌、確認是壞牌還是打錯了、必要時降級。

BBA 補充：
```
在 BBA 線上 MTT 環境下，這個錯誤更嚴重：
  1. 加大報名費後，如果繼續犯 BBA 底池計算錯誤，損失更大
  2. BBA 格式每圈成本更高（2.5bb），downswing 時 stack 燃燒更快
  3. 加大 stake 後，BBA 底池金額更大，Tilt 決策的損失更嚴重

正確的 downswing 應對（BBA 版本）：
  1. 確認所有 push/fold 計算使用了 BBA Nash（非傳統 Nash）
  2. 確認底池計算包含 BB ante（不要低估底池）
  3. 降至熟悉的 stake，在正確的 BBA 計算框架下重建信心
  4. 不要在 Tilt 狀態下使用錯誤的 BBA 計算做更大的賭注
```

</details>
