# 練習題 第3頁：概念進階 + 情境入門（Q21-30）

難度：⭐ 基礎 / ⭐⭐ 中級 / ⭐⭐⭐ 進階

**本頁前提：所有底池計算均預設 Big Blind Ante（BBA）格式。**
BBA 標準：BB 付大盲 + 額外 1bb ante，底池 = SB + BB + BB ante（例：100/200 → 底池 500）

---

**21. ⭐⭐⭐**
BB Ante（BBA）格式對策略有什麼影響？

A. 讓 BTN steal 的 EV 降低
B. 讓 BB 每一 orbit 的成本更高，同時提升 steal EV
C. 沒有影響
D. 讓所有位置的 open range 縮緊

<details>
<summary>答案</summary>

**B**

BBA 讓 BB 每一 orbit 付的錢更多（1bb 大盲 + 1bb ante = 2bb），但同時底池更大（2.5bb），偷盲的 EV 也更高。你應該在有 ante 時放寬 steal range（BTN/SB/CO 更積極 open）。

詳細計算：
```
BBA 底池偷盲 EV 計算（BTN，假設 BB fold 率 70%）：
  BBA 底池 = 2.5bb（SB 0.5 + BB 1 + BB ante 1）
  成功偷盲 EV = 70% × 2.5bb = 1.75bb
  失敗 EV = 30% × (-2.5bb 開注成本) = -0.75bb（簡化）
  淨 EV ≈ +1.0bb（每次 BTN open）

傳統底池（無 ante）：
  底池 = 1.5bb，成功偷盲 EV = 70% × 1.5bb = 1.05bb
  淨 EV 更低

BBA 讓 BTN steal EV 提升約 67%（1.0bb vs 1.05bb 基礎），
這就是為什麼 BBA 環境下應該放寬後位 open range。
```

BBA 標準前提補充：BB 雖然成本更高，但 BB 的 defense 頻率也應相應提升，以避免被過度利用。

</details>

**22. ⭐⭐⭐**
Final Table 10人，你是 chip leader（30% 籌碼）。以下打法哪個是正確的？

A. 保守打，保住 chip lead
B. 積極偷盲，施壓中疊，利用 ICM 優勢
C. 只和短疊打，避免和其他人衝突
D. 等到 5人再開始積極

<details>
<summary>答案</summary>

**B**

大疊在 FT 的 ICM 壓力最低，中疊不敢輕易 call 你的 push/open（怕出局）。這是最好的偷盲時機，應該積極施壓中疊，積累更多籌碼。

BBA 補充：在 BBA 格式的 FT 中，大疊偷盲的 EV 更高：
```
FT 大疊（30%，假設籌碼 300,000，盲注 5000/10000，BBA 10000）：
  BBA 底池 = 5,000 + 10,000 + 10,000 = 25,000
  每次成功偷盲贏 25,000（BBA）vs 傳統 15,000

FT 10人，平均每人需要 fold 才能讓你贏底池。
BBA 讓每次成功偷盲的回報更豐厚，大疊的積極策略更有 EV。
```

</details>

**23. ⭐⭐⭐**
你打了三條街的 bluff，river 對手 call 你的 all-in。翻牌時你應該做什麼？

A. 繼續假裝有牌
B. 直接攤牌，接受結果
C. 說對不起
D. 以上皆非

<details>
<summary>答案</summary>

**B**

攤牌是標準程序，不需要表情管理或道歉。輸了就接受，bluff 被抓是撲克正常的一部分。

BBA 補充：此題與 BBA 的策略無直接關係，但值得注意：BBA 底池更大，被 call 時的損失更大，這讓三條街 bluff 在 BBA 環境下的風險更高。因此在 BBA 環境下更要謹慎選擇三條街 bluff 的機會，確保有足夠的可信故事和 equity 支撐。

</details>

**24. ⭐⭐⭐**
9-max 中，UTG open 後，以下哪手牌最適合做 4-bet bluff？

A. T9s（翻牌潛力高）
B. A5s（有 A blocker + suited）
C. 88（有牌力）
D. KQo（兩張高牌）

<details>
<summary>答案</summary>

**B**

4-bet bluff 的最佳手牌是有 **Blocker** 的牌。A5s 有 A，阻礙了對手的 AA、AK 等 4-bet value range，提高 bluff 成功率。T9s 雖然有翻牌潛力，但沒有 blocker 效果，4-bet 後很難繼續。

BBA 補充：在 BBA 格式下，4-bet bluff 的 EV 計算基礎是 BBA 底池。4-bet 後底池更大，成功 4-bet bluff 贏得的籌碼更多。A5s 的 4-bet bluff 在 BBA 環境下：
```
假設 UTG 3-bet 到 7bb（BBA 環境），你 4-bet 到 18bb：
  成功 fold：贏 BBA 底池 + UTG 3-bet = 2.5 + 7 = 9.5bb（淨收益）
  BBA 底池讓 blocker 4-bet bluff 的 EV 比傳統更高
```

</details>

**25. ⭐⭐⭐**
以下哪個情境中 Flat Call 比 3-bet 更好？

A. BB 面對 BTN open，有 AA
B. BTN 面對 UTG open，有 TT（IP，有 set mining value）
C. SB 面對 CO open，有 AQo
D. BB 面對 SB raise，有 KK

<details>
<summary>答案</summary>

**B**

TT 面對 UTG（緊 range）在 BTN（IP）：
- 3-bet 後被 4-bet 很難受（UTG 4-bet = 很強）
- IP flat call，SPR 合理，可以 set mine
- Set 後可以贏大底池

AA（A選項）通常要 3-bet 建大底池；KK（D選項）OOP 也應 3-bet。

BBA 補充：在 BBA 格式下，flat call TT 後的翻牌底池更大（約 7.5bb vs 傳統 6.5bb），set mining 的 implied odds 也相應更高。BBA 讓 TT 的 set mining flat call 更有價值（因為底池更大，set 後可以建更大的底池）。

</details>

**26. ⭐**
你在 BTN，10bb，所有人 fold，手牌 K♦ 9♣。應該？

**場景（BBA）：** 盲注 1000/2000，BBA 2000。BTN 10bb = 20,000 chips。翻牌前底池（未入局）= 500 + 2,000 + 2,000 = 4,500。

A. Push
B. Fold
C. Open 2bb

<details>
<summary>答案</summary>

**A - Push**

BTN 10bb BBA Nash push range ≈ 65%，K9o 在 range 內。只需要過 SB/BB，有足夠 fold equity。Open 2bb 後被 3-bet 更難受。

BBA 底池計算：
```
成功 push 後贏得 = 4,500 chips（BBA 底池）
傳統格式成功後贏得 = 3,000 chips
BBA 讓這個 push 的 EV 提升了 50%（多贏 1,500 chips）
K9o 在 BTN 10bb BBA Nash push range 內 → push
```

</details>

**27. ⭐**
你在 UTG，10bb，9-max，手牌 Q♠ J♦。應該？

**場景（BBA）：** 盲注 1000/2000，BBA 2000。UTG 10bb push 後底池 = 20,000 + 500 + 2,000 + 2,000 = 24,500。

A. Push
B. Fold
C. Open 2bb

<details>
<summary>答案</summary>

**B - Fold**

UTG 10bb BBA Nash push range ≈ 28%。QJo 不在這個 range 內（UTG push range 主要是 TT+, ATs+, AJo+, KQs 等）。9-max 後面有 7 個人，QJo 不夠強。

BBA 說明：
```
雖然 BBA 底池（4,500 chips）比傳統（3,000）更大，
使得 push 成功的 EV 更高，
但 UTG 面對 8 個後位玩家被 call 的機率仍然太高。
QJo 對這些對手的 call range 勝率不足 → fold 仍然正確。
BBA 底池不能補救 UTG 位置劣勢帶來的 EV 損失。
```

</details>

**28. ⭐**
你在 SB，8bb，BTN fold，你對 BB，手牌 A♠ 6♦。應該？

**場景（BBA）：** 盲注 1000/2000，BBA 2000。SB 8bb = 16,000 chips。底池（未入局）= 500 + 2,000 + 2,000 = 4,500。

A. Limp
B. Fold
C. Push

<details>
<summary>答案</summary>

**C - Push**

SB 8bb BBA Nash push range ≈ 70%+。A6o 在 SB push range 內（Ace 對 BB 有很強的牌力）。只需要過 BB 一人，Fold equity 好。Limp 是錯的（翻牌後 OOP）。

BBA 底池計算：
```
SB push 16,000，BB fold：
  SB 贏 BBA 底池 = 500 + 2,000 + 2,000 = 4,500 chips
  傳統底池 = 3,000 chips（BBA 多贏 1,500）

BB call 情境（BBA）：
  底池 = 16,000 + 500 + 2,000 + 2,000 = 20,500
  BB call 需補 = 16,000 - 2,000 = 14,000（大盲已計）
  BB 所需勝率 = 14,000 ÷ (20,500 + 14,000) = 40.6%
  （傳統：14,000 ÷ 18,500 = 43.2%）
  BBA 讓 BB call 更容易，但 A6o 的勝率仍充足 → push
```

</details>

**29. ⭐**
你在 BB，對手 BTN push 8bb。SB fold。你有 T♠ 9♠。Call 的損益平衡勝率是多少？

**BBA 底池計算：**
盲注 1000/2000，BBA 2000。BTN push 8bb = 16,000 chips。

```
BBA 底池組成：
  BTN push = 16,000
  SB fold = 500（留底池）
  BB 已投入 = 2,000（大盲）+ 2,000（BB ante）= 4,000

底池合計 = 16,000 + 500 + 4,000 = 20,500
BB call 需補 = 16,000 - 2,000 = 14,000（BB 大盲已算，ante 已計）

實際計算（BB ante 已是 BB 投入的一部分）：
底池 = 16,000 + 500 + 2,000 = 18,500（不重複計 ante）
Call 補 = 16,000 - 2,000 = 14,000
所需勝率 = 14,000 ÷ (18,500 + 14,000) = 14,000 ÷ 32,500 = 43.1%
```

A. 約 42-43%（BBA）
B. 約 33%
C. 約 50%

<details>
<summary>答案</summary>

**A - 約 42-43%（BBA）**

BBA 底池計算：
```
底池 = BTN 16,000 + SB 500 + BB 2,000（大盲）= 18,500
（BB ante 2,000 已是 BB 投入的一部分，不再重複計）
call 補 = 16,000 - 2,000 = 14,000

所需勝率 = 14,000 ÷ (18,500 + 14,000) = 14,000 ÷ 32,500 = **43.1%**

傳統底池（無 ante）：
  底池 = 16,000 + 500 + 2,000 = 18,500（同，因為 ante 就在 BB 的投入中）
  實際上 BBA 的底池更正確計算應包含 ante 貢獻：
  含 ante 底池 = 18,500 + 2,000 = 20,500，
  所需勝率 = 14,000 ÷ 34,500 = 40.6%
```

**使用 HRC/ICMIZER BBA Nash 模式：約 41-43%**

BTN 8bb BBA push range ≈ 70%，T9s 對 70% range 的勝率大約 48-50%，超過所需勝率，應該 **Call**。

</details>

**30. ⭐⭐**
9-max，盲注 100/200，**BBA 200**，100bb，你在 CO，open 2.5bb（500 chips），BTN call，BB fold（含 ante 已入底池）。翻牌底池多少？你有 Q♠ J♠（完全 miss）。應該？

**BBA 翻牌底池計算：**
```
SB fold = 100（留底池）
BB fold（大盲 200 + BB ante 200 留底池）= 400
CO raise = 500
BTN call = 500
翻牌底池 = 100 + 400 + 500 + 500 = 1,500（合計）

簡化：CO 500 + BTN 500 + SB 100 + BB 400（含 ante）= 1,500 chips = 7.5bb
```

翻牌：A♠ K♦ 7♣（完全 miss，只有 backdoor）。應該？

A. C-bet 33% pot（小 bluff）= 500 chips
B. C-bet 75% pot（大 bluff）= 1,125 chips
C. Check（放棄）

<details>
<summary>答案</summary>

**A - C-bet 33% pot（500 chips）**

BBA 翻牌底池 = 1,500 chips（7.5bb）
33% c-bet = 500 chips（BBA）vs 傳統 33% ≈ 413 chips（傳統底池約 1,250）

AK7 乾燥翻牌，你的 CO range 有大量 Ax, Kx，range advantage 高。用小 size C-bet 有正 EV（對手 miss 就 fold）。大 size C-bet 沒有必要（乾燥翻牌不需要保護）。

BBA 說明：
```
BBA 底池（1,500）比傳統（1,250）大 20%。
你的 c-bet 金額（500 chips）比傳統（約 415）大，
但比例（33%）不變。在 BBA 環境下，小尺寸 c-bet 的
絕對金額更大，對手 fold 讓你贏得更多，
這讓 c-bet EV 在 BBA 下更高。
```

</details>
