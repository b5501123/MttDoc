# 練習題 第4頁：情境判斷（Q31-40）

難度：⭐ 基礎 / ⭐⭐ 中級 / ⭐⭐⭐ 進階

**本頁前提：所有底池計算均預設 Big Blind Ante（BBA）格式。**
BBA 標準：BB 付大盲 + 額外 1bb ante，底池 = SB + BB + BB ante（例：100/200 → 底池 500）

---

**31. ⭐⭐**
9-max，盲注 100/200，**BBA 200**，你在 BB，100bb，BTN open 2.5bb（500 chips），SB fold，你有 9♦ 8♦。

**BBA 底池情境：**
```
SB fold = 100（留底池）
BTN raise = 500
BB 已有 200（大盲）+ 200（BB ante）= 400 投入
翻牌前底池（如 call）= 500 + 100 + 400 = 1,000（5bb）
BB call 需補 = 500 - 200 = 300 chips
```

應該？

A. 3-bet（適合做 polar bluff）
B. Flat call（IP 不好，但有 implied odds）
C. Fold
D. B 和 A 都可以，視情況

<details>
<summary>答案</summary>

**D - 都可以**

98s 在 BB 是兩種打法都合理：
- Flat call：有 flush draw, straight draw 潛力，BB discount 讓 call 值得
- 3-bet：作為 polar bluff 的一部分（suited connector 有 equity 支撐）

面對激進對手（常 C-bet）→ call 然後 check-raise
面對緊對手 → 3-bet bluff

BBA 底池計算：
```
Flat call 後翻牌底池 = BTN 500 + BB call 500 + SB 100 = 1,100 chips（5.5bb）
（傳統：BTN 500 + BB 500 + SB 100 = 1,100，相同，因為 BB ante 已在投入中）
更精確 BBA：SB 100 + BB 200(大盲) + BB 200(ante) + BTN 500 = 1,000，BB call 補 300
翻牌底池 = 1,000 + 300 = 1,300？

正確計算：BTN 500 + BB call 500 + SB 100 fold 留底 = 1,100（實際翻牌底池）
SPR（BBA）= (100,000 - 500) ÷ 1,100 = 99,500 ÷ 1,100 ≈ 90（深疊，大量後手空間）
```

BBA 翻牌底池（1,100 chips）讓 c-bet 金額更大，check-raise semi-bluff 的 EV 也相應更高。

</details>

**32. ⭐⭐**
Bubble！盲注 500/1000，**BBA 1000**。你是中疊 28bb，在 BB。大疊 BTN（70bb）open 2.5bb（2,500 chips），SB fold，你有 A♠ J♦。

**BBA 底池情境：**
```
SB fold = 500（留底池）
BTN raise = 2,500
BB 已有 1,000（大盲）+ 1,000（BB ante）= 2,000 投入
翻牌前底池（如 call）= 2,500 + 500 + 2,000 = 5,000（5bb）
BB call 需補 = 2,500 - 1,000 = 1,500 chips
```

應該？

A. 3-bet all-in（AJ 是強牌）
B. Fold（ICM 壓力高）
C. Flat call（控制底池）

<details>
<summary>答案</summary>

**C 或 B，視情況**

Bubble 中疊最難打。AJo 是中等強牌：
- 3-bet all-in：風險很高，被 call 後即使 flip 輸了就 bubble out
- Flat call：進翻牌後，如果翻牌來 A 或 J，可以繼續；否則 check-fold
- Fold：過於保守，AJ 有一定牌力

**最佳：flat call**，控制底池，翻牌後見機行事。大疊可能繼續 bluff，你可以用 top pair 抓詐。

BBA 底池影響：
```
Flat call 後翻牌底池（BBA）= 2,500 + 2,500 + 500 = 5,500 chips（5.5bb）
傳統（無 ante）翻牌底池 ≈ 5,000 chips（5bb）

BBA 讓翻牌底池稍大，C-bet 金額相應稍高，但 bubble ICM 考量不變。
AJo flat call 在 BBA bubble 的最優策略：控制底池，翻牌後以 A/J 翻牌為條件繼續。
```

</details>

**33. ⭐⭐**
盲注 200/400，**BBA 400**。翻牌：T♣ 9♦ 8♠（超濕潤）。你在 OOP（BB），有 K♥ Q♥（gutshot + two overcards）。

**BBA 翻牌底池：** 假設 BTN open 2.5bb（1,000），BB call。
```
翻牌底池（BBA）= BTN 1,000 + BB 1,000 + SB 200（fold）= 2,200 chips（5.5bb）
對手 IP bet 66% pot = 2,200 × 66% ≈ 1,450 chips
```

應該？

A. Fold
B. Call
C. Check-raise（有 equity 支撐）

<details>
<summary>答案</summary>

**C - Check-raise（或 B Call）**

KQ 在這個翻牌有：gutshot（J 完成順子，4 outs）+ 兩張 overcards（可能有 6 outs）。
有足夠 equity 做 semi-bluff CR，施壓對手的 c-bet range。
若選 Call 也合理，但 OOP 多條街 call 難打，CR 更主動。

BBA check-raise 計算：
```
翻牌底池（BBA）= 2,200 chips
對手 bet 1,450（66%）→ 底池含 bet = 3,650 chips
CR 尺寸（標準 2.5-3x）= 1,450 × 2.5 = 3,625 chips

BBA 底池讓 check-raise 的絕對金額更大（2,200 base vs 傳統 2,000），
你的 semi-bluff CR 代表更大的底池爭奪，fold equity 也相應更高。
```

</details>

**34. ⭐⭐**
你在 HJ，15bb，9-max，盲注 1000/2000，**BBA 2000**。手牌 A♣ 8♦。應該 push 還是 fold？

**BBA 底池（push 成功）：** = 500 + 2,000 + 2,000 = 4,500 chips（2.25bb，未入局底池）

HJ 15bb BBA push range ≈ 30%

A. Push（A8o 在 range 內）
B. Fold（A8o 太弱）

<details>
<summary>答案</summary>

**A - Push**

HJ 15bb BBA push range ≈ 30%，A8o 大概在 range 的邊界或邊界外，但：
- 有 Ace（牌力合理）
- 15bb 有 fold equity
- Fold 會損失積累機會

A8o 是接近邊界的手牌，push 或 fold 都可以接受。**Bubble 時傾向 fold（ICM），非 Bubble 傾向 push。**

BBA push EV 計算：
```
push 成功（對手 fold）贏 BBA 底池 4,500 chips（比傳統的 3,000 多 50%）
BBA 讓每次成功 push 的回報更高，A8o 的邊緣 push 在 BBA 環境下 EV 更正向。
非 bubble 情況下，BBA 支持 push 決定。
```

</details>

**35. ⭐⭐**
翻牌：A♥ 7♣ 2♦（很乾燥）。盲注 200/400，**BBA 400**。BTN open 2.5bb（1,000），BB call。你 IP（BTN），有 A♠ T♠（TPTK）。

**BBA 翻牌底池：**
```
BTN 1,000 + BB 1,000 + SB 200（fold）= 2,200 chips（5.5bb）
```

對手 BB check。應該？

A. Check back（慢打，製造陷阱）
B. C-bet 33%（小 size value）= 726 chips
C. C-bet 75%（大 size，防 draw）= 1,650 chips

<details>
<summary>答案</summary>

**B - C-bet 33%（約 726 chips）**

乾燥翻牌，幾乎沒有 draw。TPTK 應該 value bet，但 size 不需要太大（沒有 draw 需要保護）。小 size 讓對手 call range 更寬（有 A 比你踢腳差、中等對子）。偶爾也可以 check back 製造 balance（但 33% C-bet 更常見）。

BBA 下注計算：
```
BBA 翻牌底池 = 2,200 chips
33% c-bet = 726 chips（BBA）
傳統翻牌底池 ≈ 2,000 chips，33% = 660 chips

BBA 讓你的 value bet 金額稍高（726 vs 660），
對手以弱 Ax 或中等對子 call 時你贏得更多。
三條街 value 在 BBA 下累積更多籌碼。
```

</details>

**36. ⭐⭐**
你打了翻牌和轉牌的 bluff（有 flush draw），河牌來了一張空白（draw miss）。你在 OOP，對手 check。你有 K♠ high，沒有任何牌力。

**BBA 底池背景（假設）：** 盲注 200/400，BBA 400，翻牌底池 2,200，翻牌 bet 726，轉牌 bet 1,500。
```
河牌底池（BBA）= 2,200 + 726 + 726 + 1,500 + 1,500 = 6,652 chips
（翻牌 bet + call，轉牌 bet + call）
```

應該？

A. 大 bet（繼續 bluff，三條街 bluff line）≈ 6,652 × 75% = 4,989 chips
B. Check/give up（放棄底池）

<details>
<summary>答案</summary>

**視情況，偏 B**

三條街 bluff 在 MTT 是高風險行為，特別是 OOP。但也不是完全不能做：
- 如果對手的 check range 很弱（他 check = 無法 call）→ bet 有效
- 如果你有 blocker（例如你有 A♠，能阻礙 nut flush）→ bluff 成功率更高
- **一般情況：check/give up，保留籌碼**

BBA 說明：
```
BBA 環境下，三條街 bluff 的損失更大（河牌底池更大）。
BBA 底池讓河牌 overbet（75% 以上）的金額非常大（近 5,000 chips）。
在沒有 blocker 的情況下，在 BBA 大底池做三條街 bluff
風險遠大於回報。check/give up 保留籌碼，在 BBA 環境下更正確。
```

</details>

**37. ⭐⭐**
Final Table，5人剩餘，盲注 5000/10000，**BBA 10000**。你是中疊（25bb），大疊（55bb）在 BTN 頻繁偷盲。你在 BB 有 J♠ T♠（JTs）。大疊 BTN open 2.5bb（25,000 chips），SB fold。

**BBA 底池（BBA call 後翻牌底池）：**
```
BTN 25,000 + BB 25,000 + SB 5,000（fold）= 55,000 chips（5.5bb）
BB call 需補 = 25,000 - 10,000 = 15,000 chips
```

應該？

A. Fold（FT 保守）
B. 3-bet all-in（JTs 有牌力，施壓大疊）
C. Call（翻牌後見機行事）

<details>
<summary>答案</summary>

**C - Call（或 B 3-bet，都可以接受）**

JTs 是一手好牌，有翻牌潛力。Call 進翻牌後，你可以：
- 翻牌來好牌 → value bet 或 check-raise
- Flush draw 或 OESD → semi-bluff

3-bet all-in 也可以考慮（施壓大疊的寬 range），但 FT 的 ICM 讓 25bb 3-bet shove 有一定風險。

**Fold 是過於保守的選擇**，JTs 有足夠牌力。

BBA 翻牌底池計算：
```
Flat call 後翻牌底池（BBA）= BTN 25,000 + BB 25,000 + SB 5,000 = 55,000 chips
傳統翻牌底池 ≈ 50,000 chips

BBA 讓翻牌底池更大，JTs 的 semi-bluff 潛力（flush draw, OESD）價值更高。
FT 5 人，大疊偷盲很寬，JTs call 是 FT 的正確積極策略。
```

</details>

**38. ⭐⭐**
你在 CO，100bb，9-max，盲注 200/400，**BBA 400**。open 2.5bb（1,000 chips）。BTN 3-bet 到 8bb（3,200 chips），你有 A♥ K♦（AKo）。

**BBA 底池情境：**
```
如果 4-bet：CO 4-bet 到 18bb（7,200），BTN fold 後底池 ≈ 10,200 chips
如果 call：翻牌底池 = CO 3,200 + BTN 3,200 + SB 200 + BB 400(含ante) = 7,000 chips
```

應該？

A. 4-bet（繼續施壓）
B. Call（有牌力，IP 翻牌後打）
C. Fold
D. A 或 B 都合理

<details>
<summary>答案</summary>

**D - 4-bet 或 Call 都合理**

AKo 面對 BTN 3-bet：
- **4-bet**：建大底池，AK 是強牌，對手很多弱 3-bet bluff
- **Call**：你 OOP（CO vs BTN），IP 有優勢給 BTN，但 AK 有牌力可以打

現代打法：AKo 混合 4-bet 和 call（保持 balance）。高 ICM 壓力時更多 call（避免大底池），低 ICM 壓力時更多 4-bet。

BBA 底池計算：
```
4-bet 成功（BTN fold）後贏 BBA 底池：
  BTN 3,200 + CO open 1,000 + SB 200 + BB ante+大盲 400+400 = 約 5,200 chips
  BBA 讓你的 4-bet bluff EV 更高（底池更大，fold 成功贏得更多）

Call 後翻牌底池（BBA）= 約 7,000 chips
  AKo 有很大的後手潛力（top pair top kicker），BBA 底池讓翻牌後 value 更高
```

</details>

**39. ⭐⭐⭐**
PKO，盲注 1000/2000，**BBA 2000**。對手賞金 $400（你的報名費是 $100）。你 all-in，勝率 45%。

**BBA 底池計算（假設對手 push 20bb）：**
```
底池 = 40,000（push）+ 500（SB）+ 2,000（BB）+ 2,000（BB ante）= 44,500
call 需補 = 40,000 - 2,000 = 38,000
BBA 純 chip EV 所需勝率 = 38,000 ÷ (44,500 + 38,000) = 38,000 ÷ 82,500 = 46.1%

傳統純 chip EV 所需勝率（無 BBA）= 38,000 ÷ 80,500 = 47.2%
```

賞金 EV = $400 × 50% × 45% = $90。如果 ICM 風險是 -$120，這個 call 是正還是負 EV？

A. 正 EV（$90 > 0）
B. 負 EV（賞金 EV $90 < ICM 損失 $120）
C. 不確定

<details>
<summary>答案</summary>

**B - 負 EV**

總 EV = 賞金 EV + BBA Chip EV - ICM 損失

```
BBA Chip EV：45% < 46.1%（BBA 所需勝率），略負
Bounty EV = $90
ICM 損失 = -$120

總 EV = $90（賞金）- $120（ICM 損失）- 少量 BBA chip EV 損失
      ≈ $90 - $120 = -$30（負 EV）
```

雖然賞金很吸引人，BBA 底池也讓 chip odds 稍微更好（46.1% vs 47.2%），但 ICM 損失（$120）仍遠大於賞金 EV（$90）加上 BBA 的改善。這個 call 是負 EV。

需要更高的賞金或更高的勝率才能值得 call：
- 若勝率提升到 50%：賞金 EV = $100，接近損益平衡
- 或者 ICM 損失降低（例如你不在 bubble，損失較小）

</details>

**40. ⭐⭐⭐**
你在 BB，100bb，盲注 200/400，**BBA 400**。LJ open 2.5bb（1,000），CO call，BTN call，SB fold，你有 A♥ 8♥（A8s）。

**BBA 多人底池計算：**
```
SB fold = 200（留底池）
BB 已投入 = 400（大盲）+ 400（BB ante）= 800
LJ 1,000 + CO 1,000 + BTN 1,000 = 3,000

翻牌前底池（如 call）= SB 200 + BB 800 + LJ 1,000 + CO 1,000 + BTN 1,000 = 4,000 chips（10bb）
（傳統無 ante：SB 200 + BB 400 + 3×1,000 = 3,600 chips）
BB call 需補 = 1,000 - 400 = 600 chips
```

多人底池，應該？

A. 3-bet（A8s 是好的 bluff）
B. Call（多人底池有隱含賠率）
C. Fold（OOP 多人不好打）

<details>
<summary>答案</summary>

**B 或 C**

多人底池中 3-bet bluff 成功率很低（需要 3 個人都 fold）。
A8s 在多人底池：
- **Call**：有 flush draw 潛力，nut flush 可以贏大底池
- **Fold**：OOP 多人底池非常難打

**建議：面對 3 個對手，A8s call（有 implied odds），但翻牌後要謹慎，miss 就 check/fold。**

BBA 多人底池計算：
```
BBA 翻牌底池（4人進入）= SB 200 + BB 800 + 3×1,000 = 4,000 chips（10bb）
傳統翻牌底池 ≈ 3,600 chips（9bb）

BBA 讓翻牌底池更大（10bb vs 9bb），A8s 的 nut flush 潛力在 BBA 底池下
value 更高（完成 flush 後底池更大，value bet 金額更多）。
這讓 A8s 的 call 在 BBA 環境下略微更有吸引力。
但 OOP 多人難打的基本原則不變。
```

</details>
