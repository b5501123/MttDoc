# PKO 進階策略：賞金計算與桌面動態（BBA 版本）

## 追殺 EV 的精確計算（BBA 格式）

在 PKO 中，每個 call 決策都需要考慮賞金 EV。以下是完整的計算框架，**全部以 BBA 底池為基礎**。

### 完整 PKO BBA Call EV 公式

```
Call EV = BBA Chip EV（考慮 ICM）+ Bounty EV
        = [p × (BBA 新底池的 ICM value) - (1-p) × (你損失的 ICM value)]
          + p × (目標賞金 B/2)

BBA 底池 = SB + BB + BB ante + 所有入局者的投注
```

### 範例：BB Call 計算（BBA 格式）

**場景：**
- 500人 MTT（PKO，$20 buy-in，$10 rank + $10 bounty）
- 剩 100 人（進 50 名），你在 BB，45bb
- 目標在 CO push all-in 18bb，賞金 $15（已積累了一些）
- SB fold，你 call 需要投入多少？

**步驟 1：BBA 底池計算**
```
盲注（假設 1000/2000，BBA 2000）：
  底池 = CO push 18bb（36,000）+ SB fold 500 + BB 2,000 + BB ante 2,000
  底池合計 = 36,000 + 500 + 2,000 + 2,000 = 40,500
  你 call 需補 = 36,000 - 2,000 = 34,000（大盲已算）

BBA Pot Odds（純 Chip EV）= 34,000 ÷ (40,500 + 34,000) = 34,000 ÷ 74,500 = **45.6%**
```

**傳統底池對比（無 BBA）：**
```
底池 = 36,000 + 500 + 2,000 = 38,500
所需勝率 = 34,000 ÷ (38,500 + 34,000) = 34,000 ÷ 72,500 = **46.9%**

BBA 降低所需勝率：46.9% → 45.6%（差 1.3%）
```

**步驟 2：手牌 equity**
假設你有 A9s，對手 CO 18bb push range ≈ 44%（BBA 環境下更寬，因為 push EV 更高）。
A9s 對 44% range ≈ 55% 勝率。

**步驟 3：BBA Chip EV**
```
BBA Chip EV = 55% 勝率 > 45.6% 需要 → Chip EV 正，call 合理
（傳統需要 46.9%，BBA 需要 45.6%，兩者都是 call，但 BBA 更確定）
```

**步驟 4：加入 Bounty EV**
```
Bounty EV = 55% × ($15 / 2) = 55% × $7.5 = $4.13
```

總 EV = BBA Chip EV（正）+ $4.13 額外賞金收益

**更加確認 call 正確，即使 BBA Chip EV 略為中性也應該 call（Bounty EV 補足差距）。**

## Bounty 的放大效應（BBA 強化）

PKO 賞金會隨時間增長，形成「大魚」效應。BBA 在每個階段都強化了賞金追殺的吸引力：

**早期（每人賞金接近初始）：**
- 賞金普遍較小（$5-$15）
- Bounty EV 影響相對小，打法接近標準 MTT
- **BBA 影響：** push EV 略高，短疊更傾向 push，追殺機會略多

**中後期（有玩家積累了高賞金）：**
- 某些玩家賞金可能達到 $50-$200
- Bounty EV 影響顯著，call range 大幅放寬
- 高賞金玩家成為「攻擊目標」
- **BBA 影響：** BBA 底池 + 高賞金讓追殺 EV 更大，中後期 call 更積極

**計算高賞金目標的 BBA call 調整：**

對手賞金 $100（高賞金），盲注 1000/2000，BBA 2000：
```
假設對手 push 15bb（30,000 chips）：
  BBA 底池 = 30,000 + 500 + 2,000 + 2,000 = 34,500
  call 需補 = 30,000 - 2,000 = 28,000
  純 chip EV 所需勝率 = 28,000 ÷ (34,500 + 28,000) = 28,000 ÷ 62,500 = 44.8%

Bounty EV = P(win) × $50（$100 賞金的一半）

如果你有 48% 勝率：
  Chip EV：48% < 44.8%，純 chip 略負（差 3.2%）
  Bounty EV = 48% × $50 = $24

$24 的賞金 EV 是否足以補償 chip EV 損失？
  取決於你的籌碼有多少，但對於中疊玩家，$24 通常很可觀
  → BBA + 大賞金讓這個 call 很可能是正確的
```

## 高賞金玩家的自我保護（BBA 環境）

當你自己有高賞金，對手的 call range 對你會放寬。BBA 底池讓這個問題更嚴重。

**你有高賞金時的策略調整（BBA 版本）：**

1. **Push range 縮緊：** 對手有更高的追殺激勵（BBA + Bounty 雙重），push 弱牌的 fold equity 顯著降低

2. **注意 BBA 底池讓 call 更容易：** 對手 call 你的 push 時，BBA 底池讓他們的 chip EV 所需勝率更低，配合賞金 EV，即使很弱的牌也可能 call 你

3. **偏向小底池打法：** 避免大底池（BBA 已讓底池更大，更要避免再進一步擴大）

4. **利用 steal 而非 3-bet call：** 偷盲贏小底池，比大底池對抗更安全

**實際例子（BBA 環境）：**
你有 $80 賞金，BTN push 20bb，盲注 1000/2000，BBA 2000。

```
BBA 底池（面對你的 BB call）：
  20bb push = 40,000 + SB 500 + BB 2,000 + BB ante 2,000 = 44,500
  BB call 需補 = 40,000 - 2,000 = 38,000
  所需勝率（純 chip）= 38,000 ÷ 82,500 = 46.1%

對手追殺 EV：P(win) × $40（你賞金的一半）
  對手即使只有 47% 勝率：47% × $40 = $18.8 額外賞金
  配合 chip EV（47% ≈ 46.1%，幾乎平衡），任何有追殺激勵的對手都會 call 你
```

**結論：你有高賞金時，即使你推注強牌，對手的 BBA + Bounty 組合讓他們幾乎總是 call。縮緊 push range，謹慎打大底池。**

## PKO 的桌面動態（BBA 格式）

### 識別高賞金目標（BBA 環境）

在 GGPoker 等平台，每個玩家頭上有賞金顯示。BBA 底池讓追殺高賞金玩家的激勵更大：

**高賞金玩家（Bounty Hunter）的傾向：**
- 通常是積極的玩家（已淘汰多人）
- 可能有大量籌碼（淘汰換籌碼）
- 是比賽的「目標玩家」
- BBA 環境：他們的 push 因底池更大而 EV 更高，但被追殺的機會也更多

**低賞金玩家的傾向：**
- 可能是新進的重買玩家
- 對 PKO 不熟悉，打法更接近標準 MTT
- BBA 底池對他們的影響也一樣，只是少了賞金誘因

### 調整基於對手的 Bounty 水平（BBA 修正）

| 對手賞金等級 | 你的 call 調整（BBA）| 你的 push 調整（BBA）|
|------------|------------------|------------------|
| 低（初始附近）| 標準 BBA call range | 標準 BBA push range |
| 中（2-5x 初始）| 稍微放寬（BBA 底池已讓 chip odds 更優）| 正常 |
| 高（5x+ 初始）| 顯著放寬（BBA + Bounty 雙重）| 謹慎（對方對你 BBA call 也積極）|

## PKO 的 Bubble 特殊策略（BBA 版本）

PKO BBA bubble 是最複雜的決策時刻：BBA Chip EV、Bounty 和 ICM 三重影響。

**PKO BBA Bubble 的三方角力：**
- ICM 說：保守，減少風險
- BBA 說：底池更大，push/call 的 chip EV 更高
- Bounty 說：積極，追殺賞金

**解決框架（BBA 版本）：**
1. 計算 BBA 底池 → 純 chip EV（所需勝率降低）
2. 加入 Bounty EV（對手賞金 × 50% × 勝率）
3. 計算 ICM EV（bubble ICM 壓力）
4. 如果（BBA Chip EV + Bounty EV）> ICM 損失 → call 更積極
5. 如果 ICM 損失 >> （BBA Chip EV + Bounty EV）→ 仍然保守

**典型情境（BBA 計算）：**

中疊 BB（40bb），bubble 附近，短疊 BTN push 7bb（盲注 1000/2000，BBA 2000），賞金 $25。

```
BBA 底池計算：
  底池 = 14,000（7bb push）+ 500（SB）+ 2,000（BB）+ 2,000（BB ante）= 18,500
  call 需補 = 14,000 - 2,000 = 12,000
  BBA chip EV 所需勝率 = 12,000 ÷ (18,500 + 12,000) = 12,000 ÷ 30,500 = 39.3%

傳統底池比較：
  底池 = 14,000 + 500 + 2,000 = 16,500
  所需勝率 = 12,000 ÷ 28,500 = 42.1%
  BBA 降低所需勝率：42.1% → 39.3%（差 2.8%，顯著！）

假設你的勝率 = 55%（手牌不錯）：
  BBA Chip EV：55% > 39.3% → 正值
  Bounty EV = 55% × $12.5 = $6.9 額外
  ICM 損失估算：你有 40bb，輸 7bb 後還有 33bb（不會直接 bubble）

結論：（BBA Chip EV 正值 + Bounty EV $6.9）> 小幅 ICM 損失 → call 通常正確

對比：如果你只有 8bb，輸了直接 bubble：
  ICM 損失 >> $6.9，fold 仍然是正確的
```

**BBA 讓 bubble 的追殺門檻更低，尤其在你有足夠深度不會直接 bubble 出局時。**

## PKO 的邊緣情況：BBA 如何改變計算

### 場景一：BBA 將「fold」變為「call」

**傳統格式：fold（chip EV 稍負 + 賞金 EV 不足）**
**BBA 格式：call（chip EV 因底池更大略正 + 賞金 EV 足夠補充）**

這種情況最常出現在：
- 對手 push 7-12bb，你有邊緣手牌（40-45% 勝率）
- 對手有中等賞金（2-3x 初始）
- 你有足夠深度不會因 call 失敗而直接 bubble

### 場景二：BBA 不改變「fold」決定

即使 BBA 底池讓 chip odds 更優，以下情況仍應 fold：
- 你在 bubble，是真正的短疊（< 12bb）
- 對手的賞金很低（接近初始賞金）
- ICM 損失遠超 BBA 帶來的 chip EV 改善和賞金 EV 之和

### 計算工具的 BBA 設定（重要）

使用 ICMIZER 或 HRC 計算 PKO 情境時：
- **必須選擇 BBA（Big Blind Ante）設定**
- 不選 BBA 會低估底池大小，導致計算出的所需勝率偏高（過於保守）
- GGPoker 匯入的手牌歷史會自動顯示 BBA，但手動輸入情境時必須手動選擇

## PKO 的學習路徑（BBA 版本）

**初學者重點：**
1. 理解 BBA 底池計算（SB + BB + BB ante）
2. 理解賞金 EV 的計算（B/2 × 勝率）
3. 學會在 call 決策中加入 BBA Chip EV + Bounty EV
4. 注意自己有高賞金時的 BBA 保護策略

**中級重點：**
1. 使用 ICMIZER PKO mode（選 BBA 設定）分析手牌
2. 理解 PKO BBA bubble 的三重壓力（BBA + Bounty + ICM）
3. 識別桌面上的高賞金目標，計算 BBA 追殺 EV
4. 在 BBA 環境下調整 push range（底池更大，push EV 更高）

**進階重點：**
1. 完整的 PKO BBA ICM + Bounty 計算框架
2. BBA 如何在 PKO 邊緣情況中改變 fold/call 判斷
3. 動態桌面策略（隨賞金分佈和盲注結構調整 BBA 打法）
4. 多桌 PKO 管理（識別哪桌有高賞金目標，計算每桌的 BBA 追殺 EV）

**BBA PKO 計算速查表：**

| 對手 push（bb）| BBA 所需勝率（大約）| 傳統所需勝率 | BBA 改善 |
|-------------|------------------|-----------|--------|
| 5bb | 33% | 36% | -3% |
| 8bb | 39% | 42% | -3% |
| 10bb | 41% | 44% | -3% |
| 15bb | 43% | 46% | -3% |
| 20bb | 44% | 47% | -3% |

（BBA 一律降低所需勝率約 2-3%，配合賞金 EV，PKO call range 比傳統 MTT 寬約 5-8%）
