# MTT GTO 策略教學文件目錄

## 文件架構說明

本教學系列以 **9-max（9人桌）為標準**，**線上 MTT 為主要環境**，覆蓋從基礎概念到進階實戰的完整內容。

9-max 標準位置：UTG → UTG+1 → UTG+2 → LJ → HJ → CO → BTN → SB → BB

### ICM 情境速查

| 情境 | Push Range | Call Range | 關鍵原則 |
|------|-----------|-----------|---------|
| 早期深疊（遠離 money）| Nash 標準 | Nash 標準 | 純 Chip EV |
| Bubble 大疊 | +2-3% | 標準 | 施壓中疊 |
| Bubble 中疊 | -10-15% | 非常緊 | 保護生存 |
| Bubble 短疊 | -3-5% | 很緊 | 積極 push |
| Final Table 5-4 人 | -10% | 緊 | ICM 峰值 |
| Heads-Up | Nash 放寬 | Nash HU | 純 Chip EV |

### Antes 啟動的影響

有 Antes 後，以下位置的 open / steal range 應該放寬：
BTN / CO / SB 各放寬約 3-5%，HJ 放寬約 2-3%。

### 線上 MTT 通用調整

- 對手 fold to 3-bet >65%：增加 3-bet bluff 頻率
- 對手 fold to c-bet >65%：增加 c-bet bluff 頻率
- 線上 call range 偏窄：push range 可稍微放寬（+3-5%）
- Bubble 持續時間長：保持長時間 ICM 意識，bubble 時主動減桌
- FT 疲勞管理：FT 前關閉其他桌，保持清醒
