# ICM 調整：Push/Fold 的獎金結構修正

## ICM 如何讓 Push Range 縮緊

Nash 均衡計算的是 Chip EV 最優。當獎金結構存在時，ICM 會改變最優策略。

**核心機制：**
- 失去籌碼的 ICM 代價 > 贏得同量籌碼的 ICM 收益
- 因此，在關鍵節點，即使 Chip EV 是正的，ICM EV 可能是負的
- 結果：push range 縮緊，call range 也縮緊

**縮緊幅度取決於：**
1. 你距離 money 有多近（bubble 最大）
2. 獎金結構的陡峭程度（FT 名次差距越大，影響越大）
3. 你的相對籌碼量（中疊受影響最大）

## Bubble 三種角色

### 角色一：大疊（Chip Leader / Near Chip Leader）

**ICM 壓力：最小**

大疊在 bubble 的優勢：
- 輸一場不會出局，只是籌碼減少
- 對所有人都有威脅，中疊/短疊不願意面對你
- 可以積極偷盲，逼迫中疊和短疊 fold

**策略調整：**
- Push range 可以比 Nash **稍微放寬**（因為即使輸，ICM 損失相對小）
- 積極針對中疊（他們 ICM 壓力最大）
- 對短疊更謹慎（短疊 push 的手牌品質較好）

### 角色二：中疊（Middle Stack）

**ICM 壓力：最大**

中疊在 bubble 的困境：
- 跟注 all-in 可能嚴重損害籌碼，接近短疊甚至出局
- 不能如大疊般輕鬆冒險
- 距離 money 很近，但還沒進

**策略調整：**
- Push range 縮緊最多（相比 Nash 可能縮緊 10-15%）
- Call range 非常保守（只 call AA/KK/AK 級別的手牌面對大疊 push）
- 主動 push 時要看清楚周圍籌碼分佈：短疊在後位時，push 風險更高

### 角色三：短疊

**ICM 壓力：反而降低**

短疊在 bubble 的邏輯：
- 即使謹慎，盲注也快把你吃光
- 積極 push 才有翻盤機會
- 被 call 輸了，ICM 損失有限（你已經接近出局）

**策略調整：**
- Push range 比標準 Nash **略窄**（小幅縮緊，因為被 call 輸了可能直接出局）
- 但不能太保守，積極找機會 push 是唯一生路
- 面對大疊的 push，call range 更緊（輸了直接出局）

## Bubble ICM 場景計算

**場景：** 100 人 MTT，10人 bubble，11人進錢

獎金結構：1st $5,000 / 2nd $3,000 / 3rd $2,000 / ... / 11th $200

籌碼分佈（10人剩）：
- 大疊：120,000
- 中疊 A：45,000
- 中疊 B：38,000
- 短疊：12,000
- 其餘6人：平均約 35,000

**場景：大疊對中疊 A All-in，中疊 A 勝率 55%**

Chip EV 說：call（+EV）

ICM 計算：
- 中疊 A 現在 ICM equity：約 $310
- 贏了（55%）：65,000 → ICM equity 約 $480
- 輸了（45%）：出局 $0

```
Call EV = 55% × $480 + 45% × $0 = $264
Fold EV ≈ $310
```

**應該 fold**，即使有 55% 勝率。

## Final Table ICM 調整

FT 的 ICM 壓力與 bubble 類似，但名次差距可能更大。

**FT 各人數的 ICM 壓力（以 FT 開始時為基準）：**

| 剩餘人數 | ICM 壓力 | 策略重點 |
|---------|---------|---------|
| 9-7 人 | 中等 | 積累籌碼仍重要，但開始注意 ICM |
| 6-5 人 | 增加 | 名次差距開始顯著，中疊要謹慎 |
| 4-3 人 | 高 | 每個淘汰都有大額獎金差距 |
| 2 人 | 消失 | 純 Chip EV，HU 不需要 ICM 考量 |

FT 的獎金結構通常前幾名差距很大（如 1st 是 2nd 的 1.5-2 倍），這讓大疊積極、中疊保守的策略更加明顯。

| 情境 | Push Range 調整 | Call Range 調整 | 關鍵原則 |
|------|----------------|----------------|---------|
| 早期（遠離 bubble） | Nash 標準 | Nash 標準 | 純 Chip EV |
| 接近 bubble 3 桌 | 輕微縮緊（-3-5%） | 輕微縮緊 | 開始意識 ICM |
| Bubble 大疊 | 略放寬（+2-3%） | Nash 標準 | 施壓中疊 |
| Bubble 中疊 | 明顯縮緊（-10-15%） | 非常緊 | 保護生存 |
| Bubble 短疊 | 輕微縮緊（-3-5%） | 很緊 | 仍需積極 push |
| FT 9-7 人 | 縮緊（-5%） | 縮緊 | 名次意識 |
| FT 5-4 人 | 明顯縮緊（-10%） | 緊 | ICM 峰值 |
| FT 3-2 人 | 縮緊降低（-5%） | 標準 | 接近 HU |
| HU | Nash 放寬 | Nash HU | 純 Chip EV |

## 線上 MTT 特別說明

**線上大型 MTT 的 bubble 持續時間非常長。**

一個 1,000 人的 MTT，前 150 名進錢。當剩下 170-200 人時進入 bubble 階段，此時可能有：
- 15-20 桌同時進行
- 每桌有不同的籌碼壓力格局
- Bubble 可能持續 30-60 分鐘（幾十甚至上百手牌）

這對玩家有幾個特殊要求：

1. **長時間 ICM 意識：** 不像現場 bubble 可能只有幾手，線上 bubble 需要長時間保持正確心態

2. **多桌同步判斷：** 你可能在 A 桌打 bubble，同時在 B 桌已經進錢。需要動態調整每桌的 ICM 優先級

3. **Lobby 監控：** 線上可以看到其他桌的進展，了解整體籌碼分佈。大型 MTT 平台（GGPoker, PokerStars）都有 lobby 功能顯示各桌狀況

4. **避免 bubble 疲勞：** 長時間的高度緊張容易疲勞，ICM 判斷品質下降。保持節奏，不要因為「熬過了這麼久」而在最後關鍵手牌鬆懈

5. **識別哪個桌打的是 Bubble：** 多桌情況下，哪桌是「真正的 bubble 桌」（短疊聚集、最可能出局的桌）需要特別關注
