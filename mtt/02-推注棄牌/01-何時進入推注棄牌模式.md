# 何時進入推注棄牌模式

## Push/Fold 的定義

Push/Fold 模式：翻牌前的選擇只有兩個——**All-in（push）或 Fold**，完全跳過 open small 和 call 的選項。

這不是因為「強牌才 push」，而是因為在特定籌碼深度下，push/fold 在數學上是最優策略。

本章所有計算均以**Big Blind Ante（BBA）**為預設標準。BBA 是現代線上 MTT 的通行規則：由大盲位玩家額外支付 1bb 的 ante，每手牌底池因此比傳統無 ante 結構大出約 50%。

---

## BBA 標準底池計算

在 BBA 環境下，底池的起始大小與傳統無 ante 結構截然不同：

| 盲注 | SB | BB | BB Ante | 起始底池 |
|------|----|----|---------|---------|
| 100/200 | 100 | 200 | 200 | **500** |
| 200/400 | 200 | 400 | 400 | **1,000** |
| 500/1,000 | 500 | 1,000 | 1,000 | **2,500** |

傳統無 ante 結構的底池僅為 SB + BB（例：100/200 = 300）。BBA 讓底池大出 67%，這對 push/fold 計算有決定性影響：**fold equity 的收益更高，push range 應比傳統 Nash 表（無 ante 版）更寬。**

---

## 為何短疊應該 push/fold

### 數學基礎

當你 push all-in，有兩種結果：
1. 所有人 fold → 你直接贏得底池（SB + BB + BB ante）
2. 有人 call → 進入攤牌，靠牌力決定勝負

這就是 **Fold Equity（棄牌股權）** 的核心。

```
Push EV = P(all fold) × 底池 + P(called) × [勝率 × 新底池 - 輸時損失]
```

在 BBA 環境下，底池更大（例：10bb push 底池約 12.5bb 而非 7.5bb），fold equity 的絕對收益更高。即使對手有更好的 pot odds call，整體 push 公式在 BBA 下仍比無 ante 環境更有利。

**BBA 對 Push EV 的具體影響（10bb push，BTN 位置）：**

| 結構 | 起始底池 | Fold equity 收益 | Push range（近似） |
|------|---------|-----------------|------------------|
| 無 ante | 1.5bb | 1.5bb | ~62% |
| BBA | 2.5bb | 2.5bb | ~65% |

差距看似不大，但在 8-12bb 深度下，每增加 1bb 的 fold equity，邊界手牌的 push EV 差值可達 0.3-0.5bb，足以改變決策。

### 為何不能 open small

假設你有 12bb，open 2.5bb：

- 如果被 fold，你在 BBA 底池（2.5bb）中只贏得 SB 0.5bb + BB 1bb（你付出 2.5bb，淨賺接近 0 或為負）
- 如果有人 3-bet，你面對 6-7bb 的 raise，剩下 9.5bb
  - Call：SPR 趨近於 0，無翻牌後遊戲空間
  - Fold：浪費了 2.5bb
- 如果有人 flat call，翻牌後你還有 9.5bb，SPR ≈ 2，被迫 all-in 翻牌前才是正確的

**結論：** Open small 的問題是你的籌碼不夠深，無法有效支撐翻牌後的博弈。直接 push/fold 讓策略更清晰，也避免了被 3-bet 夾在中間的困境。BBA 環境下 open small 的效率更低——因為你 steal 成功時贏得的底池更大，讓 push 更具吸引力。

## 臨界點：何時進入 push/fold

### BBA 標準通用準則

| Stack | 建議 |
|-------|------|
| >25bb | 仍可 open small（2-2.5bb），有完整翻牌後空間 |
| 20-25bb | 視情況：後位強牌可 push，前位可 open small |
| 15-20bb | 多數位置 push/fold，後位（BTN/CO）可嘗試 open 2bb |
| <15bb | **純 push/fold** |
| <10bb | 越短越寬，積極 push |

BBA 環境下，進入 push/fold 的臨界點與傳統結構相同（約 15-20bb），但同等深度下的 push range 比無 ante 版本**寬 3-5%**。這是因為底池更大使得 fold equity 收益更高，讓邊界手牌的 push EV 跨過正值門檻。

### 15bb 是關鍵門檻

為什麼 15bb 特別重要：
- 15bb open 2.5bb 後，剩 12.5bb，SPR 在多人底池下已不夠打多條街
- 被 3-bet all-in 後，你的 effective call size 太大，無法舒服地 fold
- 直接 push 15bb，對手需要非常強的手牌才能正確 call（你有大量 fold equity）
- BBA 底池讓這個 push 的 EV 比無 ante 時更高：你在 15bb push 時贏得的底池約為 3.5bb（BBA）vs 2.5bb（無 ante），fold equity 提升 40%

### 20bb 時的特殊考量

在 20bb 左右，BBA 環境特別值得考慮直接 push 而非 open small 的情況：

**BBA 20bb push EV 優勢顯現於：**
1. 後位（BTN/CO/SB），對手多數為短疊或受 ICM 壓力的中疊
2. Bubble 附近，中疊的 fold equity 極高
3. 盲注後位（即將付 BB + ante），需要積極偷盲補充

---

## Open-shove vs Open-small 的判斷

有些情況下，比 15bb 更深也適合 open-shove：

**適合 open-shove 的情況（BBA 環境）：**
1. 20-22bb，位置為 UTG/UTG+1，強牌（AK, QQ-AA）直接 shove 簡化打法
2. 17-20bb，後位（CO/BTN），shove 比 open small 更能讓 SB/BB fold——尤其在 BBA 環境下，shove 贏得的底池更大
3. 任何情況下，短疊的隱含賠率極低，不值得 open small
4. 接近 bubble，BBA 讓 steal 收益更大，更寬的 shove range 具備正 EV

**仍可 open small 的情況：**
1. 25bb+，後位（BTN/CO），open 2bb 有完整後手選擇
2. 深疊 pair hands，想要深疊人 call（隱含賠率）

## BB Call 的 Pot Odds 計算（BBA 版本）

作為 BB，面對某人的 push，你需要計算是否值得 call。

**公式：**
```
需要的勝率 = 需要 call 的量 ÷ （底池 + 需要 call 的量）
```

**BBA 範例：** 9-max，BTN push 12bb，SB fold，你在 BB 有 1bb 已投入（BB ante 已由你付出 1bb）

- BBA 底池組成：12bb（BTN push）+ 0.5bb（SB，已 fold）+ 1bb（你的 BB）+ 1bb（你的 BB ante）= **14.5bb**
- 你需要再 call 11bb（12bb - 1bb 已投入）
- 需要的勝率 = 11 ÷ (14.5 + 11) = 11 ÷ 25.5 ≈ **43.1%**

與無 ante 結構相比（需要 44.9% 勝率），BBA 讓你的 call 標準稍微降低，因為底池更大、pot odds 更佳。這使得 BB 的 call range 比無 ante Nash 表略寬。

**常見手牌 vs BTN push range（65%）的勝率：**

| 手牌 | 勝率（對 BTN 65% range） | BBA call 是否達標（43.1%） |
|------|------------------------|-----------------------------|
| KK | ~77% | ✓ |
| AKs | ~62% | ✓ |
| JJ | ~63% | ✓ |
| 99 | ~56% | ✓ |
| ATo | ~55% | ✓ |
| KQo | ~53% | ✓ |
| 77 | ~51% | ✓ |
| A5s | ~51% | ✓ |
| K9o | ~46% | ✓（BBA 環境勉強過線） |
| Q8s | ~44% | ✓（BBA 邊緣） |

## BBA 對 Push Range 的系統性影響

BBA 是現代線上 MTT 的標準結構，對 push/fold 策略有三個關鍵影響：

### 影響一：所有 bb 深度的 push range 均放寬

| 深度 | 無 ante Nash（BTN） | BBA Nash（BTN） | 差距 |
|------|---------------------|-----------------|------|
| 20bb | ~40% | ~43-44% | +3-4% |
| 15bb | ~52% | ~55-57% | +3-5% |
| 10bb | ~62% | ~65-67% | +3-5% |
| 7bb | ~74% | ~77-79% | +3-5% |

### 影響二：早位 push range 也有所放寬

BBA 的底池增益對早位 push 的影響同樣明顯：
- UTG 10bb：無 ante 約 26-28%，BBA 環境約 29-31%
- CO 10bb：無 ante 約 50%，BBA 環境約 52-55%

### 影響三：SB push range 是最受 BBA 影響的位置

SB push 只需讓 BB fold：
- SB 10bb：無 ante 約 65%，BBA 環境約 68-70%
- SB 7bb：無 ante 約 76%，BBA 環境約 79-82%

原因：BBA 讓底池更大，SB push 贏得的 fold equity 比例更高，且 BB 已付出 2bb（BB + ante），call 的邊際成本相對更低但你的 push EV 也更高。

---

## 線上 MTT 特別說明

**線上玩家的 call range 普遍比 Nash 窄。**

原因：
1. 很多線上玩家（尤其是中低籌碼等級）對 push range 不夠了解，傾向保守跟注
2. 短疊 push 有一定的「恐嚇效果」，讓一些玩家 fold 本應 call 的手牌
3. 線上多桌玩家有時在非主桌不夠專注，做出過 tight 的 fold

**實際影響（BBA 環境）：**

在 BBA 標準下，push range 的放寬來自兩個疊加因素：
1. **BBA 結構本身**：比無 ante Nash 寬約 3-5%
2. **線上玩家 call 偏緊**：在此基礎上再寬約 2-3%

結合兩者，線上低/中 stakes 的 BBA MTT，你的實際最優 push range 可能比無 ante Nash 表寬出 5-8%。

但在高 stakes 或強玩家主導的桌上，不要過度放寬。強玩家了解 BBA 的影響，其 call range 已針對 BBA 調整，不會給你額外的 fold equity。

**推薦工具：** 使用 ICMIZER 或 HoldemResources Calculator（HRC）的 BBA 模式計算 push range，不要直接套用舊版無 ante Nash 表。兩個工具均支援設定 BBA 盲注結構，輸出的 range 已自動反映 BBA 底池。
