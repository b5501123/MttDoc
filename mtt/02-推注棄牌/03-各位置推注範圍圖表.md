# 各位置推注範圍圖表（BBA 標準）

本章提供 9-max 標準線上 MTT 各位置的 push range，以**Big Blind Ante（BBA）Nash 均衡**為基準，並附上代表性手牌說明。

**重要說明：** 本章所有數據均預設 BBA 環境（BB 額外付 1bb ante）。BBA 底池 = SB + BB + BB ante，例如 100/200 時起始底池為 500（而非無 ante 的 300）。這使得所有位置、所有 bb 深度的 push range 均比傳統無 ante Nash 表**寬約 3-5%**。

數字為近似值，基於 HRC/ICMIZER BBA 模式計算結果，實際略有浮動（受具體籌碼深度、桌上玩家數影響）。

---

## BTN（Button）Push Range（BBA 版）

BTN 是 push/fold 中收益最高的位置，只需通過 SB 和 BB。BBA 環境下 BTN push 的 fold equity 收益提升顯著。

| Stack | BBA Range % | 無 ante Range %（參考） | BBA 代表性邊界手牌 |
|-------|-------------|----------------------|-----------------|
| 20bb | ~44-46% | ~40-42% | K8o, Q9s, J9o, T8s, 66 |
| 15bb | ~55-57% | ~52-54% | K5o, Q8s, J8o, T7s, 44 |
| 12bb | ~60-62% | ~57-59% | K4o, Q7s, J7o, T6s, 33 |
| 10bb | ~65-67% | ~62-64% | K2o, Q5s, J6o, T6s, 33 |
| 8bb | ~72-74% | ~69-71% | Q2s, J5o, T5s, 97o, 22 |
| 6bb | ~80-83% | ~77-80% | 96o, 85s, 74o, 63s, 22 |

**BBA 代表性手牌（10bb BTN）：**
- 所有對子（22+）
- A2o+（幾乎所有 Ace）
- K2s+, K7o+
- Q5s+, Q9o+
- J6s+, JTo
- T6s+, T9o
- 96s+, 98o
- 86s+
- 76s+, 65s

**BBA 注意事項：** BTN push 很寬，是因為 SB/BB 需要很好的牌才能正確 call。BBA 環境下，BB 的 pot odds 稍好（底池更大），call range 略寬，但 BTN push range 放寬幅度更大，兩者之間的「可 push 不可 call」區間仍然廣泛。

## UTG（Under the Gun）Push Range（BBA 版）

UTG 是最緊的位置，需要通過整桌。BBA 雖然放寬了範圍，但早位多人 call 的風險仍要注意。

| Stack | BBA Range % | 無 ante Range %（參考） | BBA 代表性邊界手牌 |
|-------|-------------|----------------------|-----------------|
| 20bb | ~14-15% | ~12-14% | ATs, KQo, JJ |
| 15bb | ~19-21% | ~17-19% | ATo, KJo, QTs, 88 |
| 12bb | ~23-25% | ~20-22% | KTo, Q9o, J9s, T8s, 77 |
| 10bb | ~29-31% | ~26-28% | KTo, Q9o, J9s, T8s, 66 |
| 8bb | ~37-39% | ~34-36% | K8o, Q7s, J8s, T7o, 44 |
| 6bb | ~49-51% | ~46-48% | K5o, Q5s, J6s, T5s, 33 |

**UTG 特別說明：** UTG BBA push range 雖比無 ante 寬，但實際上面對多人 call 的情況仍然需要收緊邊界手牌。BBA 的主要好處在於對整桌的 fold equity 收益，但多人 call 後底池賠率讓短牌的勝率需求也提高。

## SB（Small Blind）Push Range（BBA 版）

SB push range（假設所有前位 fold，只需過 BB）：BBA 對 SB 的影響最大，因為 BB 付出了更多（BB + ante），但 SB push 贏得的底池也更大。

| Stack | BBA Range % | 無 ante Range %（參考） | BBA 代表性邊界手牌 |
|-------|-------------|----------------------|-----------------|
| 20bb | ~58-60% | ~55-57% | K6o, Q8s, J8o, T7s, 55 |
| 15bb | ~60-62% | ~57-59% | K5o, Q8s, J8o, T7s, 55 |
| 12bb | ~65-67% | ~62-64% | K3o, Q6s, J7o, T6s, 44 |
| 10bb | ~70-72% | ~67-69% | K2o, Q4s, J6o, 97s, 33 |
| 8bb | ~78-80% | ~75-77% | Q2s, J4o, T5s, 96o, 22 |
| 6bb | ~85-87% | ~82-84% | 85o, 74s, 63s, 52s, 22 |

SB push range 特別寬，因為只需讓 BB fold，fold equity 最高。BBA 環境下 BB 多付出了 1bb ante，有時會讓 BB 的 call 略寬（已投入更多），但 SB push 贏得的 fold equity 也更大，整體仍然是 push range 放寬。

## BB Call Range（BBA 版）

BB 作為最後一個行動者，面對各位置的 push，BBA call range 如下（10bb push）：

| Push 位置 | BBA BB Call Range | 無 ante BB Call Range（參考） | 說明 |
|----------|-------------------|------------------------------|-----|
| BTN | ~37-38% | ~34-36% | BTN BBA push 65%，BB call 仍更窄 |
| CO | ~31-32% | ~29-30% | CO push 更窄，BB call 相應收緊 |
| HJ | ~27-28% | ~25-26% | 更窄的 push → 更窄的 call |
| LJ | ~24-25% | ~22-23% | |
| UTG+2 | ~22-23% | ~20-21% | |
| UTG | ~21-22% | ~19-20% | UTG BBA push ~30%，BB call 約 21% |

**規律：** push 位置越早（push range 越窄，手牌越強）→ BB call range 越窄。BBA 版 call range 比無 ante 版整體略寬 1-2%。

**BBA BB 面對 BTN push 10bb 的 call range（近似）：**
- 所有對子（33+）
- A2s+, A7o+
- K9s+, KTo+
- Q9s+, QJo
- J9s+
- T9s

## SB 面對 BTN Push 的 Call Range（BBA 版）

| BTN Stack | SB BBA Call Range | 無 ante SB Call Range（參考） |
|-----------|-------------------|------------------------------|
| 10bb | ~23-24% | ~21-22% |
| 7bb | ~28-30% | ~26-27% |

SB 比 BB call 更窄，因為 SB 如果 call，需要投入更多（SB 只有 0.5bb 在底池，而 BB 已有 2bb：1bb BB + 1bb ante）。BBA 讓 BB 的 pot odds 更好，加大了 SB 和 BB call range 之間的差距。

## 關於這些數字的重要說明

1. **預設 BBA 環境：** 以上所有數據均基於 BBA（BB 額外付 1bb ante）計算。如果在無 ante 結構下，請將所有範圍縮緊約 3-5%

2. **這是 Chip EV Nash，ICM 未納入：** Bubble 或 FT 附近，push range 通常縮緊 5-10%，call range 也縮緊

3. **多人 call 未考慮：** 早位 push 面對多個潛在 caller，應縮緊。UTG/UTG+1 的數字在多人桌上需要額外謹慎

4. **建議用 HRC/ICMIZER BBA 模式驗證邊緣手牌：** 真正邊界附近（如 CO 10bb 的 K5o、HJ 10bb 的 J8s）需要軟體確認。在工具中設定「Big Blind Ante」選項，不要使用預設的無 ante 模式

5. **線上調整：** 線上低/中 stakes 的玩家 call range 普遍偏窄，push range 在 BBA Nash 基礎上可再稍微放寬（約 +2-3%）。高 stakes 玩家已熟悉 BBA 環境，不需要額外放寬

6. **深度插值：** 本表只列出幾個代表性深度（20/15/12/10/8/6bb）。如果你是 11bb 或 9bb，用相鄰兩個深度的範圍插值估算即可
