# 各位置推注範圍圖表（9-max）

本章提供 9-max 標準 MTT 各位置的 push range，以 Nash 均衡為基準，並附上代表性手牌說明。數字為近似值，實際略有浮動（受 antes 比例、具體玩家數影響）。

---

## BTN（Button）Push Range

| Stack | Range % | 代表性邊界手牌 |
|-------|---------|-------------|
| 20bb | ~42% | K7o, Q9s, J9o, T8s, 66 |
| 15bb | ~54% | K4o, Q7s, J8o, T7s, 44 |
| 10bb | ~65% | K2o, Q4s, J6o, T6s, 33 |
| 7bb | ~76% | 97o, 85s, 74o, 62s, 22 |

**代表性手牌（10bb BTN）：**
- 所有對子（22+）
- A2o+（幾乎所有 Ace）
- K2s+, K7o+
- Q4s+, Q9o+
- J6s+, JTo
- T6s+, T9o
- 96s+, 98o
- 86s+
- 75s+, 65s

**注意：** BTN push 很寬，是因為 SB/BB 需要很好的牌才能 call 這麼深的 push。

## BB Call Range

BB 作為最後一個行動者，面對各位置的 push，call range 如下（10bb push）：

| Push 位置 | BB Call Range | 說明 |
|----------|--------------|-----|
| BTN | ~36% | BTN push 65%，但 BB call 更窄 |
| CO | ~30% | CO push 更窄，BB call 相應收緊 |
| HJ | ~26% | 更窄的 push → 更窄的 call |
| LJ | ~23% | |
| UTG+2 | ~21% | |
| UTG | ~20% | UTG push 28%，BB call 約 20% |

**規律：** push 位置越早（push range 越窄，手牌越強）→ BB call range 越窄

**BB 面對 BTN push 10bb 的 call range（近似）：**
- 所有對子（33+）
- A2s+, A7o+
- K9s+, KTo+
- Q9s+, QTo+
- J9s+
- T9s

---

## 關於這些數字的重要說明

1. **這是近似值：** 實際 Nash range 依 antes 比例、具體籌碼深度（12bb vs 10bb vs 8bb 都不同）、軟體算法略有差異

2. **ICM 未納入：** Bubble 或 FT 附近，push range 通常縮緊 5-10%，call range 也縮緊

3. **多人 call 未考慮：** 早位 push 面對多個潛在 caller，應縮緊

4. **建議用 HRC 驗證邊緣手牌：** 真正邊界附近（如 UTG 10bb 的 K9o、J9s）需要軟體確認

5. **線上調整：** 線上低/中 stakes 的玩家 call range 普遍偏窄，push range 可稍微放寬（約 +3-5%）
