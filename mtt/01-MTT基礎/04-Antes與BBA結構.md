# Antes 與 Big Blind Ante（BBA）結構：現代線上 MTT 的底池基礎

## 為什麼本章是所有計算的前提

在閱讀本教材的任何策略內容之前，你必須先掌握 Big Blind Ante（BBA）結構。這不是一個「選項」或「某些比賽才有的規則」，而是**現代線上 MTT 的預設環境**。

如果你用「沒有 ante」的方式計算底池大小、思考偷盲 EV、評估 push/fold 邊界，你的所有計算都會出錯——往往會低估底池約 40-50%，導致策略過於保守。

本章目的：建立 BBA 環境下所有計算的正確基礎。

---

## 什麼是 Big Blind Ante（BBA）

### 基本定義

BBA 是一種 ante 支付方式。在每一手牌中：

- SB（小盲）支付 0.5bb
- BB（大盲）支付 1bb（大盲本身）**加上** 1bb（ante）
- 其他位置玩家不付 ante

**BB 實際投入 = 1bb（大盲）+ 1bb（ante）= 2bb**

因此，每手翻牌前的底池基礎 = SB + BB + BBA：

```
0.5bb（SB）+ 1bb（BB）+ 1bb（BBA）= 2.5bb
```

這是打出任何一手牌之前，底池裡已有的籌碼。

### 實際數字範例

| 盲注等級 | SB | BB | BBA | 翻牌前底池 |
|---------|----|----|-----|----------|
| 50/100 | 50 | 100 | 100 | 250 |
| 100/200 | 100 | 200 | 200 | 500 |
| 200/400 | 200 | 400 | 400 | 1,000 |
| 500/1,000 | 500 | 1,000 | 1,000 | 2,500 |
| 1,000/2,000 | 1,000 | 2,000 | 2,000 | 5,000 |
| 2,000/4,000 | 2,000 | 4,000 | 4,000 | 10,000 |
| 3,000/6,000 | 3,000 | 6,000 | 6,000 | 15,000 |
| 5,000/10,000 | 5,000 | 10,000 | 10,000 | 25,000 |

**規律：翻牌前底池 = 2.5 × BB**（而非無 ante 情況下的 1.5 × BB）

## BBA 與傳統 Antes 的差別

### 傳統 Antes（每人付）

傳統 antes 要求桌上每位玩家各自支付一個 ante（通常為 BB 的 10-12.5%）。

**9-max 傳統 antes 範例（100/200，ante = 25）：**

```
SB: 100
BB: 200
其他 7 人各付: 25 × 7 = 175
BB 自己也付: 25

總底池 = 100 + 200 + 25 × 9 = 525
```

### BBA（現代線上標準）

BBA 把所有 antes 集中由 BB 支付，金額通常等於 1bb。

**9-max BBA 範例（100/200，BBA = 200）：**

```
SB: 100
BB: 200（大盲）+ 200（BBA）
其他位置: 0

總底池 = 100 + 200 + 200 = 500
```

### 主要差異對比

| 比較項目 | 傳統 Antes（9人 × 25） | BBA（等於 1bb）|
|---------|---------------------|--------------|
| 底池大小 | 約 525（100/200 級） | 500（100/200 級） |
| 誰付出最多 | 全桌均攤 | BB 額外承擔 |
| 操作簡便性 | 每人各自投入 | 只需 BB 投入 |
| 每圈輪轉成本 | 每人都付 | 只在 BB 位付 |
| 線上普及程度 | 現場賽事較多 | 線上 MTT 標準 |

### BBA 對不同位置的實際影響

BBA 的一個重要含義是：**BB 在每手額外承擔了一個 ante 的成本**。這代表：

- BB 位置的每圈成本是 2bb（1bb 大盲 + 1bb ante），而不是 1bb
- 其他位置的每圈成本相對減少（不再每人付 ante）
- BB 在翻牌前的 pot odds 計算需要考慮這個額外投入

## BBA 底池計算：全面範例

### 基礎底池計算

以 100/200 BBA 為例，底池 = **500**。

所有翻牌前行動的尺寸都要以這個 500 為基礎計算：

**翻牌前 open（各位置標準尺寸）：**

| 行動 | 尺寸（bb） | 實際籌碼 | open 後底池 |
|------|----------|--------|-----------|
| open 2bb | 400 | 以 200bb 計 | 100 + 200 + 200 + 400 = 900 |
| open 2.2bb | 440 | 以 200bb 計 | 940 |
| open 2.5bb | 500 | 以 200bb 計 | 1,000 |
| open 3bb | 600 | 以 200bb 計 | 1,100 |

### 偷盲計算（BBA 環境）

**情境：所有人 fold，BTN open 2.5bb（500），SB/BB fold**

BTN 贏得：
- SB 的 100
- BB 的 200
- BBA 的 200
- 共 500

BTN 投入：500（open raise）

**淨收益 = 500 - 500 = 0（不計算機會成本）**

但這不是重點。重點是：BTN 用 500 的籌碼冒險，**贏了就得回 500 的底池**，相當於 1 倍回報。

如果 fold，BTN 輸 0。如果 call/被 3-bet，損失可能更大。

BTN 的盲注偷取 EV 計算：

```
假設對手 fold 率 = F%
BTN EV = F% × (+500 底池) + (1-F%) × [翻牌後 EV]
```

在 BBA 環境下，底池是 500（而非無 ante 的 300），**因此 F% 只需要更低就能保持正 EV**。

### 無 Ante vs BBA 的偷盲 EV 對比（100/200）

| 環境 | 翻牌前底池 | open 2.5bb 後底池 | 需要 fold 率（break even） |
|------|----------|-----------------|------------------------|
| 無 ante | 300 | 800（300+500）| 約 62.5% |
| BBA（200）| 500 | 1,000（500+500）| 約 50% |

**BBA 讓每次偷盲降低了約 12.5% 的必要 fold 率。** 這是一個非常顯著的差距——意味著你可以對著更寬的 defend range 獲利地偷盲。

## BBA 如何改變偷盲 EV：數學深度分析

### 基礎公式

設：
- P = 翻牌前底池（BBA 環境 = 2.5bb）
- R = open raise 尺寸
- F = 對手 fold 率（全部 fold 的機率）
- EV_postflop = 進入翻牌後的期望值（依技術而定）

```
EV(steal) = F × R + (1 - F) × (EV_postflop - R)
```

為讓 EV(steal) > 0，需要：

```
F × R > (1 - F) × (R - EV_postflop)
F > (R - EV_postflop) / (P + R - EV_postflop)
```

假設翻牌後 EV = 0（保守估計），open 2.5bb（=R=500，底池基礎 P=500）：

```
需要 fold 率 > 500 / (500 + 500) = 50%
```

若是無 ante（P = 300）：

```
需要 fold 率 > 500 / (300 + 500) = 62.5%
```

### 各位置的 steal EV 在 BBA 環境下

**BTN 偷盲（對 SB+BB 兩人）**

在 BBA（100/200）下，open 2.5bb（500）：

```
底池 = 500
Call 一人的情況：底池 = 1,000，有效 SPR 仍合理
Fold 收益 = +500（SB + BB + BBA）
```

BTN 偷盲在 BBA 環境下的期望收益特別高，因為：
1. BBA 增加了底池基礎（多贏 1bb）
2. BB 投入了更多（有動機 fold）
3. 成功偷盲的回報更大

**SB 偷盲（對 BB 一人）**

在 BBA（100/200）下，SB raise to 500：

```
底池 = 100 + 200 + 200（BBA）= 500
SB raise 500：底池 = 1,000
BB call：底池 = 1,000，SB 總投 500，SPR ≈ 很低（需計算有效籌碼）
```

SB 的每次偷盲成功，淨收益：
- 贏 BB 的 200 + BBA 的 200 = 400 的淨收益（比無 ante 多 200）

## BBA 如何改變 Push/Fold 臨界值

### 為什麼 BBA 讓 push range 更寬

在 BBA 環境下，每次成功 all-in push 讓對手 fold，你贏得的底池更大（多贏了 BBA 的部分）。這使得 push 的 fold equity 收益更高，對應 push range 更寬。

### Push 臨界值對比表（BTN，對抗 SB+BB）

以下為在不同籌碼深度，BBA 環境 vs 無 ante 環境的近似 push range 比較：

| 深度（bb）| 無 Ante BTN push range | BBA BTN push range | 差距 |
|---------|----------------------|-------------------|-----|
| 20bb | ~55% | ~62% | +7% |
| 15bb | ~62% | ~68% | +6% |
| 12bb | ~68% | ~74% | +6% |
| 10bb | ~72% | ~78% | +6% |
| 8bb | ~80% | ~85% | +5% |
| 6bb | ~88% | ~92% | +4% |

**核心規律：BBA 環境的 push range 比無 ante 環境寬約 5-7%**

### CO push range 對比（對抗 BTN/SB/BB）

| 深度（bb）| 無 Ante CO push range | BBA CO push range | 差距 |
|---------|---------------------|-----------------|-----|
| 20bb | ~40% | ~46% | +6% |
| 15bb | ~48% | ~54% | +6% |
| 12bb | ~55% | ~61% | +6% |
| 10bb | ~62% | ~68% | +6% |
| 8bb | ~70% | ~75% | +5% |

### SB push range 對比（僅對抗 BB）

| 深度（bb）| 無 Ante SB push range | BBA SB push range | 差距 |
|---------|---------------------|-----------------|-----|
| 20bb | ~68% | ~75% | +7% |
| 15bb | ~75% | ~81% | +6% |
| 12bb | ~80% | ~86% | +6% |
| 10bb | ~85% | ~90% | +5% |
| 8bb | ~91% | ~95% | +4% |

### 為何 SB 受益最大

SB 在 BBA 環境下的偷盲受益特別大，因為：
1. 只需要對抗一個對手（BB）
2. BB 投入了 BBA（2bb total），BB 的跟注成本相對更高
3. 成功偷盲直接贏回 BB 的 2bb + SB 自己的 0.5bb = 2.5bb 底池

相比無 ante（底池 1.5bb），成功偷盲多贏 1bb，影響顯著。

## BBA 如何影響 BB 的 Defend Range

### BB 的特殊處境

在 BBA 環境下，BB 投入了 2bb（1bb 大盲 + 1bb BBA）。這有兩個含義：

**1. BB 的 pot odds 更有利（底池更大，跟注比例更低）**

面對 BTN open 2.5bb（500）：
- 底池 = 500（包含 BBA）
- BB 已投入 200（大盲）+ 200（BBA）= 400
- BB 跟注需要額外 300（從 400 補到 700）
- Pot odds = 300 / (500 + 300) = 37.5%（相對有利）

若無 ante（底池 300）：
- BB 已投入 200
- BB 跟注需要額外 300
- Pot odds = 300 / (300 + 300) = 50%（相對不利）

**BBA 讓 BB 的跟注 pot odds 從 50% 下降到 37.5%**，BB 的 defend range 因此更寬。

**2. BB 的每圈成本增加（需要更多偷盲成功率才能打平）**

BB 每圈成本 = 2bb（BBA 環境）vs 1bb（無 ante）

這意味著 BB 若只 fold 不參與，每圈都在虧損 2bb。BB 有更強的動機積極防守。

### BB Defend Range 的 BBA 調整

面對不同位置 open（2.5bb，BBA 環境 100/200）：

| Open 位置 | 底池 | BB 跟注 pot odds | BB defend range（BBA）| BB defend range（無 ante）|
|----------|-----|----------------|---------------------|------------------------|
| BTN | 500 | 37.5% | ~56% | ~45% |
| CO | 500 | 37.5% | ~48% | ~38% |
| HJ | 500 | 37.5% | ~43% | ~34% |
| UTG | 500 | 37.5% | ~38% | ~30% |

BBA 讓 BB 在每個位置的 defend range 普遍擴大 8-11%。

## BBA 對翻牌後底池大小和 SPR 的影響

### 翻牌後底池基礎

以 100/200 BBA 為例：

**情境 1：CO open 2.5bb（500），BB call**
- 翻牌後底池 = 500（BBA 底池）+ 500（CO）+ 300（BB 補足）= 1,300？

不對。讓我們重新計算：

```
底池開始 = 500（SB 100 + BB 大盲 200 + BBA 200）
CO open 500（2.5bb）
BB call 500（補足 300，因 BB 已投入 200）
SB fold（SB 的 100 留在底池）

翻牌後底池 = 500（底池基礎）+ 300（BB 補足）+ 500（CO open）- 200（BB 大盲已計）
= 正確計算：SB 100 + BB 大盲 200 + BBA 200 + BB 補 300 + CO 500
= 100 + 200 + 200 + 300 + 500 = 1,300
```

若無 ante：SB 100 + BB 200 + BB 補 300 + CO 500 = 1,100

**BBA 讓翻牌後底池增大了 200（約 18% 的增幅）**

### SPR 的影響

SPR（Stack-to-Pot Ratio）= 有效籌碼 ÷ 翻牌後底池

假設有效籌碼 10,000（50bb）：

| 環境 | 翻牌後底池 | SPR |
|-----|----------|-----|
| 無 ante | 1,100 | 9.1 |
| BBA | 1,300 | 7.7 |

BBA 讓 SPR 降低，意味著：
- 翻牌後「相對承諾」更高
- 更適合用大尺寸下注（底池比例更大）
- Suited connector 和 set mining 的隱含賠率稍微降低（底池已經更大，後手能贏的額外籌碼相對少）

### 3-bet pot 的 SPR 影響

**情境：CO open 2.5bb，BTN 3-bet 7.5bb，CO call**

BBA 環境（100/200）：
```
底池 = 500（基礎）+ 1,500（BTN）+ 1,000（CO 補足，從 500 到 1,500）
= 500 + 1,500 + 1,000 = 3,000
```

無 ante（100/200）：
```
底池 = 300（基礎）+ 1,500（BTN）+ 1,000（CO 補足）
= 2,800
```

BBA 讓 3-bet pot 的翻牌後底池增加 200，SPR 進一步降低。在 3-bet pot 中的承諾閾值更低。

## Antes 在線上 MTT 的啟動時機

### 標準啟動時機

現代線上 MTT 的 antes（BBA 形式）通常在以下時機啟動：

| 賽制類型 | Antes 啟動時機 | 說明 |
|---------|-------------|-----|
| Regular MTT（15分/level）| Level 3-4 | 約遊戲開始 30-60 分鐘後 |
| Turbo MTT（8分/level）| Level 3-5 | 約 24-40 分鐘後 |
| Hyper-Turbo（5分/level）| Level 2-3 | 約 10-15 分鐘後 |
| Deep Stack（20-30分/level）| Level 4-6 | 約 80-120 分鐘後 |
| GGPoker 標準格式 | Level 3 | 從 Level 3 開始 BBA |
| PokerStars 標準格式 | Level 4 | 從 Level 4 開始 BBA |

**重要：一旦 antes 啟動，就永遠保持啟動狀態。比賽後段的所有計算都在 BBA 環境下進行。**

### Antes 啟動前後的策略轉換

**Antes 啟動前（Level 1-2/3，視賽制而定）：**
- 底池 = 1.5bb（只有 SB + BB）
- 偷盲收益較低，open 應該更謹慎
- 不需要過度激進，等待好牌建立優勢

**Antes 啟動後（BBA 開始）：**
- 底池 = 2.5bb，每次偷盲多贏 1bb
- 應立即調整為更積極的偷盲和 resteal 策略
- BTN 和 CO 的 open 頻率應顯著提高
- SB 的 steal 也更有利可圖

**策略切換點：** 當 antes（BBA）啟動時，你的翻牌前積極性應該明顯提升。很多玩家在 antes 啟動後仍然維持同樣的保守 open 頻率，這是重大 EV 損失。

## 常見誤區：用「無 ante」的方式計算 BBA 環境

### 誤區 1：低估底池大小

**錯誤想法：** 「100/200 的底池是 300（SB + BB），所以 open 2bb 是 400，底池變 700。」

**正確計算：** BBA 環境底池是 500，open 2bb（400）後底池 900（500 底池 + 400 open - 200 BB 已投入，但 BB 需補 200 = 底池 900）。

等等，讓我們更仔細計算：

```
底池開始：SB 100 + BB 200 + BBA 200 = 500
open 2bb = 400（相對 BB 大小的 2倍 = 400）
BB fold，SB fold

贏得底池 = 500
```

關鍵：贏得的是 500，不是 300。

### 誤區 2：低估 push/fold 的 fold equity 收益

**錯誤計算：** 「我 push 15bb，對手 fold 我只贏 SB + BB = 1.5bb，不值得。」

**正確計算：** BBA 環境下，fold 收益 = 2.5bb（SB + BB + BBA）。這使得 push 的 fold equity 更高，臨界值更低，push range 更寬。

### 誤區 3：低估每圈的「盲注成本」

**錯誤想法：** 「我每圈的成本是 1bb（BB 位）或 0.5bb（SB 位）。」

**正確計算：** 在 BBA 環境下：
- BB 每圈成本 = 1bb + 1bb（BBA）= 2bb
- SB 每圈成本 = 0.5bb（不變）
- 其他位置 = 0（不付 ante）

這改變了「每圈成本」的分析，以及什麼時候籌碼快要耗盡的時間線計算。

### 誤區 4：用舊的 GTO 軟體設定計算 BBA 手牌

很多舊版 GTO 工具預設「無 ante」或「傳統 antes（每人 10%BB）」。如果你用這些工具分析手牌，必須手動設定正確的 antes 結構，否則所有 range 建議和 EV 計算都會有偏差。

**解決方案：** 在任何 solver 或分析工具中，確認設定為 BBA 模式（Big Blind Ante = 1bb）。

### 誤區 5：忽略 BBA 啟動時的策略轉換

很多玩家在 antes 啟動後繼續用相同的 open 頻率和 steal 頻率，沒有意識到底池已經增大 67%（從 1.5bb 到 2.5bb）。

**正確做法：** Antes 啟動後立即提高 BTN/CO/SB 的偷盲頻率，並擴大 push range。

## BBA 的詳細 EV 計算案例

### 案例 1：BTN steal EV 計算（BBA 環境）

**設定：**
- 盲注：100/200 BBA
- BTN 籌碼：5,000（25bb）
- SB fold 率：80%
- BB fold 率：70%
- 兩人都 fold 率 = 80% × 70% = 56%

**BBA 環境：**
```
底池基礎 = 500
BTN open 2.5bb（500）
期望值 = 56% × 500 + 44% × EV_postflop
```

假設翻牌後 EV（有位置，適當手牌）= +100（保守估計）：
```
EV = 56% × 500 + 44% × 100 = 280 + 44 = +324
```

**無 ante 環境（假設其他條件不變）：**
```
底池基礎 = 300
EV = 56% × 300 + 44% × 100 = 168 + 44 = +212
```

**BBA 讓這次 steal 的 EV 從 +212 提升到 +324，增加 53%。**

### 案例 2：SB push/fold 計算（BBA 環境）

**設定：**
- 盲注：100/200 BBA
- SB 籌碼：1,500（7.5bb）
- BB call 率：40%（面對 SB push）
- SB 手牌勝率（被 call 後）：40%

**BBA 環境（底池 500 = 2.5bb）：**
```
Push EV = 60% × 500 + 40% × [40% × 3,000 + 60% × 0]
= 60% × 500 + 40% × 1,200
= 300 + 480 = +780

Wait/Fold EV ≈ 0（假設下一手繼續計算）
```

實際上還要扣除已投入的 SB = 100，但這已計入底池。

```
淨 Push EV 相對於 fold = +780 - 100（SB 投入）= +680
```

**無 ante（底池 300 = 1.5bb）：**
```
Push EV = 60% × 300 + 40% × 2,600
= 180 + 1,040 = +1,220
```

注意：無 ante 時被 call 的底池也不同（2 × 1,500 = 3,000 vs. 1,500 + 1,500 + 100 + 200 = 3,300 in BBA）。

BBA 環境被 call 的底池包含了 BBA（200），因此實際略大。

### 案例 3：BB 的 defend range 計算（BBA 環境）

**設定：**
- 盲注：100/200 BBA
- CO open 2.5bb（500）
- BB 決策

BB 已投入：200（大盲）+ 200（BBA）= 400
BB 跟注需補：500 - 200 = 300（BB 只需補差額，因 BB 的大盲 200 已算入底池）

等等，更精確的計算：
BB 已在底池中投入 200（大盲）。BBA 的 200 也是 BB 投入的。
CO open 500 → BB 要跟注需要補足到 500，即補 300。

底池（call 後）= SB 100（fold）+ BB 大盲 200 + BBA 200 + CO 500 + BB 補 300 = 1,300
BB 跟注需 300，獲得 1,300 的底池。

```
Pot odds = 300 / 1,300 = 23%（即 BB 只需要 23% 的勝率就有正 EV）
```

這是 BB defend range 極寬的原因（BBA 讓 pot odds 更好）。

## 實戰調整清單：BBA 環境下的行動準則

### 翻牌前調整

- [ ] **確認 antes 是否已啟動：** 每當進入新賽局或盲注升級時，確認目前 BBA 狀態
- [ ] **BTN/CO 提高 steal 頻率：** Antes 啟動後，BTN open 頻率從約 40% 提升至 50%+
- [ ] **SB 積極利用偷盲機會：** SB 單挑 BB 的 steal 收益顯著提高（多贏 BBA 部分）
- [ ] **BB 寬 defend：** 因 pot odds 更佳，BB 應防守更多手牌
- [ ] **push range 擴大：** BBA 環境下所有位置的 push range 比無 ante 環境寬 5-7%
- [ ] **open 尺寸維持 2-2.5bb：** BBA 已增大底池，不需要開大來創造底池

### 翻牌後調整

- [ ] **底池更大，下注尺寸相應調整：** 翻牌後底池比無 ante 大，同比例下注的實際籌碼更多
- [ ] **SPR 更低，承諾門檻更低：** 強牌更容易達到 all-in（SPR 降低讓承諾更早觸發）
- [ ] **bluff sizing 可以更積極：** 更大的翻牌後底池意味著半底池下注也是較大的絕對金額，bluff 效率更高

### ICM 調整

- [ ] **底池 EV 計算包含 BBA：** 在 ICM 計算中，底池大小要用 BBA 環境的數字（2.5bb 基礎，不是 1.5bb）
- [ ] **bubble 時更積極偷盲（大疊）：** BBA 讓成功偷盲的收益更高，大疊的施壓更有回報
- [ ] **短疊 push 更有利：** BBA 增加了每次成功 fold 的收益，短疊的 push range 應該更寬

### 常見數字快速記憶

```
BBA 環境底池基礎 = 2.5bb（而非 1.5bb）
成功偷盲額外收益 = +1bb（相比無 ante）
BB 每圈成本 = 2bb（大盲 + BBA）
break-even fold 率（2.5bb open）= 50%（而非無 ante 的 62.5%）
push range 調整 = +5-7% 更寬
BB defend range = +8-11% 更寬
```
