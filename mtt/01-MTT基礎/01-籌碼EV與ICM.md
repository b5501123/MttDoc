# 籌碼EV與ICM：MTT最核心的思維切換

## 為什麼這是 MTT 最重要的概念

Cash Game 目標：贏最多籌碼。
MTT 目標：贏最多**獎金**，不是籌碼。

大多數情況下方向一致，但在關鍵時刻**完全相反**。

理解這個切換，是從 Cash 玩家升級為 MTT 玩家的第一步。

**本章的所有計算預設 Big Blind Ante（BBA）環境。** 在現代線上 MTT 中，每手的翻牌前底池基礎 = SB（0.5bb）+ BB（1bb）+ BBA（1bb）= 2.5bb。這個數字貫穿所有 EV 計算，請將它設為你的預設。

---

## Chip EV

Chip EV = 純粹計算籌碼得失的期望值。

**範例（BBA 環境，100/200 BBA）：**
你有 10,000 籌碼（50bb），對手 all-in 10,000，你勝率 60%。
翻牌前底池 = 100 + 200 + 200（BBA）= 500，雙方各已投入部分籌碼。

假設在翻牌後發生 all-in（底池已有若干籌碼）：

```
Chip EV = 60% × 20,500 + 40% × 0 ≈ 12,300
（20,500 = 雙方各 10,000 + 底池中的 BBA 等費用）
淨 Chip EV = +約 2,300 chips → 正 EV
```

Cash Game 永遠按 Chip EV 決策。

---

## ICM（Independent Chip Model）

ICM = 把籌碼換算成**獎金價值**。

核心結論：**籌碼不是線性的。**

| 籌碼量 | Chip EV 增加 | 實際獎金增加 |
|--------|-------------|-------------|
| 10,000 → 20,000（翻倍）| +100% | +約 60-70% |
| 50,000 → 60,000（+20%）| +20% | +約 12-15% |

籌碼越多，每增加一顆籌碼的獎金邊際價值越低。

ICM 的計算基礎是：每個玩家贏得某名次的機率，與其籌碼量佔總籌碼的比例相關。這造成了一個根本性的非對稱：贏得籌碼帶來的獎金增加，永遠小於失去同量籌碼的獎金損失。

---

## 最直觀的例子（BBA 底池環境）

**場景：** 3人剩 2人拿錢，獎金 1st $600 / 2nd $400 / 3rd $0

你有 50,000 籌碼，短疊有 10,000，第三人有 40,000。
總籌碼 = 100,000。
盲注 500/1,000 BBA，翻牌前底池 = 500 + 1,000 + 1,000 = 2,500。

短疊在 BB 位（已投入 1,000 大盲 + 1,000 BBA = 2,000）對你 all-in，你勝率 60%。

**Chip EV 說：call**（正 EV）

**ICM 計算：**
- 你現在的 ICM equity（現有籌碼的獎金價值）≈ $333
- 贏了（60%）：60,000 籌碼 → ICM equity ≈ $440
- 輸了（40%）：40,000 籌碼 → ICM equity ≈ $290

```
Call EV = 60% × $440 + 40% × $290 = $264 + $116 = $380
Fold EV ≈ $333（維持現有 ICM equity）
```

即使 60% 勝率，**fold 更好**。

這就是 ICM 壓力的核心：輸的代價（掉 10,000 籌碼）在獎金上的損失，遠大於贏的收益。BBA 讓底池稍大，但 ICM 的非對稱性仍然主導決策。

## BBA 環境下的 EV 計算標準

在所有翻牌前 EV 計算中，底池基礎 = 2.5bb。

**偷盲 EV 範例（BTN，BBA 100/200）：**

設定：BTN 籌碼 = 5,000（25bb），open 2.5bb（500），SB/BB fold 率 = 56%（各自 fold 率之積）。

```
底池基礎 = 100 + 200 + 200（BBA）= 500
BTN open 500（2.5bb）
成功 steal：贏得 500
EV = 56% × (+500) + 44% × EV_postflop
   = 280 + 44% × EV_postflop
```

翻牌後 EV 假設 +100（有位置，合理估計）：
```
總 EV = 280 + 44 = +324
```

若是舊式無 ante 環境（底池 300）：
```
EV = 56% × 300 + 44% × 100 = 168 + 44 = +212
```

**BBA 讓這次 BTN steal 的 EV 提升了 53%（從 +212 到 +324）。**

## 何時用 Chip EV，何時用 ICM

| 情境 | 模型 | 原因 |
|------|------|------|
| 早期深疊，遠離 money | Chip EV | ICM 影響微小 |
| 中期，接近 bubble 前 2-3 桌 | 開始考慮 ICM | 泡沫壓力開始 |
| Bubble | 重 ICM | 出局代價極高 |
| Final Table | 全 ICM | 每名次獎金差距巨大 |
| 短疊 push/fold | Nash ICM | 特殊計算 |

**線上 MTT 特別說明：**
線上大型 MTT 通常有 500-5,000 人報名，早期距離 money 非常遠（前 15-20% 進錢）。一個 1,000 人的 MTT，前 150 名進錢，你在前 300 人的時候，距離 bubble 仍有 150 人要淘汰。此時完全打 Chip EV，不需要考慮 ICM。很多玩家因為「是錦標賽」而在早期打得過度保守，是很大的 EV 損失。

BBA 啟動後（通常 Level 3-5），偷盲的 Chip EV 顯著提升，這是進一步積極積累籌碼的訊號。

---

## ICM 的非對稱性

不同籌碼量的玩家，受 ICM 的影響完全不同：

**大疊玩家：**
- ICM 壓力相對小
- 輸一場 all-in 不會出局，只是籌碼減少
- 可以更積極地對中疊施壓
- 對短疊有更大的打擊能力
- BBA 環境下大疊偷盲每次多贏 1bb，施壓效益更高

**中疊玩家（最難打）：**
- ICM 壓力最大
- 跟注 all-in 可能嚴重損害籌碼量
- 不能像大疊那樣輕鬆承擔風險
- 需要非常精確的 push/call 邊界判斷
- BBA 讓底池稍大，意味著部分邊緣跟注場景的 pot odds 改善

**短疊玩家：**
- ICM 壓力反而降低
- 快出局了，保守策略已沒有意義
- 打 Nash 均衡最優
- BBA 環境下 push range 應比無 ante 更寬（fold equity 收益更高）

## ICM 底池 EV 計算（BBA 版本）

在 ICM 分析中，底池大小直接影響 push/fold 的 EV 計算。

**範例：bubble 場景（BBA 1,000/2,000 BBA）**

底池基礎 = 1,000 + 2,000 + 2,000（BBA）= 5,000

短疊玩家（10,000，即 5bb）在 BTN 位考慮 push all-in：

```
Push 成功（全部 fold）：贏得底池 5,000
Push 失敗（被 call）：進入攤牌
```

**BBA 環境下 push 成功的收益 = 5,000（2.5bb）**

若無 ante，push 成功收益 = 3,000（1.5bb）

這個差距使得在 BBA 環境下，短疊的 push ICM EV 更高，push range 更寬。

---

## ICM 壓力的實際感受

以下是一個 bubble 場景的心理框架：

你在 bubble，有 30bb，是全桌中等籌碼。大疊在你左邊。盲注為 500/1,000 BBA，底池基礎 2,500。

- 你 open，大疊 3-bet
- Chip EV 可能說 call
- ICM 說：**fold**，因為你輸了直接接近短疊，而贏了也不能大幅改善獎金 equity

BBA 底池讓 3-bet 後的底池更大，承諾門檻更低，這實際上讓 ICM fold 的壓力更強——因為一旦跟注 3-bet，後續的投入量更大，風險更高。

這種「寧願錯過正 EV，也要保住生存資本」的思維，是 ICM 的精髓。

## 常見錯誤

**錯誤 1：早期打太保守**
早期 100bb+，無 ICM 壓力，很多玩家因為「是錦標賽」打太緊，放棄大量 EV。線上 MTT 早期應該和 Cash Game 一樣積極地積累籌碼。BBA 啟動後積極性應進一步提升。

**錯誤 2：Bubble 打太激進**
「我 60% 勝率當然跟注」→ Chip EV 思維，完全忘記 ICM。60% 勝率在 bubble 往往是 fold。

**錯誤 3：忽略對手的 ICM 壓力**
你是大疊，對手中疊在 bubble → 他的 ICM 壓力比你大得多。你可以更積極地偷盲、3-bet 他，因為他無法輕易回應而不承擔巨大 ICM 風險。BBA 讓你的大疊偷盲每次多贏 1bb，施壓成本效益更高。

**錯誤 4：短疊打太保守**
5bb 的玩家繼續 fold 等好牌 → ICM 壓力已很低，此時積極 push 才對。BBA 讓 push 的 fold equity 更高，更應該積極。

**錯誤 5：用無 ante 的底池計算 BBA 場景**
「這個 BTN steal 只贏 1.5bb，值得嗎？」→ BBA 環境下是贏 2.5bb，差距巨大。所有計算都必須用 2.5bb 作為底池基礎。

## ICM 工具

現代線上 MTT 玩家應該熟悉以下工具：

- **ICMIZER**：手牌 ICM 分析，輸入籌碼分佈和手牌，給出 push/fold 建議。確保設定 BBA 格式。
- **HRC（Hold'em Resources Calculator）**：全面的 push/fold + ICM 計算工具，9-max 支援完整。支援 BBA 設定。
- **GTO Wizard MTT mode**：翻牌前和翻牌後 MTT ICM 解。預設使用 BBA 結構。
- **PokerStrategy Equilab**：基礎 equity 計算

**重要：** 使用任何計算工具時，確認 antes 設定為 BBA（BB ante = 1bb），而非「無 ante」或「傳統 antes（每人）」。設定錯誤會使所有計算結果都有偏差。

---

## 總結

```
MTT 獲利 = 早期積累籌碼（Chip EV）+ 後期保護籌碼（ICM）
```

兩者缺一不可。只會 ICM 的玩家在早期輸掉太多 EV；只會 Chip EV 的玩家在後期做出 ICM 自殺的決定。

掌握什麼時候切換，是 MTT 技術的核心。

**記住 BBA 底池基礎 = 2.5bb。這個數字影響所有偷盲 EV、push/fold 邊界、以及 ICM 計算。**
