# 位置重要性：9-max MTT 的位置全解析

## 9-max 位置圖

```
           BTN（按鈕）
          /            \
     SB（小盲）         CO（切牌）
        |                  |
     BB（大盲）           HJ（劫持）
        |                  |
     UTG（槍口）          LJ（Lojack）
          \            /
           UTG+1/UTG+2
```

9-max 標準桌的完整位置（由早到晚）：

**UTG → UTG+1 → UTG+2 → LJ → HJ → CO → BTN → SB → BB**

**翻牌前行動順序：**
UTG 最早，BB 最後（有選擇 check、raise、fold 的優勢）。

**翻牌後行動順序（固定，不隨翻牌前結束者改變）：**
SB 最早行動 → BB → UTG → ... → BTN 最後行動

BTN 翻牌後**永遠最後行動**，是位置優勢最大的席位。

---

## 各位置特性與策略

### BTN（Button）— 最強位置

- 翻牌後對所有對手都有位置（永遠最後行動）
- 翻牌前只需面對 SB/BB 的反應
- 兩個 blind 的 defend 範圍再寬，仍有大量 fold
- Open range 最寬（約 42-52%，有 antes 更寬）
- Push/fold range 最寬
- 是最適合 bluff 和薄 value 的位置

實戰重點：BTN 是你最應該積極利用的位置。每次輪到 BTN 都應確保有足夠的 open 頻率，不要因為沒有「好牌」就 fold 掉本質上有 EV 的偷盲機會。

### CO（Cutoff）— 第二強

- 翻牌後對 SB/BB 有位置，但對 BTN OOP
- 需要注意 BTN 可能 3-bet（BTN 的 3-bet range 很寬）
- 面對 BTN 的冷叫也會壓縮後手空間
- Open range 約 28-34%

### HJ（Hijack）

- BTN、CO 都在後面，有兩人可以 3-bet
- Open range 約 22-26%
- 仍有偷盲機會，但需要更強的手牌基礎

### LJ（Lojack / MP2）

- 四個人在後面（HJ、CO、BTN、SB/BB 的 3-bet）
- Open range 約 18-22%
- 手牌品質要求開始提升

### UTG+2（MP1）

- 五個人在後面
- Open range 約 15-18%

### UTG+1

- 六個人在後面
- Open range 約 13-16%

### UTG（Under the Gun）— 最弱翻牌前位置

- 七個人在後面，任何人都可以 3-bet
- 只打頂端強牌（大對子、AK、AQs 等）
- 較後位置的邊緣手牌（如 KQo、JTs）在 UTG 通常 fold
- Open range 約 12-15%

重要：UTG open 傳遞了很強的 range 訊號。這在翻牌後也有影響——你的 c-bet 和 bet 代表更緊的 range，對手會給予更多 credit。

### SB（Small Blind）

- 翻牌前最後行動（有偷盲機會，可以 raise 所有 fold 進入的底池）
- 翻牌後**第一個行動**（對所有人 OOP）
- SB 是最難打的位置之一：翻牌前有優勢，翻牌後是劣勢
- 策略：**Raise or Fold**，幾乎不 limp（limp 有時可以作為平衡，但 raise/fold 是標準）
- 面對 BB 時，SB 的 raise range 比其他位置更寬（因為只剩一個人）

### BB（Big Blind）

- 翻牌前最後行動（可以 defend 任何人的 open，也可以 3-bet）
- 翻牌後對所有人 OOP
- 已投入 1bb，defend range 最寬（更好的 pot odds）
- 是唯一對所有對手都 OOP 的位置（除非在多人底池某特殊情況）

## IP vs OOP 的影響

**IP（In Position，有位置）的優勢：**
- 看到對手行動後再決定，擁有更多資訊
- 控制底池大小（check behind 縮小底池，bet 放大底池）
- 更多 bluff 機會（對手 check，你可以 bet 取底池）
- 在 showdown 前可以更晚 commit，避免過度投入弱牌

**OOP（Out of Position，無位置）的劣勢：**
- 必須先行動，缺少資訊，容易做出非最優選擇
- 被迫 check（有時不能 bet）給對手免費的 equity realization
- Check-raise 是 OOP 最主要的主動武器，但使用受限

IP vs OOP 的優勢差距：研究顯示，同樣的手牌，IP 的 EV 通常比 OOP 高 15-25%。這解釋了為什麼位置這麼重要，以及為什麼 BTN steal 的 EV 如此之高。

## 各位置 Push Range 速覽（9-max，10bb 深度）

| 位置 | Push Range（近似） | 代表性手牌下限 |
|------|-------------------|-------------|
| UTG | ~28% | K9o, Q9s, J9s |
| UTG+1 | ~30% | K8o, Q9o, T9s |
| UTG+2 | ~31% | K8o, Q8s, J9o |
| LJ | ~34% | K7o, Q8s, J8s |
| HJ | ~42% | K4o, Q5o, J7s |
| CO | ~52% | K2o, Q2s, T7s |
| BTN | ~65% | 94o, 82s, 63s |
| SB | ~68% | 94o, 83s, 62s |

**規律：後面需要過的人越少 → push range 越寬**

注意：BB 沒有 push range，因為 BB 是跟注者（所有人都 fold 時，BB 拿回 BB 不需要 push）。BB 的決策是 call range（面對各位置的 shove）。

## 線上 vs 現場的位置影響

**線上環境：**
- 玩家普遍依位置機械地 open/fold，位置信號更明確
- 弱玩家對「被偷盲」的反應更被動，BTN 和 CO 的 steal 成功率高
- HUD 可以追蹤每個對手在每個位置的 open 頻率（如 UTG open 15% vs 25%），幫助判斷手牌範圍
- 多桌情況下，確保在 BTN/CO 不錯過 steal 機會更重要

**現場環境：**
- 位置優勢更多維度：可以觀察對手翻牌前的肢體語言
- 玩家對被偷盲有更強的情緒反應，有時會觸發不理性的 resteal
- 基本位置邏輯完全相同，只是讀人的工具不同

## MTT 中特殊的位置考量

### 短疊的位置效果遞減

當你只有 10bb，位置優勢大幅縮小。BTN 的 10bb push range（65%）和 CO（52%）仍有差距，但和 Cash Game 100bb 的位置差距相比微不足道。位置在深疊時最有價值。

### Bubble 的位置放大效應

在 bubble 附近，BTN 的大疊偷盲效果被放大——不只是因為位置，還因為對手的 ICM 壓力讓他們 fold 更多。大疊 BTN 面對中疊 SB/BB 在 bubble 時，steal 成功率可能高達 80%+。

### 3-bet 的位置考量

IP 的 3-bet range 比 OOP 更寬。BTN 面對 CO open 的 3-bet（IP），可以包含更多 bluff；BB 面對 UTG 的 3-bet（OOP），應該更傾向 value-heavy。
