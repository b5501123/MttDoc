# 個人錯誤分類表

## Preflop

- Open 太寬或太緊。
- Cold call 太多。
- SB 沒有 3bet / fold 結構。
- BB 因價格便宜過度 defend。
- 4bet bluff 對錯對手。

## Flop

- 不看 board texture 就 c-bet。
- 多人底池 bluff 太多。
- OOP 3bet pot 沒有 check range。
- check-raise 沒有 equity 或 blocker。

## Turn

- Flop bluff 後 turn 無計畫硬打。
- 把 showdown value 轉成壞 bluff。
- 沒有計算 SPR 和 river commitment。

## River

- 對 under-bluff pool hero call。
- 對 calling station bluff。
- 錯過 thin value。
- 大底池只看自己牌力，不看對手 value range。

## 心態與流程

- 輸錢後加桌。
- 升級別追損。
- 魚離桌後還留在差桌。
- 疲勞時仍繼續打。

每週只選出現次數最多的兩類錯誤修正。Cash game 的核心不是知道所有答案，而是讓最大漏水點停止漏。
