# 練習題第 6 頁：River value / bluff catch

## Q51

你 BTN KQ，K83r-4-2 三街對 BB，對手 check 到你。

**建議答案：** 可 thin value，尤其對手是 station。KQ 領先大量 Kx。

## Q52

你 BB defend A7，A72-K-9，BTN river pot，你無特殊 read。

**建議答案：** 對 under-bluff pool 可偏 fold。兩對牌面被強 value 壓制，需看 blocker。

## Q53

你 CO AQ，AQTss-4-4，river missed flush，對手 check。

**建議答案：** 可 value bet，但 sizing 不宜過大；能被 weaker Ax / Qx call。

## Q54

你 miss nut flush draw，river 對手是 calling station。

**建議答案：** 少 bluff。對 station missed draw 不該自動開槍。

## Q55

你有 blocker A♠，牌面三黑桃，對手是 reg 且可 fold。

**建議答案：** 可考慮 bluff，前提是你的 line 能代表 nut flush。

## Q56

被動玩家 river check-raise all-in，你只有 top pair。

**建議答案：** 大量 fold。被動 pool 河牌 raise 通常極強。

## Q57

Maniac river overbet，你有 second pair good blocker。

**建議答案：** 可 bluff-catch 頻率提高，但要確認他真的過度 bluff。

## Q58

你 river 有 second pair，對手連三街 check-call 很寬。

**建議答案：** 可小 thin value，尤其他會用 ace-high 或低 pair 跟。

## Q59

你 3bet pot 持 AA，runout K72-8-9，對手 check river。

**建議答案：** 多數 value bet。較差 Kx、QQ/JJ 可能 call。

## Q60

你 bluff river，被對手 tank-call bottom pair。

**建議答案：** 筆記為 station，下次減少 bluff、增加 value。
