# Cash Game 練習方法

Cash game 練習要用「分類」取代「記答案」。一手牌的正確線，會被位置、有效籌碼、rake、玩家類型、下注尺度和牌面紋理同時改變。

## 每題固定問五件事

1. 我在哪個位置？翻牌後是否有位置？
2. Effective stack 是多少？SPR 會落在哪裡？
3. 這是 SRP、3bet pot、4bet pot 還是 multiway？
4. 對手類型是 unknown、reg、nit、station 還是 maniac？
5. 我的行動是為了 value、protection、bluff，還是 realization？

## 錯題分類

- Preflop：open 太寬、cold call 太多、盲位 defend 過寬、3bet 不成結構。
- Flop：c-bet 頻率不看牌面、多人底池 bluff 太多。
- Turn：沒有計畫的 second barrel、把 showdown value 轉成壞 bluff。
- River：under-value、over-bluff、對 under-bluff pool hero call。
- 心態：追輸、加桌、升級別、報復 3bet。

每次 session 後只修一類錯誤。Cash game 的進步來自重複降低最大 leak，而不是每天換一套打法。
