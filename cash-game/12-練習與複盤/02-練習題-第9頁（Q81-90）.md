# 練習題第 9 頁：Deep stack / short stack

## Q81

200BB deep，你 BTN 65s，CO weak player open。

**建議答案：** 可 call。位置、深度、弱玩家 implied odds 支撐。

## Q82

35BB short stack open，你 BTN 44。

**建議答案：** 通常 fold，set mining 條件不足。

## Q83

200BB deep，你持 AA 在 987ss 面對 check-raise。

**建議答案：** 不能自動打光。深碼下 overpair 需降級。

## Q84

50BB effective，你 AQs 3bet 後 flop top pair。

**建議答案：** 更接近承諾，可 value 打大。

## Q85

你 200BB OOP call 3bet with KQo。

**建議答案：** 通常避免。domination 和 reverse implied odds 嚴重。

## Q86

短碼 recreational limp，你 CO AJo。

**建議答案：** 可 isolate value，但面對 limp-jam 要看對手傾向。

## Q87

Deep stack nut flush draw + pair 面對大注。

**建議答案：** 可繼續，尤其有位置；但注意成牌後是否 nut。

## Q88

200BB set mining 面對 tight UTG open。

**建議答案：** 可 call，因對手強 range 更可能付錢，但注意背後 squeeze。

## Q89

Straddle 桌你以為自己 120BB，實際只有 60 straddle BB。

**建議答案：** 用 straddle 重新計算深度，策略要變淺。

## Q90

短碼玩家 3bet jam 30BB，你 AJo。

**建議答案：** 不要自動 call。看位置與 jam range，多數對 tight 短碼可 fold。
