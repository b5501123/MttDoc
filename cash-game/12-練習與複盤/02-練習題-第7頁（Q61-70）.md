# 練習題第 7 頁：多人底池

## Q61

UTG open，兩人 call，你 BTN call 66，Flop K62r。

**建議答案：** 強 value。多人底池 set 應建立底池，不必過度 slowplay。

## Q62

CO open，你 BTN call A5s，BB call，Flop K92 同花你是低同花聽牌。

**建議答案：** 謹慎。非 nut flush draw 多人底池 reverse implied odds 高。

## Q63

你 UTG AK，三人 call，Flop QJ9ss。

**建議答案：** 多數 check。多人濕牌 bluff 成功率低。

## Q64

你 BTN QJ，三人底池 Flop Q84r。

**建議答案：** top pair 要降級，可小 value / check，面對大注謹慎。

## Q65

你 BB 97s 免費看 flop，五人底池 Flop T86r。

**建議答案：** 強順子可直接 value/protection，因多人有 pair+draw。

## Q66

多人底池你拿 bottom two pair，turn 補第三張同花。

**建議答案：** 降速。你的相對牌力下降，非 nut 大底池危險。

## Q67

Limp pot 四人，你拿 AKo miss flop。

**建議答案：** 不要因為 AK 就 bluff。limp pot 多人 fold equity 低。

## Q68

你有 nut flush draw + overcards，多人底池面對小注。

**建議答案：** 可 call 或 raise 視位置與 implied odds；nut draw 比低 draw 好很多。

## Q69

你 set 在 987ss 多人底池被 raise。

**建議答案：** 強但需計算對手能有順子/強 draw。多數可繼續，但 turn 要讀牌。

## Q70

你 top pair good kicker，多人底池 river 被 passive player 大注。

**建議答案：** 偏 fold。passive 玩家多人底池大注 bluff 很少。
