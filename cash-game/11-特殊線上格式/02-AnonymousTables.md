# Anonymous Tables

## 線上桌面設定

Anonymous table 讓你無法累積個人 HUD，降低針對單一玩家的能力。

## 核心觀念

策略要更偏 baseline + population read。即時 showdown 和下注 size 是重要資訊。

Cash game 的第一原則是：每一個決策都直接換算成長期 bb/100 和真實金額。沒有 ICM 可以保護錯誤，也沒有下一個 blind level 會幫你改變策略；你在這一手選擇的 open、call、3bet、下注尺度和河牌跟注，都會被 rake、位置、有效籌碼與對手類型直接校正。

## 決策流程

先避免高風險 exploit，等看見具體行為再調整。例如 river 從不 bluff、flop call 太寬、preflop limp/call。

線上多桌時不要追求每一手都算到最細。你需要先建立 default，再依對手偏差調整：對手太緊就多偷、多小注；對手太愛跟就少 bluff、多 thin value；對手河牌下注不足就大幅降低 bluff-catch。這比背一張靜態表更接近可執行策略。

## 線上調整

Anonymous 也會降低對手對你的針對，所以簡潔穩定的 value strategy 很有效。

## 常見錯誤

沒有名字就完全不觀察；或把同桌不同玩家混成同一個 read。

## 練習

每桌記三種行為：open size、showdown 弱牌、river 大注牌型。
