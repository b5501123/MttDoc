# River Value Bet、Thin Value 與 Bluff Ratio

## 線上桌面設定

River 沒有未來 equity，下注只剩 value 或 bluff。線上低 stakes 最大獲利常來自 thin value，而不是華麗 bluff。

## 核心觀念

Value bet 的問題是：多少較差牌會 call？Bluff 的問題是：多少較好牌會 fold？若兩個答案都不清楚，下注通常只是情緒。

Cash game 的第一原則是：每一個決策都直接換算成長期 bb/100 和真實金額。沒有 ICM 可以保護錯誤，也沒有下一個 blind level 會幫你改變策略；你在這一手選擇的 open、call、3bet、下注尺度和河牌跟注，都會被 rake、位置、有效籌碼與對手類型直接校正。

## 決策流程

River 先列出對手到河牌的 range，再把你的牌放進 value、showdown、bluff catcher、missed draw。不要只看絕對牌力。

線上多桌時不要追求每一手都算到最細。你需要先建立 default，再依對手偏差調整：對手太緊就多偷、多小注；對手太愛跟就少 bluff、多 thin value；對手河牌下注不足就大幅降低 bluff-catch。這比背一張靜態表更接近可執行策略。

## 線上調整

對 under-bluff pool，面對大 river bet 可大幅 overfold；對 calling station，少 bluff、多薄價值。

## 常見錯誤

怕被 check-raise 而錯過 value；或因為 draw miss 就用任何 blocker 亂 bluff。

## 練習

找 5 手你 river check back 的牌，問自己是否錯過 thin value。
