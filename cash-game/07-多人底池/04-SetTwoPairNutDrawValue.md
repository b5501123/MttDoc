# Set、Two Pair、Nut Draw 的 Value 下注

## 線上桌面設定

多人底池最值得打大的牌通常是 set、強 two pair、nut straight、nut flush draw combo。

## 核心觀念

強牌需要建立底池並保護 equity，但也要看牌面是否讓更強組合存在。例如 bottom set 在單色連接面不是無敵。

Cash game 的第一原則是：每一個決策都直接換算成長期 bb/100 和真實金額。沒有 ICM 可以保護錯誤，也沒有下一個 blind level 會幫你改變策略；你在這一手選擇的 open、call、3bet、下注尺度和河牌跟注，都會被 rake、位置、有效籌碼與對手類型直接校正。

## 決策流程

Value 下注先想目標：讓 top pair、pair+draw、lower draw 付錢。Size 可比 heads-up 更直接，因弱玩家常願意跟。

線上多桌時不要追求每一手都算到最細。你需要先建立 default，再依對手偏差調整：對手太緊就多偷、多小注；對手太愛跟就少 bluff、多 thin value；對手河牌下注不足就大幅降低 bluff-catch。這比背一張靜態表更接近可執行策略。

## 線上調整

低 stakes 多人底池對強牌應少 slowplay。你讓免費牌，常是在給多個玩家實現 equity。

## 常見錯誤

拿 set 永遠 slowplay；或非 nut two pair 在危險 turn 仍不降級。

## 練習

找三手你 flop 很強卻 check 的牌，判斷是否錯過 value/protection。
