# Deep Stack 下 Suited Connector、Small Pair、Axs

## 線上桌面設定

深碼會提高 suited connector、小對、Axs 的 implied odds，但也提高輸大底池的風險。

## 核心觀念

深碼可玩牌不等於垃圾牌。好投機牌需要位置、nut potential、可隱蔽成牌，以及對手會付錢。

Cash game 的第一原則是：每一個決策都直接換算成長期 bb/100 和真實金額。沒有 ICM 可以保護錯誤，也沒有下一個 blind level 會幫你改變策略；你在這一手選擇的 open、call、3bet、下注尺度和河牌跟注，都會被 rake、位置、有效籌碼與對手類型直接校正。

## 決策流程

在 BTN vs fish deep 時可放寬；在 SB OOP vs reg deep 時要收緊。Axs 比低 suited gapper 更好，因有 nut flush。

線上多桌時不要追求每一手都算到最細。你需要先建立 default，再依對手偏差調整：對手太緊就多偷、多小注；對手太愛跟就少 bluff、多 thin value；對手河牌下注不足就大幅降低 bluff-catch。這比背一張靜態表更接近可執行策略。

## 線上調整

線上 deep stack 對 regular 時，非 nut draw 和 weak two pair 容易輸大。要避免 OOP 打膨脹底池。

## 常見錯誤

只因 200BB 就跟所有 suited；或小對在對手短碼時仍 set mine。
