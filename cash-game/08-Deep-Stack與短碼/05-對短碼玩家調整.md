# 對短碼玩家的調整

## 線上桌面設定

短碼玩家讓 implied odds 下降，且 preflop / flop 更容易承諾。你不能用深碼策略跟投機牌。

## 核心觀念

面對 30-50BB 對手，suited connector、小對和弱 Axs 價值下降；高牌、強 broadway、可直接打 value 的牌上升。

Cash game 的第一原則是：每一個決策都直接換算成長期 bb/100 和真實金額。沒有 ICM 可以保護錯誤，也沒有下一個 blind level 會幫你改變策略；你在這一手選擇的 open、call、3bet、下注尺度和河牌跟注，都會被 rake、位置、有效籌碼與對手類型直接校正。

## 決策流程

先看短碼是否會 limp/call、open/fold 或 3bet jam。對 jam 多者收緊 open/call；對 limp/call 多者 value isolate。

線上多桌時不要追求每一手都算到最細。你需要先建立 default，再依對手偏差調整：對手太緊就多偷、多小注；對手太愛跟就少 bluff、多 thin value；對手河牌下注不足就大幅降低 bluff-catch。這比背一張靜態表更接近可執行策略。

## 線上調整

線上短碼常有 recreational player，也有短碼策略玩家。先觀察，不要自動假設魚。

## 常見錯誤

拿 76s、33 去跟 35BB open；或用深碼 implied odds 合理化 call。

## 練習

記錄三個短碼對手，看他們是 limp/call 型、jam 型還是 tight 型。
