# Set Mining 的真實條件

## 線上桌面設定

小對跟注 open 的主要價值是中 set 贏大底池，但條件是對手和自己都有足夠深度，且對手會付錢。

## 核心觀念

你大約 12% flop 中 set。若有效籌碼太短、對手 range 太弱或你 OOP，set mining 可能負 EV。

Cash game 的第一原則是：每一個決策都直接換算成長期 bb/100 和真實金額。沒有 ICM 可以保護錯誤，也沒有下一個 blind level 會幫你改變策略；你在這一手選擇的 open、call、3bet、下注尺度和河牌跟注，都會被 rake、位置、有效籌碼與對手類型直接校正。

## 決策流程

跟小對前檢查：effective stack 是否至少 80-100BB？對手是否有強 range 會付錢？背後 squeeze 風險高嗎？rake 是否高？

線上多桌時不要追求每一手都算到最細。你需要先建立 default，再依對手偏差調整：對手太緊就多偷、多小注；對手太愛跟就少 bluff、多 thin value；對手河牌下注不足就大幅降低 bluff-catch。這比背一張靜態表更接近可執行策略。

## 線上調整

在 BTN vs UTG deep 可考慮；在 SB vs CO 高 rake 或背後 BB aggressive 時要少跟。

## 常見錯誤

任何小對都 call；或中 set 後在極危險牌面不懂降速。
