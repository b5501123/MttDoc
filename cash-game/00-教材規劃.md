# 線上 NLH Cash Game 教材規劃

## 定位

這一套教材獨立於 MTT 教材，主軸是線上 NLH cash game。第一版以 6-max、100BB、無限注德州、線上多桌環境為核心，並補充 9-max、50BB、150BB+ deep stack、fast-fold、rake、straddle / ante 桌的調整。

本教材不以 live cash 為主。live 讀人、現場節奏、口頭下注、桌邊心理戰只作為附錄，不放在主線。

## 學員目標

完成教材後，學員應能做到：

- 知道 cash game 和 MTT 的根本差異：籌碼等於現金、沒有 ICM、可重買、可離桌、rake 直接改變 EV。
- 建立 6-max 線上現金桌的 preflop 基礎：open、call、3bet、4bet、blind defense、squeeze。
- 能在 single-raised pot、3bet pot、4bet pot 中判斷 range advantage、nut advantage、SPR 與下注大小。
- 理解 rake 對小底池、冷跟、SB complete、防守頻率與低 stakes 策略的影響。
- 能針對不同玩家類型做 exploit：nit、loose passive、reg、over-bluffer、under-bluffer、短碼玩家。
- 建立多桌與複盤流程：標記手牌、分類錯誤、看數據、建立個人 default strategy。

## 第一版教材規格

- 課程數量：建議 48 篇正文 + 100 題練習。
- 遊戲設定：NLH cash game，6-max 100BB 為預設。
- 盲注設定：線上小盲 / 大盲；如平台有 ante、straddle、bomb pot，獨立章節處理。
- 語氣：直接、實戰、以線上操作與決策樹為主。
- 每篇格式：
  - 核心觀念
  - 線上桌面情境
  - 決策流程
  - 常見錯誤
  - 練習題或複盤問題

## 目錄設計

### 00-目錄與學習路線

1. 現金桌教材使用方式
2. 6-max 100BB 學習路線
3. 從 MTT 轉 cash 的觀念切換
4. 術語與線上桌面設定

### 01-Cash Game 基礎

1. Cash game 和 MTT 的核心差異
2. 籌碼等於現金：EV、bb/100、winrate
3. Rake 如何改變策略
4. Buy-in、auto top-up、stop loss、table selection
5. 線上現金桌常見格式：regular table、fast-fold、anonymous、ante table

重點：

- Cash game 不用 ICM 思考，但更需要長期 EV 與 rake awareness。
- 同一手牌在 MTT 可因籌碼壓力變好，在 cash 只看 chip EV 和實際現金 EV。
- 低 stakes 最大問題不是 GTO 不精準，而是 rake 高、玩家錯誤集中、過度冷跟。

### 02-Preflop 核心框架

1. 6-max 位置與 open range
2. 9-max 的前位收緊與後位偷盲
3. Call、3bet、fold 的 EV 分解
4. 3bet linear range vs polar range
5. 4bet、5bet jam 與 blocker
6. SB / BB 防守邏輯
7. Squeeze 與多人入池前的隔離策略

重點：

- Preflop 不是背表，而是理解位置、rake、後位優勢與對手錯誤。
- 低 rake / 高 rake、100BB / 200BB、reg / fish 都會改變 call 與 3bet 邊界。
- SB 是最容易輸錢的位置，教材要強調少冷跟、多 3bet 或 fold。

### 03-Single-Raised Pot

1. BTN vs BB 的基礎模型
2. CO / HJ / UTG open 後的 range 差異
3. Flop c-bet 頻率與 sizing
4. Board texture：A-high、K-high、paired、connected、monotone
5. Turn barrel：哪些牌繼續打、哪些牌放棄
6. River value bet、thin value、bluff ratio

重點：

- Single-raised pot 是 cash game 最大量的底池類型。
- BTN vs BB 不能套用到所有位置；前位 range 較強，BB 防守範圍也不同。
- River 是低 stakes 最大 EV 來源：少做沒 fold equity 的 bluff，多做 thin value。

### 04-3bet Pot

1. IP 3bet pot：BTN vs CO、BTN vs HJ
2. OOP 3bet pot：SB vs BTN、BB vs BTN
3. SPR 降低後的 top pair、overpair、draw 打法
4. 小 c-bet、大 c-bet、check range
5. 3bet pot turn jam 與 river commitment
6. 3bet pot 的 exploit：對手過度 call、過度 fold、過度 float

重點：

- 3bet pot 的錯誤成本高，不能只靠「我有強牌」下注。
- OOP 3bet pot 需要有清楚的 check strategy，否則會在 turn / river 被打爆。
- 線上玩家常在 3bet pot 對 c-bet fold 太多或 float 太多，需依 pool 調整。

### 05-4bet Pot 與大底池

1. 4bet range 的 value / bluff 結構
2. A blocker、K blocker 的實際用途
3. 100BB 4bet pot 的 SPR
4. AA / KK / AK / QQ 的標準線
5. 4bet pot 中低牌面與高牌面的策略
6. 不該打大的牌：dominated top pair 與弱 kicker

重點：

- 4bet pot 不是靠感覺硬打，因為 SPR 已經逼近承諾。
- AQ、JJ、TT 在不同位置和對手類型下差異很大，不可一律全下。
- 低 stakes 對手 5bet jam 通常偏 value，教材要明確寫 exploit fold 的位置。

### 06-Blind Play

1. SB 的長期虧損控制
2. BB defend：pot odds、rake、realization
3. Blind vs blind：SB limp、raise、3bet
4. BB check-raise 策略
5. 對 BTN steal 的防守
6. 對 loose opener 的 exploit 3bet

重點：

- 盲位不是「保護盲注」，而是控制不可避免的虧損。
- BB 有 pot odds，但 rake 和 OOP realization 會吃掉很多看似可跟的 EV。
- SB complete 在高 rake 環境要非常謹慎。

### 07-多人底池

1. Multiway pot 的 equity realization
2. 為什麼多人底池 c-bet 要大幅降低
3. Top pair 在多人底池的降級
4. Set、two pair、nut draw 的 value 下注
5. 非 nut draw 的風險
6. 對 loose passive 桌子的 exploit

重點：

- 多人底池中 bluff 成本高、fold equity 低。
- Cash game 的低 stakes 常見多人入池，教材要把 value-heavy 策略寫清楚。
- 非 nut 同花和低順子在多人底池不能當成自動打光。

### 08-Deep Stack 與短碼

1. 50BB、100BB、150BB、200BB 策略差異
2. Deep stack 下 suited connector、small pair、Axs 的價值
3. Reverse implied odds
4. Set mining 的真實條件
5. 對短碼玩家的 open / 3bet / call 調整
6. 200BB 大底池的風險控管

重點：

- 深碼不是「可以玩更多爛牌」，而是 implied odds 與 reverse implied odds 同時變大。
- 200BB 下 overpair 不再是自動打光。
- 短碼玩家讓 implied odds 變差，不能用深碼邏輯跟小對或同花連張。

### 09-Rake、Pool Tendencies 與 Exploit

1. Rake 對 preflop call 的影響
2. Micro / low stakes pool 常見傾向
3. Nit、TAG、LAG、fish、maniac 的對策
4. 對 under-bluff pool 的大 fold
5. 對 calling station 的 thin value
6. 對 over-c-bet 玩家 check-raise
7. 對 over-fold 玩家小注偷底

重點：

- 低 stakes 不該盲目追求平衡，先打對 pool 的漏洞。
- 最常見 exploit 是少 bluff catcher、多 value bet。
- 但教材仍要保留 baseline，避免學員只學到偏門打法。

### 10-線上多桌與數據

1. 多桌數量與決策品質
2. Fast-fold 的優缺點
3. HUD 基礎：VPIP、PFR、3bet、fold to c-bet、WTSD、WWSF
4. 無 HUD / anonymous 桌的替代觀察
5. 標記手牌與 session review
6. Tilt、stop loss、game selection

重點：

- Cash game 是大量樣本遊戲，但多桌不能犧牲決策深度。
- HUD 數據必須搭配樣本數，不能用 20 hands 下結論。
- 無 HUD 平台更重視即時筆記與 pool exploit。

### 11-特殊線上格式

1. Fast-fold pool
2. Anonymous tables
3. Ante cash game
4. Straddle tables
5. Bomb pot / splash pot
6. Short deck cash 的差異提示

重點：

- Ante / straddle 會放大底池與位置價值，但不等於所有牌都能入池。
- Fast-fold 對手 preflop 通常更緊，偷盲與 3bet exploit 要調整。
- Anonymous 桌不適合過度針對單一玩家，要偏 pool strategy。

### 12-練習與複盤

1. Cash game 練習方法
2. Preflop 決策題 30 題
3. Flop 決策題 25 題
4. Turn / river 決策題 25 題
5. Exploit 與玩家類型題 20 題
6. Session review 模板
7. 個人錯誤分類表

重點：

- 練習題要用現金桌語境：有效籌碼、rake、位置、對手數據、玩家類型。
- 答案不能只寫「raise / call / fold」，要寫 EV 原因與替代線。
- 複盤模板要讓學員能把錯誤分成 preflop、sizing、range、river、tilt。

## App 打包策略

建議分兩階段：

### 階段 1：獨立 Markdown 教材

- 先完成 `docs/cash-game` 全套 Markdown。
- 不改現有 MTT app。
- 用人工閱讀與 `rg` 檢查標題、章節、亂碼、空檔。

### 階段 2：Cash Game App 或多課程 App

兩種可選方案：

- 獨立 app：複製現有 `docs/course-app` 流程，改成吃 `docs/cash-game`。
- 多課程 app：改 `build-www.mjs`，支援 `mtt`、`cash-game` 多來源與課程切換。

若目標是快速發 TG 測試包，建議先做獨立 cash app，風險最低。等 MTT 與 cash 內容都穩定，再做多課程 app。

## 編寫原則

- 不複製現有 MTT 內容。
- 不把 MTT 的 ICM、BBA、短碼 all-in 模型硬套到 cash。
- 每章都從「線上現金桌」角度寫，不寫成 live 心理戰教材。
- Rake 必須貫穿 preflop、blind defense、multiway、small pot。
- 低 stakes exploit 和 baseline strategy 必須並存。
- 所有例子都要標明位置、有效籌碼、底池、下注尺度與對手類型。

## 後續實作順序

1. 建立完整目錄與 48 篇空白章節。
2. 先寫 `01-Cash Game 基礎`、`02-Preflop 核心框架`、`03-Single-Raised Pot`。
3. 再寫 `04-3bet Pot`、`06-Blind Play`、`09-Rake 與 Exploit`。
4. 補完 deep stack、multiway、特殊線上格式。
5. 最後一次生成 100 題練習與答案解析。
6. 做 app build script 分支：獨立 cash app 或多課程 app。
