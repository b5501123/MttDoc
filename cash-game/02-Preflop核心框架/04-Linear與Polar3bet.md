# Linear 3bet vs Polar 3bet

## 線上桌面設定

Linear 3bet 是用整段強牌和中強牌加注；polar 3bet 則是 value hand 加上 blocker / 可玩性 bluff。

## 核心觀念

面對寬 open 且會 call 3bet 的對手，linear 3bet 較好，因為 AQs、TT、KQs 這類牌領先對手 continuing range。面對 tight open 且 fold 多，polar 更合理。

Cash game 的第一原則是：每一個決策都直接換算成長期 bb/100 和真實金額。沒有 ICM 可以保護錯誤，也沒有下一個 blind level 會幫你改變策略；你在這一手選擇的 open、call、3bet、下注尺度和河牌跟注，都會被 rake、位置、有效籌碼與對手類型直接校正。

## 決策流程

先看位置：SB vs BTN 常偏 linear，因為 OOP 不想 cold call；BTN vs UTG 可更 polar，保留部分中強牌跟注。

線上多桌時不要追求每一手都算到最細。你需要先建立 default，再依對手偏差調整：對手太緊就多偷、多小注；對手太愛跟就少 bluff、多 thin value；對手河牌下注不足就大幅降低 bluff-catch。這比背一張靜態表更接近可執行策略。

## 線上調整

低 stakes 很多玩家 call 3bet 太多，先用 value-heavy linear 懲罰，不要過度拿垃圾 blocker 3bet。

## 常見錯誤

把所有 A5s、K9s 都當自動 3bet bluff；或永遠只用 QQ+ AK 3bet，讓範圍過透明。

## 練習

找一個 BTN vs CO spot，分別寫 linear 和 polar 3bet 的牌型。
