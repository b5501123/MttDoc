# PKO 賞金賽基礎概念

## 什麼是 PKO

**PKO（Progressive Knockout）** = 進階淘汰賽金。

每淘汰一個人，你拿走他賞金的一半，另一半加到你的賞金上。

```
例：
報名費 $100：
- $50 進入獎金池（正常 MTT 獎金）
- $50 成為你的賞金
- 你賞金的 50% 給淘汰你的人，50% 到第一名

淘汰別人時：
你拿走對手賞金的 50%
另外 50% 加到你自己的賞金（讓你更值錢）
```

---

## PKO vs 標準 MTT 的差異

### 標準 MTT
- 目標：獲得最高名次
- ICM = 純粹的獎金池 EV
- 淘汰別人沒有直接 EV（除了積累籌碼）

### PKO
- 目標：獲得名次 EV + **賞金 EV**
- 淘汰別人有立即的獎金收益
- 你的賞金越大，你越「值得」被淘汰（被更積極追殺）

---

## 賞金 EV 的計算

當你和對手 all-in，PKO 的 EV 計算包含：

```
EV(call) = P(win) × [Pot EV + 賞金 EV] + P(lose) × 出局 EV

賞金 EV = 對手賞金的 50%（你淘汰他直接拿走）
```

**影響：** 你願意用更低的 EV 去 call/push，因為有賞金 EV 的加成。

### 數值範例

```
標準 MTT：
你和對手 all-in，你 45% 勝率
Chip EV：負 EV，通常不 call

PKO：
對手賞金 $200
你淘汰他：拿到 $100 即時賞金
加入賞金 EV 後：即使 45% 勝率，call 可能是正 EV
```

---

## PKO 的核心策略調整

### 1. 追殺有大賞金的對手

大賞金的對手 = 你有更高的動機去淘汰他。

**調整：**
- 針對大賞金目標，放寬 push/call range
- 即使數學上邊緣，賞金 EV 可以讓 call 值得

### 2. 你自己的賞金讓你成為目標

你的賞金越大，對手越想淘汰你。

**調整：**
- 對手 call range 比正常更寬（因為你的賞金）
- 你的 push range 要稍微縮緊（被 call 機率更高）

### 3. 短疊 + 大賞金 = 特殊場景

對手是短疊但有大賞金（他積累了很多賞金）：
→ 你 call range 要大幅放寬（賞金 EV 很高）
→ 即使有點劣勢，追殺他也值得

---

## PKO 的 Stack Interaction

### 當你有大量籌碼但賞金很小

你一路積累籌碼，但沒有淘汰很多人：
- 你的賞金仍是起始值（例如 $50）
- 其他人追殺你的動機低

打法：相對正常的 ICM 打法，賞金影響不大。

### 當你有很多賞金（積累了很多 KO）

你淘汰了多個對手，賞金累積到 $200+：
- 每個人都想淘汰你拿賞金
- 你被 call 的機率遠比正常高

打法：
- 縮緊 bluff push（對手更願意 call）
- Value push 仍然正常（因為賞金讓你值得 call，value 也增加）

---

## PKO 翻牌前調整公式

### 簡化版賞金 EV 加成

```
有效賞金 EV = 對手賞金 × 50% × P(你贏)

例：
對手賞金 $100
你和對手各有 50% 勝率
→ 有效賞金 EV = $100 × 50% × 50% = $25
```

這個 $25 可以加到你的 EV 計算中。

### 實際的調整幅度

| 對手賞金 vs 你的進場費 | Call range 放寬幅度 |
|---------------------|------------------|
| 1x（等同你的進場費）| +5-8% |
| 2x | +10-15% |
| 4x | +20-25% |
| 8x+（超大賞金）| +30-40% |

---

## PKO 的 ICM 特殊性

PKO 的 ICM 計算比標準 MTT 更複雜：

**標準 MTT ICM：**
只考慮名次獎金

**PKO ICM：**
考慮名次獎金 + 現在的賞金 + 未來可能淘汰對手的賞金

**結論：**
PKO 在早中期比標準 MTT **更積極**（賞金 EV 讓你更願意冒險）。
但 Bubble/FT 時，名次 ICM 仍然重要，需要平衡。
