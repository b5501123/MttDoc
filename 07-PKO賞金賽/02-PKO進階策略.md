# PKO 進階策略

## PKO vs 標準 MTT：思維切換

### 標準 MTT 的問題
「我應該 fold 這手邊緣牌嗎？」
→ 考慮 ICM，通常 fold

### PKO 的問題
「我應該 fold 這手邊緣牌嗎？」
→ 先考慮：**對手的賞金是多少？**
→ 再考慮 ICM

---

## 計算「追殺 EV」

追殺一個對手是否值得？

### 追殺 EV 計算

```
你追殺 X 的 EV = P(win vs X) × X的賞金 × 50%
                - P(lose vs X) × 影響（你失去的 ICM equity）
```

### 實際案例

**情境：**
- PKO 錦標賽，報名費 $100（$50 進獎金池，$50 賞金）
- 你：50bb，賞金 $50
- 對手 X：12bb，賞金 $200（他已淘汰了多人）
- 你在 BTN，X 在 BB

X 的賞金 $200 → 淘汰他你拿 $100

**Push 分析：**

如果你 push，X call（他 12bb，大概率 call）：

```
設你有 AT，X 的 call range 很寬（50%）
AT vs 50% range 勝率 ≈ 65%

追殺 EV = 65% × $100 = +$65
輸掉 EV = 35% × 你失去的 ICM equity（假設 -$150）

追殺總 EV = +$65 - 35% × $150 = +$65 - $52.5 = **+$12.5**
```

即使是邊緣場景，追殺有大賞金的短疊通常是正 EV。

## PKO 的位置策略

### 大賞金目標坐在你右邊（你在 IP）

最理想的情況：
- 你可以從位置上施壓
- 他 push 你可以 call（有賞金 EV）
- 你 push 他被迫 call 或 fold

**行動：積極對這個目標**

### 大賞金目標坐在你左邊（你在 OOP）

較難的情況：
- 他有位置優勢
- 他可能先 push 你

**行動：大賞金讓你 call range 更寬（即使 OOP）**

---

## 多人桌的 PKO 動態

### 有大賞金目標時的桌面動態

假設 X 賞金 $400（是進場費的 4倍）：

**大家都想淘汰 X：**
- X 的 push 會被更多人 call
- X 知道這一點，應該縮緊 push range
- 你可以利用其他人追殺 X 的注意力，偷其他人的盲注

**你在 X 旁邊時的策略：**
- 等 X push，然後 call（賞金 EV）
- 不要被其他人搶先（擠在你和 X 之間）

## PKO Bubble 的特殊性

### PKO Bubble 比標準 MTT Bubble 更複雜

標準 MTT Bubble：保守，等進錢
PKO Bubble：進錢 EV + 賞金 EV 都要考慮

**場景：**
PKO Bubble，你是中疊，有一個大賞金短疊

**思路：**
```
短疊賞金 = $300
淘汰他：$150 即時賞金
如果你 bubble out：$0 名次 + 失去機會

問題：追殺他的賞金 EV 能否補償 bubble out 的風險？
```

通常：
- 如果 bubble 進錢只有 min cash（很小）→ 積極追殺
- 如果 bubble 進錢很大（FT bubble）→ 保守，不冒險

## PKO 的翻牌後調整

### 翻牌後追殺策略

如果你翻牌後有機會淘汰大賞金對手（他有 draw 或中等牌力）：

**比標準 MTT 更積極打多條街**

原因：
- 即使你翻牌有中等牌，賞金 EV 讓你繼續打有正 EV
- 對手可能 call 你的 bet（因為他知道如果輸他失去賞金）

### 你是大賞金目標的翻牌後策略

對手追殺你，他們 call range 更寬：
- 你的 bluff 成功率降低
- 你應該更多 value bet（有牌力時下注）
- 少做純 bluff（對手不太 fold）

## PKO 心態管理

### 不要被賞金衝昏頭

常見錯誤：
- 為了賞金不顧一切 call，甚至數學上是負 EV
- 看到大賞金就興奮，忘記計算實際 EV

**正確心態：**
賞金是 EV 的一部分，要計算進去，但不是唯一因素。

### 你是目標時的心態

你積累了大賞金 = 你是「獵物」：
- 被 call 機率更高，接受這個現實
- 調整策略（縮緊 bluff）
- 保持價值導向的打法

---

## PKO 快速策略框架

```
1. 確認桌上有沒有大賞金目標？
   有 → 計算追殺 EV，可能放寬 range

2. 我的賞金大嗎？
   大 → 縮緊 bluff，接受被更多人 call

3. 現在是 bubble 嗎？
   是 → 平衡名次 EV 和賞金 EV

4. 追殺機會出現時：
   計算：賞金 EV = 對手賞金 × 50% × P(win)
   比較：賞金 EV vs ICM risk

5. 追殺 EV 正 → call/push
   追殺 EV 負 → 用正常 MTT 邏輯
```
