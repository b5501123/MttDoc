# 短疊推注場景分析

---

## 範例 1：BTN 10bb，A7o，是否 Push？

**情境：**
- 你在 BTN，10bb
- 手牌：A♠ 7♦
- 所有人 fold 到你

**分析：**

BTN 10bb push range ≈ 67%

A7o 在 BTN 10bb 的 push range 中嗎？

```
Ax push range（BTN 10bb）：A2o+（幾乎全部 Ace）
A7o：是的，在 range 內
```

**行動：Push**

**理由：**
- A7o 是有牌力的手牌，對 BB 的隨機手牌有 60%+ 勝率
- BTN 位置讓你只需過 SB/BB
- 10bb push 有 fold equity，即使被 call 也有牌力
- Fold 會損失這個有利的 push 機會

## 範例 2：UTG 12bb，KJo，是否 Push？

**情境：**
- 你在 UTG，12bb
- 手牌：K♥ J♦
- 6-max，第一個行動

**分析：**

UTG 12bb push range ≈ 37-40%

KJo 在 UTG push range 嗎？

```
UTG 強牌 push：AA-77, AK-ATo, KQs-KTs, QJs
KJo 在 UTG：邊緣，大約在 range 的邊界
```

**考量因素：**
1. 6個人需要 fold（UTG 6-max 成功率最低）
2. 12bb 仍有 fold equity，但不如 7-8bb 高
3. KJo 牌力中等，被 call 後對 AK, QQ+ 不利

**行動：Push（邊緣情況，可以 fold）**

Push 的理由：
- 有足夠 fold equity
- KJo 對很多 call range 有牌力
- 等待更好的牌 = 被 blinds 吃掉

Fold 的理由（Bubble 時）：
- ICM 壓力讓這個邊緣 push 不值得
- 等更強的牌避免 bubble out

## 範例 3：SB 8bb，Q9s，面對 BTN fold

**情境：**
- SB，8bb
- BTN 和更早的人都 fold
- 手牌：Q♦ 9♦
- 你對 BB

**分析：**

SB 對 BB 的 push range（8bb）≈ 72%

Q9s 在 SB 8bb push range 嗎？

```
Q9s 是 suited connector，有牌力
SB 8bb：幾乎所有有價值的手牌都 push
Q9s：是，在 range 內
```

**行動：Push**

**理由：**
- 只需要過 BB 一人
- 8bb 讓 fold equity 充足
- Q9s 被 call 後對 BB 的隨機牌有良好勝率
- SB 的 limp/fold 浪費了 0.5bb

## 範例 4：BB，對手 BTN Push 9bb，你有 JTs

**情境：**
- 你在 BB，20bb
- BTN push 9bb（all-in）
- SB fold
- 手牌：J♠ T♠

**計算：**

Call 金額：8bb（你已有 1bb，call to 9bb）
底池（call 後）：9 + 0.5（SB）+ 1（BB）= 10.5bb，call 8，total 18.5bb

所需勝率 = 8 ÷ 18.5 = **43%**

BTN 9bb push range ≈ 70%

JTs vs BTN 70% push range 的勝率 ≈ **52%**

**52% > 43% → Call**

**行動：Call**

**補充：**
- JTs 是有良好權益的手牌
- 對手 push range 很寬（70%），你的 JTs 有優勢
- 即使非 Bubble，這也是正確的 call

## 範例 5：Bubble！BB 20bb，大疊 BTN push 50bb，你有 99

**情境：**
- Bubble（20人剩，18進錢）
- 你：BB，20bb
- 大疊 BTN：50bb，push all-in
- SB fold

**數學計算（Chip EV）：**

Call 金額：19bb
底池（call 後）：39.5bb
所需勝率 = 19 ÷ 39.5 = **48%**

99 vs 大疊寬 push range（~70%）≈ **52% 勝率**

Chip EV 角度：Call 是正 EV

**但等等——ICM！**

Bubble 場景下：
- 輸了 = 出局 = $0（假設 min cash $300）
- 贏了 = 40bb，但還是在 bubble 中
- 其他短疊可能自己出局（你可以不用冒險就進錢）

**ICM 計算（簡化）：**
如果其他桌有短疊 <10bb，他們很快出局的機率高。
你現在 20bb，可以等他們出局進錢，然後再打。

**行動：Fold（Bubble 情境）**

即使有 52% 勝率，ICM 讓 fold 更好。

**非 Bubble 時：Call（按 Chip EV）**

## 範例 6：SB 12bb，面對 BB，對手是 unknown（未知）

**情境：**
- SB，12bb
- 所有人 fold，你對 BB
- BB 未知玩家（可能是 nit 或 loose）

**問題：你應該用 Nash，還是調整 BB 的 calling tendency？**

**Nash 基準（SB 12bb push range）：≈ 62%**

**如果 BB 是 Nit（call range 非常緊，只 call 頂端強牌）：**
→ 你可以更寬 push（Nash 已經最優，但對緊的人 Nash 偏保守）
→ Push range 可以到 70%+

**如果 BB 是 Loose（call range 很寬，call 任何 pair, Ax, Kx...）：**
→ 縮緊你的 push range（更多 fold equity 消失）
→ 只 push 真正有牌力的手牌（45-50%）

**未知對手：用 Nash（62%）**

## 範例 7：Final Table，3人剩，你短疊 9bb，SB

**情境：**
- FT 3人剩
- 獎金：1st $10,000，2nd $6,000，3rd $4,000
- 你：SB，9bb
- BTN fold
- 你對 BB

**Nash 計算：SB 9bb push ≈ 73%**

**ICM 調整（FT 3人）：**
- 3人時 ICM 差距相對不大（1st vs 3rd 差 $6,000）
- 你是短疊，ICM 壓力較低（快出局了）
- Push range 縮緊約 5-8%

**調整後 push range：≈ 65-68%**

**行動：大部分手牌 push，只去掉最弱的 bluff（72o, 83o 等）**
