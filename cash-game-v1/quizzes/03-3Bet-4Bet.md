# Cash Game 測驗 3：3Bet / 4Bet

## Q21

CO open，BTN 3bet，CO AQs。

**答案：** 多數 continue；call 或 4bet mixed 取決於 BTN 3bet。

## Q22

BTN open，SB 3bet，BTN A5s。

**答案：** 4bet bluff 候選，但對不 fold 的 pool 要收。

## Q23

UTG open，BTN 3bet，UTG QQ。

**答案：** 強 4bet / continue。

## Q24

BTN open，BB 3bet，BTN 76s。

**答案：** 多數 fold；不要過度 call 3bet。

## Q25

SB 3bet BTN，持 KTs。

**答案：** 可作 3bet bluff / mixed。

## Q26

4bet bluff 的核心條件。

**答案：** blocker、fold equity、被 call 後仍有 equity。

## Q27

OOP call 3bet 為何要收緊？

**答案：** realization 差，rake 與 position 懲罰。

## Q28

JJ 面對 4bet 是否一定打光？

**答案：** 不是；看位置、player pool 和 size。

## Q29

A2s 作 4bet bluff 是否永遠正確？

**答案：** 不是；對 value-heavy 不 fold pool 要收。

## Q30

3bet pot A72r。

**答案：** 通常偏 3bettor range。
