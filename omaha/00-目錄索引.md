# 奧馬哈（PLO）MTT 教材 — 目錄

> 本教材專為 **線上 9-max PLO MTT（底池限注奧馬哈多桌錦標賽）** 玩家設計。
> 從規則基礎到 ICM 決策，從翻牌後技術到 Bubble 策略，涵蓋完整的 PLO MTT 知識體系。
> 前提知識：熟悉德州撲克（NLH）基本規則（盲注、位置、下注輪次）。

## PLO MTT 術語速查表

| 術語 | 分類 | 說明 |
|------|------|------|
| **PLO** | 遊戲類型 | Pot-Limit Omaha，底池限注奧馬哈 |
| **MTT** | 賽制 | Multi-Table Tournament，多桌錦標賽 |
| **ICM** | 理論 | Independent Chip Model，獨立籌碼模型，計算籌碼的獎金價值 |
| **ICM EV** | 理論 | ICM 期望值，獎金期望而非籌碼期望 |
| **Chip EV** | 理論 | 籌碼期望值，不考慮 ICM 的純籌碼計算 |
| **Nuts / Nut Hand** | 牌力 | 當前牌面上最強的可能組合（如 Nut Flush = 最高同花） |
| **Nut Draw** | 牌力 | 聽向最強組合的 Draw（如 Nut Flush Draw） |
| **Wrap Draw** | 牌力 | 奧馬哈特有的環繞型順子聽牌，最多 20 outs |
| **Double-suited** | 起始牌 | 手牌中有兩對同花（如 A♠K♠Q♥J♥） |
| **Rundown** | 起始牌 | 連續數字的手牌（如 J-T-9-8） |
| **Dangling Card** | 起始牌 | 與其他牌不連貫、幾乎無用的一張牌 |
| **SPR** | 翻牌後 | Stack-to-Pot Ratio，籌碼底池比，影響 Commit 決策 |
| **Commit** | 翻牌後 | 籌碼到達不能合理 Fold 的狀態（通常 SPR < 2） |
| **Semi-bluff** | 策略 | 有 Equity（Draw）的情況下下注，兼顧 Fold Equity 和 Draw Equity |
| **Fold Equity** | 策略 | 讓對手 Fold 的機率 × 底池價值，短疊 Push 的重要組成部分 |
| **C-bet** | 策略 | Continuation Bet，翻牌前 Raiser 在翻牌後繼續下注 |
| **OOP** | 位置 | Out of Position，位置不利（先行動的玩家） |
| **IP** | 位置 | In Position，位置有利（後行動的玩家） |
| **Bubble** | MTT 術語 | 最後一名未獲獎位置的附近階段，ICM 壓力最大 |
| **Hard Bubble** | MTT 術語 | 剛好多 1 人在獎金圈外的 Bubble 時刻 |
| **Final Table** | MTT 術語 | 決賽桌，最後 9 人（視賽制而定） |
| **Push/Fold** | 短疊策略 | 短疊的 All-in 或 Fold 簡化決策模式 |
| **Equity** | 數學 | 在對抗中的勝率（如你有 55% Equity = 55% 勝率） |
| **Implied Odds** | 數學 | 隱含賠率，未來可能贏取的底池，影響 Draw 的期望值 |
| **Pot Bet / Pot-raise** | PLO 下注 | 下注或加注等於當前底池大小（PLO 的最大允許下注） |
| **HUD** | 線上工具 | Heads-Up Display，即時顯示對手統計數據的軟體 |
| **VPIP** | HUD 指標 | Voluntarily Put In Pot，自願入池率（選牌緊/鬆的指標） |
| **PFR** | HUD 指標 | Pre-Flop Raise Rate，翻牌前加注率 |
| **AF** | HUD 指標 | Aggression Factor，(Bet+Raise)/Call 的積極性指數 |

## 與 MTT 德州撲克（NLH）教材的對照建議

如果你同時在學習 NLH MTT，以下是兩個教材的對照和補充建議：

```
核心概念對照：

NLH MTT 概念              PLO MTT 對應概念（差異）
─────────────────────────────────────────────────────
Push/Fold（NLH）          Push/Fold 邏輯相同，但 Range 更窄
                          （PLO 被 call 時 Equity 較低）

ICM 計算（NLH）           ICM 計算方法相同，但 PLO 的 all-in
                          更接近 flip，ICM 成本更高

翻牌前 AA（NLH 最強牌）   翻牌前 AA（PLO 也強，但只有 65% 優勢）

C-bet 保護（NLH）         PLO 的 C-bet 更依賴 Nut 或 Nut Draw
                          非 Nut 的 Bluff C-bet 效果有限

位置優勢（NLH）           位置在 PLO 同樣重要，但影響更多體現在
                          翻牌後的 Draw 追逐和資訊優勢

Bluff（NLH）              PLO 的純 Bluff 成功率更低，
                          Semi-bluff（有 Draw 的 Bluff）更重要
```

**建議學習順序：**

```
如果你已有 NLH MTT 基礎：
  1. 先讀 01-PLO-MTT與Cash的差異.md（快速理解差異）
  2. 再讀 02-起始牌策略（最重要的技術差異：選牌）
  3. 重點閱讀 05-MTT專項策略（MTT 核心）
  4. 用 06-練習與自評 測試理解

如果你只有 NLH Cash 基礎（無 MTT 經驗）：
  建議同時學習 NLH MTT 教材的 ICM 章節，
  再對照本教材的 02-ICM與籌碼管理.md，
  理解 MTT 特有的 ICM 思維
```

## 教材適用範圍說明

- **格式**：線上 9-max MTT（多桌錦標賽）
- **遊戲類型**：Omaha Hi / PLO（底池限注）
- **技術方向**：GTO 導向，但強調 Exploitative 調整
- **前提知識**：NLH 基本規則（盲注、位置、下注輪次）

> **不涵蓋的內容**：
> Omaha Hi/Lo（八或更好）、Fixed-Limit Omaha（限注奧馬哈）、
> 5 張奧馬哈、現場 Live PLO MTT 的特殊考量
