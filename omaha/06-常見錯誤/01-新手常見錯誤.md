# 常見錯誤 01：奧馬哈新手最常犯的 5 大錯誤

> **學習目標**：深入了解奧馬哈新手（特別是從德州撲克轉過來的玩家）最常犯的錯誤，理解每個錯誤的根本原因，並學習正確的對應策略。

---

## 前言：為什麼奧馬哈新手特別容易犯錯？

從德州撲克轉學奧馬哈的玩家面臨一個特殊的挑戰：**你知道得越多，越容易犯錯**。

德州撲克的直覺和習慣在奧馬哈中往往是**反效果的**：
- 「頂對頂踢腳很強」→ 在奧馬哈是弱牌
- 「Set 幾乎不用考慮就全押」→ 在奧馬哈需要謹慎
- 「Flush 是超強牌」→ 在奧馬哈非 Nut Flush 很危險
- 「Bluff 是重要工具」→ 在奧馬哈 Bluff 成功率大幅降低

以下是 5 個最常見、代價最高昂的新手錯誤。

---

## 錯誤 1：用德州撲克的眼光評估牌力（Top Pair 在奧馬哈很弱）

### 1.1 錯誤描述

許多新手（尤其是德州撲克玩家）在奧馬哈中用德州撲克的標準評估自己的牌力：
- 「我有頂對頂踢腳（TPTK），這很強！」
- 「我有兩對，很有可能贏！」
- 「我有一個 Flush，幾乎必贏！」

### 1.2 為什麼這是錯誤的？

**奧馬哈的牌力通貨膨脹**：

```
德州撲克中：
  頂對頂踢腳（TPTK）→ 在多人底池 勝率約 60-70%（良好的牌力）
  兩對 → 勝率約 70-80%（很強）
  普通 Flush → 勝率約 85%（非常強）

奧馬哈中：
  頂對頂踢腳 → 勝率約 20-30%（在多人底池）
  兩對 → 勝率約 40-50%（中等偏弱）
  Non-Nut Flush → 勝率約 50-60%（危險）
```

**原因**：奧馬哈每個玩家有 6 種兩牌組合，更容易做出強牌，攤牌的平均強度遠高於德州撲克。

### 1.3 具體錯誤案例

**案例 A：頂對的陷阱**

```
情境：6 人底池（多人 limp）
你的手牌：A♠ K♥ 7♦ 2♣
翻牌：A♥ Q♠ 5♦

新手的想法：「我有頂對頂踢腳（AA）！翻牌命中了！我要大注！」

現實分析：
  你用 A♠K♥（手牌 2 張）配 A♥Q♠5♦（公牌 3 張）= 一對 A + K-Q-5
  最強牌型：A♠A♥（一對 A，踢腳 K-Q-5）

  問題：
  1. 翻牌 A♥Q♠5♦ 不夠乾燥（有 A 高連可能讓人有 Wrap）
  2. 你的 A 是「One Pair」，在多人底池非常弱
  3. 有人可能有 AA（三條 A），或 QQ（三條 Q），或 Nut Wrap
  4. 你的手牌 7♦2♣ 完全無用（Dangling cards）

  正確認知：這手牌幾乎應該在翻牌前就棄牌（A♠K♥7♦2♣ 是 C 級手牌）
  如果進了底池，翻牌後你的「頂對」在多人底池中勝率很低
  正確行動：Check → Fold（面對任何下注）
```

**案例 B：兩對的陷阱**

```
情境：3 人底池
你的手牌：K♠ Q♥ 8♦ 3♣
翻牌：K♥ Q♠ 7♦

新手的想法：「我中了頂部兩對！KK + QQ！這太強了！」

現實分析：
  用 K♠Q♥（手牌）配 K♥Q♠7♦（公牌）= K♠K♥（兩 K）+ Q♥Q♠（兩 Q）= Full House？
  等等：K♠（手）+ Q♥（手）+ K♥（公）+ Q♠（公）+ 7♦（公）
  牌型：K♠K♥（一對 K）+ Q♥Q♠（一對 Q）+ 7♦ = 兩對（KK + QQ），踢腳 7

  問題：
  1. 兩對在奧馬哈中是弱牌（在多人底池）
  2. 翻牌 K-Q-7 有連線，任何有 J-T-9 或 T-8 的人有 Wrap Draw
  3. 有 KQxx（且 K 和 Q 都在手牌的人）可能有更好的兩對或 Set
  4. 如果翻牌配出 Set（如對手有 K-K 或 Q-Q 配 set），你輸

  你的兩對 KK + QQ：
  對抗 Set（三條 Q）：勝率 約 25%
  對抗 Wrap Draw（20 outs）：勝率 約 60%（翻牌後）
  在 3 人底池（對手一個有 Set，一個有 Wrap）：勝率 約 25%！

  正確認知：兩對在奧馬哈需要發展成葫蘆才能感到安全
  用兩對大注是常見的新手錯誤
```

### 1.4 正確的牌力評估標準

```
奧馬哈的牌力標準（多人底池）：

極強（可以大注）：
  ✅ Nut Straight（最強順子）
  ✅ Nut Flush（A 高同花）
  ✅ Full House（葫蘆）
  ✅ Top Set + 乾燥翻牌（三條 + 無大 draw）

中等強（謹慎下注）：
  ⚠️ Non-Nut Straight（可能被更高順子打敗）
  ⚠️ Non-Nut Flush（可能被更高同花打敗）
  ⚠️ Top Set + 濕潤翻牌（有大量 draw）

弱（接近棄牌）：
  ❌ 兩對
  ❌ Top Pair（一對 K、一對 A 等）
  ❌ 任何 One Pair
  ❌ High Card（無對）
```

## 錯誤 2：追非 Nut Draw（Non-Nut Flush Draw 很危險）

### 2.1 錯誤描述

新手常常看到「Flush Draw」就興奮地追牌，不論這個 Flush Draw 是否是 Nut（最強同花）。

### 2.2 為什麼非 Nut Draw 危險？

```
在奧馬哈，幾乎每個人都有某種 Draw。

如果你有 Non-Nut Flush Draw（如 Q 高同花聽牌）：
  → 當你命中時（得到你需要的同花牌），可能另一個人也命中了
  → 如果對手有 A 高同花（Nut Flush），你的 Q 高同花輸掉
  → 你追牌的費用（Call 或 Bet）變成完全浪費

更嚴重的「Reverse Implied Odds（反向隱含賠率）」：
  → Non-Nut Draw 命中時，底池通常很大
  → 但你面對更強 Draw 的對手，你輸掉大底池
  → 你的追牌代價 = 你投入的籌碼（命中後輸掉更多）
```

### 2.3 具體案例

**案例：追 Q 高同花並命中，然後輸掉**

```
情境：翻牌後 3 人底池，底池 60bb
你的手牌：Q♠ J♠ 9♥ 8♥
翻牌：K♠ 6♠ 2♦（兩張黑桃）

你有什麼？
  Q♠J♠（手牌）+ K♠6♠（公牌黑桃）= 4 張黑桃！→ Flush Draw
  但你的 flush 是 Q-high（Q♠J♠K♠6♠ + 一張）= Q 高同花

  對手 A Pot Bet 60bb（對手可能有 A♠X♠，即 Nut Flush Draw）
  你 Call 60bb（「我有 Flush Draw！」）

  Turn：5♠（第 5 張黑桃！你成了！）

  你的牌型：Q♠J♠ + K♠6♠5♠ = K-Q-J-6-5 同花（Q 高，選最強 5 張：K♠Q♠J♠6♠5♠）
  = K-high flush（最高牌是 K）

  等等，哪張是最高？K♠ 是公牌的最高，你手牌有 Q♠J♠，所以：
  你的 flush：Q♠J♠ 手牌 + K♠6♠5♠（公牌）= K♠Q♠J♠6♠5♠ = K-high flush（以 K 為最高牌）

  對手 A（A♠X♠）的 flush：A♠ + K♠Q♠J♠5♠（公牌 5 選 3）= A♠K♠Q♠J♠5♠ = A-high flush（Nut！）

  結果：你的 K-high flush 輸給對手的 A-high flush！

  你追了 Q♠J♠ 的 flush（Non-Nut），最終命中卻輸掉了！
  → 這就是 Non-Nut Draw 的危險性

  你的損失：Call 60bb（翻牌）+ 繼續 All-in（如果你繼續）= 大量損失
```

### 2.4 正確應對 Non-Nut Draw 的策略

```
遇到 Non-Nut Flush Draw 時：

問題 1：有 Nut Flush Draw 的玩家在桌上嗎？
  如果翻牌有兩張黑桃，任何有 A♠ 的玩家都可能有 Nut Flush Draw
  → 在 9 人桌，有人持有 A♠ 的概率很高

問題 2：你的 Draw 是否有其他支撐（如 Nut Wrap）？
  如果你同時有 Nut Wrap Draw，Non-Nut Flush 只是輔助
  → 主要依賴 Wrap，Flush 是 bonus 但不追求

問題 3：底池賠率是否划算？
  如果你確定你的 Draw 是 Non-Nut，你需要更高的底池賠率才合算
  → Non-Nut Flush Draw 的「有效 outs」應該打折計算（例如 9 → 6）

結論：
  ✅ 只有在有其他強 Draw（Nut Wrap 等）輔助時，才追 Non-Nut Flush
  ❌ 純 Non-Nut Flush Draw = 高風險，通常不值得追
```

## 錯誤 3：不保護強牌（讓對手免費 Draw）

### 3.1 錯誤描述

許多新手在有強牌時選擇慢打（Slow Play），想讓對手在後期街道繼續投入籌碼。這在德州撲克有時合理，但在奧馬哈通常是嚴重錯誤。

### 3.2 為什麼不保護強牌是錯誤的？

```
在德州撲克：
  慢打 Set 可行，因為對手的 draw 只有 8-9 outs（約 35% 命中率）
  讓對手免費看 1 張，他有 35% 機率命中 → 你的 65% 領先

在奧馬哈：
  對手的 draw 可能有 20 outs（約 70% 命中率！）
  讓對手免費看 1 張，他有 70% 機率命中 → 你的 30% 劣勢！
  → 免費看牌讓你從「領先」變成「劣勢」！
```

### 3.3 慢打代價的量化

```
情境：翻牌底池 100bb，你有 Set（60% equity），對手有 20-out Wrap（40% equity）

選項 A：你 Pot Bet 100bb（正確）
  對手的底池賠率 = 100/300 = 33%，他有 40% equity → 他應該跟注
  底池 after call = 300bb
  你的 EV = 300 × 60% - 100 = 180 - 100 = +80bb

選項 B：你 Check（錯誤的慢打）
  對手 Check → Turn 免費看牌
  Turn 命中 Wrap（假設）概率 = 40%（單張牌的命中率）

  如果 Turn 命中（40% 概率）：
    對手現在領先，你後面投入的籌碼大多會輸
    假設剩餘 100bb 投入，你贏 = 100 × 30% = 30bb，你輸 = 100 × 70% = 70bb
    EV = -40bb

  如果 Turn 未命中（60% 概率）：
    你仍領先，後面繼續，EV ≈ +80bb（但底池因 Check 而減小）

  選項 B 的期望 EV：
  = 40% × (-40bb) + 60% × (+80bb)
  = -16bb + 48bb = +32bb

  結論：
  選項 A（Pot Bet）：+80bb
  選項 B（慢打）：+32bb

  慢打的代價：+80 - +32 = 48bb！
  每一次慢打，你損失了 48bb 的期望值！
```

### 3.4 正確的保護策略

```
奧馬哈的保護原則（已在第 3 章詳細討論）：

規則：翻牌後有強牌 = 幾乎永遠 Pot Bet

唯一例外（乾燥翻牌 + 你有 Absolute Nuts，如 Full House 或 Quads）：
  → 此時對手幾乎沒有 Draw，慢打讓弱牌繼續（小 EV 增加）
  → 但即使在此情況，通常也應該小 Bet（不能完全 Check）
```

## 錯誤 4：錯誤計算 Outs（忘了必須用 2 張手牌）

### 4.1 錯誤描述

新手在計算 outs 時，常常忘記奧馬哈的「必須用 2 張手牌」規則，誤以為所有手牌中的牌都是 outs 的一部分。

### 4.2 具體錯誤案例

**案例 A：錯誤計算 Flush Outs**

```
你的手牌：A♠ K♠ Q♠ J♠（4 張黑桃）
翻牌：T♥ 8♣ 6♦（Rainbow）

錯誤想法：「我有 4 張黑桃！我正在追 Flush！只需要再來 1 張黑桃！」

實際情況：
  翻牌是 Rainbow，公牌中沒有黑桃
  你用 2 張手牌（選 A♠K♠）配 3 張公牌（T♥8♣6♦）
  → 你只有 2 張黑桃（A♠K♠），公牌沒有任何黑桃
  → 你需要翻牌後再來兩張黑桃（Turn 和 River 各一張）才能成 Flush
  → 這不是「9 outs Flush Draw」，而是「Backdoor Flush Draw」（只有 3-4% 命中率！）

  正確計算：Backdoor Flush = ~3-4% chance（非常弱）
  手牌 4 張全是同花色 = 一個方向的 Backdoor Flush Draw（弱！）

  更有用的分析：你的 4 張連牌 AKQJ 有 Wrap Draw：
  用 A♠K♠（手牌）配 T♥8♣6♦（公牌）：A-K-T-8-6（不連）
  用 Q♠J♠（手牌）配 T♥8♣6♦（公牌）：Q-J-T-8-6（有缺口，J-T 連，但 8 和 T 之間差 9）
  用 K♠Q♠ 配 T-8-6：K-Q-T-8-6（多個缺口）
  → 這個翻牌對你的 AKQJ 連線幫助不大，你幾乎沒有有用的 draw
```

**案例 B：錯誤計算 Straight Outs**

```
你的手牌：9♠ 8♥ 7♦ 6♣
翻牌：Q♥ J♠ 2♦

錯誤想法：「我有 9-8-7-6，只差一個就成順子！只需要 T 就可以了！還有 5！」

實際情況：
  你的手牌是 9-8-7-6，翻牌是 Q-J-2
  要做出順子，你需要選 2 張手牌 + 3 張公牌（全部）

  用 9-8（手）配 Q-J-2（公）：9-8 + Q-J = Q-J-9-8（缺口，J 和 9 相鄰，Q 多餘）
    最強連線：J-9-8（不是 5 連）
  用 8-7（手）配 Q-J-2（公）：J-8-7（不連，J 和 8 差 2）
  用 9-7（手）配 Q-J-2（公）：Q-J-9-7（不連）
  用 8-6（手）配 Q-J-2（公）：J-8-6（不連）
  用 9-6（手）配 Q-J-2：Q-J-9-6（不連）
  用 7-6（手）配 Q-J-2：J-7-6（不連）

  在翻牌 Q-J-2 上，你的 9-8-7-6 手牌幾乎沒有任何 Straight Draw！
  Q-J-2 和 9-8-7-6 的連接性很差（翻牌的 Q-J 和你的 9 之間相鄰，但 2 完全不相關）

  正確認知：
  你的手牌 9876 在這個翻牌幾乎是空氣
  需要翻牌是 T-9 相關的連牌才對你有利（如翻牌 T♥9♠2♦）

  正確行動：Check/Fold（這個翻牌對你毫無幫助）
```

### 4.3 正確計算 Outs 的方法

```
計算 Outs 的正確步驟：

步驟 1：選擇你的 2 張手牌組合（C(4,2) = 6 種組合）
步驟 2：對每種 2 張組合，搭配全部 3 張公牌，看能做出什麼牌型
步驟 3：找出每種組合需要什麼 Turn 或 River 牌
步驟 4：彙總所有有效 outs，去掉手牌中已有的牌（減 outs）
步驟 5：去掉重複計算的牌

快速 Checklist（防止錯誤）：
  ✅ 我選了幾張手牌？（必須是 2 張）
  ✅ 我用了幾張公牌？（必須是 3 張）
  ✅ 我計算的 out 是在牌組中嗎？（不在手牌或公牌中）
  ✅ 我的 out 確實讓我做出 5 連牌或同花嗎？（仔細確認連線）
```

## 錯誤 5：翻牌後過度 Bluff（奧馬哈大家都有強 Draw，Bluff 很少成功）

### 5.1 錯誤描述

德州撲克玩家習慣了 c-bet（Continuation Bet）bluff 和多街道 bluff。這些技術在奧馬哈中效果大幅降低，但新手仍然頻繁嘗試。

### 5.2 為什麼奧馬哈的 Bluff 失敗率更高？

```
在德州撲克：
  翻牌後 c-bet bluff 成功率約 50-65%（在許多情況下）
  對手可能完全沒有命中翻牌（沒有 pair，沒有 draw）
  → 對手更容易 Fold

在奧馬哈：
  每個人有 6 個手牌組合，更容易命中翻牌
  幾乎每個玩家在大多數翻牌上都有某種繼續的理由（Draw 或 Made Hand）
  → 對手很少完全沒有理由繼續
  → 你的 Bluff 面對更多「Drawer」和「Caller」

量化差異：
  德州撲克翻牌後「完全沒有繼續理由」的概率：約 30-40%
  奧馬哈翻牌後「完全沒有繼續理由」的概率：約 10-15%
  → 奧馬哈的 Bluff 面對「對手真的沒有牌」的場景少得多
```

### 5.3 過度 Bluff 的常見失敗案例

**案例 A：無 Draw 支撐的 C-bet Bluff**

```
情境：翻牌前 CO 開牌，你跟注（BTN），BB 跟注，3 人底池
你的手牌：A♠ K♥ 5♦ 2♣（A 高牌，但其他牌完全無用）
翻牌：J♠ T♥ 9♣（濕潤的高位連牌翻牌）

錯誤行動：CO Check，你 Pot Bet（Bluff，因為你「有 A」）

問題：
  翻牌 J-T-9：
  → 任何有 Q-8 的人已成 K-high straight
  → 任何有 K-Q 的人有 Nut Straight Draw
  → 任何有 QJ 或 JT 的人有 Pair + Straight Draw
  → 在 9 人桌，幾乎每個人的手牌都與 J-T-9 有連接！

  你的牌（A♠K♥5♦2♣）在這個翻牌：
  → 完全沒有命中（沒有 Pair，沒有 Draw）
  → 你是在「純空氣」Bluff
  → 對手（CO 和 BB）幾乎一定有繼續的理由

  結果：你的 Pot Bet 被 Call（甚至 Raise），你輸掉了所有投入

正確行動：Check（承認你在這個翻牌什麼都沒有，控制損失）
```

**案例 B：多街道 Bluff 失敗**

```
情境：你從 BTN 開牌，BB 跟注，2 人底池
你的手牌：A♥ K♦ 8♠ 3♣（有 A，但無配合）
翻牌：Q♠ 7♦ 2♣（乾燥翻牌）

你 Pot Bet（C-bet）→ BB Call

Turn：J♠

你再次 Pot Bet（Second Barrel）→ BB Call

River：T♥

你三桶（Triple Barrel）→ BB Call（甚至 Raise！）

分析：
  在德州撲克，Q-7-2 乾燥翻牌上的 C-bet 通常成功
  但在奧馬哈：
  → BB 用 4 張手牌，在任何翻牌都有命中的可能
  → BB Call 了翻牌 = 他有某種繼續的理由（Pair, Draw, 等）
  → Turn J♠ 讓連牌可能性增加（J-T-9-8 或 Q-J-T 的 wrap draw）
  → River T♥ 讓 J-T 配 Q-J-T 的 Straight 完成

  BB 可能有：
  → 在翻牌：Q 相關的 pair + draw
  → Turn：有了 Wrap draw 命中更多
  → River：可能成了 Straight 或更強

  你的三桶 Bluff 在奧馬哈的多人底池失敗率極高

正確策略：
  如果你要 Bluff 奧馬哈，必須有以下支撐：
  ✅ 你有 Nut Draw（Semi-Bluff，即使被 Call 你還有 equity）
  ✅ 在單挑底池（而非多人）
  ✅ 對手顯示明顯弱勢（如多次 Check）
  ✅ 公牌對你的「故事」有利
```

### 5.4 奧馬哈中有效的 Bluff 條件

```
可以考慮 Bluff 的情況（所有條件最好都滿足）：

條件 1：你有 Semi-Bluff 支撐（Nut Draw）
  → 即使 Bluff 被 Call，你有 equity 可以繼續
  → Nut Flush Draw（9 outs）+ c-bet = Semi-Bluff

條件 2：翻牌對你的「手牌故事」有利
  → 如果你翻前代表有某種 Strong Hand（比如你 3-bet），
    翻牌應該符合你「宣稱的」強牌的連牌

條件 3：單挑底池（對手只有 1 人）
  → 多人底池的 Bluff 成功率接近 0
  → 單挑底池 Bluff 有更高的成功機率

條件 4：對手有 Fold Equity（可能棄牌）
  → 對手是 Tight 玩家（容易 Fold）
  → 對手顯示弱勢（Check-call，沒有主動性）
  → 翻牌對對手不利（他的「手牌範圍」在這個翻牌難以命中）

不可以 Bluff 的情況：
  ❌ 你完全沒有 equity（純空氣）
  ❌ 濕潤翻牌（每個人都有 Draw）
  ❌ 多人底池
  ❌ 對手是鬆散（Loose）的 Caller
```

## 六、5 大錯誤總覽與快速修正

| 錯誤 | 根本原因 | 快速修正 |
|------|---------|--------|
| 1. 用 NLH 眼光評估牌力 | 德州撲克習慣遷移 | 記住：奧馬哈需要 Nut 或接近 Nut 才能大注 |
| 2. 追 Non-Nut Draw | 不了解 Nut 的重要性 | 只追 Nut Draw 或 Near-Nut，Non-Nut 要折扣計算 |
| 3. 不保護強牌 | 德州撲克慢打習慣 | 濕潤翻牌永遠 Pot Bet，讓 Draw 付費 |
| 4. 錯誤計算 Outs | 忘記「必用 2 張」規則 | 每次計算前確認：選 2 張手牌 + 3 張公牌 |
| 5. 過度 Bluff | 德州撲克 Bluff 習慣 | 只在有 Nut Draw 支撐時 Semi-Bluff |

## 七、自我診斷清單

在每次奧馬哈決策前，問自己這些問題：

```
翻牌前：
□ 我的手牌是 A/B 級嗎？（如果是 C/D/F，考慮棄牌）
□ 我的手牌能做出 Nut draw 嗎？

翻牌後：
□ 我現在的牌型是 Nut 嗎？（如果不是，有多少人可能更強？）
□ 翻牌是乾燥還是濕潤的？（濕潤 = 我需要保護）
□ 如果我下注，被 Raise 時我怎麼辦？（是否有計劃）

面對下注：
□ 我有 Nut Draw 嗎？（有 → 考慮跟注；沒有 → 謹慎）
□ 我的 Equity 是否超過底池賠率？（< 33% 通常棄牌）
□ 如果我繼續，在河牌我是 Nut 嗎？

考慮 Bluff 時：
□ 我有 Semi-Bluff 支撐嗎？（Nut Draw？）
□ 這是單挑底池嗎？
□ 對手顯示弱勢嗎？
□ 如果對手 Call，我還有 equity 嗎？
```
