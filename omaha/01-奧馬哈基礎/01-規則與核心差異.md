# 奧馬哈基礎 01：規則與核心差異

> **學習目標**：理解奧馬哈的基本規則，掌握與德州撲克的根本差異，避免最常見的新手混淆。

---

## 一、奧馬哈基本規則

### 1.1 遊戲結構

奧馬哈（Omaha Hold'em）的牌局流程與德州撲克完全相同：

```
發牌前：
  盲注發放（小盲、大盲）

翻牌前（Pre-flop）：
  每位玩家獲得 4 張私人手牌（hole cards）
  一輪下注

翻牌（Flop）：
  發出 3 張公共牌（community cards）
  一輪下注

轉牌（Turn）：
  發出第 4 張公共牌
  一輪下注

河牌（River）：
  發出第 5 張公共牌
  最終下注

攤牌（Showdown）：
  比較牌力，最強牌型獲勝
```

### 1.2 核心規則：必須使用「剛好 2 張」手牌

這是奧馬哈最重要、最容易被忽視的規則：

> **你必須使用手牌中「剛好 2 張」+ 公共牌中「剛好 3 張」組成最終 5 張牌型。**

既不能用 1 張，也不能用 3 張，只能用「剛好 2 張」。

**例子 1：為什麼不能用 1 張**

```
你的手牌：A♠ K♥ 7♦ 2♣
公共牌：  A♥ A♦ A♣ 8♠ 9♠

你的牌型是什麼？

❌ 錯誤想法：我有 4 張 A，是四條！
✅ 正確答案：你只能用手中的 2 張。
   - 選 A♠ + K♥，搭配公共牌 A♥ + A♦ + A♣ → 四條 A，踢腳 K
   - 這才是合法的牌型。
   - 你不能只用 A♠ 一張手牌去配 4 張公牌（那樣就是用了 1 張手牌）。
```

**例子 2：為什麼不能用 3 張**

```
你的手牌：K♠ Q♠ J♠ T♠
公共牌：  A♠ 2♥ 5♦ 7♣ 9♣

你的牌型是什麼？

❌ 錯誤想法：我有同花 K♠Q♠J♠T♠ + A♠，是同花順！
✅ 正確答案：你只能用手中的 2 張。
   - 你最多能湊成：K♠Q♠（手牌 2 張）+ A♠（公牌）= 只有 3 張同花，不成順子
   - 最好的牌型大約是：K-Q-A-9-7（無對的高牌）
   - 注意：雖然你手中有 4 張同花，但公牌只有 1 張同花，加起來才 5 張，
     但你只能用手牌 2 張，所以只有 3 張同花，不成 flush。
```

## 二、奧馬哈 Hi 與 Hi/Lo 的區別

本教材主要討論 **奧馬哈 Hi（Omaha High）**。

| 項目 | Omaha Hi | Omaha Hi/Lo |
|------|----------|-------------|
| 獲勝條件 | 最強牌型獲全部底池 | 最強牌型拿 High，最低牌型拿 Low |
| Low 條件 | 無 | 需要 A-2-3-4-5 等 8 或以下 5 張不同牌 |
| 常見縮寫 | PLO | PLO8 / O8 |
| 線上 MTT 常見度 | 非常普遍 | 較少見 |
| 策略複雜度 | 高 | 更高（需同時考慮 High 和 Low） |

> **本教材專注 Omaha Hi（PLO）**，不涉及 Hi/Lo 策略。

## 三、與德州撲克的 5 大核心差異

### 差異 1：手牌數量（2 張 → 4 張）

```
德州撲克：手中 2 張，組合數 = C(2,2) = 1 種組合
奧馬哈：  手中 4 張，組合數 = C(4,2) = 6 種組合
```

這意味著奧馬哈玩家手中有 **6 倍**的兩張牌組合可以去搭配公共牌。結果是：

- 每個人都更容易配成強牌
- 平均攤牌牌力遠高於德州撲克
- 頂對（Top Pair）幾乎沒有獨立贏牌能力

**實際影響**：在奧馬哈，一局 9 人桌，攤牌時的平均最強牌型大約是「順子」，而德州撲克通常只需要「兩對」就能贏得多人底池。

---

### 差異 2：牌力通貨膨脹（Inflation of Hand Strength）

德州撲克 vs 奧馬哈的常見攤牌牌力比較（多人底池）：

| 牌型 | 德州撲克評估 | 奧馬哈評估 |
|------|-------------|-----------|
| 頂對頂踢腳 | 強（可以下注追值） | **極弱**（幾乎無法單獨獲利） |
| 兩對 | 很強 | **弱**（在多人底池容易輸） |
| 暗三條 | 非常強 | **中等偏強**（需要保護） |
| 順子 | 超強 | **中等**（非 nut 順子很危險） |
| 同花 | 超強 | **中等**（非 nut flush 危險） |
| 葫蘆 | 接近必贏 | **強，但仍需謹慎** |
| 四條 | 幾乎必贏 | **強** |

**關鍵認知**：在奧馬哈，你需要用**德州撲克再升一個等級**的標準來評估是否值得押注。

---

### 差異 3：起始牌協同性（Connectivity）的重要性大幅提升

德州撲克中，AA 的強大來自於它本身就是一對，而且是最大的對。

奧馬哈中，單純有一對 AA 不夠——你需要 **AA + 其他 2 張能配合的牌**。

```
比較：
AA72 rainbow（四種花色）→ B 級牌（AA 但其他牌無配合）
AKQJds（double-suited）→ A 級牌（雖然沒有對，但協同性極強）
```

**為什麼協同性重要**：奧馬哈翻牌後幾乎每個人都有 draw，單純有一對強牌在翻牌後容易被超越。你需要手牌能夠做出 **Nut draws（最強聽牌）**。

---

### 差異 4：同花聽牌的頻率與危險性

在德州撲克，有同花聽牌的手牌比例約 **24%**（9 outs）。

在奧馬哈，4 張手牌中更容易湊出同花聽牌：
- **Double-suited 手牌**（兩組同花）：非常常見，且同時擁有兩個同花聽牌可能
- **Single-suited 手牌**：至少有一個同花聽牌可能
- **Rainbow 手牌**：無同花聽牌（相對弱點）

奧馬哈的公共牌出現同花的機率，加上幾乎每個人都有潛在的同花聽牌，使得：

> **在奧馬哈，非最強同花（non-nut flush）的價值大幅下降。**

若你有 Q♠J♠ 聽到了 Q-高同花，但對手有 A♠X♠，你的同花毫無價值。

---

### 差異 5：下注限制（Pot Limit vs No Limit）

大多數奧馬哈以**底池限注（Pot Limit / PLO）**格式進行，而德州撲克多為**無限注（No Limit / NLH）**。

| 項目 | NLH | PLO |
|------|-----|-----|
| 最大下注 | 無限制（可全押） | 不超過當前底池 |
| 翻牌前全押 | 常見策略 | 很少，除非短疊 |
| 翻牌後全押速度 | 可一次達成 | 通常需要多輪下注 |
| Bluff 效果 | 可以大 bet 代表強牌 | 受限於底池大小 |
| 保護費用 | 可以超額下注保護 | 最多只能 pot bet |

**實際影響**：在 PLO 中，你無法像 NLH 一樣「超額下注」來折疊對手的 draw。最多只能 pot bet，所以對手的 draw 永遠有足夠的底池賠率去追牌。

## 四、常見混淆釋疑

### 混淆 Q1：「我手中有 4 張同花，是不是保證有同花？」

**答案：不一定。**

```
手牌：A♠ K♠ Q♠ J♠（4 張同花）
公牌：T♥ 8♣ 6♦ 4♥ 2♣（5 張全不同花）

你能做出同花嗎？
→ 你手牌只能選 2 張（如 A♠K♠），加上公牌 3 張，
  但公牌中沒有任何黑桃，所以你只有 2 張黑桃。
→ 無法成同花（需要 5 張同一花色）。
```

事實上，4 張同花手牌在奧馬哈被稱為 **「Single-suited only」**——你的 4 張都是同一花色反而是**壞事**，因為：
1. 你只有一個同花組合（A♠K♠），而不是兩個
2. 其他牌都浪費了花色資源
3. 對手持有同花時你的踢腳牌優勢消失

---

### 混淆 Q2：「我手中有 AAKK，是不是超強？」

**答案：中等，但被高估了。**

AAKK 在奧馬哈中的問題：
- 你有 6 個手牌組合：AA, AK×4, KK
- **AA 和 KK 「重疊」（blocking 效應）**：你手中有 2 張 A 和 2 張 K，對手就不可能有 AA 或 KK
- 在翻牌後，如果翻出 J♠T♦9♣，AAKK 毫無 draw 價值
- AAKK 的真正問題：**只有一種（或幾種）贏牌方式**

更強的牌是 AAKK double-suited（兩組同花），因為增加了 flush draw 的可能性。

---

### 混淆 Q3：「三條在奧馬哈是不是很強？」

**暗三條（Set）確實強，但不像德州撲克那麼絕對。**

```
在德州撲克：有 Set 幾乎可以 stack off（全押）
在奧馬哈：Set 需要謹慎對待

原因：
- 對手可能有 wrap + flush draw，equity 高達 40-50%
- 翻牌有同花時，Set 對同花聽牌的 equity 約 60% vs 40%
- 翻牌是兩同花三高牌時，Set 可能只有 55% equity
```

---

### 混淆 Q4：「德州撲克的 bluff 策略在奧馬哈有效嗎？」

**大幅降效，但不是完全無效。**

奧馬哈 bluff 困難的原因：
1. 每個人有 6 個手牌組合，更容易命中公共牌
2. 對手幾乎永遠有某種 draw 或 made hand
3. PLO 格式限制了 bluff 的下注大小（不能超額 bet）

奧馬哈中有效的 bluff 條件：
- **有 equity 的 semi-bluff**（你有 draw 時的下注）
- **對手位置不利（OOP）且顯示弱勢**
- **只有 1-2 名對手**（多人底池 bluff 幾乎無效）

## 五、奧馬哈牌力排行（與德州撲克相同，但實際強度不同）

牌型從強到弱（標準撲克牌型，奧馬哈亦同）：

```
1. 同花順（Straight Flush）    ← 奧馬哈中稱為「Nut straight flush」
2. 四條（Four of a Kind）
3. 葫蘆（Full House）          ← 奧馬哈攤牌相當常見
4. 同花（Flush）               ← 需要 Nut flush 才安全
5. 順子（Straight）            ← 需要 Nut straight 才安全
6. 三條（Three of a Kind）     ← 奧馬哈中較弱
7. 兩對（Two Pair）            ← 奧馬哈中很弱
8. 一對（One Pair）            ← 奧馬哈中幾乎無獨立贏牌能力
9. 高牌（High Card）           ← 幾乎不可能以此獲勝
```

**奧馬哈特別提醒**：
- **順子和同花必須是 Nut**：如果你的順子或同花不是最大的，很容易輸給更大的順子/同花
- **兩對通常不夠強**：在多人底池，兩對輸牌的概率非常高
- **一對幾乎永遠不夠強**：包括頂對頂踢腳（TPTK）

## 六、奧馬哈的正確學習心態

從德州撲克轉學奧馬哈的玩家最容易犯的思維錯誤：

### 思維 1：「我的牌很好，所以我要慢打」

在奧馬哈，**慢打強牌是危險的**。因為對手幾乎永遠有 draw，免費給牌只會讓他們免費配中。

### 思維 2：「我有頂對，我值得繼續跟注」

在奧馬哈，頂對在翻牌後的 equity 通常**低於 30%**（在多人底池中更低）。這是應該棄牌的邊界，不是繼續跟注的理由。

### 思維 3：「我有很多 outs，我要繼續」

重要：你必須確認自己的 outs 是**有效 outs**。如果你追的是 non-nut draw，即使命中，你也可能輸給更強的牌。

| 核心概念 | 重點 |
|----------|------|
| 規則 | 必須用**剛好 2 張**手牌 + **剛好 3 張**公牌 |
| 手牌數量 | 4 張手牌 = 6 種二牌組合 |
| 牌力通貨膨脹 | 奧馬哈攤牌牌型普遍強於德州撲克 |

| PLO 格式 | 最大下注受底池限制，bluff 難度高 |
