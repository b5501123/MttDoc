# 奧馬哈基礎 03：堅果概念（Nut Concept）

> **學習目標**：深刻理解「堅果（Nut）」在奧馬哈中的核心地位，掌握 Nut flush draw 與 Non-nut flush draw 的根本差異，建立「永遠向 Nuts 聽牌」的奧馬哈核心思維。

---

## 一、什麼是 Nut Hand？

**Nut hand**（堅果牌）指的是在當前公共牌面（board）上，所有玩家中**最強的可能牌型**。

### 1.1 Nut 的定義隨牌面而變化

```
公共牌：K♠ Q♥ J♦ T♠ 5♣

此牌面的 Nut hand = A-high straight（百老匯順子）
  → 持有 Ax + 9x（只需要 A 和 9 中的其中一張是手牌中的 A）
  → 注意：必須是 A + 9 各一張來自手牌

等等，稍微複雜：
  公共牌已有 K-Q-J-T，最強順子是 A-K-Q-J-T（百老匯）
  要做成百老匯：手牌必須有 A（配公牌 K-Q-J-T）
  → 但在奧馬哈，還要用 2 張手牌 + 3 張公牌
  → 所以你需要 A + 任意一張（配 K-Q-J-T 中的 3 張）

最終：手牌有 A♠X（X 為任意牌）→ 湊出 A-K-Q-J-T（Nut）
```

### 1.2 Nut 的層次

Nut 不只是最強牌，還有相對的「Nut 程度」：

```
第 1 Nut（絕對 Nut）：沒有任何手牌能打敗你
第 2 Nut（次強）：只有一種手牌組合能打敗你
第 3 Nut：有兩種手牌組合能打敗你
...
Non-nut：存在多種可能的更強牌型
```

在奧馬哈，**下注/跟注的強度應隨 Nut 程度而調整**：
- 第 1 Nut：可以全押
- 第 2-3 Nut：謹慎，視底池大小和對手行動
- Non-nut：通常只值得小注或棄牌

## 二、為什麼奧馬哈比德州撲克更強調 Nuts？

### 2.1 組合爆炸：每個人都更可能有強牌

德州撲克 2 張手牌的組合數 = C(2,2) = 1 種
奧馬哈 4 張手牌的組合數 = C(4,2) = 6 種

這意味著每個玩家都有 **6 倍**的機會湊出強牌。

**統計上的影響**：

```
德州撲克（9人桌）：
  至少有人有同花的概率 ≈ 低
  攤牌平均強度 ≈ 兩對

奧馬哈（9人桌）：
  至少有人有同花（如果有同花翻牌）≈ 高
  攤牌平均強度 ≈ 順子甚至葫蘆
```

### 2.2 「弱強牌」（Weak Strong Hand）的陷阱

在奧馬哈，存在一類「看起來很強但實際上不夠強」的牌型，稱為**弱強牌（Weak Made Hand）**：

```
情境：你有一個順子
公共牌：J♥ T♠ 9♣ 2♦ 5♥

你的手牌：K♠ Q♥ 8♦ 7♣
你做出的順子：K-Q-J-T-9 → 這是 K-high straight

問題：有沒有更強的順子？
  → 持有 Q-8（手牌）+ J-T-9 = Q-高順子（Q-J-T-9-8）... 等等，
    實際上最強順子是 K-high（KQJT9），你就是 Nut！

換一個情境：
公共牌：J♥ T♠ 9♣ 8♦ 2♥
你的手牌：8♠ 7♥ 6♦ 5♣
你做出：J-T-9-8-7... 等等，需要確認：
  你的 2 張手牌 + 3 張公牌：
  用 8♠7♥ 配 J♥T♠9♣ → 8-9-T-J-7？不對，順序：7-8-9-T-J = J-high straight

問題：最強順子是什麼？
  → 持有 QK 的人：K-Q-J-T-9 = K-high（更強！）
  → 持有 Q7 的人：用 Q-7 配 J-T-9：9-T-J-Q + 7 不成順子
                  用 Q-7 配其他：Q-J-T-9-8 = Q-high（更強）
  → 你的 J-high straight = Non-nut → 危險！
```

### 2.3 「一手牌的問題」原則

奧馬哈有一句經典格言：

> **「If it's not the nuts or the nut draw, it might be nothing.」**
> （如果不是堅果或堅果聽牌，可能什麼都不是。）

這不是字面意思上的「完全無用」，而是強調：

在奧馬哈的大注場景中，非 Nut 牌型的勝率往往**不足以支撐大額跟注**，因為有太多可能的更強牌型存在。

## 三、Nut Flush Draw vs Non-Nut Flush Draw

同花聽牌在奧馬哈中極為常見，但**品質**差異巨大。

### 3.1 Nut Flush Draw 的定義

**Nut flush draw**：你的同花聽牌中，如果命中，將做出該花色中最強的同花。

要有 Nut flush draw，你的兩張同花牌中**必須包含該花色的 A（Ace）**。

```
例子：公共牌有 2 張黑桃時

手牌：A♠ K♠（其他兩張不重要）
→ 你有 Nut flush draw（黑桃最強同花）
→ 如果翻牌有 Q♠ 5♠，你的 flush 是 A♠K♠Q♠5♠ + 另一張，A-high flush = Nut

手牌：K♠ Q♠
→ 你有 Non-nut flush draw（2nd nut）
→ 如果命中，你的最高同花是 K-high，但 A♠ 的人打敗你

手牌：T♠ 9♠
→ 你有 Non-nut flush draw（很危險的等級）
→ 如果命中，T-high flush 可能輸給 A♠、K♠、Q♠ 的玩家
```

### 3.2 Non-Nut Flush Draw 的危險性

**案例分析**：

```
情境：翻牌後
你的手牌：T♠ 9♠ 8♥ 7♥
公共牌：J♠ 5♠ 2♣

你有：
  - T♠9♠ = Non-nut flush draw（黑桃，但 T 高，有 A♠K♠Q♠J♠ 的人都打敗你）
  - T9 配 J 但還不成 made hand
  - T987 的 Wrap draw（更有價值的部分！）

如果你追求同花並命中：
  公共牌變成：J♠ 5♠ 2♣ K♠ X
  你的同花：T♠9♠ + J♠5♠2♣（選 3 張黑桃）= T-high flush

  任何有 A♠X♠、K♠X♠、Q♠X♠ 的對手都打敗你！
  → Non-nut flush 的勝率**低於你預期**

結論：T♠9♠ 的同花聽牌在這手牌中，不應該作為主要追牌目標
     T9 的 Wrap draw（通往 Nut straight）才是更有價值的方向
```

### 3.3 Nut Flush Draw 的溢價

| Flush Draw 類型 | 命中時的安全性 | 可下注/跟注的力度 |
|---------------|-------------|----------------|
| A 高 Nut flush draw | 高（沒有人能打敗你的 flush） | 可以全力追牌 |
| K 高 flush draw | 中（只輸給 A 高） | 中等力度 |
| Q 高 flush draw | 低（輸給 A 高和 K 高） | 謹慎 |
| J 高以下 | 極低 | 幾乎不應該以 flush 為目標 |

## 四、Wrap Straight Draw vs Non-Nut Straight Draw

### 4.1 什麼是 Wrap Draw？

**Wrap draw（環繞順子聽牌）** 是奧馬哈特有的概念，指你的手牌「環繞」著公共牌兩側，形成超過 8 個 outs 的順子聽牌。

```
標準 8-out open-ended straight draw（德州撲克常見）：
  公共牌有 J-T-9，你有 K-Q（手牌）
  缺 A → 成 AKQJT，或缺 8 → 成 QJT98
  = 8 個 outs（4個A + 4個8）

Wrap draw（奧馬哈特有）：
  公共牌有 J-T-9，你有 K-Q-8-7（手牌）
  可以：
    K♠Q♥ + J-T-9 → 需要 A 或 8 → 8 outs
    Q♥8♦ + J-T-9 → Q-J-T-9-8 = 成了！（Q 和 8 都在手中，Q 用了，9-J-T 公牌，只需 Q+8 → 已有！）

  等等，讓我重新算：
  手牌：K-Q-8-7，公共牌：J-T-9

  用 KQ 配 J-T-9：需要 A（做 AKQJT）或 8（做 QJJT8？不對）
                  實際上：Q-J-T-9 + K = KQJT9（K 高順子）？
                  或：K-Q + J-T-9 → 最長連線：9-T-J-Q-K（需要 8 配底部 or A 配頂部）

  用 Q8 配 J-T-9：Q-J-T-9-8（完成！5連牌全在公牌+手牌）= 已成順子
  用 K8 配 J-T-9：K-J-T-9-8（不連，K 和 8 中間有缺口）= 不成順子
  用 Q7 配 J-T-9：Q-J-T-9-7（不連）= 不成順子
  用 K7 配 J-T-9：= 不成順子
  用 87 配 J-T-9：8-9-T-J + 7（低端） = 7-8-9-T-J（已成！）= 已是 J-high straight

  所以 K-Q-8-7 手牌對 J-T-9 公牌的聽牌情況：
  已成牌：用 Q8 → Q-J-T-9-8 順子
         用 87 → 7-8-9-T-J 順子（同樣已成！）

  → 你已經有兩個 made straight，問題是哪個是 Nut？
  → J-high straight = QJJT9-8 → Q-high straight
  → J-high straight = 7-8-9-T-J → J-high straight

  最強的可能順子（公牌 JT9）：
  誰有 AK → A-K-Q-J-T → K-high（最強，百老匯相鄰）
  誰有 KQ → Q-J-T-K... 不對 → K-Q-J-T-9（K-high）
  誰有 KQ → KQJT9（K-high straight）= Nut straight

  你有 KQ → 你有 Nut straight！（K-Q-J-T-9）
```

讓我用一個更清晰的例子重新解釋 Wrap：

### 4.2 Wrap Draw 的清晰例子

```
公共牌：T♥ 9♠ 6♦（翻牌）
你的手牌：K♠ J♥ 8♣ 7♦

你有幾個 outs 做順子？

情況分析：
  用 J8 → 需要 公牌有連接 J..8：T-9 + 8 = 8-9-T-J（已有J，缺一個數字）
           實際上：J-T-9-8 + 7？不對
           用 J8 + T96：J-T-9 已有，8 在手，6 在公牌
           最強連線：J-T-9-8-7？7 不在公牌，但 7 在你手牌！
           用 J8 + T9 + 7（手牌）→ 你可以用 J+8（手牌）配 T-9-X（公牌）
           J-T-9-8... 需要第 5 張：要麼是 7（你有 7）或 Q（配頂部）
           實際組合：J♥8♣（手牌）+ T♥9♠6♦（公牌 3 張）→ 最大連線：J-T-9-8-6（不連）

好吧，讓我用更系統的方法：

公共牌：T-9-6
手牌：K-J-8-7

所有可能的 5 牌組合（選手牌 2 張 + 公牌 3 張）：
KJ + T96 → K-J-T-9-6（不成順）
K8 + T96 → K-8-T-9-6（不成順）
K7 + T96 → K-7-T-9-6（不成順）
J8 + T96 → J-8-T-9-6（不成順）
J7 + T96 → J-7-T-9-6（不成順）
87 + T96 → 8-7-T-9-6（不成順）

翻牌時暫時都不成順，但我們看 turn 需要什麼牌：

用 K-J 配 T-9-X：KJ + T9 + 需要 Q（KQJT9）或 8（JT98? 需要 Q 不對）
                  → 需要 Q 或 8（？）
                  K-Q-J-T-9：需要 Q（手牌沒有，希望公牌來 Q）→ 4 outs（4 張 Q）
                  J-T-9-8-？：J 和 T-9 有了，需要 8 在公牌 → 你手中有 8！→ J8（手牌）即可
                  → 實際上你用 J8（手牌 2 張）+ T-9-X 更好分析

讓我換一個更典型的 Wrap 例子：

公共牌：Q♥ J♠ 9♣
你的手牌：K♥ T♦ 8♠ 7♣

現在分析 outs：
需要什麼牌來完成順子？

用 KT + Q-J-9：K-Q-J-T-9（需要 T 在手牌，K 在手牌）→ 已成！K-high straight ✓
用 K8 + Q-J-9：K-Q-J-9-8（不連，QJ9 中間有 1 個缺口）→ 不成順子
用 K7 + Q-J-9：→ 不成順子
用 T8 + Q-J-9：T-9-8 + Q-J → Q-J-T-9-8（連！）→ 已成！Q-high straight ✓
用 T7 + Q-J-9：T-9-7 + Q-J → 不連（9-7 有缺口）→ 不成
用 87 + Q-J-9：8-7 + Q-J-9 → Q-J-9-8-7（連！）→ 已成！J-high straight ✓

所以你已有三個 made straight（K-high, Q-high, J-high）。
其中 K-high straight（KQJT9）= Nut straight（假設沒有更長的可能）

等等，有沒有比 KQJT9 更強的？
  有 A 的話：A-K-Q-J-T？需要 A 在公牌，但公牌是 Q-J-9，所以 T 需要從手牌來...
  A-K + Q-J-9 → 還需要 T，但 T 在公牌沒有...
  → 不可能比 KQJT9 更強（在這個公牌下）
  → 你的 KT（手牌）已做出 Nut straight！
```

### 4.3 各種 Wrap 的 Outs 數量

```
翻牌後的 Wrap draw outs 統計：

8 個 outs（標準 OESD）：
  情況：公共牌 T-9-8，你有 J-7（手牌）
  J + T-9-8 需要 Q（4 outs）→ Q-J-T-9-8
  7 + T-9-8 需要 6（4 outs）→ T-9-8-7-6
  總計：8 個 outs（OESD）

13 個 outs（標準 Wrap）：
  情況：公共牌 T-9-6，你有 J-8-7（實際是 3 張，選 2 張）
  → 需要重新計算（13-out wrap 的標準案例）

17 個 outs（強 Wrap）：
  情況：公共牌 T-9-X，手牌有 K-J-8-7
  → 做成 Nut 或接近 Nut 的 straight 有更多 outs

20 個 outs（最強 Wrap - Nut Wrap）：
  情況：公共牌 J-T-9，你有 K-Q-8-7（所有 4 張都連接公牌）
  K 搭配：K-Q-J-T-9 需要 Q（你有 Q！）→ 已成順子
  8-7 搭配：8-7-9-T-J → 7-8-9-T-J → 已成
  → 實際這是 Made hand，不是 draw

  最強 20-out wrap 的實際案例：
  公共牌：J-T-2（2 不連接）
  你的手牌：K-Q-9-8

  用 KQ + 任何 3 公牌：KQ + JT? 需要 A 或 9
                        → KQ + J-T-X：缺 A（4 outs）或 9（4 outs）
  用 K9 + JT？：不好分析
  用 Q9 + JT2：Q-J-T-9 + 8？8 不在公牌
                Q-J-T-9 + Q（你用了）= Q-J-T-9 需要 8（另一個 8）
  用 98 + JT？：9-8 配 J-T-X：9-T-J + 8-7？缺 7 or 缺高端

  更典型的 20-out wrap：
  公共牌：Q-J-7（rainbow）
  手牌：K-T-9-8

  用 KT + QJ7：K-Q-J-T-? 需要 9（4 outs）→ K-Q-J-T-9
  用 T9 + QJ7：T-9 + Q-J-? 需要 K（4 outs）→ K-Q-J-T-9，或需要 8（4 outs）→ J-T-9-8-?，
               實際上 T-9 配 Q-J：T-Q-J-9 需要 K（做 KQJT9）或 8（做 QJT98）
  用 K9 + QJ7：K-Q-J-9 需要 T（4 outs）→ K-Q-J-T-9（等等，9 在手 T 不在，需要 T 在公牌）
  用 T8 + QJ7：T-8 + Q-J：Q-J-T-9-8 需要 9（4 outs）
  用 98 + QJ7：Q-J-9-8 需要 T（4 outs）

  總 outs：K（4）+ A（4）+ T（4）+ 8（4）+ 6（4）= 20 outs（去掉重複計算）

  → 20-out wrap 是奧馬哈最強的順子聽牌！
```

### 4.4 Outs 計算實際應用表

| Wrap 類型 | Outs 數 | 命中概率（翻轉牌+河牌） | 備注 |
|----------|---------|-------------------|------|
| 標準 OESD | 8 | 32% | 最低等級 |
| 13-out wrap | 13 | 49% | 高於 50/50 |
| 17-out wrap | 17 | 62% | 高 equity |
| 20-out wrap | 20 | 70% | 壓倒性優勢 |

> **注意**：Nut flush draw（9 outs）+ 20-out wrap 的**組合** outs 理論上可達 29 outs，但需去掉重複（某些牌既是 flush out 又是 straight out），實際通常約 20-25 個有效 outs。

## 五、「Drawing to the Nuts」的核心思維

### 5.1 原則：每一步都問自己「我在聽什麼？」

奧馬哈的正確思維模式：

```
❌ 德州撲克思維（錯誤遷移）：
「我有好牌，我要繼續。」

✅ 奧馬哈核心思維：
「我現在的牌能做出什麼 Nut？」
「如果我中了，我是 Nut 嗎？」
「如果不是 Nut，有多少玩家可能有更強的牌？」
```

### 5.2 三個關鍵問題

每次面對下注決定，問這三個問題：

**問題 1：我現在是不是 Nut？**
- 是：考慮如何最大化贏得籌碼
- 否：進入問題 2

**問題 2：我有沒有 Nut draw？**
- 有：評估 outs、pot odds，決定是否值得追
- 沒有：進入問題 3

**問題 3：我的 equity 足夠嗎？**
- 計算對手可能有的牌型範圍
- 如果 equity 低於底池賠率，考慮棄牌

### 5.3 實際案例：Nut 思維的應用

```
情境設定：
你的手牌：J♠ T♠ 9♥ 8♥（JT98 double-suited）
翻牌：Q♠ 7♠ 2♥

你有什麼？

同花聽牌分析：
  J♠T♠ + Q♠7♠ → 已有 4 張黑桃！等待第 5 張 = Flush draw
  但 J♠T♠ = J 高黑桃，非 Nut（A♠ 在某人手中可能）
  → Non-nut flush draw（危險信號）

  9♥8♥ + 2♥ → 已有 3 張紅心，等待第 4、5 張 = Flush draw
  → 9 高紅心，完全 Non-nut（危險）

順子聽牌分析：
  J-T-9-8 + Q：J-T-9-8 已有，Q 在公牌 → Q-J-T-9-8 = 已成！Q-high straight

  但 Q-high straight 是 Nut 嗎？
  有人有 KJ 嗎？ K-Q-J-T（缺 9）... 公牌有 Q，手牌 KJ，公牌再來 9 → K-Q-J-T-9（更強！）
  有人有 K 和 J？他們需要 T-9 → T-9 在你手中，你 block 了一些

  結論：Q-high straight 不一定是 Nut！
  → 你的 Non-nut made hand 面臨風險

正確評估：
  - 你有一個 Q-high straight（可能是 Nut，可能不是）
  - 你有 Non-nut flush draws（危險）
  - Wrap draws：J-T-9-8 配 Q-7-2，其實你已成順子了

  如果對手在這個翻牌大力下注（甚至 Pot bet），你的 Q-high straight 在 4 way pot 中：
  → 謹慎！非 Nut 的 Q-high straight 在多人底池很危險
  → 如果對手有 KJ 或更強的 Set，你處於劣勢
```

## 六、Nut 概念的實戰應用

### 6.1 Nut 聽牌 vs Made Hand 的優先級

```
情況 A：你有 Nut Flush Draw + 現在無 Made Hand
  → 積極 semi-bluff，因為命中後是 Nut（完全 safe）

情況 B：你有 Nut Straight（Made）
  → 積極下注，但注意是否有 flush 可能打敗你

情況 C：你有 Non-nut Made Hand（如 Q-high straight）
  → 謹慎，根據底池大小和對手行動評估

情況 D：你有 Non-nut Flush Draw + Non-nut Straight
  → 通常應該棄牌或只做小跟注
  → 命中後仍可能輸（Double non-nut draw）
```

### 6.2 「Nut blocker」的概念

擁有某張牌，意味著你「阻斷（block）」了對手做出 Nut 的可能性。

```
公共牌：A♠ K♠ Q♠ J♦ T♣

可能的 Nut：
  - A-high straight flush（A♠ K♠ Q♠ J♠ T♠）→ 需要 J♠T♠ 在手
  - Royal flush（同上）

如果你手中有 A♠，你：
  1. 確認自己不可能輸給更強的 flush（因為 A♠ 在你手中）
  2. 阻斷了對手做 Nut flush（他們需要 A♠，但 A♠ 在你手中）
  → 這是 Nut blocker 的防守效果

如果你手中有 J♠T♠（Royal flush draw 的關鍵牌）：
  → 你的 flush 是 J-high flush（Non-nut）
  → 但你同時 block 了對手做 Royal flush 的可能性
  → 這就是 Nut blocker 的複雜性：有時 Nut blocker 讓你更安全 bluff
```

---

## 七、章節總結

| 核心概念 | 要點 |
|---------|------|
| Nut Hand | 當前牌面上最強的可能牌型 |
| Nut Flush Draw | 必須持有 A（該花色），命中後無法被同花打敗 |
| Non-nut Flush Draw | 命中後仍可能輸給更高的同花，風險極高 |
| Wrap Draw | 環繞型順子聽牌，最多 20 outs（奧馬哈特有）|
| Drawing to Nuts | 永遠以追求 Nut 為目標的核心思維 |
| Nut Blocker | 你手中的牌阻斷了對手做 Nut 的可能性 |

**奧馬哈黃金法則**：
> 在考慮任何跟注或加注之前，先問：「如果我中了，我是 Nut 嗎？如果不是，有多少人可能打敗我？」
