# 奧馬哈基礎 02：手牌評估

> **學習目標**：掌握評估奧馬哈起始牌的 4 個維度，建立系統性的選牌標準，區分強牌弱牌，避免用德州撲克的直覺誤判奧馬哈手牌。

---

## 一、為什麼奧馬哈手牌評估更複雜？

德州撲克起始牌評估相對直觀：AA > KK > QQ > AKs > AKo……主要看牌面大小和是否同花。

奧馬哈則完全不同。一手看起來很好的牌（如 A♠A♥7♦2♣）可能實際上表現平庸，而一手看起來中等的牌（如 9♠8♠7♥6♥）可能是非常強的起始牌。

原因在於：**奧馬哈翻牌後的大量 drawing**。你的手牌不只是「現在有什麼」，更重要的是「能做出什麼 Nut draws」。

---

## 二、手牌評估的 4 個維度

### 維度 1：連接性（Connectivity）

連接性指手牌中各張牌之間的數字距離，直接決定你能否做出強 Wrap draw（環繞型順子聽牌）。

**連接性等級**：

```
完美連接（Perfect Rundown）：
AKQJ, KQJT, QJT9, JT98, T987, 9876, 8765...
→ 4 張連續，可以產生最多種 wrap draws

缺口連接（Gapped Rundown）：
AKQ9, KQJT（一個缺口）
→ 仍然很強，只是 wrap outs 稍微少一些

雙缺口（Double Gapped）：
AKQ8, JT86
→ 連接性減弱，draw 的可能性降低

無連接（Disconnected）：
AK52, AJ73
→ 沒有 wrap draw 可能性
```

**評分標準**：
| 連接類型 | 評分 |
|---------|------|
| 完美 4 連牌 | +3 |
| 1 個缺口 | +2 |
| 2 個缺口 | +1 |
| 3 個以上缺口 | 0 |
| 完全不連接 | -1 |

---

### 維度 2：同花性（Suitedness）

同花性決定你是否能做出 Flush draw，以及是否能做出 **Nut flush draw**。

```
Double-suited（雙同花）：兩組同花對
  例：A♠K♥Q♠J♥（黑桃對 + 紅心對）
  → 最佳，可同時有兩個不同花色的 flush draw

Single-suited（單同花）：一組同花對
  例：A♠K♠Q♥J♦（只有黑桃對）
  → 良好，有一個 flush draw 機會

Triple-suited（三同色）：三張相同花色（不好！）
  例：A♠K♠Q♠J♥
  → 較差，只有一個有效 flush draw（第三張同花是「浪費」）

Rainbow（彩虹/四色）：四張不同花色
  例：A♠K♥Q♦J♣
  → 最差，完全沒有 flush draw 機會
```

**為什麼 Triple-suited 比 Double-suited 差？**

Triple-suited（三同花）：
- 你用 A♠K♠ 聽 flush：有效
- 你用 A♠Q♠ 聽 flush：有效
- 你用 K♠Q♠ 聽 flush：有效
- **但你只有 3 張黑桃在手，多餘的第三張沒有配對**
- 而且公牌出現同花時，你的 flush draw 所用的兩張手牌與第三張「衝突」

Double-suited（雙同花）：
- 你用 A♠K♠ 聽黑桃 flush
- 你用 Q♥J♥ 聽紅心 flush
- **兩個獨立的 flush draw 機會，效率最高**

**評分標準**：
| 同花類型 | 評分 |
|---------|------|
| Double-suited（含 A 同花） | +3 |
| Double-suited（不含 A） | +2 |
| Single-suited（含 A 同花） | +1 |
| Single-suited（不含 A） | 0 |
| Triple-suited | -1 |
| Rainbow | -2 |

---

### 維度 3：對子（Pairs）

手牌中有對子代表翻牌後有更高機率做出「Set（暗三條）」，Set 是奧馬哈中非常強的牌型。

```
AA（一對 A）：
  → 有天然的大對，翻牌後可能直接有 Overpair
  → 配合其他好牌時是頂級起始牌

KK, QQ, JJ, TT：
  → 強對，但需要其他牌配合

低對（22-99）：
  → 主要價值是翻出 Set
  → 單獨的低對沒有太多獨立價值
```

**重要**：在奧馬哈，一對 AA 搭配無用的其他牌（如 AA72），實際上比許多看起來更小的牌差。

**評分標準**：
| 對子類型 | 評分 |
|---------|------|
| AA | +3 |
| KK, QQ | +2 |
| JJ, TT | +1 |
| 99 以下 | 0（除非搭配連牌）|
| 手中有兩對但都不大 | +1（兩組 Set 機會） |

---

### 維度 4：高牌（High Cards）

高牌代表你能做出高的 Straight 或 Top Pair（雖然 Top Pair 在奧馬哈相對弱，但高順子比低順子強）。

奧馬哈中最重要的高牌是 **A**：
- A 是最高 Straight 的必備牌（AKQJT 百老匯順子）
- A 是 Nut Flush 的必備牌
- A 配成 AA 是最強的對子

**高牌價值**：
```
A：最高價值
K：高價值（特別是配合 A 時）
Q, J：中等價值
T, 9, 8：在連牌中有很好的連接價值
7 以下：主要靠連接性，單張低牌沒有獨立高牌價值
```

## 三、好手牌的特徵

一手理想的奧馬哈起始牌應該具備以下特徵：

### 特徵 1：能做出 Nut Flush Draw

你的同花應該包含 A 或 K（對應花色的最高或次高牌）。

```
✅ 好的 flush draw 基礎：
A♠K♠ → Nut flush draw（最強同花聽牌）
A♠Q♠ → Nut flush draw
A♠2♠ → Nut flush draw（但 A♠ 的 kicker 2♠ 是浪費）

❌ 危險的 flush draw 基礎：
J♠T♠ → Non-nut flush draw（如果 A♠ 或 K♠ 在公牌上，你輸）
9♠8♠ → Non-nut flush draw（更危險）
```

### 特徵 2：能做出 Nut Straight（或 Wrap Draw）

你的連牌應該能做出最強的順子。

```
✅ Nut Straight 能力強：
AKQJ → 能做出 AKQJT（最強順子）
QJT9 → 翻牌 KQJ 時你有 AKQJT 的 Nut straight draw
JT98 → 多種 wrap draw，且通常是 Nut 或接近 Nut

❌ Non-nut Straight 風險：
5432 → 低位順子，容易被高位順子覆蓋
7654 → 中低位順子，中風險
```

### 特徵 3：多條 Nut Draw 路線

最好的手牌有**兩條以上**同時追求不同 Nut 的路線。

```
理想例子：A♠K♠Q♥J♥（AKQJ double-suited）
  路線 1：黑桃 Nut flush（A♠K♠ 聽黑桃）
  路線 2：紅心 Nut flush（Q♥J♥ 聽紅心）
  路線 3：百老匯順子（A-K-Q-J-T）
  路線 4：多種 Wrap draws（KQJT, QJT9 等）
  → 4 條路線，每條都能做出 Nut！
```

### 特徵 4：手牌之間沒有「浪費牌（Dangling Card）」

Dangling card 是指手牌中與其他 3 張完全不連接、也不同花的牌，完全浪費一個手牌位置。

```
❌ 有 Dangling Card 的手牌：
A♠K♠Q♥ **2♦** → 2♦ 完全不配合，它：
  - 不幫助同花（不是黑桃也不是紅心）
  - 不幫助順子（2 太低，完全脫離 AKQJ 的連線）
  - 只是浪費一個手牌位置

✅ 無 Dangling Card 的手牌：
A♠K♠Q♥J♥ → 每張牌都有作用
  - A♠K♠：黑桃同花組
  - Q♥J♥：紅心同花組
  - AKQJ：順子基礎
```

## 四、壞手牌的特徵

### 特徵 1：有 Dangling Card（浪費牌）

已如上述，手牌中有 1 張完全不配合的牌，等於在打 3 張牌。

### 特徵 2：手牌重複（Suit/Number Duplication）

```
❌ 花色重複（Triple/Quadruple suited）：
A♠K♠Q♠J♥ → 三張黑桃，一個 flush draw 卻佔了 3 個位置

❌ 數字重複（Blocking your own outs）：
A♠A♥A♦K♣ → 三張 A！這意味著：
  - 公牌只剩 1 張 A，你做出四條的機率極低
  - 你已經有 3 個「A 的 outs」被自己擋住了
  - 對手同樣很少有 AA，缺少價值型的 double-up 機會
```

### 特徵 3：Non-nut 只能做出低位 Flush 或順子

如果你的手牌只能做出 7-高同花或 6-高順子，你贏牌時的底池往往很小（因為對手沒有強牌），但輸牌時的底池可能很大（因為對手有更強的同花或順子）。

### 特徵 4：無連接且無大對（Pure Garbage）

```
最差類型例子：
K♠9♥5♦2♣ → Rainbow，無連接，無對，甚至 K 單獨也很弱
J♠7♥4♦2♣ → 完全的廢牌

這類手牌應該在任何位置直接棄牌。
```

## 五、手牌評估打分表（A/B/C/D/F 分級）

### A 級手牌（必打，任何位置）

**特徵**：AA double-suited、AKQJ double-suited、高位連牌 double-suited

| 手牌例子 | 說明 |
|---------|------|
| A♠A♥K♠Q♥（AA double-suited, connected） | 頂級起始牌 |
| A♠A♥K♥J♥（AA single-suited, connected） | 強起始牌 |
| A♠K♠Q♥J♥（AKQJ double-suited） | 四色協同最強 |
| A♠K♥Q♠J♥（AKQJ double-suited 另一種） | 同等強度 |
| K♠K♥Q♠J♥（KK double-suited, connected） | 高強度起始牌 |
| J♠T♠9♥8♥（JT98 double-suited） | 強連牌雙同花 |
| Q♠J♠T♥9♥（QJTS double-suited） | 高連牌雙同花 |

---

### B 級手牌（強牌，多數位置可打）

**特徵**：AA 但協同性一般、中位連牌 double-suited、高位連牌 single-suited

| 手牌例子 | 說明 |
|---------|------|
| A♠A♥K♦Q♣（AA, connected, rainbow） | AA 但無同花 |
| A♠A♥J♦T♣（AA, connected, rainbow） | AA 但無同花 |
| K♠K♥Q♠J♦（KK single-suited, connected） | KK 但只有一個同花 |
| Q♠J♠T♥9♦（QJTS single-suited） | 高連牌但只有一個同花 |
| T♠9♠8♥7♥（T987 double-suited） | 中位連牌雙同花 |
| A♠K♠Q♦J♣（AKQ 單同花，有 gap） | 高牌連線但不夠完美 |
| J♠T♥9♠8♥（JT98 double-suited，另一種排列） | 雙同花連牌 |

---

### C 級手牌（可打，需要位置配合）

**特徵**：中位連牌 single-suited、AA 但協同性差、有一個缺口的高連牌

| 手牌例子 | 說明 |
|---------|------|
| A♠A♥7♦2♣（AA, no connectivity） | AA 但其他牌無配合 |
| 9♠8♠7♥6♦（9876 single-suited） | 中位連牌但只有一同花 |
| K♠Q♠J♦9♣（KQJ9，一個缺口） | 有缺口但仍有價值 |
| A♠K♠J♦T♣（AKJT，中間缺口） | Nut flush + 有缺口連牌 |
| Q♠Q♥J♠T♣（QQ connected single-suited） | 中強對子有連牌 |

---

### D 級手牌（弱牌，只在有利位置考慮）

**特徵**：低位連牌、有兩個以上缺口、大對但協同性很差

| 手牌例子 | 說明 |
|---------|------|
| 6♠5♠4♥3♥（6543 double-suited） | 低位連牌，做出非 Nut |
| A♠A♥3♦2♣（AA, very weak other cards） | AA 但有 dangling cards |
| K♠9♠8♦7♣（大缺口 + 中位連牌） | 缺口太大 |
| Q♠J♦9♣7♥（多缺口，rainbow） | 多缺口無配合 |
| J♠T♦8♣6♥（雙缺口，無同花） | 太多缺口 |

---

### F 級手牌（直接棄牌）

**特徵**：無連接、無高對、rainbow、有 dangling cards

| 手牌例子 | 說明 |
|---------|------|
| K♠9♥5♦2♣ | 完全無配合 |
| Q♠8♥4♦2♣ | 廢牌 |
| J♠7♥3♦3♣（低對且無連接） | 低對配廢牌 |
| A♠7♥4♦2♣（A 配三張廢牌） | A 很有價值，但其他太差 |
| T♠6♥3♦2♣ | 明顯廢牌 |

## 六、特殊評估案例分析

### 案例 1：AAKK vs AKQJ（有趣的比較）

```
AAKK（兩個大對）：
+ 有兩個 Set 機會（AA 翻 A，KK 翻 K）
+ AA 是最強對子
- 手中有 2A + 2K，阻斷了對手的 AA/KK
- 翻牌後如果不中 Set，只有 Overpair
- 沒有強 Wrap draw 能力
→ 評級：B+（但被高估）

AKQJ double-suited：
+ Nut Flush draw（最強同花）×2
+ Nut Straight draw（百老匯）
+ 多種 Wrap draws（KQJT, QJT9...）
+ 每張牌都有作用，無浪費
→ 評級：A（被低估）
```

**結論**：AKQJ double-suited 在長期 EV 上很可能強於 AAKK rainbow。

---

### 案例 2：同位連牌的同花比較

```
QJT9 double-suited：
  翻牌前 Equity vs 隨機對手：約 54%（平均）
  可能的 Nut draws：Nut flush ×2，多種 Wrap

QJT9 single-suited：
  翻牌前 Equity vs 隨機對手：約 50%（平均）
  可能的 Nut draws：Nut flush ×1，多種 Wrap

QJT9 rainbow：
  翻牌前 Equity vs 隨機對手：約 46%（平均）
  可能的 Nut draws：多種 Wrap（無 Flush）
```

**Double-suited 的溢價**：同一連牌，double-suited 比 rainbow 翻牌前 equity 高約 8%，這是非常顯著的差異。

---

### 案例 3：「看起來強但其實弱」的手牌

```
A♠A♥A♦K♣（三張 A）：
問題：
  - 三張 A 意味著你自己擋住了自己的 Set out
  - 理論上 AA 的 Set out（第四張 A）只剩 1 張
  - 對手很少有 AA，所以 Stack off 機會少
  - K 單獨一張，flush draw 需要公牌出現 3 張同花（K 不 Nut flush）
評級：C（看起來是 A 實際上是 C）

A♠K♠K♥Q♥（AK + KQ，有重複）：
問題：
  - K 在手中重複（2 張 K），一方面增加 Set 機會，
    但也意味著 K 高牌做順子時會有限制
  - A♠K♠ 的 Nut flush + Q♥K♥ 的 Non-nut flush（K 不是 Nut heart flush）
評級：B-
```

## 七、快速評估流程（翻牌前決策參考）

當你看到手牌時，按照以下步驟快速評估：

```
步驟 1：有 AA 嗎？
  → 是：自動加分，但看其他 3 張是否有配合
  → 否：進入步驟 2

步驟 2：是 double-suited 嗎？
  → 是：加分，特別是有 A 的同花組
  → 否：是否 single-suited？
  → Rainbow：扣分

步驟 3：連接性如何？
  → 4 連牌（rundown）：加分
  → 有缺口：視缺口大小
  → 無連接：扣分

步驟 4：有沒有 dangling card？
  → 有：重大扣分（實際上只有 3 張牌在發揮）

步驟 5：這手牌能做出 Nut 嗎？
  → 能做 Nut flush + Nut straight：好牌
  → 只能做 Non-nut：危險
  → 完全不能做 Nut draw：棄牌
```

## 八、章節總結

| 評估維度 | 最佳情況 | 最差情況 |
|---------|---------|---------|
| 連接性 | 4 連牌（無缺口 rundown） | 完全不連接 |
| 同花性 | Double-suited（含 A 同花） | Rainbow |
| 對子 | AA（配合好牌） | 低對（無連接） |
| 高牌 | A + 高連牌 | 低位無連牌 |

**記住**：奧馬哈選牌的核心問題不是「現在牌大不大」，而是「這手牌能做出什麼 **Nut draws**？」
