# 奧馬哈 MTT 翻牌後場景分析

本章節透過五個完整的翻牌後場景，系統性地解析 PLO MTT 翻牌後決策的核心思維。每個場景均包含手牌強度分析、Outs 計算、bet/check 決策、sizing 選擇，以及轉牌和河牌的計劃。

---

## 場景 1：持有 A♠K♠Q♦J♣，翻牌 T♠9♥2♠（OESD + nut flush draw）

### 場景設定

- **賽事階段**：常規賽段
- **有效籌碼**：80bb（你），90bb（對手）
- **底池**：14bb（3-bet 底池，HU，你在 OOP）
- **你的位置**：SB（OOP）
- **對手位置**：BTN（IP）
- **手牌**：A♠K♠Q♦J♣
- **翻牌**：T♠9♥2♠

---

### 手牌強度分析

A♠K♠Q♦J♣ 在翻牌 T♠9♥2♠ 上有以下 made hand 和 draw：

**Made Hands（現有牌力）**
- 目前沒有成牌（no pair, no straight, no flush）
- 僅有高牌（A♠K♠Q♦J♣ 的高牌組合）

**Draw 組合（潛在牌力）**

*Nut Straight Draw（堅果順子 draw）*
- 你有 AKQJ + 翻牌 T9：已完成 AKQJT（Royal Straight）！
- 等等，讓我重新計算：
  - A♠K♠Q♦J♣ + T♠9♥2♠ 的 best 5-card hand？
  - PLO 規則：必須使用恰好 2 張手牌 + 3 張公共牌
  - 使用 KQ + T92 = K high，無用
  - 使用 QJ + T9X = 需要再一張配對
  - 使用 AK + T92 = A high，無用
  - **最佳 draw**：使用 Q♦J♣ + T♠9♥ = QJT9 (需要 K 或 8 完成順子)
  - 使用 KJ + T9 = KJT9（需要 Q 或 8）
  - 使用 KQ + T9 = KQT9（需要 J 或 8）

*OESD（Open-ended Straight Draw）*
- Q♦J♣ 搭配 T♠9♥：QJTS9，需要 K 或 8 完成 KQJT9 或 QJT98
- A♠K♠ 搭配 T♠9♥ 的各種組合：尋找 Q 或 J 相關順子
- **最強 draw**：QJ + T9 = OESD（任何 K 或 8 都能完成頂級順子）

*Nut Flush Draw*
- A♠K♠ + 翻牌 T♠2♠ = 四張 spade，一張到 nut flush！
- 這是最高等級的 flush draw（Ace-high spades）
- 需要任何第五張 spade 在轉牌或河牌出現

**Outs 計算**

*Nut Flush Draw outs*：
- 已用 spades：A♠、K♠、T♠、2♠ = 4 張
- 剩餘 spades：13 - 4 = 9 張 spade outs

*OESD outs（順子 draw）*：
- Q♦J♣ + T♠9♥：需要 K 或 8
- K 的 outs：4 張（扣除 K♠ 已計入 flush draw = 3 張新 outs）
- 8 的 outs：4 張
- 純 straight outs：3 + 4 = 7 張（扣除與 flush 重疊的）

*總 clean outs（不重複計算）*：
- Flush outs：9
- Additional straight outs（非 spade）：7
- **合計約 15-16 個 outs**

**Equity 計算**
- 轉牌前（2 張牌待出）：16 outs × 4% = 約 64% 贏率
- 僅看轉牌（1 張牌）：16 × 2% = 約 32% 命中率
- 這是極強的 draw，equity 接近甚至超過許多 made hands

---

### Bet / Check 決策

**OOP 的 c-bet 決策**

在 OOP 的 3-bet 底池，你有兩個主要選擇：

**選項 A：Donk bet / Lead bet（主動出牌）**
- 你是翻牌前的 aggressor（3-better），可以選擇主動出牌
- 有 64% equity 的強 draw + 有 fold equity 的情況下，lead 是合理的

**選項 B：Check-raise（check 後反加注）**
- Check 給對手機會 c-bet，你再 check-raise
- Check-raise 的效果：建立更大底池、施加更大壓力
- 風險：對手可能 check back（你損失一輪 bet 機會）

**最優決策：Check-raise**

在 OOP 3-bet 底池，check-raise 通常優於直接 lead：

理由：
1. 對手在 IP 幾乎 100% 會 c-bet（他有位置優勢和 range 優勢）
2. Check-raise 建立更大底池（你的 draw 值得大底池）
3. Check-raise 對對手施加更大壓力（迫使他用弱 hand 做決定）
4. Check-raise 隱藏手牌強度（對手無法確定你有 made hand 還是 draw）

---

### Sizing 建議

**Check-raise sizing**

底池目前 14bb，對手 c-bet 假設 9bb（約 65% pot）：

- 你的 check-raise：pot raise = 14 + 9 + 9 = 32bb × 3 = raise to 約 45-50bb
- 或者 check-raise all-in（若底池夠大）

**All-in 計算**
- 你的 stack：80bb
- 底池：14bb + 9bb（對手 c-bet）= 23bb
- Check-raise to all-in：23bb + 57bb（你剩餘 stack）= 80bb all-in
- 這是 semi-bluff all-in，你有 64% equity 支持這個決定

**為何 all-in 是最優 sizing？**
1. 你有 nut flush draw + OESD，有清晰的 equity 優勢
2. All-in 消除對手在轉牌的選擇（不給他免費看牌）
3. 你的 fold equity 讓 all-in 即使被 call 也有 64% 贏率
4. 在 PLO 中，nut draw 的 semi-bluff all-in 是標準操作

---

### 轉牌 / 河牌計劃

**若沒有 all-in（call + 繼續 betting）**

轉牌 Hit（flush 或 straight 完成）：
- Spade 轉牌（flush 完成）：bet pot，對手很可能 call（他可能有 made hand）
- K 或 8 轉牌（straight 完成）：bet pot，同樣積極

轉牌 Blank（miss）：
- 如果對手 call 了 check-raise，你仍有 32% 命中率（約 16 outs on river）
- 選擇：check-call 或 semi-bluff 繼續（取決於對手的 calling tendency）
- 河牌 miss：check-fold 或 bluff（根據對手 fold frequency 決定）

**關鍵思考點**
- 你的 nut draw 在 all-in 後是 64% 贏率，這是正 EV 的 all-in
- 不要讓對手免費看轉牌/河牌，那對你最不利
- 強 draw 應該用來建立大底池，而非 pot-controlling

## 場景 2：持有 Q♠Q♦J♣T♦，翻牌 Q♥8♥7♦（頂對 + draw 的保護問題）

### 場景設定

- **賽事階段**：常規賽段，中期
- **有效籌碼**：65bb（你），70bb（對手）
- **底池**：9bb（3-way：你 OOP，CO IP，BTN IP）
- **手牌**：Q♠Q♦J♣T♦
- **翻牌**：Q♥8♥7♦

---

### 手牌強度分析

Q♠Q♦J♣T♦ 在翻牌 Q♥8♥7♦ 上有以下牌力：

**Made Hand：頂點三條（Top Set）**
- 使用 Q♠Q♦ + Q♥8♥7♦ 的 Q♥ = 三條 QQQ
- 這是頂點三條，是翻牌上最強的 made hand（除了 quads）
- 在 PLO 中，set 是極強的翻牌手牌

**附加 Draws**
- J♣T♦ + 8♥7♦：JT87 的部分組合
- JT 搭配 87：可以組成 J-T-9-8-7 順子（需要 9）
- T♦ 搭配 8♥7♦（翻牌）：需要 9 和 J 完成 7-8-9-T-J 順子
- **Gutshot straight draw**：需要 9 完成 Q♥8♥7♦ + JT = J T 9 8 7（使用 JT 手牌）

**最大威脅分析**
翻牌 Q♥8♥7♦ 的危險性：

*Heart Flush Draw*：
- 任何持有 A♥x♥ 的對手有 nut flush draw
- 翻牌上有兩張 heart，轉牌出現 heart 的概率 = 9/47 ≈ 19%
- 兩條街都有 heart：約 34%

*Straight Draw*：
- 翻牌 Q87，持有 JT 的對手有 OESD（需要 9 或 J）
- 持有 T9 的對手有 OESD（需要 J 或 6）
- 持有 J9 的對手有 gutshot（需要 T）
- **最危險**：JT9x 的對手有超強 wrap draw

*Full House Draw（Full House 的威脅）*：
- 你有 set，但對手若有 88 或 77，他們有下點三條
- 若出現配對的公共牌（如 Q♥8♥7♦ 後出現第二個 8 或 7），對手可能成 full house

---

### 保護策略分析

**為何保護至關重要**

在 PLO 中，set 雖強，但在危險 board 上需要保護：
- 翻牌 Q♥8♥7♦ 有大量 draw 可能
- 在三人底池（3-way），draw 的免費看牌概率更高
- 你需要讓 draw 「付錢」看轉牌

**保護 vs. 慢玩（Slow Play）的比較**

*Slow Play（check-raise 計劃）*：
- 優點：讓對手建立底池，然後 check-raise 贏更多
- 缺點：給 draw 免費看牌，失去 equity 保護

*立即 Pot Bet（保護）*：
- 優點：讓 draw 付錢，保護你的 equity
- 缺點：可能讓對手 fold，贏不到更多籌碼

**在 3-way 底池的正確選擇**

在多人底池，保護遠比慢玩重要：
- 3 個對手各自可能有 draw
- 給所有人免費看牌的概率損失超過慢玩的收益
- **最優決策：Pot bet（約 9bb = 100% 底池）**

---

### Bet / Check 決策

**OOP 在 3-way 底池的 Pot Bet**

底池 9bb，你 OOP，兩個 IP 對手：

**決策：Pot bet 9bb**

理由：
1. **Draw-heavy board**：Q♥8♥7♦ 有大量 flush 和 straight draws
2. **3-way 底池**：更多對手 = 更高 draw 概率
3. **Top set 值得最大 protection**：你有最強的 made hand，應該積極建底池
4. **讓 draw 付高昂成本**：pot bet 讓 draw 的賠率（odds）不划算

**Sizing 深度思考**

為何選擇 pot bet 而非 half-pot？
- Half-pot（4.5bb）：給 flush draw 賠率 2:1（大約 9 outs = 約 4:1 可能性，實際稍有利）
- Pot bet（9bb）：給 flush draw 賠率 2:1（底池 18bb，call 9bb = 2:1 賠率）
- 計算：flush draw 的正確賠率約 4:1，pot bet 讓他們 call 是虧損的

**面對 raise 的應對**

若對手 raise（可能有 straight + flush combo draw）：
- 你有 top set，equity 通常仍在 50%+ 以上
- 可以 3-bet 或 call，視 stack 深度
- 若 re-raise all-in：call，你的 set 有足夠 equity

---

### 具體 Outs 計算（對手視角，你需要知道）

**假設對手有 J♥T♥9x（wrap + flush draw）**

J♥T♥ + 翻牌 Q♥8♥7♦：
- Flush draw（heart）：9 outs（9 hearts remaining）
- Straight outs：
  - J-T + Q87：需要 9 或 6 完成各種順子
  - 使用 JT + Q87 中的 87：需要 9 完成 JT987（T9876 使用 T9 不行）
  - 更精確計算：JT 搭配 Q87 的 wrap 包括多個版本
- 假設對手有約 15-17 個 outs

**你 top set 對 draw 的 equity**
- Top set vs. 15 outs（2 streets remaining）：約 56% 贏率
- Top set vs. 17 outs：約 51% 贏率
- 你仍是邊緣優勢，但確保讓 draw 付錢

---

### 轉牌 / 河牌計劃

**轉牌計劃**

*好的轉牌（保護你的 set）*：
- 配對公共牌（如 Q、8、7 的另一張）：你成 full house，極強
- 非心 / 非直牌的 blank（如 A♣、K♠）：你的 set 仍領先，繼續 pot bet

*危險的轉牌*：
- Heart 出現：可能有人完成 flush，你需要重新評估
  - 若你有 Q♠ of set，心花 board 讓你需要看 betting
  - 若對手 check，可能是在慢玩 flush？謹慎
- 9 出現（如 9♣）：可能完成 JT9 的 straight，危險
  - 若對手 bet，評估是否是 made straight 還是 continue bluff
  - 你仍有 full house outs（配對公共牌）

*轉牌 strategy*：
- Hit board（對子出現）：bet pot，繼續建底池
- Flush/straight complete card：謹慎 bet，根據對手反應判斷

**河牌計劃**

*你的 full house 完成（公共牌配對）*：
- River bet pot，盡量榨取最大 value
- 對手的 flush/straight 遇到你的 full house = 大贏

*River 無配對，board 保持原樣*：
- 你的 set 可能仍是最強 made hand
- Value bet 約 70-80% pot，不要 overbet（對手可能 fold）

*River 有 flush/straight 完成牌*：
- 根據對手之前的 betting 判斷
- 若對手在 draw card 出現後大 bet：可能有 made draw
- 若對手 check：可能沒有或在慢玩，謹慎出牌

## 場景 3：持有 A♦A♣7♥6♦，翻牌 K♥J♠T♥（AA 在危險 board）

### 場景設定

- **賽事階段**：中期賽段
- **有效籌碼**：95bb（你），100bb（對手）
- **底池**：20bb（3-bet 底池，HU，你在 OOP）
- **手牌**：A♦A♣7♥6♦
- **翻牌**：K♥J♠T♥

---

### 手牌強度分析

A♦A♣7♥6♦ 在翻牌 K♥J♠T♥ 上的評估：

**Made Hand 評估**
- 使用 A♦A♣ + KJT 的 K：你有頂頂對（AA with K on board）
- 但等等：你的 AA 是「只是一對 Aces」，在 KJT board 上非常脆弱
- 翻牌 KJT 是 PLO 中最危險的 board 之一

**你的 Draw 分析**
- A♦ + 7♥6♦ 的組合：
  - 使用 A♦ + 7♥：有 A7 high，無特別 draw
  - A♦A♣ + KJT = 只是一對 Aces（無 straight 或 flush draw）
  - 7♥6♦ 在 KJT board 上：幾乎無用
- **你沒有任何顯著的 draw**：只有純粹的 AA 一對

**Board 的危險性評估**

翻牌 K♥J♠T♥ 對你的威脅：

*Straight Possibilities*：
- AQJ 的人有 Broadway（AKQJT）順子！
- QJT 的人有 KQJT9 的 OESD（one end）
- QJ 搭配 KT：AKQJT 需要 A
- **最危險**：任何持有 QX 的對手有潛在 Broadway draw

*Flush Draw（Heart）*：
- 任何 A♥x♥ 的對手有 nut flush draw（你的 A♦A♣ 沒有 heart）
- 你沒有 heart，無法阻擋 flush 完成

*Made Straight 可能*：
- 若對手有 AQ（任意花色）：AQ + KJT = **已完成 Broadway！**
- 若對手有 QJ：需要 A 或 9 完成，但 AQ + KJT 更危險
- **若對手有 AQ，你的 AA 已經輸了！**

**Equity 評估**
- AA（no draw） vs. KJT board：
  - vs. 已完成 straight（AQ）：約 10-15%（需要 full house）
  - vs. strong draw（QJT9 wrap + flush）：約 35-40%
  - vs. BTN 整體 3-bet calling range：約 30-35%

---

### 關鍵決策：如何打？

**情況評估**

你的 AA 在 KJT 翻牌上面臨嚴峻挑戰：
1. 你沒有 nut straight draw
2. 你沒有 heart flush draw（無法阻擋 flush）
3. 對手的 3-bet calling range 在 KJT 上 hit 率極高
4. 你的 equity 可能只有 30-35%

**選項分析**

*選項 A：Pot bet（激進出牌）*
- 優點：有 fold equity（對手可能 fold draws）
- 缺點：若對手 raise，你需要在 30-35% equity 下做決定
- 適合：確信對手 range 以 draw 為主，而非 made hands

*選項 B：Check-call（被動防守）*
- 優點：控制底池大小，避免在 bad spot 投入太多籌碼
- 缺點：給 draw 免費看牌（如果對手 check back）
- 適合：你對手牌強度有疑慮，想控制底池

*選項 C：Check-fold（放棄）*
- 優點：保留籌碼用於更好的機會
- 缺點：可能放棄還有機會的手牌

**最優決策：Check-call（謹慎打法）**

在危險 board K♥J♠T♥ 上，OOP 持有 AA（無 draw）的最優策略是 check-call：

理由：
1. **不要在劣勢位置建大底池**：你的 equity 約 30-35%，pot bet + call 是虧損的
2. **保持底池控制**：check 讓你控制每條街投入多少
3. **收集資訊**：對手的翻牌行動提供重要 range 資訊
4. **等待 blank 轉牌**：非配對、非 heart、非 Q/9 的轉牌改善你的局面

---

### Outs 計算（你需要改善的牌）

**你的 AA 改善需要什麼？**

*Full House outs（讓你的 AA 變成 full house）*：
- 公共牌出現 A（另一張 A）：不可能（你已有 2 張 A，牌堆只剩 2 張 A）
- 公共牌配對（K、J 或 T 再出現）：
  - K out：3 張（已有 K♥，還有 3 張 K）
  - J out：3 張（已有 J♠，還有 3 張 J）
  - T out：3 張（已有 T♥，還有 3 張 T）
  - 總計：9 個 outs → 你的 AA 成為 AAK/J/T full house

*Runner-Runner 可能性（需要 2 張特定牌）*：
- A♦ 翻牌（成四條）：幾乎不可能（只剩 2 張 A）
- 其他 runner-runner：機率極低

**實際 equity 計算**
- 你有約 9 個 outs（配對公共牌成 full house）
- 9 outs × 4%（2 streets）= 約 36% 贏率
- 但部分 outs 重疊（對手有 KK 或 JJ 時你仍輸），淨 equity 約 25-30%

---

### 轉牌計劃

**好的轉牌**
- K、J 或 T 出現（配對）：你有 full house！積極出牌
- 非 heart、非 Q、非 9 的 blank 牌（如 2、3、4、5）：
  - 對手的 draw 仍未完成，你仍在 30-35% equity
  - 繼續 check-call（不要建大底池）

**危險的轉牌**
- Heart 出現（如 4♥）：可能完成 flush，你無 heart，equity 急劇下降 → check-fold
- Q 出現：可能完成 Broadway（AQ + KJT + Q = 已完成），你幾乎 folding
- 9 出現：完成更多順子可能性（KJT + Q9 = KQJT9）

**轉牌後的主要問題**

若轉牌是 blank，對手 bet：
- 你的 check-call 決定需要分析底池賠率
- 底池 20bb + 你 check + 對手 bet 10bb = 底池 30bb，你 call 10bb = 3:1 賠率
- 你約 28% equity（9 outs × 2 streets 的轉牌版本）
- 3:1 賠率 = 你需要 25% equity → 勉強可以 call
- 但若對手過牌更大，可能需要 fold

---

### 河牌計劃

**若 full house 完成（公共牌配對）**
- 大 value bet：約 70-80% pot
- 這是你最強的牌，盡量榨取

**若 full house 未完成，board 保持原樣**
- 你的 AA 在危險 board 上很可能輸
- Check-fold 或 thin call（根據底池賠率）

**本場景核心教訓**

AA 在 PLO 中並非「永遠最強」。在危險 board（如 KJT）上，AA 沒有 draw 且很可能已落後。正確策略是：
1. 控制底池（check-call 而非 bet-call）
2. 等待改善（full house outs）
3. 在明顯落後時勇敢 fold

## 場景 4：多人底池（3-way），持有 9♠8♠7♦6♦，翻牌 T♠5♠2♣（OOP 打法）

### 場景設定

- **賽事階段**：常規賽段
- **有效籌碼**：70bb（你），75bb（CO），80bb（BTN）
- **底池**：15bb（3-way 底池：你 OOP，CO IP，BTN IP）
- **你的位置**：SB（OOP）
- **手牌**：9♠8♠7♦6♦
- **翻牌**：T♠5♠2♣

---

### 手牌強度分析

9♠8♠7♦6♦ 在翻牌 T♠5♠2♣ 上：

**Made Hand 評估**
- 無 made hand（no pair, no straight, no flush yet）
- 但擁有強力的 draw combination

**Draw 分析**

*Wrap Straight Draw（超強順子 draw）*：
- 9♠8♠7♦6♦ + T♠5♠2♣ 翻牌
- 使用 9♦8♠（或 9♠8♦）+ T♠5♠ 的 T：
  - 9876 + T（10）= T9876，需要 J 完成 JT987 或 T9876
  - 使用 7♦6♦ + T5 = 7654T 區間
  - 更精確：98 搭配 T = 需要 J 或 7 完成 JT987 或 T9876
  - 76 搭配 T5 = 需要 8 或 9 完成 98765 或 87654
- **Wrap analysis**：你有 J、9、8、7 都能完成至少一種順子
  - J：完成 JT987（使用 98 + T）
  - 9：完成 T987X（使用 987 + T）
  - 8：完成 98765（使用 876 + 5）
  - 7：完成 87654（使用 76 + 5）—— 但只用了翻牌中的 5，OK？
  - 計算後約 13-15 個 straight outs

*Nut Flush Draw（Spade）*：
- 9♠8♠ + T♠2♠（翻牌）= 4 張 spades = nut flush draw！
- 9 個 spade outs（13 - 4 = 9）
- 這是 9-high spade flush（非 nut，但很強）

**總 Outs 估算**

*Spade flush outs*：9
*Straight outs*（非 spade）：約 8-10（扣除與 flush 重疊的）
*合計約 17-19 個 outs*

**Equity 計算**
- 17 outs × 4% = 68% 贏率（2 streets）
- 這是極強的 drawing hand，幾乎與 made hand 持平

---

### OOP 3-way 底池的決策難題

**OOP 的特殊挑戰**

在 OOP 的 3-way 底池，你面臨：
1. 你先行動（每條街都在最不利位置）
2. 你沒有 made hand（只有 draw）
3. 兩個 IP 對手可能各自有不同的 made hands 或 draws

**選項分析**

*選項 A：Donk Bet（主動出牌）*
- 在 3-way 底池 OOP，donk bet 有一定合理性
- 你的 draw 有 68% equity，值得積極出牌
- Donk bet 可以讓你建立底池，並對 IP 對手施壓

*選項 B：Check-raise*
- Check → 等一個 IP 對手 bet → raise
- 風險：兩個 IP 對手都 check back（你損失一輪 bet）
- 在 3-way 底池，至少有一個對手 c-bet 的概率很高

*選項 C：Check-call*
- 被動接受對手的 bet
- 優點：保留 stack，看轉牌
- 缺點：給另一個 IP 對手免費看牌（若他在第一個 IP check-call 後 overcall）

**最優決策：Check-raise（對第一個 bettor）**

在 OOP 3-way，check-raise 是最優策略：

理由：
1. **Squeeze 效果**：check-raise 可以 fold out 第三個玩家（BTN），讓你 HU 打
2. **建立大底池**：你的 68% equity 值得大底池
3. **施壓策略**：check-raise 隱藏手牌強度（對手不知道你是 draw 還是 made hand）
4. **Fold equity**：讓 made hands 付出巨大代價，或直接 fold

---

### Sizing 建議

**Check-raise sizing 計算**

假設 CO c-bet 10bb（底池 15bb + 10bb = 25bb）：

- Minimum check-raise：25bb（底池大小）
- Pot-size check-raise：(15 + 10 + 10) × 2.5 = 約 87.5bb（接近 all-in）
- 最優 sizing：check-raise to 35-45bb（約 3.5x 對手的 c-bet）

**為何選擇中等大小 check-raise？**
- 太小（25bb）：給對手和 BTN 良好賠率繼續
- 太大（all-in）：只能 fold 出所有對手，贏不到 value
- 中等（35-45bb）：對手面臨困難選擇，你的 draw 仍有改善機會

---

### 轉牌 / 河牌計劃

**轉牌計劃（若 check-raise 被 call，1 對 1 繼續）**

*命中 flush 或 straight*：
- Bet pot（約 80-100bb 的底池）
- 你的 made hand 極強，榨取最大 value

*Blank 轉牌（miss）*：
- 仍有約 32% river hit（17 outs × 2%）
- 選擇：continue bluff（semi-bluff）或 check
- 若 IP 對手 stack 約 30-40bb，可以 all-in semi-bluff
- 若對手 stack 仍很深，check-call 更保守

**河牌計劃**

*Hit*：bet pot，value bet
*Miss*：
- 評估底池賠率
- 若底池大，偶爾 bluff（若對手 fold frequency 高）
- 通常 check-fold（draw miss = 無 showdown value）

## 場景 5：Bubble 情境，持有 Set（777），翻牌有 Flush Draw，是否 Pot Bet 保護

### 場景設定

- **賽事階段**：Bubble（最後 5 人出局即進錢圈）
- **有效籌碼**：45bb（你），60bb（對手 CO），90bb（BTN 大疊）
- **底池**：12bb（3-way：你在 SB OOP，CO IP，BTN IP）
- **手牌**：7♥7♦5♣4♠（含 77 的手牌，以下省略雜牌）
- **翻牌**：7♠K♥J♥（三條 777 + heart flush draw on board）

---

### 手牌強度分析

7♥7♦5♣4♠ 在翻牌 7♠K♥J♥ 上：

**Made Hand：底點三條（Bottom Set）**

- 使用 7♥7♦ + 公共牌 7♠ = 三條 777（Bottom Set）
- 在翻牌上有三條是極強的 made hand

**弱點分析**

*Board Texture（牌面質地）*：
- K♥J♥ 提供了心花 flush draw
- 任何持有 A♥x♥ 或 Q♥T♥ 的對手有強力 flush draw
- K♥J♥ 也有 K、J 高牌，可能配合直牌形成順子 draw

*Flush Draw 的威脅*：
- Nut flush draw（A♥x♥）：約 9 outs，下一條街命中率 19%
- 2 streets 命中率：約 35%
- 你的 set 在 flush 完成後輸掉（除非你能成 full house）

**Full House Outs（保護你的 set）**

你的 set 改善成 full house 的條件：
- 公共牌配對（K 或 J 再出現）：
  - K out：3 張（已有 K♥，還有 3 張 K）
  - J out：3 張（已有 J♥，還有 3 張 J）
  - 7 out：1 張（已有 3 張 7，最後 1 張 7♣）
  - 總計：7 個 full house outs

*Equity vs. Flush Draw*：
- 你的 set vs. 9-out flush draw：
  - 你的 full house outs = 7（約 14% 一條街）
  - 對手的 flush outs = 9（約 19% 一條街）
  - 你在翻牌後仍是 equity 領先（約 60% 贏率 2 streets）

---

### Bubble 特殊考量

**Bubble 情境的額外壓力**

在 bubble 情境，ICM 考量重新排序你的優先級：
1. 對手（60bb）接近「對你有威脅」的大小，若輸掉你剩約 5bb
2. BTN（90bb）是大疊，可以 cover 你

**Bubble 的 Pot Bet 爭議**

*理由 A：應該 Pot Bet 保護*
- 你有 top set，draw-heavy board
- Pot bet 讓 flush draw 付出高昂代價
- 你的 equity 優勢 justifies 建大底池

*理由 B：應該控制底池（Bubble ICM）*
- 你有 45bb，輸掉此底池 = 出局 or 極短疊
- Bubble 情境讓每個 all-in 的 ICM EV 大幅減少
- 若對手 raise all-in，你在 60% equity 下 call 是 ICM -EV？

---

### 數學分析：Pot Bet vs. Small Bet

**情境計算**

*底池：12bb，你的 stack：45bb，對手 CO stack：60bb*

**方案一：Pot Bet 12bb**

- 若對手 fold：你贏 12bb
- 若對手 raise all-in 到 45bb（你 all-in）：
  - 底池 = 12 + 45 + 45 = 102bb
  - 你有 60% equity → EV = 102 × 0.60 - 45 = 16.2bb（chip EV +EV）
  - ICM 折算後（bubble）：EV 縮減，可能變成 ICM +EV 或 -EV

**方案二：Small Bet 6bb（半底池）**

- 若對手 fold：贏 12bb
- 若對手 raise：你面對更小的 all-in（對手可以 3-bet to 20bb）
- 更小的底池 = 更小的 ICM 風險

**結論：在 Bubble，應選擇中等 bet（約 2/3 pot = 8bb）**

理由：
1. **有保護效果**：8bb 讓 flush draw 賠率不划算（賠率 2.5:1，flush draw 需要 4.2:1 才有利）
2. **控制底池規模**：不是 pot bet，降低 all-in 概率
3. **保留選項**：若對手 raise，你可以 fold 或 call 根據情況

---

### 最終決策：Bet 8bb（2/3 pot，Bubble 版本）

**最優決策：Bet 8bb**

在 Bubble 情境，持有 bottom set 在 heart-draw board 上：

1. **出牌保護**：給 flush draw 不划算的賠率
2. **中等 sizing**：避免過大 pot 引發的 ICM 問題
3. **收集資訊**：對手的反應（call/raise/fold）提供 range 資訊

**面對 Raise 的應對**

*若 CO raise to 25bb*：
- 你剩餘 stack = 45 - 8 = 37bb
- Call 25bb = 剩 20bb，底池很大
- 你的 equity 約 60%，ICM 折算後可能 close to break-even
- **建議：Call**（你有 60% equity，不應 fold top set）

*若 BTN 過牌追加（squeez）*：
- BTN（90bb）的 raise 表示很強（set+ 或 made straight）
- 重新評估你的 equity
- 若 BTN 有 AA 或 KK，你只有 full house outs

**若沒有 raise（CO call，BTN fold）**

轉牌計劃：
- *Heart 出現*：謹慎，check-call 或 small bet（對手可能已完成 flush）
- *Non-heart blank*：繼續 bet 2/3 pot，保護
- *K 或 J（公共牌配對）*：你成 full house，積極 bet pot

---

### Bubble 特殊場景總結

**關鍵問題：Bubble 是否改變 set 的打法？**

**答案：Bubble 讓你的 bet sizing 更保守，但不改變「出牌」的決定。**

- 非 bubble：pot bet 保護（12bb）
- Bubble：中等 bet 保護（8bb）
- 兩種情況都選擇「出牌」，差異只在 sizing

**何時 Bubble 下應該 check（而非 bet）？**

1. 你的 set 是 bottom set，board 極度危險（如 KQJ 彩虹 + flush）
2. 對手傾向過激的 raise-bluff（你可以 check-raise trap）
3. 你的 stack 很淺（< 20bb），all-in 風險超過 check 的損失

## 翻牌後決策的核心原則

### 原則一：Equity 決定積極性

在 PLO 中，翻牌後的主要指標是 equity：
- > 60% equity：積極出牌，建大底池（semi-bluff all-in 可行）
- 50-60% equity：中等積極性（pot bet 或 check-raise）
- 40-50% equity：謹慎（check-call 或 small bet）
- < 40% equity：被動防守或 fold

### 原則二：Board Texture 決定保護需求

- **Draw-heavy board**（如 K♥J♥T♠）：需要保護，積極出牌
- **Dry board**（如 K♣5♦2♠）：可以慢玩，build pot slowly
- **Monotone board**（如 K♥Q♥J♥）：極度謹慎，高度危險

### 原則三：位置影響策略選擇

- **IP（後位）**：可以更靈活地 check-back 控制底池，或積極出牌
- **OOP（前位）**：傾向 lead bet 或 check-raise，避免被動 check-call

### 原則四：Bubble / ICM 調整 Sizing，不改變方向

- 應該出牌的手牌在 bubble 仍應出牌
- 差異在於：sizing 更保守（2/3 pot 而非 pot bet）
- 目標是保護 equity 同時控制 ICM 風險

### 原則五：在 PLO 中，Set 比 NLH 更需要保護

PLO 玩家常犯的錯誤是「慢玩 set」，但在 PLO 中：
- Draw-heavy board 讓 set 在 2-3 個對手下急劇貶值
- Flush 和 straight 在 PLO 中完成率遠高於 NLH
- Set 需要主動建底池、保護 equity，而非慢玩等待 full house
