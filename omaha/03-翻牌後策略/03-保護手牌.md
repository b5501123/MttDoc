# 翻牌後策略 03：保護手牌

> **學習目標**：理解為何奧馬哈比德州撲克更需要積極保護強牌，掌握何時使用 Pot bet、Check-raise，以及多人底池中的保護策略。

---

## 一、奧馬哈中保護的重要性：為什麼和德州撲克不同？

### 1.1 德州撲克 vs 奧馬哈的保護需求對比

**德州撲克的情境**：

```
你有 Set（暗三條），翻牌是 K♠ 7♥ 2♦（乾燥翻牌）
對手一：有 KQ（頂對）
對手二：有 AJ（無配對）

你的 Set 對頂對：約 90% equity
→ 即使讓對手免費看一張，你幾乎不受影響
→ 可以考慮 slow play（慢打），讓對手繼續建底池
```

**奧馬哈的情境**：

```
你有 Set（暗三條），翻牌是 K♠ 7♥ 2♦（看似乾燥）
對手一：有 A♥K♦Q♣J♠（有 K，有 AKQ 的 wrap draw 可能）
對手二：有 T♠9♠8♦7♣（連牌，有 wrap draw）

你的 Set 對「對手一」的 K-pair + draw：可能 60-70%
你的 Set 對「對手二」的 wrap draw：可能 65%
兩人同時對抗：你的 equity ≈ 45-55%（在多人底池中）

結論：即使你有 Set，在奧馬哈多人底池中你常常不到 60% equity！
→ 你**必須**讓對手付費才能看下一張牌
→ 免費看牌讓每個人都有機會免費超越你
```

### 1.2 奧馬哈的核心保護觀念

> **奧馬哈的強牌需要「收費」才能讓其他人看下一張牌。**

原因：
1. **每個人有 6 個手牌組合**，更容易命中翻牌
2. **Wrap draw 可以有 20 outs**，比德州撲克的 8 outs 多得多
3. **Draw vs Set 的 equity 差距小**：Set（60%）vs 20-out wrap + flush（40%+）
4. **PLO 格式**：最大下注被限制在底池，你無法用 3x pot bet 驅逐 draw

## 二、Set 在奧馬哈：為何也需要保護？

### 2.1 Set 的 Equity 在不同翻牌上的變化

```
翻牌 A：K♠ 7♦ 2♣（Rainbow 乾燥翻牌）
  你的 Set of 7（7♦7♣在手）：
  對抗單一對手（AKQJ rainbow）：約 80% equity
  對抗兩個對手（AKQJ + T987）：約 60% equity

翻牌 B：K♠ 7♠ J♦（Two-Tone，單張同花）
  你的 Set of 7：
  對抗有 flush draw 的對手（A♠X♠）：約 68% equity
  對抗有 wrap draw 的對手（T987）：約 62% equity
  兩人同時：約 45% equity！

翻牌 C：K♠ 7♠ J♠（Monotone 翻牌）
  你的 Set of 7：
  任何有 2 張黑桃的對手（已成 Flush）= 你輸！
  → 在 Monotone 翻牌，Set 需要更謹慎評估
  → 如果你沒有任何黑桃，你的 Set 在 Monotone 翻牌面臨「已成 Flush」的威脅
```

### 2.2 Set 面對威脅翻牌的保護策略

```
原則：翻牌越「濕潤」，越需要積極保護 Set

乾燥翻牌（Rainbow + 不連接）：
  → Set 相對安全，但在多人底池仍需 bet
  → 建議：1/2 pot 到 pot bet，讓 draw 付出代價

中等翻牌（Two-Tone 或有連牌）：
  → Set 需要積極保護
  → 建議：Pot bet（滿底池下注）讓 draw 沒有好的賠率

濕潤翻牌（Two-Tone + 連牌）：
  → Set 必須 Pot bet
  → 考慮是否需要 Check-raise 來提高底池並測試對手

Monotone 翻牌：
  → 你沒有同花牌：謹慎，甚至可能棄牌（Set 面對 Flush 很弱）
  → 你有 Nut flush（A 同花）：積極，你有最強的牌型
```

## 三、何時使用 Pot Bet 保護？

### 3.1 Pot Bet 的計算

在 PLO 中，Pot bet 是最大允許的下注額：

```
Pot bet 計算：
  底池 = P，你要下注 X
  Pot bet 公式：X = P（底池）+ 2 × 你的跟注（call）部分

  例子（翻牌後你先行動）：
  底池：30bb，你先行動
  Pot bet = 30bb（直接下底池的大小）
  → 你下注 30bb

  例子（你跟注後再 pot raise）：
  底池：30bb，對手下注 20bb
  你要 pot raise：
    底池現在 = 30 + 20 = 50bb（算上對手的注）
    你的跟注 = 20bb
    Pot raise = 50 + 20 = 70bb（= 底池 + 你的跟注 × 2）
    等等：Pot Limit raise 計算 = Call + Pot after call
    = 20（跟注）+ 70（底池加上跟注後）= 90bb？

  標準 PLO Pot Raise 公式：
    Call 金額 = C
    Raise to = 3C + 現有底池

    例：底池 30bb，對手 bet 20bb
    C = 20
    Raise to = 3 × 20 + 30 = 60 + 30 = 90bb（這是「pot raise」的大小）
    → 你加注到 90bb（對手的 20bb 算在內）
```

### 3.2 使用 Pot Bet 的情況

```
必須 Pot Bet 的情況：

1. 濕潤翻牌 + 你有強 made hand（如 Set, Straight, Flush）
   理由：讓 draw 沒有足夠的底池賠率去追牌

2. 多人底池 + 任何強牌
   理由：多人底池中 draw 的 equity 疊加，你需要盡快建立更大的底池

3. Monotone 翻牌 + 你有 Nut Flush
   理由：讓其他人的 Flush draw 付費，你的 Nut 確保你贏

4. 翻牌後你的 equity 明顯領先但不穩定
   理由：盡快在你領先時「收割」

例子：
  你：A♣ K♦ A♥ Q♣（AAKQ）
  公牌：A♠ T♦ 9♠（你中了 Top Set，三條 A）
  底池：30bb，多人底池

  你的行動：
  ✅ Pot bet（30bb）
  理由：
    - 公牌 T-9 有連線，任何有 J-Q 或 Q-8 的人有 wrap draw
    - 公牌 A♠ 和 9♠ = 兩張黑桃，有 flush draw 可能
    - 你的 Set of A 需要保護
    - 在多人底池，讓所有人免費看轉牌風險太高
```

### 3.3 不需要 Pot Bet 的情況

```
可以考慮小注（1/2 pot 或更小）或 Check 的情況：

1. 超乾燥翻牌 + 你有絕對 Nuts（如葫蘆、四條）
   理由：對手幾乎沒有任何 draw，small bet 更有可能得到 call

2. 單挑底池 + 你有大幅領先
   理由：單挑時 small bet 可以建底池，對手很難有大 draw

3. 你想要 slow play（讓對手 bluff 或建底池）
   理由：特殊情況，但奧馬哈要謹慎慢打

注意：在奧馬哈，「慢打」的風險遠高於德州撲克。
     大多數情況下，有強牌就應該積極下注。
```

## 四、Check-Raise 在奧馬哈的重要性

### 4.1 Check-Raise 的目的

**Check-Raise（先過牌再加注）** 在奧馬哈中比德州撲克更常見，原因是：

1. **OOP 玩家的工具**：前位玩家（OOP）先 Check，讓後位玩家 Bet，然後加注
2. **保護強牌的武器**：Check 誘使對手 Bet，然後用加注建立更大底池
3. **Semi-bluff 工具**：有 Nut draw 時，Check-raise 可以折疊對手的弱牌或 Non-Nut draw
4. **信息收集**：Check-raise 測試對手對自己加注的反應，獲取信息

### 4.2 Check-Raise 的最佳時機

```
時機 1：OOP 持有強 made hand，翻牌相對乾燥

情境：
  你在 BB（OOP），持有 K♠K♦Q♠J♦（KK double-suited）
  翻牌：K♥ 7♣ 2♦（你中了 Top Set）
  對手（BTN）在你後面

  策略：Check（假裝弱），等待 BTN bet
  → BTN bet（在後位，常見 c-bet）
  → 你 Pot Raise（Check-Raise）
  → 目的：建立更大底池，測試對手手牌強度
  → 如果 BTN 有 AK 或 draw，他可能 3-bet，你可以更進一步

  為什麼不直接 Pot bet？
  → 乾燥翻牌上直接 Pot bet（OOP）常常讓對手 fold（因為弱牌在乾燥翻牌不願跟注）
  → Check-Raise 讓對手有機會 bet，然後你加注建更大底池
```

```
時機 2：濕潤翻牌，你 OOP 持有 Nut Draw

情境：
  你在 SB（OOP），持有 A♠K♠Q♥J♥（AKQJ double-suited）
  翻牌：T♠9♠3♦（兩張黑桃，你有 Nut flush draw！）

  策略：Check（等待對手行動）
  → 對手（CO 或 BTN）Bet（他可能有 made hand 或 Draw）
  → 你 Pot Raise（Check-Raise semi-bluff）

  理由：
  → 你有 Nut flush draw（9 outs），命中後是最強 flush
  → 你有 Wrap draw（KQJ 配 T9）
  → Check-Raise 讓你的 Draw 獲得「折疊 equity」（對手可能直接 fold）
  → 即使對手 call，你的 Nut draw 有很高命中率
```

```
時機 3：多人底池，你有強 made hand，翻牌有 draw

情境：
  你在 UTG+1（OOP），持有 9♦9♣8♠7♦（9987）
  翻牌：9♥ 6♦ 3♠（你中了 Top Set of 9）
  3 人底池（底池 30bb）

  問題：翻牌 9-6-3，有潛在的 wrap draw（87, 54 等人有 draw）
  策略選擇：
  A）直接 Pot bet → 清楚表示強牌，對 draw 施壓
  B）Check-Raise → 等後位玩家 Bet，然後 Pot Raise

  在多人底池，A 方案更常用（直接 Pot bet）
  B 方案適合你確信後位玩家一定會 Bet 的情況

  選擇 A 的理由：
  → 多人底池中，有人可能直接 Bet 很大（你的 Check 讓後位有主動權）
  → Check-Raise 後，如果第三個玩家已 Bet，加注更複雜
  → 直接 Pot bet 簡單清晰，讓所有人付費
```

### 4.3 Check-Raise 的注意事項

```
避免 Check-Raise 的情況：

1. 多人底池 + 你 Check + 所有人都 Check
   → 底池沒有建大，你失去了保護的機會
   → 在多人底池，Check-Raise 失效的可能性更高

2. 你的手牌較弱（non-nut draw），不適合 Check-Raise
   → 如果對手 Call 你的 Check-Raise，你可能處於劣勢

3. 對手非常緊（Tight），Check-Raise 后他可能 fold 所有弱牌
   → 你失去了從弱牌中贏得的底池
   → 此時直接 Bet 可能讓弱牌 Call

常見錯誤：OOP 有強牌但總是 Check，等待 Check-Raise
→ 問題：如果對手也 Check，你的強牌沒有得到保護，翻牌免費
→ 解決：即使 OOP，有非常強的牌（Set, Nut straight 等）在濕潤翻牌通常應該直接 Bet
```

## 五、多人底池的保護策略

### 5.1 多人底池的特殊挑戰

在多人底池（3 人以上）中保護強牌的難點：

```
問題 1：多個對手有 Draw，你的 Pot bet 無法驅逐所有人
  → 即使你 Pot bet，3-4 個對手可能都有足夠的底池賠率跟注
  → 你無法「驅逐」所有 draw 玩家

問題 2：Equity 疊加效應
  → 每個額外的對手都貢獻一些 equity 對抗你
  → 3 人底池中，你的 equity 比單挑要低

問題 3：PLO 格式限制下注大小
  → 你最多只能 Pot bet，不能超額下注
  → 在德州撲克中，你可以用 3x pot 驅逐 draw，在 PLO 中不行

解決方法：
  → 接受你無法驅逐所有人，但盡量讓他們付出最大代價
  → Pot bet 仍然是最佳選擇（給 draw 最差的賠率）
  → 接受多人底池中的方差（Variance）更高
```

### 5.2 多人底池中各手牌類型的保護策略

```
手牌類型 1：Nut made hand（Nut Straight, Nut Flush, or Top Set on dry board）

  策略：積極 Pot bet
  理由：你的 Nut 在這個翻牌上最強，讓 draw 付費是正確的
  注意：即使你的手牌是 Nut，仍需注意翻牌是否會讓對手有強 draw

  例子：
    你有 K-Q（手牌）配 J-T-9（公牌）= K-high Nut straight
    翻牌：J♥ T♠ 9♣ Rainbow
    → 多人底池（底池 40bb，4 人）
    → Pot bet（40bb）讓所有 draw 付費

  效果分析：
    如果 draw 玩家有 20-out wrap：他們有 70% 命中率（T+R）
    底池賠率：他們需要付 40bb 進入 80bb 底池 = 33% 的賠率
    即使他們有 70% equity，跟注是 +EV 的（他們理應跟注）
    → 這就是奧馬哈的現實：即使 Pot bet，對手有大 draw 時跟注是正確的
    → 但你的 Pot bet 仍然比 Check 或 Small bet 更好，因為你保持最大壓力
```

```
手牌類型 2：中等 made hand（Non-Nut Straight, 兩對, Top Pair）

  策略：謹慎，視翻牌決定下注大小
  理由：你的手牌不是最強，大注可能面對 Raise 而進退兩難

  乾燥翻牌 + 兩對：
    → 小到中等下注（1/3 到 1/2 pot）
    → 測試對手是否有更強的牌

  濕潤翻牌 + Non-Nut made hand：
    → 謹慎下注或 Check，因為：
    → Pot bet 後面對 Raise，你很難知道是否繼續
    → 你的 Non-Nut 手牌面對 Nut 的玩家處於劣勢
```

```
手牌類型 3：Nut Draw（Nut flush draw + strong wrap）

  策略：積極 Semi-Bluff Pot bet
  理由：你有高 equity + 折疊 equity（對手可能 fold）

  即使你現在沒有 made hand，有強 Nut draw 的情況下積極下注有雙重收益：
  1. 對手 fold → 你贏得底池（fold equity）
  2. 對手 call → 你有高機率命中 Nut（draw equity）
```

### 5.3 多人底池的 Pot bet 範例分析

```
完整案例：

設定：
  6 人多人 limped pot
  你的手牌（BTN）：J♠ T♠ 9♥ 8♥（JT98 double-suited）
  翻牌：Q♠ 8♠ 3♥（兩張黑桃 + 一張紅心）
  底池：30bb（6 人各 limp 5bb）

  你有什麼？
  J♠T♠（手牌）+ Q♠8♠3♥（公牌）= J♠T♠Q♠8♠ = 4 張黑桃 + 正在進行 flush draw
  → Flush draw（J♠T♠ = J-high flush draw，Non-Nut！A♠ 的人打敗你）

  9♥8♥（手牌）+ Q♠8♠3♥（公牌）：
  用 98 + Q83：Q-8-3 不連，9-8 在手，但 9-8 + Q-8 = 有重複的 8
  等等：你的手牌 J♠T♠9♥8♥，翻牌 Q♠8♠3♥

  公牌有 8♠，你手牌有 8♥：你有兩張 8！但在奧馬哈，你只能選 2 張手牌

  最佳手牌組合分析：
  用 J♠T♠（手牌）+ Q♠8♠3♥（公牌）：最強 5 張 = flush（J♠T♠Q♠8♠+一張黑桃，但只有 4 張黑桃，還差一張）
  → 4 張黑桃 = flush draw（還不是 flush）

  用 9♥8♥（手牌）+ Q♠8♠3♥（公牌）：
  9-8 + Q-8-3 = 有兩個 8（手中 8♥ + 公牌 8♠），最強牌型：
  9♥8♥ + Q♠8♠3♥ = 選最強 5 牌：Q-9-8-8-3？= 一對 8（QQ? 不，是 88）+ Q+9+3
  → 牌型：一對 8，踢腳 Q-9-3
  → 在多人底池，一對 8 幾乎無法贏

  用 JT（手牌）+ Q-X-X（公牌）：
  J-T-Q = J-T + Q → Q-J-T（連！）需要 K 或 9
  J♠T♠ + Q♠8♠3♥（全公牌）= Q-J-T-8-3？不連（8 和 T 之間差 9）
  → J-T-Q 連線中需要 K 或 9 才成 straight

  翻牌 Q-8-3 的 outs 分析：

  Flush draw（J-high 黑桃，Non-Nut）：9 outs
  Wrap/Straight draw：
    你有 J-T-9-8，公牌 Q-8-3
    用 JT + Q83：Q-J-T 連線，需要 K（做 K-Q-J-T-9？缺 9 手牌... 用 JT，不用 9）
      K 讓 K-Q-J-T-9 成（但 9 不在這個組合中 = K-Q-J-T + 8 = 不成！）
      需要 K + 9（不是一張）
    用 JT + Q：Q-J-T，需要 K（做 K-Q-J-T-?）+ 需要另一張底部
      只用 JT 和 Q（3 張），還需 2 張：K 和 9 = 兩張牌，不是 1 張 out
    用 T9（手牌）+ Q83：T-9 + Q-8 = 不連（Q 和 T 差 J，8 和 9 相鄰）
      T-9-8 連線（T 手牌，9 手牌，8 公牌）= 實際上：用 T9 手牌配 Q♠8♠3♥（公牌）
      最強連線：T-9-8（T 和 9 手牌，8 公牌），需要 J（J 在手，但用 T9 不用 J）
      → J 的 outs：4-1（J♠ 在手）= 3 outs（讓 J-T-9-8-? 成順，還需要 7 或 Q）
      等等，J + T-9-8（已有）= J-T-9-8 需要 7 或 Q 完成
      → 你同時是用 T9 手牌（T 和 9）+ 公牌 Q-8-3 = T-9-8 + Q + 3
      最強直線：9-T（連）+8（連）= 8-9-T，加 J 或 7
      J = 讓 8-9-T-J（4 連）+ 再需要 7 或 Q → 這是在 turn 後的情況，不是完整直

  這個翻牌對你的直線 outs 很少（Q-8-3 和你的 JT98 不是很好的配合）

  實際分析（Q-8-3 vs JT98）：
  你的主要 draw：
  1. J-high flush draw（Non-Nut）：9 outs（危險）
  2. 有限的 straight draw（非標準 wrap）：約 3-5 outs

  你的 Non-Nut flush + 弱 straight draw = 中等強度 draw

  多人底池中的正確策略：
  → Check（不要主動 Pot bet）
  → 理由：你的 draw 是 Non-Nut，在 6 人底池中積極下注風險大
  → 如果翻後可以便宜看 Turn，再評估是否繼續

  如果你的 flush 是 Nut flush（A♠X♠）：
  → 積極 Pot bet（Semi-bluff + 保護 equity）
```

## 六、保護手牌的常見錯誤

### 錯誤 1：過度慢打（Over-Slow-Playing）

```
情境：你有 Top Set 在濕潤翻牌
德州撲克玩家的直覺：慢打！等對手 bet 再 raise！

奧馬哈的問題：
  → 如果你 Check，對手免費看 Turn
  → Turn 可能讓對手完成 Wrap 或 Flush
  → 你的 Set 從 65% equity 降到 45% equity
  → 你的「慢打」讓對手免費超越你

正確：有強牌在濕潤翻牌 = 幾乎永遠 Pot bet
唯一可以慢打的情況：極乾燥翻牌 + 你有絕對的 Nuts（葫蘆等）
```

### 錯誤 2：用小注「保護」強牌

```
情境：翻牌濕潤，你有 Set，下注 1/4 pot

問題：
  → 1/4 pot 給了 draw 非常好的底池賠率（4:1）
  → 有 20-out wrap 的對手（70% 命中率）用 4:1 的賠率跟注 = 大幅 +EV 給對手
  → 你的「保護」適得其反，讓 draw 更願意跟注

正確：保護手牌應該用 Pot bet（或接近 Pot）給 draw 最差的賠率（2:1）
```

### 錯誤 3：在不需要保護的翻牌強行 Pot bet

```
情境：翻牌 A♠ 7♦ 2♣（Rainbow，乾燥），你有 Set of 7

問題：
  → 這個乾燥翻牌上，對手大多數牌型都不願 call Pot bet
  → Pot bet 只讓弱牌 fold，浪費了從弱牌身上贏取的機會
  → 唯一跟注你的可能是有 AA（你輸）或有某些 draw（很少）

更好的方法：
  → 乾燥翻牌 + 你有 Set = 考慮 Small bet（1/3 到 1/2 pot）
  → 小注更容易得到對手的 call，從弱牌身上建底池
  → 逐漸增加下注（Turn 和 River 再加大）
```

## 七、章節總結

| 概念 | 要點 |
|------|------|
| 為何保護 | 奧馬哈每個人都有強 draw，免費看牌風險極高 |
| Set 的保護 | 即使有 Set，濕潤翻牌上也需要 Pot bet |
| Pot bet 時機 | 濕潤翻牌、多人底池、你有強牌 |
| Check-Raise | OOP 玩家的重要工具，誘導對手 Bet 再加注 |
| 多人底池保護 | 接受無法驅逐所有人，但 Pot bet 仍是最佳 |
| 常見錯誤 | 過度慢打、下注過小、不必要的 Pot bet |

**核心保護原則**：
> 在奧馬哈，**有強牌就要讓對手付費**。不管你有多強，在濕潤翻牌上免費給牌對你永遠是損失。Pot bet 是你的最佳保護工具。
