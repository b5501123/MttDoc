# 翻牌後策略 01：翻牌質地判斷

> **學習目標**：掌握奧馬哈翻牌質地的分析框架，學會判斷乾燥翻牌與濕潤翻牌，理解單花翻牌和對子翻牌的影響，並能夠評估自身在任何翻牌上的相對強度。

---

## 一、奧馬哈翻牌質地比德州撲克更複雜

### 1.1 為什麼奧馬哈的翻牌質地分析更重要？

在德州撲克中，翻牌質地相對簡單：
- 乾燥翻牌（如 A-7-2 rainbow）：made hand 很強
- 濕潤翻牌（如 K-Q-J 兩同色）：有很多 draws

在奧馬哈中，幾乎**所有翻牌都是「濕潤」的**，原因：
1. 每個玩家有 4 張手牌，6 種二牌組合 → 更容易命中翻牌
2. 即使翻牌看似「乾燥」，對手的 4 張牌中總有一些能搭上
3. Wrap draw（環繞型順子聽牌）比德州撲克的 draw 更多 outs

**重要觀念轉換**：
```
德州撲克思維：
  乾燥翻牌 = 我的 made hand 很安全

奧馬哈正確思維：
  即使「乾燥」翻牌，仍需評估：
  1. 是否有 flush draw 可能
  2. 是否有 wrap/straight draw 可能
  3. 對手的 4 張牌是否能搭上翻牌
```

## 二、乾燥翻牌 vs 濕潤翻牌

### 2.1 奧馬哈的「乾燥翻牌」定義

奧馬哈的乾燥翻牌比德州撲克更嚴格，需要同時滿足：

```
奧馬哈乾燥翻牌的條件：
  ✅ 三張不同花色（Rainbow）
  ✅ 三張數字不連接（差距大）
  ✅ 沒有 Broadway 牌（AKQJT）讓高位 wrap 成立
  ✅ 通常是中低位牌面

最乾燥的翻牌例子：
  A♣ 7♦ 2♥（Rainbow，差距大，A 是高牌但無連接）
  K♦ 5♠ 2♣（Rainbow，高牌但無連接）
  Q♥ 7♣ 2♦（Rainbow，中高牌無連接）

在這些翻牌上：
  → flush draw：無（rainbow）
  → straight draw：只有 OESD 或更弱（因為差距大）
  → 你的 made hand 相對安全
```

### 2.2 奧馬哈的「濕潤翻牌」定義

```
奧馬哈濕潤翻牌的特徵（任一條件）：
  ⚠️ 有兩張以上同花（flush draw 可能）
  ⚠️ 有兩張以上連牌（straight/wrap draw 可能）
  ⚠️ Broadway 牌面（A-K-Q-J-T 組成的高位連牌）
  ⚠️ 雙連牌 + 同花（最濕潤的類型）

濕潤翻牌例子：
  K♠ Q♥ J♠（高位連牌 + 兩張黑桃）= 極濕潤
  T♥ 9♦ 8♥（中位連牌 + 兩張紅心）= 很濕潤
  J♠ T♠ 5♥（兩張連牌 + 兩張黑桃）= 濕潤
  9♠ 8♦ 7♠（中位連牌 + 兩張黑桃）= 很濕潤
```

### 2.3 翻牌濕潤程度對策略的影響

| 翻牌類型 | 你的 made hand 安全性 | 你應該如何下注 |
|---------|---------------------|------------|
| 極乾燥（rainbow, unconnected） | 高 | 可以選擇慢打 |
| 中等（single-suited 或略連） | 中 | 中等大小下注 |
| 濕潤（two-tone + 連牌） | 低 | 需要 Pot bet 保護 |
| 極濕潤（monotone 或三連高牌） | 極低 | 必須最大保護或考慮棄牌 |

## 三、單花翻牌（Monotone Board）的特殊影響

### 3.1 什麼是 Monotone Board？

Monotone（單調）翻牌：三張公牌都是同一花色。

```
例子：
  A♠ K♠ Q♠（三張黑桃）
  J♥ T♥ 6♥（三張紅心）
  9♦ 5♦ 2♦（三張方塊）
```

### 3.2 Monotone 翻牌的策略影響

```
情況 A：你沒有任何同花牌

  你的 made hand（即使是 Set 或 Straight）：
    → 非常脆弱！對手可能已成 Flush
    → 你的 Set 在 Monotone 翻牌面對已成 Flush 只有 ~33% equity
    → 應該謹慎，不應 Pot bet（可能面對更強牌型的 raise）

  例子：
    你的手牌：A♥ A♦ K♣ Q♣（無黑桃）
    翻牌：J♠ T♠ 6♠（三張黑桃）
    → 你的 AA 幾乎沒有價值
    → 你沒有任何黑桃，對手可能已有 Flush
    → 正確行動：Check，或如果對手下注，很可能棄牌

情況 B：你有一張同花牌（Backdoor Flush Draw）

  → 你有約 4-5% 的 Backdoor Flush Out（需要轉牌+河牌各一張同花）
  → 通常不足以大額跟注
  → 只有在同時有其他強 Draw 時才考慮繼續

情況 C：你有兩張同花牌（已成 Flush 或 Flush Draw Completed）

  翻牌已有三張同花 + 你有兩張同花 = 你已成 Flush！
  但關鍵：你的 Flush 是 Nut 嗎？

  例子：
    翻牌：J♠ T♠ 6♠（三張黑桃）
    你有 A♠ K♠：你已有 A-K-J-T-6 的 Nut Flush → 超強，可以積極下注
    你有 Q♠ 9♠：你已有 Q-J-T-9-6 的 Q-high Flush → 非 Nut，A♠ 或 K♠ 的人打敗你
    你有 7♠ 5♠：你已有 J-T-7-6-5 的 7-high Flush → 非常危險，多人打敗你

  在 Monotone 翻牌，你的 Flush 越高越安全，越低越危險
```

### 3.3 Monotone 翻牌的實戰建議

```
有 Nut Flush（A 高）：
  → 可以 pot bet，對手有較低同花可能跟注
  → 注意：有時候可以 slow play（如果對手有 draw）

有 Non-Nut Flush（K/Q 高等）：
  → 謹慎，對手可能有 A 高同花
  → 小注測試，面對加注考慮棄牌

有 Flush Draw（只有 2 張同花手牌）：
  → 如果是 Nut Flush Draw（A♠X♠）：強大，積極
  → 如果是 Non-Nut Flush Draw：危險，謹慎

無同花牌：
  → 即使有 Set 或 Straight，也要謹慎
  → 主要 Check，不主動下大注
```

## 四、對子翻牌（Paired Board）的策略

### 4.1 對子翻牌的特殊性

對子翻牌指公共牌中有兩張相同數字。

```
例子：
  A♠ A♥ 7♦（有對 A）
  K♦ K♠ J♣（有對 K）
  9♥ 9♦ 5♣（有對 9）
  T♠ T♣ 8♥（有對 T）
```

### 4.2 對子翻牌對各種手牌的影響

**對有 Set 的玩家（暗三條）**：
```
你有一張與公牌配對的牌 + 公牌有一對 = 你有 Full House（葫蘆）

例子：
  公牌：K♠ K♥ 7♦
  你的手牌包含 K♣（一張 K）

  奧馬哈規則：你必須用 2 張手牌 + 3 張公牌
  → 用手牌 K♣ + 任意一張，配公牌 K♠K♥ 和另外 2 張？
  → 但公牌只有 3 張（翻牌），所以 K♠K♥7♦ 是翻牌
  → 你用 K♣（手牌 1 張）+ X（手牌另 1 張）配 K♠K♥7♦（公牌 3 張）
  → K♣ + K♠ + K♥ = 三條 K，加上手牌的另一張 X 和公牌 7♦
  → 如果 X > 7：三條 K 踢 X，就是 K-K-K-X-K 等等...

  實際上：
  你有 K♣，公牌有 K♠K♥7♦
  最佳牌型：K♣ + 最強手牌 X 配 K♠K♥7♦
  → 三條 K（K♣K♠K♥）+ X + 7 = 三條
  → 如果 X 是 7♥：Full House（K♣K♠K♥7♦7♥）= 葫蘆 K full of 7！

  等等，奧馬哈是用 2 張手牌：
  如果手牌是 K♣ 7♥ Q♠ J♦：
  選 K♣7♥（手牌 2 張）配 K♠K♥7♦（公牌 3 張）
  = K♣K♠K♥ 三條 + 7♥7♦ 對 = Full House（K full of 7）葫蘆！
```

**對沒有配對手牌的玩家（有 Set 但非葫蘆）**：
```
在對子翻牌，如果公牌出現一對，
沒有這張牌的玩家「Set」的機會減少（因為牌組中那張牌已是對子）

但對子翻牌有另一個影響：
→ 有人可能暗四條（Quads）
→ 葫蘆（Full House）的可能性增加
→ 你的 Flush 和 Straight 在對子翻牌上更危險（輸給葫蘆）
```

**對 Draw 玩家**：
```
對子翻牌通常對 Draw 玩家不利：
  - 對手可能有暗三條或葫蘆，你的 Draw 即使命中也可能輸
  - 例外：你的 Draw 命中後同時做出葫蘆（如 Wrap Draw + Set 機會）
```

### 4.3 對子翻牌的實戰策略

```
面對對子翻牌的決策原則：

你有 Trips（三條）或 Full House：
  → 積極下注，對手可能有順子/同花在追牌
  → 對子翻牌你的「保護」需求更小（對手的 Draw 命中後仍可能輸）

你有 Straight 或 Flush（无 Full House）：
  → 謹慎！公共牌的對子意味著：
  → 有人可能有 Full House 或 Trips + Draw
  → 你的 Straight/Flush 在對子翻牌是中等強度手牌，非 Nut

你有 Draw（無 made hand）：
  → 考慮你的 Draw 命中後是否能打敗 Full House
  → 如果你的 Draw 命中只做出 Straight/Flush，可能仍輸
  → 謹慎跟注
```

## 五、如何判斷自己在翻牌上的相對強度

### 5.1 「相對強度（Relative Strength）」的概念

在奧馬哈中，手牌的強度不是絕對的，而是**相對於翻牌和對手範圍**的。

```
例子：
  你有 K♠ K♥ Q♠ J♥（KK double-suited）

  翻牌 A：A♦ A♣ 7♠（對 A 翻牌）
    → 你的 KK 在這個翻牌很弱
    → 任何有 A 的人（AA 或單張 A）都有 Trips 或 Full House
    → 你的最強手牌：KK only（無 set，無 flush，無 straight）
    → 相對強度：**非常弱**

  翻牌 B：K♦ Q♥ J♠（你中 Top Set！）
    → 你有 Set of Kings！
    → 公牌 KQJ 有 flush draw 可能（紅心、黑桃各 1）
    → 有 Wrap draw（AJT 或 T9 的人有順子聽牌）
    → 但你的 Set 仍然非常強
    → 相對強度：**強，但需要保護**

  翻牌 C：Q♥ T♦ 9♠（中間數字，你命中兩對？）
    → 你用 K♠K♥（手牌）配 QT9（公牌）= 只有 KK Overpair，無 Set
    → 或用 K♠Q♠（手牌）配 QT9 中的 T9 = KKQT9？不成
    → 用 Q♠J♥（手牌）配 QT9（公牌）= QQJ T9？= 三條 Q？
        等等：Q♠（手牌 1 張）+ J♥（手牌 2 張）配 Q♥T♦9♠（公牌 3 張）
        = Q♠Q♥ 對 + J♥T♦9♠ = 「Three of a Kind Q」？不對
        = 你用 Q♠J♥（手牌 2 張）+ Q♥T♦9♠（公牌 3 張）
        = Q♠ + Q♥（兩 Q）+ J♥ + T♦ + 9♠ = 兩對（QQ + 無第二對，實際是 Three Q）
        → 實際：Q♠Q♥T♦J♥9♠... 最強牌型是 Three of a Kind（三條 Q）
        → 因為手牌只有一張 Q，配公牌一張 Q = 兩張 Q = 只是一對 Q

    好，讓我重算：
    手牌 K♠K♥Q♠J♥ 的所有 2 張組合：KK, KQ, KJ×4, QJ
    公牌：Q♥T♦9♠

    KK + QT9 = K-K-Q-T-9（兩對？KK + 無第二對）→ 兩對 KK+Q
    KQ + QT9 = K-Q-Q-T-9 = 兩對（QQ + K-high kicker）
      等等：K♠Q♠（手牌）配 Q♥T♦9♠（公牌）= K-Q-Q-T-9（三條 Q！因為有 Q♠Q♥）
      → Q♠（手牌）+ Q♥（公牌）= 兩張 Q = 一對 Q
      → K♠Q♠ + Q♥T♦9♠：最強牌型 = 三條 Q（Q-Q-Q-K-T），因為有 Q♠,Q♥,Q？
      等等，只有兩張 Q（一張在手牌，一張在公牌），不是三條。
      → 兩對：Q♠-Q♥ 的 QQ + K + T + 9 的最強牌型 = QQ + 無第二對 = 只有 QQ
      → QQ 踢腳 K（K-Q-Q-K？不對）
      → 牌型：K♠Q♠ + Q♥T♦9♠ = K, Q, Q, T, 9 = 最強牌型：一對 Q（踢腳 K-T-9）

    KJ + QT9：K♠J♥ + Q♥T♦9♠ = K-J-Q-T-9 = J-high straight！(9-T-J-Q-K)
      → 這是 Straight！K-high straight (K-Q-J-T-9)
    QJ + QT9：Q♠J♥ + Q♥T♦9♠ = Q-Q-J-T-9 = 一對 Q + Straight？
      J♥ + Q♥T♦9♠ → 用 QJ 手牌：J 配 Q-T-9 = Q-J-T-9（連牌）需要 8 或 K = straight draw
      用 QJ 完整：Q♠J♥ + Q♥T♦9♠ = 有一對 Q（Q♠Q♥），加上 J-T-9
      最強牌型：Q♠Q♥ + J♥ + T♦ + 9♠ = 一對 Q 踢 J-T-9

    → 最強手牌：用 KJ（手牌）+ Q-T-9（公牌）= Straight（KQJT9）
    → 相對強度：**中等**（K-high straight，但不一定是 Nut）

    翻牌 QT9 的 Nut straight？
    最強 straight on QT9：需要 KJ（做 KQJT9）或 AK（做 AK + QT9？不成 5 連）
    → KQJT9 = K-high straight = Nut straight on this board ✓
    → 你有 KJ（手牌 K♠,J♥）= 你有 Nut straight！

    相對強度：**強**（Nut straight），但翻牌有兩同色（黑桃 Q♥... 等等，Q♥T♦9♠ 不是兩同色）
    → Rainbow 翻牌 QT9 + 你有 Nut straight = 相對安全
```

### 5.2 相對強度評估的實用框架

```
評估翻牌相對強度的 5 個問題：

Q1：我現在有什麼 made hand？
   → Set > Two Pair > Top Pair > 無牌（只有 draw）

Q2：我的 made hand 是不是 Nut？
   → 是：相對安全
   → 否：有多少更強的可能牌型？

Q3：翻牌上有 flush draw 嗎？
   → 有（兩張同花）：我的 made hand 面臨 flush draw 威脅
   → 有（三張同花）：我如果沒有同花，非常危險

Q4：翻牌上有 straight/wrap draw 嗎？
   → 有連牌：有 draw 的威脅
   → 無連牌：draw 威脅小

Q5：是對子翻牌嗎？
   → 是：有葫蘆可能，我的 straight/flush 安全性降低
   → 否：葫蘆可能性較低（除非有人有兩對 + 翻牌配對）
```

## 六、翻牌質地判斷的綜合案例

### 案例 1：K♠ Q♥ J♦ Rainbow

```
翻牌：K♠ Q♥ J♦（Rainbow，高位連牌）

翻牌質地分析：
  ✅ Rainbow（三張不同花色）→ 無 flush draw
  ⚠️ 高位連牌（KQJ）→ 有大量 straight draw
    - 有 AT 的人已成 Broadway（A-K-Q-J-T）= 最強 straight
    - 有 T9 的人已成 J-high straight（T-9-J？不對，J-T-9-8-7？）
      等等：K-Q-J 已有，有 AT 的人：A+T+K+Q+J = A-high straight（最強）
      有 T9 的人：T+9+K+Q+J = K-high straight？不對
      T配K：T-J-Q-K（缺 A 或 9）
      → 實際上：公牌 KQJ，有 AT（手牌 2 張）→ A-K-Q-J-T（最強順子）
      有 T9：T+K+Q+J = K-Q-J-T（缺底端 9？）→ K-Q-J-T-9（K-high）= 非 Nut

  Nut hand 分析：
    Nut straight：AT → A-K-Q-J-T（百老匯）
    2nd Nut：T9 → K-Q-J-T-9
    Set（暗三條）：有 KK, QQ, 或 JJ 的玩家

  如果你有 Set of Q（一張 Q 在手配公牌 Q）：
    → 你有 Q-Q-Q（三條 Q）= 很強
    → 但對手可能有 AT（直接已做 Broadway straight）
    → 翻牌後面對下注要謹慎：可能輸給 Broadway

這個翻牌的關鍵信息：
  → 任何有 A 和 T 的人已做出最強順子
  → 許多人有 wrap draw
  → 你的 Set 可能在劣勢
  → 你的 Two Pair / Top Pair 幾乎沒有價值
```

### 案例 2：T♥ 9♥ 6♣ Two-Tone

```
翻牌：T♥ 9♥ 6♣（Two-Tone，兩張紅心，中位連牌）

翻牌質地分析：
  ⚠️ Two-Tone（兩張紅心）→ 有 flush draw
  ⚠️ 中位連牌（T-9-6，有缺口）→ 有 wrap draw 可能
  → 這是「中等濕潤」的翻牌

Nut analysis（在這個翻牌）：
  Nut flush draw：A♥X♥ → 有 Nut flush draw
  Nut straight（已成）：J-T-9-8 = J-high？
    T-9-6，有 KJ 的人：K + J + T + 9 = K-Q-J-T-9？公牌 T-9-6，有 J-8 的人：
    J + 8 + T + 9 + 6？不連（8-9-T-J + 6 不成）
    Wait: J-T-9 連線，加上 8 在手 = J-T-9-8（需要 7 或 Q 完成）→ 還不是 made hand

    在翻牌 T-9-6 已成的 Straight（用 2 張手牌 + 3 張公牌 T-9-6）：
    你需要 2 張手牌能和 T-9-6 組成 5 連牌：
    → 有 J-8：J+8+T+9+6？ = 6-8-9-T-J（J-high straight）✓ 缺口在 7 ... 等等 6-7-8-9-T-J 是 6 張
      只需 5：8-9-T-J（需要底端 7 或頂端 Q），尚未成順
    → 有 8-7：8+7+T+9+6？= 6-7-8-9-T（T-high straight）✓
      用 87（手牌）配 T-9-6（公牌）= 6-7-8-9-T（已成！T-high straight）
    → 有 Q-J：Q+J+T+9+6？= 6-9-T-J-Q（缺口在 7-8）不連
    → 有 J-8：J-T-9-8（用 J-8 手牌配 T-9 公牌）= J-T-9-8（順？需要第 5 張：7 或 Q）還不成

    所以在 T-9-6 翻牌，已成 Straight 的情況：
    8-7 → T-9-8-7-6（T-high straight）✓

    Nut straight on T-9-6 翻牌：
    最強 straight = 需要找出最高的 5 連牌包含 T, 9, 6
    → T-9-6，周圍可以填：11（J）, 8, 7
    → 可能的 5 連：6-7-8-9-T（T-high）
    → 公牌已有 T-9-6，有 8-7 的人已成 T-high straight
    → 沒有比 T-high 更高的（因為 T-9 後下一個是 J，但 J 和 6 之間有太多缺口）

    等等：公牌 T-9-6 中最長連線是 T-9（2 張連），6 是單獨的
    → 可以做的最高直順，包含 T-9-6 的三張：
    → 要包含全部 3 張（T, 9, 6），那直順是 6-7-8-9-T 只有這一個（5 張 6 到 T）
    → 不包含全部 3 張：T-9 + 手牌的 J-8 → J-T-9-8 + 7？
      但 J-T-9-8-7 需要同時有 J, 8 手牌，而公牌只選 T-9（不用 6）= 用 JT 手牌 + T-9-X？
      等等：在奧馬哈，用 2 張手牌 + 3 張公牌（所有 3 張公牌）
      不是「選 2 張公牌」，而是「必須用全部 3 張公牌」！

  ⚠️ 重要奧馬哈規則：你必須用 3 張公牌（不能選 2 張）！

  所以在翻牌 T♥9♥6♣，你必須用 T, 9, 6 這三張：
  → 用手牌 J-8：J+8+T+9+6 = 有 J-T-9-8（連），6 多了 = J-T-9-8-6（不連！6 和 8 之間缺 7）
  → 用手牌 8-7：8+7+T+9+6 = 8-7+T-9-6 = 6-7-8-9-T（連！）= T-high straight ✓
  → 用手牌 Q-8：Q+8+T+9+6 = Q-T-9-8-6（缺口 Q-T 之間少 J）= 不連

  Nut straight on T-9-6：
  → 只有 8-7 組合可以做出順子（6-7-8-9-T）
  → Nut = T-high straight with 8♥7♥（or any 8-7）
```

### 案例 3：簡化版翻牌質地判斷表

```
快速判斷翻牌質地的備忘表：

翻牌類型 → 濕潤程度 → 你的策略

A-7-2 rainbow → 乾燥 → 你的 Set/Straight 相對安全，可慢打
K-Q-J rainbow → 中等（高位連牌，直順可能多） → 需保護 made hand
K-Q-J two-tone → 濕潤 → 積極保護
K-Q-J monotone → 極濕潤 → 沒有 Nut flush 則非常謹慎
T-9-8 rainbow → 中高（中位連牌，wrap 豐富） → 保護
T-9-8 two-tone → 很濕潤 → 積極保護 / semi-bluff
T-9-8 monotone → 極濕潤 → flush 玩家為主的攻防
A-A-7（對子）→ 特殊（Full House 可能） → 謹慎判斷
```

## 七、章節總結

| 概念 | 要點 |
|------|------|
| 乾燥翻牌 | Rainbow + 不連接，made hand 相對安全 |
| 濕潤翻牌 | Two-Tone 或連牌，需要積極保護 |
| Monotone 翻牌 | 三張同花，沒有 Nut flush 非常危險 |
| 對子翻牌 | 葫蘆可能性高，Straight/Flush 相對貶值 |
| 相對強度 | 手牌強度取決於翻牌質地和對手範圍，非絕對 |

**核心原則**：
> 奧馬哈的「乾燥」翻牌比德州撲克的乾燥翻牌還要「濕潤」。即使在看似安全的翻牌上，也要問：「有沒有 Flush Draw？有沒有 Wrap？我的手牌是不是 Nut？」
