# 起始牌策略 03：雙面同花連牌（Double-Suited Rundowns）

> **學習目標**：深入理解 Double-suited rundown 的定義、價值和使用策略，掌握 Outs 計算方法，學會如何在多人底池中發揮 rundown 手牌的最大優勢。

---

## 一、什麼是 Double-Suited Rundown？

### 1.1 定義

**Rundown（連牌）**：手牌中的 4 張牌在數字上緊密連接，沒有或只有少數缺口。

**Double-suited（雙同花）**：手牌中有兩組不同花色的配對（兩張黑桃 + 兩張紅心，或其他兩對花色組合）。

**Double-Suited Rundown（雙面同花連牌）**：同時具備上述兩個特徵的手牌。

### 1.2 例子

```
完美的 Double-Suited Rundown：

Q♠ J♥ T♠ 9♥（QJTS，黑桃 + 紅心雙同花）
  黑桃組：Q♠T♠
  紅心組：J♥9♥
  連接性：Q-J-T-9（4 連牌，無缺口）
  → 典型的 Double-Suited Rundown ✅

其他例子：
J♠ T♥ 9♠ 8♥（JT98 ds，黑桃 + 紅心）
T♠ 9♣ 8♠ 7♣（T987 ds，黑桃 + 梅花）
K♦ Q♠ J♦ T♠（KQJT ds，方塊 + 黑桃）
A♠ K♥ Q♠ J♥（AKQJ ds，黑桃 + 紅心）

非 Double-Suited（注意區分）：
Q♠ J♠ T♥ 9♥（同上，排列不同，但仍是 double-suited）✅
Q♠ J♠ T♠ 9♥（三張黑桃 + 一張紅心 = triple-suited）❌（不是 double-suited）
Q♠ J♥ T♦ 9♣（四色 = rainbow）❌
```

### 1.3 Double-Suited 的組合結構

一手 Double-Suited Rundown 有以下特徵：

```
手牌：Q♠ J♥ T♠ 9♥（舉例）

花色對：
  對 1：Q♠ T♠（黑桃）→ 聽黑桃同花
  對 2：J♥ 9♥（紅心）→ 聽紅心同花

注意：每種花色各有 2 張，不多也不少（perfect double-suited）

可能的 Flush Draw 路線：
  路線 A：翻牌出現兩張或更多黑桃 → Q♠T♠ 有黑桃 flush draw
  路線 B：翻牌出現兩張或更多紅心 → J♥9♥ 有紅心 flush draw
  → 兩條獨立的 flush draw 路線！
```

## 二、為什麼 Double-Suited 比 Single-Suited 強得多？

### 2.1 Equity 的量化差距

以 QJT9 為例，比較三種同花配置：

```
QJT9 Double-Suited（ds）  vs  隨機對手：平均 Equity ≈ 54%
QJT9 Single-Suited（ss）  vs  隨機對手：平均 Equity ≈ 50%
QJT9 Rainbow（rb）        vs  隨機對手：平均 Equity ≈ 46%

差距：ds 比 ss 高約 4%，比 rainbow 高約 8%
```

這 8% 的差距在長期 PLO 遊戲中非常顯著，因為：
- 每局底池你的期望值都更高
- 在深疊時，這個差距被放大
- 多人底池中，每個額外的 draw 路線都有獨立價值

### 2.2 為什麼 QJTS Double-Suited 比 QJTS Single-Suited 強很多？

**具體分析**：

```
QJTS Single-Suited（Q♠J♠T♥9♣）：

  有黑桃 flush draw（Q♠J♠）：✅ 但只有一條 flush 路線
  無第二個 flush draw：❌

  翻牌的 flush draw 命中機率：
  - 翻牌出現 2+ 張黑桃的機率：約 55%
  - 翻牌出現 2+ 張其他特定花色：0%（你沒有那個花色）

  Wrap draw 仍然完整（連牌效果相同）

QJTS Double-Suited（Q♠J♥T♠9♥）：

  有黑桃 flush draw（Q♠T♠）：✅
  有紅心 flush draw（J♥9♥）：✅ 第二條 flush 路線！

  翻牌的 flush draw 機率：
  - 翻牌出現 2+ 張黑桃：約 55% → Q♠T♠ flush draw 激活
  - 翻牌出現 2+ 張紅心：約 55% → J♥9♥ flush draw 激活
  - 兩個 flush draw 同時激活（不太可能，因為翻牌只有 3 張）
  - 總計：你在更多翻牌上有 flush draw

  總結：Double-Suited 在更多翻牌（約 2 倍的 flush 翻牌）上有 flush draw！
```

### 2.3 「Flush Cover」效應

Double-Suited 的另一個優勢是「覆蓋」更多花色，讓對手更難有 Nut flush draw：

```
你的手牌：Q♠J♥T♠9♥
  你有黑桃和紅心各 2 張

  如果翻牌出現 2 張黑桃：
  → 持有 A♠X♠ 的對手有 Nut flush draw（可能）
  → 但你有 Q♠T♠ 的 2nd Nut flush draw

  如果翻牌出現 2 張紅心：
  → 持有 A♥X♥ 的對手有 Nut flush draw（可能）
  → 但你有 J♥9♥ 的 2nd Nut flush draw（仍然危險）

  問題：你有 2nd Nut flush draw（不是 Nut）
  解決：選擇含 A 的同花組合！
```

### 2.4 含 A 的 Double-Suited Rundown

最強的 Double-Suited Rundown 通常包含 Ace：

```
頂級例子：
  A♠ K♥ Q♠ J♥（AKQJ ds）
    → A♠Q♠ = Nut 黑桃 flush draw ✅
    → K♥J♥ = K-high 紅心（2nd Nut）⚠️ 但仍有價值
    → AKQJ 連線 = 多種 Nut wrap draws ✅

  A♠ J♠ T♥ 9♥（AJTS ds）
    → A♠J♠ = Nut 黑桃 flush draw ✅
    → T♥9♥ = T-high 紅心（4th Nut）⚠️ 非 Nut，但有 wrap 補償
    → AJT9 = 有缺口連牌（稍弱）

  最佳形式：一組 A-同花 + 一組中高牌-同花
  例：A♠K♠Q♥J♥（一組有 A，一組有 Q）
      A♠K♥J♠T♥（一組有 A，一組連線）
```

## 三、Rundown 手牌的 Outs 計算

### 3.1 基礎：連牌的 Wrap Draw Outs

先理解 Wrap Draw 的 outs 計算：

```
Wrap Draw 定義：你的手牌「環繞」公共牌的連牌，形成多個outs的順子聽牌

例子：
你的手牌：J-T-9-8（JTWS）
公共牌：K-7-2（與你的牌無連接的翻牌）
→ 這裡沒有 wrap，因為公牌和手牌不連接

更好的例子：
你的手牌：J-T-9-8（JT98）
公共牌：Q-7-2（Q 在手牌 J-T-9-8 的頂端接近）

分析：
  用 JT + Q72：Q-J-T 有了，需要 K（做 K-Q-J-T-9）或 9（做 Q-J-T-9-8）
               → 但 9 在你手牌中！所以用 J-T（手牌）配 Q（公牌）：
               你只需要 K 和 9，但 9 已在手牌...
               等等：用 J♠T♦（手牌 2 張）配 Q♥？♦？♣（公牌 3 張）
               → 公牌只有 Q-7-2，無法做成 5 連牌

  用 T9 + Q72：T-9 配 Q，需要 J 和 8（但 J 在手牌！）
               不對，需要公牌給 J：J 在手牌，不在公牌...

讓我換一個清晰的例子：

公共牌：J♥ T♠ 6♦（JT6 rainbow）
你的手牌：K♠ Q♥ 9♦ 8♣（KQ98）

分析翻牌後的 Wrap draws：

用 KQ（手牌）+ JT6（公牌）：
  KQ + J-T = K-Q-J-T，需要 A（做 AKQJT）或 9（做 KQJT9）
  A：4 outs，9：你手中有 9♦！但 9 要用作「手牌選擇之一」
  等等：你選擇用 K-Q（手牌 2 張），所以 9 不能再用了
  → 需要公牌來 A（4 outs）
  → 也需要 9 從公牌來（4 outs）→ 但 9 在手牌不是公牌
  → 實際上只有 A（4 outs）配合這個 K-Q 組合

用 Q9（手牌）+ JT6（公牌）：
  Q-J-T-9，需要 K（做 KQJT9）或 8（做 QJT98）
  K：4 outs（K 在手牌！不行，K 如果用了這裡就佔了手牌位置）
  等等：我在用 Q9（手牌 2 張）配 JT6（公牌）
  → 再加牌的話是 turn/river 的 out，那個牌來自牌組（不是手牌）
  → K 有 3 outs（1 張 K 在你手中，剩 3 張）
  → 8 有 4 outs（8 的 4 張，全在牌組）
  → 這個組合：7 outs

用 K9（手牌）+ JT6（公牌）：
  K + J-T-9 = K-J-T-9，缺 Q（做 KQJT9）
  → Q 有 3 outs（1 張 Q 在你手中，剩 3 張）
  → 這個組合：3 outs

用 Q8（手牌）+ JT6（公牌）：
  Q-J-T + 8，需要 9（做 QJT98）
  9 有 3 outs（9 在手牌，剩 3 張）
  或需要 K（做 KQJ T，等等：K-Q-J-T-8？不連）
  → K-Q-J-T 需要 9 配底端：K-Q-J-T-9？不對，我在用 Q8
  → Q8 + JT：Q-J-T-8 不連（T 和 8 中間缺 9）
  → 這個組合：需要 9（做 Q-J-T-9-8）= 3 outs

用 K8（手牌）+ JT6（公牌）：
  K-J-T-8 不連，需要 Q 和 9 同時...不成 5 連
  → 0 outs

用 98（手牌）+ JT6（公牌）：
  J-T-9-8，需要 Q（做 QJJT98，等等：Q-J-T-9-8 = Q-high straight）
  Q：3 outs（你手中有 Q）
  或需要 7（做 J-T-9-8-7）
  7：4 outs
  → 這個組合：7 outs

總 outs（去重）：
  A（4）, Q（3，1 張在手）, 8（4）, 9（3，1 張在手）, 7（4）=
  4+3+4+3+4 = 18... 但需要去掉重複計算的牌

實際上，Wrap draw 的標準計算方式比較複雜，讓我用一個標準例子：
```

### 3.2 標準 Wrap Draw Outs 計算（清晰版本）

```
最清晰的 20-out Wrap 案例：

公共牌：9♠ 8♥ 2♣（翻牌）
你的手牌：K♠ J♦ T♣ 7♥（KJT7）

分析（逐一列出每個 turn 牌讓你中順子）：

用 JT（手牌）配 9-8 + 更多公牌：
  J-T-9-8 已有連線（J 和 T 在手，9 和 8 在公牌）
  需要第 5 張：Q（J-T-9-8 + Q → 實際上 Q-J-T-9-8）
  或 7（J-T-9-8-7 = J-high straight）

  Q 讓你中：Q-J-T-9-8（Q-high straight）→ Q 的 4 outs
  7 讓你中：7-8-9-T-J（J-high straight）→ 7 有 3 outs（你手中有 7♥）

用 J7（手牌）配 9-8 + 更多公牌：
  J-9-8-7 需要 T（已在手牌，T 不是公牌）... 不對，T 在手牌不能用
  等等：用 J7（手牌 2 張），公牌有 9-8
  J + 9 + 8 + 7 = J-9-8-7（不連，J 和 9 不相鄰）→ 不成順子

用 T7（手牌）配 9-8 + 更多公牌：
  T-9-8-7 已有連線！（T 手牌，9-8 公牌，7 手牌）
  等等：T 和 7 是手牌，9 和 8 是公牌
  組合：T(手) + 9(公) + 8(公) + 7(手) + X
  = 10-9-8-7，需要 J（做 J-T-9-8-7）或 6（做 T-9-8-7-6）

  J 讓你中：J-T-9-8-7（J-high）→ J 有 3 outs（你手中有 J♦）
  6 讓你中：6-7-8-9-T（T-high）→ 6 的 4 outs

用 KJ（手牌）配 9-8 + 更多公牌：
  K + J + 9 + 8 = K-J-9-8（缺 Q 和 T 才能成順，但不是 1 張就能填）
  → 無法 1 張牌完成順子

用 KT（手牌）配 9-8 + 更多公牌：
  K-T-9-8，缺 J（做 K-Q-J-T-9？不對，K 和 T 中間也缺）
  K + T-9-8 = K-T-9-8（K 和 T 中間缺 J,Q 兩個）→ 無法 1 張完成

用 K7（手牌）配 9-8 + 更多公牌：
  → K 和 7 差距太大，無法在翻後組成 5 連牌

彙總有效 turn outs：
  Q（4）：JT + Q → Q-J-T-9-8
  7（3）：JT + 7 → J-T-9-8-7（一張 7 在手）
  J（3）：T7 + J → J-T-9-8-7（一張 J 在手）
  6（4）：T7 + 6 → T-9-8-7-6

  去掉重複：Q(4) + 7(3) + J(3) + 6(4) = 14 outs

  等等，還要確認這是正確的 wrap count...
```

### 3.3 Wrap Outs 速查表（標準結果）

為了實用性，以下是標準 Wrap draw 的 outs 數：

| Wrap 類型 | 公共牌結構 | 你的手牌舉例 | Outs 數 |
|----------|-----------|------------|---------|
| 標準 OESD | 連續三張 | 翻牌 Q-J-T，你有 K-9 | 8 outs |
| 小 Wrap | 翻牌三張，你有上下各一 | 翻牌 9-8-7，你有 J-6 | 13 outs |
| 中 Wrap | 翻牌三張，你有上兩下一 | 翻牌 9-8-7，你有 J-T-6 中選 2 張 | 16 outs |
| 大 Wrap | 翻牌三張，你有下兩上一 | 翻牌 9-8-7，你有 J-6-5 中選 2 張 | 17 outs |
| 最大 Wrap | 翻牌三張，上下各有兩張 | 翻牌 9-8-7，你有 J-T-6-5 | 20 outs |

**實用記憶法**：

```
翻牌 J-T-9（三張連牌），你有多少 outs？

你有 K-Q-8-7（四張環繞 J-T-9）：
  高端：K,Q 在 JT9 之上 → 加入頂端的牌
  低端：8,7 在 JT9 之下 → 加入底端的牌
  → 上兩下兩 = 20 outs（最大 Wrap）

你有 K-Q-8（三張）：
  高端：K,Q，低端：8
  → 上兩下一 = 17 outs

你有 K-8-7（三張）：
  高端：K，低端：8,7
  → 上一下兩 = 17 outs（對稱）

你有 K-7（兩張）：
  高端：K，低端：7（缺口！JT9 和 7 中間還缺 8）
  → 缺口 wrap = 13 outs
```

## 四、Double-Suited Rundown 的 Flush + Wrap 組合 Outs

### 4.1 組合計算方法

Double-Suited Rundown 的真正威力在於同時有 **Flush draw + Wrap draw**。

```
手牌：Q♠ J♥ T♠ 9♥（QJTS double-suited）
翻牌：K♠ 8♠ 7♦（兩張黑桃，一個較低的連牌）

分析：

Flush draw（黑桃）：
  你有 Q♠T♠，公牌有 K♠8♠ → 你已有 4 張黑桃！
  需要第 5 張黑桃 = 9 outs（牌組中剩餘 9 張黑桃）
  但等等：Q♠T♠ 不是 Nut flush draw（K♠ 在公牌，A♠ 在某人手中可能）
  如果 A♠X♠ 的玩家命中，你的 flush 輸掉

Wrap draw（順子）：
  公牌 K-8-7，你的手牌 Q-J-T-9
  分析 wrap：
    J-T-9-8（T,9 手牌，8 公牌）→ 需要 J-T-9-8-7 → 7 在公牌，J-T-9 有了
                                    實際：用 J♥T♠（手牌）配 K♠8♠7♦（公牌 3 張）
                                    → K♠ 是多餘的（不在連線中）
                                    → J-T-8-7 = J-T-8-7，缺 9（做 J-T-9-8-7？9 在手牌）
    等等，讓我重新做：用手牌 JT（J♥T♠）配公牌 3 張（K♠8♠7♦）：
      J-T + K = K-Q-J-T（缺 Q）? 不是，你只是選 JT 加上公牌 K-8-7
      → J-T-8-7 不連，K 有 gap

    用手牌 QJ 配公牌 K-8-7：
      K-Q-J + 8 + 7 = K-Q-J + 8-7？不連（J 和 8 中間差兩個）

    用手牌 T9 配公牌 K-8-7：
      T-9 + 8-7 = T-9-8-7，需要 J（做 J-T-9-8-7）或 6（做 T-9-8-7-6）
      J：你手中有 J♥，是手牌的一部分（但你選了 T9），所以 J 不在
         公牌中的 J 概率：4 outs（4 張 J 全在牌組）
      6：4 outs

    用手牌 QT 配公牌 K-8-7：
      K-Q-T，缺口太多，不成 wrap

    用手牌 Q9 配公牌 K-8-7：
      K + 9 + 8 + 7 = K-9-8-7，缺口（K 和 9 中間差太多）

    用手牌 J9 配公牌 K-8-7：
      J-9-8-7，需要 T（做 J-T-9-8-7）或 6（做 J-9-8-7-6，缺口！不成連）
      T：你手中有 T♠，如果選了 J-9 作為手牌組，T 也在手牌中但不在「使用」的 2 張
         所以 T 的 outs 來自公牌：4 outs（但 T♠ 在你手中，減 1 = 3 outs）

彙總有效 straight outs（選用 T9 組合）：
  J（4 outs）+ 6（4 outs）= 8 outs（straight）

Flush outs：9 outs（黑桃）

總 outs（去重）：
  Straight outs：J（4）+ 6（4）= 8
  Flush outs（黑桃）：9
  重複（J♠ 同時是 flush out 和 straight out）：
    J♠ 是黑桃，同時也是 straight out → 需要扣掉
    假設 J♠ 有 1 張被你的手牌中的 J♥ 算入，另有 J♠ J♣ J♦ = 3 張 J 在牌組
    其中 J♠ 是黑桃，算在 flush outs 中

  去重後：8 + 9 - 1（J♠ 重複計算）= 16 outs

注意：這已是非常強的 draw！（16 outs ≈ 58% 的 equity 在 turn + river）
```

### 4.2 Double-Suited Rundown 的實際 Equity 例子

```
手牌：J♠ T♥ 9♠ 8♥（JT98 double-suited）
對手：A♠ A♥ K♠ K♥（AAKK double-suited）
翻牌：Q♠ 7♠ 2♦

計算：
  你的 equity：
    黑桃 flush draw（J♠9♠ 配 Q♠7♠）：你已有 4 張黑桃
    → 還需 1 張黑桃（9 outs - 已知 4 張 = 9 張剩餘黑桃在牌組）

    Wrap draw：Q-J-T-9-8 → 用 JT（手）或 T9（手）
      用 T9（手）配 Q72（公）：T-9 + Q，需要 J（4 outs，你手有一張）或 8（你手有，不算）
      用 J8（手）配 Q72（公）：J + Q + 8，不成好連線
      → 順子 outs 約 4-8 個

  你的總 equity 約 45-55%（對手有 Nut flush draw，你有非 Nut flush draw）

  在這個翻牌，Double-Suited JT98 對 AAKK Double-Suited 約是接近 50/50！
  這展示了 rundown 手牌的強大：對 AA 的比賽中接近平手
```

## 五、如何用 Rundown 打多人底池

### 5.1 多人底池的優勢

Double-Suited Rundown 在多人底池（3+ 人）中特別有價值，原因是：

```
在多人底池中，你的 Draw 價值更高，因為：
  - 底池更大（多人入池 = 更大獎勵）
  - 你的 Nut draw 命中後，贏取更多籌碼
  - 弱手的玩家會在底池中拿著非 Nut 的 made hands，給你機會跑牌

例子：
  3 人底池（底池：30bb）
  你有 JT98 ds，翻牌有 Nut wrap draw（20 outs）
  → 你有約 70% equity
  → 每個 bb 的期望值：0.7 × 30bb = 21bb（你投入了 10bb）
  → +EV

  vs 單挑底池（底池：10bb）
  同樣的情況
  → 每個 bb 的期望值：0.7 × 10bb = 7bb（你投入了 5bb）
  → 仍然 +EV，但絕對值較小

多人底池讓 rundown 的相對 EV 更高（因為底池更大）。
```

### 5.2 在多人底池的具體策略

```
策略 1：主動建底池（翻牌前加注）

如果你有 A 級 Double-Suited Rundown（如 AKQJ ds, JT98 ds）：
  → 翻牌前加注（3-5bb）鼓勵多人跟注
  → 目標是建立 20-30bb 的底池
  → 翻牌後你的 draw 有更大底池可以贏

策略 2：翻牌後的下注選擇

  有 Nut draw（20 outs wrap + flush）：
    → 積極下注（pot bet）= 建立更大底池 + 保護 equity
    → 即使被跟注或加注，你仍然有 equity 可以繼續

  有 Non-nut draw（8-13 outs）：
    → 謹慎，考慮是否值得繼續
    → 在多人底池中，non-nut draw 命中也可能輸

策略 3：多人底池的 Equity Denial

有時候你需要「拒絕對手的 equity」：
  → 如果你有 strong made hand + weak draw，可以 pot bet 拒絕免費牌
  → 如果你有 Nut draw + no made hand，pot bet semi-bluff

  注意：在 PLO 多人底池中，你無法「驅逐」所有對手
  現實是多人底池中的 Nut draw 應該充分進攻，非 Nut draw 應謹慎
```

### 5.3 Multi-way 底池的 Rundown 手牌例子

```
情境：4 人底池
你的位置：BTN
你的手牌：T♠ 9♥ 8♠ 7♥（T987 double-suited）
底池：20bb（4 人各出 5bb）
翻牌：J♠ 6♠ 2♥

分析：
  你的優勢：
    黑桃 flush draw（T♠8♠）：2 張黑桃在手，J♠6♠ 在公牌 = 你有 4 張黑桃！
    → flush draw 激活，需要 1 張黑桃 = 9 outs
    但：T♠8♠ 不是 Nut flush（A♠X♠ 打敗你）→ Non-nut flush draw ⚠️

    Wrap draw：J-T-9-8-7 = 你有 T-9-8-7（用 T9 或 98 配 J），需要填頂端或底端
      用 T9（手）配 J-6-2：J-T-9 已有！缺 Q（做 K-Q-J-T-9 或 Q-J-T-9-8）
        Q = 4 outs（做 Q-J-T-9-8，你用手牌 T9）
        8 在手牌（T9 + J → 缺 Q 或 8，8 在手中？等等，用 T9 做 2 張手牌，8 不在）
        所以：需要 Q（4 outs）或 8（若 8 可以從牌組來：你手中有 8♠，但你選了 T9...）

        等等，讓我重新釐清：你「手牌」是 T♠9♥8♠7♥，你可以選任意 2 張
        如果你選 T♠9♥（2 張手牌），那 8♠7♥ 就不使用
        → T♠9♥ + J♠6♠2♥（公牌 3 張）= T-9 + J = J-T-9，缺 Q 或 8
        → Q：4 outs，8：4 outs
        → Wrap outs：8 個

      用 98（手）配 J-6-2：9-8 + J = J-9-8，不連（J 和 9 中間缺 T）
        需要 T（你手中有 T，若選 98 就不用 T）→ T 的 outs：3 張在牌組（T♠ 在你手）
        和 7（在你手 7♥，若選 98 就不用）→ 7 outs：3 張在牌組
      → 這個組合：6 outs

      用 87（手）配 J-6-2：8-7 + 6 = 8-7-6，缺 T 和 9（需要兩張填補）
        → 無法 1 張完成

      最強 wrap 組合：用 T9，8 個 outs

  總 outs：
    Flush：9（但 Non-nut，減值）
    Wrap：8
    重複（例如 Q♠ 同時是 flush 和 straight）：~1
    淨 outs：約 16

  BUT：Flush 是 Non-nut（危險！）

  正確策略：
    → 主要依賴 Wrap draw（8 outs，命中後是 J-high straight，可能是 Nut）
    → Flush draw 是 bonus，但不要過度依賴（Non-nut）
    → 在多人底池跟注（而非 pot bet）因為 flush 不是 Nut
    → 如果翻牌後對手 bet pot，評估你的 straight outs 是否足夠

  這個手牌在這個翻牌：中等強度，謹慎追牌
```

## 六、Double-Suited Rundown 的常見錯誤

### 錯誤 1：過度重視 Non-Nut Flush Draw

```
❌ 錯誤思維：「我有 flush draw！我要繼續！」
✅ 正確思維：「我的 flush draw 是 Nut 嗎？如果不是，命中後還安全嗎？」
```

### 錯誤 2：在單調翻牌（Monotone Board）過度激進

```
如果翻牌是三張同花（如 K♠Q♠J♠），你有兩張黑桃：
  你已成 flush，但你的 flush 可能不是 Nut
  → 在三同花翻牌，已成 flush 的玩家很多，高 flush 才有價值
  → Non-nut flush 在三同花翻牌是危險的 made hand
```

### 錯誤 3：忽視 Rundown 在乾燥翻牌的弱勢

```
你有 JT98 ds，翻牌 A♥ 2♦ 7♣（乾燥，不連接你的牌）：
  → 你幾乎沒有任何 draw（翻牌和你的手牌完全不連接）
  → 你的 JT98 在這個翻牌是空氣
  → 正確：check 或棄牌（如果有人下注）

Rundown 手牌在 connected 翻牌（有連接你的牌面）才有價值
在乾燥、不連接的翻牌，Rundown 的強度大幅下降
```

## 八、章節總結

| 核心概念 | 要點 |
|---------|------|
| Double-Suited Rundown | 同時有兩組同花 + 4 張連牌，奧馬哈最強起始牌類型之一 |
| 優勢 | 兩條獨立 flush draw 路線 + Wrap draw，比 single-suited 高 ~4-8% equity |
| Nut 優先 | 含 A 的同花組（Nut flush draw）遠優於 Non-Nut flush draw |
| Wrap Draw Outs | 最多 20 outs（上兩下兩 = Nut wrap），比標準 OESD 多 12 outs |
| 多人底池 | Rundown 在多人底池中價值最高（更大的底池獎勵） |
| 乾燥翻牌 | Rundown 在不連接的乾燥翻牌幾乎無效，需謹慎 |
