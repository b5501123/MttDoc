# 起始牌策略 01：起始牌選擇（分級系統）

> **學習目標**：建立奧馬哈起始牌的 A-F 分級系統，掌握每個等級的具體例子，能夠在翻牌前快速判斷手牌質量，做出正確的進入/棄牌決定。

---

## 一、為什麼奧馬哈的起始牌選擇至關重要？

在德州撲克中，即使翻牌前起始牌稍差，你仍然可以透過位置、讀牌、bluff 等技術彌補。

在奧馬哈（特別是 PLO）中，**翻牌前的選牌是你最重要的決策之一**，原因是：

1. **翻牌後 equity 差距往往不大**：奧馬哈中等牌和強牌的 equity 差距比德州撲克小，意味著你很難用後期技術彌補翻牌前的選牌錯誤
2. **非 Nut draw 代價高昂**：如果起始牌質量差，你翻牌後做出的 draw 往往是 Non-nut，追牌有風險
3. **PLO 的底池限注格式**：大注很快就會建立，翻牌前的范圍選擇影響深遠

---

## 二、A 級起始牌（頂級，任何位置可以加注進入）

A 級手牌是奧馬哈中最強的起始牌，這些手牌同時具備：
- 強 Nut flush draw 潛力
- 強 Nut straight draw 潛力
- 多條贏牌路線

### A 級手牌完整列表

**A+ 級（極頂級，三提/四提也可跟）**：

| 手牌 | 說明 |
|------|------|
| A♠A♥K♠Q♥（AA ds, connected） | AA + 高連牌 + 雙同花，奧馬哈最強之一 |
| A♠A♥K♥Q♠（AA ds, connected） | 同上，排列不同 |
| A♠A♥J♠T♥（AA ds, JT connected） | AA + 強連牌 + 雙同花 |
| A♠K♠Q♥J♥（AKQJ ds） | 高連牌雙同花，Nut draw 機器 |
| A♠K♥Q♠J♥（AKQJ ds 另一種） | 同上 |

**A 級（強牌，標準加注）**：

| 手牌 | 說明 |
|------|------|
| A♠A♥K♠J♥（AA ds, 一缺口） | AA + 雙同花，略有缺口 |
| A♠A♥Q♠J♥（AA ds, connected） | AA + 雙同花 QJ |
| K♠K♥Q♠J♥（KK ds, connected） | KK + 高連牌 + 雙同花 |
| Q♠J♠T♥9♥（QJTS ds） | 高位連牌雙同花 |
| J♠T♠9♥8♥（JT98 ds） | 強中位連牌雙同花 |
| T♠9♠8♥7♥（T987 ds） | 中位連牌雙同花 |

### A 級手牌的共同特徵

```
✅ 共同點：
  - Double-suited（兩組同花，最好其中一組有 A）
  - 有 AA 或高位連牌（AKQJ, KQJT 等）
  - 4 張牌協同工作，無 dangling card
  - 能做出多條 Nut draw 路線
```

**翻牌前行動**：
- 作為 CO/BTN/SB：標準開牌（2-3x）
- 作為 EP/MP：可以開牌，但需要注意多人底池
- 面對加注：可以三提（3-bet）或跟注（取決於位置）
- 面對三提：A+ 級可以四提，A 級通常跟注

## 三、B 級起始牌（強牌，多數位置可進入）

B 級手牌比 A 級稍弱，但仍然是奧馬哈的優質起始牌。它們通常缺少一個 A 級特徵（比如只有 single-suited 而非 double-suited，或有一個缺口）。

### B 級手牌完整列表

**B+ 級（強牌，多數位置加注）**：

| 手牌 | 說明 |
|------|------|
| A♠A♥K♦Q♣（AA, connected, rainbow） | AA + 高連牌，但 rainbow 無同花 |
| A♠A♥J♦T♣（AA, connected, rainbow） | AA + 中高連牌，rainbow |
| K♠K♥Q♠J♦（KK ss, connected） | KK + 單同花高連牌 |
| A♠K♠Q♦J♣（AKQ single-suited, connected） | AKQ 連牌但只有一個同花 |
| Q♠J♠T♥9♦（QJTS single-suited） | 高連牌但只有一個同花 |
| A♠A♥2♠2♥（AA double-suited, low pair） | AA 雙同花，但低對協同差 |

**B 級（中強牌，多數位置跟注/部分位置開牌）**：

| 手牌 | 說明 |
|------|------|
| T♠9♠8♥7♦（T987 single-suited） | 中位連牌單同花 |
| J♠T♥9♠8♦（JT98 single-suited） | 中高連牌單同花 |
| A♠K♠J♦T♣（AKJ ss, 一缺口） | 高位連牌一缺口但有 Nut flush |
| K♠Q♠J♥T♣（KQJT single-suited） | 高連牌單同花 |
| Q♠Q♥J♠T♣（QQ connected, single-suited） | 中強對子 + 連牌 |
| J♠J♥T♠9♣（JJ connected, single-suited） | 中對 + 連牌 |
| A♠J♠T♥9♥（AJTS ds, 一缺口） | 雙同花但有缺口 |

### B 級手牌的共同特徵

```
✅ 共同點：
  - 通常是 single-suited（一個同花）或 AA 但協同性一般
  - 有高牌（A/K/Q）且具備一定連接性
  - 能做出 Nut flush draw 或接近 Nut 的 straight
  - 可能有一個缺口但整體仍有多條路線
```

**翻牌前行動**：
- 作為 CO/BTN：標準開牌
- 作為 EP/MP：多數可開牌，面對多個對手的加注要謹慎
- 面對加注：多數情況跟注（IP），OOP 時更謹慎
- 面對三提：通常棄牌，除非有位置優勢（BTN 對 SB/BB 的三提可以跟）

## 四、C 級起始牌（可接受，需要好位置）

C 級手牌有一定價值，但需要有利位置（BTN/CO）或者特殊場合（多人 limped pot、有弱玩家）才值得進入。

### C 級手牌完整列表

**C+ 級（位置有利時可進入）**：

| 手牌 | 說明 |
|------|------|
| A♠A♥7♦2♣（AA, no connectivity） | AA 但其他牌完全無配合 |
| 9♠8♠7♥6♦（9876 single-suited） | 中低位連牌單同花 |
| K♠Q♠J♦9♣（KQJ9，一缺口 ss） | 高位連牌有缺口，單同花 |
| A♠K♥Q♦J♣（AKQJ rainbow） | 高牌連牌但 rainbow |
| T♠T♥9♠8♣（TT connected, single-suited） | 中對 + 連牌 |
| 8♠7♠6♥5♥（8765 double-suited） | 低中位連牌雙同花 |

**C 級（謹慎使用，主要從 BTN 進入）**：

| 手牌 | 說明 |
|------|------|
| A♠A♥3♦2♣（AA, very low other cards） | AA 但低對 dangling cards |
| J♠T♦9♠8♣（JT98 rainbow） | 中高連牌但 rainbow |
| K♠J♠T♦9♣（KJT9，一缺口 ss） | 有缺口 + 單同花 |
| A♠Q♠J♦T♣（AQJ single-suited, 一缺口） | 高牌一缺口 |
| 7♠6♠5♥4♥（7654 double-suited） | 低位連牌雙同花（做出 non-nut）|

### C 級手牌的問題

```
⚠️ 常見缺陷：
  - 可能做出 Non-nut draws（特別是低位連牌）
  - 協同性不夠完美（有缺口或 rainbow）
  - AA 配低牌時，翻牌後如果不中 Set，手牌幾乎無用

⚠️ 使用建議：
  - 僅從 BTN/CO 開牌進入（後位優勢補償弱牌質）
  - 多人 limped pot 時跟注（小成本多人攤牌）
  - 面對加注通常棄牌（OOP 時一定棄牌）
```

## 五、D 級起始牌（弱牌，通常應棄牌）

D 級手牌在大多數情況下應該直接棄牌。它們在少數特定場合（極有利位置、特殊底池結構）可以考慮，但整體期望值偏負。

### D 級手牌例子

| 手牌 | 問題 |
|------|------|
| 6♠5♠4♥3♥（6543 ds） | 做出 non-nut，低位連牌贏底池小 |
| A♠7♥4♦2♣（A 配廢牌） | A 有價值但其他 3 張完全無配合 |
| K♠9♠8♦7♣（大缺口） | 缺口太大，難以做出強 draw |
| Q♠J♦9♣7♥（多缺口，rainbow） | 連接性差，無同花，多缺口 |
| A♠K♠4♦2♣（高牌配低廢牌） | AK 同花但其他無配合 |
| 5♠5♥4♦3♣（低對低連牌） | 所有 draw 都是 Non-nut |
| J♠8♦5♣2♥（完全不連接） | Dangling cards 太多 |

---

## 六、F 級起始牌（直接棄牌）

F 級是應該在任何情況下（包括 BTN）直接棄牌的手牌。

### F 級手牌例子

| 手牌 | 原因 |
|------|------|
| K♠9♥5♦2♣（完全廢牌） | 無連接、無同花、無大對 |
| Q♠8♥4♦2♣ | 同上 |
| J♠7♥3♦3♣（低對無連） | 低對價值極小，無配合 |
| T♠6♥3♦2♣ | 完全廢牌 |
| A♠A♥A♦K♣（三張 A） | 重複使用了 A，浪費同花資源 |
| 8♠4♥3♦2♣ | 低位廢牌 |
| K♠K♥2♠2♥（KK 22 rainbow） | 對子不連，rainbow，無 draw 潛力 |
| 9♠7♦5♣3♥（跳空廢牌） | 雙缺口且 rainbow |

## 七、起始牌分級的動態調整

### 7.1 位置的影響

```
同一手牌，位置不同，可開牌等級不同：

例：KQJT rainbow（C 級基礎評分）

UTG 開牌建議：❌ 棄牌（位置最差，需要更高質量手牌）
MP 開牌建議：△ 邊緣（視桌上特徵）
CO 開牌建議：✅ 可以開牌（後位有優勢補償）
BTN 開牌建議：✅ 積極開牌（最佳位置）
SB 開牌建議：△ 謹慎（OOP 劣勢）
BB 開牌建議：△ 視加注大小跟注（已有強迫下注）
```

### 7.2 MTT vs Cash Game 的調整

在 **MTT（多桌錦標賽）** 中，起始牌選擇需要額外考慮：

| 調整因素 | MTT 中的影響 |
|---------|------------|
| 籌碼深度（Stack Depth） | MTT 後期常見短疊，短疊下 PLO 打法改變 |
| MTT 氣泡（Bubble） | 氣泡前收緊範圍，避免在邊緣局面冒險 |
| 籌碼領先 | 可以適度放寬範圍，用深籌碼壓制對手 |
| ICM 壓力 | 最終桌附近，降級的代價比現金局更高 |

### 7.3 多人底池的調整

```
單挑（Heads-up）：可以放寬進入範圍（對手只有 1 人）
3 人底池：標準範圍
4+ 人底池（多人 limp）：收緊非 Nut draw 類手牌，放寬強 draw 類手牌
```

## 八、特殊情況分析

### 案例 1：面對 3-bet（三提）應該如何調整？

```
面對 3-bet 的跟注條件（at least one of these）：
  ✅ 你有 AA（任何 AA 幾乎都可跟 3-bet）
  ✅ 你有 A 級 double-suited 手牌
  ✅ 你有位置（BTN 對 SB 的 3-bet）
  ✅ 3-bet 者的 range 寬（loose aggressive 玩家）

面對 3-bet 的棄牌信號：
  ❌ 你有 C 級以下手牌
  ❌ 你在 OOP（盲注位置）
  ❌ 這是 tight 玩家的 3-bet
```

### 案例 2：多人 limped pot 應該如何調整？

```
多人 limped pot（比如 4-5 人 limp 進入）:

A 級手牌：加注（隔離弱手並建立底池）
B 級手牌：可以加注，也可以 limp 進入
C 級手牌：limp 跟注（不加注，但值得見翻牌）
D 級手牌：通常棄牌（即使便宜，不值得見翻牌）

理由：多人底池意味著你需要更強的牌力才能贏，
      弱 draw 手牌在多人底池追牌不划算。
```

### 案例 3：MTT 短疊時的調整

```
當你的有效籌碼 < 25bb 時（短疊）：

PLO 短疊策略完全不同：
  - 短疊時，底池在翻牌前加注後可能已有一半以上
  - 實際上接近 Shove 或 Fold 的決策

短疊下的起始牌調整：
  - AA 任何搭配：強制加注（可能直接全押）
  - KK/QQ + 高牌：值得 shove
  - 高連牌（KQJT, QJTS）：視深度
  - 低連牌：通常不值得短疊 shove
```

## 九、起始牌選擇速查表

```
位置 → 最低進入等級

UTG：A 級（非常謹慎，只有頂級才開牌）
UTG+1：A 級到 B+ 級
MP：B 級（可開一些強 B 級）
HJ：B 級到 B- 級
CO：B 級（B- 也可以）
BTN：C 級（B/C 界線，加注範圍寬）
SB：B 級（OOP 不利，要謹慎）
BB：特殊（已有強迫注，視具體加注大小）
```

## 十、章節總結

| 等級 | 描述 | 進入策略 |
|------|------|---------|
| A | 最強，多路線 Nut | 任何位置加注進入，可 3-bet |
| B | 強，缺一個特徵 | 多數位置進入，謹慎 3-bet |
| C | 可接受，需位置 | 只從 BTN/CO 進入 |
| D | 弱，期望值偏負 | 通常棄牌 |
| F | 廢牌 | 一律棄牌 |

**核心選牌標準**：
> 一手好的奧馬哈起始牌必須能夠做出 **Nut flush draw** 和/或 **Nut straight（wrap）draw**。不能做出任何 Nut 的手牌，長期期望值為負。
