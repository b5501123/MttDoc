# 起始牌策略 02：位置與起始牌（9-max 位置分析）

> **學習目標**：理解 9-max 奧馬哈中各個位置的策略差異，掌握位置對起始牌選擇的影響，學會根據位置調整開牌範圍和應對策略。

---

## 一、位置的重要性：奧馬哈比德州撲克更敏感

在德州撲克中，位置很重要，但有時可以用技術部分彌補。

在奧馬哈（PLO）中，**位置的重要性更高**，原因是：

1. **翻牌後頻繁面對 draw vs made hand 的對抗**：後位（IP）可以看對手如何行動後再決定是否繼續
2. **PLO 底池增長快**：後位玩家能根據前位的下注大小調整決策
3. **保護手牌的困難**：前位（OOP）玩家難以有效保護強牌，因為不知道後面有多少對手
4. **Bluff 的可行性**：後位 bluff 更有效（對手的 check 更有意義），前位 bluff 幾乎無效

---

## 二、9-max 位置圖

```
9-max 位置（順時針，從莊家位計算）：

        BTN（莊家）
    CO           SB
  HJ               BB
MP                 UTG
   MP2         UTG+1
         UTG+2

位置縮寫說明：
  UTG（Under the Gun）   = 第一個行動的玩家，最差位置
  UTG+1                  = 第二個行動
  UTG+2                  = 第三個行動
  MP（Middle Position）  = 第四個行動
  MP2                    = 第五個行動
  HJ（Hijack）           = 第六個行動
  CO（Cutoff）           = 第七個行動，較好位置
  BTN（Button）          = 第八個行動，最佳位置（最後行動）
  SB（Small Blind）      = 第九個行動，但翻後是第一個行動（OOP）
  BB（Big Blind）        = 最後翻牌前行動，但翻後第二個行動（OOP）

翻牌後行動順序（永遠從 SB 開始）：
  SB → BB → UTG → UTG+1 → ... → BTN
```

## 三、各位置起始牌策略詳解

### 3.1 UTG、UTG+1、UTG+2（早期位置）

**特徵**：
- 翻牌前後都要先行動
- 後面有 6-8 名玩家，你的開牌 range 必須很強
- 即使贏得一個底池，你也是在對抗最多的對手

**開牌範圍（UTG）**：

```
A 級手牌（全部可以）：
  AA double-suited（任何搭配）
  AA single-suited + high connector（如 AA+KQ, AA+KJ, AA+QJ）
  AKQJ double-suited
  高位連牌 double-suited（KQJT ds, QJT9 ds, JT98 ds）

B+ 級部分（謹慎）：
  AA rainbow + connected（如 AAKQ rainbow）
  KK double-suited + connected
  AKQJ single-suited

B 級以下：通常棄牌

特殊考量：
  - MTT 氣泡附近：收緊至 A+ 級
  - 深籌碼（200bb+）：可以略微放寬 draw 類手牌
  - 短疊（< 30bb）：只有 AA 和少數強牌值得 shove
```

**為什麼 UTG 開牌範圍要窄？**

```
UTG 開牌後的場景分析：
  → 8 個玩家還沒有行動
  → 平均會有 2-3 名玩家跟注
  → 你在翻牌後永遠是第一個行動（OOP）
  → 即使翻到好牌，你也不知道後面的玩家手中有什麼

反例：UTG 開牌 QJT9 rainbow（C 級手牌）
  問題：
  1. 被 3-bet 時你必須棄牌（浪費了開牌投入）
  2. 多人跟注時你在 OOP，難以保護手牌
  3. 做出的 draw 可能是 Non-nut（QJT9 的順子在高牌公牌面上不是 Nut）
  結論：UTG 這手牌應該棄牌
```

---

### 3.2 MP、MP2（中期位置）

**特徵**：
- 仍在 OOP（翻牌後不是最後行動）
- 前面已有 3-4 人棄牌，後面還有 4-5 人
- 可以比 UTG 稍微放寬，但仍需強牌

**開牌範圍（MP）**：

```
全部 A 級：開牌
B+ 級：大多數可以開牌
B 級：位置好時開牌，以下手牌例外需謹慎：
  - B 級 rainbow 手牌（缺少同花支撐）
  - B 級有多個缺口的手牌

C+ 級：只有特殊情況（桌上很多弱手）
C 級以下：棄牌

具體例子：
  可以從 MP 開牌：
  A♠A♥J♠T♥（AA ds connected）✅
  K♠K♥Q♠J♦（KK ss connected）✅
  J♠T♠9♥8♥（JT98 ds）✅
  Q♠J♠T♦9♣（QJTS ss）✅

  MP 應該棄牌：
  Q♠J♦9♣7♥（多缺口 rainbow）❌
  A♠A♥3♦2♣（AA 廢牌搭配）❌（太弱的協同性）
  9♠8♠7♦6♣（低位 ss）△ 邊緣，謹慎
```

---

### 3.3 HJ（Hijack）

**特徵**：
- 後面只有 CO, BTN, SB, BB（4 人）
- 相對合理的位置開始放寬範圍
- 開牌後有機率只面對 1-2 名對手（比 UTG 好得多）

**開牌範圍（HJ）**：

```
比 MP 多開：
  大多數 B 級手牌都可以從 HJ 開牌
  C+ 級的強勢手牌也可以嘗試

加入的手牌類型：
  B 級 single-suited 連牌（如 QJT9 ss, JT98 ss）
  B 級 AA（即使協同性一般的 AA）
  中位連牌 double-suited（如 9876 ds, 8765 ds）
```

---

### 3.4 CO（Cutoff）

**特徵**：
- 後面只有 BTN, SB, BB（3 人）
- 相對較好的位置
- 可以開較多範圍，因為取得後位的機率高

**開牌範圍（CO）**：

```
B 級：全部可以開牌
C+ 級：大多數可以開牌
C 級：謹慎，視具體手牌

從 CO 新增的手牌類型：
  - 低中位連牌 double-suited（如 7654 ds, 6543 ds）→ 但記住，做出 Non-nut
  - 高位連牌 rainbow（如 KQJT rainbow）→ 接受
  - 帶中等缺口的高牌（如 AKQT, KQJT 各種搭配）

CO 開牌例子：
  A♠K♠Q♦J♣（AKQJ rainbow）✅（雖然 rainbow，但高牌連線）
  T♠9♠8♦7♣（T987 ss）✅
  K♠Q♥J♠T♦（KQJT ds）✅（雙同花高連牌，當然可以）
  8♠7♠6♥5♦（8765 ss）✅（中位連牌，位置補償）
  A♠A♥6♦3♣（AA 但其他牌差）△ 邊緣，只因 AA 的緣故
```

---

### 3.5 BTN（Button）— 最佳位置

**特徵**：
- 翻牌後永遠是最後行動（最佳 IP）
- 可以看所有玩家行動後再決定
- 開牌範圍最寬，可以「steal the blinds」

**開牌範圍（BTN）**：

```
開牌範圍：所有 B 級以上，以及許多 C 級

BTN 獨特的加入手牌：
  - 低位連牌（6543 ds, 5432 ds）→ 僅因為位置優勢
  - 低對配連牌（如 77 + 65）
  - Rainbow 高牌（AKQJ rainbow, KQJT rainbow）
  - 有缺口的 double-suited（如 AJT8 ds, KJT8 ds）

BTN 應該棄牌（仍然有限制）：
  完全廢牌（K752 rainbow 等）❌
  Low dangling card 手牌（AK52 rainbow 等）❌
  Triple-suited 低牌（A♠K♠Q♠2♣）❌

BTN 加注的策略目的：
  1. 搶先機（對 SB/BB 施壓）
  2. 建立可以翻牌後 c-bet 的底池
  3. 取得後位優勢（BTN 翻後位置最強）
```

---

### 3.6 SB（小盲注）

**特徵**：
- 翻牌前最後行動（只需決定是否補全大盲）
- 翻牌後永遠第一個行動（最差 OOP）
- 位置最差（除了 BB）

**SB 的策略**：

```
SB 加注入池的條件（更嚴格）：
  - A/B+ 級手牌：加注
  - B 級手牌：視情況（面對弱 BB 可以加注）
  - C 級以下：棄牌（OOP 的代價太高）

SB 特殊情況：
  只有 SB vs BB（所有人棄牌到 SB）：
  → 可以放寬到 C 級（因為只有 1 個對手，影響有限）
  → 甚至可以 limp 進入（試探 BB 的強度）

SB 面對開牌的跟注條件：
  - A 級：三提或跟注（很少棄牌）
  - B+ 級：跟注（三提有時）
  - B 級：謹慎跟注（需要很好的牌才行）
  - C 級以下：棄牌（OOP 代價太高）

常見錯誤：SB 用 C 級手牌跟注開牌，
          翻牌後 OOP 面對 c-bet 進退兩難
```

---

### 3.7 BB（大盲注）

**特徵**：
- 已強迫下注 1 個大盲
- 需要補的費用通常是 1bb（如果有人開牌你需要付差額）
- 翻牌後第二個行動（仍然 OOP，但不是最差的）

**BB 的跟注策略（防守大盲）**：

```
BB 的跟注「折扣」：
  你已經投入了 1bb，所以跟注的「邊際成本」更低
  例如：有人從 CO 開 3bb，你只需補 2bb 跟注（而不是全付 3bb）

BB 對單一開牌（CO, BTN 等）的跟注範圍：
  - 比 SB 稍微寬一點（因為「折扣」效果）
  - 但仍然受 OOP 限制

BB 跟注標準（面對標準 3bb 開牌）：
  高連牌（KQJT 以上）：跟注
  中連牌 ds（T987 ds, 9876 ds）：跟注
  AA 任何搭配：跟注或 3-bet
  B+ 以上：通常跟注
  C 級：視對手和具體牌型，邊緣案例
  D/F 級：棄牌

BB 的三提（3-bet）條件：
  - AA 手牌：積極 3-bet
  - A 級 double-suited：可以 3-bet
  - 目的是改善 OOP 劣勢（3-bet 讓對手 IP 不確定你的手牌）
```

## 四、OOP 的實際影響

### 4.1 OOP 玩家的翻牌後困境

```
情境：你在 UTG，持有 T♠9♠8♥7♥（B 級，double-suited）
你開牌，CO 和 BTN 跟注

翻牌：K♠ Q♠ 2♣（Nut flush draw for you T♠9♠）

你的問題：
  ✅ 你有 T♠9♠ = Nut flush draw（等 A♠ 在手的話才是真正 Nut，但 T♠9♠ 在黑桃牌面上至少是 T-high flush）
  ⚠️ 實際上你的 flush 不是 Nut！K♠、Q♠ 在公牌，A♠ 如果在 CO 或 BTN 手中你輸
  ⚠️ 你要先行動，不知道對手手中有什麼

  如果你 bet（領先行動）：
  → 對手如果有 AA/KK/AK 或 Nut flush draw（A♠X♠）可能加注
  → 你面對加注很難決策

  如果你 check（被動）：
  → 對手可能 check（資訊不明確）
  → 或對手 bet（你需要決定 call/raise/fold）
  → 你處於劣勢

OOP 的核心問題：「先行動」讓你暴露更多資訊，得到更少資訊。
```

### 4.2 位置優勢的量化影響

在奧馬哈中，**後位（IP）比前位（OOP）在同等手牌下有約 5-10% 的 EV 優勢**。

這意味著：
- 同一手 C 級手牌在 BTN 可能是 +EV 的（可以開牌），在 UTG 是 -EV 的（應棄牌）
- 同一手 B 級手牌在 BTN 可以 3-bet，在 SB 只能跟注

## 五、多人底池 vs 單挑（Heads-up）

### 5.1 多人底池（3+ 人）

多人底池對起始牌的要求：

```
多人底池的策略調整：

加強點（適合多人底池的手牌）：
  ✅ 高位 double-suited 連牌：贏底池更大（多人進入，底池更肥）
  ✅ Nut draw 能力強的手牌：多人底池更需要 Nut
  ✅ AA + 強搭配：Set 能贏多人的籌碼

削弱點（多人底池中貶值的手牌）：
  ❌ Non-nut draw 手牌：多人 = 更高機率有人有 Nut
  ❌ 中等 made hand（兩對等）：多人 = 更需要 Nut 牌型
  ❌ 小 Set（因為大 set 可能存在）
```

### 5.2 單挑（Heads-up）

單挑對起始牌的要求：

```
單挑的策略調整：

加強點（適合單挑的手牌）：
  ✅ High card（A, K 高牌）的相對價值上升
  ✅ 中等 made hand（兩對、Set 等）在單挑中更有效
  ✅ Bluff 更有效（只有 1 個對手）

調整行動：
  - 單挑時範圍可以更寬
  - BTN 可以幾乎任何 B 級以上手牌加注
  - 從 SB 對 BB 的跟注也可以放寬
```

## 六、針對 9-max MTT 的特殊考量

### 6.1 MTT 不同階段的位置策略

**早期（深籌碼，100-200bb）**：
```
  → 可以打更多 draw 類手牌
  → 連牌 ds 的價值更高
  → 翻牌後可以追更多 outs（deep stack = 更大的回報）
```

**中期（50-100bb）**：
```
  → 標準 PLO 策略
  → 位置影響最顯著的階段
  → 注意 ICM 考量（MTT 特有）
```

**氣泡期（Bubble）**：
```
  → 進入金圈前的謹慎期
  → 大部分玩家收緊範圍
  → 籌碼領先者：可以積極利用小籌碼玩家的氣泡壓力
  → 短籌碼者：只有強牌才 shove（AA, AK ds 等）
```

**後期（< 30bb）**：
```
  → 短疊奧馬哈：幾乎是 push/fold 策略
  → AA 永遠 shove
  → 高連牌 ds 值得 shove
  → 大多數 C 級以下棄牌
```

### 6.2 利用位置施加 ICM 壓力

MTT 特有的策略：在氣泡附近，後位（BTN/CO）玩家可以對短籌碼的盲注位置施加 ICM 壓力：

```
情境：氣泡還剩 5 人到進圈
  你在 BTN，籌碼 100bb
  BB 有 15bb（氣泡壓力最大）
  SB 有 25bb（有壓力）

即使你的手牌只有 C 級，你也可以從 BTN 加注，因為：
  - BB/SB 的 ICM 壓力讓他們不願意冒險
  - 即使他們有 B 級手牌，「輸掉」的代價（氣泡出局）遠大於「跟注並贏」的回報
  - 所以他們的跟注/三提範圍大幅縮水

注意：這是 ICM 策略，與純 EV 不同，需要了解 MTT 的 ICM 概念。
```

## 七、位置與起始牌的綜合決策框架

```
翻牌前決策流程：

步驟 1：評估手牌等級（A/B/C/D/F）
步驟 2：確認你的位置
步驟 3：查看已有的行動（有人開牌？有 3-bet？）

情況 A：無人開牌（你是第一個行動）
  A 級 → 加注（任何位置）
  B 級 → UTG/MP 謹慎，HJ/CO/BTN 加注
  C 級 → 只從 BTN 加注
  D/F → 棄牌

情況 B：有人開牌（你需要決定跟/加/棄）
  A 級 → 通常跟注或三提（BTN 積極三提）
  B+ 級 → IP 跟注，OOP 謹慎
  B 級 → IP 可跟，OOP 通常棄牌
  C 級以下 → 幾乎一律棄牌

情況 C：有三提（你面對 3-bet）
  A+ 級（AA ds 等）→ 可以四提或跟注
  A 級 → 跟注（IP），三提太緊時考慮棄牌（OOP）
  B 級 → 大多棄牌，除非有非常好的位置
  C 級以下 → 棄牌
```

## 八、章節總結

| 位置 | 最低開牌等級 | 特殊考量 |
|------|------------|---------|
| UTG/UTG+1/UTG+2 | A 級 | 最保守，只打強牌 |
| MP/MP2 | B+ 級 | 稍微放寬，但仍謹慎 |
| HJ | B 級 | 開始放寬 B 級範圍 |
| CO | B-/C+ 級 | 較多 C 級可以嘗試 |
| BTN | C 級（部分） | 最寬範圍，但仍有底線 |
| SB | B+ 級（加注） | OOP 嚴格，加注要強牌 |
| BB | B 級（跟注） | 折扣效果，略寬跟注 |

**核心原則**：
> 位置越差（越靠近 UTG 或 SB），起始牌要求越高。OOP 的代價在奧馬哈中比德州撲克更大，因此選牌標準必須更嚴格。
