### Q1｜奧馬哈基本規則

你的手牌：A♠ K♥ Q♦ J♣
公共牌：T♠ 9♥ 8♦ 7♣ 2♠

你的最強牌型是什麼？

**A.** A-K-Q-J-T（Broadway straight）
**B.** K-Q-J-T-9（K-high straight）
**C.** Q-J-T-9-8（Q-high straight）
**D.** A-K-Q-J-T-9（6 張牌組合）

<details>
<summary>答案與解析</summary>

**正確答案：A**

解析：
公共牌有 T-9-8-7，你有 A-K-Q-J（手牌 4 張）。

在奧馬哈，必須用**剛好 2 張手牌 + 3 張公牌**。

選擇手牌 A♠K♥ + 公牌 T♠9♥8♦？不，這需要確認能做出什麼：
- A-K + T-9-8 = A-K-T-9-8（不是 5 連）

讓我們試 Q-J（手牌）+ T-9-8（公牌）：
- Q-J-T-9-8 = Q-high straight ✓

試 K-Q（手牌）+ J-T-9（公牌，但公牌是 T-9-8-7-2，選 T-9-8）：
- K-Q + J？J 不在公牌...等等，公牌是 T-9-8-7-2

試 A-K（手牌）+ 公牌中選 Q-J-T？公牌沒有 Q 和 J！

正確分析：公牌是 T-9-8-7-2
- A♠K♥（手牌）+ T-9-8（公牌選）= A-K-T-9-8（不連）
- A♠J♣（手牌）+ T-9-8（公牌選）= A-J-T-9-8（不連，A 和 J 差 3 個）
- A♠J♣（手牌）+ J-T-9？J 不在公牌
- K♥J♣（手牌）+ T-9-8（公牌）= K-J-T-9-8（不連，K 和 J 差 Q）

等等，讓我重新看手牌和公牌：
手牌：A♠ K♥ Q♦ J♣
公牌：T♠ 9♥ 8♦ 7♣ 2♠

用 K♥Q♦（手牌）+ T♠9♥8♦（公牌 3 張）= K-Q-T-9-8（不連，Q 和 T 差 J）

用 Q♦J♣（手牌）+ T♠9♥8♦（公牌）= Q-J-T-9-8（Q-high straight！）

用 A♠K♥（手牌）+ T♠9♥7♣（公牌選）= A-K-T-9-7（不連）

最強的我能找到的是 Q-J-T-9-8（Q-high，選項 C）...

等等，選項 A 說 A-K-Q-J-T（Broadway），這需要 A-K-Q-J 在手牌（4 張），但你只能選 2 張！
所以 A-K-Q-J-T 需要 A 和 K（手牌 2 張）+ Q-J-T（公牌 3 張），但公牌沒有 Q 和 J！

所以正確答案應該是 **C：Q-J-T-9-8**（Q-high straight）
用 Q♦J♣（手牌）+ T♠9♥8♦（公牌）= Q-J-T-9-8

**實際正確答案：C**

注意：題目有一個小陷阱，讓你以為 AKQJ 都可以用，但公牌是 T-9-8-7-2，不包含 Q 和 J，所以 A-K 配公牌做不出 Broadway。你只能用手牌中的 Q 和 J 配公牌 T-9-8。

**關鍵學習點**：奧馬哈必須用 2 張手牌 + 3 張公牌，不能自行選擇。

</details>

### Q2｜手牌評估基礎

以下哪一手起始牌評級最高？

**A.** A♠A♥7♦2♣（AA rainbow，無連）
**B.** Q♠J♥T♠9♥（QJTS double-suited）
**C.** K♠K♥9♠8♥（KK double-suited，有連）
**D.** A♠K♠Q♥J♥（AKQJ double-suited）

<details>
<summary>答案與解析</summary>

**正確答案：D**

解析：

選項分析：
- A：AA 但其他牌完全無用（7 和 2 是 dangling cards），連接性差，rainbow，評級 C
- B：QJTS double-suited，高連牌雙同花，但缺少大對，評級 A-
- C：KK double-suited 且有輕微連接（K-9-8），但 K 和 9 之間差太多，評級 B
- D：AKQJ double-suited，四張完美連牌 + 雙同花 + A 高牌，評級 A+

AKQJ double-suited 的優勢：
1. A♠K♠ = Nut 黑桃 Flush Draw（最強！）
2. Q♥J♥ = Q-high 紅心 Flush Draw
3. A-K-Q-J 百老匯連牌 = 多種 Nut Wrap
4. 4 張牌全部有用，無 Dangling Card

**關鍵學習點**：評估奧馬哈起始牌的 4 個維度：連接性、同花性（Double-Suited 最強）、對子、高牌。AKQJ ds 在連接性和同花性上都達到頂級。

</details>

### Q3｜Nut 概念

翻牌：K♠ Q♠ J♥

以下哪手手牌持有人有 **Nut straight**？

**A.** 手牌：A♥T♦（持有 A 和 T）
**B.** 手牌：T♦9♣（持有 T 和 9）
**C.** 手牌：A♠9♠（持有 A♠ 和 9♠）
**D.** 手牌：9♦8♣（持有 9 和 8）

<details>
<summary>答案與解析</summary>

**正確答案：A**

解析：

翻牌 K-Q-J，分析可能的 Straight：

選項 A：A♥T♦ + K-Q-J = A-K-Q-J-T（Broadway = 最強 Straight！）
→ 這是 Nut Straight ✓

選項 B：T♦9♣ + K-Q-J = K-Q-J-T-9（K-high Straight）
→ 不是 Nut！如果有人有 AT，他的 Broadway 更強

選項 C：A♠9♠ + K-Q-J = A + 9 + K-Q-J = A-K-Q-J-9（不連，J 和 9 之間缺 T）
→ 不成順子！（A♠9♠ 配 K-Q-J 無法做出完整 5 連牌）

選項 D：9♦8♣ + K-Q-J = K-Q-J-9-8（不連，J 和 9 之間差 T）
→ 不成順子！

**關鍵學習點**：在奧馬哈，確認你的手牌能做出 Nut 非常重要。Broadway（A-K-Q-J-T）是翻牌 K-Q-J 上的 Nut Straight，只有持有 AT 的玩家才有。

</details>

### Q4｜手牌分級

以下哪一手牌最接近 **F 級（應直接棄牌）**？

**A.** 9♠8♠7♥6♥（9876 double-suited）
**B.** A♥A♦5♠5♣（AABB rainbow，兩對 A 和 5）
**C.** K♠9♥4♦2♣（完全無連接 rainbow）
**D.** J♠J♥T♠9♥（JJ connected double-suited）

<details>
<summary>答案與解析</summary>

**正確答案：C**

解析：

- A：9876 ds = B 級（中位連牌雙同花，有價值）
- B：AA55 rainbow = B-/C+ 級（AA 配低對，有兩個 Set 機會，但協同性差）
- C：K♠9♥4♦2♣ = F 級（K 孤立，其他三張完全無連接，rainbow，K 和 9 差距大）
- D：JJ connected ds = A-/B+ 級（中大對子 + 連牌 + 雙同花）

選項 C 的問題：
1. 無連接（K-9 差距太大，9-4-2 也不連）
2. Rainbow（無同花）
3. 有三張 Dangling Cards（4 和 2 完全無用）
4. 唯一的價值是 K，但單張 K 在奧馬哈沒有獨立贏牌能力

**關鍵學習點**：F 級手牌通常是「完全無連接 + 無同花 + 無大對」的組合。K 高牌在沒有配合的情況下是廢牌。

</details>

### Q5｜奧馬哈規則確認

你的手牌：A♠ A♥ A♦ K♣（三張 A）
公共牌：A♣ 2♥ 7♦ 8♣ Q♠

你能做出四條（Four of a Kind Aces）嗎？

**A.** 是的，A♠A♥A♦A♣ = 四條 A
**B.** 不能，因為你必須用剛好 2 張手牌，你只有 2 張 A 在你的手牌組合中能和公牌的 A♣ 搭配
**C.** 能，選任意 2 張 A（手牌）+ A♣（公牌）+ 任意 2 張公牌 = 三條 A，不是四條
**D.** 能，但需要選 A♠A♥（手牌）+ A♦A♣ = 四條，但 A♦ 在手牌不在公牌

<details>
<summary>答案與解析</summary>

**正確答案：C（用詞修正）**

解析：

你的手牌：A♠ A♥ A♦ K♣（4 張手牌）
公牌：A♣ 2♥ 7♦ 8♣ Q♠

你選 2 張手牌 + 3 張公牌（最多 5 張）：

要做四條 A（A-A-A-A + X）：
- 你需要 4 張 A 出現在你的最終 5 張牌中
- 你有 3 張 A 在手牌（A♠A♥A♦），公牌有 1 張 A（A♣）= 共 4 張 A
- 但你只能選 2 張手牌！你最多選 A♠A♥（2 張手牌 A），配上公牌 A♣ = 只有 3 張 A（三條）
- 你不能選 3 張 A（A♠A♥A♦），那違反「必須用 2 張手牌」規則

所以**你不能做出四條 A**，最多只能做出 A-A-A 三條（用 A♠A♥ 手牌 + A♣ 公牌）

答案是：你只能做出**三條 A**（三張 A = Trips），不能做四條。

**關鍵學習點**：手牌中有 3 張同點牌其實是「壞事」——你浪費了一個手牌位置（第三張 A 沒用），而且自己阻斷了做四條的可能（你佔了 3 張 A，公牌中只剩 1 張 A，加上你只能選 2 張 A 手牌 = 只有 3 張 A = 三條）。

</details>

### Q6｜手牌評估維度

在評估奧馬哈起始牌時，以下哪個維度「最不」重要？

**A.** 連接性（Connectivity）
**B.** 同花性（Suitedness）
**C.** 對子（Pairs）
**D.** 單張最大牌的絕對大小（如 「最大張是不是 A？」）

<details>
<summary>答案與解析</summary>

**正確答案：D**

解析：

奧馬哈手牌評估的 4 個核心維度：
1. 連接性：決定 Wrap Draw 的可能性（非常重要）
2. 同花性：決定 Flush Draw 的可能性（非常重要）
3. 對子：決定 Set 的可能性（重要）
4. 高牌：提供高位 Straight 和 Flush 的基礎（重要，但相對其他維度稍弱）

「單張最大牌的絕對大小」本身沒有連接性和同花性來得重要。一張孤立的 A（沒有配合）在奧馬哈的價值遠低於德州撲克。

反例：
- A♠K♥5♦2♣（有 A，但無配合）= D 級手牌
- 9♠8♠7♥6♥（無 A，但 Double-Suited Rundown）= B+ 級手牌

9876 ds 的期望值遠高於 AK52 rainbow，即使後者有 A 和 K。

**關鍵學習點**：在奧馬哈，手牌的「協同性（Synergy）」遠比單張大牌的絕對大小重要。

</details>

### Q7｜Nut Flush Draw vs Non-Nut

翻牌：J♠ 8♠ 3♦（兩張黑桃）

以下哪手手牌有 **Nut Flush Draw**？

**A.** K♠Q♠（持有 K 和 Q 黑桃）
**B.** A♠T♠（持有 A 和 T 黑桃）
**C.** Q♠J♣（持有 Q 黑桃 + J 梅花）
**D.** T♠9♠（持有 T 和 9 黑桃）

<details>
<summary>答案與解析</summary>

**正確答案：B**

解析：

Nut Flush Draw 要求：你的同花組合中必須包含 **A**（該花色的最高牌）。

- A：K♠Q♠ = K-high 黑桃 flush draw → Non-Nut（A♠ 的人打敗你）
- B：A♠T♠ = **A-high 黑桃 flush draw = Nut Flush Draw!** ✓（無人能比你的 flush 更大）
- C：Q♠J♣ = 只有 Q♠ 一張黑桃，無法做黑桃 flush（需要兩張黑桃手牌）
- D：T♠9♠ = T-high 黑桃 flush draw → Non-Nut（A♠, K♠, Q♠, J♠ 的人都打敗你）

**關鍵學習點**：Nut Flush Draw 必須持有 Ace of the flush suit（同花色的 A）。

</details>

### Q8｜起始牌與 Dangling Card

以下手牌中，哪一手有 **Dangling Card（浪費牌）**？

**A.** A♠K♠Q♥J♥（AKQJ double-suited）
**B.** Q♠J♠T♥9♥（QJTS double-suited）
**C.** A♠A♥K♣2♦（AA + K + 2）
**D.** 9♠8♠7♥6♥（9876 double-suited）

<details>
<summary>答案與解析</summary>

**正確答案：C**

解析：

- A：AKQJ ds = 每張牌都有作用（A♠K♠ 黑桃組，Q♥J♥ 紅心組，AKQJ 連線），無 Dangling Card
- B：QJTS ds = 同上，無 Dangling Card
- C：A♠A♥K♣2♦ = 2♦ 是 Dangling Card！
  - A♠A♥ = 一對 A（好）
  - K♣ = 高牌（有用，配 A 做順子或同花）
  - 2♦ = 完全不配合（不是黑桃/紅心/梅花的同花，數字 2 與 A-K 相差太遠，無法做 Nut Wrap）
  - 2♦ 是一張浪費的 Dangling Card
- D：9876 ds = 每張都有連接，無 Dangling Card

注意：有 Dangling Card 的手牌等於在打 3 張牌，大幅降低起始牌強度。

**關鍵學習點**：理想的奧馬哈起始牌中，4 張牌應該都有作用。有 Dangling Card（完全不配合的牌）會嚴重削弱手牌。

</details>

### Q9｜牌力通貨膨脹

在一個 5 人底池的奧馬哈翻牌後攤牌，最可能的「贏家」牌型是什麼？

**A.** 頂對（One Pair, Top Pair）
**B.** 兩對（Two Pair）
**C.** 順子（Straight）
**D.** 高牌（High Card）

<details>
<summary>答案與解析</summary>

**正確答案：C**

解析：

在奧馬哈（特別是 5 人多人底池），攤牌的平均強度遠高於德州撲克。

奧馬哈多人底池攤牌常見贏家牌型（從常見到少見）：
1. 順子（Straight）- 最常見的贏家牌型
2. 同花（Flush）- 非常常見
3. 葫蘆（Full House）- 在對子或三條翻牌上常見
4. 三條（Trips/Set）- 有時贏，但常輸給順子/同花
5. 兩對 - 在小底池偶爾贏，多人底池幾乎不贏
6. 一對 / 高牌 - 在奧馬哈多人底池幾乎永遠輸

與德州撲克的對比：
- 德州撲克 5 人底池攤牌平均強度：兩對
- 奧馬哈 5 人底池攤牌平均強度：順子

**關鍵學習點**：這就是為什麼「奧馬哈要追 Nut」——在多人底池，你需要順子以上的強牌才有獲勝的現實機會。

</details>

### Q10｜翻牌後牌力判斷

翻牌：A♠ A♦ K♥
你的手牌：K♠ K♦ Q♣ J♠

你的最強牌型是什麼？

**A.** Full House（KK full of AA，AAKK）
**B.** 三條 K（Three of a Kind Kings）
**C.** Full House（AA full of KK，KKAA）
**D.** 四條 K（Four of a Kind Kings）

<details>
<summary>答案與解析</summary>

**正確答案：A**

解析：

手牌：K♠ K♦ Q♣ J♠
公牌：A♠ A♦ K♥

你選 2 張手牌 + 3 張公牌：

選 K♠K♦（手牌）+ A♠A♦K♥（公牌）= K♠K♦ + A♠A♦ + K♥
= 三張 K（K♠K♦K♥）+ 兩張 A（A♠A♦）= **Full House（KKK over AA）！**

更完整表示：牌型為 **KKKAA（葫蘆，三條 K over 兩張 A）**

選項分析：
- A：Full House KK full of AA = 是的，但表述順序：葫蘆表示「三條 K over 一對 A」= KKK-AA ✓
- B：三條 K = 錯，你有葫蘆（比三條強）
- C：Full House AA full of KK = 錯，你有三條 K，不是三條 A（A 在公牌，你用手牌 K 配）
- D：四條 K = 錯，你只有 3 張 K（K♠K♦ 手牌 + K♥ 公牌），不是四條

**關鍵學習點**：奧馬哈中，確認自己能做出的最強牌型需要仔細核對「2 張手牌 + 3 張公牌」的規則。這個例子中，用 KK 手牌配 AAK 公牌做出了葫蘆。

</details>

### Q11｜翻牌前開牌決策

你在 **UTG**（9-max，100bb 深度）。你的手牌是：

T♠9♥8♠7♥（T987 double-suited）

你應該：

**A.** 開牌加注（Raise）
**B.** 跟注大盲（Call）
**C.** 棄牌（Fold）
**D.** 翻前全押（Shove）

<details>
<summary>答案與解析</summary>

**正確答案：C（但在許多情況下 A 也可以）**

解析：

T987 double-suited 是一手 B 級手牌，但在 **UTG** 這個最差位置，評估如下：

支持開牌的理由（選 A）：
- Double-Suited Rundown 是強牌
- 有 Nut Flush Draw 潛力和多種 Wrap

反對開牌的理由（選 C）：
- UTG 是最差位置（翻後永遠 OOP）
- 後面有 8 個玩家，開牌後很可能面對加注（3-bet）或多人跟注
- T987 ds 在 9-max UTG 是邊緣手牌
- 面對 3-bet 時必須棄牌（浪費開牌投入）
- 如果多人入池，你在 OOP 難以充分發揮 Rundown 的優勢

在標準 GTO 框架下，**UTG 的開牌範圍通常不包含 T987 ds**（這是 B 級，但 UTG 要求 A/B+ 級）。

然而，在較鬆散的牌局中（對手不常 3-bet，可以多人 limp）選 A 也有道理。

**實際結論**：在嚴格的 GTO 策略下，UTG 的 T987 ds 應該棄牌（C）。在 Exploitative 策略下（利用鬆散對手），可以開牌（A）。

**關鍵學習點**：位置是選牌的重要因素。同一手牌在 BTN 可以開牌，在 UTG 可能應該棄牌。

</details>

### Q12｜3-bet 的決策

你在 **BTN**，CO 開牌到 3bb。你的手牌是：

A♠A♥J♠T♥（AA double-suited, connected）

你應該：

**A.** 棄牌
**B.** 跟注（Call 3bb）
**C.** 3-bet（加注到約 10-11bb）
**D.** 4-bet（直接加注到 35bb+）

<details>
<summary>答案與解析</summary>

**正確答案：C**

解析：

A♠A♥J♠T♥ 是 A+ 級起始牌（AA double-suited + connected），在 BTN 面對 CO 開牌：

選 A（棄牌）：完全錯誤，這是最強的起始牌之一
選 B（跟注）：可行但不最優，你放棄了三提的價值
選 C（3-bet）：最佳！理由：
  - AA 是 3-bet 的最強動機
  - BTN 有位置優勢（IP）
  - 3-bet 建立更大底池（你有最強手牌 + 後位優勢）
  - 3-bet 到約 10-11bb（PLO 翻前 pot 3-bet ≈ 開牌 × 3.5）
選 D（4-bet）：只有在面對 3-bet 時才考慮 4-bet，這裡對手只是開牌（非 3-bet）

**關鍵學習點**：有 AA 時，特別是 AA double-suited，在有利位置應積極 3-bet 建立底池。

</details>

### Q13｜位置判斷

以下哪個說法關於奧馬哈位置是**錯誤的**？

**A.** 後位（BTN）玩家在翻牌後永遠最後行動，有資訊優勢
**B.** 在奧馬哈中，位置對策略的影響比德州撲克更小
**C.** SB 是翻牌後最不利的位置（永遠第一個行動）
**D.** OOP 玩家的起始牌要求比 IP 玩家更嚴格

<details>
<summary>答案與解析</summary>

**正確答案：B**

解析：

選項 A：正確。BTN 翻後永遠最後行動，能看到所有人行動後再決定。
選項 B：**錯誤！** 在奧馬哈中，位置對策略的影響比德州撲克**更大**（不是更小）。原因：翻後有大量 Draw 和複雜的 equity 計算，後位玩家的資訊優勢被放大。研究顯示同一手牌，IP 比 OOP 的 EV 高 5-10%（在奧馬哈，這個差距可能更大）。
選項 C：正確。SB 翻後第一個行動，是最差的 OOP 位置。
選項 D：正確。OOP 的位置劣勢在奧馬哈中需要用更強的手牌補償。

**關鍵學習點**：奧馬哈中位置的重要性被**放大**（不是縮小），因為每個玩家都有更多的 Draw 和 Made Hand 可能性，後位的資訊優勢更加有價值。

</details>

### Q14｜多人底池選牌調整

以下哪種手牌在「多人 limp pot（5 人以上）」中相對**升值**？

**A.** AA + 2 張無用牌（如 AA52）
**B.** 高位 Double-Suited Rundown（如 KQJT ds）
**C.** 單張 A + 3 張中等牌（如 AJ75）
**D.** 低對（如 33 + 72）

<summary>答案與解析</summary>

**正確答案：B**

解析：

在多人 limp pot 中，更多人入池意味著：
1. 底池更大（命中後能贏更多）
2. 需要更強的牌才能贏（多人競爭）
3. Nut Draw 的價值更高（底池更大）

**關鍵學習點**：Multi-way pots（多人底池）是高位 Double-Suited Rundown 的「天堂」——更大的底池 + 更多需要被打敗的玩家 = 你的 Nut Draw 命中後的巨大回報。

### Q15｜Double-Suited 的辨認

以下哪手牌是 **Double-Suited**（雙同花）？

**A.** A♠K♠Q♥J♣（三張黑桃一張梅花，非標準 ds）
**B.** A♠K♥Q♠J♥（兩張黑桃兩張紅心，perfect ds）
**C.** A♠K♠Q♠J♥（三張黑桃 + 一張紅心，triple-suited）
**D.** A♠K♥Q♦J♣（四種不同花色，rainbow）

<summary>答案與解析</summary>

**正確答案：B**

- A：A♠K♠Q♥J♣ = 有 A♠, K♠（黑桃對），Q♥（紅心，只有 1 張），J♣（梅花）
  → 這是 Single-suited（只有一對黑桃），不是 Double-Suited

- B：A♠K♥Q♠J♥ = A♠,Q♠（黑桃對）+ K♥,J♥（紅心對）

  → 這是 Triple-Suited（三同花），比 Double-Suited 弱！

- D：A♠K♥Q♦J♣ = 四種花色，無任何同花 = Rainbow，最弱的同花配置

**關鍵學習點**：Double-Suited = 正好兩種花色，每種各 2 張（2+2）。三種花色（Triple-Suited）雖然聽起來更多，但效率更低。

### Q17｜MTT 氣泡附近的選牌

你在 MTT **氣泡（Bubble）** 前 3 名，你的手牌是：

9♠8♥7♠6♥（9876 double-suited）

UTG 玩家（短疊，15bb）開牌 All-in。你（BTN，100bb）的最佳行動是？

**A.** 跟注（Call All-in）
**B.** 3-bet（加注到更大金額）
**C.** 棄牌（Fold）
**D.** 跟注（Call），因為你有 Double-Suited Rundown

<details>
<summary>答案與解析</summary>

**正確答案：C**

解析：

在 MTT 氣泡前，ICM 考量使這個決策複雜：

純 equity 分析：
- 9876 ds vs UTG 短疊的 range（主要是強牌，如 AA/AKQJ/KKxx）
- 你的 equity 可能是 40-45%（面對強 UTG range）

ICM 分析：
- 氣泡前，你有 100bb（大籌碼），進圈幾乎確定
- 跟注並輸掉 = 你剩下 85bb（損失 15bb，但仍安全）
- 跟注並贏 = 你有 115bb（增加 15bb）
- ICM 壓力讓「輸的代價」比「贏的收益」更大
- 你的 equity 必須更高（> 50-55%）才值得在氣泡冒 ICM 風險

9876 ds 的問題：
1. 這不是 AA 或 AKQJ ds 這種壓倒性的手牌
2. 面對 UTG 短疊（他的 range 很強），你的 equity 可能不足
3. ICM 壓力讓邊緣手牌的跟注成本更高

選項 A/D（跟注）：從純 EV 角度可能接近邊緣，但 ICM 考量讓跟注成本更高
選項 C（棄牌）：在氣泡前，保守的選擇保留你的 MTT 生存優勢

**關鍵學習點**：MTT 的氣泡前，即使手牌有 EV，ICM 考量也可能使棄牌更優。大籌碼在氣泡前有巨大的 ICM 優勢，不應輕易冒險。

</details>

### Q18｜起始牌範圍比較

### Q20｜起始牌的同花設計

以下兩手牌，哪一手在奧馬哈中**更強**？

**A.** K♠Q♠J♠T♥（3 張黑桃 + 1 張紅心，Triple-suited rundown）
**B.** K♠Q♥J♠T♥（2 張黑桃 + 2 張紅心，Double-suited rundown）

<details>
<summary>答案與解析</summary>

**正確答案：B**

解析：

兩手牌的連接性相同（K-Q-J-T，完美 rundown），差別只在同花配置。

選項 A（K♠Q♠J♠T♥）Triple-suited（三同花）：
- 黑桃組：K♠,Q♠,J♠（3 張黑桃）
  → 有效 Flush Draw 組合：K♠Q♠, K♠J♠, Q♠J♠（3 種組合，但只有一個 flush suit）
  → 但你的「對」只是其中 2 張，第三張「浪費」了
  → 紅心只有 T♥（1 張），無法做紅心 flush

- 問題：你只有**一個方向的 Flush Draw（黑桃）**，紅心沒有 Flush Draw

選項 B（K♠Q♥J♠T♥）Double-suited（雙同花）：
- 黑桃組：K♠,J♠（2 張黑桃）→ K-high 黑桃 flush draw（K♠J♠）
- 紅心組：Q♥,T♥（2 張紅心）→ Q-high 紅心 flush draw（Q♥T♥）

- 優勢：**兩個方向的 Flush Draw（黑桃 + 紅心）**，更多翻牌激活 flush draw

選項 B 在更多翻牌上有 flush draw 機會（黑桃翻牌 OR 紅心翻牌），所以 B > A。

這就是為什麼「Triple-suited 比 Double-suited 差」！三張同花不是「更多同花」，而是效率降低。

**關鍵學習點**：Double-Suited（2+2）比 Triple-Suited（3+1）更有效，因為它在兩個花色方向都有 Flush Draw 機會。

</details>

### Q21｜翻牌質地判斷

以下哪個翻牌對於你的 **Top Set（三條頂牌）** 來說**最危險**？

**A.** A♣ 7♦ 2♠（Rainbow，不連接）
**B.** K♠ Q♠ J♣（Three Broadway cards，兩張黑桃）
**C.** 9♥ 8♥ 7♣（中位連牌，兩張紅心）
**D.** A♠ A♦ K♣（對 A 翻牌）

<details>
<summary>答案與解析</summary>

**正確答案：B 或 C（B 更危險，但 C 也非常危險）**

解析：

如果你有 Top Set（如三條 K），不同翻牌的危險程度：

選項 A（A♣7♦2♠，Rainbow 乾燥）：
- 幾乎無 flush draw，無 straight draw
- 你的 Set 相對安全，equity ≈ 80%+
- 危險程度：低

選項 B（K♠Q♠J♣，高位連牌 + 兩張黑桃）：
- 你如果有 Set of K（三條 K）面對這個翻牌：
  → 任何有 AT 的人已成 Broadway（A-K-Q-J-T = Nut Straight）！

- 有大量 Wrap Draw（上下各有 outs）

- 危險程度：中（取決於具體情況）

**最佳答案：B**，因為 KQJ 翻牌讓有 AT 的人已成 Nut Straight，你的 Set 可能直接就輸了（不只是 equity 劣勢，而是可能直接被打敗）。

**關鍵學習點**：高位連牌翻牌（KQJ, QJT 等）是 Set 最危險的翻牌，因為有人可能已成 Straight。

### Q22｜Wrap Draw Outs 計算

公共牌：T♥ 9♠ 6♦（翻牌）
你的手牌：K♠ J♦ 8♣ 7♥

以下哪種手牌組合做出的 Wrap Draw 有最多 **outs**？

**A.** K♠J♦（選 K 和 J）配合翻牌 T♥9♠6♦
**B.** J♦8♣（選 J 和 8）配合翻牌
**C.** 8♣7♥（選 8 和 7）配合翻牌
**D.** K♠7♥（選 K 和 7）配合翻牌

<details>
<summary>答案與解析</summary>

**正確答案：C**

解析：

公牌 T-9-6，你的手牌組合分析：

選項 C（8♣7♥）+ T-9-6：
8-7 手牌 + T-9-6 公牌 = T-9-8-7-6（5 連牌！已成順子！）
等等，這已是 Made Hand，但題目問的是 Draw...

讓我重新理解題目：哪個組合在翻牌後有最多**outs**（即最多可以完成順子的牌）？

如果 C 已成，那就是 Made Hand 不是 Draw。

但如果我們問「命中 turn 能讓你成更強的順子」：
8♣7♥ + T-9-6 = T-9-8-7-6 = T-high straight（已成）
Turn 牌讓你更強：
- J 讓你成 J-T-9-8-7（J-high）→ 更強！（4-1=3 outs，J 在手牌減 1）
- 5 讓你成 9-8-7-6-5 = 9-high → 更弱，不想要
- Q 讓 Q-J-T-9-8？J 不在...
所以 C 有 3 outs 讓你的 T-high straight 升為 J-high straight。

但 C 已是 Made Hand（T-high straight），關鍵是各組合的「Total valuable outs」。

讓我重新評估各組合的最佳 draw potential：

A（KJ）+ T-9-6：K-J + T-9 連線，缺 Q 讓 K-Q-J-T-9（K-high，Nut）
→ outs：Q（4，減手中 0 = 4 outs），但 K 配 T-9-6 需要 Q 和 J 才成 Nut...
KJ + T96：最強連線 K-J-T-9，缺 Q（讓 K-Q-J-T-9）= 4 outs

B（J8）+ T-9-6：J-8 + T-9 連線，J-T-9-8（連），缺頂端（Q）或底端（7）
→ outs：Q（4）+ 7（4-1=3，7♥ 在手）= 7 outs

C（87）+ T-9-6：8-7 + T-9-6 = 已成 T-9-8-7-6 = Made Hand，outs 是讓你升為更強 straight
→ J（3 outs）= 升為 J-T-9-8-7

D（K7）+ T-9-6：K-T-9-7，不連（K 和 T 差 Q-J，7 和 9 差 8）= 幾乎無 straight outs

最多 outs：B（JT/J8）有 7 outs（Q 和 7），比 A（4 outs）和 D（~0）多

等等：B 是 J♦8♣，A 是 K♠J♦...

**重新計算 B**（J♦8♣）配 T♥9♠6♦：
J-T-9-8（J 手，T,9 公牌，8 手）= 已成 J-T-9-8（4 連）= 需要 7 或 Q 完成
- Q（4 outs）→ Q-J-T-9-8（Q-high straight）
- 7（4-1=3 outs，7♥ 在手牌）→ J-T-9-8-7（J-high straight）
B 的 outs = 7 個

**C（8♣7♥）配 T♥9♠6♦**：已成 made hand，是最好的情況（有 Made Hand 比 Draw 更強）

**最後答案：C** 是最強的，因為已成 Made Hand（T-high straight）。但如果題目問的是「outs」，B 有更多 draw outs（7 個）。

由於 C 已成 Made Hand，C 比所有 Draw 都強。**答案：C**

</details>

### Q23｜Flush Draw 的行動決策

翻牌後，底池 40bb，你在 IP（後位）。
你的手牌：A♠K♥Q♠J♥（Nut 黑桃 flush draw + 有連牌 Wrap）
翻牌：8♠5♠2♦（兩張黑桃，非連接翻牌）

對手 Check。你應該：

**A.** Check（保留資訊，等待 Turn）
**B.** Bet 20bb（Half Pot）
**C.** Bet 40bb（Pot Bet）
**D.** 什麼都不做（等攤牌）

<details>
<summary>答案與解析</summary>

**正確答案：C**

解析：

你的手牌分析：
- A♠Q♠（手牌）+ 8♠5♠（公牌）= 4 張黑桃 = Nut Flush Draw（9 outs，A-high）
- 連牌 Wrap：AKQJ vs 8-5-2（不連接），Wrap draw 效果有限（8 和 5 之間差太多）
- 主要優勢：Nut Flush Draw（9 outs）

對手 Check → 你是 IP

選項 A（Check）：放棄了 Semi-Bluff 的機會，免費給對手看 Turn（對手可能有 Set 等）
選項 B（Bet 20bb）：可行但不最優；20bb 的底池賠率讓對手更容易跟注 Flush Draw
選項 C（Pot Bet 40bb）：**最佳！**
  - 你有 Nut Flush Draw（Semi-Bluff）
  - Pot Bet 給對手最差的底池賠率
  - 即使對手 Call，你的 9 outs ≈ 35% equity → 你仍有合理的命中機會
  - 如果對手 Fold，你立即贏得底池（Fold Equity）

選項 D：沒有意義

**關鍵學習點**：有 Nut Draw 時，積極 Semi-Bluff Pot Bet 是最優策略（雙重收益：Fold Equity + Draw Equity）。

### Q24｜Monotone 翻牌的決策

翻牌：K♠Q♠J♠（三張黑桃，Monotone）
你的手牌：A♠T♣9♦8♦

你最好的牌型和應該採取的行動是？

**A.** 你有同花順（Straight Flush），積極下注
**B.** 你有 Nut Flush（A-high spade flush），積極下注
**C.** 你有 K-high Straight，謹慎下注
**D.** 你沒有黑桃，謹慎（不下注）

<details>
<summary>答案與解析</summary>

**正確答案：B**

解析：

你的手牌：A♠T♣9♦8♦
公牌：K♠Q♠J♠（Monotone 黑桃）

你選 2 張手牌：

用 A♠T♣ + K♠Q♠J♠：
- 黑桃牌：A♠（手），K♠,Q♠,J♠（公牌）= 4 張黑桃 + T♣（非黑桃）
- 最佳 flush：A♠ + K♠Q♠J♠（4 張黑桃）+ 需要第 5 張黑桃？已有 4 張 → 實際上已有 4 張黑桃在翻牌後 = **Flush Draw！**（還需要 1 張）

等等：翻牌有 3 張黑桃（K♠Q♠J♠），你手牌有 A♠ = 已有 4 張黑桃。等 Turn 或 River 來任何黑桃（9 outs）= Nut Flush Draw！

但更直接：公牌已有 3 張黑桃，你手牌有 A♠：
- 你已有 A♠ + K♠Q♠J♠（公牌）= 4 張黑桃（仍需第 5 張 = Flush Draw）

Wait：在 Monotone 翻牌，你需要 2 張手牌 + 3 張公牌：
用 A♠T♣（手牌 2 張）+ K♠Q♠J♠（公牌 3 張）= A♠ + K♠Q♠J♠ + T♣ = 只有 4 張黑桃（A♠K♠Q♠J♠）+ 1 張其他 = 4 張黑桃 = 仍需 5 張才成 flush

翻牌後仍是 Flush Draw（4 張黑桃，需第 5 張）？不對，翻牌已有 3 張黑桃 + 你有 1 張黑桃 = 翻牌時你已有 4 張黑桃（使用 A♠T♣ 手牌組合中的 A♠）。

**Flush 判斷**：翻牌有 3 張黑桃（K♠Q♠J♠），你手牌有 A♠。翻牌後，如果 Turn 或 River 來黑桃，你成 A-high flush（Nut Flush！）。目前是 Nut Flush Draw（9 outs）。

但還有個問題：你能已成 Nut Flush 嗎？翻牌只有 3 張（K♠Q♠J♠），你用 A♠T♣ 配 3 張公牌 = A♠ + K♠ + Q♠ + J♠ + T♣ = 4 張黑桃，不是 5 張 flush（需要 5 張同花才成 flush）。

所以你目前只有 Flush Draw（4 張黑桃，還差 1 張）。

選 B（Nut Flush Draw，積極下注）= 正確答案！

你有 Nut Flush Draw（A♠ 的黑桃 flush），命中後是最強的同花，應該積極 Semi-Bluff。

注意：選項 A 說「同花順」，但你還沒成 flush，更沒有 straight flush（需要 5 張連續同花）。

**關鍵學習點**：在 Monotone 翻牌，有 A 同花的玩家有 Nut Flush Draw（最強）。應積極下注（Semi-Bluff），因為命中後無可打敗。

### Q25｜保護手牌的決策

底池 50bb，多人底池（4 人）。你先行動。

**A.** Check（慢打，讓對手建底池）
**B.** Bet 25bb（Half Pot）
**C.** Bet 50bb（Pot Bet）
**D.** 直接 All-in（如果有效籌碼 100bb）

<details>
<summary>答案與解析</summary>

解析：

翻牌 T-9-8（中位連牌），你有 Set of T：
- 任何有 J-7 或 Q-J 的人有 Wrap Draw（甚至有人已成 Straight！）

### Q26｜Non-Nut Draw 的評估

翻牌：Q♠ J♦ T♠（高位連牌，兩張黑桃），底池 60bb

你有哪些 Draws？它們的質量如何？

**A.** Nut Flush Draw（A-high spade）= 高質量
**B.** Non-Nut Flush Draw（J-high spade）= 低質量
**C.** Nut Straight（K-high straight）= 高質量（已成）
**D.** 選項 B 和 D（Non-Nut Flush Draw + Nut Straight Wait = 中等組合）

<details>
<summary>答案與解析</summary>

**正確答案：D（應為 B + 其他 draw）**

解析：

你的手牌：J♠9♠8♥7♦
公牌：Q♠J♦T♠

**Flush Draw 分析**：
選 J♠9♠（手牌）+ Q♠T♠（公牌黑桃）= J♠9♠Q♠T♠ = 4 張黑桃，等待第 5 張
→ J-high 黑桃 flush drive = **Non-Nut Flush Drive！**（A♠,K♠ 的人可以打敗）
→ 選項 B 正確（低質量）

**Straight 分析**：
公牌 Q-J-T，你有 J 和 9 在手：
用 J♠9♠ + Q♠J♦T♠（公牌 3 張）：Q-J-J-T-9（有重複 J）= 一對 J + 高牌，非順子
用 9♠8♥ + Q♠J♦T♠：Q-J-T-9-8 = Q-high straight（已成！）
→ Q-J-T-9-8 = Q-high straight

是否是 Nut Straight？最強 straight on Q-J-T = A-K-Q-J-T（百老匯）
→ 有 AK 的人有 Broadway（比你的 Q-high 強）
→ 你的 Q-J-T-9-8 = 2nd Nut straight（Non-Nut！）

**結論**：
- Flush Drive：Non-Nut（J-high）= 低質量
- Made Straight：Non-Nut（Q-high，輸給 AK 的 Broadway）= 中等質量
- 組合：Non-Nut Made Straight + Non-Nut Flush Drive = **危險手牌**！

在 Q-J-T 翻牌上，你的牌雖然表面上很強（已成 straight，有 flush drive），但實際上都是 Non-Nut，非常危險。

正確行動：謹慎，面對大注可能應該棄牌或小跟。

**關鍵學習點**：在高位連牌翻牌（Q-J-T）上，即使你「做到了」順子，也要確認是否是 Nut。非 Nut 的強牌在奧馬哈中非常危險。

### Q27｜Check-Raise 的時機

你在 OOP（SB），翻牌 K♥ 7♠ 2♦（乾燥）。
你的手牌：K♠K♦Q♣J♥（KK + 連牌）→ 你有 **Top Set of K**。

對手（BTN，IP）先等你行動。你應該：

**A.** 直接 Pot Bet（K♥72 乾燥，Pot Bet 保護）
**B.** Check（等待 BTN 的 C-bet，然後 Check-Raise）
**C.** Check（讓 BTN 免費看牌）
**D.** 棄牌

<details>
<summary>答案與解析</summary>

**正確答案：B（通常更優；A 也合理）**

解析：

翻牌 K-7-2（Rainbow 乾燥）：
- 你有 Top Set of K
- 幾乎無 flush drive，straight drive 極少

在這種乾燥翻牌，你的 Set 非常強，幾乎無 drive 威脅。

選項 A（直接 Pot Bet）：可行，但問題在於：
- 乾燥翻牌上，弱牌（如 73, 22, 7x 等）面對 Pot Bet 可能直接棄牌
- 你失去了從弱牌身上贏取更多籌碼的機會

選項 C（純 Check）：如果 BTN 也 Check，你的 Set 沒有得到任何保護，免費給 Turn 牌

**最佳答案：B**，Check-Raise 在乾燥翻牌 OOP 持有 Set 時是很好的策略。

**關鍵學習點**：Check-Raise 在乾燥翻牌 + OOP Set 是經典策略，讓 IP 玩家的 C-bet 成為你建底池的工具。

### Q28｜Paired Board 的影響

翻牌：A♠ A♥ Q♦（對 A 翻牌）

你的手牌：Q♠ Q♥ J♣ T♠（QQ + JT，你有 Full House！）

等等：讓我計算你的牌型。
選 Q♠Q♥（手牌）+ A♠A♥Q♦（公牌）= Q♠Q♥A♠A♥Q♦ = 有 3 張 Q（Q♠Q♥Q♦）+ 兩張 A = **Full House（QQQ over AA）！**

你有 Full House。你應該：

**A.** 棄牌（太謹慎了）
**B.** 小注（1/3 pot）讓弱牌跟注
**C.** Pot Bet
**D.** 慢打（Check）讓對手建底池

<details>
<summary>答案與解析</summary>

**正確答案：D 或 B**

解析：

你有 Full House（QQQ over AA）。在 A-A-Q 翻牌上：

分析：
- 你的 Full House = QQQ-AA = 很強
- 但有 AA（兩張 A 在手牌）的人有四條（4 張 A）= 打敗你！
- 還有 AQ（手牌有 A 和 Q）的人可能有 AQ + AA 公牌 = A-A-A-Q 三條 A 以上（更強？）

等等：A♠A♥Q♦ 翻牌，有人有 A♣（一張 A）的手牌組合 + Q = 選 AQ 手牌 + A♠A♥Q♦ 公牌

用 A(手)Q(手) + A♠A♥Q♦：A♠A♥A（手）= 三條 A，Q♦Q（手）= 兩張 Q = Full House：AAA over QQ（更強！打敗你的 QQQ over AA）

所以如果有人有 AQ 在手，他的 Full House（AAA-QQ）打敗你的（QQQ-AA）！

翻牌 A-A-Q 上的 Nut：
- 有 AA（兩張 A 手牌）= 四條（Quads AA）= 最強
- 有 AQ（一張 A + 一張 Q）= Full House（AAA-QQ）= 第二強

鑒於你的 Full House 可能不是 Nut，你應該：
- 不要 Pot Bet（可能被 Raise 而陷入困境）
- 考慮慢打（D）或小注（B）
- 如果對手大注，需要謹慎

**最佳答案：D（慢打）或 B（小注）**，謹慎對待 A-A-Q 翻牌上的 Full House，因為你不是 Nut。

### Q30｜多人底池的 Outs 調整

你有一個 **Non-Nut Flush Drive（J-high 黑桃）**，標準 outs = 9。
在一個 5 人多人底池中，你應該如何調整這個 outs 數？

**A.** 保持 9 outs（不需調整）
**B.** 調整為 7-8 outs（輕微折扣）
**C.** 調整為 4-6 outs（大幅折扣）
**D.** 調整為 0 outs（完全無效）

<details>
<summary>答案與解析</summary>

**正確答案：C**

解析：

Non-Nut Flush Drive 的 outs 調整：

在 5 人多人底池中，有人可能持有 A♠X♠（Nut Flush Drive）：

- 在 9 人桌，A♠ 被某人持有的概率是約 50%（大約一半的情況）
- 在 5 人多人底池，有人持有 A♠ 的概率更高（他們留了下來，可能有黑桃手牌）

### Q31｜SPR 計算

翻牌前，SB 0.5bb，BB 1bb，CO 開牌 3bb，BTN 跟注，BB 跟注，SB 棄牌。
翻牌底池 ≈ 9.5bb（近似 10bb）。
有效籌碼（每人約 97bb）。

翻牌後的 SPR 是多少？

**A.** SPR = 1（短疊）
**B.** SPR ≈ 5
**C.** SPR ≈ 10
**D.** SPR = 20（深疊）

<details>
<summary>答案與解析</summary>

**正確答案：C**

解析：

SPR = 有效籌碼 / 底池大小

有效籌碼 = 每人剩餘籌碼（翻牌後）
= 100bb（初始）- 3bb（翻前投入）= 97bb

底池大小 = 9.5bb（近似 10bb）

SPR = 97 / 10 = 9.7（約 10）

**正確答案：C（SPR ≈ 10）**

這是「高 SPR」場景，意味著：
- 需要 3+ 輪 Pot Bet 才能 Stack off
- Drive 的隱含賠率較高
- 策略複雜性高（有更多決策街道）

**關鍵學習點**：理解 SPR 幫助你規劃翻牌後的整體策略。SPR ≈ 10 意味著你有充裕的「策略空間」。

</details>

### Q32｜PLO Pot Raise 計算

底池 30bb，對手 Bet 30bb（Pot Bet）。

你要 **Pot Raise**，你的總投入是多少？

**A.** 60bb
**B.** 90bb
**C.** 120bb
**D.** 150bb

<details>
<summary>答案與解析</summary>

**正確答案：C**

解析：

Pot Raise 計算步驟：

1. 底池 before bet = 30bb
2. 對手 Bet 30bb → 底池 after bet = 60bb

### Q33｜Deep Stack 策略

你的有效籌碼是 300bb（深疊），底池 20bb，對手 Bet 20bb。

你有 Nut Flush Drive（9 outs）。底池賠率 = 33%（你需要 33% equity 才合算）。
你的 equity = 35%（9 outs）。

光看底池賠率，是否值得 Call？考慮隱含賠率後呢？

**A.** 不值得 Call（35% < 需要的 50%）
**B.** 值得 Call（35% > 33%，邊緣但合算）
**C.** 值得 Call，深疊的隱含賠率大幅增加你的 EV
**D.** 不確定，需要更多資訊

<details>
<summary>答案與解析</summary>

**正確答案：C**

解析：

光看底池賠率：
- 你需要 33% equity（Pot Bet 的標準要求）
- 你有 35% equity（9 outs Flush Drive）
- 35% > 33% → 邊緣合算（選 B 也正確）

加上隱含賠率（深疊 300bb）：
- 如果你命中 Nut Flush（Turn），你可能從對手贏取大量額外籌碼
- 估算：如果命中後你 Pot Bet（40bb）→ 對手可能 Call（他有 Set，不易棄牌）
         再 Pot Bet River（120bb）→ 再次可能 Call
- 隱含贏得：可能額外 160bb（2 輪下注）

隱含賠率計算：
- 你投入：20bb（Call）
- 底池賠率贏得：60bb - 20bb = 40bb（如果不考慮後續下注）
- 隱含贏得：+160bb（命中後的額外下注）
- 總預期贏得（如果命中）= 40 + 160 = 200bb
- 總賠率 = 20 : 200 = 1:10（需要只要 9% equity 就合算！）

**結論：C** — 深疊的隱含賠率讓 Nut Flush Drive 的實際 EV 遠高於表面的 35%。

**關鍵學習點**：深疊（Deep Stack）讓 Nut Drive 的隱含賠率大幅增加。即使底池賠率勉強合算，深疊的隱含賠率讓追 Nut Drive 成為明智選擇。

</details>

### Q34｜Commit 的判斷

翻牌前，你有 100bb 籌碼，你 3-bet 到 35bb（用了 35% 籌碼）。
對手 Call，你進入翻牌（底池 ≈ 72bb）。
翻牌：J♠T♠9♦（高位連牌 + 兩張黑桃），底池 72bb。

你現在剩 65bb，SPR ≈ 0.9。

對手 Pot Bet 65bb（All-in，剛好你的剩餘籌碼）。

你應該：

**A.** 棄牌（保住剩餘 65bb）
**B.** 跟注（只要有 40%+ equity 就 Call）
**C.** 跟注（只要有任何 equity 就 Call，因為你已 Commit）
**D.** 取決於你的具體手牌

<details>
<summary>答案與解析</summary>

**正確答案：D（最佳），B（實用答案）**

解析：

SPR ≈ 0.9 = 極低 SPR。但這不意味著你「自動 Commit」。

理論上（D）：取決於具體手牌
- 如果你的手牌完全沒有 equity（純空氣）→ 棄牌（A）
- 如果你有任何 Drive（Nut Drive）→ 跟注（B 或 C）

Commit 的計算：
- 你已投入 35bb，面對再投入 65bb 的決定
- 底池 after call = 72 + 65 + 65 = 202bb
- 你需要的 equity = 65 / 202 = 32%

任何 Nut Drive 或 Made Hand 通常 > 32% equity → Call 是正確的

例外：
- 你有完全無 equity 的手牌（如 AA 在 J-T-9 上，且無同花 Drive，equity 可能 < 30%）→ Fold 是合理的

實用答案（B）：在大多數有任何 equity 的情況下，SPR 這麼低時 Call 是正確的（32% 門檻很低）。

**關鍵學習點**：低 SPR 降低了 Call 的門檻（你只需要 32% equity），但不是「自動 Call」。完全無 equity 的手牌應棄牌。

</details>

### Q35｜MTT ICM 與 PLO 策略

Final Table（最終桌），剩餘 3 名玩家。
你有 60bb，對手 A 有 100bb，對手 B 有 40bb。
Payouts：1st = 50%, 2nd = 30%, 3rd = 20%。

你有 AA double-suited，UTG 開牌到 3bb，你在 BTN 可以 3-bet。你的最佳行動是什麼？

**A.** 直接 All-in（Shove，Pot × Pot 讓 AA 快速入場）
**B.** 3-bet（標準 Pot 3-bet = 10.5bb），計劃翻後進一步下注
**C.** 跟注（Call），看翻牌再決定
**D.** 棄牌（保守，Final Table 要謹慎）

<details>
<summary>答案與解析</summary>

**正確答案：B（或 A，視具體情況）**

解析：

AA double-suited 在 Final Table 的決策：

選 D（棄牌）：完全錯誤，AA ds 是最強的起始牌
選 A（All-in）：在 PLO 中，翻前直接 All-in 不符合 PLO 格式（除非短疊），而且 60bb 的 Pot Limit 通常需要多輪加注才能 All-in
選 C（跟注）：放棄了 3-bet 的主動性和建底池機會
選 B（3-bet）：**最佳！**
  - 建立更大底池（你有最強的手牌）
  - 讓對手以不利的賠率繼續（如果他們跟注 3-bet）
  - 如果對手棄牌，直接贏取底池

ICM 考量：
- 你有 60bb，對手 B 是短疊（40bb）
- 在 3 名玩家的 Final Table，ICM 壓力最重要的是「不要先出局」
- AA ds 是值得積極對抗任何對手的手牌
- 即使在 ICM 考量下，AA ds 的 Stack off 通常是正確的

**關鍵學習點**：Final Table 的 ICM 考量使你稍微保守，但 AA ds 幾乎永遠值得積極下注（3-bet）。ICM 讓你避免用邊緣手牌冒險，但不影響你用 AA ds 積極進攻。

</details>

### Q36｜PLO Bluff 的評估

你在 BTN，單挑對手（SB），底池 40bb，公牌：K♠ Q♥ J♦ T♣（Turn 牌面）。

你的手牌：A♠9♦8♣7♥（完全無 made hand，但有 Nut Flush Drive 可能？）

分析你是否應該 Bluff：

**A.** 是，公牌面 K-Q-J-T，對手很難有強牌，Bluff 成功率高
**B.** 否，K-Q-J-T 是對 Connect Board，對手很可能有強牌
**C.** 是，你有 A♠（Backdoor Nut Flush）和 A 高牌，有足夠的 Nut Blocker
**D.** 否，你在單挑底池但無任何 equity，純 Bluff 風險太高

<details>
<summary>答案與解析</summary>

**正確答案：C（有一定道理），但整體答案 D 更保守正確**

解析：

公牌 K-Q-J-T（Turn）：
- 任何有 A 的人有 Broadway（A-K-Q-J-T = Nut Straight）
- 任何有 9 的人有 K-high straight（K-Q-J-T-9 = 2nd Nut）
- 公牌非常「強」，對手命中率高

你的手牌 A♠9♦8♣7♥：
- A♠：你有 A Blocker！有 A 的人能做 Broadway，你持有 A♠ 阻斷了部分 Broadway 可能
- 但：你的 9 讓對手的 K-high straight 可能性下降（你 Block 了 9）
- 實際上：A♠ 是 Nut Straight Blocker！你持有 A♠ 讓對手的 Broadway 範圍縮小

選 C（Nut Blocker）：有一定道理，A♠ 是 Nut Blocker
- 但：在奧馬哈，Blocker 的效力比 NLH 弱得多（因為每個人有 4 張手牌，即使你持有 A♠，對手仍可能有非黑桃 A + Broadway 等）

選 D（保守）：也有道理
- 你沒有任何 equity（無 made hand，無好的 drive）
- K-Q-J-T 公牌對多數對手的手牌有利
- 純 Bluff 無 drive 支撐，如果 Call 你輸

**實際最佳答案**：在有 A♠ Blocker 的情況下，可以考慮小 Bluff（C），但整體上奧馬哈的 Bluff 應有 Drive 支撐。如果你只有 A Blocker 而無 equity，Bluff 風險很高。

**關鍵學習點**：Nut Blocker（持有關鍵牌阻斷對手的 Nut）在奧馬哈的 Bluff 中有一定作用，但不如在 NLH 中那麼強力。奧馬哈中純 Bluff 仍然危險。

</details>

### Q37｜Equity Realization

以下哪種情況的 Equity Realization（Equity 實現率）最高？

**A.** OOP，手牌 AAKK ds，面對多人底池
**B.** IP（BTN），手牌 KQJT ds，面對 3 人底池
**C.** OOP（SB），手牌 AA72 rainbow，單挑 BTN
**D.** IP（BTN），手牌 AA ds connected，單挑 SB

<details>
<summary>答案與解析</summary>

**正確答案：D**

解析：

Equity Realization 受以下因素影響：
1. **位置**：IP > OOP（顯著影響）
2. **手牌多路線（Multi-way）**：多路線手牌 > 單路線
3. **底池人數**：多人底池降低 Realization（更多競爭）
4. **手牌質量**：能做出 Nut 的手牌 > 只能做出非 Nut 的手牌

分析各選項：
- A：AAKK ds OOP + 多人底池 = 低 Realization（OOP 劣勢 + 多人競爭）
- B：KQJT ds IP + 3 人底池 = 中高 Realization（IP 優勢，多路線手牌，但 3 人競爭）
- C：AA72 rainbow OOP + 單挑 = 中等（OOP 劣勢抵消了單挑優勢，且 rainbow + dangling cards）
- D：AA ds connected IP + 單挑 = **最高 Realization！**
  - IP（最佳位置）
  - AA ds connected = 高質量多路線手牌（Nut Flush 可能 + AA + 連牌 Wrap）
  - 單挑（只有 1 個對手，競爭最小）
  - 所有因素都有利

**關鍵學習點**：IP + 高質量手牌 + 單挑 = 最高的 Equity Realization。每一個有利因素都會提升你實際贏取的 equity 比例。

</details>

### Q38｜MTT 短疊 PLO

你在 MTT，籌碼 12bb，發出的手牌是：A♠K♠Q♥J♥（AKQJ ds）。

UTG+2 開牌到 3bb，你在 BTN，應該：

**A.** 棄牌（12bb 太短，不適合 PLO）
**B.** 跟注（Call 3bb）
**C.** 3-bet（加注到 10.5bb，接近全押）
**D.** 直接 All-in（Shove 12bb）

<details>
<summary>答案與解析</summary>

**正確答案：C 或 D**

解析：

AKQJ ds 是 A+ 級起始牌，在 12bb 短疊時：

選 B（跟注）：你投入 3bb，剩 9bb，SPR ≈ 1（底池 6.5bb，剩餘 9bb），翻後幾乎直接 All-in
選 C（3-bet to 10.5bb）：你投入 10.5bb，幾乎是全押（剩 1.5bb），但不完全全押；翻後 SPR < 0.5，強制性接近 All-in。**有道理！**
選 D（All-in 12bb）：直接 Shove，在 PLO 短疊場景也是合理的

分析：
- 12bb 短疊 PLO，3-bet 或 All-in 都合理
- AKQJ ds 面對 UTG 的開牌，你的 equity 很強（> 50%）
- 3-bet（C）讓你建大底池，如果對手 Call，翻後你已接近全押
- Shove（D）更直接，省去翻牌後的複雜計算

在 MTT 12bb 短疊，面對 UTG 的開牌，A♠K♠Q♥J♥ 使用 **D（直接 All-in）** 是最乾淨的選擇。

**關鍵學習點**：MTT 短疊 PLO（< 15bb），面對強牌時直接 All-in（Push or Fold）是簡化且有效的策略，避免翻後複雜的 SPR < 1 決策。

</details>

### Q39｜綜合策略應用

你的手牌：Q♠J♥T♠9♥（QJTS double-suited）
翻牌：K♠8♠2♦（兩張黑桃，K 在翻牌）

你在 IP（BTN），對手（CO，OOP）Pot Bet 50bb（底池 50bb）。

你應該：

**A.** 棄牌（你的 flush 是 Non-Nut，straight draw 效果不佳）
**B.** 跟注（Call 50bb，追 draw）
**C.** Pot Raise（加注到 200bb）
**D.** 先評估，視情況跟注或加注

<details>
<summary>答案與解析</summary>

**正確答案：D（B 也可行）**

解析：

分析你的手牌 QJTS ds 在 K♠8♠2♦ 翻牌：

Flush Draw：
- Q♠T♠（手牌）+ K♠8♠（公牌黑桃）= 4 張黑桃 = Flush Drive
- Q-high 黑桃 Flush Drive = **Non-Nut！**（A♠,K♠ 的人打敗你）
- K♠ 在公牌，A♠ 的人有 Nut Flush Drive

Wait: Q♠T♠ 是你的黑桃手牌組合，加上公牌 K♠8♠ = 已有 4 張黑桃！
你的 Flush Drive = Q-high flush（如果命中，Q♠T♠K♠8♠ + 一張黑桃 = Q-high flush）
但公牌中 K♠ 是最高的黑桃，A♠ 如果命中 = A-high flush > 你的 Q-high

**Non-Nut Flush Drive（Q-high）= 危險**

Wrap/Straight Drive：
- 公牌 K-8-2（K 和 8 差距大），你的手牌 Q-J-T-9
- 用 QJ + K82：Q-J + K + 8 = K-Q-J-8（不連）
- 用 JT + K82：J-T + K + 8 = K-J-T-8（缺 Q）
- 用 T9 + K82：T-9 + K + 8 = K-T-9-8（缺 J）
- → 在 K-8-2 翻牌，你的 QJTS 幾乎無有效 straight drive（K 和 8 中間差 Q-J-T-9-7-6-5-4-3！）

你有：
- Non-Nut Flush Drive（危險）
- 幾乎無 Straight Drive

**整體評估**：
- 你的手牌在這個翻牌相對弱
- Non-Nut Flush Drive + 無 Straight Drive = 中等偏弱
- 對手 OOP Pot Bet 代表強牌（可能有 Set of K, Nut Flush, 或 Straight）

**建議行動**：
- 跟注（B）是可以的，你有 Flush Drive 的 equity（即使不是 Nut）
- 但要有棄牌的心理準備（如果 Turn 來不利的牌）
- 不應該 Pot Raise（C），你的 Non-Nut Drive 不適合 Raise

**最佳答案：D（評估後跟注，B）**

**關鍵學習點**：即使有 Flush Drive，如果是 Non-Nut 且翻牌不支持 Straight Drive，手牌的實際強度有限。謹慎跟注而非激進加注。

</details>

### Q40｜最終綜合題

以下哪個描述最準確地總結了 **PLO vs NLH** 的策略核心差異？

**A.** PLO 中 Bluff 更重要，因為底池限制讓對手不容易判斷你的牌力
**B.** PLO 中 Nut draw 和保護強牌更重要，Made Hand 的安全性更低，慢打風險更高
**C.** PLO 中位置的影響可以被忽視，因為 Draw 可以補償位置劣勢
**D.** PLO 中 AA 翻前幾乎必全押，因為 AA 在 PLO 中是絕對主導的牌

<details>
<summary>答案與解析</summary>

**正確答案：B**

解析：

選項 A（Bluff 更重要）：**錯誤！** PLO 中 Bluff 比 NLH 更難成功，因為每個人都有更多 Draw 和命中翻牌的機會。

選項 B（Nut Drive + 保護更重要）：**正確！**
- Nut Drive 重要：奧馬哈中非 Nut 的 Draw 在多人底池命中後可能仍然輸
- 保護強牌重要：對手的 Drive equity 比 NLH 更高（20 outs vs 8 outs），給免費牌代價更高
- Made Hand 安全性更低：Set 在 NLH 中幾乎安全，但在 PLO 中 Set 面對強 Wrap drive 只有 60% equity
- 慢打風險更高：免費牌在 PLO 中更危險（對手有更高的命中概率）

選項 C（位置可以忽視）：**錯誤！** PLO 中位置比 NLH 更重要（不是可以忽視），因為每輪決策的複雜性更高，後位玩家的資訊優勢被放大。

選項 D（AA 幾乎必全押）：**錯誤！** AA 在 PLO 翻前全押不常見（因為 PLO 格式），翻前 AA 的價值比 NLH 小（因為翻後對手的 Drive 可能讓 AA 的優勢消失）。AA ds connected 是強牌，但不是「翻前必全押」。

**關鍵學習點**：PLO 策略核心 = Nut 思維（追 Nut Drive，保護強牌）+ 積極保護（Pot Bet，不慢打）。這是與 NLH 最本質的差異。

</details>
