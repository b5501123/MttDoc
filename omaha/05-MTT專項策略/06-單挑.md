# PLO MTT 單挑（Heads-Up）完整策略指南

> 本章專門針對 9-max 線上 PLO MTT 的單挑（Heads-Up，HU）階段設計。
> 覆蓋從 preflop range 建立到多條街打法，以及 PLO HU 特有的心理戰術。

---

## 概覽：PLO HU 的根本邏輯

進入單挑是 MTT 的終極對決。PLO HU 與 NLH HU 有根本性的差異。

### ICM 的消失

```
PLO MTT HU 最重要的認知轉變：

MTT 前期 / FT 中期：
  每個決策都受 ICM 約束
  「生存」和「獎金跳升」影響每個 raise/fold 決定
  需要同時考慮 Chip EV + ICM 壓力

一旦進入 HU（2 人剩餘）：
  ICM 完全消失
  只剩兩個獎金名次（1st 和 2nd）
  你的 ICM EV 只取決於你贏得 HU 的機率

數學：
  HU ICM EV = P(你贏) × 1st 獎金 + P(你輸) × 2nd 獎金

  如果 1st = $10,000，2nd = $6,000，差額 = $4,000
  你每增加 1% 的勝率 = +$40 的 EV
  → 純 Chip EV 最大化 = ICM EV 最大化（兩者方向一致）

結論：HU 就是純 EV 最大化，可以打得更激進
```

### PLO HU vs NLH HU 的差異

```
PLO HU 比 NLH HU 更刺激的原因：

1. 更多 Draw 組合
   PLO 每人有 4 張牌，HU 環境下翻牌後幾乎每個人都有 draw
   → 底池更快速增長
   → 更多 semi-bluff 機會
   → 更多「我有 draw，我 bet」的合理動作

2. Equity 更平均
   NLH HU：strong made hand 可以 barrel 壓垮對手
   PLO HU：對手幾乎總有一定 equity（flush draw, straight draw）
   → 純粹依賴 made hand 的策略在 PLO 不夠有效

3. Range 更寬
   PLO HU 兩人各有 4 張牌，range 的計算複雜得多
   → 更難「range cap」對手
   → 更難讀牌（因為對手可能有很多組合）

4. Pot Limit 創造獨特的施壓節奏
   PLO 的 pot raise 讓每條街的籌碼投入更有結構
   → 不能隨意 jam，必須通過多條街建立底池
   → 創造有趣的「逐步施壓」戰術
```

## 第一節：PLO HU 翻牌前策略

### 1.1 HU 起始牌的大幅放寬

```
為什麼 PLO HU 的翻牌前 range 要大幅放寬？

數學理由：
  HU = 只有 1 個對手
  對手的 range = 幾乎所有 4 張牌組合
  你的「相對 equity」在 HU 天然更高（比 9-max 中）

  例子：
  9-max 中，A♠5♣4♦3♥（弱 A high rundown）進入翻牌
  可能面對 3-5 個對手，你可能只有 20-30% equity

  HU 中，同樣的手牌對 1 個對手
  你的 equity ≈ 45-50%（接近翻轉）

結論：
  任何有合理 combinatorial 潛力的手牌都可以 HU 打
  只有最爛的無結構手牌才考慮 fold
```

### 1.2 BTN（=Dealer/SB）的 Open Range

```
PLO HU：BTN = Dealer = SB（在 HU 中 BTN 先動，翻牌後後動）

HU 的位置規則：
  翻牌前：BTN/SB 先行動
  翻牌後：BTN/SB 後行動（IP，有位置優勢）
  → BTN 在 PLO HU 是有利位置（翻牌後 IP）

BTN 建議 Open Range：90%+ 所有手牌

可以 FOLD 的手牌（約 10%）：
  完全 rainbow 且無任何連接性的手牌：
    K♠8♦4♣2♥（rainbow, 無 broadway, 無連牌, 無 A）
    Q♠7♦3♣2♥（類似結構）
    J♠8♦4♣2♥（類似結構）

  原則：如果你的 4 張牌有任何以下特徵之一，可以 open：
    ✓ 含 A（任何 A）
    ✓ 兩張 connected（差 1-2 張）
    ✓ 一對（任何對子）
    ✓ 有 suited（兩張同花色）

  實際上，在標準的 PLO HU 中，幾乎所有手牌都 open
```

#### BTN Pot Raise Sizing

```
PLO HU BTN Pot Raise 計算：

HU Pot Raise 計算（大盲 = 10,000 為例）：
  底池 = SB（你）1 個大盲（5,000）+ BB 1 個大盲（10,000）= 15,000
  你在 SB = BTN，call 需要再 5,000 → 底池 = 20,000
  最大 raise = 20,000 + 5,000 = 25,000

  因此 PLO HU 的標準 preflop raise = 到 3x-3.5x 大盲
  具體：如果大盲 10,000，BTN pot raise = 35,000（3.5x）

非 pot raise（small raise）也是選項：
  BTN raise to 2.5x（較小的 raise）：
    + 建立更小的底池（有利於 IP 多條街打法）
    + 保留更多籌碼在翻牌後使用
    - 對手的 call 更容易（odds 更好）

  BTN raise to 4x（大 raise）：
    + 建立更大的底池（IP 翻牌後施壓更有效）
    + 逼對手 call 更多（fold equity 稍增）
    - 自己也 commit 更多（若翻牌後 miss）

PLO HU 常用 sizing：
  短疊（< 30bb）：傾向 pot raise（30-35%）
  中疊（30-70bb）：2.5x 到 3x（靈活）
  深疊（70bb+）：2.5x（保留翻牌後靈活性）
```

### 1.3 BB 的 Defend Range 和 3-bet 頻率

```
PLO HU BB 的選擇：call, 3-bet, 或 fold

BB Defend 原則：
  PLO HU 的 BB pot odds（面對 3x raise）：
    底池 = 3x + SB 的 0.5x = 3.5x
    你要 call 2x 大盲
    Pot odds = 2 / (3.5 + 2) = 2 / 5.5 ≈ 36%
    你需要至少 36% equity 才值得 call

  PLO HU 中，BB 面對 BTN 的 open，幾乎任何合理手牌都有 36%+ equity
  → BB 的 defend range 也極寬（80-90%）

BB 應該 3-bet 的手牌（~20-30% 時間）：

Value 3-bet（強牌）：
  AA（任何），AAKK，AAQQ ds，AA ds
  AKQJ ds，KQJT ds

Bluff 3-bet（製造壓力）：
  中等 rundown + suited：QJT9, JT98, T987（ds 或 2 suits）
  A-high suited hand（A 加上 3 張有結構的牌）

不建議 3-bet 的手牌（call 或 fold）：
  弱高牌雜牌：Q842, J953（無 suit 無連牌）
  這些牌 call 尚可，3-bet 後面對 4-bet 或大底池 SPR 低

BTN 面對 3-bet 的回應：
  Premium（AA, AAKK, AKQJ ds）：4-bet
  中等強度（KK ds, QQ ds, 連牌 ds）：call
  弱牌（C 級）：fold
```

## 第二節：PLO HU 翻牌後策略

### 2.1 C-bet 策略（HU 的 C-bet 頻率調整）

```
NLH HU vs PLO HU 的 C-bet 差異：

NLH HU：
  Raiser 的 C-bet 頻率：75-85%
  因為對手 miss flop 的機率高（2 張手牌 vs 3 張翻牌）

PLO HU：
  Raiser 的 C-bet 頻率：60-70%
  原因：
    1. 對手有 4 張牌，PLO HU 翻牌後 miss 的機率更低
    2. 對手幾乎永遠有一些 equity（pair, draw, 或兩者都有）
    3. 純粹 air 的 C-bet 在 PLO 更容易被 call

C-bet 建議（PLO HU）：

應該 C-bet 的情況：
  你有 top pair + draw（任何 draw）
  你有 made hand（set, two pair）
  你有 nut draw（nut flush draw, wrap）
  翻牌非常乾燥（dry board：如 K♠7♦2♣）

可以 check 的情況：
  你 completely miss flop（無任何 pair 或 draw）
  Wet board 且對手可能有更好的 draw（你的 C-bet 可能 check-raise）
  你有 strong made hand → 考慮 slow play（讓對手 bluff）

PLO HU C-bet Sizing：
  常見選擇：50-75% pot
    → 75%：在 wet board 上表示強度
    → 50%：在 dry board 上偷底池，同時節省籌碼
  Pot-size C-bet（100%）：
    → 用於 top set 或 nut draw combo（建立大底池）
```

### 2.2 IP（有位置）在 PLO HU 的重要性

```
為什麼 IP 在 PLO HU 比 NLH HU 更重要？

NLH HU IP 優勢：
  翻牌後可以 check back（控制底池大小）
  對手 check → 你可以 bet or check（靈活）
  可以 see 免費的轉牌（保護弱手）

PLO HU IP 優勢（更大）：
  PLO 翻牌後的決策更複雜
  IP 玩家可以觀察對手行動後再決定
    → 對手 bet：你有更多信息（他的 range 縮小）
    → 對手 check：可能是 trap 或 miss，你決定 bet size
  隱含賠率：IP 在有 draw 時可以更精準估算追牌代價
  多條街計劃：IP 可以更好地規劃 3 條街的行動

PLO HU 無位置（OOP）的困境：
  PLO 無位置時，每個動作都讓對手得到信息
  Check-fold 的頻率必須謹慎控制（不能太多）
  Check-raise 是 OOP 的主要工具（但需要強牌或 combo draw 支撐）

OOP 的 check-raise 策略：
  適合 check-raise 的情況：
    你有 nut draw（nut flush 或 最大 wrap）
    你有 set + 翻牌後 draw
    你有 two pair + nut draw（super combo）
  不適合 check-raise：
    你只有弱 made hand（例如：僅 top pair 無 kicker）
    你的 draw 不是 nut level（中等 draw 被 check-raise 後可能被 re-raise）
```

### 2.3 Draw 打法（HU 的 Semi-bluff 更積極）

```
PLO HU Draw 策略：比 9-max 更積極

理由：
  HU 的底池 odds 更好（只有 1 個對手追）
  對手無法確認你是 bluff 還是 value（手牌信息少）
  Semi-bluff 在 HU 有雙重獲利：
    a. 對手 fold → 你贏得底池
    b. 對手 call → 你有機會打中 draw

PLO HU 的 Draw 下注策略：

Nut Draw（最大 wrap + nut flush）：
  積極 pot-size bet 或 check-raise
  目標：建立大底池，最大化贏錢幅度
  即使對手 call，你有強力 draw 支撐

中等 Draw（flush draw 或 open-ended straight draw）：
  50-75% pot bet（保留 fold equity 同時不過度 commit）
  如果遇到 raise：評估 draw 的 outs 和 pot odds

弱 Draw（gut-shot 或 backdoor draw）：
  小 bet（30-40% pot）或直接 check
  PLO HU 中，弱 draw 的 semi-bluff 風險較高
  保留後街的選擇權

Draw vs Made Hand 的對抗原則：
  如果你是 draw，對方是 made hand → 積極 bet（fold equity + draw equity）
  如果你是 made hand，對方可能是 draw → 積極 bet（不讓他免費追牌）
```

### 2.4 Nut Hand 的慢打 vs 快打

```
PLO HU 的 Nut Hand 策略選擇：

快打（Bet/Raise）適合的情況：
  Wet board（多個 draw 可能）：
    你有 nut hand（top set）on A♥K♦Q♠ 型 board
    → 對手可能有 wrap, flush draw，必須快打
    → 目的：讓 draw 付出昂貴的代價追牌

  對手是積極型（bluff 頻繁）：
    如果對手傾向多 bet/bluff，你的 nut hand 可以 raise value
    → 讓他 bluff 多投入，然後 raise

  SPR 低（< 2）：
    無論如何快打，讓底池 commit

慢打（Check/Call）適合的情況：
  Dry board（不容易有 draw）：
    你有 set on 2♠7♦J♣（彩虹乾燥板面）
    → 對手可能 miss，check 讓他 bluff
    → 等他 bet 再 raise，或等轉牌繼續

  對手是被動型（傾向 check-fold）：
    如果你立刻 bet，對手可能 fold
    → 慢打讓他形成「我有機會」的幻覺

  你有 top set + 最強 draw（super combo）：
    你的 equity 已超過 90% → 不怕任何動作
    可以慢打建立更大底池（對手更容易 commit）

PLO HU 慢打的風險：
  PLO 的 board texture 變化很快
  轉牌可能帶來對手的 draw
  如果你慢打 + 對手免費追中 → 你損失隱含賠率
  原則：wet board 不慢打，dry board 才考慮慢打
```

## 第三節：PLO HU 的 Bluff 策略

### 3.1 PLO HU 的 Bluff 成功率分析

```
PLO HU Bluff 的基本環境：

NLH HU bluff 成功率：
  對手 miss flop 機率較高（2 張手牌）
  Dry board 上 C-bet bluff 成功率 ≈ 55-65%

PLO HU bluff 成功率：
  對手 miss flop 機率較低（4 張手牌）
  同一個 Dry board 的 bluff 成功率 ≈ 40-55%

原因分析：
  PLO 翻牌後，對手幾乎都有一些 equity
  即使 miss top pair，也可能有 backdoor draw
  → 對手更難 fold（因為有後退選項）

結論：PLO HU 的純 bluff 成功率比 NLH HU 低
     Semi-bluff（有 draw 支撐的 bluff）更有效
```

### 3.2 Semi-bluff 的頻率和選擇

```
PLO HU Semi-bluff 策略：

Semi-bluff 的雙重價值：
  1. 立即獲利（對手 fold）
  2. 未來獲利（你打中 draw 後贏大底池）

最佳 Semi-bluff 情況（PLO HU）：

Tier 1 Semi-bluff（最高頻率下注）：
  Nut flush draw + any pair
  Wrap + flush draw（combo draw）
  Top pair + nut flush draw
  → 這些手牌有 12-18+ outs，即使被 call 勝率高

Tier 2 Semi-bluff（中等頻率）：
  Nut flush draw（無 pair）：約 9 outs
  Open-ended straight draw（8 outs）
  Wrap draw（9-13 outs）
  → 被 call 後有 38-55% 機率繼續有機會

Tier 3 Semi-bluff（低頻率，謹慎使用）：
  Medium flush draw（非 nut）：約 9 outs，但可能被更好的 flush 打敗
  Gut-shot straight draw（4 outs）：只在 pot odds 極好時才 bet
  Backdoor draw only：幾乎不 bet（太少 outs）
```

### 3.3 River Bluff 策略

```
PLO HU River Bluff 的難點：

在 NLH HU 中，river bluff 相對常見
  對手可能 miss 各種 draw → 容易 fold

PLO HU River Bluff 更困難：
  River 時，對手要麼中了，要麼有較強的 made hand
  PLO 的 draw-heavy 打法讓雙方都會追多條街
  → River bluff 面對的是「已經有 made hand」的對手

何時 PLO HU River Bluff 有效？

條件 1：你有 Blocker（阻擋牌）
  例：River 來了第 4 張 flush 牌
  如果你有 Axx（Ace of that suit）= nut flush blocker
  對手沒有 nut flush 的機率上升 → bluff 更有效

條件 2：你完整的 Semi-bluff Line
  三條街都有 semi-bluff（bet/bet/bet）
  River 未中 → 你仍然可以 bet（因為 line 一致）
  對手的 range 被 bet 壓縮（他可能也是半bluff on earlier streets）

條件 3：Board 對對手 range 威脅更大
  River 來了一張 connected 牌（可能完成順子）
  你的 range 能代表更多 made hand（你之前的 bet 說明你有 draw）
  而對手的 range 可能只有 medium made hand（不願對抗 strong draw line）

純 Bluff（無 blocker，無一致 line）：
  PLO HU 幾乎不做純 river bluff
  勝率太低（對手已到 river = 通常有東西）
  更好的選擇：check/fold 接受這個底池的虧損
```

## 第四節：PLO HU Stack Depth 策略

### 4.1 深疊 HU（100bb+）

```
PLO HU 深疊定義：各有 100bb 以上

深疊 PLO HU 的特色：
  多條街打法是核心（有足夠籌碼三條街都 bet/raise）
  隱含賠率最大（追 draw 有很高的回報）
  Pot control 策略更重要（不想意外 commit 弱手）

深疊 HU preflop：
  寬 range，小 raise size（2.5x）
  保留更多籌碼在翻牌後使用
  讓 SPR 保持在 15-20（翻牌後仍有很多操作空間）

深疊 HU 翻牌後：
  強調 3 條街打法規劃
  翻牌 C-bet → 轉牌 barrel → River bet/raise
  每條街的 size 要有計劃（讓 3 條街都有 bet 的餘地）

深疊 HU 追 Draw 策略：
  Draw + Pot Odds 計算更精確
  例：翻牌後有 12 outs 的 combo draw
    Call rate = 24/47 ≈ 51%（一條街到轉牌）
    深疊隱含賠率：如果你中了，可以贏得後續 2 條街的投入
    → 深疊時 call pot-size raise 也可能是 +EV

深疊 HU 的 Slowplay：
  Set on dry board（SPR = 15+）：可以 check-call 讓對手 bluff
  讓底池在轉牌和 river 自然增長
  避免立刻嚇走對手
```

### 4.2 中疊 HU（30-50bb）

```
PLO HU 中疊定義：各有 30-50bb

中疊 PLO HU 的特色：
  SPR 下降（翻牌後 SPR ≈ 5-8）
  Commit 門檻降低（更容易達到 all-in）
  3 條街打法仍可行，但每條街 size 更有限

中疊 HU preflop：
  Pot raise（3.5x）更合適（建立更快全押的底池）
  或者 call preflop + 翻牌後 pot-bet（達到翻牌後全押）

中疊 HU 翻牌後：
  翻牌 pot-bet → 對手 call → 轉牌 all-in（常見路徑）
  SPR ≈ 6 時：翻牌 pot-bet 後，轉牌 pot-bet = all-in（約 1.5x pot）
  需要有 combo draw 或 strong made hand 才能這樣打

中疊的 Commit 門檻：
  中疊 = 更低的 fold equity（對手知道你快 commit）
  意味著你的 range advantage 更重要
  需要更強的手牌才能 3-bet or raise（因為更容易 commit）

中疊的理想 range（翻牌 commit）：
  Nut flush draw + pair：可以 commit（15+ effective outs）
  Top set：可以 commit（80%+ equity vs draw）
  Wrap + flush draw：可以 commit（最大 draw combo）
  中等 pair + 中等 draw：評估具體情況
```

### 4.3 短疊 HU（< 20bb）

```
PLO HU 短疊定義：你或對手有 < 20bb

PLO HU 短疊 Push/Fold 邏輯：

為什麼 PLO 短疊比 NLH 短疊更緊？
  PLO 的 best hand 在 all-in 時的 equity 不夠高
  NLH：AA push = 85% 贏（幾乎鎖定）
  PLO：AA push = 60-65% 贏（有可能輸）

  如果你 AA（65% 優勢）在 PLO HU 短疊 push：
    期望收益計算（假設籌碼對等）：
    0.65 × (+pot) + 0.35 × (-pot) = +0.30 × pot（正 EV）
    但 variance 高（35% 的時間你輸）

  PLO HU 短疊 push 門檻比 NLH 高，因為：
    EV 優勢較小（即使 premium，優勢不大）
    每次 push 都有相當機率輸（因為 PLO 的 equity 更均衡）

PLO HU 建議 Push Range（< 15bb）：

強力推薦 push：
  AA（任何 suit）→ 永遠 push
  AAKK（2+ suits）→ 永遠 push
  AA ds（double-suited）→ 永遠 push
  AKQJ ds → 強力 push
  KK ds → push（但對手有 AA 時 35-40% 輸）

條件性 push（< 10bb 時可以 push）：
  KK（single suited）
  QQ ds + 連牌
  KQJT（ds 或 2 suits）

不建議 push（即使 < 15bb）：
  中等連牌 rainbow（如 9876 無 suit）
  弱高牌（如 KQ83 rainbow）
  只有一個 strong element（如 AA without suit or rundown 組合）

短疊 HU 的心態：
  20bb 以下，每一手都可能是最後一手
  等品質手牌，用 push 的 fold equity + equity 獲利
  不要因為「我快死了」就隨便 push garbage
```

## 第五節：PLO HU 讀牌

### 5.1 多張手牌環境下的 Range 分析

```
PLO HU 讀牌的根本挑戰：

NLH HU：
  對手有 2 張牌
  可能的組合：52 × 51 / 2 = 1,326 種
  已知翻牌後，對手的 range 縮小到 500-800 種

PLO HU：
  對手有 4 張牌
  可能的組合：52 × 51 × 50 × 49 / 24 ≈ 270,725 種
  即使縮減，對手仍然可能有很多組合
  → PLO 的 range analysis 更困難

PLO HU 的實用讀牌方法（非完整 combinatorial 分析）：

方法 1：Hand Category 分析
  對手的行動指向哪種「手牌類型」？
    Category A：Made hand（pair, two pair, set）
    Category B：Draw（flush draw, straight draw, wrap）
    Category C：Combo（Made hand + Draw）
    Category D：Bluff/Semi-bluff（weak hand or weak draw）

  通過對手的 bet size 和行動節奏判斷 category
    → 大 bet on wet board：通常是 category C 或強 draw
    → 小 bet on dry board：可能是 A（慢打）或 D（試探）
    → Check-raise：通常是 A, C, 或強 draw

方法 2：Board Texture + Action 交叉分析
  Wet board + 對手激進 bet：
    → 更可能是 category B 或 C（有 draw 支撐）
    → 純粹 made hand 在 wet board 更可能 pot-bet 保護
  Dry board + 對手激進 bet：
    → 更可能是 category A（strong made hand，慢打沒意義）
    → 或 category D（試探弱對手）

方法 3：Historical Pattern（對手歷史行為）
  記住對手的 bluff 頻率（特別在 HU 中）
  記住對手是否有過 check-raise bluff
  記住對手的 showdown 手牌（學習他的 range）
```

### 5.2 常見 PLO HU 讀牌情境

```
情境 A：對手翻牌 check，轉牌 bet

  可能的含義：
    1. 翻牌 check-call 的 draw，轉牌繼續追
    2. 翻牌慢打的 made hand，轉牌建立底池
    3. 翻牌 check 因為 miss，轉牌再試一次（bluff）

  你的行動：
    如果你有強手 → raise
    如果你有中等手 → call（看 river 再決定）
    如果你有弱手 → fold（不值得 call 兩條街）

情境 B：對手 preflop call，翻牌 pot-size raise 你的 C-bet

  可能的含義：
    1. Nut draw combo（最常見，PLO 玩家愛用 combo draw raise）
    2. Set（strong made hand，值得 raise for value）
    3. Semi-bluff（中等 draw，製造壓力）
    4. 純 bluff（少見但存在）

  你的行動：
    如果你有 top set 或 nut draw combo → 4-bet 或 call（依 SPR）
    如果你有 middle draw + pair → call 評估轉牌
    如果你有 top pair 無 draw → fold（面對 pot-size raise 通常 dominated）
    如果你有弱手 → fold

情境 C：三條街連續 bet（bet/bet/bet line）

  可能的含義：
    1. Strong made hand（set, full house 在 river）
    2. Nut draw → 打中 → value bet all streets
    3. Semi-bluff 三條街（但 miss river → river bluff）

  如果你有 medium made hand（two pair）：
    面對三條街連續 pot-size bet
    PLO 中，three-street barreling = 通常有強牌或 nut draw line
    大多數情況：fold（除非你的 read 是對手在 bluff）
```

## 第六節：PLO HU 常見錯誤

### 錯誤 1：HU 仍然使用 FT 的緊打策略

```
錯誤描述：
  進入 HU 後，玩家繼續使用 FT 的謹慎打法
  Fold 很多本該 call 或 raise 的手牌
  過度保守，讓對手免費取得盲注

為什麼這是錯誤的：
  HU = 沒有 ICM，純 EV 最大化
  保守打法在 HU = 讓對手持續偷盲 → 你的籌碼緩慢消失
  即使你等到「好牌」，盲注已經消耗大量籌碼

正確做法：
  一進入 HU，立刻切換到寬 range 打法
  BTN/SB 幾乎所有手牌都 open
  BB defend 80%+ 的手牌
```

### 錯誤 2：在 PLO HU 做太多 River Pure Bluff

```
錯誤描述：
  模仿 NLH HU 的積極 river bluff 策略
  在沒有 blocker 或一致 line 的情況下 river 大 bet bluff

為什麼這是錯誤的：
  PLO HU 的對手到 river 通常有東西
  純 bluff 被 call 的機率比 NLH 高（對手有 4 張牌，更難完全 miss）

正確做法：
  River bluff 需要：blocker + 一致的 semi-bluff line
  沒有 blocker 且之前沒有 draw line = 幾乎不 river bluff
  PLO HU 的 bluff 重心在翻牌和轉牌（semi-bluff 階段）
```

### 錯誤 3：深疊 HU 使用過大的 preflop raise size

```
錯誤描述：
  深疊 HU（100bb+）中 pot raise（3.5x）preflop
  結果翻牌後 SPR 太低（約 13-14）
  在某些情況下逼自己 too early commit

為什麼這是錯誤的：
  深疊 HU 的優勢在於多條街打法
  過大的 preflop raise 壓縮了翻牌後的打法空間

正確做法：
  深疊 HU 用 2.5x 開局（保留 SPR 在 18-20）
  讓翻牌後有更多籌碼可以逐步投入
  Exception：有極強手牌（AA ds）時可以大 raise，快速建立大底池
```

### 錯誤 4：忽略位置優勢（IP vs OOP 不調整打法）

```
錯誤描述：
  HU 中不管是 IP 還是 OOP，都用同樣的打法
  OOP 也做同樣頻率的 bet/raise（缺乏位置意識）

為什麼這是錯誤的：
  PLO HU 的位置優勢很大
  OOP 玩家如果激進 bet，IP 玩家可以輕鬆 raise + 逼你決定
  OOP 在 wet board 上 bet 出去，面對 raise 很難決策

正確做法：
  OOP（BB）：增加 check-call 和 check-raise 的比例
  OOP 的 bet 應該主要是：strong hand + strong draw（不要太寬）
  IP（BTN）：增加 C-bet 頻率，積極利用位置優勢追牌
```

### 錯誤 5：短疊 HU Push 過寬（NLH 思維）

```
錯誤描述：
  以為 PLO HU 短疊可以 push 任何「看起來像樣」的手牌
  例如 push 9876 rainbow（中等連牌但無 suit）

為什麼這是錯誤的：
  PLO 的 equity 差異小：9876 rainbow vs AA = 約 35-40%
  短疊 push = 在 35-40% 的 equity 上賭全部
  相比 NLH：同等地位的手牌 push 可能有 50-60%

正確做法：
  PLO HU 短疊 push 需要比 NLH 更強的手牌
  確保你有：兩個以上的 draw 路徑（suited + connected）
  或者：對子 + 連牌 + suit（如 AA ds 等）
  純連牌 rainbow 需要非常低的 bb（< 5bb）才考慮 push
```

### 錯誤 6：完全不做 HU Bluff（過度保守）

```
錯誤描述：
  認為 PLO HU 不能 bluff（因為對手 4 張牌，很少 miss）
  結果從不 bluff，打法完全可預測

為什麼這是錯誤的：
  PLO HU 中 bluff 仍然必要（semi-bluff 尤其）
  如果對手知道你只 bet strong hand，他可以輕鬆 fold → 你失去 EV

正確做法：
  PLO HU 的 bluff 策略 = 豐富的 semi-bluff（draw + bet）
  結合 blocker + 一致的打法 line
  適當頻率的 river bluff（但需要有理由）
  保持打法多樣性讓對手難以讀牌
```

## 第七節：PLO HU 的 Momentum 策略

### 7.1 搶節奏

```
PLO HU 的節奏控制：

什麼是節奏（Momentum）？
  HU 中，連續贏得幾個底池 → 籌碼優勢擴大 → 對手的壓力增加
  心理上：對手開始擔心、猶豫 → 決策品質下降
  籌碼上：大疊可以用更多 spot 施壓

搶節奏的方法：

方法 1：連續 C-bet 壓力
  連續 2-3 手 C-bet（不管 miss 或 hit）
  讓對手感覺「你每次都有牌」
  他開始 fold → 你贏得節奏優勢

方法 2：控制手牌選擇
  當你剛贏了一個大底池（節奏在你）
  → 接下來 2-3 手可以更積極偷盲（對手還在心理恢復）

方法 3：適當的 Show Down 管理
  有時候你可以 show down 強牌（給對手看）
  也可以 muck bluff（不讓對手知道你在 bluff）
  選擇性 show → 管理你的 image

節奏在對手時的應對：
  對手連贏 → 你要稍微收緊，等 premium
  不要「情緒化 tilt」試圖立刻追回來
  等對手的 aggression 稍微降溫，再重新施壓
```

### 7.2 製造壓力

```
PLO HU 製造壓力的工具：

工具 1：持續的 Pot Raise 開局
  每手都 pot raise（從 BTN）
  讓對手習慣性地防守 → 防守的心理負擔增加
  當對手開始 3-bet 防守 → 你開始有選擇性地 4-bet premium

工具 2：翻牌後的快速 bet
  翻牌後快速 bet（不需要太長時間思考）
  顯示你「早有計劃」→ 心理上的壓迫感
  讓對手不確定你是 value 還是 bluff

工具 3：河牌的心理戰術
  River 時，你的 bet size 傳遞信號
  偶爾在 river 用 overbet（超過底池）
  Overbet = 強烈信號（強牌或強力 bluff）
  讓對手 range 判斷困難

工具 4：有選擇性地 tanking（假裝思考）
  偶爾在顯而易見的決策上 tank
  讓對手不知道你在想什麼
  Note：不要過度使用，會讓對手注意到模式
```

### 7.3 心理戰術

```
PLO HU 的心理面向：

認識對手類型：
  Type A：緊打型（tight-passive）
    特徵：只在有強牌時積極，經常 check-call
    應對：增加 bluff 頻率，利用他的被動性
    警告：當他 raise，很可能有強牌 → 不要 commit 弱手

  Type B：廣泛型（loose-aggressive，LAG）
    特徵：經常 3-bet, check-raise，bet 很多
    應對：減少 bluff，增加 trap（用強手讓他投入）
    警告：他的 bluff 頻率高，可以 call 到 river 更多

  Type C：呼牌型（calling station）
    特徵：幾乎 call 所有 bet，很少 raise
    應對：增加 value bet size，幾乎不 bluff
    警告：他有強牌時可能 raise，這時你的 bet 都是 value loss

  Type D：魚（fish/recreational）
    特徵：不規律，做出明顯錯誤（overbet weak, flat premium）
    應對：等強牌 + value 最大化，少 bluff

情緒管理：
  PLO HU 的 variance 很高，可能連輸多個大底池
  關鍵：不要情緒化調整策略（tilt）
  如果你注意到自己開始情緒化 → 暫停，回到基本面
  平靜的決策 > 情緒化的「追回來」
```

## 第八節：PLO HU 具體手牌場景分析

### 場景 1：深疊 HU 的多條街 Draw 對決

```
情境設定：
  線上 PLO MTT，HU，各有 300,000 chips
  盲注：10,000/20,000，SPR ≈ 14（深疊）

你（BTN/SB）：A♠Q♠J♥T♦（AQJT，單花色黑桃）
對手（BB）：未知

行動：
  你 raise to 50,000（2.5x）
  對手 call

翻牌：K♠9♠2♥（底池 = 100,000）

翻牌分析：
  你的手牌：
    Nut flush draw（A♠Q♠ = 2 black spades on K♠9♠2♥）
    Broadway outs：Q♠ in hand + K on board + J,T in hand → gut-shot to broadway
    Wrap outs：QJT 連牌 + K,9 on board → 很多 straight outs

  你的實際 outs（近似）：
    Nut flush draw：7-9 outs（部分 flush outs 已用掉）
    Straight outs（QJT + K,9 board）：大約 6-8 outs
    總計：約 13-15 outs（強力 combo draw）

  最優先動作：C-bet pot（製造 fold equity + draw equity）

你 C-bet 75,000（75% pot）
對手 raise to 250,000（pot-size raise）

轉折點分析：
  對手 pot-size raise = 什麼意思？
    強力 option 1：他有 top set（KKxx），想保護 vs draw
    強力 option 2：他有 nut flush draw + pair（比你更強的 combo）
    強力 option 3：他有 wrap + pair（13+ outs combo draw）
    Bluff option：他在 semi-bluff（但 PLO 中 pot-size raise 通常有東西）

  你剩餘籌碼：300,000 - 50,000（preflop）- 75,000（flop bet）= 175,000
  對手的 raise = 250,000，你 call 需要 175,000（all-in）

  你的決定：All-in call（175,000 into 600,000 pot）

  Pot odds 計算：
    你需要 call 175,000 to win 600,000 + 175,000 = 775,000
    Call 勝率要求 = 175 / 775 = 22.6%

  你的 equity vs 對手的 range：
    vs top set（KKxx）：你的 13-15 outs = 30-35% 兩條街
    vs 他的 combo draw（稍強於你）：你約 40%
    加權平均：約 33-38%

  決定：Call（33% > 22.6% 所需，明顯 +EV）

結果（數學 EV）：
  Call 勝率 35%，EV = 0.35 × $775k - 0.65 × $175k
                    = $271,250 - $113,750 = +$157,500（正 EV call）

關鍵學習：
  深疊 HU 中，combo draw（13+ outs）可以 call pot-size raise
  即使你可能面對更強的 combo，pot odds 支持 call
  PLO HU 的 all-in 計算需要精確的 pot odds vs equity 比較
```

### 場景 2：中疊 HU 的 Bluff 決策

```
情境設定：
  HU，你（BTN）有 200,000，對手有 200,000
  盲注：10,000/20,000（各約 20bb）

你的手牌：J♠T♠9♥8♦（JJTO98 連牌，1 suit）

行動：
  你 pot raise to 70,000
  對手 call（底池 = 140,000，剩餘各 130,000）

翻牌：A♥K♦2♠（乾燥板面）

翻牌分析：
  你 completely miss（J,T,9,8 在 A,K,2 上沒有任何 pair 或 draw）
  只有遠遠的 backdoor straight 可能性（需要 QJ 或 QT）

  你的選擇：
    A) C-bet（bluff）
    B) Check

  分析：
    乾燥板面 AK2 → 通常利於翻牌前 raiser（你）
    你的 range 包含很多 AXxx 手牌（你是 BTN，open range 寬）
    對手的 range 也有 A，但你更可能有 A

    C-bet 50% pot（70,000）的 bluff：
      如果對手 fold → 你贏得 140,000 的底池
      如果對手 call → 你有 backdoor draw，但基本上需要放棄

  決定：C-bet 50% pot（70,000）bluff

對手 call → 底池 = 280,000，剩餘各 60,000

轉牌：Q♥

轉牌分析：
  Q 來了 → 你現在有 QJT9 = open-ended straight draw！
  Outs：K or 8（你需要 K 或 8 完成順子）
  你有大約 8 outs（K,K,K,8,8,8,8 = 7-8 outs）

  現在你從「純 bluff」變成了「semi-bluff」
  你有 60,000 剩餘，底池 = 280,000
  SPR ≈ 0.2（極低，幾乎必須全押）

  策略：All-in semi-bluff（60,000 into 280,000）
    Pot odds 要求：60 / (280 + 60) = 17.6%
    你的 outs（8）：8/46 ≈ 17.4%（兩條街等效更高）

  邊緣決策，但在 HU 中，semi-bluff 有額外 fold equity
  → 對手可能在 AK2Q board 上 fold middle pair 類手牌

決定：All-in 60,000

關鍵學習：
  Pure bluff（miss flop）→ 轉牌意外獲得 draw = 有機會繼續
  PLO HU 的半途 draw 轉換很常見（4 張手牌提供更多可能性）
  中疊 HU 一旦下注後，繼續施壓的 fold equity + draw equity 通常值得
```

### 場景 3：短疊 HU Push/Fold 決策

```
情境設定：
  HU，你有 80,000，對手有 920,000
  盲注：20,000/40,000（你只有 2bb！）

情況 A：你（BTN/SB）有 K♥K♦J♠T♥
  這是 B+ 級手牌（KK + 連牌，無雙花）
  建議：Pot raise all-in（80,000，2bb）
  理由：
    你是大劣勢短疊，任何 B+ 級手牌都要 push
    KK + JT = 有對子 + 有順子潛力
    等更好的牌不值得（盲注已經佔你 50% 籌碼）

情況 B：你有 9♠8♦7♣6♥（低連牌 rainbow）
  PLO HU 短疊評估：
    9876 rainbow vs 任何手牌 ≈ 45-50%
    但這只是 flip，而你在 2bb 短疊狀態
    建議：Push（但勉強）
    理由：2bb = 必須 push or fold，9876 約 50% equity，push 是正 EV

情況 C：你有 Q♥7♦4♣2♠（弱雜牌）
  PLO HU 短疊評估：
    Q742 rainbow vs 任何手牌 ≈ 35-40%
    這是低於 50% equity 的 push
    建議：Push（因為你已是 2bb 短疊，blind 壓力不允許等待）
    理由：即使 40% equity，push 仍然比 fold（保留 1 blind = 浪費）好

  注意：如果你還有 5bb+，Q742 rainbow = fold

核心學習：
  PLO HU 短疊的最後幾個 bb = 幾乎任何手牌都 push
  但在 10bb 以上：仍然需要 B 級以上手牌
  PLO HU 短疊策略 = 比 NLH 稍緊，但仍然要積極
```

## 第九節：PLO HU 策略總結

### 核心原則彙整

```
PLO HU 十大核心原則：

1. HU = 純 EV，沒有 ICM
   進入 HU 立刻切換打法，不再受 ICM 約束

2. Open Range 極寬（90%+ 從 BTN）
   只有最糟糕的無結構手牌才 fold

3. BB Defend 也要寬（80%+）
   PLO HU 的 BB pot odds 支持廣泛防守

4. IP 優勢比 NLH HU 更重要
   翻牌後有位置 = 更多打法選擇

5. Semi-bluff 是 bluff 的核心
   純 bluff 少用，帶 draw 的 bet 更有效

6. River pure bluff 需要 blocker + 一致 line
   沒有支撐的 river bluff 在 PLO 成功率太低

7. 深疊 HU 用小 raise（2.5x）保留 SPR
   讓多條街打法有足夠空間

8. 短疊 HU push range 比 NLH 更緊（但仍積極）
   PLO 的 equity 差距小，需要更高品質手牌

9. 搶節奏，製造連續壓力
   連贏幾個底池後對手心理防線降低

10. 讀對手類型並調整
    緊打型 → 多 bluff
    呼牌型 → 多 value，少 bluff
    激進型 → 多 trap，等強牌
```
