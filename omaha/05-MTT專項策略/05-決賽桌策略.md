# PLO MTT 決賽桌（Final Table）完整策略指南

> 本章專門針對 9-max 線上 PLO MTT 的決賽桌（Final Table，FT）設計。
> 涵蓋從 10 人進場到單挑的完整策略框架，強調 PLO 特有的 Pot Limit 限制與 ICM 複雜性。

---

## 概覽：為什麼 PLO 決賽桌特別困難

進入決賽桌是 PLO MTT 玩家的重大成就，但最艱難的挑戰才剛開始。
PLO FT 比 NLH FT 困難的核心原因：

```
PLO FT 四大特殊挑戰：

挑戰 1：All-in 方差更大
  NLH FT：AA vs KK preflop = 80% 優勢，幾乎鎖定贏
  PLO FT：AA ds vs KK ds preflop = 63-65% 優勢，可能輸
  PLO FT：翻牌後 set vs wrap = 45-55%，你可能是劣勢方

挑戰 2：Equity 差距更小
  NLH：頂對 vs 低對 = 70-80%（巨大差距）
  PLO：頂對 vs Wrap Draw = 48-52%（幾乎 flip）
  結論：PLO 的「premium hand」在 all-in 時沒有 NLH 那麼安全

挑戰 3：Pot Limit 限制
  PLO 無法像 NLH 一樣隨意 jam all-in
  每次 raise 必須遵守底池限注規則
  這使得「push or fold」決策更複雜，需要多條街計算

挑戰 4：ICM 和 PLO Equity 雙重計算
  每個 FT 決策 = ICM 壓力 + PLO equity 不確定性
  需要同時考慮：你的 PLO 手牌強度、對手 range、獎金結構
```

## 第一節：PLO FT 的特殊性分析

### 1.1 Pot Limit 在 FT 的實際影響

在 NLH MTT 決賽桌，玩家可以隨時推 all-in 製造壓力。
在 PLO FT，每次加注必須計算底池大小：

```
PLO Pot Raise 計算公式（FT 情境）：

底池 = 之前所有下注的總和
最大加注 = 目前底池大小 + 你的 call 金額 + 再加注金額

例子：
  盲注 2000/4000，底池 = 6000（僅盲注）
  UTG 想 pot raise：
    call 4000 → 底池變 10000 → 最大加注 = 10000 + 4000 = 14000
    實際：UTG raise to 14000

FT 短疊的 pot raise 問題：
  短疊 = 40000 chips（10 bb）
  POT SIZE = 6000
  即使 UTG pot raise，也只是 14000，對短疊來說不是 jam
  短疊還要再等翻牌後才能全押——這製造複雜的 SPR 計算
```

### 1.2 PLO FT 的 All-in 頻率

PLO FT 比 NLH FT 全押次數更多，因為：

```
PLO All-in 頻率高的原因：

1. 翻牌後建大底池速度快
   PLO 翻牌後經常有 wrap + flush draw
   玩家願意用 draw 承擔大底池風險
   → 底池快速擴大 → SPR 下降 → 自動全押

2. Semi-bluff 更合理
   PLO 中「我有 draw」幾乎永遠是正當的下注理由
   這使翻牌後更多 pot-size bet → 更快全押

3. 多人底池更容易失控
   10 人 FT，多人翻牌很常見
   多人底池 + PLO 的 draw 豐富 → 底池爆炸

結論：PLO FT 玩家必須習慣「比預期更早全押」的情況
```

### 1.3 PLO FT 的 Equity 現實

以下是 PLO FT 最常見的 all-in 情境及其 equity：

```
PLO FT 常見 All-in Equity 對比（近似值）：

翻牌前：
  AA ds vs KK ds       ≈ 64% vs 36%
  AA ds vs 隨機手牌    ≈ 60% vs 40%（比 NLH AA 的 85% 低得多！）
  AKQJ ds vs 隨機手牌  ≈ 56% vs 44%

翻牌後（常見情況）：
  Set（頂三條）vs Wrap（最大順子 draw）  ≈ 45% vs 55%
  兩對 vs Wrap + Flush Draw              ≈ 35% vs 65%（兩對是劣勢！）
  Nut Flush Draw vs 頂三條              ≈ 38% vs 62%
  Set vs Set（較低三條）                ≈ 82% vs 18%（少見但一面倒）

關鍵結論：
  NLH 的「我有 set，安全全押」在 PLO 不成立
  PLO 的 set 面對 combo draw 可能是劣勢方
  FT ICM 壓力下，這些「可能輸的全押」成本極高
```

## 第二節：10 人 FT 進場策略（各疊打法）

### 2.1 大疊策略（30%+ 籌碼）

大疊在 PLO FT 擁有最多工具，但必須謹慎使用：

```
PLO FT 大疊定義（10 人桌）：
  FT 總籌碼 = 例如 4,000,000
  你的籌碼 ≥ 1,200,000（佔 30%+）
  其他 9 人平均 = 311,111

大疊的工具：
  工具 1：盲注壓力
    → 可以 pot raise 偷盲，短疊必須謹慎防守
  工具 2：ICM 施壓
    → 對中疊施壓，中疊不敢冒險出局
  工具 3：多人底池控制
    → 可以廣泛進入 multiway pot（你有籌碼緩衝）

PLO FT 大疊注意事項（與 NLH 的差異）：
  NLH 大疊：可以對任何人隨意 jam，幾乎無風險
  PLO 大疊：all-in vs 其他大疊 = 高風險
    → 如果對手也有 1,000,000+，你打 all-in 就是在冒 25% 籌碼
    → 翻牌後對戰另一位大疊：PLO 的 flip 機率讓你可能失去大疊地位
```

#### 大疊的 偷盲策略

```
PLO FT 大疊偷盲建議（10 人）：

最佳位置偷盲：
  BTN、CO（位置最佳）：使用 pot raise
  HJ（中位）：選擇性 pot raise
  EP（早位）：謹慎，幾乎不偷盲

PLO 大疊偷盲的手牌要求（FT 10 人）：
  仍然需要有一定品質的手牌！原因：
    1. PLO 的 pot raise 很大，如果遇到 3-bet，你難以繼續
    2. 翻牌後即使 C-bet，對手有很多 draw 可以反打

建議 BTN/CO 偷盲最低要求（FT 10 人大疊）：
  A 級手牌：任何含 AA/KK 的四張 → 毫無疑問 raise
  B 級手牌：AKQJ, KQJT suited, 雙對子 J以上 → 可以 raise
  C 級手牌：隨機連牌（如 8765 ds）→ FT 早期謹慎，FT 中後期可以偷
```

### 2.2 中疊策略（10-20% 籌碼）

```
PLO FT 中疊定義：
  你的籌碼 = 400,000 - 800,000（佔 10-20%，約 20-50 bb）

中疊困境：
  太多籌碼 → 不能輕易全押（出局損失大）
  太少籌碼 → 缺乏施壓工具
  中疊是 PLO FT 最難操作的籌碼段

中疊核心原則：
  原則 1：避開大疊的 pot raise
    → 大疊 raise，你的中等手牌 fold
    → 只有 premium hand 才能對抗大疊

  原則 2：等待 premium hand 然後 commit
    → 中疊的 PLO premium = AA, KK, AA ds, AAKK
    → 拿到這些手牌 → 願意 pot raise → willing to go all-in

  原則 3：位置比手牌更重要
    → 中疊在位置上應該更積極（BTN/CO 的標準 open 更寬）
    → 無位置時（SB、UTG）嚴格緊打
```

#### 中疊的起始牌調整

```
PLO FT 中疊可 open 手牌（相對 cash game）：

應該 OPEN 的手牌：
  AA（任何組合）：永遠 open，準備 commit
  KK ds：open，對 3-bet 評估情況
  AAKK, AAQQ, AAJJ：open，有隱含強度
  AKQJ ds：open（但對 3-bet 謹慎）
  連牌 ds（KQJT, QJT9 double-suited）：位置好才 open

應該 FOLD 的手牌（FT 中疊）：
  任何無對子、無 suit、無連牌的手牌（如 K852 rainbow）
  低連牌（6543, 5432）：cash game 可以，FT 中疊不行
  弱高牌（KJ82 ds）：結構太差，即使有 flush draw 也不夠強
```

### 2.3 短疊策略（< 10% 籌碼）

```
PLO FT 短疊定義：
  你的籌碼 < 400,000（< 10%，約 < 20 bb）

PLO FT 短疊的核心現實：
  你無法 pot raise + C-bet = 有效施壓（籌碼太少）
  你的主要武器 = preflop all-in（利用殘存 fold equity）
  但 PLO 的短疊 push range 比 NLH 更緊！

為什麼 PLO 短疊需要更緊？
  原因 1：PLO 的 best hand vs best hand 沒有 NLH 那麼大的優勢
    → NLH：AA vs 隨機手牌 = 85%（幾乎鎖定）
    → PLO：AA ds vs 隨機手牌 = 60%（可能輸）
    → 所以你更需要確保 hand 的品質

  原因 2：PLO 的隱含賠率概念不同
    → NLH 短疊：有 draw = 還有機會追
    → PLO 短疊 all-in 後：翻牌後通常已經無籌碼可用

  原因 3：多人底池風險
    → 短疊 all-in 可能被多人 call
    → PLO 的多人底池讓你的 equity 被分散

PLO FT 短疊建議 Push Range（< 15 bb）：
  強力推薦 push：
    AA（任何）、AAKK、AA ds、KK ds
    AKQJ ds（best rundown ds）

  可以考慮 push（< 10 bb 時）：
    KK（無 suit）、AAQQ、AAJJ
    KQJT ds（強連牌 ds）

  不建議 push（即使 < 10 bb）：
    弱連牌（如 6543 無 suit）
    任何 rainbow 非 premium 手牌
```

## 第三節：人數縮減策略（10→6→4→3→2）

### 3.1 10→8 人（FT 初期）

```
PLO FT 10→8 人策略重點：

目標：生存，讓短疊先出局
主要策略調整：
  1. 減少與其他大疊的非必要對抗
  2. 對短疊增加壓力（ICM 壓力最有效）
  3. 觀察誰是 short stack，誰是 big stack

常見錯誤：FT 一開始就打太多手（cash game 習慣）
  → 等等等，先讓幾個短疊出局再擴展 range
```

### 3.2 8→6 人（FT 中前期）

```
PLO FT 8→6 人策略重點：

人數減少 → 盲注壓力增加 → 必須更積極
每過掉 1 人 → 平均每人多 12.5% 盲注壓力（相對籌碼）

調整方向：
  中疊開始擴展 open range（從 B 級手牌往下延伸）
  大疊增加 BTN 偷盲頻率
  短疊加速 push or fold 決策

PLO 6-max 與 9-max 的 range 差異：
  6 人時，類似 cash game 的 6-max 打法
  BTN open range 可以延伸至 60-70% 手牌
  但注意：FT ICM 仍然存在，不能完全當 cash game 打
```

### 3.3 6→4 人（關鍵桌泡泡期）

```
PLO FT 6→4 人策略重點（獎金跳躍最大）：

通常獎金結構：
  6th place：$X
  5th place：$1.5X（或更高）
  4th place：$2.5X（大跳升）
  3rd place：$4X

這個階段的 ICM 壓力達到最高峰！

特別注意：
  5th place 出局者通常會後悔沒再多撐一下（4th 的獎金更高）
  你要成為施壓者，而非被施壓者

具體行動：
  有籌碼優勢時：對疊量接近的對手施壓（他們的 ICM 成本最高）
  疊量接近時：避開不必要的 flip（ICM 代價太大）
  有短疊在場時：不要讓短疊「免費」看翻牌（pot raise 驅逐）
```

### 3.4 4→3 人（三人桌）

```
PLO FT 三人桌（3-Handed）策略：

三人桌與 10 人 FT 的根本差異：
  盲注比例急劇上升（每人每 3 手就要交一次大盲）
  範圍必須大幅擴展
  推/棄 決策更頻繁

三人 PLO 的 preflop 動作：
  BTN（=Dealer）：open 70%+ 手牌（幾乎任何有結構的牌）
  SB：3-bet 頻率增加，或 call + 翻牌後打法
  BB：defend 很寬（pot odds 不錯）

三人 PLO 翻牌後：
  C-bet 頻率增加（只有 2 個對手，更可能 miss flop）
  Pot control 策略（避免翻牌後在 3-way 建大底池）

特別注意：三人時的 ICM 不再那麼限制（獎金跳升在 3→2→1）
  但如果你是中間籌碼，仍然要避開與大疊的非必要全押
```

### 3.5 3→2 人（進單挑）

```
PLO FT 三人到單挑的過渡：

當還有 3 人時的關鍵決策：
  你是大疊：對中疊施壓，驅逐他，讓短疊自然出局
  你是中疊：等短疊出局，除非有超強手牌才 commit
  你是短疊：push or fold，不要慢慢等死

進入 HU 的心理準備：
  HU = ICM 消失，純 Chip EV 對決
  PLO HU 是完全不同的遊戲（見下一章）
  在三人還沒 HU 前，已要開始思考 HU 策略
```

## 第四節：PLO FT 的 Pot Limit 計算實務

### 4.1 為什麼 PLO 的 Pot Limit 在 FT 更複雜

```
NLH FT vs PLO FT 的施壓工具差異：

NLH FT：
  任何時候：jam all-in → 簡單直接
  短疊可以直接 all-in preflop
  大疊可以 over-jam 威脅任何人

PLO FT：
  Preflop：只能 pot raise（= 3.5x 大盲，從 UTG）
  翻牌後：只能 pot-size bet/raise
  要讓對手 all-in 需要多條街計算

PLO FT 的「逐步全押」路徑：
  例：你和對手各有 100,000 籌碼，盲注 4000/8000

  Preflop pot raise：你 raise 到 28,000（pot）
  對手 call → 底池 = 56,000
  翻牌後你 pot-bet = 56,000（你們各還有 ~72,000）
  對手 call → 底池 = 168,000
  轉牌你可以 pot-bet，但只剩 16,000（自動 all-in）
  → 三條街自然全押

FT 的計算能力要求：
  每次 pot raise 前要知道：
    1. 底池現在多大？
    2. 最大加注是多少？
    3. 加注後對手還剩多少？（計算 SPR）
    4. 是否需要兩條街 vs 一條街全押？
```

### 4.2 FT 常用的 Pot Raise Size 速算

```
PLO FT Pot Raise 速算表（大盲 = 10,000 為例）：

情況                    底池           最大加注
---------------------------------------------------
只有盲注（6 人桌）      15,000         35,000
EP limp + SB call      25,000         55,000
EP raise to 35k, 1 call 85,000        120,000
3-bet 場景             240,000        380,000+

記憶技巧：
  底池 + 2 倍 call = 約等於 pot raise 後底池大小
  翻牌後 pot-size bet = 底池 × 1 = 翻倍底池
```

## 第五節：3 人剩餘 ICM 計算例子（PLO 具體情境）

### 5.1 三人 ICM 基礎框架

```
情境設定：
  PLO MTT，3 人剩餘
  獎金結構：
    1st：$5,000
    2nd：$3,000
    3rd：$2,000（已獲獎）

  籌碼分布：
    玩家 A（你）：600,000（60%）
    玩家 B（大盲）：250,000（25%）
    玩家 C（小盲）：150,000（15%）
  總籌碼 = 1,000,000

計算各自的 ICM EV（簡化 Malmuth-Harville 方法）：

玩家 A 的 ICM EV：
  A 拿 1st 的機率 ≈ 60%（比例）
  A 拿 2nd 的機率 ≈（在 B 或 C 拿 1st 的情況下...）

  簡化計算：
  P(A 1st) = 0.60
  P(A 2nd | B 1st) = 0.25 / 0.40 = 0.625 × (1-0.60) = 0.25
  P(A 2nd | C 1st) = 0.60 / 0.85 × 0.15 ≈ 0.106

  ICM EV(A) ≈ 0.60 × $5000 + 0.35 × $3000 + 0.05 × $2000
             ≈ $3000 + $1050 + $100 = $4,150

玩家 B：
  ICM EV(B) ≈ 0.25 × $5000 + 0.40 × $3000 + 0.35 × $2000
             ≈ $1250 + $1200 + $700 = $3,150

玩家 C：
  ICM EV(C) ≈ 0.15 × $5000 + 0.25 × $3000 + 0.60 × $2000
             ≈ $750 + $750 + $1200 = $2,700
```

### 5.2 PLO 3 人 All-in 情境分析

```
情境：你（A）在 BTN，手牌 A♠A♥K♦Q♣（AAKQ 單花色）

玩家 B（BB）pot raise，玩家 C fold
B 有 250,000，你有 600,000，底池 = ~60,000

問題：你要 call 還是 fold？

PLO Equity 分析：
  A 的 AAKQ（無雙花）vs B 的未知 range
  假設 B 的 range = AA ds, KK ds, QQ ds, AKQJ ds, rundown ds
  你的 equity ≈ 52-55%（因為無雙花，equity 稍低）

ICM 分析：
  如果 call all-in：
    贏（55%）：A 有 850,000（85%籌碼），B 出局
    A 的 ICM：≈ $4,800+（接近獨佔籌碼）

    輸（45%）：A 有 350,000（35%），B 有 500,000（50%），C 有 150,000（15%）
    A 的 ICM：≈ $3,500（降低）

  期望 ICM：
    Call EV = 0.55 × $4,800 + 0.45 × $3,500 = $2,640 + $1,575 = $4,215
    vs 目前 ICM EV = $4,150

  Call 的 ICM 邊際收益 = $4,215 - $4,150 = +$65

結論：
  ICM 上略正 EV，但非常小
  如果 B 有 AA ds（你的 equity 只剩 40%），call 是負 EV
  建議：謹慎 call，如果你判斷 B 有 AA ds → fold
  如果你判斷 B 有 rundown（你有 AA 優勢）→ call
```

## 第六節：FT Bubble（Money Bubble 前最後一人）

### 6.1 PLO FT Bubble 的特殊性

```
FT Bubble 定義（不同於 MTT Money Bubble）：
  通常指「最後一個未付獎金名次」或「獎金大跳升前的關卡」

例子：
  10 人付獎，FT 有 10 人進場（全員付獎）
  但通常有「獎金跳升 bubble」：
    如 FT 底部 3 人的獎金差距較小
    第 4 名 vs 第 3 名 → 大跳升（這才是 FT 內的關鍵 bubble）

PLO FT Bubble 的翻身機率：
  NLH FT Bubble：短疊翻身難（大疊優勢明顯）
  PLO FT Bubble：短疊翻身機率更高！

  原因：PLO 的 equity 差距小
    短疊 push：即使遇到 AA，也有 35-40% 機率贏
    NLH 短疊 push：遇到 AA 只有 15-30%（取決於手牌）

建議策略：
  PLO FT Bubble 的短疊 → 不要太早放棄
  保持 push range 品質，選對手牌
  PLO 的翻身機率讓堅持到底更有價值
```

### 6.2 大疊在 FT Bubble 的行為

```
大疊面對 FT Bubble 的選擇：

積極施壓（推薦）：
  對中疊連續 raise → 製造壓力（中疊 ICM 成本高）
  對短疊 raise → 逼短疊做決定
  BUT：PLO 中，大疊不應輕易 call 短疊的 all-in
    因為 PLO 的 equity 差不夠大，保護已有大疊地位更重要

保守策略（不推薦）：
  看著短疊慢慢出局
  這浪費了大疊的 ICM 槓桿優勢

最佳策略：
  連續對中疊施壓（最有效的 ICM 武器）
  偶爾對短疊出手（需要有品質的手牌）
  避免大疊 vs 大疊（除非有極強手牌）
```

## 第七節：大疊 vs 大疊的 PLO FT Spot

### 7.1 深疊 PLO 對決的風險評估

```
情境：FT 只剩 5 人，籌碼分布：
  你（大疊）：900,000（45%）
  對手（大疊）：750,000（37.5%）
  其他 3 人：350,000 共（17.5%，都是短疊）

大疊 vs 大疊的 PLO 對決代價：

最壞情況（你輸）：
  你：900,000 → 150,000（從大疊變短疊）
  對手：750,000 → 1,650,000（獨佔主導地位）
  ICM 損失：你的 ICM 從頂端跌落到危險區

如果贏：
  你：900,000 → 1,650,000
  ICM 增加，但邊際遞減（從大疊到更大疊，增益有限）

結論：大疊 vs 大疊 = 高風險，低邊際收益
  PLO 中尤其危險（因為 equity 差距小 = flip 機率高）
```

### 7.2 哪些手牌值得大疊 vs 大疊？

```
PLO FT 大疊 vs 大疊值得 commit 的手牌：

絕對值得（Tier 1）：
  AA ds（雙花色 AA）：有足夠的 equity 優勢
  AAKK ds：同上
  A♠A♥K♠Q♥（AA + nut flush draws）：很強

可以 commit（Tier 2，取決於 board 和情況）：
  Nut Straight + Nut Flush Draw（翻牌後）
  Set + Nut Flush Draw（翻牌後強力 combo）

  注意：這些在 cash game 是明顯 commit 的手牌
  但在 FT 大疊 vs 大疊場景，仍需評估 ICM

不建議 commit（儘管很強）：
  Bottom set without redraws（無備用 draw）
  Naked top set（只有三條，無 draw backup）
  Nut flush draw without pair/straight draw
```

## 第八節：PLO FT 起始牌調整

### 8.1 FT 應該收緊的手牌（C 級牌全部折）

```
PLO FT 需要折棄的「Cash Game 可以打但 FT 不能打」手牌：

C 級手牌（FT 早期 / 中期全部 fold）：

❌ 低連牌（無 suit）：
   6543 rainbow, 5432 rainbow, 7654 rainbow
   原因：Cash game 有隱含賠率，FT 中 SPR 低，隱含賠率消失

❌ 弱高牌雜牌：
   KJ82 (1 suit), Q943 (rainbow), K852 (2 suits)
   原因：手牌結構太差，翻牌後難以形成強手

❌ 弱對子雜牌：
   JJ43 (rainbow), TT52 (1 suit)
   原因：FT 中小對子的設陷阱（set mining）隱含賠率不足

❌ 單花色但無連牌的雜牌：
   K♠T♠5♥2♦：只有高牌和一個 flush draw 可能性
   原因：手牌 combinatorial 潛力太低

FT 的 C 級手牌 fold 原則：
  「如果你的手牌翻牌後只能靠一種 draw 保命，就是太弱」
  FT 需要 A+B 的手牌結構：同時有 2 條以上的 draw 路徑
```

### 8.2 FT 仍然可以 Open 的手牌

```
PLO FT 推薦開放的手牌清單（從 A 到 B 級）：

A 級手牌（任何位置、任何 FT 階段均可 open）：
  AA（任何 suit）
  AAKK（2 suits+）
  AAQQ, AAJJ（2 suits）
  AA ds（AA + 2 suited cards）
  KK ds（KK double-suited）

B+ 級手牌（位置良好時 open，中位以後）：
  AKQJ（任何 2 suits）
  AKQJ ds（最強 rundown）
  KQJT（ds 或 2 suits）
  QJT9 ds

B 級手牌（僅限 BTN/CO 開放，FT 6 人以下）：
  JT98 ds
  T987 ds
  A-high rundown（如 A5432 ds）
  AATT, AAJJ（single suited）

FT 位置 × 手牌品質矩陣：
  位置       A 級      B+ 級     B 級
  UTG        ✓         ✓         ✗
  HJ/MP      ✓         ✓         ✗（6人以下 ✓）
  CO         ✓         ✓         ✓（人數減少後）
  BTN        ✓         ✓         ✓
  SB         ✓         ✓         ✗（無位置）
```

## 第九節：Deal Making in PLO MTT

### 9.1 為什麼 PLO MTT 的 Deal 更常見

```
PLO MTT Deal Making 的背景：

線上 PLO MTT 中，FT 3-5 人時常提出 deal 原因：
  1. PLO 的 high variance：即使大疊也可能在幾手牌內出局
  2. 大家都知道任何人都可能逆轉 → 願意 chop
  3. 剩餘獎金差距大（1st vs 3rd 可能差 5 倍）

Deal 類型：
  ICM Chop：最公平，按 ICM 計算每人應得
  Chip Chop：按籌碼比例分，對大疊有利
  Even Chop：平分，對小疊有利
  Deal + 留一小部分獎金繼續打（最常見）
```

### 9.2 ICM Chop 計算方法

```
ICM Chop 計算（3 人剩餘例子）：

FT 剩餘 3 人，剩餘獎金池 = $10,000：
  1st：$5,000  2nd：$3,000  3rd：$2,000

籌碼：
  A：600,000（60%）
  B：250,000（25%）
  C：150,000（15%）

步驟 1：計算每人 ICM EV（見第五節方法）
  A 的 ICM ≈ $4,150
  B 的 ICM ≈ $3,150
  C 的 ICM ≈ $2,700
  總和 = $10,000 ✓

ICM Chop 結果：
  A 拿：$4,150
  B 拿：$3,150
  C 拿：$2,700

對比 Chip Chop：
  A 拿：$6,000（60%）
  B 拿：$2,500（25%）
  C 拿：$1,500（15%）

分析：
  ICM Chop 對 B 和 C 更有利（保護小疊）
  Chip Chop 對大疊有利
  PLO 的 high variance → ICM Chop 對大疊比 NLH 更重要
    （因為大疊在 PLO 的籌碼優勢較難維持）
```

### 9.3 Deal 談判技巧

```
PLO MTT Deal 談判策略：

你是大疊時：
  提議：Chip Chop（但對手通常拒絕）
  實際：可以接受 ICM Chop
  策略：如果 ICM Chop 給你 $4,000+，值得接受
         避免因為貪心繼續打而遭遇 bad beat

你是中疊時：
  提議：ICM Chop（最符合你的利益）
  如果對手拒絕：繼續打，等更好機會再提

你是短疊時：
  提議：Even Chop（但大疊通常拒絕）
  或提議：ICM Chop（比繼續打可能出局好）
  策略：評估你的 PLO 翻身機率
         如果對手明顯比你強（更有 PLO 技術）→ 傾向接受 deal
         如果你有技術優勢或對手犯錯 → 繼續打
```

## 第十節：PLO FT 常見錯誤（至少 5 個）

### 錯誤 1：把 PLO FT 當 Cash Game 打

```
錯誤描述：
  繼續用 Cash Game 的 open range（太寬）進入底池
  翻牌後繼續用 Cash Game 的打法（不考慮 SPR 和 ICM）

具體例子：
  FT 10 人，你在 CO，手牌 8♠7♦6♣5♥（低連牌 rainbow）
  Cash Game：open（有隱含賠率）
  FT：fold（手牌結構差，FT 的 SPR 不適合 draw 玩法）

後果：
  頻繁進入翻牌後但沒有強手 → 持續消耗籌碼 → 淪為短疊
```

### 錯誤 2：FT 大疊過度激進（把每個 spot 都打）

```
錯誤描述：
  大疊把每個可以 pot raise 的機會都利用
  導致和其他大疊發生不必要的對抗

具體例子：
  你有 40% 籌碼，在 HJ 拿到 KQJT ds
  CO（20% 籌碼）raise，你 3-bet
  CO 4-bet，你 call
  翻牌：A♠J♥2♦（你沒打中）→ 繼續下注 → 浪費籌碼

正確做法：
  KQJT ds 是 B+ 級手牌，但面對 CO 的強力 raise 可以 fold
  大疊的價值在於「隨時可以施壓」，不是「必須打每一手」
```

### 錯誤 3：低估短疊的翻身潛力（不對短疊施壓）

```
錯誤描述：
  大疊/中疊認為「短疊快死了，不用管他」
  讓短疊免費看翻牌，或讓短疊在底部掙扎太久

具體例子：
  FT 5 人，短疊有 8 bb
  你（大疊）在 BTN 拿到 QQ74 ds，不 raise → 短疊 BB 拿到免費翻牌
  短牌翻中 set，對你的 QQ 造成威脅

正確做法：
  PLO 的 set mining 潛力很高，不要讓短疊免費看牌
  在 BTN 用任何 B 級以上手牌 pot raise
  逼短疊決定是否全押（讓他在惡劣條件下做決定）
```

### 錯誤 4：翻牌後不考慮 SPR 就 commit

```
錯誤描述：
  FT 中的 SPR 通常比 Cash Game 低
  玩家直接用 Cash Game 的「我有 draw，可以打」邏輯 commit
  結果在 SPR 很低的情況下用 draw 全押（實際是負 EV）

具體例子：
  FT，SPR = 2（底池 = 100bb，各有 200bb 籌碼）
  你翻牌後有 open-ended straight draw（8 outs）
  Cash Game：可以考慮 semi-bluff
  FT SPR = 2：你的 draw 在翻牌有約 32% 機率中（一條街），
               全押是 32% vs 68%，在 FT ICM 加持下是負 EV

正確做法：
  FT 翻牌後評估 SPR，SPR < 2 時只有 combo draw（15+ outs）才 commit
```

### 錯誤 5：不做 Deal 計算，情緒化接受或拒絕 Deal

```
錯誤描述：
  Deal 提議來了，玩家憑感覺答應或拒絕
  不計算自己的 ICM EV，結果接受了不公平的 deal

具體例子：
  FT 3 人，你有 60% 籌碼，對手提議 Even Chop（平分）
  你說「好啊，大家都想回家」→ 你放棄了 $1,450 的 EV

正確做法：
  任何 deal 前，快速心算 ICM Chop 的大致金額
  如果對手的提議比你的 ICM EV 低 10% 以上 → 拒絕
  如果接近或高於 ICM EV → 可以考慮接受
```

### 錯誤 6：PLO FT 對每次 3-bet 都 4-bet（過度激進）

```
錯誤描述：
  在 FT 遇到 3-bet 後，總是想要 4-bet 表現強勢
  沒有考慮 PLO 4-bet 後的底池大小和 SPR

具體例子：
  你 raise，對手 3-bet（底池 = 3 × 大盲）
  你 4-bet pot → 底池已經 = 10+ × 大盲
  翻牌後 SPR ≈ 0.5 → 自動全押
  你其實只有 QQ87，而對手有 AA → 你是 40% 劣勢方 + ICM 代價

正確做法：
  FT 的 4-bet range 應該更緊：主要是 AA, AAKK
  遇到 3-bet：先評估對手 range，多數時候 call 或 fold 比 4-bet 更好
```

## 第十一節：PLO FT 具體手牌場景分析

### 場景 1：FT 獎金泡泡期的困難決定

```
情境設定：
  FT 5 人剩餘，獎金跳升前（第 4 名 vs 第 3 名差 $1,500）
  盲注：10,000/20,000
  籌碼：
    你（BTN）：450,000
    SB（大疊）：700,000
    BB（短疊）：80,000（4 bb）
    其他 2 人各 ≈ 385,000

你的手牌：K♠K♥Q♠J♥（KK + Broadway 連牌）

動作：
  Fold, Fold（輪到你），SB fold，BB 已在（4 bb 剩餘）

你的選擇：
  A) 直接 pot raise（逼 BB 決定）
  B) Call（讓 BB 免費翻牌）
  C) Fold（放棄位置優勢）

分析：
  選項 A 最正確：
    KK QJ ss 是 B+ 級手牌
    Pot raise → BB 面臨 all-in 決定（只有 4 bb）
    BB 會 call with 很多手牌（短疊被迫 gamble）
    即使 BB call，你有 KK 的翻牌前 equity 優勢

  ICM 角度：
    BB 出局 = +$1,500 獎金跳升（接近）
    你 raise 後 BB fold = 贏了盲注，BB 更快出局
    你 raise 後 BB all-in，call（80,000）是小代價

  結論：Pot raise，call BB 的 all-in
```

### 場景 2：FT 大疊 vs 大疊的正確棄牌

```
情境設定：
  FT 4 人，籌碼：
    你（CO）：900,000（45%）
    BTN（大疊）：850,000（42.5%）
    SB：150,000
    BB：100,000
  盲注：20,000/40,000

你的手牌：Q♠J♠T♥9♦（QJT9 ds 但只 1 suit = QJTS 只有黑桃同花）

動作：
  BTN raise pot to 140,000
  SB, BB fold
  輪到你（CO）

問題：call, 3-bet, 還是 fold？

分析：
  QJT9 with 1 suit = B 級手牌（不是 ds，強度打折）
  BTN 是大疊，range 較寬，但可能有強牌

  Call 分析：
    進入翻牌後 SPR ≈ 5（900k - 140k = 760k 剩，底池 = 280k + 40k 盲注）
    SPR ≈ 760/320 ≈ 2.4（其實 SPR 低）
    翻牌後很容易被 bet 進 all-in 困境

  3-bet 分析：
    3-bet 到 500,000
    BTN 可能 4-bet（因為他是大疊）
    你不想在 FT 大疊 vs 大疊 commit QJT9（非頂級手牌）

  Fold 分析：
    ICM 壓力：大疊 vs 大疊在 FT 4 人 = 高風險
    QJT9 1 suit 在 FT 不夠強到要對大疊 commit

  結論：Fold（ICM 壓力 > 手牌潛力）

  關鍵學習：
    在 Cash Game，QJT9 ds 面對 BTN raise 幾乎一定 call
    在 FT 4 人大疊 vs 大疊，正確做法是 fold
    這就是 FT ICM 策略調整的核心
```

### 場景 3：三人 ICM 計算後的 Deal 決策

```
情境設定：
  FT 最後 3 人
  獎金：1st $8,000 / 2nd $5,000 / 3rd $3,000
  剩餘獎金池 = $16,000

籌碼：
  你：500,000（50%）
  A：300,000（30%）
  B：200,000（20%）

對手 A 提議：Even Chop（每人 $5,333）

你的 ICM 計算：
  你的 P(1st) ≈ 50%
  你的 ICM ≈ 0.50 × $8000 + 0.32 × $5000 + 0.18 × $3000
           ≈ $4,000 + $1,600 + $540 = $6,140

A 的 ICM ≈ 0.30 × $8000 + 0.35 × $5000 + 0.35 × $3000
         ≈ $2,400 + $1,750 + $1,050 = $5,200

B 的 ICM ≈ 0.20 × $8000 + 0.33 × $5000 + 0.47 × $3000
         ≈ $1,600 + $1,650 + $1,410 = $4,660

ICM Chop 結果：你 $6,140 / A $5,200 / B $4,660

對比 Even Chop：你 $5,333 / A $5,333 / B $5,333

分析：
  Even Chop 對你損失：$6,140 - $5,333 = $807
  對 A 增加：$133（A 的 ICM 比 Even Chop 稍低）
  對 B 增加：$673（B 明顯得益）

  你應該如何回應：
  方案 1：拒絕 Even Chop，提議 ICM Chop
    「我的 ICM 價值是 $6,140，我接受 ICM Chop 或類似計算」

  方案 2：如果對手不接受 ICM Chop
    繼續打，你有籌碼優勢，應該可以維持 ICM 優勢

  方案 3：接受 Even Chop（如果你評估對手 PLO 技術更強）
    PLO 的 variance 很高，即使你有大疊，對手可能更擅長 HU
    評估：如果你的技術比對手差 → 可以考慮接受 Even Chop 的小損失換確定性

結論：
  絕對不要情緒化接受 deal
  先計算 ICM，再做決定
  PLO 的 high variance 讓 deal 有其合理性，但要確保不吃大虧
```

## 第十二節：PLO FT 策略總結

### 核心原則彙整

```
PLO FT 十大核心原則：

1. ICM 第一，Chip EV 第二
   PLO 的高方差使 ICM 考量比 NLH FT 更重要

2. 大疊謹慎施壓，不打不必要的大疊 vs 大疊
   PLO 的 flip 機率讓大疊 vs 大疊有巨大下行風險

3. 中疊等 premium，不浪費在 B 級手牌
   中疊的籌碼是生存資本，要用在最高 EV 的 spot

4. 短疊更緊，但不放棄翻身希望
   PLO 的短疊翻身機率比 NLH 高，等 premium 手牌 push

5. Pot Limit 計算在腦中常備
   每次 raise 前快速計算底池大小和 SPR

6. FT 的 C 級手牌一律折
   低連牌、弱雜牌在 FT 沒有足夠的隱含賠率

7. 人數越少，range 越寬（6 人以下）
   人數縮減後逐步擴展 open range

8. Deal Making 前先算 ICM
   不情緒化接受不公平的 deal

9. 永遠記得 PLO 翻牌後的逆轉機率
   即使你有強手，對手的 draw 可能是真實威脅

10. FT 的目標是最大化 $EV，不是最多 chips
    記住籌碼的邊際遞減效應
```
