# PLO MTT 各階段策略調整

> 本章以籌碼深度為主軸，詳細講解 PLO MTT 從開局到超短疊的完整策略轉換。
> 涵蓋 9-max 位置策略、起始牌調整、翻牌後邏輯，以及每個階段的常見錯誤。

---

## 總覽：四大籌碼深度階段

```
深疊期    100bb+   類 Cash Game 策略，充分發揮 PLO 技術
中疊期    30-100bb  漸進收緊，減少 Marginal Spots
短疊期    15-30bb   Push/Fold 主導，選擇翻倍時機
超短疊    <15bb     純 Push/Fold，等待最強手牌
```

每個階段的策略差異巨大，需要明確感知自己當前所在的階段。

---

## 第一階段：深疊期（100bb+）

### 核心特點

深疊期是 PLO 最接近 Cash Game 的階段。100bb+ 的籌碼深度允許複雜的翻牌後策略，
Implied Odds（隱含賠率）高，可以追逐各種 Draw。

### 起始牌策略（深疊期）

```
可玩範圍：約 28-35%（位置調整後）

A 級手牌（任何位置可玩）：
  - AA double-suited（最強起始牌）
  - AA + 任何 rundown（AAKK, AAQJ, AAJT 等）
  - AKQJ double-suited
  - 強 double-suited rundown（JT98 ds, QJ09 ds, KQJ9 ds）

B 級手牌（EP 謹慎，IP/後位可玩）：
  - KK double-suited 帶 broadway
  - 中等 double-suited rundown（T987 ds, 9876 ds）
  - AA single-suited 帶 low rundown
  - Suited Ace + rundown（A♠K♦J♠T♦ 類型）

C 級手牌（只在 CO/BTN/SB 可玩，需 fold equity）：
  - Single-suited rundown（QJT9 ss）
  - KK rainbow 帶 connected board
  - Double-paired hands（KKQQ ds, JJTT ds）

深疊特別重視的牌型：
  - 高 Implied Odds 手牌（如 T♠9♠8♦7♦：可以在多人底池中暗 set）
  - Double-suited low rundown（可以撈到巨大底池）
```

### 翻牌後策略（深疊期）

**多人底池打法**

深疊期的 PLO MTT 常見多人底池（3-4 名玩家入池），這是 PLO 最有趣也最複雜的情況。

```
多人底池的核心原則：
  1. 只追求 Nut 或接近 Nut 的牌力
  2. 有 Nut Draw 才積極，沒有就保守
  3. 乾燥板可以適當 C-bet，濕潤板需要謹慎

翻牌場景：4 人入池（你在 BTN）
翻牌：K♥Q♣9♠

你的手牌：J♠T♠8♦7♦

分析：
  你有 Wrap Draw（J-T-8 + 9 on board = Wrap to A/K/Q/J/T/8/7 multiple outs）
  約 13-17 outs（視具體 Wrap 計算）
  Backdoor Flush Draw (Diamonds)

  多人底池中，這手是 strong draw，可以接受一個 Pot-size bet
  如果有人在你前面 Bet + Raise，你有折疊考量（非 Nut Draw in multi-way）
```

**深疊翻牌後 SPR 分析**

```
SPR（Stack-to-Pot Ratio）= 有效籌碼 / 底池

深疊期 SPR 通常很高（10-20+）

高 SPR 的打法含義：
  你需要更強的牌力才能 commit
  翻牌後的「Get it in」需要接近 Nut 水準

翻牌後 SPR 示例：
  3-bet 底池，3 人
  底池大小：15bb
  你的有效籌碼：100bb
  SPR = 100/15 ≈ 6.7（仍相對高）

  SPR 6-7 的標準：
    Set 可以考慮 commit（尤其乾燥板）
    Nut Flush Draw + OESD 可以積極 semi-bluff
    Top Two Pair 需要謹慎，視板質而定
    弱 Set（底層 3 of a kind）在濕潤板可以 fold！
```

### 深疊期的位置策略（9-max）

```
9-max 位置分類（深疊期）：

UTG / UTG+1（早位）：
  開牌 range：A 級手牌 + 部分 B 級（大約 15-18%）
  不要用邊緣牌在 OOP 建大底池
  重視 3-bet 保護（避免多人進底池時失去優勢）

MP / HJ（中位）：
  開牌 range：A+B 級手牌（大約 20-25%）
  可以開放更多 suited Ace 手牌
  位置相對改善，Implied Odds 更高

CO（中晚位）：
  開牌 range：A+B+部分C（大約 28-32%）
  隔離 Limp 的機會增加（3-bet with strong hands）
  BTN 的 call/steal 對你影響最大，注意

BTN（按鈕）：
  最強位置，可以玩最廣的範圍（32-38%）
  翻牌後永遠 IP，Implied Odds 最高
  可以玩更多 speculative hands（9876 ds 等）

SB（小盲）：
  謹慎：翻牌後永遠 OOP（除非 BB 折疊）
  Limp 進底池：適合深疊期追逐 Draw（OOP 的 Implied Odds）
  3-bet：只用強手牌，因為 OOP 打大底池很難受

BB（大盲）：
  防守 range 廣（你已付 1bb）
  可以用更多手牌 defend（利用 closing action）
  翻牌後 OOP，但底池賠率好
```

## 第二階段：中疊期（30-100bb）

### 策略轉換信號

當你的籌碼縮減到 80bb 以下，開始感受 ICM 壓力時，需要調整策略。

```
中疊期信號：
  ✓ 籌碼 < 80bb
  ✓ 距離泡沫 < 2 倍剩餘玩家數
  ✓ 開始有短疊玩家在桌
  ✓ 對手開始改變策略（更保守或更激進）
```

### 起始牌調整（中疊期）

**核心原則：減少 Marginal Spots**

```
從深疊期「可玩」到中疊期「不可玩」的手牌：

去掉的手牌類型：
  1. Single-suited rundown（非 A）
     深疊：T987 single-suited 可玩（Implied Odds 補償）
     中疊：Implied Odds 減少，翻牌後能力下降，fold

  2. Low dangling 手牌
     深疊：K♠Q♠J♠3♦（3 是 dangling，仍可接受）
     中疊：只要有 dangling card 的 broadway，考慮 fold

  3. Bare pairs（無連接性）
     深疊：JJ72 double-suited 可玩
     中疊：JJ72 ds 在 EP/MP fold（太多 flip 情況）

  4. 弱 double-paired
     深疊：8877 ds 可玩
     中疊：除非有 IP，否則 fold

保留的手牌（在中疊期仍然重要）：
  - AA 任何搭配
  - KK double-suited + connected
  - 強 double-suited rundown（JT98 ds, QJT9 ds）
  - 有 Nut draw 潛力的手牌
```

### 中疊期翻牌後調整

**減少「Marginal」翻牌後投入**

```
什麼是 Marginal PLO 底池？

1. 你有強牌，但對手可能有 Nut
   例：你有 Top Set，對手 Pot-raises，板面有 Flush（你無 Flush）
   深疊：call，你可能 draw out
   中疊：fold，ICM 代價太高

2. 你有好的 Non-nut Draw
   例：Second Nut Flush Draw（沒有最高同花牌）
   深疊：積極 Semi-bluff
   中疾：謹慎，只在有額外 Outs（OESD + Second Nut FD）時繼續

3. 翻牌後的「被動選擇」
   例：BB defend，翻牌 hit 中等（Top Pair + 弱 Draw）
   深疊：可以做 Donk Bet 或 Check-call
   中疊：傾向 Check-fold（非 Nut situation）
```

**中疊期 C-bet 調整**

```
翻牌後 C-bet 頻率調整（中疊期）：

深疊期 C-bet 頻率：約 50-60%（包含 Bluff）
中疊期 C-bet 頻率：約 35-45%（更多 Value-only）

調整方向：
  ✓ 繼續 C-bet：有 Nut Draw 或 Strong Made Hand
  ✓ 繼續 C-bet：乾燥板（K72 rainbow），保護式 C-bet
  ✗ 停止 C-bet：多人底池，沒有 Nut Draw
  ✗ 停止 C-bet：濕潤板，只有邊際手牌
```

### 中疊期的位置策略

```
中疊期位置調整（9-max）：

EP/MP 的調整：
  范圍收緊 5-8%
  重點：只開 A 級 + 強 B 級手牌
  避免：limping（中疊 limp 給對手便宜看翻牌）

BTN/CO 的維持：
  仍然可以較寬範圍，因為 IP 的優勢抵消部分 ICM 壓力
  但要注意：BTN 3-bet 的 commit 門檻

SB 的調整（重要）：
  中疊期在 SB 的 limp 減少
  OOP 打中等 PLO 底池代價太高
  主要策略：fold 或 3-bet（極化）
```

## 第三階段：短疊期（15-30bb）

### Push/Fold 邏輯的引入

短疊期（15-30bb）是 PLO MTT 最獨特的階段。PLO 的翻牌後複雜性在此幾乎消失，
轉變為高度簡化的 **Push/Fold** 決策。

**為什麼 PLO 的短疊 Push/Fold 和 NLH 不同：**

```
NLH 短疊 Push/Fold：
  決策因素：你的手牌 Equity vs 對手 Call range
  翻牌後：很少，因為直接 all-in 在翻牌前
  AA push：約 80% 贏率

PLO 短疊 Push/Fold：
  決策因素更複雜：
    1. 翻牌前 Equity（AA 約 60-65%）
    2. 你的 Fold Equity（能讓幾人 fold？）
    3. 位置（IP push 比 OOP push 有更多 Fold Equity）
    4. PLO 沒有 NLH 那樣的「壓倒性翻牌前優勢」

結論：PLO 短疊 Push/Fold 需要更謹慎，因為被 call 時你的 Equity 不如 NLH 那麼高
```

### PLO 短疊 Push Range（以 25bb 為例）

```
25bb 深度，9-max PLO MTT Push Range：

UTG Push Range（緊，約 8-10%）：
  Tier 1（必 Push）：
    - AA 任何（4 張帶 AA）
    - KKQQ double-suited
    - KK + strong rundown（KKJT ds）
  Tier 2（考慮 Push）：
    - QQ double-suited 帶 broadway（QQJT ds）
    - 強 4-card double-suited rundown（JT98 ds, QJT9 ds）

MP Push Range（稍放寬，約 12-15%）：
  Tier 1 + Tier 2 + 以下：
    - KK + suited broadway
    - T987 double-suited
    - AA single-suited（仍然 push）

CO Push Range（約 18-22%）：
  上述所有 + 以下：
    - QQ + any suited rundown
    - K♠Q♠J♦T♦（KQJ suited）
    - 中等 double-suited rundown（9876 ds）

BTN Push Range（最廣，約 25-30%）：
  CO Range + 以下：
    - Single-suited rundown（QJT9 ss）
    - Double-paired broadway（KKQQ rb）
    - JJ + rundown（JJ09 ds）

SB vs BB（特殊位置）：
  SB Push：約 BTN 的 70%（對抗 BB，BB 可以 call 更寬）
  BB Call vs 各位置 Push：
    用 AA，KK ds，強 rundown call（約 30-40% 的手牌）
```

### 短疊期的「Pot then Fold」模式

```
一個短疊 PLO 特有的策略：

情況：你有 22bb，在 CO 位置，手牌 K♠Q♠J♦T♦
      前面有人 Open Raise（標準 2.5bb）

選項分析：
  A. 3-bet pot（大約 pot = 2.5 + 0.5 + 1 = 4, pot-raise ≈ 13bb）
     → 你投入 13bb，有效籌碼 = 9bb 剩餘
     → 此時你已 commit（9bb vs 剩餘），必須全押翻牌

  B. Call
     → 翻牌後有位置，但只有 19bb 剩餘，SPR 很小
     → 翻牌後你也幾乎是 commit（如果翻牌 hit 你的牌）

  C. All-in（22bb push）
     → 最簡單，利用 Fold Equity
     → 如果有人 call，你有 KQJTs 的 Equity（較強）

  最優選擇：視情況，通常是 C（直接 push）或 A（pot + commit）
  不適合 B（call 然後翻牌後複雜決策，短疊 OOP）
```

### 短疊期翻牌後的 Commit 原則

```
PLO 短疊翻牌後 Commit 門檻：

如果翻牌後你的 SPR < 2：
  幾乎所有 Top Pair + Draw 或以上都應該 commit
  折疊只有在板面對你極為不利時

如果翻牌後你的 SPR 在 2-4：
  需要至少 Nut Draw 或 Two Pair+ 才考慮 commit
  弱牌可以放棄

PLO 短疊翻牌後常見錯誤：
  × 翻牌後太慢（check-call 而非 push），浪費 Fold Equity
  × 在沒有 Equity 時 commit（Pair only，無 Draw）
  √ 翻牌後有 Nut Draw 就積極 push（拿到 Fold Equity 最重要）
```

## 第四階段：超短疊（<15bb）

### 超短疊的生存邏輯

超短疊（< 15bb）時，PLO MTT 的策略極度簡化。

```
超短疊核心思維：

1. Fold Equity 幾乎消失（<10bb 時，大家更願意 call）
2. 你必須依賴 Equity 贏牌
3. 盲注正在快速消耗你的籌碼
4. 每次 fold 都在接近「被動 all-in」（被迫用 BB/SB 拿最差手牌）

結論：必須積極行動，但只用 Premium hands
```

### 超短疊 Push Range（< 15bb）

```
10-15bb 深度的 Push Range：

任何位置都應該 Push 的手牌（Top ~15%）：
  必 Push：
    - AA 任何搭配
    - KK double-suited 帶連牌（KKQJ ds, KKQT ds）
    - 強 4-card rundown double-suited（JT98 ds, QJT9 ds, KQJ9 ds）
    - AAKK（任何花色組合）

  Strong Push（從 MP 開始）：
    - QQ double-suited + broadway
    - AA single-suited
    - T987 double-suited

  Position-dependent Push（只在 CO/BTN）：
    - KK + single-suited connected
    - JJ double-suited + connected
    - 9876 double-suited

手牌應該 Fold（即使有時候很難 fold）：
  - Single-suited rundown 非 Nut（低牌）
  - Bare Pairs 無連接（TT74 rainbow）
  - Rainbow 無高牌（8765 rb）
  - Dangling 低牌（K854 rb）
```

### 超短疊的 BB Push/Fold

```
在 BB 位置面對 Push 時（10-15bb）：

你的 Call Range（寬，因為你已付 1bb）：
  Call 約 35-45% 的 Push：
    - 所有 AA
    - 所有 KK + broadway
    - Double-suited 強 rundown
    - AKQJ 帶 suited

  Fold 的手牌（即使 BB 已付錢）：
    - 弱 rainbow 手牌
    - 單牌配 3 張無關牌
    - Low dangling（8743 rb）

重要：PLO BB vs Push 的 Equity 計算
  你需要 ~40% Equity 才值得 call（假設 10bb push）
  弱 PLO 手牌往往只有 25-35% Equity vs 強 Push range
```

## 各階段翻牌後分析範例

### 深疊翻牌場景（100bb）

```
手牌：A♠K♠Q♥J♥（AKQJ double-suited）
翻牌：T♠9♦8♣（三連牌）

分析：
  你有 Nut Straight + Backdoor Flush Draw
  這是 Deep Stack PLO 中的「夢幻翻牌」

  策略：
    OOP：Donk-bet pot（保護並建立底池）
    IP：Check-raise（讓對手 bluff into you）
    多人底池：Bet-pot（Nut Straight on wet board 需要保護）

  深疊的好處：即使被 re-raise，你有 Nut，可以 call/raise back
```

### 中疊翻牌場景（60bb）

```
手牌：Q♠J♥T♣8♦（single-suited，中等 rundown）
翻牌：K♥9♦7♠（你有 Wrap Draw）

分析：
  你有 Wrap Draw（J-T-8 + K-9-7 on board = outs to J, 8, and 6 = 约 13-16 outs）
  但你沒有 Made Hand，沒有 Flush Draw

  中疊（60bb）的策略：
    SPR ≈ 60/6（如果是 3-bet 底池） = 10
    這不是 Commit 情況，即使你的 Draw 很強

    IP：Check back（控制底池，等 Turn 決定）
    OOP：Check-call 如果對手 bet 小（≤ 1/2 pot）
    OOP 面對 Pot-bet：Fold（非 Nut，中疊，ICM 代價）

    關鍵差異（vs 深疊）：
      深疊：可以積極 Semi-bluff 這個 Wrap
      中疊：保守，non-nut draw 的 Pot-size bet 不值得冒
```

### 短疊翻牌場景（20bb）

```
手牌：K♠Q♠J♦9♦（double-suited）
翻牌：T♠8♣2♦

分析：
  你有 Wrap Draw（K-Q-J + T-8 = J-9 or 9-7 = Wrap outs...）
  計算：你需要 J, 9, 7 for straight
  約 9-13 outs

  短疊（20bb）翻牌後場景：
    如果翻牌前 Pot = 4bb，你有 16bb 剩
    SPR ≈ 16/4 = 4（低 SPR）

    策略：
      你有 Wrap Draw 在低 SPR 底池 → 積極
      應該 Push（16bb into 4bb pot）
      理由：Fold Equity + Equity（9-13 outs = ~35-50% to improve）

      即使被 call，你有 35-50% Equity（在 Chip EV 是正值）
      加上 Fold Equity（有人 fold），整體 EV 更好
```

## 各階段常見錯誤

### 深疊期常見錯誤

```
錯誤 1：追非 Nut Draw 在多人底池
  情況：3+ 人入池，你有 Second Nut Flush Draw
  問題：在 PLO 多人底池，Second Nut 常常輸給 Nut
  修正：只在你有 Nut Draw 或 Made + Non-nut Draw 組合時積極

錯誤 2：對 Dry Board 過度 C-bet Bluff
  情況：EP 開牌，2 人 call，翻牌 K72 rainbow，你 Pot-bet Bluff
  問題：在多人底池，C-bet bluff 的成功率低（需要 2+ 人 fold）
  修正：多人底池主要 C-bet Value，減少 Bluff

錯誤 3：對強手牌慢打導致失去底池
  情況：你翻牌三條（Set），Check，Turn 不利，對手已有 Flush
  問題：PLO Set 必須在翻牌積極下注保護
  修正：濕潤板上 Set 必須積極，不能慢打
```

### 中疊期常見錯誤

```
錯誤 1：用中疊打「深疊 PLO 底池」
  情況：60bb 深，進入 100bb 以上的 3-bet 底池
  問題：你的 SPR 很低，等同於短疊打法，但選牌沒有調整
  修正：中疊不要 call 大的 3-bet，除非你有 Premium hands

錯誤 2：在 Marginal 情況追 Non-nut Draw
  情況：有人 Pot-bet，你有 Wrap Draw 但沒有 Nut，中疊 call
  問題：這是 Chip EV 邊際的情況，ICM 代價可能使其 -EV
  修正：非 Nut Draw 在中疊期面對 Pot-size bet 傾向 fold
```

### 短疊期常見錯誤

```
錯誤 1：等待「完美手牌」太久
  情況：25bb，等到 12bb 才 push，Fold Equity 已消失
  問題：Short-stack PLO 需要在 15-25bb 時積極找機會
  修正：20-25bb 時，就要積極用 Tier 1/2 hands push

錯誤 2：用弱牌 push（焦慮式 push）
  情況：18bb，著急，用 K985 rb（弱牌）push
  問題：被 call 時 Equity 太差（可能只有 25-30%）
  修正：短疊 push 仍需要有 40%+ Equity 當被 call 時
```

## 本章重點回顧

1. **深疊期（100bb+）**：類 Cash Game，追 Nut Draw，利用 Implied Odds，可以複雜多人底池。
2. **中疊期（30-100bb）**：收緊起始牌，減少 Marginal Spots，Non-nut Draw 面對 Pot-bet 傾向 fold。
3. **短疊期（15-30bb）**：Push/Fold 主導，PLO push range 比 NLH 更窄（因為被 call 時 Equity 較低）。
4. **超短疊（<15bb）**：只打 Top ~15% 的 Premium hands，積極等待，不要浪費在弱牌上。
5. **位置永遠重要**：每個階段 BTN 的可玩範圍都是 EP 的 2 倍左右，位置在短疊期仍有 Fold Equity 價值。
