# 多條街打法：轉牌與河牌

## 多條街思維

撲克是一場**三條街的戰鬥**（翻牌 + 轉牌 + 河牌）。

每一條街都不是獨立的：
- 翻牌的行動決定了轉牌的底池大小和 SPR
- 轉牌的牌影響哪一方 range 改善更多
- 河牌是最終攤牌或對手 fold 的時刻

**多條街打法的核心問題：**
> 我計劃打幾條街？每條街打多大？

---

## SPR（Stack-to-Pot Ratio）回顧

```
SPR = 有效籌碼 ÷ 翻牌後底池
```

| SPR | 含義 | 打法 |
|-----|------|------|
| >10 | 深疊，多條街空間 | 可以打三條街，慢打有價值 |
| 4-10 | 標準，中等承諾 | 兩條街通常已 commit |
| 2-4 | 低 SPR，高承諾 | 翻牌強牌幾乎 stack off |
| <2  | 接近 all-in | 翻牌就決定了 |

## 轉牌策略

### 轉牌的三個主要場景

#### 場景 1：翻牌 C-bet，對手 call，轉牌繼續（雙桶）

**轉牌應該繼續 bet 的情況：**

1. **你有很強的手牌**（value）
   - 翻牌 TPTK，轉牌仍是最強 → 繼續 bet
   - 翻牌 set，繼續建底池

2. **轉牌改善了你的 range**
   - 你 BTN open，翻牌 AK7，轉牌 A（paired）
   - 你的 range 有 AA, AK → 強化你的 range advantage

3. **轉牌給你 strong draw**
   - 翻牌有 backdoor flush，轉牌來了一張同花 → 現在你有 flush draw
   - Semi-bluff 繼續

**轉牌應該 check 的情況：**

1. **轉牌對對手 range 更好**
   - 翻牌 AK7，轉牌 8 → 對手的 78s, 89s 直接中順子邊
   - 謹慎繼續

2. **你要保護 check range**
   - 不能每次轉牌都 bet，否則你 check = 弱牌
   - 把一些強牌加入 check range（慢打/陷阱）

3. **你是純 bluff，已經無路可走**
   - 翻牌 bluff，轉牌對你 range 沒幫助 → check，放棄

#### 場景 2：翻牌 check-check，轉牌下注

翻牌雙方都 check，轉牌你選擇 bet：

**適合 bet 的情況：**
- 轉牌牌型讓你有 range advantage
- 對手翻牌 check = 弱牌訊號，轉牌 bet 可以偷底池

**適合 check 的情況：**
- 你有強牌，想讓對手補牌
- 你想等河牌建更大底池

#### 場景 3：翻牌對手 bet，你 call，轉牌

轉牌你是 OOP 的 caller：

**主要動作：**
- Check-call：有一定牌力，想看河牌
- Check-fold：沒改善，對手繼續 bet → fold
- Check-raise：轉牌讓你有很強的牌或 draw → 施壓

## 河牌策略

### 河牌是最終戰場

河牌的特殊性：
- **沒有後續街**，不需要考慮「保留 draw」
- 所有決策都是最終的
- Bluff 的成敗完全在於對手是否 fold

### 河牌 Value Bet

**原則：對手會 call 的時候 bet**

River value bet 的問題：「對手有什麼 call 我的？」

如果對手的 call range 比你的牌差 → bet（有 value）
如果對手只有比你更強的牌才 call → check（bet 沒有 value）

**河牌尺寸：**
- 薄 value（對手剛好能 call）：50-66% pot
- 厚 value（對手一定 call）：75-100% pot
- Overbet（對手 range 很弱）：125-150% pot，只在特定 line

### 河牌 Bluff

**原則：對手會 fold 的時候 bluff**

好的 bluff 手牌：
1. **Missed draw**：你有 flush draw，河牌 miss → 現在你有 air，bluff 假裝你 made 它
2. **有 blocker 的手牌**：你有 A，阻止對手有 nut flush/straight

**Bluff 的條件：**
- 對手的 call range 較弱（他 check/call 了兩條街，可能只有中等牌）
- 你的 bet 代表一個可信的 value range
- 對手沒有 trapped（不要對可能有強牌的人 bluff）

### 河牌 Check-Call / Check-Fold

當對手 bet 河牌：

**Check-call 的情況：**
- 你有中等牌，對手可能是 bluff
- 底池賠率值得 call
- Pot odds：所需勝率 = call 金額 ÷ call 後底池

**Check-fold 的情況：**
- 對手的 range 在這條 line 很強
- 你的牌無法 beat 任何 value hand
- 底池賠率不夠好

## 多條街打法的整合

### 三條街 Value（建大底池）

```
翻牌：Bet（value/build pot）
轉牌：Bet（繼續 value）
河牌：Bet（最大化 EV）
```

用於：set, nut flush, top two pair 對 call station 的對手

### 兩條街 Value（翻牌 + 轉牌）

```
翻牌：Bet
轉牌：Bet
河牌：Check-call 或 small bet
```

用於：TPTK 等中等強牌，控制底池

### 一條街 Bluff（翻牌 C-bet，放棄）

```
翻牌：Bet（miss 後 C-bet）
轉牌：Check/Fold（沒有 equity，放棄）
```

用於：純 C-bet bluff，翻牌沒中，不繼續

### 三條街 Bluff（高風險，高回報）

```
翻牌：C-bet bluff
轉牌：繼續 bluff（有 blocker 或 story）
河牌：大尺寸 bluff
```

用於：深疊，有可信 line，對手可能 fold 強牌
MTT 中相對少用（ICM 風險）

## MTT 多條街的特殊考量

### SPR 更低，更快 commit

MTT 盲注增長讓 SPR 比 Cash Game 低。
很多時候翻牌 C-bet 後，轉牌就已經是 all-in。

**調整：**
- 翻牌決定要 value 就要想好到底
- 不要翻牌 bet 轉牌 fold（commit 了就走完）

### ICM 讓多條街更保守

Bubble/FT 時：
- 避免在大底池做多條街 bluff
- 三條街 value 要確認對手能 call
- 謹慎 overbet bluff（被 call 損失巨大）
