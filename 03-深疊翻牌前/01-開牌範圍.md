# 深疊開牌範圍（25bb+）

## 為什麼 Open Size 很重要

Open size 影響：
1. **底池大小** → 影響翻牌後的 SPR
2. **對手跟注成本** → 影響對手 call range 寬度
3. **你的風險** → 影響你的 bluff 自由度

MTT 現代打法傾向 **小尺寸 open（2-2.5bb）**。

---

## 現代 MTT Open Size

### 標準 Open Size

| 位置 | Open Size | 理由 |
|------|---------|------|
| 任何位置 | 2-2.5bb | 節省籌碼，保持平衡 |
| 有 antes 時 | 2bb 或更小 | Antes 已經讓底池夠大 |
| 無 antes 早期 | 2.5-3bb | 底池相對小，open 大一點 |

**為什麼不 open 3bb+？**
- 現代打法已經精細化
- Open 小讓你的 range 更平衡（bluff 和 value 都一樣開）
- 省下的籌碼累積起來很可觀

---

## 各位置 Open Range

### BTN（最寬）

**100bb BTN open range：約 45-55%**

```
價值 open（無條件打到底）：
- QQ+, AK

標準 open（強牌）：
- 77-JJ
- ATs+, AJo+
- KTs+, KJo+
- QTs+, QJo

標準 open（中等牌，位置依賴）：
- 55-66
- A5s-A9s
- K8s-K9s
- Q8s-Q9s
- J8s-JTo
- T8s-T9s, T8o-T9o
- 97s-98s
- 86s-87s
- 75s-76s
- 64s-65s

Thin value / Bluff open（只在 BTN）：
- 22-44
- A2s-A4s
- K6s-K7s
- Q6s-Q7s
- J6s-J7s
- 85s
- 74s
- 63s, 53s
```

### CO（次寬）

**100bb CO open range：約 32-38%**

```
相對 BTN，去掉：
- 22-44（小對子折扣降低）
- 最低端的 suited connector（63s, 74s）
- 低端的 Kx, Qx suited
- 大部分 offsuit broadway 以外的牌
```

主要保留：
- 55+
- A2s+, ATo+
- KTs+, KJo+
- QTs+, QJo
- JTs, JTo
- T9s, T8s
- 98s, 97s
- 87s, 76s, 65s

### HJ（中等）

**100bb HJ open range：約 22-28%**

相對 CO，再縮緊：
- 去掉 22-44
- 去掉低端 Ax suited（A2s-A5s 視情況）
- 去掉低端 Kx（K8s-K9s 邊緣）
- 去掉中低端 suited connector（65s, 74s）

主要保留：
- 66+
- A8s+, AJo+
- KTs+, KQo+
- QTs+, QJo
- JTs
- T9s
- 98s

### UTG（最緊）

**100bb UTG open range：約 15-20%**

只打強牌：
- 88+
- ATs+, AJo+
- KQs, KQo
- QJs（邊緣）

**記憶法：** UTG range 的口訣：
> 對子 8 以上，Ace 配高牌，King Queen 同花，其餘謹慎

## Open Range 的邏輯

### 為什麼位置越後 range 越寬？

**資訊和後手優勢：**
- BTN open 後只需面對 SB/BB
- UTG open 後面有 5 個人可以 3bet 你

**平衡性需求：**
- UTG range 要 balanced，因為大家都知道你 UTG open = 強牌
- BTN range 可以 unbalanced 一點，因為偷盲成功率高

### Suited vs Offsuit 的差異

**同花牌（Suited）** 的加成：
- Flush draw 機率
- 可以做 semi-bluff
- Backdoor flush 增加 equity

**結論：**
同花版本的開牌門檻比非同花低約 2-3 個點。
例：K9s 可以 open，但 K9o 在某些位置需要更謹慎。

---

## 面對 Limp 的 Isolation Raise

在某些 MTT 中，鬆散玩家喜歡 limp。

**Isolation Raise（隔離加注）：**
當有人 limp，你跟著 limp 後面有玩家 limp → 加注將他們隔離。

**目的：** 和最弱的玩家（limp 者）單挑。

**尺寸：** 約 3bb + 每個 limp 者加 1bb
例：1 個 limp → open 3-4bb
    2 個 limp → open 4-5bb

**可以做 isolation 的手牌：**
比正常 open range 稍緊一點（因為尺寸更大，EV 門檻更高）

## 深疊 Open Range 速查

| 位置 | 大約寬度 | 記憶關鍵字 |
|------|---------|----------|
| UTG  | 15-20%  | 只打頂端強牌 |
| HJ   | 22-28%  | 移除最弱的小對子和套牌 |
| CO   | 32-38%  | 中等套牌開始進入 |
| BTN  | 45-55%  | 大多數有邊際價值的牌 |
| SB   | 38-45%  | 類似 CO，但翻牌後 OOP |
