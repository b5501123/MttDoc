# 偷盲與反偷策略

## 什麼是偷盲

**偷盲（Steal）：** 從 CO/BTN/SB 位置 open raise，目標是讓 SB/BB fold，直接拿走盲注。

為什麼 MTT 比 Cash Game 更重視偷盲？
- MTT 有 antes，底池更大，偷盲 EV 更高
- 盲注相對籌碼量隨時間增大，不偷盲 = 慢慢被吃死

---

## 偷盲的數學

### 有 Antes 時的底池

**例：BTN，盲注 100/200，antes 25，8人桌**

底池 = 100（SB）+ 200（BB）+ 25 × 8（antes）= **500**

你 open 2.5bb = 500：如果 SB/BB fold，你贏 500。
你的 open 投入：500（=2.5bb × 200）

**盈虧平衡點：**
你需要 fold equity 超過 50% 才能讓 open profitable（純 bluff 角度）
```
EV(steal) = P(fold) × 500 - P(call) × 500
= 0 when P(fold) = 50%
```
但你的手牌也有一定 equity，所以實際上需要的 fold equity 更低。

**結論：Antes 讓偷盲更有利可圖。**

---

## Steal 位置和頻率

### BTN Steal
- 偷盲最有利的位置
- 只需要過 SB/BB 兩人
- 典型 steal range：45-55%（和 BTN open range 幾乎一樣）

### CO Steal
- 次佳位置
- 需要過 BTN/SB/BB
- 典型 steal range：30-38%

### SB Steal（對 BB）
- 只需要過 BB 一人
- 但 SB 翻牌後 OOP
- 典型 steal range：50-60%（比 BTN 更積極，因為只有一個人）

## 反偷（Resteal / 3-bet Bluff）

**反偷** = 對偷盲者做 3-bet，強迫他 fold。

### 什麼時候反偷有利？

1. **對手偷盲頻率高**：BTN 或 CO 開牌頻率 >30%
2. **你在 SB 或 BB**：你有反偷的位置
3. **你有 fold equity**：對手的 Stack 讓 3-bet 有意義
4. **ICM 允許**：不在高 ICM 壓力的場景

### 反偷的手牌選擇

**反偷不需要強牌，需要合適的牌：**

```
好的反偷手牌：
- A5s-A2s（Ace blocker + suited，被 call 後有 equity）
- KQs, KJs（強牌，可以 value + bluff）
- 76s, 65s, 87s（suited connector，被 call 後有翻牌潛力）
- 小對子（22-55）偶爾混入（被 call 後有 set 機率）

差的反偷手牌：
- K5o, Q8o（沒有 blocker，沒有翻牌潛力）
- 9To（邊際手牌，被 call 後 OOP 很難打）
```

## Blind vs Blind 對決（SB vs BB）

當所有人 fold 到 SB，SB 和 BB 的對決是**最難打的場景之一**。

### SB 的策略

**SB 應該 raise or fold，幾乎不 limp：**
- Limp 讓 BB 免費看牌，你翻牌後 OOP，優勢消失
- Raise 可以拿走 BB 的 fold 機率

SB raise range 很寬（50-70% 視 stack 深度）：
- 深疊：約 50-55%
- 中疊（30-40bb）：約 40-50%（3-bet 後幾乎 committed）
- 短疊（≤15bb）：push/fold

SB raise size：約 2.5bb（稍大於標準，因為 OOP）

### BB 的防守策略

**BB 面對 SB steal 的選擇：**

1. **Call**：翻牌後 IP（SB 先行動），有機會
2. **3-bet**：驅逐 SB 或建立更大底池
3. **Fold**：只 fold 最差的牌

**BB 面對 SB 的 3-bet range：**
很寬，因為 SB 的 steal range 很寬。
BB 可以用約 18-22% 的 range 3-bet。

```
BB 3-bet value：QQ+, AK, AQs
BB 3-bet bluff：A2s-A5s, KQs, suited connectors, 各種 bluff
BB call：中等強度的牌，翻牌後準備打
```

## 偷盲的 ICM 考量

### 大疊偷盲最有利

你是大疊 BTN，中疊在 SB/BB：
- 他們 ICM 壓力大（怕出局）
- 他們 defend/3-bet 頻率比正常更低
- **你的 steal 成功率更高**

### 中疊被偷盲

你是中疊 BB，大疊 BTN open：
- 你 call 後，輸了可能 bubble out
- 你的 defend range 要比正常更緊
- 只 call/3-bet 你真正確定的手牌

### 短疊盲注的特殊性

短疊在 BB（<10bb）：
- 你幾乎被迫 call 任何 push（pot odds 太好）
- 但非 push 的 open，你可以更謹慎

## 調整對手的偷盲策略

### 當對手偷盲太積極時

觀察：BTN 每 3 手就偷一次，open range 很寬

**你的調整：**
- 在 BB/SB 加大 defend range
- 加入更多 3-bet bluff（他被 3-bet 會更容易 fold）
- Call 更多，翻牌後積極用 position 打

### 當對手偷盲太保守時

觀察：BTN open 很少，range 很緊

**你的調整：**
- BB/SB fold 更多（對手 open = 強牌）
- 如果你在 CO 或更早的位置，可以更積極 steal（他不會輕易防守）

## 常用思路框架

**每次面對偷盲場景問自己：**

```
1. 對手的偷盲頻率高嗎？（鬆散 vs 保守）
2. 我現在幾 bb？（影響 3-bet 後的 SPR）
3. ICM 壓力高嗎？（Bubble/FT）
4. 我有 fold equity 嗎？（對手 stack 夠大嗎）
5. 我的手牌適合 call 還是 3-bet？
```

**記憶口訣：**
```
BTN 偷盲 = 必須積極
SB 偷 BB = 寬 range，raise or fold
BB 守盲 = 用 pot odds，寬 call，偶爾反偷
中疊被偷 + Bubble = 縮緊，不亂反偷
大疊偷盲 = 最有利的時機
```
