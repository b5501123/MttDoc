# 位置重要性：為什麼 BTN 是金礦

## 位置的定義

**Position（位置）** = 你在這手牌中的行動順序。

- **IP（In Position）**：你最後行動 → 資訊優勢
- **OOP（Out of Position）**：你先行動 → 資訊劣勢

MTT 中位置的價值比 Cash Game **更高**，因為犯錯的代價是出局。

---

## 6-max 位置圖

```
        BTN（按鈕）
       /            \
   SB（小盲）      CO（切牌）
      |                |
   BB（大盲）      HJ（劫持位）
       \            /
        UTG（槍口位）
```

**行動順序（翻牌前）：**
UTG → HJ → CO → BTN → SB → BB

**翻牌後行動順序（固定）：**
SB → BB → UTG → HJ → CO → BTN

BTN 翻牌後**永遠最後行動**，是最強的位置。

---

## 各位置特性

### BTN（Button，按鈕位）
**最強位置**

優點：
- 翻牌後永遠 IP
- 對 SB/BB 有位置優勢
- 可以用最寬的 range open
- Steal equity 最高

典型 open range：45-55%（深疊）
典型 push range（10bb）：65-70%

**打法：**
- 積極偷盲
- IP 可以做更多 bluff
- 面對 3bet 可以更寬 call（因為有位置）

---

### CO（Cutoff，切牌位）
**第二強位置**

優點：
- 翻牌後對 SB/BB IP
- 對 BTN OOP，需要注意

典型 open range：30-40%（深疊）
典型 push range（10bb）：55-60%

**打法：**
- BTN 沒有行動時，打法接近 BTN
- BTN 在時，縮緊 range（因為 BTN 有位置優勢）

---

### HJ（Hijack，劫持位）
**中等位置**

典型 open range：22-28%（深疊）
典型 push range（10bb）：45-50%

**打法：**
- CO 和 BTN 都可能有位置，需要更強的牌
- 適合做 squeeze（當有人 limp 時）

---

### UTG（Under the Gun，槍口位）
**最弱位置（6-max）**

翻牌後對所有人 OOP（除非大家都 fold）

典型 open range：15-20%（深疊）
典型 push range（10bb）：35-40%

**打法：**
- 只打強牌
- Range 要 strong 且 balanced
- Bluff 頻率最低

---

### SB（Small Blind，小盲）
**特殊位置**

翻牌前最後一個行動，翻牌後第一個行動。
OOP 優勢 = 翻牌前可 steal，但翻牌後代價高。

典型 open/steal range：50-60%（deep）
典型 push range（10bb）：55-65%

**打法：**
- 面對 fold to BTN 時，積極 steal
- 面對 BTN open 時，3bet 比 call 更好（avoid BB squeeze）
- BB 只有一人防守，偷盲成功率高

**SB 的特殊困境：**
call → 翻牌後 OOP（差）
3bet → 翻牌後仍 OOP，但縮小底池
fold → 損失小盲（但有時最好）

> 建議：SB 的 limp 非常少，多數情況是 fold 或 raise/push

---

### BB（Big Blind，大盲）
**防守位置**

翻牌前最後行動（可以 defend 或 3bet）
翻牌後對所有人 OOP

**BB 的獨特性：**
- 已經投入 1bb，所以 defend 的 pot odds 比其他位置好
- 任何位置 open，BB 都是以 1bb 的折扣 defend

**Pot Odds 計算：**
面對 BTN open 2.5bb：
```
需要投入：1.5bb（已有 1bb，補到 2.5bb）
底池：4bb（BTN 2.5 + SB 0.5 + BB 1）
所需勝率：1.5 / (4 + 1.5) = 27%
```
所以 BB 面對 BTN open 需要 **27% 勝率**才值得 call。

這讓 BB 的 defend range 相當寬（但翻牌後 OOP 難打）。

---

## 位置影響 Range 寬度

**同樣 10bb 的 push range：**

| 位置 | 估計 Push Range |
|------|----------------|
| UTG  | ~35%（JTo+, A8o+, A2s+, KTs+...）|
| HJ   | ~45%（T9o+, A6o+...）|
| CO   | ~55%（97o+, A4o+...）|
| BTN  | ~67%（85o+, A2o+...）|
| SB   | ~60%（vs BB only）|

---

## 位置 × ICM 的交互效應

**Bubble 時位置影響更大：**

你是大疊 BTN，對手都是中短疊 → 可以更積極 steal
你是中疊 BB，大疊 BTN open → 你的 ICM 壓力讓你 fold 更多
你是短疊 UTG，在 bubble → push range 反而比非 bubble 更緊

**大疊的位置紅利：**
大疊在 BTN = 雙重優勢（位置 + ICM 壓力免疫）
大疊在 BB = 只有 ICM 優勢，位置弱

---

## 實戰記憶點

```
位置越晚 = range 越寬 = 偷盲更頻繁
IP 翻牌後 = 多一條街的 bluff 機會
OOP 翻牌後 = 需要更強牌才能繼續
BB = 用 pot odds 寬 defend，但翻牌後要謹慎
SB = 偷 or fold，很少 limp
```
