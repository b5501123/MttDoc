# 不同報名結構調整

## 報名結構的種類

### 1. 單次報名（Freezeout）
傳統格式，報名一次，出局就結束。

### 2. 再買入（Re-buy）
在限定時間內（通常第一小時）可以重新購買籌碼。

### 3. 加購（Add-on）
特定時間可以加購額外籌碼（通常比原始報名費更划算）。

### 4. 無限再買入（Rebuy + Add-on）
再買入期間可以任意次數重新購買。

### 5. 延遲報名（Late Registration）
正式開始後一段時間仍可報名（通常帶滿起始籌碼）。

---

## 再買入期間的策略

### 核心問題：你願意再買入嗎？

**如果你願意再買入：**
再買入期間的 EV 計算改變：
- 出局不是終結，而是「付一次費用重來」
- 這讓你可以更激進

**如果你不願意再買入：**
按照標準 Freezeout 策略打。

---

### 再買入期間的積極打法

**前提：你決定最多再買入 N 次**

在再買入期間：
1. **Chip EV 最優先**：ICM 幾乎不存在，打Chip EV
2. **追求更多籌碼**：帶更多籌碼進入 freeze 階段有巨大優勢
3. **接受更高風險**：幾乎像 Cash Game 打

**策略改變：**
- 更積極的翻牌後打法（bluff 更多）
- 更寬的 3-bet range
- 更多的 set mining（小對子，隱含賠率好）

### 再買入期間的一個陷阱

**不要無腦送錢給對手：**
即使可以再買入，也不應該用很差的牌 all-in。
目標是獲得**更多籌碼**，不是浪費金錢。

**再買入策略的邊界：**
```
可以：積極建底池，主動出擊，接受較高風險
不可以：用 72o all-in，用不合理的純 bluff 燒錢
```

---

### 加購時間點的策略

**加購通常在 break 時：**
- 加購費用通常 = 初始報名費
- 獲得的籌碼通常比初始更多（更有 EV）

**應該加購的條件：**
1. 加購的籌碼對你有價值（你還在 field 中有競爭力）
2. 加購費用 = 正期望值的長期投資

**不應該加購的情況：**
你已經有遠超平均的籌碼，加購的邊際 EV 很低。

---

## 延遲報名（Late Registration）的策略

### 延遲報名的 EV 考量

**優點：**
- 可以觀察牌局走向再決定是否加入
- 節省早期盲注損耗
- 起始籌碼可能相對更多（其他人因為打牌有輸贏）

**缺點：**
- 起始籌碼相對其他人少（他們可能已積累更多）
- 早期技術優勢的窗口縮短

### 什麼時候延遲報名最有利

```
最適合延遲報名：
- 你只有有限時間，不能全程參加
- 賽事起始籌碼很深（200bb+），早期優勢不大
- 快速賽（早期也是 push/fold，進場時間不影響太多）

不適合延遲報名：
- 深籌碼慢速賽（早期技術優勢最大）
- 你想最大化 EV（早進場更好）
```

## Antes（前注）的影響

### 有 Antes vs 沒有 Antes

**沒有 Antes（早期）：**
底池相對小，open 成功率需求更高。

**有 Antes（中後期）：**
底池更大，偷盲 EV 提升。

```
例：盲注 100/200，8人桌，antes 25

無 antes 底池：100 + 200 = 300
有 antes 底池：100 + 200 + 25×8 = 500（+66%）
```

**調整：**
- 有 antes 時，open range 放寬（底池更有利可圖）
- 偷盲的 EV 更高，更積極偷盲

### Big Blind Ante（BBA）

現代 MTT 常見格式：只有 BB 付 antes（等於 BB × 桌上人數）。

**影響：**
- BB 的成本更高（每 orbit 付更多）
- BTN/CO/SB 的 steal EV 更高（底池更大）
- 對 BB 的偷盲和對 BTN 的攻擊更有利

**調整：BBA 下 steal range 稍微放寬**

## 特殊賽制：衛星賽（Satellite）

### 衛星賽的目標

衛星賽不是贏最多籌碼，而是**進入一定名次**（例如贏得一張主賽入場券）。

```
例：100人參賽，10人拿到入場券（1st-10th 都一樣）
→ 目標：survive 到 top 10，不需要贏 1st
```

### 衛星賽的 ICM

衛星賽的 ICM 非常極端：
- 所有進錢名次獎金相同（都是一張券）
- 出局 = $0
- 進錢 = 固定金額

**這讓衛星賽的 ICM 和標準 MTT 完全不同。**

### 衛星賽的策略

**超級保守（接近 bubble 時）：**
- 即使 99% 勝率，如果輸了你出局，fold 可能更好！
- 確保 survive 比積累籌碼更重要
- 只和你 MUST 戰的對手打（短疊 push 進你的 BB）

**早期（離 bubble 很遠）：**
- 正常 Chip EV
- 積累籌碼，增加 survive 的安全墊

**衛星賽的極端例子：**
```
5人剩餘，4人進錢（拿到入場券）
你有 30bb，大疊 push all-in 對你

計算：
- 如果你 fold，你有 30bb，還有 3 個人需要出局
- 你的 survive 機率很高（其他人可能互打）

- 如果你 call 且贏（70% 機率）→ 你有更多籌碼
- 如果你 call 且輸（30% 機率）→ 你出局 $0

ICM EV（call）= 70% × 券 EV + 30% × $0
ICM EV（fold）≈ 保留高機率的 survive

結論：即使 70% 勝率，FOLD！
```

## 結構影響的綜合速查

| 賽制特徵 | 策略調整 |
|---------|---------|
| 再買入期間 | Chip EV 優先，更積極 |
| 有 Antes | 放寬 steal range，更積極偷盲 |
| BBA 格式 | steal EV 更高，BB 成本更高 |
| 延遲報名 | 進場時間影響早期策略 |
| 快速賽 | 更早 push/fold，積極早期積累 |
| 衛星賽 | 接近 bubble 超保守，survive > 積累 |
| PKO | 考慮賞金 EV，追殺大賞金目標 |
