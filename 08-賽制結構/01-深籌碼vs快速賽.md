# 深籌碼結構 vs 快速賽結構

## 為什麼賽制結構很重要

同樣是「MTT」，不同結構差異極大：

| 結構 | 起始 bb | 盲注等級時長 | 風格 |
|------|---------|------------|------|
| 深籌碼（慢速）| 200-300bb | 20-30分鐘 | 技術型 |
| 標準 | 100-150bb | 15-20分鐘 | 平衡 |
| 快速賽（Turbo）| 50-100bb | 5-10分鐘 | 運氣成分高 |
| 超快（Hyper Turbo）| 20-50bb | 3-5分鐘 | 幾乎純 push/fold |

---

## 深籌碼結構（Deep Stack）

### 特徵

- 起始籌碼 200bb+，盲注時間長
- 技術優勢持續時間長
- 可以玩複雜的翻牌後 line
- 後手多條街空間充足

### 深籌碼的策略調整

**1. 早期更主動積累籌碼**

因為後手有大量時間，早期不怕輸籌碼。
早期應該打 Chip EV，積極建底池。

```
深籌碼早期 ≠ 保守
深籌碼早期 = 積極用技術優勢積累籌碼
```

**2. 套牌（Implied Odds）價值更高**

200bb 深疊下，小對子、suited connector 的隱含賠率爆炸式提升。

```
以 22 為例（100bb 深疊）：
Set 機率 ≈ 11%
Set 後贏對手的 top pair = 可以贏 80-100bb

以 22 為例（200bb 深疊）：
Set 後可以贏 180-200bb
隱含賠率 = 翻倍
```

深籌碼應該更積極 call/open 小對子和 suited hands。

**3. 位置優勢最大化**

200bb 的三條街空間讓位置價值達到最高。
BTN IP 在 200bb 比 100bb 更有優勢（更多 float, bluff 機會）。

**4. 早期 ICM 影響極小**

深籌碼結構通常進 15-20% 玩家，早期離 money 很遠。
→ 純粹打 Chip EV，不考慮 ICM

---

## 標準結構（Standard MTT）

### 特徵

- 起始 100-150bb，15-20分鐘盲注
- 技術和運氣相對平衡
- 幾個小時後開始進入短疊場景
- 典型的 online 標準 MTT（PokerStars, WSOP）

### 標準結構的策略

這是本教材的主要參考基準，無需特殊調整。

---

## 快速賽（Turbo）

### 特徵

- 起始 50-100bb，10分鐘盲注
- 很快進入中疊/短疊場景
- Push/fold 比例更高
- 技術差異縮小（因為少了深疊階段）

### 快速賽的策略調整

**1. 早期更激進積累（縮短的時間窗口）**

你只有少數 orbit 的深疊時間：
- 別浪費早期的 EV 機會
- 積極偷盲，快速積累籌碼
- 不要等好牌，早期也要用位置優勢

**2. 更早進入 Push/Fold 思考**

標準 MTT 可能在 Level 6-8 才進入 short stack 場景。
快速賽可能 Level 3-4 就開始：
- 20-25bb 開始考慮 open-shove
- 15bb 確定進入 push/fold

**3. 技術邊緣縮小，基礎更重要**

快速賽對好的玩家沒那麼友善（技術發揮時間短）。
重點：
- 紮實的 push/fold 策略
- 快速判斷（沒時間慢慢想）
- 正確的 ICM 感覺

**4. 翻牌後打法更簡單**

快速賽籌碼相對較少，SPR 很快降低：
- 翻牌後很多場景已 committed
- 翻牌前的決策更重要
- 三條街複雜打法很少出現

---

## 超快速賽（Hyper Turbo）

### 特徵

- 起始 20-50bb
- 3-5分鐘盲注
- 幾乎全部是 push/fold
- 幾乎不需要翻牌後策略

### 超快速賽的策略

**基本上 = 純 Push/Fold 鬼**

**調整：**
- 幾乎不 open 小尺寸（直接 push/fold）
- 對手的 range 因為快速盲注而更寬
- 賽早期就要積極偷盲（不能等到短疊）

**必須精通的技能：**
- Push/fold Nash 圖表
- ICM 計算（短時間內就需要）
- 快速位置判斷

## Online vs Live MTT 結構差異

### Online 特點
- 一般是標準或快速結構
- 多桌（同時打多場）是常態
- 決策時間短
- HUD 數據可用

### Live 特點
- 通常是深籌碼（賽事級別）
- 每手時間較長
- 讀牌/心理戰更重要
- 疲勞是因素（長時間賽事）

**Live 深籌碼 MTT 的額外技能：**
- 讀牌型和桌面動態
- Live 告牌（timing tell, physical tell）
- 長時間集中注意力
- 在 tells 不準時的「調整回歸 GTO」

---

## 選擇適合你的賽制

**新手 → 標準結構：**
學習曲線最完整，技術範圍最廣。

**想練技術 → 深籌碼：**
翻牌後技術完全發揮，技術差異最大。

**想快速獲利 → 快速賽：**
縮短技術周期，push/fold EV 更重要。

**時間有限 → 超快速賽：**
15-20分鐘可以打完一場，決策簡單。
