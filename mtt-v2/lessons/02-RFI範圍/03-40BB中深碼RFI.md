# 40BB 中深碼 RFI：開始重視反擊成本

## 場景設定

Effective stack 40BB。你仍可 open/fold，但 3bet pot 的 SPR 已下降，邊界手牌被反擊時更難舒服防守。

## 核心觀念

- 40BB 是線上 MTT 最常見的工作深度。
- 後位仍可偷盲，但要知道哪些牌能面對 3bet。
- 前位 open 被 3bet 時，不要用 dominated offsuit broadway 硬撐。
- 小對不再單靠 set mining 支撐所有 open。

## 操作流程

1. 先用 40BB RFI 表找 baseline。
2. 標記 R+、R、M，M hand 只在盲位偏緊或桌子偏被動時加入。
3. 面對 3bet，先把 value continue 與 fold 分清楚。
4. 若後面有 20BB aggressive stack，要預先規劃被 rejam。

## Range 表

- 40BB 9-max RFI 全位置。
- 40BB BB defend vs HJ/CO/BTN。

## 邊界手牌

- AJo：HJ 以後較自然，UTG/LJ 要看桌況。
- KQo：前位可開但怕被 3bet；後位價值上升。
- T9s/98s：位置好才舒服。
- 22-44：面對短碼盲位時不再純靠 set value。

## 常見錯誤

- 40BB BTN 亂開，卻不知道被 18BB jam 要不要跟。
- CO 開太多低 offsuit Kx。
- 把 40BB 當 100BB 打，postflop 過度浮動。

## 練習

1. 40BB CO KTo，BB 18BB aggressive，是否 open？
2. 40BB LJ 66，後面有兩個 25BB rejam stack，如何調整？
3. 40BB BTN Q8o，兩盲都 tight，是否加入？
