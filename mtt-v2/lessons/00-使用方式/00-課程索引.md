# MTT v2 課程索引

## 場景設定

本課程只針對線上 NLH MTT、Big Blind Ante、8-max / 9-max、多桌環境。舊版文章式教材不作為 v2 內容來源。

## 你要先記住的規則

- 先學 stack mode，再學單張手牌。
- 每個 preflop spot 都必須連到 range 表。
- Range 是 baseline，不是永遠不變的命令。
- 練習題要能反推你是否真的懂 range。

## Range 表

- 先看 RFI，再看 BB defend，再看 rejam / push-fold。
- 範圍表頁可依 stack、spot、position 搜尋。

## 邊界手牌

邊界手牌不是背答案，而是看 stack、ICM、盲位玩家與 opener 類型做調整。每次遇到 mixed hand，先問：如果被 rejam，我是否知道要不要跟？如果答案是否定，這手牌通常不該無腦 open。

## 常見錯誤

- 只讀文章不看表。
- 把 40BB open range 套到 20BB。
- 用 push range 去 call shove。

## 練習

1. 打開 25BB BTN RFI，列出三手 raise-call 和三手 raise-fold。
2. 打開 10BB CO Push/Fold，說明 KTo 是否可推。
