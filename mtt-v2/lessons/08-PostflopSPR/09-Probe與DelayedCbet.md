# Probe 與 Delayed C-bet：對手示弱後再拿回主動

## 場景設定

Preflop aggressor flop check back，turn 到你或你在位置上面對第二次 check。這是線上 MTT 常被忽略的盈利點。

## 核心觀念

- Flop check back 後，turn probe 可以攻擊 capped range。
- Delayed c-bet 適合有 showdown value 或 backdoor equity 的 flop check。
- OOP probe 要看 turn 是否改善你的 range。
- 短碼時 probe size 要避免把自己綁死。

## 操作流程

1. 先判斷 flop check back 代表對手 range 是否 capped。
2. Turn 若改善你的 range，可用中小 size probe。
3. 有 showdown value 的牌不要過度轉 bluff。
4. River 只延續 blocker 好或 value 清楚的牌。

## Range 表

- BTN RFI vs BB defend。
- CO RFI vs BB defend。

## 邊界手牌

- Turn A/K：常改善 preflop aggressor。
- 低牌配對：常改善 BB defend。
- Second pair：可 check-call，不必硬 probe。
- Nut draw：可 probe 建立 fold equity。

## 常見錯誤

- 對手 flop check back 就 turn 亂打。
- 沒有 river 計畫就 probe。
- 短碼 probe/fold 浪費太多 stack。

2. BTN open BB call，flop K72r 你 check back AQ，turn 5 是否 delayed c-bet？
